# Assets

标了不进 git 的，缺了从商店再导入，不要在仓库里补一份。

## 代码

`Scripts/`。怎么写见 [`Scripts/README.md`](Scripts/README.md)。目录表在 [`../Docs/代码分析/构架设计.md`](../Docs/代码分析/构架设计.md)。
