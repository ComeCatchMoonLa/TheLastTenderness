# Scripts

技术栈是 Unity + C#。命名空间 `CatchMoon`。`Animator/HandleState/` 下的状态行为在全局命名空间。

类型是 MonoBehaviour、Animator 的 `StateMachineBehaviour`、ScriptableObject。

目录职责以 [`../../Docs/代码分析/构架设计.md`](../../Docs/代码分析/构架设计.md) 的目录表为准。

先在本目录找已有类型。找不到时，不要为了通过编译造临时代替。技术设计里标 **[待确认]** 的接口形状由用户决定。目录名和已有类型名保持现状，包括拼写。未进入的版本不要提前搭空壳，也不要改写成另一套纯 C# 战斗核心。
