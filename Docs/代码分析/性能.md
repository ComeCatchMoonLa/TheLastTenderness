# 性能

> **没有测过帧时间。** 下面只保留每帧都会发生的堆分配，或每次更新里数量随场景物体增长的物理查询。单次、无分配的射线不单列。模块分层见 [构架设计.md](构架设计.md)，可读性与修改代价见 [可维护性.md](可维护性.md)。

## 每帧物理查询热点

### 交互检测

`PlayerManager.Update` 在玩家未死亡时调 `CheckForInteractableObject`。`OverlapSphereNonAlloc` 写入组件上长度 1 的同一块数组，不再每次 `new`。范围内有交互物时才 `GetComponent<Interactable>` 并刷新提示。

### 锁定开启后每帧扫一次 npc 层

`PlayerCameraManager.Update` 调 `LockOnQuery.UpdateLockOnTargets`，`lockOnMode` 为假立刻返回。为真时每个显示帧：

- `OverlapSphereNonAlloc`（半径 `maxLockOnDist`，层 `npc`）。候选数组初始 `new Collider[32]`，留在组件上，经 `OverlapQuery.CollectOverlaps` 装满才倍增；
- 每个碰撞体一次 `GetComponent<CharacterManager>`；
- 每个尚在扇形内的候选人一次 `Linecast`；
- `lockableTargets` 先 `Clear` 再 `Add`；
- 已有当前目标时，`HandleChangeLockOnTarget` 可能再打一条 `Linecast`。

查询量跟着锁定半径内的碰撞体数量走。

### 近战待机每帧探测玩家

`EnemyManager.Update` 在未死亡时跑当前状态 `Tick`。处于 `IdleState`（人形子类沿用）时，AI 开着、未交互，则每次 `Tick` 对玩家层做一次 `OverlapSphereNonAlloc`（数组留在状态上，初始 16，装满倍增），命中后再可能 `GetComponent` 与 `Linecast`。没有独立 AI 节拍。`AmbushState.Tick` 也走同一查询。锁定与待机都调 `OverlapQuery.CollectOverlaps`。

## 每帧分配

逐方法扫过全部含 `Update` / `FixedUpdate` / `LateUpdate` 的文件：帧循环体内没有 `new`，也没有无条件字符串拼接。唯一插值日志在 `LadderRide.Update`，但被 `climbSpeedLogged` 一次性门闩保护。`ToString()` 共 9 处，全部在窗口刷新或数值变更方法里，不在帧循环。FPS 文本每 300 帧拼一次字符串。

命中时才发生的分配：血溅、法术、炸弹、弹药嵌入的 `Instantiate`。

## 查过、不单列的热路径

这些每帧或每物理步都跑，次数固定，没有看到堆分配或随场景物体数增长的查询：

- `PlayerLocomotionManager.FixedUpdate` 的移动、转向和 `HandleFall`：人在地上也打向前、向下各一次 `Raycast` 并 `Debug.DrawRay`；向前那次不传层。`"Land"` 只在刚着陆的那一步播。
- 非瞄准时 `HandleCameraCollisions` 每个 `LateUpdate` 一次环境层 `SphereCast`。
- `FindAnyObjectByType` 全工程 8 处、7 个文件，全部在 `Awake`/`Start`（玩家找相机、相机找玩家、敌人血条找玩家、敌人属性找 `WorldManager` 和玩家）。敌人死亡沿用开局缓存引用，不在每帧查找。旧 API `FindObjectOfType` 0 处。工程内没有 `LINQ`、`SendMessage`、C# `event`/`UnityEvent`、静态 `Instance` 单例。
- `GetComponentsInChildren` 共 43 处，绝大多数在 `Awake`/`Start`/装载路径；命中回调里的 `DamageCollider`、每支箭的 `ShootArrowAction`、上 Buff 时的 `WeaponBuff` 是少数非初始化处。
- 动画参数：`UpdateAnimatorValues` 两次阻尼 `SetFloat`，`CharacterManager.UpdateBoolsValue` 每帧三次 `SetBool`，`UpdateHandIKWeight` 每帧写双手 IK 权重。没有 `SetLayerWeight`。
- 持箭未瞄准时，`PlayerEffectsManager.Update` 对 Animator 第 4 层取一次状态，用 `shortNameHash` 比较。
- `PlayerStatsManager.RegenerateStamina` 在不交互、不冲刺、过 1 秒且未满时，每显示帧改体力并写一次条。冻伤/剧毒时回复系数会变。
- 小怪血条脚本挂在自身 `Slider` 上，隐藏后物体不活动。

## 已知低风险疑点（非每帧恒定开销）

- **`LadderRide.Update` 每帧 `GetComponent<PlayerManager>()`**（并每帧读 `player.input`）：只在爬梯状态，建议像其他 Manager 一样缓存。
- **`CampFireInteractable` 每次尝试休息用分配版 `Physics.OverlapSphere`**（new 碰撞体数组）并对每个命中 `GetComponentInParent<EnemyManager>()`：事件触发、非每帧，但与交互检测那条复用 NonAlloc 数组的做法不一致，可统一。
