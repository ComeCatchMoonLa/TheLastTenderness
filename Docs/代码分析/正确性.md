## 查过、对得上

### 移动、镜头、精力与负重

- **FR-移动-01～04、FR-移动-06。** `HandleMove` 在未交互、无待处理翻滚时按镜头水平方向移动，非冲刺不扣精力。按住闪避且移动量大于 0、未瞄准、未格挡、精力高于 `sprintNeedMinStamina` 时置冲刺，用 `sprintSpeed` 并每物理步 `DeductStamina(sprintCost)`，落到门槛及以下则停。短按松手：有移动量播 `Rolling`，无移动量播 `Backstep`；`DeductStamina` 失败则不播、精力不变。交互动画里不再改速度。
- **FR-移动-05 的起跳与着地。** 有移动量、未瞄准、未交互、精力够时播 `Jump`。瞄准中按跳跃直接返回。离地后播 `Falling`。着地切一次，见上一节。
- **FR-镜头-01、FR-镜头-02。** 未锁定、未瞄准时绕角色转，俯仰夹在仰角限制里，平滑跟随。未瞄准时碰到环境就拉近，挡住消失后回到默认距离。
- **FR-镜头-03～06。** 左手不是弓时按锁定键进入锁定；范围内有未死亡、视线未被挡住的目标才锁上，再按一次解除。锁定后镜头水平朝向目标；未冲刺、未翻滚且 `canRotate` 时身体朝目标，冲刺或翻滚时朝移动方向。关闭自动换目标时左右键改锁两侧目标。超出距离或被挡住时改锁更近的合格目标，没有就解除。敌人死亡时先解除，再打开锁定并重新查找。
- **FR-镜头-08。** 双手持弓且有箭时进入瞄准，镜头跟到瞄准机位，角色水平朝向跟着视角。松开瞄准键清掉瞄准；已锁定则回到锁定镜头。左手是弓时锁定键直接返回。瞄准期间胶囊半径保持 0.4，离开后写回。
- **锁定时的翻滚。** 调研写锁定后翻滚朝目标的前后左右、身体继续面向目标。FR-镜头-04 写翻滚期间身体朝移动方向。`HandleRoll` 按当时移动方向转向，与 FR-镜头-04 一致。
- **跳跃与掉落扣血。** 调研写从冲刺里起跳、高处落下按高度扣生命。FR-移动-05 写有移动量、精力够就播 `Jump`。掉落扣血不在这四篇需求里。
- **FR-精力-01～05。** 进游戏时精力等于上限。冲刺、翻滚、后撤、跳跃在 `DeductStamina` 成功后才改条。轻重击按武器基础消耗和轻重系数扣。冲刺或交互动画把回复计时清零；两者都结束后超过 1 秒才涨，并且不超过上限。举盾且未冲刺、未在交互动画时用格挡回复速率。精力小于等于 0 时轻重击直接返回。
