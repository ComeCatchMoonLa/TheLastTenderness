## 已修复

下表是当时四份分节认定的大出入。代码已按版本改过，不再当作未关闭的偏离。

| 出入 | 版本 | 现在的结果 | 详见 |
| --- | --- | --- | --- |
| 付不清的一记格挡不破防 | 0.16 | `DeductStamina` 返回 false 时 `EmptyStamina` 把精力写成 0，再走破防。翻滚不够仍不扣 | [战斗](战斗.md) |
| 侧面在距离稍远时也算挡住 | 0.17 | 点积前先把指向攻击者的向量归一化，阈值仍是 `0.3` | [战斗](战斗.md) |
| 护甲槽选中后再点背包武器，武器离开背包 | 0.18 | 不是四个武器槽时，在 `RemoveItem` 之前返回 | [物品与法术](物品与法术.md) |
| 投射法术打中一律进火段 | 0.19 | `pyromancy` 进火，`sorvery` 进魔，`miracle` 进雷。火球仍只进火段 | [物品与法术](物品与法术.md) |

0.20、0.21 修的是 [`../代码分析/可维护性与性能.md`](../代码分析/可维护性与性能.md) 里的两条，不在上面这张偏离表里：瞄准期间不把胶囊半径写回默认；喝药和炸弹一样，结算认按下时的那一件。
