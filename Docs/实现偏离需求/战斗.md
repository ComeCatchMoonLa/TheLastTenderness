# 战斗实现偏离

> **当前没有未关闭的大出入。** 轻重攻击、双手、挥击窗口、同队、无敌、破韧比较、背刺扣一次，以及架势和踢击，不记偏离。

对照的是 [`Docs/需求文档/功能需求/`](../需求文档/功能需求/) 里轻重攻击、命中伤害、霸体硬直、背刺处决、架势踢击。行为以 `Assets/Scripts` 为准。和调研打架时，可观察结果以 [`Docs/调研文档/战斗系统.md`](../调研文档/战斗系统.md) 为准。[`Docs/调研文档/本仓库对照.md`](../调研文档/本仓库对照.md) 里「穿甲只写物理吸收」「炸弹同一人结算两次」「背刺 `pendingCriticalDamage` 读到 0」已经和现在代码对不上，不拿来当偏离。

## 查过、不记偏离

标了待补，或整段还没有对应行为的，只核对代码里有没有已经在跑、并且和需求正文对不上的结果。

| 条目 | 结论 |
| --- | --- |
| FR-攻击-01、02、03 | `LightAttackAction`、`HeavyAttackAction` 在精力小于等于 0 时不开始。不在连击窗口且 `isInteracting` 时不开始。窗口内由 `MeleeAttackSegment` 在 `lastAttack` 等于第一段时改播第二段，并写成 `light_2` / `heavy_2`。窗口外再点回到第一段。 |
| FR-攻击-04 | 右手且 `isTwoHandingWeapon` 时改播 `thLightAttack*`、`thHeavyAttack*`。切回单手再回到单手字段。玩家输入仍调用 `oh_*` 槽，需求正文写明是这样。 |
| FR-攻击-05 | `BlockAction` 把 `isBlocking` 写成 true，`PlayTargetAnimation("Block - Start", false, true)` 不锁交互动画。`PlayerLocomotionManager.HandleMove` 仍会改速度。松开格挡键时 `PlayerCombatManager.Handle_Hold_Q_Input` 把 `isBlocking` 写成 false。左手盾走 `isUsingLeftHand`，吸收读左手武器。 |
| FR-攻击-06 | 待补。`ParryAction` 单手只播 `weapon_art`，不读专注；双手分支是空的。没有另做武器技类型。 |
| FR-攻击-07 | `CharacterAnimatorManager.OpenDamageCollider` / `CloseDamageCollider` 开关当前手的伤害体。片段没挂事件时打不中，需求正文就是这个结果。 |
| FR-伤害-01、02、03 | 打中走 `DamageCollider.DealDamage` → `ResolveIncomingHit` → `TakeDamage`，生命下降后玩家和敌人刷新血条，降到 0 进 `Death`。`teamID` 相同直接返回；武器装上时 `CharacterWeaponSlotManager.LoadWeaponDamageCollider` 把伤害体 `teamID` 写成角色的。`isInvulnerable` 为真时 `TakeDamage` 返回，生命和受击动画都不变。 |
| FR-伤害-05 | 待补。同一次挥击仍没有「已经打过这人」的记录。 |
| FR-伤害-06 | 待补条文里的「穿戴只写物理吸收」已经过时。`PlayerArmorManager.EquipAllArmorModels` 把头、躯干、下身的物理和火、魔、雷、暗都写进属性，`TakeDamage` 按部位合成。穿上有元素吸收的甲，对应伤害会少于赤裸。这是需求要的结果，不记偏离。 |
| FR-伤害-08 | 待补。武器和结算里没有打击、斩击、突刺分开的吸收。 |
| FR-硬直-01、02 | `ResolveIncomingHit` 先减去 `poiseBreak`，剩下的仍大于这一次 `poiseBreak` 就只扣血、动画名为空；否则把受击动画名传给 `TakeDamage`。`PlayTargetAnimation` 把 `isInteracting` 写成 true，`HandleMove` 不再按输入改速度。这和需求括号里的比较一致。 |
| FR-硬直-03 | 计时结束后 `totalPoiseDefence` 回到 `armorPoiseBonus`。0.28 起玩家也不再等 `isInteracting`。默认仍是 15 秒。 |
| FR-硬直-04、05 | 待补。进攻韧性只在动画事件 `GrantWeaponAttackingPoiseBonus` 被调用时加上。`armorPoiseBonus` 没有穿戴写入。`poiseLevel` 不参与结算。 |
| FR-处决-01 至 05 | 整篇待补。剑的 `oh_hold_e_action` 是 `CriticalAttackAction`，按住 E 会射线检测：背后点积约 -1 到 -0.8 进 `GetBackStabbed`，正面且 `canBeRiposted` 进 `GetRiposte`。伤害一次，用攻击者 `rightWeapon`，经 `ResolveIncomingHit` 且不走格挡和韧性。角度不够时这次按键没有攻击，不会退回普通轻击。没有鞭、野兽分支。`canBeRiposted` 只在弹反命中时写 true，成功处决时写 false，没有到时清除。这些都是待补正文里还没做完的部分，不记偏离。 |
| FR-架势-01 至 05 | 整篇待补，对照也写未找到类型。没有架势动作、没有踢击动作，也没有成对武器连段。`CombatStanceStateHumanoid` 是敌人周旋，不是武器架势。 |
