## 查过、不进主表

### 移动

- **FR-移动-01～04、FR-移动-06。** `PlayerLocomotionManager.HandleMove` 在未交互、无待处理翻滚时按镜头水平方向移动，非冲刺不扣精力。按住闪避且移动量大于 0、未瞄准、未格挡、精力高于 `sprintNeedMinStamina` 时 `HandleRollInput` 置冲刺，`HandleMove` 用 `sprintSpeed` 并每物理步 `DeductStamina(sprintCost)`，落到门槛及以下则停冲刺。短按松手：有移动量播 `Rolling` 并 `LookRotation(moveDir)`，无移动量播 `Backstep`；`DeductStamina` 失败则不播、精力不变。交互动画里 `HandleMove` 不再改速度。
- **FR-移动-05。** 有移动量、未瞄准、未交互、精力够时 `HandleJump` 播 `Jump`。瞄准中按跳跃直接返回。离地后 `HandleFall` 播 `Falling`。着地只在这一帧 `wasInAir` 为真时发生：落差够播 `Land`，落差不够播 `NonCombat Whole Body Empty`。需求段后半仍写「每个物理步再切一次 `Land`」「`Falling` 没有出口」，那句已经对不上脚本。玩家看到的是着地切一次。
- **FR-移动-07、FR-移动-08。** 两条都标待补。`HandleRollState` 只写 `isRolling`。非冲刺用同一个 `runSpeed`。

### 镜头

- **FR-镜头-01、FR-镜头-02。** 未锁定、未瞄准时 `HandleDefaultCameraRotation` 绕角色转，俯仰夹在 `minLookUpAngle`～`maxLookUpAngle`，`SetCameraPos_DefaultMode` 平滑跟随。鼠标量在当次 `LateUpdate` 乘进角度。未瞄准时 `HandleCameraCollisions` 碰到环境就拉近，挡住消失后距离回到 `defaultCameraForwardDist`。
- **FR-镜头-03～06。** 左手不是弓时按锁定键进 `lockOnMode`；范围内有未死亡、视线未被环境挡住的目标才置 `lockOnFlag`，再按一次 `Unlock`。锁定后 `HandleLockedCameraRotation` 水平朝向目标；`HandleRotate` 在未冲刺、未翻滚且 `canRotate` 时身体朝目标，冲刺或 `isRolling` 时朝 `moveDir`。`HandleEmptyState` 进入时把 `canRotate` 写成 true。关闭自动换目标时（`GameSettings.asset` 里 `autoChangeLockOnTarget` 为关），左右键改锁 `leftLockableTarget` / `rightLockableTarget`。目标超出 `maxLockOnDist` 或被环境挡住时，`HandleChangeLockOnTarget` 改锁更近的合格目标，没有就解除。死亡走 `EnemyStatsManager.HandleEnemyDeathEvent`：先 `Unlock`，再把 `lockOnMode` 打开并 `UpdateLockOnTargets`。
- **FR-镜头-07。** 标待补。HUD 里没有锁定标记类型。
- **FR-镜头-08。** 双手持弓且 `currentAmmo` 有箭时 `AimAction` 把 `aimingMode` 写成 true。镜头姿态只读这个旗标，跟到 `cameraTransformWhileAiming`。`HandleAimingCameraRotation` 让角色水平朝向跟着视角。松开格挡/瞄准键时 `PlayerCombatManager.Handle_Hold_Q_Input` 把 `aimingMode` 清掉，已锁定则回到锁定镜头。左手是弓时 `HandleLockOnInput` 直接返回。偏移在瞄准、锁定、自由三处共用 `pivotOffsetVelocity`。0.20 之后，`aimingRadiusApplied` 为真时 `ResetCollider` 不写半径，瞄准期间保持 0.4，离开后写回进入前。
- **调研 [`../调研文档/移动与镜头.md`](../调研文档/移动与镜头.md)「锁定时的闪避」。** 调研写锁定后翻滚朝目标的前后左右，身体继续面向目标。FR-镜头-04 写翻滚期间身体朝移动方向。`HandleRoll` 按当时 `moveDir` 转向，与 FR-镜头-04 一致。
- **同篇「跳跃、落地与落地攻击」。** 调研写从冲刺里起跳，高处落下按高度扣生命。FR-移动-05 写有移动量、精力够就播 `Jump`，落差够播 `Land`。`HandleJump`、`HandleFall` 按这一条。掉落扣血不在这四篇需求里。

### 精力

- **FR-精力-01～05。** 进游戏时 `currentStamina` 等于上限，`PlayerStatsManager.Start` 把条设满。冲刺、翻滚、后撤、跳跃走 `DeductStamina`，成功才改条。轻击和重击在 `CharacterAnimatorManager.DrainStamina` 里按武器基础消耗和轻重系数扣。冲刺或 `isInteracting` 时回复计时清零；两者都结束后超过 1 秒才涨。举盾、未冲刺、未在交互动画时用 `staminaRegenerationAmountWhilstBlocking`，放下盾回到非格挡速率。`BlockAction` 播 `Block - Start` 时 `isInteracting` 为 false。精力小于等于 0 时 `LightAttackAction`、`HeavyAttackAction` 直接返回，大于 0 后再点会出招。
- **回复可能略高于上限。** `PlayerStatsManager.RegenerateStamina` 在 `currentStamina < maxStamina` 时加上 `staminaRegenerationAmount * Time.deltaTime`，加完不再夹回上限。默认每秒 300，一帧高出几格。`StaminaBar` 用的 `Slider` 显示停在满格。多出来的一点不影响「满条、停手回满」的观感。
- **FR-精力-06。** 标待补。精力大于 0 但低于这一击消耗时，轻重击仍会播出，`DeductStamina` 不够则不扣。需求落点已经写了这条。调研「精力」里「剩一点仍会做出来并把精力扣空」和脚本不同：脚本是不扣、数值保持。FR-移动-06 对翻滚、后撤、跳跃要求的正是不够就不播、精力不变，脚本按 `DeductStamina` 的返回值执行。

### 负重

- **FR-负重-01～05。** 五条都标待补。`WeaponItem`、`ArmorItem`、`PlayerLocomotionManager` 上没有装备重量、负重上限、四档翻滚。翻滚只扣 `rollCost` 并播放 `Rolling`。调研「负重当位」的四档翻滚在需求里仍是待补，没有一套已经跑起来却滚反了的档位。
