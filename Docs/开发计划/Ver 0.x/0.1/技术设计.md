# 0.1 技术设计：只留 Git

> **只改包清单、两处 Collaborate 开关和忽略规则。不改场景，不改玩法脚本，不移出资源。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 卸包

从 [`../../../../Packages/manifest.json`](../../../../Packages/manifest.json) 删除 `com.unity.collab-proxy`（当前 `2.2.0`）。不要连带卸 Visual Scripting、Timeline 或其他包。

## 2. 关掉残留开关

版本控制模式保持 Visible Meta Files：

- [`../../../../ProjectSettings/VersionControlSettings.asset`](../../../../ProjectSettings/VersionControlSettings.asset) 的 `m_Mode` 保持 `Visible Meta Files`。
- 同文件 `m_CollabEditorSettings.inProgressEnabled` 从 `1` 改为 `0`。
- [`../../../../ProjectSettings/EditorSettings.asset`](../../../../ProjectSettings/EditorSettings.asset) 里同名的 `m_CollabEditorSettings.inProgressEnabled` 也改为 `0`。
- `m_ExternalVersionControlSupport` 保持 `Visible Meta Files`。不要改成 Plastic。

## 3. `ignore.conf` 退出 Git

[`../../../../ignore.conf`](../../../../ignore.conf) 从版本库删除，并在 [`.gitignore`](../../../../.gitignore) 增加 `ignore.conf`。不要把它的条目合并进 `.gitignore`。商店资源名单只在 `.gitignore` 里；并进去会把模型、角色和音效放回版本库。

不删 `Library`。[`../README.md`](../README.md) 的 0.1 状态等验收通过后再改。
