# 0.1 游戏设计：只留 Git

> **交付目标：卸掉 Unity 自带版本控制之后，Git 仍是唯一版本控制。场景和玩法不动。**
>
> 人不改场景、不点名路径。验收只看这一版的版本控制边界，不打开 Unity，也不把「工程还能玩」算进来。

## 1. 为什么排在最前

这是改几个文本文件就能完成的一刀，不依赖 Unity 里点选。`com.unity.collab-proxy` 和根目录的 `ignore.conf` 是以前没走 Git 时留下的第二套忽略规则。Git 不读 `ignore.conf`。

## 2. 验收

只核对本版改过的版本控制，不打开 Unity。

- `Packages/manifest.json` 里没有 `com.unity.collab-proxy`。
- `VersionControlSettings` 的 `m_Mode` 和 `EditorSettings` 的 `m_ExternalVersionControlSupport` 仍是 Visible Meta Files。两处 `m_CollabEditorSettings.inProgressEnabled` 都是 `0`。
- `ignore.conf` 不在版本库里。`git check-ignore` 能命中它。
- 商店资源目录仍然被 `.gitignore` 忽略，`git status` 里没有它们。
- 本版 diff 不包含 `Assets/Scenes/Game.unity` 和 `Assets/Scripts/`。
