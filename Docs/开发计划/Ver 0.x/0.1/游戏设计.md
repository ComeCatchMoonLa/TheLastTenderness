# 0.1 游戏设计：只留 Git

> **交付目标：卸掉 Unity 自带版本控制之后，Git 仍是唯一版本控制。场景和玩法不动。**
>
> 人不改场景、不点名路径。做完后只验收：工程能打开，商店资源没有进 git。

## 1. 为什么排在最前

这是改几个文本文件就能完成的一刀，不依赖 Unity 里点选。`com.unity.collab-proxy` 和根目录的 `ignore.conf` 是以前没走 Git 时留下的第二套忽略规则。Git 不读 `ignore.conf`。

## 2. 验收

- Package Manager 里没有 Collaborate / Version Control 包。
- 版本控制模式仍是 Visible Meta Files，不是 Plastic。
- `ignore.conf` 不在版本库里；若 Unity 再生了它，`git status` 也不把它列出来。
- 商店资源目录仍然被 `.gitignore` 忽略。
- `Game.unity` 和玩法脚本与本版开始前一致。
