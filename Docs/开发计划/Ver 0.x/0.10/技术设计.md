# 0.10 技术设计：落地、交互锁、敌人双手

> **三处都改现有方法。不新加状态类，不改控制器资源。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

`Humanoid.controller` 的层序是：0 Move Whole Body，1 Right Arm，2 Left Arm，3 Both Arms，4 Upper Body，5 NonCombat Whole Body，6 Combat Whole Body。上半身按层名 `Upper Body` 判断，不把 4 写死。

## 1. 落地

`PlayerLocomotionManager.HandleFall` 在射线打中时，只要落差达到 `rayStartPointHeight + minHeightNeedToLand` 就 `PlayTargetAnimation("Land", true)`，不看上一物理步是不是在空中。站在地上时条件若仍成立，每个物理步都会再切一次。

在方法开头、`isJumping` 返回之后记下 `wasInAir = player.isInAir`。射线打中并且 `wasInAir` 为真时：

- 落差够：仍切 `"Land"`。
- 落差不够：切 `"NonCombat Whole Body Empty"`，`isInteracting` 传 false。这个状态上有 `HandleEmptyState`，进入后把交互清掉。

`wasInAir` 为假时不切落地，也不切 Empty。打不中地面时仍按现在的规则切 `"Falling"`。`isJumping` 为真时整段返回，保持不动。

不改 `HeightToBeginLand`、`GroundCheckLayer` 和 `fallSpeed`。

## 2. 上半身 Empty

`HandleEmptyState.OnStateEnter` 现在不管哪一层，都清掉 `isInteracting`、`isAttacking`、背刺、无敌和左右手。它挂在 Combat、NonCombat、Upper Body 三个 Empty 上。喝药和瞄准结束会进上半身 Empty，把全身攻击放开。

`animator.GetLayerName(layerIndex) == "Upper Body"` 时直接返回，这一层不改角色旗标，也不改 `isMirrored`。另外两层的进入逻辑不动。

## 3. 没有的状态名

`CharacterAnimatorManager.PlayTargetAnimation` 在 `CrossFade` 之前就写 `isInteracting`。名字对不上时人被锁住，动画不切。

先在每一层用短名和 `层名.状态名` 查 `Animator.HasState`。都没有则 `Debug.LogError` 并返回，不改旗标，不 `CrossFade`。有才保持现在的赋值和 `CrossFade`。

## 4. 敌人双手

`CharacterInventoryManager.Start` 先从槽数组取出 `rightWeapon`，再 `LoadWeaponsOnBothHands`。`EnemyInventoryManager.Start` 在 `base.Start()` 之后才根据右手类型把 `isTwoHandingWeapon` 写成 true，装载时标记还是 false。

在 `base.Start()` 之前，用 `weaponsInRightHandSlot[currentRightWeaponIdx]` 判断。类型是 `melee_TH` 或 `melee_THL` 时先把 `enemy.isTwoHandingWeapon` 写成 true。引用为空则不写。然后 `base.Start()`。`currentItemBeingUsed = rightWeapon` 仍放在基类之后。

`EnemyWeaponSlotManager` 不改。

## 5. 不做

不改射线。不合并轻重击。不按 `WeaponType` 拆装载。那是 1.3。不补单元测试。
