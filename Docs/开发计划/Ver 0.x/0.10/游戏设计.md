# 0.10 游戏设计：落地、交互锁、敌人双手

> **交付目标：人站在地上不会每个物理步重播落地；贴地后能离开下落；喝药或结束瞄准不会把全身攻击的交互清掉；双手敌人在装武器之前就写好标记。**
>
> 对应纠错 4、10、11。不改下落速度、射线长度和层遮罩。不按武器类型重写装载。

## 1. 为什么是这一刀

0.9 改的是伤害数字。这三处是人被锁住或敌人第一次拿武器拿错的原因。交互锁和落地绑在一起，因为下落靠 `isInteracting` 停住，落地又会把它写回去。

## 2. 三处各自变成什么样

| 项 | 做完之后 |
| --- | --- |
| 4 下落和落地 | 只有刚从空中落到地上、并且落差够，才切一次 `Land`。落差不够时切回 `NonCombat Whole Body Empty`，人能走 |
| 10 交互锁 | 上半身的 Empty 不再改全身的交互、攻击、背刺和无敌。控制器里没有的状态名，不先把 `isInteracting` 写成 true |
| 11 敌人双手 | `isTwoHandingWeapon` 在 `LoadWeaponsOnBothHands` 之前写上。右手是双手武器时，开局左手在背上 |

跳跃、翻滚、冲刺的写入方保持 0.5。

## 3. 验收

- 站在平地上走几步，不连播落地。
- 从高处落下后能走。贴地、落差不大时也不停在下落姿势。
- 全身攻击还没回到 Empty 时，喝药或结束瞄准，人仍然不能自由移动。攻击结束后能走。
- 右手是双手武器的近战，开局左手模型在背上。不是双手武器时，这一条看不出差别。
