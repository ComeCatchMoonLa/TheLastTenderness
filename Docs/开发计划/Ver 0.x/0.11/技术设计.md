# 0.11 技术设计：吸收和数量

> **吸收补进现有的三段穿戴。数量从资产字段改到玩家库存的运行时字典。不新加物品类型。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 护甲五段

`PlayerArmorManager.EquipAllArmorModels` 现在只写 `headArmorPDA`、`torsoArmorPDA`、`hipsArmorPDA`。空槽只把物理写成 0。

每个部位在有装备时，再写 `fireDA`、`magicDA`、`lightningDA`、`darkDA` 到对应的 `*ArmorFDA`、`*ArmorMDA`、`*ArmorLDA`、`*ArmorDDA`。没有装备时这四段也写 0。头没有赤裸模型，躯干和下身仍打开赤裸模型名。

不改 `TakeDamage` 的 60/30/10。不写 `armorPoiseBonus`。

## 2. 数量

`FlaskItem` 和 `BombItem` 递减资产上的 `currentItemAmount`。`ShootArrowAction.PerformActionForPlayer` 递减 `currentAmmo.cnt`。`CharacterInventoryManager.Start` 把 `currentAmmo.cnt` 写回 `maxCnt`。

删掉基类 `Start` 里对 `cnt` 的赋值。`PlayerInventoryManager` 用两份字典，键是物品引用，值是剩余次数。`Start` 里对 `consumables`、`currentConsumable`、`currentAmmo` 按 `maxItemAmount` 或 `maxCnt` 记一笔。已经有记录的不覆盖。

`TrySpendConsumable`、`TrySpendAmmo`：剩余大于 0 才减一并返回 true。`AmmoRemaining` 给出当前剩余。射箭成功后剩余为 0 时，把 `currentAmmo` 设为 null，和现在打空就卸下的结果一样。剩余已经是 0 时不发射。

敌人的 `PerformActionForAI` 不减 `cnt`，这一版不改。

资产上的 `currentItemAmount` 和 `cnt` 不再被这些路径写入。上限字段仍留在资产上。

## 3. 不做

不把血瓶和炸弹合成一个类。不改装备窗只显示前两格。不把数量画到快捷栏上。不补单元测试。护甲三段合成一份描述是 1.3。
