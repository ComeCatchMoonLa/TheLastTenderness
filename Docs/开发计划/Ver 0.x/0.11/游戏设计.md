# 0.11 游戏设计：吸收和数量

> **交付目标：穿上的火、魔、雷、暗吸收会进伤害；药、炸弹和箭的剩余次数在角色身上，Play 不改资产。**
>
> 对应纠错 7、8。不加护甲部位，不改 60/30/10，不重做背包。

## 1. 为什么是这一刀

护甲资产上已经有五段吸收，穿戴只抄了物理。数量写在 `ScriptableObject` 上，玩一次会把资产改掉。这两件都是数据抄错地方，不改背包窗口。

## 2. 做完之后

| 项 | 做完之后 |
| --- | --- |
| 7 护甲 | 头、躯干、下身各自写下物理、火、魔、雷、暗。脱掉该部位时这五段都是 0 |
| 8 数量 | 开局按上限记在 `PlayerInventoryManager`。喝药、扔炸弹、射箭只减这份。退出 Play 后资产上的数量与进入前相同 |

装备窗仍只显示每手前两格。火球仍走火焰伤害。

## 3. 验收

- 穿上一件带火焰吸收的护甲，火伤比脱下时低。脱下后该部位火焰吸收为 0。
- 喝一次药或射一支箭，退出 Play。资产上的 `currentItemAmount` 和 `cnt` 与进入 Play 之前相同。
- 数量用完时不能再喝、再射。快捷栏仍能切换当前药和当前箭。
