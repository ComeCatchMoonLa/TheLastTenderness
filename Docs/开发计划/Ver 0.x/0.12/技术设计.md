# 0.12 技术设计：设置和暂停会生效

> **垂直同步和相机速度走已经有的套用方法。死亡只放开已经打开的暂停菜单。不新建设置系统。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 垂直同步

`VSYNC_SwitchOption` 改枚举并改标签，不套用。`VSYNC_ApplyCurrentOption` 只改标签，由 `ApplyGameSettings` 在 `PlayerUIManager.Start` 调用。

`VSYNC_SwitchOption` 改完枚举后调用 `VSYNC_ApplyCurrentOption`。Apply 里 `enable` 写 `QualitySettings.vSyncCount = 1`，`disable` 写 `0`，同时仍写「启用 / 禁用」。开局的 `ApplyGameSettings` 再写一次。

不改 `FrameRateLimit_ApplyCurrentOption` 里的 `targetFrameRate`。不改后处理和特效，那两项仍只改标签。

## 2. 相机速度

`SaveCameraLeftAndRightSpeedSetting` 和 `SaveCameraUpAndDownSpeedSetting` 只写 `gameSettingsData`。`ApplyCameraSpeedSetting` 把这两项赋给 `player.pCamera`，只在 `ApplyGameSettings` 里调用。

`SettingsWindowManager` 在 `Awake` 用 `transform.root` 取 `PlayerManager`，和 `EscWindowsManager` 一样。两个 Save 在 `float.Parse` 成功并写入数据之后调用 `ApplyCameraSpeedSetting`。解析抛错时赋值不会发生，镜头保持调用前的速度。

## 3. 死亡后的暂停

`PlayerUIManager.Update` 在 `isDead` 时整段返回，`HandleEscWinBackInput` 不会跑。`EscWindowsManager.Close` 仍是把 `timeScale` 写回 1 的地方。`InputManager.Update` 在死亡时返回，不挡 `UIOperation.Back` 的回调。`LateUpdate` 不清 `ui_Back_Input`。

`isDead` 且 `openedWin` 不是 `notEscWinMode` 时，仍走现在的返回和选择器分支。其余（Tab、准星、FPS、新开 Esc）继续不跑。没开菜单时保持整段返回。不在死亡时调用 `EscWindowsManager.Open`。

## 4. 不做

不改镜头偏移的 `SmoothDamp`，那是 0.13。不改炸弹结算，那是 0.14。不改格挡受伤音，那是 0.15。不补单元测试。
