# 0.12 游戏设计：设置和暂停会生效

> **交付目标：垂直同步进引擎；当次改的相机速度马上进镜头；死亡时已经打开的暂停菜单仍能关掉，时间恢复。**
>
> 1.3 已完成。这是纠错，不改谁负责结算、选段、瞄准或装载。后处理、特效、帧率档不在这一版。

## 1. 为什么是这一刀

画面里的垂直同步只改「启用 / 禁用」这几个字。相机速度写进了设置数据，镜头要下次进场景才变。玩家死亡后界面不再处理返回，暂停菜单若还开着，时间会停在 0。

## 2. 谁负责

`SettingsWindowManager` 仍负责把设置写进引擎。垂直同步在套用当前选项时写 `QualitySettings.vSyncCount`。两个相机速度在保存时写进镜头，不等下一场。

`PlayerUIManager` 仍负责暂停菜单的返回。人死了但菜单还开着时，返回和选择器照旧处理。没开菜单时，死亡仍不处理界面。

## 3. 验收

- 把垂直同步改成启用，再改回禁用。标签和 `QualitySettings.vSyncCount` 一起变。退出 Play 再进，开局仍按设置数据套用。
- 暂停菜单里改左右或上下相机速度，关掉菜单后当次转动就用新数字。不用重进场景。
- 先打开暂停菜单，再让玩家死亡。返回仍能逐层关掉，关掉根窗口后 `timeScale` 为 1。没开菜单时死亡，不会因此弹出暂停。
