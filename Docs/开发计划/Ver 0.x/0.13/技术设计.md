# 0.13 技术设计：镜头偏移的缓动不断掉

> **草稿。** 进入 0.13 之前对照当时的 `PlayerCameraManager` 复核，再去掉这行。
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SetCameraPosOffset` 按 `CurrentCameraPose` 调用三个方法。每个方法里 `Vector3 velocity = Vector3.zero`，再 `SmoothDamp` 枢轴的 `localPosition`。`cameraCurrentVelocity` 只给跟随那次 `SmoothDamp` 用。

## 2. 一份偏移速度

在 `PlayerCameraManager` 增加 `pivotOffsetVelocity`，初值 `Vector3.zero`。三个 `SetCameraPosOffset_*` 都 `ref` 这一份，方法内不再声明局部速度。

不在 `CurrentCameraPose` 变化时把 `pivotOffsetVelocity` 写成零。不把这份和 `cameraCurrentVelocity` 合成一个字段。

## 3. 不做

不改 `CameraPose` 的判断。不改锁定时的 `OverlapSphere`。不改 0.12 的相机速度数值。不补单元测试。
