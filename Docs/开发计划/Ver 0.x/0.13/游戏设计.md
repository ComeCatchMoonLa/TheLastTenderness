# 0.13 游戏设计：镜头偏移的缓动不断掉

> **交付目标：瞄准、锁定、默认三种偏移在停留和来回切换时，缓动使用上一帧留下的速度。**
>
> 1.2 已经让旋转、跟随、偏移读同一组模式。这一版只补偏移缓动丢掉的速度。不改跟随，不改锁定扫谁。

## 1. 为什么是这一刀

三种偏移各自 `SmoothDamp`，每次都用一个新的零速度。停在同一种镜头里，缓动每帧从头算。切到另一种时也接不上上一帧的速度。

## 2. 谁负责

`PlayerCameraManager` 上单独留一份枢轴偏移速度，三个偏移方法都读它。跟随用的那份速度不动。切换模式时不清这份偏移速度。

## 3. 验收

在默认、锁定、瞄准之间来回切。枢轴高度和瞄准时的左右偏移是缓过去的，不是每帧重新从静止开始。跟随仍用原来的那份速度。走路不重测。
