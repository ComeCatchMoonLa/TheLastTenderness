# 0.14 技术设计：炸弹认按下时的那一件

> **结算调用按下时的炸弹，不读当时的快捷栏。不合成血瓶和炸弹。喝药不锁移动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerAnimatorManager.SuccessfullyCastConsumable` 调用 `currentConsumable.SucessfullyUsedConsumable`。`BombItem` 再把 `currentConsumable` 转成 `BombItem` 来生成活体炸弹。快捷栏在动画途中换成别的消耗品时，这次调用已经不是按下的那颗。

`AttemptToConsumableItem` 在扣数量时用的是 `this`。

## 2. 记下按下的炸弹

`PlayerInventoryManager` 增加 `consumableBeingUsed`。`BombItem.AttemptToConsumableItem` 在 `TrySpendConsumable` 成功之后把它写成 `this`。血瓶不写这个字段。

`SuccessfullyCastConsumable`：字段非空就调用它，否则仍调用 `currentConsumable`。调用后把字段写成 null。`BombItem.SucessfullyUsedConsumable` 用 `this` 的模型、伤害和速度，不再转换 `currentConsumable`。

`HandleUseComsumableState` 离开时，若角色是玩家，把 `consumableBeingUsed` 写成 null。动画事件已经结算过的，这里再写一次 null。没播到事件就离开的，不会把这颗炸弹留到下一次喝药。

## 3. 不做

不改血瓶的 `isInteracting`。不把两个 `AttemptToConsumableItem` 合成一个方法。不改数量字典。不补单元测试。
