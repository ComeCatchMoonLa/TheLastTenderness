# 0.14 游戏设计：炸弹认按下时的那一件

> **交付目标：扔出动画播放途中换了快捷栏，生成的仍是按下时那颗炸弹。**
>
> 技术设计和 TODO 进入本版再写。不把血瓶和炸弹合成一个类。不把喝药改成锁移动。

## 1. 为什么是这一刀

数量在按下时已经扣掉。生成炸弹时读的是当时的 `currentConsumable`。动画没播完就换快捷栏，扣的是炸弹，飞出去的可能是另一件。

## 2. 做完之后

按下炸弹的那一次使用，结算认这颗炸弹。中途把快捷栏换成药或其他消耗品，不影响已经扔出的这一次。喝药仍不看 `isInteracting`，血瓶仍不锁移动。

## 3. 验收

快捷栏当前是炸弹时按下使用。动画播放途中切到另一件消耗品。生成的仍是炸弹，扣掉的仍是按下时那一次。喝药的移动和现在一样。
