# 0.15 技术设计：格挡命中不播肉体受伤音

> **只有挡住且没有破防的那一次，不播受伤音。扣血仍在 `TakeDamage`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ResolveIncomingHit` 在正面格挡时调用 `AttemptBlock`，再按格挡吸收乘五段，然后 `TakeDamage(null, ...)`。`TakeDamage` 扣血后总是 `PlayRandomDamageSoundsFX`。

`AttemptBlock` 在 `DeductStamina` 之后看 `currentStamina <= 0`。是则清掉格挡和吸收并播 `Guard_Break`。体力不够扣时 `DeductStamina` 不改体力，体力仍大于 0，这次仍算挡住。

## 2. 这一次播不播

`TakeDamage` 增加参数 `playHurtSound`，默认 true。玩家和敌人的覆写原样传给基类。基类只在它为 true 时播受伤音。

`ResolveIncomingHit` 的格挡分支在 `AttemptBlock` 之后：`currentStamina > 0` 时把 `playHurtSound` 传 false，否则传 true。没进格挡的分支、背刺和处决不传这个参数。

## 3. 不做

不改松开 Q 时每帧清 `isBlocking`。不改 `DeductStamina` 不够就不扣的结果。不把受伤音从 `TakeDamage` 里搬出去给所有调用方各自决定。不补单元测试。
