# 0.15 游戏设计：格挡命中不播肉体受伤音

> **交付目标：举盾挡住的一击不播肉体受伤音。护甲和扣血仍走 `TakeDamage`。**
>
> 技术设计和 TODO 进入本版再写。不改松开 Q 时每帧清掉 `isBlocking`。

## 1. 为什么是这一刀

格挡命中仍进入 `TakeDamage`。这个方法在扣血之后播放受伤音。挡住的一击因此和打在身上一样响。

## 2. 做完之后

正面格挡且这次没有破防时，不播肉体受伤音。破防、没挡住、背刺仍播。松开 Q 仍按现在的方式结束举盾。

## 3. 验收

举盾挡住普通一击，没有肉体受伤音，血仍按格挡后的结果减少。破防时仍有受伤音。松开 Q，盾放下，和改之前一样。
