# 0.16 游戏设计：付不清的格挡会破防

> **交付目标：这一记格挡的精力消耗大于剩余精力时，精力变为 0，盾放下，播放 `Guard_Break`。这一击按没挡住扣生命。**
>
> 0.15 已完成。翻滚、跳跃、后撤在精力不够时仍不播、不扣。侧面是否挡住不在这一版。

## 1. 为什么是这一刀

`DeductStamina` 只在剩余精力够付整笔时才扣。格挡沿用这个结果：付不清就不扣、不破防，盾继续减伤。需求要的是这一记把精力打到耗尽就崩架。

## 2. 谁负责

`AttemptBlock` 仍负责破防。付得起时，扣减和现在一样。付不起时，把精力写成 0，再走现在「精力小于等于 0」的破防。`DeductStamina` 对翻滚、跳跃、后撤的「不够就不扣」不改。

玩家体力条在精力被写成 0 时一起更新。

## 3. 验收

- 剩余精力小于这一记消耗时举盾被打到：精力变为 0，盾放下，播放 `Guard_Break`，这一击的生命按没挡住减少，并有肉体受伤音。
- 剩余精力大于这一记消耗：精力下降，盾仍举着，生命按挡住减少，没有肉体受伤音。
- 剩余精力正好等于这一记消耗：和现在一样破防，这一击按没挡住扣生命。
- 精力不够时，翻滚、跳跃、后撤仍不播放，精力不变。
