# 0.17 游戏设计：侧面按角度挡住

> **交付目标：同一侧的一击，站远和站近都是同一个挡住结果。挡住只看相对面朝的角度。**
>
> 技术设计进入本版前再对照代码。0.16 的破防不在这一版重做。

## 1. 为什么是这一刀

正面判断用的是位置差和面朝的点积，向量没有归一化。点积比的是沿面朝方向的米数。同样偏侧，站得远会过 0.3，站得近不会。

## 2. 做完之后

先把从自己指向攻击者的方向收成单位向量，再和面朝做点积，仍和 `0.3` 比。大约面朝前方 72 度以内算挡住。正侧和背后不进盾。阈值数字不改。

两人重合、方向长度接近 0 时，这一下不算挡住。

## 3. 验收

同一侧、明显偏离面朝的一击，近处和远处都不减伤、不扣格挡精力。正面近处和远处都挡住。背后不挡住。走路不重测。
