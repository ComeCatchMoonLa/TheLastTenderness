# 0.18 技术设计：护甲槽点武器不丢背包

> **不是四个武器槽时，`EquipWeapon` 在删除和重装之前返回。手槽成功路径不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`InventorySlotUI.EquipWeapon` 只在 `weapon_RH_Slot_1`、`weapon_RH_Slot_2`、`weapon_LH_Slot_1`、`weapon_LH_Slot_2` 时改对应数组并刷新装备窗格子。四个分支之后无条件 `RemoveItem`，再按 `currentRightWeaponIdx` / `currentLeftWeaponIdx` 重装左右手。选中护甲槽时四个分支都不进，武器仍被删掉。

## 2. 先确认槽位

四个分支都不进时，在 `RemoveItem` 之前返回。不重装手上模型。

进了其中一个分支时，仍是旧武器 `AddItem` 回背包、新武器写入该下标、刷新格子，然后 `RemoveItem` 并重装。

## 3. 不做

不改护甲穿戴。不让装备窗画出每手第 3、4 格。不补单元测试。
