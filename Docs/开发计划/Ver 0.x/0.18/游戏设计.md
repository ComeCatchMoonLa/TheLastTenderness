# 0.18 游戏设计：护甲槽点武器不丢背包

> **交付目标：装备窗停在护甲槽时，再点背包里的武器，武器仍在背包里，手上模型不变。**
>
> 技术设计和 TODO 进入本版再写。手槽四格的换装不改。

## 1. 为什么是这一刀

`EquipWeapon` 只在左右手前两个槽时改手槽。四个分支都不进时，仍把这把武器从背包移除，再按当前下标重装左右手。点过护甲槽之后再点武器，背包少一件，手上还是原来那把。

## 2. 做完之后

当前选中的不是那四个武器槽时，这次点击不改背包，不重装手上的模型。选中武器槽时，旧武器回背包、新武器进该槽、手上换成新模型，和现在成功的那条一样。

## 3. 验收

装备窗选中头、躯干或下身，再点背包里的一把近战武器。背包里这把还在，手上模型不变。再选中一个武器槽点同一把，手上换成它，背包里换成原先那只手上的武器。
