# 0.19 技术设计：投射法术按学派进伤害段

> **三系对应写死：`pyromancy` 进火，`sorvery` 进魔，`miracle` 进雷。暗段保持 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。`SpellType` 没有雷、暗两个成员，暗不另加枚举。

## 1. 现在

`ProjectileSpell.SuccessfullyCastSpellWithPlayer` 只写 `spellDC.fd = baseDamage`。`SpellDamageCollider.OnCollisionEnter` 只把 `fd` 传给 `TakeDamage`。`spellType` 不读。

## 2. 按学派写一段

玩家放出弹体时，先把碰撞体上的 `pd`、`fd`、`md`、`ld`、`dd` 写成 0，再按 `spellType` 把 `baseDamage` 写入一段：

| `spellType` | 写入 |
| --- | --- |
| `pyromancy` | `fd` |
| `sorvery` | `md` |
| `miracle` | `ld` |

`OnCollisionEnter` 把这五段都传进 `TakeDamage`。动画名仍是 `"Damage_ForwardRight_01"`。

AI 的 `SuccessfullyCastSpellWithAI` 仍是注释，不打开。

## 3. 不做

不改拿错催化器的门禁。不让法术进格挡。不改治疗。不加暗系枚举。不补单元测试。
