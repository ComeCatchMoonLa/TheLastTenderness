# 0.19 游戏设计：投射法术按学派进伤害段

> **交付目标：弹体打中时，伤害进这一条法术所属学派对应的那一段。现有火球仍进火段。**
>
> 技术设计和 TODO 进入本版再写。`SpellType` 只有 `miracle`、`pyromancy`、`sorvery`。后两系写进哪一段，在该版技术设计里写死，施工时不另选。

## 1. 为什么是这一刀

`ProjectileSpell` 把 `baseDamage` 只写进 `fd`。`SpellDamageCollider` 只把 `fd` 送进 `TakeDamage`。学派不参与结算。现有弹体只有火球，碰巧是火。换一条非火焰投射，仍按火吸收扣血。

## 2. 做完之后

`pyromancy` 仍只写火段。`miracle` 和 `sorvery` 各写技术设计点名的那一段，其余四段为 0。拿错催化器仍不出弹。盾仍挡不住法术。

## 3. 验收

火球打在有火吸收的人身上，扣血和现在同一套吸收。若当时已有另一系的投射资产，打在只堆了那一段吸收的人身上，血少掉；堆了别的段、这一段是 0 时，不吃那一档吸收。没有第二系资产时，只验收火球仍进火段。
