> 需求以 [`游戏设计.md`](游戏设计.md) 为准。编辑器修订号以本机安装为准，不从别的工程抄。

本机编辑器在 `C:\Program Files\Unity\Hub\Editor\6000.5.9f1\`。

## 1. 人先打开

用 Hub 选择 `6000.5.9f1` 打开本仓库。这一步不改 `ProjectVersion.txt`。

打不开：把报错记在本版目录，停手。不要为了打开去改场景、脚本或包清单。

打得开：看 `ProjectVersion.txt`。若 Unity 已经把它写成 `6000.5.9f1`，核对本机修订号后可以提交这一处。若仍是 `2022.3.17f1c1`，再改成：

```text
m_EditorVersion: 6000.5.9f1
m_EditorVersionWithRevision: 6000.5.9f1（修订号填本机这个编辑器的）
```

## 2. 不夹带的写回

这次打开若还改了 `Packages/packages-lock.json`、`ProjectSettings.asset` 或其他新设置文件，先留在工作区。人点名要进版本库的才提交。不把它们算进「编辑器版本已经对齐」。
