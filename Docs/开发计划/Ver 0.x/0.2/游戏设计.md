# 0.2 游戏设计：编辑器改为 Unity 6.5

> **交付目标：工程用本机已安装的 Unity `6000.5.9f1` 打开。这就是 Unity 6.5。**
>
> 先由人在 Hub 里用这个版本打开。打得开，再把 `ProjectVersion.txt` 改成它，让以后默认也开这个版本。打不开，停下来记报错，不要连着改场景和玩法。

现在 [`../../../../ProjectSettings/ProjectVersion.txt`](../../../../ProjectSettings/ProjectVersion.txt) 仍是 `2022.3.17f1c1`。本版开始前不改这个文件。

## 1. 为什么插在这里

后面的登记场景、改脚本，都要在同一个编辑器里做。编辑器还指着 2022 时，用 6.5 打开会由 Unity 自己升级工程。这一版只处理编辑器版本，不登记 Build Settings，不改玩法。

## 2. 验收

- 人用 `6000.5.9f1` 打开工程，并说明打得开或打不开。
- 打得开之后，`ProjectVersion.txt` 的 `m_EditorVersion` 是 `6000.5.9f1`。
- 本版不改 `Assets/Scenes/Game.unity` 和 `Assets/Scripts/`。
- 打开编辑器时 Unity 另外写回的设置，不在人点名之前不提交。
