# 0.20 技术设计：瞄准时留下胶囊半径

> **瞄准期间 `ResetCollider` 仍写中心和高度，不写半径。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerManager.ResetCollider` 在 `Update` 里、非翻滚且非跳跃时，把胶囊中心、高度、半径写回 `PlayerLocomotionManager` 的默认值。`HandleAimingState` 进入时若尚未记下半径，记下 `colliderRadiusBeforeAim`，把 `aimingRadiusApplied` 写成 true，再把半径写成 0.4。离开时写回记下的半径并清掉 `aimingRadiusApplied`。

瞄准不是翻滚也不是跳跃，所以每帧重置会盖掉 0.4。

## 2. 跳过半径

`aimingRadiusApplied` 为真时，仍写中心和高度，不写 `radius`。为假时三样都写回默认。

不改 `HandleAimingState` 的进入和离开。

## 3. 不做

不改翻滚、跳跃对胶囊的替换。不改相机。不补单元测试。
