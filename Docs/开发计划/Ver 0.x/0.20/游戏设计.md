# 0.20 游戏设计：瞄准时留下胶囊半径

> **交付目标：瞄准期间胶囊半径保持进入瞄准时写下的 0.4。取消瞄准后回到进入前。中心和高度仍按非翻滚、非跳跃恢复。**
>
> 技术设计和 TODO 进入本版再写。

## 1. 为什么是这一刀

`HandleAimingState` 进入时把玩家胶囊半径写成 0.4，离开时写回进入前的值。`ResetCollider` 每个 `Update` 在非翻滚、非跳跃时把中心、高度、半径都写回默认。瞄准不是翻滚也不是跳跃，半径每帧被盖掉。

## 2. 做完之后

`aimingRadiusApplied` 为真时，`ResetCollider` 仍写中心和高度，不写半径。离开瞄准后，下一次重置把半径写回默认，并与状态机里写回的进入前半径一致。

## 3. 验收

拉弓瞄准时半径是 0.4，停在瞄准里再过几帧仍是 0.4。取消瞄准后半径回到瞄准前。翻滚、跳跃的胶囊仍在那些状态里，结束后回到默认中心和高度。
