# 0.21 技术设计：喝药认按下的那一瓶

> **血瓶在扣数量成功后写入已有的 `consumableBeingUsed`。不新加字段。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`BombItem.AttemptToConsumableItem` 在 `TrySpendConsumable` 成功后把 `consumableBeingUsed` 写成 `this`。`PlayerAnimatorManager.SuccessfullyCastConsumable` 优先调用这个字段，然后写成 null。`HandleUseComsumableState` 离开时再写成 null。

`FlaskItem.AttemptToConsumableItem` 成功时不写这个字段。事件落到当时的 `currentConsumable`。

## 2. 血瓶也记下

`FlaskItem` 在 `TrySpendConsumable` 返回 true 之后把 `player.pInventory.consumableBeingUsed` 写成 `this`。失败播 `"Shrug"` 的分支不写。

不改 `SuccessfullyCastConsumable`。不改状态离开时的清空。不改血瓶资产上的 `isInteracting`。

## 3. 不做

不合成血瓶和炸弹。不改喝药是否锁移动。不补单元测试。
