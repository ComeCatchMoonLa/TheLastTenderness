# 0.21 游戏设计：喝药认按下的那一瓶

> **交付目标：喝药动画播放途中换了快捷栏，回的仍是按下时那一瓶的血量。**
>
> 技术设计和 TODO 进入本版再写。不把喝药改成锁移动。不合成血瓶和炸弹。

## 1. 为什么是这一刀

炸弹按下时把 `this` 记进 `consumableBeingUsed`，结算认那一颗。血瓶没有记。动画事件在字段为空时读当时的 `currentConsumable`。喝到一半换成另一件，回的是后一件。

## 2. 做完之后

血瓶在扣数量成功后把 `this` 记进同一字段。事件优先调用它，和炸弹一样。离开消耗品状态时字段仍写成空。喝药的 `isInteracting` 仍来自资产。

## 3. 验收

快捷栏是血瓶时按下使用。动画途中切到炸弹或其他消耗品。加上的血是按下那一瓶的回复量，不生成炸弹。喝药时人是否锁移动，和改之前相同。
