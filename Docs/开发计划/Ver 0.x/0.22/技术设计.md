## 2. 删掉

只删上面四个目录和它们旁边的 `.meta`。不删 `VRM Consortium` 里测试目录以外的脚本和模型。

六个 `*Tests.csproj` 一并删掉。asmdef 没了之后，Unity 不应再生成它们。

## 3. 规则

改 `Docs/代码分析/可测试性.md`：

- 0.x 不写单元测试。历史的 0.x 脚本不补用例。
- 1.x 只给该版改动写测试，而且只写 Edit Mode 里不用 `Awake` 私有引用、也不用已初始化 Animator 就能断言的。预期中的 Error 用 `LogAssert.Expect` 接住。
- 留下的用例：1.2 瞄准半径，1.3 缺模型不换掉已有模型。程序集 `CatchMoon.Tests`。
- 1.0 的 `ResolveIncomingHit`、1.1 的 `MeleeAttackSegment` 先不写。不为了测试把方法改成 `virtual`，也不为了测试进入 Play Mode。
- 断言用现有返回值和公开字段。粒子、镜头、动画曲线仍靠人看。

不把 `com.unity.test-framework` 写进 `Packages/manifest.json`。它仍由开发功能包带入。

## 4. 不做

不给 0.x 的脚本补测试。不改玩法。不删 VRM 运行时。不写 `ResolveIncomingHit` 和 `MeleeAttackSegment` 的用例。
