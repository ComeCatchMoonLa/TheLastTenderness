# 0.23 技术设计：侧面破韧播方向受击

> **`DamageCollider` 在举盾时按和结算相同的点积决定传入的动画名。不改 `ResolveIncomingHit` 的比较。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DamageCollider.OnTriggerEnter` 在 `isBlocking` 为真时调用 `DealDamage(..., "Block - Hit", ...)`。侧面和背后也走这里。

`ResolveIncomingHit` 把攻击者位置减去自己的位置，长度够才归一化，和自己的 `forward` 点积，大于 `0.3` 才算挡住。没挡住时扣韧性；剩下的仍大于这一次 `poiseDamage` 就 `TakeDamage(null, ...)`，否则把传入的动画名交给 `TakeDamage`。所以侧面破韧会播 `Block - Hit`。

正面挡住时 `AttemptBlock` 播 `Block - Hit` 或 `Guard_Break`，随后 `TakeDamage(null, ...)`，`playHurtSound` 仅在精力已经不大于 0 时为真。

## 2. 侧面和背后换名字

在 `OnTriggerEnter` 的举盾分支里，用和 `ResolveIncomingHit` 相同的点积判断正面。攻击者是伤害体上的 `character`，被打的人是 `damageTarget`。向量是攻击者位置减去被打的人的位置。长度平方不大于 `0.0001` 时不算正面。

算正面时仍传入 `"Block - Hit"`。不算正面时调用已有的 `ChooseWhichDirectionDamageCameFrom`，传入得到的 `currentDamageAnimation`。

不把这段点积抽成新类型。`ResolveIncomingHit` 的点积、韧性比较、`playHurtSound` 不改。

## 3. 不做

不改 `0.3`。不改正面挡住时的受伤音。不改破防动画。不补单元测试。
