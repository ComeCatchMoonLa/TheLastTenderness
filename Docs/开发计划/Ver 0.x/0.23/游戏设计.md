# 0.23 游戏设计：侧面破韧播方向受击

> **交付目标：举着盾时，从侧面或背后把韧性打穿，播方向受击，不播 `Block - Hit`。正面挡住时仍不播肉体受伤。**
>
> 0.22 已完成。点积阈值仍是 `0.3`。正面挡住且精力还大于 0 时仍不播受伤音。

## 1. 为什么是这一刀

伤害体只要看见 `isBlocking`，就把动画名写成 `Block - Hit`。侧面和背后其实进不了盾，破韧时却仍用这个名字。正面挡住的减伤和受伤音已经按角度分开，动画名没有跟着分开。

## 2. 做完之后

正面（点积大于 `0.3`）仍传入 `Block - Hit`。侧面和背后传入现在不举盾时会选的那四个方向受击名。破韧才播这个名字；韧性还撑得住时动画名仍是空的。

正面挡住、精力付得清时不播肉体受伤音。付不清仍破防，播 `Guard_Break`。

## 3. 验收

举盾，从正侧面和背后各挨一击，把韧性打穿。播的是方向受击，不是 `Block - Hit`。正面挡住、精力还够时，仍是盾击，不播肉体受伤音。阈值仍是 `0.3`。
