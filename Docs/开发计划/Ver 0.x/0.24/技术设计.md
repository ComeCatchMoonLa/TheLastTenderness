# 0.24 技术设计：精力回复不超过上限

> **两处 `RegenerateStamina` 在加上这一帧之后用 `maxStamina` 封顶。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CharacterStatsManager.RegenerateStamina` 在 `currentStamina < maxStamina` 且 `staminaRegenTimer > 1` 时直接 `+=`。`PlayerStatsManager` 覆写了同一方法，加上之后把未封顶的数写进体力条。玩家覆写不调用基类。

`AddStamina` 已用 `Mathf.Min(..., maxStamina)`。

## 2. 加上之后封顶

两处回复都改成：加上这一帧的量，再和 `maxStamina` 取较小值，写回 `currentStamina`。玩家在写回之后再 `SetCurrentStamina`。

回复量、`staminaRegenTimer` 的清零和 `> 1f` 不改。`AddStamina` 不改。

## 3. 不做

不改格挡回复量和普通回复量。不把已经高于上限的精力在这一帧外面再拉回去。不补单元测试。
