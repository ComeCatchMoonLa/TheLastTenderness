# 0.24 游戏设计：精力回复不超过上限

> **交付目标：自然回复把精力加上去之后，不超过最大精力。**
>
> 回复速度、格挡时用哪一档回复、满 1 秒才开始加，都不改。

## 1. 为什么是这一刀

回复前会看当前精力是否已经小于上限。加上这一帧的量之后不再封顶。靠近上限时，这一帧会加过最大精力。`AddStamina` 已经用上限封顶，自然回复没有。

## 2. 做完之后

玩家和敌人的自然回复，加上去的结果若超过最大精力，写成最大精力。玩家体力条显示这个封顶后的数。

格挡中仍用格挡那一档回复量。不在交互或冲刺中才累计那 1 秒。

## 3. 验收

精力离上限只差一点点时站着等它回来。停在最大精力，不高于它。格挡中回复更慢，这点不改。走路和翻滚不重测。
