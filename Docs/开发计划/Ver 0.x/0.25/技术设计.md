# 0.25 技术设计：交互检测复用同一个碰撞体

> **`CheckForInteractableObject` 改用 `PlayerManager` 上已有的长度为 1 的数组。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

每次调用都 `new Collider[1]`，再 `OverlapSphereNonAlloc`。半径是 `interactRadius`，层是 `LayerMask.interactable | LayerMask.npc`。只看第 0 个，并且 Tag 要是 `"Interactable"`。

## 2. 留着同一块数组

字段 `interactColliders` 在角色上创建一次。检测写入这块数组。半径、层、只处理第 0 个，都不改。

## 3. 不做

不加大数组。不改提示和按键交互。不补单元测试。
