# 0.25 游戏设计：交互检测复用同一个碰撞体

> **交付目标：靠近可交互物时，不再每次检测都新造一个长度为 1 的碰撞体数组。**
>
> 技术设计和 TODO 进入本版再写。检测半径、层、只处理第一个碰撞体，都不改。

## 1. 为什么是这一刀

`CheckForInteractableObject` 每次调用都 `new Collider[1]`，再交给 `OverlapSphereNonAlloc`。能接到的交互物本来就只有这一格。

## 2. 做完之后

角色身上留着同一块长度为 1 的数组，每次检测都用它。提示、按键交互、没有交互物时关掉提示，和现在相同。

## 3. 验收

站到宝箱或可对话的人旁边，提示仍出现，按交互键仍能用。走开提示仍关掉。同时只有这一格，多出来的交互物仍被忽略。
