# 0.26 技术设计：换类型时清掉左手拖尾

> **左手装到空手、法术、弓、盾时，把 `leftWeaponFX` 写成空。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`LoadWeaponDamageCollider` 在这些 `weaponType` 上直接返回：`unaremd`、`faithCaster`、`pyromancyCaster`、`spellCaster`、`bow`、`melee_OH_Shield`。上一把写下的 `leftWeaponFX` 还在。

## 2. 返回前清掉

这条提前返回之前把 `character.cEffects.leftWeaponFX` 写成 null。近战仍在取到模型之后写入这一把的 `WeaponFX`。

碰撞体缺失时的那次返回不改，那不是换类型。

## 3. 不做

不改 `rightWeaponFX`。不改拖尾播放。不补单元测试。
