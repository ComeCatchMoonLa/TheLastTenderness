# 0.26 游戏设计：换类型时清掉左手拖尾

> **交付目标：左手换成空手、法术、弓或盾之后，上一把武器的拖尾不再留在 `leftWeaponFX` 上。**
>
> 技术设计和 TODO 进入本版再写。右手拖尾不改。

## 1. 为什么是这一刀

左手装上近战武器时会把模型上的 `WeaponFX` 记进 `leftWeaponFX`。换成空手、信仰或咒术或火焰催化剂、弓、单手盾时，装载提前返回，旧引用还在。之后播拖尾仍会打到上一把。

## 2. 做完之后

走到这些类型时，把 `leftWeaponFX` 写成空。再播拖尾时左手没有特效。右手的 `rightWeaponFX` 仍按现在的装载留下。

## 3. 验收

左手先装备有拖尾的近战武器，再换成空手、一种法术催化剂、弓、盾。攻击或收招时不再出现上一把的拖尾。换回近战武器后，拖尾仍是这一把的。
