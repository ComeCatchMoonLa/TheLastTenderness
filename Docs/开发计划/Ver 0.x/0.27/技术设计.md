# 0.27 技术设计：格挡精力看盾的稳定度

> **成功格挡的现有扣费再乘正在格挡的武器的 `(1 - stability)`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AttemptBlock` 的扣费是五段之和 × `guardBreakModifider` × `(1 - blockingStabilityRating)`。`WeaponItem.stability` 没有读取方。选哪一把武器，和 `SetBlockingAbsorptionFromBlockingWeapon` 一样：先右手，再左手。

## 2. 再乘稳定度

`BlockingWeaponStability` 按这个顺序取武器。武器或背包为空时返回 0。扣费再乘 `(1 - stability)`。

`stability` 为 0 时乘 1。不改资产上的数。类默认值 `0.67` 仍留在资产上的盾，会比改之前扣得少。

## 3. 不做

不把 `guardBreakM` 接进消耗。不改 `blockingStabilityRating` 的抄写。不改破防条件。不补单元测试。
