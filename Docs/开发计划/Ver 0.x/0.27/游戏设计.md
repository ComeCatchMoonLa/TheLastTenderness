# 0.27 游戏设计：格挡精力看盾的稳定度

> **交付目标：成功格挡扣的精力，在现在的算法上再乘 `(1 - stability)`。`stability` 为 0 时与现在相同，更高则扣得更少。**
>
> 技术设计和 TODO 进入本版再写。资产上的数字不改。`guardBreakM` 不接进消耗。

## 1. 为什么是这一刀

调研里，挡下一击扣多少精力，看这一击的力度和盾的稳定度。现在的扣费用五段伤害之和、伤害体上的 `guardBreakModifider`、以及 `blockingStabilityRating`。`WeaponItem.stability` 没有参与。它的默认值是 `0.67`，tooltip 写的就是挡下时再乘 `(1 - stability)`。

## 2. 做完之后

成功格挡时，现有扣费再乘正在格挡的那把武器的 `(1 - stability)`。这把武器为空，或 `stability` 为 0，乘 1，和现在相同。`stability` 更高，扣得更少。

五段伤害、`guardBreakModifider`、`blockingStabilityRating` 仍按现在参与。付不清仍把精力写成 0 并破防。资产上的 `stability` 不改；仍是 `0.67` 的盾，这一版之后会比现在扣得少。

## 3. 验收

用 `stability` 为 0 的盾挡住一击，扣的精力和改之前相同。把同一面盾的 `stability` 调高再挡同一击，扣得更少，正面减伤不变。`guardBreakM` 仍不改变这次消耗。
