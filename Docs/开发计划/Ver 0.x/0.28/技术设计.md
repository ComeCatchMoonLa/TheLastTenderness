# 0.28 技术设计：韧性到时就回到护甲值

> **玩家的 `HandlePoiseResetTimer` 在计时结束时写回 `armorPoiseBonus`，不再看 `isInteracting`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CharacterStatsManager.HandlePoiseResetTimer` 在 `poiseResetTimer` 不大于 0 时写回护甲韧性。`PlayerStatsManager` 覆写多了 `isInteracting` 为假才写。`totalPoiseResetTime` 默认 15。

## 2. 到时就写

删掉玩家覆写里的 `isInteracting` 判断。计时走完就写回。15 秒不改。基类不改。

## 3. 不做

不改计时怎么被设回 `totalPoiseResetTime`。不改韧性比较。不补单元测试。
