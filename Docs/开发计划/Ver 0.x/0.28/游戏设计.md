# 0.28 游戏设计：韧性到时就回到护甲值

> **交付目标：韧性计时结束就写回护甲韧性，不再等 `isInteracting` 变成假。15 秒不改。**
>
> 技术设计和 TODO 进入本版再写。

## 1. 为什么是这一刀

基类在 `poiseResetTimer` 走完后把 `totalPoiseDefence` 写成 `armorPoiseBonus`。玩家覆写多等了 `isInteracting` 为假。受击动画还锁着交互时，计时已经结束也不会回来。默认 `totalPoiseResetTime` 是 15 秒。

## 2. 做完之后

玩家也在计时结束时写回护甲韧性，交互还锁着也写。15 秒不改。敌人仍走基类，到时就写回。

## 3. 验收

把玩家韧性打低，计时走完时人还在受击硬直里。`totalPoiseDefence` 回到 `armorPoiseBonus`，不用等硬直结束。间隔仍是 15 秒。
