# 0.29 技术设计：锁定和待机不再每帧分配数组

> **锁定和两处待机改用 `OverlapSphereNonAlloc`，数组留在组件上。装满才加大。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`UpdateLockOnTargets` 用 `OverlapSphere`，半径 `maxLockOnDist`，不传层。`IdleState.Tick` 和 `IdleStateHumanoid.Tick` 用 `OverlapSphere`，半径 `detectionRadius`，层是 `LayerMask.player`。三次都返回新数组。

## 2. 复用并在装满时加大

三处各留一块数组，查询改 `OverlapSphereNonAlloc`。返回个数等于数组长度时把数组加倍再查一次，避免少掉碰撞体。只遍历这次返回的个数。

锁定的层遮罩用 `~0`，对应原来不传层时的全部层。待机仍传 `LayerMask.player`。半径不改。

`AmbushState` 不改。

## 3. 不做

不改扇形角度和 `Linecast`。不改伏击。不补单元测试。
