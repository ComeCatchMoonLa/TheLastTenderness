# 0.29 游戏设计：锁定和待机不再每帧分配数组

> **交付目标：锁定扫描和待机发现目标时，重复使用已有数组。能锁到的人、待机能发现的人与现在相同。**
>
> 技术设计和 TODO 进入本版再写。半径和层不改。

## 1. 为什么是这一刀

`UpdateLockOnTargets` 每次 `OverlapSphere` 都得到一块新数组。人形待机和通用待机的 `Tick` 也是。半径和层已经写在字段上，分配本身不改变能看到谁。

## 2. 做完之后

这两处查询改用反复使用的数组。锁定半径仍是 `maxLockOnDist`，锁定不加层。待机半径仍是 `detectionRadius`，层仍是 `LayerMask.player`。数组要装得下现在这一下能查到的全部碰撞体，少装导致的人消失不算完成。

伏击状态里的那次查询不在这一版。

## 3. 验收

锁定仍能锁到改之前能锁的人，切换左右目标仍按现在的角度。人形敌人在待机时仍能在原来的半径和视野里发现玩家。通用待机同一条。不新加层，不改半径。
