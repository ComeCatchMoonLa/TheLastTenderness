# 0.3 游戏设计：唯一运行入口

> **交付目标：从 Build Settings 打开 `Game` 就能进现在的游戏。激活的玩家是场景里的 Player SPP，近战敌人是 `Humanoid A.I - Melee` 的实例。**
>
> 不改场景里的物体，不改移动、攻击、AI。收预制体是 0.8，近战来源收成一个预制体是 0.9。人只 Play 验收。

播放器设置里的 `bundleVersion: 0.1` 是 Unity 播放器版本号，不是开发计划版本。

## 1. 为什么是这一刀

Build Settings 里没有场景，人和 Agent 会猜该打开哪一个。登记场景和写明入口都是改配置和文档，不必在编辑器里拖物体。

## 2. 运行入口

| 谁 | 是什么 | 不是什么 |
| --- | --- | --- |
| 场景 | `Assets/Scenes/Game.unity`，且是 Build Settings 里唯一场景 | 另开测试场景 |
| 玩家 | 场景里激活的 **Player SPP** | 已关闭的 Player、Player SP；`1 Old/Player` |
| 近战敌人 | `Humanoid A.I - Melee` 在场景里开着的实例 | 本版去整理 Archer、Boss、`NPC - 001` |

已关闭的副本保持原样。挪走它们是 0.6。

## 3. 验收

- Build Settings 的场景列表只有 `Game`。Input System 的配置对象还在。
- Play：激活的玩家是 Player SPP，开着的近战敌人来自 `Humanoid A.I - Melee`。
- 移动、攻击、近战 AI 与本版开始前一致。
