# 0.30 技术设计：伏击查询复用数组

> **`AmbushState` 改调 `OverlapQuery.CollectOverlaps`。只遍历这次返回的个数。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Tick` 里 `Physics.OverlapSphere(enemy.transform.position, detectionRadius, LayerMask.player)`，再 `foreach` 整块新数组。命中后算视野角，写 `currentTarget`，`isSleeping = false`，播 `wakeAnimation`。有目标就返回 `pursueTargetState`。

## 2. 复用数组

在 `AmbushState` 上放 `Collider[] detectionOverlapResults = new Collider[16]`。`Tick` 调用 `OverlapQuery.CollectOverlaps`，半径 `detectionRadius`，层 `LayerMask.player`。`for` 只走到返回的个数。碰撞体仍用 `gameObject.GetComponent<CharacterManager>()`。视野角、沉睡和苏醒不改。

## 3. 单元测试

不写。0.x 不补用例。当前场景不挂这个状态。

## 4. 不做

不改 `detectionRadius` 的默认值 2。不改视野角字段名 `minViewAngel`、`maxViewAngel`。不改锁定和待机。
