# 0.30 游戏设计：伏击查询复用数组

> **交付目标：伏击状态发现玩家时，重复使用已有数组。能发现的人、苏醒和追击与现在相同。**
>
> 技术设计已写。不改半径、层、视野角、沉睡和苏醒动画。0.x 不写单元测试。

## 1. 为什么是这一刀

`AmbushState.Tick` 每次 `OverlapSphere` 都得到一块新数组。锁定和待机在 0.29 已经改成复用数组，1.11 收成 `OverlapQuery.CollectOverlaps`。伏击还留在外面。

## 2. 做完之后

伏击调用同一段查询。半径仍是 `detectionRadius`，层仍是 `LayerMask.player`。数组留在状态上，从 16 起，装满才加倍。循环只走到这次返回的个数。视野角、沉睡、苏醒和切到追击不变。

## 3. 验收

当前构建场景的近战不挂伏击。挂上之后，玩家走进半径和视野仍会醒来并追击。半径和层不改。不新写 Edit Mode 测试。
