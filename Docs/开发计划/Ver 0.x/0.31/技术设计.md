# 0.31 技术设计：治疗扣蓝失败就停住

> **`HealingSpell` 只在 `DeductMP` 返回 true 时生成前摇并播动画。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AttemptToCastSpell` 在 `isUsingSpell` 时返回。否则调用 `character.cStats.DeductMP(focusPointCost)`，不看返回值，然后 `Instantiate(spellWarmUpFX)` 并 `PlayTargetAnimation(spellAnimation)`。

`MagicSpellAction.PerformSpellAction` 在 `currentMP < focusPointCost` 时播 `Shrug` 并返回，不调用 `AttemptToCastSpell`。

## 2. 看返回值

`DeductMP` 返回 false 时，`AttemptToCastSpell` 返回。不生成前摇，不播 `spellAnimation`。返回 true 时，后面的生成和播放保持原样。`isUsingSpell` 的提前返回不改。

## 3. 单元测试

不写。0.x 不补用例。正常施法走不到这条返回，要先绕过施法门禁。

## 4. 不做

不改 `MagicSpellAction`。不改 `ProjectileSpell`。不把失败起手挪进 `HealingSpell`。不改 `DeductMP` 的比较和 HUD 刷新。
