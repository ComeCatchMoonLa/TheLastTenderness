# 0.31 游戏设计：治疗扣蓝失败就停住

> **交付目标：`DeductMP` 返回 false 时，治疗不生成前摇，也不播治疗动画。蓝不为负。**
>
> 技术设计已写。不改施法门禁，不改扣蓝时机。0.x 不写单元测试。

## 1. 为什么是这一刀

`MagicSpellAction` 在蓝不够时已经播 `Shrug`，不会进入 `HealingSpell`。`HealingSpell.AttemptToCastSpell` 仍调用 `DeductMP` 后不看返回值，接着生成前摇并播治疗动画。`ProjectileSpell` 只在扣蓝成功后才继续。

## 2. 做完之后

治疗在 `DeductMP` 返回 false 时直接返回。成功时仍生成前摇并播原来的治疗动画。蓝不够时的失败起手仍由施法门禁播 `Shrug`。本版不在 `HealingSpell` 里再播一段失败动作。

## 3. 验收

蓝够时放治疗，生命上升，蓝下降，不为负。蓝不够时仍是现在的 `Shrug`，没有治疗前摇。投射法术的扣蓝不重测成另一套。不写 Edit Mode 测试。
