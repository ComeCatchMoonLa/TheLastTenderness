# 0.32 技术设计：双手都空时不播挥刀音

> **两手旗标都为 false 时，`PlayRandomWeaponWhoosh` 在读武器之前返回。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`isUsingRightHand` 为 true 时用 `rightWeapon.weaponWhooshesSound`。否则用 `leftWeapon.weaponWhooshesSound`。数组长度为 0 就返回。长度为 1 直接播。更长则避开上一声再随机。

## 2. 空手当返回

右手为 true 时仍取右手。否则若左手为 true，取左手。否则返回。后面的长度判断和随机播放不改。不在这里改 `isUsingRightHand`、`isUsingLeftHand` 的写入点。

## 3. 单元测试

不写。0.x 不补用例。要等动画事件，Edit Mode 里 Animator 也没初始化。

## 4. 不做

不改音效资产。不改 `HandleEmptyState`。不改左右手为 true 时选哪一边。
