# 0.32 游戏设计：双手都空时不播挥刀音

> **交付目标：左右手都没在用时，不播挥刀音。右手在用仍用右手的音，只有左手在用仍用左手的音。**
>
> 技术设计已写。不改挥刀音资源，不改哪一只手被写成 true。0.x 不写单元测试。

## 1. 为什么是这一刀

`PlayRandomWeaponWhoosh` 在 `isUsingRightHand` 为 false 时读左手武器的挥刀音。`HandleEmptyState` 会把两手都写成 false。这时若挥刀事件还在，就会去拿左手武器。

## 2. 做完之后

右手为 true 时仍播右手的音。右手为 false 且左手为 true 时仍播左手的音。两手都为 false 时直接返回，不读武器。

## 3. 验收

正常挥砍仍有挥刀音，左右手和改之前相同。全身空状态把两手都清掉之后，不再因为这次事件去读左手武器。不写 Edit Mode 测试。
