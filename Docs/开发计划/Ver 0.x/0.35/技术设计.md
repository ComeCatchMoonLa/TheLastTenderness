# 0.35 技术设计：空图标清掉上一张图

> **清精灵和停用只在 `QuickSlotsUI` 里。不写单元测试。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`UpdateCurrentWeaponIcon` 在 `itemIcon` 为空时返回，格子保持原样。法术和消耗品在物品为 null 时返回，图标为空时也返回。武器没有先判断物品是否为 null。

## 2. 清掉

三处在物品为 null 时返回。图标为空时，该格 `sprite` 写成 null，`enabled` 写成 false。有图标时仍写入精灵并启用。

不改四个 `Image` 字段的序列化引用。

## 3. 验收

对照这三个方法。不写 `Assets/Tests`。不进 Test Runner。

## 4. 不做

不补图标贴图。不改预制体。不改背包格子。
