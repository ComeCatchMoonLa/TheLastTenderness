# 0.35 游戏设计：空图标清掉上一张图

> **交付目标：武器、法术或消耗品没有图标时，清掉该格当前精灵并停用。有图标的仍换成新图。**
>
> 0.x 不写单元测试。

## 1. 为什么是这一刀

`QuickSlotsUI` 遇到空的 `itemIcon` 直接返回，格子上还留着上一张图。

## 2. 做完之后

三处都清掉精灵并把 `Image` 停用。物品本身是 null 时仍直接返回，不写格子。有图标时仍换成新图并启用。不改快捷栏预制体上的四个 `Image` 引用。不补图标贴图。

## 3. 验收

对照 `UpdateCurrentWeaponIcon`、`UpdateCurrentSpellIcon`、`UpdateCurrentConsumableIcon`。空图标清精灵并停用；有图标换成新图；物品为 null 时返回。不写 Edit Mode 测试。
