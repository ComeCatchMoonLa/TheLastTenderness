# 0.36 技术设计：精力大于零时轻击和重击仍出手

> **轻击和重击的花费走 `DeductAttackStamina`，最低 -60。`DeductStamina` 仍是够才扣。不写单元测试。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`LightAttackAction` 和 `HeavyAttackAction` 在 `currentStamina <= 0` 时返回，大于 0 就 `MeleeAttackSegment.Play`。`CharacterAnimatorManager.DrainStamina` 对这四段调用 `DeductStamina`。`DeductStamina` 在当前精力小于花费时返回 false，不改数字。

翻滚、后撤、跳跃用 `DeductStamina` 的返回值决定出不出手。格挡付不清时调用 `EmptyStamina`，把精力写成 0。`PlayerStatsManager.DeductStamina` 在基类扣成功后刷新精力条。

## 2. 扣进负数

`CharacterStatsManager` 增加 `DeductAttackStamina(float deductAmount)`。`currentStamina` 写成 `Max(currentStamina - deductAmount, -60)`。不看够不够。

`PlayerStatsManager` 覆盖该方法，扣完后调用 `staminaBar.SetCurrentStamina`，和现有 `DeductStamina` 刷新精力条的方式相同。

`DrainStamina` 在 `attackType` 是 `light_1`、`light_2`、`heavy_1`、`heavy_2` 时改为调用 `DeductAttackStamina`，花费仍是 `AttackStaminaCost`。其他 `attackType` 不扣。

`LightAttackAction` 和 `HeavyAttackAction` 的 `currentStamina <= 0` 返回不改。

`DeductStamina` 的比较和赋值不改。

## 3. 验收

对照这两个出手方法和 `DrainStamina`、`DeductAttackStamina`。不写 `Assets/Tests`。不进 Test Runner。

## 4. 不做

不改翻滚、后撤、跳跃、冲刺、格挡。不改武器技。不改精力回复。不把 -60 写进武器资产。
