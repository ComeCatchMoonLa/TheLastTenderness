# 0.36 游戏设计：精力大于零时轻击和重击仍出手

> **交付目标：精力大于 0 但不够支付这一击时，轻击和重击仍然做出，精力按花费降到 0 以下，最低 -60。精力小于等于 0 时不开始。**
>
> 0.x 不写单元测试。

来源：[不引入美术开-不引入过多人工开-非高风险关-1个以上FR关-五小时内开或关.md](../../../版本候选池/不引入美术开-不引入过多人工开-非高风险关-1个以上FR关-五小时内开或关.md)。

## 1. 为什么是这一刀

轻击和重击已经在精力小于等于 0 时拒绝，大于 0 时会播出。事件里的 `DeductStamina` 在不够支付时不扣，精力停在正数上，下一次仍能开始。需求是 [FR-精力-06](../../../需求文档/功能需求/精力.md) 里轻击和重击这一眼。翻滚、后撤、跳跃不在这一版。

## 2. 做完之后

精力大于 0 时，轻击或重击仍然开始。这一击的花费从当前精力减去，可以低于 0，最低 -60。回到大于 0 之前不能再开始下一次轻击或重击。精力小于等于 0 时，这一下不开始。

翻滚、后撤、跳跃、冲刺和格挡仍是现在的付清才扣。付不清的格挡仍把精力写成 0，不进负数。不新做攻击动画。

## 3. 验收

对照 `LightAttackAction`、`HeavyAttackAction` 和轻击、重击的扣精力。精力大于 0 时这两下仍会进入出手；花费大于当前精力时，扣完不低于 -60。精力小于等于 0 时这两下返回。`DeductStamina` 仍是够才扣。不写 Edit Mode 测试。
