# 0.37 游戏设计：打开工程就在 Game

> **交付目标：编辑器打开工程时，默认场景是 `Assets/Scenes/Game.unity`。**
>
> 0.x 不写单元测试。

来源：根 [README.md](../../../../README.md) 的运行入口。0.3 只把这一张登记进 Build Settings。

## 1. 为什么是这一刀

Build Settings 里唯一启用的场景已经是 `Game`。`ProjectSettings` 的 `templateDefaultScene` 仍是 `Assets/Scenes/SampleScene.unity`，仓库里没有这个文件。每次打开工程要再点一次 `Game`。

## 2. 做完之后

打开工程时编辑器落到 `Game`。打出来的包仍从 Build Settings 里的这一张进。场景里的物体不改。

## 3. 验收

`templateDefaultScene` 是 `Assets/Scenes/Game.unity`。`EditorBuildSettings` 的场景列表仍只有这一张。不改 `Game.unity`。不写 Edit Mode 测试。
