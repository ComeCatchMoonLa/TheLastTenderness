# 0.38 技术设计：人不会卡在下落里

> **只改 `PlayerLocomotionManager`。判地、贴地、转身都走刚体。不改预制体、场景、控制器和 `Layer.cs`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 0. 现有入口

- [`PlayerLocomotionManager`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 的 `FixedUpdate` 依次调用 `HandleMove`、`HandleRotate`、`HandleFall`、`HandleJump`、`HandleRoll`、`HandleBackStep`。顺序不改。
- `CharacterAnimatorManager.PlayTargetAnimation`，Animator 状态 `Falling`、`Land`、`NonCombat Whole Body Empty`。`HandleEmptyState` 清 `isInteracting`。都不改。
- `PlayerAnimatorManager.OnAnimatorMove` 在交互动画期间每帧把速度写成根运动速度。不改。
- 玩家预制体：`Rigidbody` 质量 200、不用重力、`Interpolate`、冻结旋转、连续动态碰撞；`CapsuleCollider` 中心 1.2、高 1.2、半径 0.3。物理设置 `m_QueriesHitTriggers: 1`、`m_AutoSyncTransforms: 0`。都不改。

## 1. 读位置和朝向走刚体

`HandleFall` 的脚底位置用 `rigidBody.position`，向前探障碍用 `rigidBody.rotation * Vector3.forward`。不再读 `transform.position`、`transform.forward`。

## 2. 贴地改成竖直速度

去掉 `transform.position = targetPosition`。射线打中时把 `rigidBody.linearVelocity.y` 写成 `(hit.point.y - 脚底.y) / Time.fixedDeltaTime`，水平分量不动。这一步模拟完脚就在命中高度，插值照常平滑。

刚离地的那一步（上一步不在空中，这一步判成空中），竖直速度大于 0 时写成 0。贴地留下的上抬速度不带进空中。

## 3. 射线起点

起点高度是胶囊体底部那颗球的球心：`center.y - Max(height / 2 - radius, 0)`，每步按当前胶囊体算。默认 0.9，瞄准半径 0.4 时 1.0，翻滚时 0.6。

射线长度是起点高度加 `HeightToBeginLand`，最低仍到脚下 0.8。

向前探障碍仍在脚上方 `rayStartPointHeight`，长 `rayStartPointOffsetDist`。没挡住就把起点向 `moveDir` 偏 `rayStartPointOffsetDist`。

`Land` 的条件写成 `脚底.y - hit.point.y >= minHeightNeedToLand`。原来是 `|命中.y - 起点.y| >= rayStartPointHeight + minHeightNeedToLand`，起点在脚上方 `rayStartPointHeight` 时两者是同一个门槛。命中高过脚底时不播 `Land`。

## 4. 不认自己和触发器

向下的射线改成 `Physics.RaycastNonAlloc`，结果数组是本类字段，长度 8。层仍是 `GroundCheckLayer`，传 `QueryTriggerInteraction.Ignore`。跳过 `collider.attachedRigidbody == player.rigidBody` 的命中，取剩下里 `distance` 最小的。

## 5. 被托住

射线没有可用命中时，从同一个球心向下 `Physics.SphereCastNonAlloc`：半径是胶囊体半径乘 0.9，距离是胶囊体半径乘 0.1 再加 0.05，也就是只看胶囊体底面往下 0.05 以内。层、触发器、跳过自己同第 4 节。起点就和别的碰撞体重叠的命中也算。

有命中：`isInAir` 写 false，`normalVector` 写 `Vector3.up`，不改竖直速度。`wasInAir` 为真时播 `NonCombat Whole Body Empty`，`isInteracting` 传 false。

没有命中：和原来一样写 `isInAir = true`，未交互时播 `Falling`。

0.9 和 0.05 写成本类常量，不放进 Inspector。它们是判地的几何余量，不是手感数值。

## 6. 转身走刚体

`HandleRotate` 改成 `rigidBody.MoveRotation(Quaternion.Slerp(rigidBody.rotation, 目标朝向, rotateSpeed * Time.deltaTime))`。锁定时目标方向用 `rigidBody.position` 算。

`HandleRoll`、`HandleJump` 起手的朝向改成 `rigidBody.MoveRotation(Quaternion.LookRotation(moveDir))`。它们在 `HandleRotate` 之后调用，同一步里后一次生效。玩家在场景根上，原来写的 `localRotation` 就是世界朝向。

## 7. 不做

- 不改 `fallSpeed`、`HeightToBeginLand`、`GroundCheckLayer` 的三层、`rayStartPointOffsetDist` 和下落力。
- 不改 `OnAnimatorMove`。`Fall.anim` 的根运动烘进姿势，交互期间速度每帧归零，下落快慢跟帧率有关。这一版不改。
- 不改预制体的插值，不改 `DynamicsManager.asset`。
- 其他脚本写玩家 `Transform` 的地方不改：瞄准镜头、法术、炸弹、背刺、开箱、对话、`LadderRide`。梯子上下落抢先是 2.94 记下的保留项。
- 不补单元测试。

## 8. 风险

高风险。判地和贴地是走、跑、翻滚、攻击位移共同的底，改错了后面的版本会接在错的贴地上；对不对只能进 Play 看。收尾前调用 reviewer。

## 9. 验收

游戏设计第 3 节，由用户在编辑器里看。Console 没有新的错误。
