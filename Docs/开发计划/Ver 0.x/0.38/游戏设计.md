# 0.38 游戏设计：人不会卡在下落里

> **交付目标：站在地上不抖。点 Play 后、运行中点层级面板之后，人仍站在地上能操作。胶囊体落到地面上或搭在坎沿上时离开下落，不再悬空或陷进地里停在 `Falling`。**
>
> 0.x 不写单元测试。这一版算高风险，收尾前调用 reviewer。

来源：[FR-移动-05](../../../需求文档/功能需求/玩家移动与闪避.md)。正文要求离地后播 `Falling`，落差够时播 `Land`，稳定着地后能走。

## 1. 为什么是这一刀

[回归测试](../../../版本候选池/回归测试/README.md)第一步是移动，下落会把人锁死。`Falling` 没有出口，播它时 `isInteracting` 为真，只有 `HandleFall` 判到地面才切出去。判不到地面，人就停在下落里，不能操作。

下面四处会让 `HandleFall` 判不到地面，或者把人拉离刚体的真实位置：

| 原因 | 玩家看到 |
| --- | --- |
| 玩家刚体开着插值。`HandleFall` 在 `FixedUpdate` 里读 `transform.position`，再把贴地结果写回 `transform`；`HandleRotate` 每个物理步写 `transform.rotation`。[Unity 6 手册](https://docs.unity3d.com/6000.0/Documentation/Manual/rigidbody-interpolation.html)写明开插值后物理系统接管 Transform，直接改 Transform 不调用 `Physics.SyncTransforms` 会被忽略；插值后的 Transform 比刚体落后一个物理步 | 每一步都可能被拉回落后的位置，地上抖。点 Play 或点层级面板造成卡顿时，一帧里连跑好几个物理步，射线一直从旧位置打，身体已经掉下去 |
| 射线起点正好在胶囊体最低点，脚上方 0.6。胶囊体落到地面上时脚陷进地里 0.6，起点就在地表上，再也打不到地 | 陷进地里播 `Falling`，不能操作 |
| 地面层包含玩家自己那一层，查询也打触发器。站着不动时起点就在自己胶囊体表面上 | 可能把脚贴到自己身上或触发器的高度，上下抖或悬空 |
| 胶囊体搭在坎沿上或别人身上，射线（中心或向前 0.2）落在沿外 | 胶囊体被托住不往下掉，悬空播 `Falling`，不能操作 |

## 2. 做完之后

- 人站着、走动、转身时，位置和朝向只经过刚体改。地上不抖。
- 射线从胶囊体底部那颗球的球心往下打，最低仍打到脚下 `HeightToBeginLand`。陷进地里时射线看得见地面，把人抬回地面上。
- 向下的射线不认自己身上的碰撞体，也不认触发器。
- 射线打不到、但胶囊体底面下方贴着地面层、NPC 层或玩家层的东西时，算站住：离开下落，能操作，不抬高。往外走会接着掉下去，走回坎上会贴回地面。
- 落差够播 `Land`、不够播 `NonCombat Whole Body Empty`，门槛不变。陷进地里或搭在坎沿上被救回时，按落差不够处理。

不变：下落力、`HeightToBeginLand`、`Land` 门槛、地面层的三层、向前 0.2 的偏移、跳跃期间不判地、跳跃翻滚后撤的条件和精力、`Falling` 本身没有出口。

会变的一处：能直接走上去的坎，从 0.6 高变成约 0.68 高。起点抬高之后，胶囊体圆底能压到的坎沿会落进向前 0.2 的射线里。

## 3. 验收

0.x 不写 Edit Mode 测试。下面在 `Game` 里人看：

1. 点 Play，不碰键盘看 5 秒：人站在地上，不抖，不播 `Falling`。
2. 平地上走、跑、冲刺、转向、停下：不上下抖，不前后抖。
3. 运行中在层级面板里连点几个物体（包括 `Player`），再回到 Game 视图：人在地上，能走。
4. 从矮坎走下来：不播 `Land`，马上能走。从高过 0.6 的地方走下或跳下：播 `Land`，之后能走，脚不陷进地里。
5. 在坎沿上停住、慢慢往外挪，或翻滚、后撤到坎沿：不停在半空播 `Falling`。能操作；往外走会掉下去，往回走回到坎上。
6. 上下坡、上台阶：人贴着地。
7. 翻滚和跳跃朝当时的移动方向。锁定时身体朝目标。
8. 梯子仍能上下、滑到底、向外跳开。
