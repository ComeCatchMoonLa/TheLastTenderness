# 0.38 游戏设计：人不会卡在下落里

> **交付目标：点 Play 后、运行中点层级面板之后，人仍站在地上能操作。不再被顶到空中，不再悬空或陷进地里停在 `Falling`。**
>
> 0.x 不写单元测试。

来源：[FR-移动-05](../../../需求文档/功能需求/玩家移动与闪避.md)。正文要求离地后播 `Falling`，落差够时播 `Land`，稳定着地后能走。

## 1. 为什么是这一刀

[回归测试](../../../版本候选池/回归测试/README.md)第一步是移动，下落会把人锁死。`Falling` 没有出口，播它时 `isInteracting` 为真，只有 `HandleFall` 判到地面才切出去。判不到地面，人就停在下落里，不能操作。

下面两处是在 Play 里用诊断日志确认的原因：

| 原因 | 玩家看到 |
| --- | --- |
| 玩家子物体 `Character Collider Blocker` 挂着动态刚体（敌人和剧情 NPC 的是运动学刚体），它的胶囊体从脚底到 1.8 高，和身体胶囊体整段重叠。层碰撞矩阵全开，也没有忽略两者的碰撞，两个刚体一开局就互相挤。它不显示，在第 10 层，地面射线也看不见它 | 点 Play 就被顶到空中。落在它上面时悬空播 `Falling`。卡顿的一帧连跑多个物理步，挤得更狠 |
| 判地的层遮罩 `GroundCheckLayer` 是序列化字段，预制体里存的是 0，只在 `Start` 里赋成三层。运行中 Unity 把资产值写回组件时它变成 0，射线什么都打不到。诊断日志里开局第 11 个物理步就从 2816 变成了 0 | 人进 `Falling`，被下落力压到身体胶囊体贴住地板，脚陷进地里 0.6，再也出不来 |

## 2. 做完之后

- 玩家自己的 Blocker 和敌人一样是运动学刚体，也不和自己的身体胶囊体相撞，不再把人往外顶。敌人的 Blocker 仍挡得住玩家。
- 判地的层固定写在代码里，运行中不会被清空。层还是地面、NPC、玩家三层。

判地射线、贴地、下落力、`Land` 门槛、转身、翻滚、跳跃都和上一版相同。

## 3. 验收

0.x 不写 Edit Mode 测试。下面在 `Game` 里人看：

1. 点 Play，不碰键盘看 5 秒：人站在地上，不飞起来，不抖，不播 `Falling`。
2. 运行中在层级面板里连点几个物体（包括 `Player`），再回到 Game 视图：人在地上，能走。
3. 平地上走、跑、冲刺、转向、停下：不上下抖，不前后抖。
4. 从矮坎走下来：不播 `Land`，马上能走。从高过 0.6 的地方走下或跳下：播 `Land`，之后能走，脚不陷进地里。
5. 上下坡、上台阶：人贴着地。
6. 走向敌人：被挡住，穿不过去。
