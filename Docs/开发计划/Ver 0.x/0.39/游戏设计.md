# 0.39 游戏设计：开局报出没配的武器动作

> **交付目标：点 Play 后，场上角色左右手槽里的近战、空手和弓，必填动作是空的就在 Console 打出警告，带上武器资产名和字段名。攻击打不打得出去，和现在一样。**
>
> 0.x 不写单元测试。

来源：[策划数据](../../../程序工作流解耦指导/策划数据.md) 的必填引用。空手的轻击和重击算必填，因为 [装备与建造](../../../调研文档/装备与建造.md) 写右手空着时战斗动作变成拳头。

## 1. 为什么是这一刀

玩家按轻击时，`oh_tap_e_action` 为空就直接返回，Console 没有字。空手这件武器上的攻击动作全是空的，所以挥不出去，看起来和攻击代码没走到一样。

## 2. 做完之后

点 Play 时，左右手槽里已经引用到的武器各查一次：

| 武器 | 空着就警告 | 空着不警告 |
| --- | --- | --- |
| 近战、空手 | 轻击 `oh_tap_e_action`、重击 `oh_hold_e_action` | 格挡、战技、双手槽、挥刀音 |
| 弓 | 射击 `oh_tap_e_action`、瞄准 `oh_hold_q_action` | 近战轻击重击 |
| 盾、催化剂 | 无 | 攻击槽空着 |

`Unaremd` 会有两条警告。盾的轻击重击是空的，不警告。已经填了轻击和重击的剑不警告。按键之后该不该播出动作，仍按现在的代码。

不扫没挂到角色身上的资产。护甲、消耗品、法术、设置和文案不在这一版。

## 3. 验收

0.x 不写 Edit Mode 测试。在 `Game` 里点 Play，看 Console：

1. 有 `Unaremd` 的 `oh_tap_e_action` 未填、`oh_hold_e_action` 未填。
2. 盾没有因为轻击、重击为空而警告。
3. 已经配了轻击和重击的剑没有这两条警告。
4. 按轻击，空手仍然不挥。配好的武器仍能打。
