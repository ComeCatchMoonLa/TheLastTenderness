# 0.40 技术设计：记忆栏为空时放不出法术

> **施法前先看当前法术在不在 `memorized` 里。开局对不上就清掉当前法术和图标。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 施法

[`MagicSpellAction.PerformSpellAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Magic/Super%20Class/MagicSpellAction.cs) 在学派和属性判断之前：角色是玩家，且 `memorized` 为空或没有 `currentSpell` 时，播 `Shrug` 并返回。不调用 `AttemptToCastSpell`，不扣蓝。

敌人没有这份记忆栏，不走这一判断。

## 2. 开局

[`PlayerInventoryManager.Start`](../../../../Assets/Scripts/Character/Player/PlayerInventoryManager.cs) 在 `base.Start()` 之后：`currentSpell` 不在 `memorized` 里就写成 null，并 `UpdateCurrentSpellIcon`。`memorized` 为 null 时先当成空列表，不新建一份去装学会列表。

`ChangeSpell` 仍只轮换 `memorized`。

## 3. 不做

不改 `Spells`。不自动把学会列表抄进记忆栏。不填玩家预制体上的 `Memorized`。不改治疗是一次加血。不接篝火整理界面。0.x 不写单元测试。不算高风险。
