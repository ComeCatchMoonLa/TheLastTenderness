# 0.40 游戏设计：记忆栏为空时放不出法术

> **交付目标：记忆栏里没有的法术，按施法没有弹体、治疗或增益，蓝不扣。学会列表里有它也不算。快捷栏不再显示记忆栏以外的当前法术。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-法术-08](../../../需求文档/功能需求/法术.md)、[FR-法术-01](../../../需求文档/功能需求/法术.md)。记忆栏为空时再按施法，没有这些效果。还没放进记忆栏时，战斗轮换里没有它。

## 1. 为什么是这一刀

`Spells` 是学会列表。`Memorized` 是带进战斗的记忆栏。施法现在只看预制体上的当前法术，不看记忆栏。记忆栏是空的，火球仍放得出去。上方向键只轮换记忆栏，所以换不了。

## 2. 做完之后

记忆栏为空，或当前法术不在记忆栏里：按施法播 `Shrug`，没有弹体或治疗，蓝不变。快捷栏清掉这个法术图标。

记忆栏里有两条时，上方向键仍在这两条之间换。催化器对系、蓝够时，当前这一条仍放得出去。

不把学会列表自动抄进记忆栏。不在这一版做篝火整理界面。

## 3. 验收

0.x 不写 Edit Mode 测试。在 `Game` 里看：

1. `Memorized` 是空的，`Spells` 里有火球：按施法没有火球，蓝不降，快捷栏没有这颗火球。
2. 把火球和治疗术都放进 `Memorized`：上方向键能换图标。火焰催化器放得出火球。`Talisman` 放得出治疗，是一次加血。
