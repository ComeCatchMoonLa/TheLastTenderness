# 0.41 技术设计：箭的剩余数量用 Cnt

> **`RememberAmmo` 的初始剩余改成 `Cnt`，并用 `Max Cnt` 封顶。不写回资产。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 初始剩余

[`PlayerInventoryManager.RememberAmmo`](../../../../Assets/Scripts/Character/Player/PlayerInventoryManager.cs) 现在把 `ammoLeft` 写成 `item.maxCnt`。

改成：

- `cnt < 0` 时用 0。
- `maxCnt > 0` 且 `cnt > maxCnt` 时用 `maxCnt`。
- 其余用 `cnt`。

已经记进 `ammoLeft` 的不再重算。`TrySpendAmmo` 仍是剩余大于 0 才减 1 并返回 true。减到 0 之后 `ShootArrowAction` 已有的失败分支不生成飞行物。

不改 `AmmoItem.cnt`。不在 HUD 上显示箭数。

## 2. 不做

不改拉满伤害。不改敌人射箭。不把 `Cnt` 为 0 当成「改用上限」。0.x 不写单元测试。不算高风险。

## 3. 验收

游戏设计第 3 节。改数量要退出 Play 再进，进游戏之后再改资产不会重算已经记下的剩余。
