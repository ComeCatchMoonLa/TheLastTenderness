# 0.41 游戏设计：箭的剩余数量用 Cnt

> **交付目标：开局能射的箭数是弹药上的 `Cnt`。每射一发少一。少到 0 后再射，没有新的箭飞出。`Max Cnt` 只是上限，填得再大也不会比 `Cnt` 多射。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-远程-01](../../../需求文档/功能需求/箭矢与弩.md)、[FR-远程-03](../../../需求文档/功能需求/箭矢与弩.md)。射出的那一发数量少一。打到 0 后再射，没有飞行物。

## 1. 为什么是这一刀

`Cnt` 是当前数量，`Max Cnt` 是上限。扣弹却从 `Max Cnt` 起算，也不改 `Cnt`。把 `Cnt` 改成 1、上限仍是 25 时，还能按 25 发继续射，资产上的 1 一直不动。

## 2. 做完之后

开局剩余是 `Cnt`。`Cnt` 大于 `Max Cnt` 且上限大于 0 时，剩余改成上限。`Cnt` 小于 0 时当成 0。

每射一发，这名玩家身上的剩余少一。少到 0 后再射，不生成飞行物，也不播 `Shoot Arrow`。资产上的 `Cnt` 不跟着改，避免 Play 时把这份资产写成 0。

画面上仍没有箭数。要看扣没扣，把 `Cnt` 设成 1，射出一发后再射，没有第二支。

拉满和快射的伤害不变。两档仍然都扣这一发。

## 3. 验收

0.x 不写 Edit Mode 测试。退出 Play，改 `Arrow`，保存后再点 Play：

1. `Cnt` 是 1、`Max Cnt` 是 25：第一发飞出，第二发没有新的箭。资产上的 `Cnt` 仍是 1。
2. `Cnt` 是 0：瞄准或射出都没有新的箭。
3. `Cnt` 是 30、`Max Cnt` 是 2：只能射出 2 发。
