# 0.42 游戏设计：消耗品开局次数用 Current Item Amount

> **交付目标：开局能用的次数是消耗品上的 `Current Item Amount`。每用一次少一。少到 0 后再用，耸肩或扔不出去。`Max Item Amount` 只是上限。休息仍把次数补回这个上限。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-回复-04](../../../需求文档/功能需求/回复类消耗品.md)、[FR-回复-06](../../../需求文档/功能需求/回复类消耗品.md)。次数记在这名玩家身上，不把资产喝成 0。休息成功后次数回到上限。

## 1. 为什么是这一刀

`Current Item Amount` 是当前次数，`Max Item Amount` 是上限。记入字典时却从上限起算，也不改当前次数。把当前次数改成 82、上限仍是 99 时，这一局从 99 开始扣。0.34 把这条写成了边界。这一版改掉。

## 2. 做完之后

开局剩余是 `Current Item Amount`。它大于上限且上限大于 0 时，剩余改成上限。小于 0 时当成 0。等于 0 时这一局不能用，不改去读上限。

每用一次，这名玩家身上的剩余少一。少到 0 后再用，血瓶和炸弹仍走原来的失败。资产上的 `Current Item Amount` 不跟着改。

休息成功后，剩余仍写回 `Max Item Amount`。

快捷栏上这一件的数字跟着这次剩余变。血瓶和灰瓶那一行仍是 `estusLeft` 和 `ashLeft`，不读这两个字段。

## 3. 验收

0.x 不新写 Edit Mode 测试。退出 Play，改这件消耗品，保存后再点 Play：

1. `Current Item Amount` 是 1、`Max Item Amount` 是 99：快捷栏数字是 1。用成功一次后变成 0，再按使用没有第二次。资产上的当前次数仍是 1。
2. 当前次数是 0：按使用没有效果。
3. 当前次数是 30、上限是 2：快捷栏数字是 2。用掉两次后不能再用。
4. 从 1 用到 0 之后休息成功：快捷栏数字回到上限。
