>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 还贴着

[`IllusionWall`](../../../../Assets/Scripts/Items/Interactions/IllusionWall.cs) 的 `OnCollisionEnter` 在接触开始时调用 `NotifyContact`。人已经重叠时再翻滚，不会再进 `OnCollisionEnter`。

`OnCollisionStay` 用同一套取 `CharacterManager` 的办法，再调用 `NotifyContact`。`isRolling` 为假时 `NotifyContact` 直接返回。已经 `opened` 时 `Strike` 直接返回。

不改攻击打中那条 `Strike`。不改 `AfterRest`。
