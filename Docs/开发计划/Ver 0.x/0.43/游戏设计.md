# 0.43 游戏设计：贴着幻影墙翻滚也能打开

> **交付目标：人已经贴在幻影墙上时再翻滚，墙打开。走路贴着不开。走开再翻滚撞上，仍打开。休息后仍开着。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-机关-06](../../../需求文档/功能需求/场景机关.md)。翻滚撞上或攻击打中后墙打开，休息后缺口还在。

## 1. 为什么是这一刀

墙只在刚撞上的那一帧看人是不是正在翻滚。人先贴住再翻滚时，碰撞不会再进一次，墙不开。

## 2. 做完之后

人贴在墙上并处于翻滚时，墙打开，碰撞和模型关掉。贴着走路不开。从远处翻滚撞上仍打开。攻击打中仍打开。休息不把它关回去。

## 3. 验收

0.x 不新写 Edit Mode 测试。在 `Game` 里对 `LlusionWall`：

1. 走到贴住墙，不翻滚：墙还在。
2. 贴住之后再翻滚：墙打开，人能走过去。
3. 再休息一次：墙仍是开的。
