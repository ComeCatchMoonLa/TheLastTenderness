# 0.44 技术设计：电梯旁能拉到

> **平台留在第 8 层。触发体在第 7 层。两层不在脚下时，按高度差从当前位置升降。人只跟着竖直移动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 触发体

靠近检测在 [`PlayerManager.CheckForInteractableObject`](../../../../Assets/Scripts/Character/Player/PlayerManager.cs)，只看第 7 层和 `npc` 层，并且碰撞体标签是 `Interactable`。不改这个检测。判地不包含第 7 层，平台不能改到这一层。

[`ElevatorPlatform`](../../../../Assets/Scripts/World/ElevatorPlatform.cs) 在 `Awake` 里，若还没有名为 `Elevator Call` 的子物体，就建一个：层是 `Layer.interactable`，标签 `Interactable`，盒子是触发体。盒子在世界坐标里盖住平台的占地，并从平台中心向上 2 米。上面的 `Interactable` 调用父物体的 `Pull`。提示文字抄平台的 `interactTipText`。

`Pull` 不在一帧里写完位置。`FixedUpdate` 用 `Rigidbody.MovePosition` 按每秒 2 米走向目标，刚体是运动学的，并且开插值。不直接写 `transform.position`。

## 2. 两层和载人

`Awake` 里，平台的 `localPosition` 既不等于 `home` 也不等于 `away` 时，记下 `away - home`，再把 `home` 写成当前位置、`away` 写成当前位置加上这个差。

[`PlayerLocomotionManager.HandleFall`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 在人贴着正在升降的台面时，不把 `transform.position` 吸回去，只把竖直速度写成平台速度。人离台面超过 0.35 时仍吸回台面，避免跳完悬在半空。跳跃中 `HandleFall` 原本整段返回，平台会从脚下顶开人；这一版改为只把人的高度加上平台这一帧的升降，不取消跳跃。水平速度仍是原来的走路。不把人设成平台的子物体。

正在升降时再拉一次，忽略，到站之后才能再拉。

## 3. 不做

不改 `Elevator.Next`。静止时的贴地仍写 `transform.position`。不改休息。不新写测试。现有两层往返的断言仍在。不算高风险。
