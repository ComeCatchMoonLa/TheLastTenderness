# 0.44 游戏设计：电梯旁能拉到

> **交付目标：站在 `Game` 里这块电梯上，出现「拉动」。按交互，平台升到另一层。再按一次，回到刚才离开的位置。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-机关-04](../../../需求文档/功能需求/场景机关.md)。拉一次到另一层，再拉一次回到刚才离开的方向。

## 1. 为什么是这一刀

靠近检测只找第 7 层、标签是 `Interactable` 的碰撞体。这块平台在第 8 层，标签不是 `Interactable`，所以没有提示，按交互也没有反应。

它的 `home` 是 `(0, 0, 0)`，平台实际停在 `(-11.75, 0.1, -21.74)`。就算能拉，第一次也会把它拉到父物体原点，不是从脚下往上升。

## 2. 做完之后

平台仍在第 8 层，站在上面仍算站在地上。运行时在平台上加一块第 7 层、标签 `Interactable` 的触发体，提示用平台上的 `interactTipText`。

`Game` 里这块平台的 `home` 改成它现在的本地坐标。`away` 用同一个 x、z，y 加 5。第一次拉到 `away`，第二次回到 `home`。休息不改它停在哪。

## 3. 验收

0.x 不新写 Edit Mode 测试。在 `Game` 里：

1. 站上电梯，出现「拉动」。
2. 按和开门一样的交互键：平台往上升。
3. 再按一次：平台回到刚才的位置。
4. 休息一次：平台仍停在按完之后的那一层。
