# 0.45 技术设计：走路不把敌人顶走

> **玩家身体和玩家自己的 Blocker 都不撞敌人根胶囊体。敌人的 Blocker 仍挡人。敌人刚体仍是动态的。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 忽略这一对

近战预制体里的 `Colliders` 是关着的，敌人的 Blocker 不在场上。只忽略根胶囊体时，人会穿进去。

[`EnemyManager.Start`](../../../../Assets/Scripts/Character/NPC/EnemyManager.cs) 先把第 10 层的 Blocker 及其关掉的父物体打开，并忽略它和敌人自己根胶囊体的碰撞，避免从内部把敌人顶飞。然后忽略玩家身体、玩家 Blocker 对敌人根胶囊体，以及两边 Blocker 彼此。留下的一对是玩家身体对敌人 Blocker：人被挡住，敌人的动态刚体不被挤开。

不改 `linearVelocity` 的追击。不改伤害触发体。

## 2. 不做

不把敌人刚体改成运动学。不忽略敌人之间的碰撞。不新写测试。不算高风险：改错了人会穿过去或敌人仍被顶走，当场能看出来。
