# 0.45 技术设计：走路不把敌人顶走

> **只忽略玩家身体胶囊体和敌人根胶囊体这一对。Blocker 仍挡人。敌人刚体仍是动态的。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 忽略这一对

[`EnemyManager.Start`](../../../../Assets/Scripts/Character/NPC/EnemyManager.cs) 在把 `rigidBody.isKinematic` 写成 false 之后，找到场上的 `PlayerManager`。若双方根上的 `cCollider` 都在，`Physics.IgnoreCollision(player.cCollider, cCollider, true)`。

`cCollider` 来自根物体的 `GetComponent<CapsuleCollider>`，不是子物体。Blocker 在第 10 层，不在这次忽略里。玩家自己的 Blocker 仍由 [`PlayerManager.Awake`](../../../../Assets/Scripts/Character/Player/PlayerManager.cs) 忽略。

不改 `linearVelocity` 的追击。不改伤害触发体。

## 2. 不做

不把敌人刚体改成运动学。不忽略敌人之间的碰撞。不新写测试。不算高风险：改错了人会穿过去或敌人仍被顶走，当场能看出来。
