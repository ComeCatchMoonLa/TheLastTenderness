# 0.45 游戏设计：走路不把敌人顶走

> **交付目标：玩家走过去，敌人停在原地，人被挡住。敌人自己的追击仍能走。**
>
> 0.x 不写单元测试。1.58 的施工文档还在，这一版插在它前面。

需求和调研没有写成「走路不得顶走敌人」。回归里看到走路会把近战顶开。原作是人被挡住，敌人不被顶着滑开。这一版按这个结果修。

## 1. 为什么是这一刀

近战根上的刚体是动态的，玩家身体胶囊体也是动态的。两个实心碰撞体重叠时，物理把敌人挤开。敌人走路靠写这颗刚体的速度，不能改成运动学。

敌人身上的 `Character Collider Blocker` 已是运动学刚体，用来挡人。

## 2. 做完之后

玩家身体胶囊体不和敌人根上那颗胶囊体相撞。人仍会被敌人的 Blocker 挡住，走不穿过去。敌人不被这下走路顶走。敌人追击、受击、攻击判定仍走原来的刚体和触发体。

## 3. 验收

0.x 不新写 Edit Mode 测试。在 `Game` 里对近战：

1. 走过去贴住：敌人不被顶着滑开，人也走不穿。
2. 它发现玩家后仍会追过来。
3. 打中它仍掉血。
