# 0.46 技术设计：梯子下端接到地面

> **挂上时用脚下高度。爬过或滑到下端就离开。挂着时落地射线返回。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 高度

[`LadderRide.Mount`](../../../../Assets/Scripts/World/LadderRide.cs) 增加脚下高度。`along` 用这个高度，大于 `top` 时写成 `top`。不抬到 `bottom`。

[`LadderInteractable`](../../../../Assets/Scripts/World/LadderInteractable.cs) 把 `player.transform.position.y` 传进去。

[`LadderMove.Climb`](../../../../Assets/Scripts/World/LadderMove.cs) 在 `along` 低于 `bottom` 时写成 `bottom` 并 `onLadder = false`。`Slide` 把 `along` 写成 `bottom` 并 `onLadder = false`。摇杆回中按闪避仍只设离开，不改成滑梯。

[`LadderRide.Update`](../../../../Assets/Scripts/World/LadderRide.cs) 在已经离开时不写 `position.y`。这一帧是从梯子上下来的，把 `isInAir` 写成真。

## 2. 落地射线

[`PlayerLocomotionManager.HandleFall`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 在 `LadderRide.onLadder` 为真时直接返回。`LadderRide` 可能是交互时才加上的，引用空了再取一次。

## 3. 已有测试

`Assets/Tests/EditMode/World/LadderMoveTests.cs` 里滑到下端之后 `onLadder` 改为假。后面的向外跳之前把 `onLadder` 设回真。不新写测试文件。

## 4. 不做

不新做爬梯动画。不改短梯踢倒。不算高风险。
