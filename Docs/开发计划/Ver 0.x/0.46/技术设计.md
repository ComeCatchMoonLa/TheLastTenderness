# 0.46 技术设计：梯子下端接到地面

> **挂上时用脚下高度。随时能往下，到地面才离开。按住闪避且向下是 2 倍速下降。摇杆回中按闪避进入下落。挂着时落地射线返回。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 高度

[`LadderRide.Mount`](../../../../Assets/Scripts/World/LadderRide.cs) 增加脚下高度。`along` 用这个高度，大于 `top` 时写成 `top`。不抬到 `bottom`。

[`LadderInteractable`](../../../../Assets/Scripts/World/LadderInteractable.cs) 把 `player.transform.position.y` 传进去。

[`LadderMove.Climb`](../../../../Assets/Scripts/World/LadderMove.cs) 用 `floor` 当地面，不用梯子标记的 `bottom` 当地面。人在 `floor` 上面时向下就降；已经在 `floor` 上再向下则停住，不离开。从上面降过 `floor` 才离开。`Step` 不再把按住闪避且向下做成瞬移到 `bottom`。

[`LadderRide`](../../../../Assets/Scripts/World/LadderRide.cs) 在按住闪避且摇杆向下时，用 2 倍 `climbSpeed` 向下，人还在梯子上。摇杆回中按闪避离开并进入下落，不先落到地上。人还在梯子上时，[`InputManager`](../../../../Assets/Scripts/Character/Player/InputManager.cs) 不把按住的闪避清掉，也不当成冲刺。离开梯子时 `KeepDodgeFromRolling` 清掉这一下的翻滚。

[`LadderRide.LeaveToGround`](../../../../Assets/Scripts/World/LadderRide.cs) 在离开时，高于 `along` 才降到 `along`。再从脚上方向下 8 米找地，找到就把人放在地面，`isInAir` 为假，`isInteracting` 为假，`canRotate` 为真，速度清零。找不到才进入下落。不播 `Falling` 或 `Land`。

[`PlayerLocomotionManager`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 在 `onLadder` 为真时不走、不转、不跳、不翻滚，并把水平速度写成 0。

## 2. 落地射线

[`PlayerLocomotionManager.HandleFall`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 在 `LadderRide.onLadder` 为真时直接返回。`LadderRide` 可能是交互时才加上的，引用空了再取一次。

## 3. 已有测试

`Assets/Tests/EditMode/World/LadderMoveTests.cs` 里向下是沿梯子降，人还挂着。从地面上面降过地面才离开。不新写测试文件。

## 4. 不做

不新做爬梯动画。不改短梯踢倒。不算高风险。
