# 0.46 游戏设计：梯子下端接到地面

> **交付目标：交互后人不被抬到梯子下端悬空。爬到或滑到下端时离开梯子，落到地上，走路恢复。挂在梯子上时不播下落。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-机关-01](../../../需求文档/功能需求/场景机关.md)。交互后能上下，按住闪避向下到梯底，摇杆回中按闪避离开并进入下落。

## 1. 为什么是这一刀

`Mount` 把高度写成梯子的 `bottom`。`bottom` 是梯子那一段的下端，不是脚下的地。下一帧只改 `position.y`，人被抬起来。

往下爬和滑梯都停在 `bottom`，不离开梯子。落地射线够不着地板，就判成在空中，播 `Falling`，走路停掉。缺爬梯动画不造成这次腾空。

## 2. 做完之后

交互时高度用脚下现在的位置，高于梯子上端才钳到上端，不抬到 `bottom`。

往下爬要低于 `bottom`，或按住闪避并且摇杆向下时，离开梯子，高度不再被梯子写回去。人从当时的高度落到地上，落地后能走。

还挂在梯子上时，落地射线不把人判成下落，不播 `Falling`。摇杆回中再按闪避，仍离开并进入下落。

## 3. 验收

在 `Game` 里对现有梯子：

1. 站在地上交互：人留在脚下的高度，不悬空，不播 `Falling`，摇杆向上能爬。
2. 爬到下端：人落到地上，能走。
3. 在梯子上按住闪避且摇杆向下：滑到下端后同样落到地上，能走。
4. 摇杆回中再按闪避：离开梯子并进入下落。
