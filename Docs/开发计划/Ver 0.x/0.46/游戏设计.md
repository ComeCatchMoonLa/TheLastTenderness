# 0.46 游戏设计：梯子下端接到地面

> **交付目标：交互后人不被抬到梯子下端悬空。爬到或滑到下端时离开梯子，落到地上，走路恢复。挂在梯子上时不播下落。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-机关-01](../../../需求文档/功能需求/场景机关.md)。交互后能上下。按住闪避且摇杆向下是沿梯子加速下降，到地面再站下。摇杆回中按闪避离开并进入下落。没有爬梯动画，加速下降先用 2 倍爬梯速度。

## 1. 为什么是这一刀

`Mount` 把高度写成梯子的 `bottom`。`bottom` 是梯子那一段的下端，不是脚下的地。下一帧只改 `position.y`，人被抬起来。

往下爬和滑梯都停在 `bottom`，不离开梯子。落地射线够不着地板，就判成在空中，播 `Falling`，走路停掉。缺爬梯动画不造成这次腾空。

## 2. 做完之后

交互时高度用脚下现在的位置，高于梯子上端才钳到上端，不抬到 `bottom`。脚下比 `bottom` 低时仍挂着，向上爬，不因为还没到下端就离开。

挂上之后随时能往下，不必先爬过梯子标记的下端。最低只到挂上时脚下的地面，再往下就离开并站在地上，不播下落。按住闪避且摇杆向下是 2 倍速沿梯子下降，不立刻跳下来，也不滚动。到地面后同样站下。

还挂在梯子上时，不左右走、不转向，落地射线不把人判成下落，不播 `Falling`。摇杆回中再按闪避，仍离开并进入下落。

## 3. 验收

在 `Game` 里对现有梯子：

1. 站在地上交互：人留在脚下的高度，不悬空，不播 `Falling`，摇杆向上能爬。
2. 爬到下端：人落到地上，能走。
3. 刚挂上就按向下：人沿梯子下降，不先被要求往上爬。按住闪避且摇杆向下：下得更快，仍在梯子上，到地面后站下，不滚动。
4. 摇杆回中再按闪避：离开梯子并进入下落。
