# 0.47 技术设计：第一次点火弹出已点燃

> **`PopUp` 先激活物体，再开淡入协程。淡入淡出的时间和火的点燃不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 激活

[`CampFireLitPopUpUI.PopUp`](../../../../Assets/Scripts/UI/Player%20UI/Pop%20Up%20Windows/CampFireLitPopUpUI.cs) 现在第一行就是 `StartCoroutine`。物体未激活时，协程开不起来，`FadeInPopUp` 开头的 `SetActive(true)` 不会执行。

`PopUp` 在开协程之前，物体未激活时先 `SetActive(true)`。`Awake` 里已经取 `CanvasGroup`，激活时会先跑到。协程里的那次激活留着。

不改 [`CampFireInteractable.Interact`](../../../../Assets/Scripts/Items/Interactions/CampFireInteractable.cs)。不改淡入、停 2 秒、淡出的步进。
