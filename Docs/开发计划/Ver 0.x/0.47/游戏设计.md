# 0.47 游戏设计：第一次点火弹出已点燃

> **交付目标：还没点着的火，第一次交互时燃起提示会淡入再淡出。Console 不再报协程开不起来。火仍点着，靠近时提示仍是「休息」。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-燃火-01](../../../需求文档/功能需求/燃火休息与死亡惩罚.md)。未点燃的火交互后，屏幕出现燃起提示，火焰可见，再次靠近时提示是「休息」。第一次交互要不要接着坐下，需求和调研还没写成同一句，这一版不选。

## 1. 为什么是这一刀

`Camp Fire Activated` 平时是关着的，用来藏那句提示。`PopUp` 在这个物体上 `StartCoroutine`。Unity 不能在未激活的物体上开协程，直接抛错，淡入不会跑。提示不出现。

火不靠这句字。报错之后同一段仍把火记成点着，提示改成「休息」，打开火焰，播点火声。

## 2. 做完之后

第一次点火时，燃起提示先淡入，停一下，再淡出。Console 没有协程开不起来的报错。火焰可见，靠近时提示是「休息」。

已经点着的火再交互，不重复弹这句。获得提示和对话不改。不新做一套通用弹字。不改坐下。

## 3. 验收

在 `Game` 里对还没点着的火：

1. 交互一次：没有协程报错。燃起提示淡入，过一会儿淡出。火焰可见。提示改成「休息」。
2. 再交互：不重复弹这句。休息仍走现在的已点燃分支。
