# 0.48 游戏设计：追击时人会走过去

> **交付目标：发现玩家后，敌人沿着导航走过来，位置跟着变。走路动画仍在播。回家也走得动。攻击时的根运动仍在。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-敌人-02](../../../需求文档/功能需求/敌人.md)。发现玩家后向玩家移动，近到攻击距离就停下追击并出手。回家走的是同一段移动，距离规则不在这一版改。

## 1. 为什么是这一刀

追击把导航目标设上，又把刚体速度写回设目标之前的值。走路动画在播，人停在原地。回家用的是同一段。

`OnAnimatorMove` 在基础层是 `Locomotion` 时也写速度。走路片段不带位移时，这一写把水平速度写成 0，和导航抢。

## 2. 做完之后

追击和回家只由导航的 `desiredVelocity` 推水平位置，竖直速度留着。根运动只在 `isInteracting` 时推，攻击、受击、死亡仍走它。

人形周旋不再被 `Locomotion` 的根运动写成 0。不在交互时，水平速度写成 0，不带着追击的速度滑进去。发现、出手、回家的距离不改。

## 3. 验收

在 `Game` 里对现有近战：

1. 人出现在它面朝的扇形里：它走过来，位置在变，然后出招。
2. 把它拉出大约 15 米：它走回放置点，不是原地播走路。
3. 攻击时人仍跟着动作挪。

已有 `EnemyRootMotionTests`：不在交互、基础层是 `Locomotion` 时不再写根运动速度。交互中仍写。不新写测试文件。
