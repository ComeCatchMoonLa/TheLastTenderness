# 0.49 技术设计：周旋时人会绕着走

> **人形近战周旋用已有的左右、进退乘导航 `speed` 写水平速度。不再同一帧清成 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 周旋

[`CombatStanceStateHumanoid.ProcessMeleeCombatStyle`](../../../../Assets/Scripts/Character/NPC/State/Humanoid%20A.I/CombatStanceStateHumanoid.cs) 在不交互时先 `StopHorizontal`，再 `WalkAroundTarget`。混合值出来之后没有写进刚体。

改成先 `WalkAroundTarget`，再用 `transform.right * horizontalMovementValue + transform.forward * verticalMovementValue`，乘 `navmeshAgent.speed`，写成水平速度。竖直分量留着。两边都是 0 时水平速度是 0。近战不再调用 `StopHorizontal`。

`WalkAroundTarget` 里的 0.5、`-0.5`、3 米、`ApproachDistance` 不改。

交互中仍提前返回，根运动不被这下清掉。弓的 `StopHorizontal` 留着。追击和回家的 `WalkToward` 不改。
