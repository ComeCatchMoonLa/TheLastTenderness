# 0.49 游戏设计：周旋时人会绕着走

> **交付目标：近战进了攻击距离、攻击还在冷却时，会按已经算好的左右和进退挪位置，不是只播走路。追击、回家、攻击根运动仍和现在一样。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-敌人-02](../../../需求文档/功能需求/敌人.md)。近到攻击距离后停下追击并出手。冷却里的左右和进退是现有周旋，这一版让它带动位置。

## 1. 为什么是这一刀

追击已经用导航速度在走。进了周旋之后，左右和进退只写进动画，同一帧又把水平速度写成 0。走路在播，人不挪。

## 2. 做完之后

人形近战在周旋里：冷却中随机向左或向右，近于 3 米就后退；冷却好了、远于 1.4 米就走近；两边都是 0 时停住。速度用导航代理的 `speed` 乘这些已有的混合值。竖直速度留着。

追击和回家仍用 `desiredVelocity`。攻击、翻滚、格挡、弹反仍用根运动。弓的周旋仍停住。

## 3. 验收

在 `Game` 里对现有近战：

1. 它追到身边后，冷却中会向侧向或后退挪，不是原地播走路。
2. 冷却好了、还差一点距离时会再走近，然后出招。
3. 追击过来、拉远回家，仍和 0.48 一样会走。
