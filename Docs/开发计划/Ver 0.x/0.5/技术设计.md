# 0.5 技术设计：移动旗标只有一个写入方

> **只收冲刺的第二写入方。翻滚、跳跃、在空中已经各只有一处赋值，保持不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现状里的赋值

| 旗标 | 赋值位置 | 本版 |
| --- | --- | --- |
| `isRolling` | `HandleRollState.OnStateEnter` / `OnStateExit` | 不改 |
| `isJumping` | `HandleJumpState.OnStateEnter` / `OnStateExit` | 不改 |
| `isInAir` | `PlayerLocomotionManager.HandleFall` | 不改 |
| `isSprinting` | `InputManager.HandleRollInput` 多处；`BlockAction.PerformAction` 一处写成 false | 删掉 `BlockAction` 那一处 |

`PlayerAnimatorManager.UpdateAnimatorValues` 的 `isSprinting` 参数是只读入参，不是字段赋值。`CombatStanceStateHumanoid`、`PlayerLocomotionManager.HandleMove`、`PlayerManager` 只读这些字段。

## 2. 冲刺改哪里

`InputManager.HandleRollInput` 现在开头是 `if (player.isInteracting) return;`。举盾会先把 `isSprinting` 清掉，再进入交互动画；如果删掉 `BlockAction` 的赋值又不改这里，函数会在清冲刺之前 return，人会继续按冲刺速度滑。

在这个 return 之前加上：`cCombat.isBlocking` 时把 `isSprinting` 设为 false。瞄准时的清除已经在这个函数末尾，保留。

`BlockAction` 删掉 `character.isSprinting = false;`。格挡、扣体力、播 `Block - Start` 不动。

## 3. 不做

不把四个字段挪出 `CharacterManager`。不改敌人是否会翻滚。不补单元测试；验收靠 Play 和全库搜索赋值点。
