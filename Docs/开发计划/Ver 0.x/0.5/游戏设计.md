> **草稿。** 靠后。移出目录要先确认绝对路径，不是 AI 做完再验收。轮到本版时再拿掉这行。

> **交付目标：工程里不再留着 `Game` 和项目预制体都引用不到的顶层导入目录。功能不变，只去掉臃肿。**

## 1. 为什么靠后

功能很少，但 `Assets` 里堆着整包导入：Polygon、武器包、Ida Faber、TextMesh Pro 示例、多套 BGM。删磁盘之前必须有一份人点过名的路径，所以不排在前排。

已经知道不能整包删的：

- Ida Faber 的 Vampire Girl：`Game.unity` 引用了预制体 guid `cf9469e6ac458304fbcd3cb657bad0fa`。
- Polygon 的一部分道具：场景里有 `SM_Env_CampFire_01`。

一个包里只有部分引用时，只移出零引用的子目录。

## 2. 怎么算零引用

从 `Assets/Scenes/Game.unity` 和 git 正在跟踪的项目预制体收集 guid，再反查 `.meta`。一个目录下的资源 guid 都没有出现，它才是删除候选。按文件夹名字猜测不算数。

## 3. 验收

- 清单分成「留下」和「移出」，移出项是绝对路径，并且已经确认。
- 移出之后打开 `Game`，Vampire Girl 和营火还在，玩家仍能移动。
- 场景和玩法脚本与本版开始前一致。
