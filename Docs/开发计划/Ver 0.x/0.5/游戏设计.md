# 0.5 游戏设计：移动旗标只有一个写入方

> **交付目标：`isRolling`、`isJumping`、`isSprinting`、`isInAir` 各只有一个类型负责写入。其他脚本只读。翻滚、跳跃、冲刺的手感与现在一致。**
>
> 不改战斗旗标（格挡、瞄准、交互）。不拆 `CharacterManager` 上的 Manager，不加事件总线。

## 1. 为什么是这一刀

这四个字段挂在 `CharacterManager` 上，谁都能改。冲刺尤其明显：按住 Shift 的逻辑在 `InputManager`，举盾时 `BlockAction` 又直接把它写成 false。以后改移动，要先猜这帧是谁改的。

## 2. 谁写

| 旗标 | 唯一写入方 | 含义 |
| --- | --- | --- |
| `isRolling` | `HandleRollState` | 进入翻滚动画为 true，离开为 false |
| `isJumping` | `HandleJumpState` | 进入跳跃动画为 true，离开为 false |
| `isInAir` | `PlayerLocomotionManager` | 脚下射线判定在空中或落地 |
| `isSprinting` | `InputManager` | 按住左 Shift、在移动、体力够、且没在瞄准或格挡 |

举盾时不再由 `BlockAction` 改冲刺。冲刺在格挡期间由 `InputManager` 清掉，避免人还按着 Shift 就继续加速。

## 3. 验收

- 走、冲刺、短按 Shift 翻滚、跳跃、下落落地，与本版开始前一致。
- 冲刺中举盾，冲刺停下，盾的动作仍在。
- `Assets/Scripts` 里对这四个字段的赋值，每种只出现在上表那一个类型里。
