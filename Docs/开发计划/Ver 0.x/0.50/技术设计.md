# 0.50 技术设计：活动范围围着放置点

> **活动范围改量离 `placement` 的距离。察觉距离仍量离玩家。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 距离

[`Territory.PulledOut`](../../../../Assets/Scripts/Character/NPC/Territory.cs) 仍是「不是头目、活动范围大于 0、距离大于活动范围」。不改它的参数。已有 `TerritoryTests` 仍成立。

[`EnemyManager`](../../../../Assets/Scripts/Character/NPC/EnemyManager.cs) 增加 `LeftActivity`。距离用 `transform.position` 到 `placement`，再交给 `PulledOut`。

[`PursueTargetState`](../../../../Assets/Scripts/Character/NPC/State/General%20A.I/PursueTargetState.cs) 的活动范围判断改调 `LeftActivity`。`Leash.TooFar` 仍传入 `distFromTarget` 和 `detectionRadius`。

[`CombatStanceState`](../../../../Assets/Scripts/Character/NPC/State/General%20A.I/CombatStanceState.cs) 和 [`CombatStanceStateHumanoid`](../../../../Assets/Scripts/Character/NPC/State/Humanoid%20A.I/CombatStanceStateHumanoid.cs) 在还追着时，若 `LeftActivity` 成立，把 `returningHome` 和 `returnToPlacement` 写成真，回到追击状态。下一帧由追击走回家。
