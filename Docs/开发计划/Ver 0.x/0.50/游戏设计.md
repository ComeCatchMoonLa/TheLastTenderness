# 0.50 游戏设计：活动范围围着放置点

> **交付目标：普通敌人离开放置点超过活动范围，就放弃追击，走回放置点，走到之后满血。贴着它走，不能把它带出这一圈还接着打。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-头目-01](../../../需求文档/功能需求/头目.md)，[敌人与头目](../../../调研文档/敌人与头目.md)「围绕放置点的活动范围」。2.77 把这条写成了离玩家的距离，和这两处不一致。

## 1. 为什么是这一刀

`activityRadius` 现在拿去和敌人到玩家的距离比。它贴着人追时，这个距离只有几米，超不过 15。人可以把它带离放置点很远，它仍接着打。

察觉距离那条是玩家拉开到超过配置距离，走回发现前的位置、不回血。那条仍量离玩家有多远，这一版不改。

## 2. 做完之后

普通敌人离开局记下的放置点超过 `activityRadius` 时，停止追击和周旋，走回放置点。走到之后生命写成上限，再回待机。归途中被打中，并且离玩家还不大于 `aggroRadius`，转回追击，生命保持被打过的数。

头目仍不因此归位。`activityRadius` 不大于 0 时仍不走这条。离玩家超过察觉距离，仍走回发现前的位置、不回血。

## 3. 验收

在 `Game` 里对这只近战（活动半径 15，察觉距离 30）：

1. 贴着它走出放置点大约 15 米：它放弃追击，走回放置点，走到之后满血。
2. 归途中离它大约 5 米以内打中：转回追击，不满血。离得更远打中：继续回家。
3. 头目不在这场。这一条不测。
