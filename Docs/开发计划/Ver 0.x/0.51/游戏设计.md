# 0.51 游戏设计：点在界面上不触发鼠标战斗键

> **交付目标：指针在界面上时，鼠标左键的点按和长按、鼠标右键，不再开出战斗动作。键盘上的同一批动作仍生效。菜单开着时世界不停。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[界面与场景交互](../../../调研文档/界面与场景交互.md)「背包分页」「装备界面」。菜单开着时世界仍走，选中后模型马上换。这篇没写时间停住。点在界面上的鼠标不再兼做战斗键，是这一版要补上的结果。

## 1. 为什么是这一刀

鼠标左键点按绑着右手轻击，长按绑着处决。鼠标右键同时绑着左手轻击，以及举盾或瞄准。分页用同一套鼠标点选。点在格子上时，界面收到点击，战斗也跟着触发。

## 2. 做完之后

指针打在界面图形上时：

- 鼠标左键点按不轻击、不射箭。
- 鼠标左键长按不进入处决。
- 鼠标右键不打出左手轻击，也不举盾、不进入瞄准。

键盘 `E`、`Q`、`R`、`Z` 仍走原来的战斗动作。已经按在世界里的举盾，松开仍放下。不暂停。换上另一把仍换成新模型。

换上空手后用拳头打。伤害体用拳头模型上的那一只，不再去开已经销毁的上一把。盾和法杖没有近战伤害体时，挥击事件直接返回。

## 3. 验收

`Tab` 打开分页，指针放在格子上：

1. 点鼠标左键：不挥剑。再点同一件装备仍按现在的规则换上。
2. 按住鼠标左键约半秒：不进入处决。
3. 点鼠标右键：不打出左手攻击，也不举盾。
4. 指针移开界面，在画面空处点左键：仍轻击。
5. 点空手那一格，或方向键轮到它：换成拳头。再在画面空处点左键：打出拳头，Console 不报 `MeshCollider` 已销毁。
