# 0.52 技术设计：光标停在装备格上不换武器

> **指针移入只刷新旁边的数字。点选才换上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 分开两次

[`EquipmentSlotUI`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/EquipmentWindow/EquipmentSlotUI.cs) 增加 `PreviewThisSlot`。它只调用 `UpdateEquipmentItemStats`，不改当前武器，不加载模型。

[`Global UI.prefab`](../../../../Assets/Prefabs/UI/Global%20UI/Global%20UI.prefab) 里，装备格 `EventTrigger` 的指针移入（`eventID` 0）改调 `PreviewThisSlot`。点选（`eventID` 9）仍调 `SelectThisSlot`。左右手第 1、第 2 格和头、身、髋的按钮点击里，去掉 `SelectInventoryWin`。分页上的背包按钮留着。

## 2. 不做

不改背包里点两次才换上。不改方向键轮换。不新写测试。不算高风险。

## 3. 验收

游戏设计第 3 节。
