# 0.52 游戏设计：光标停在装备格上不换武器

> **交付目标：鼠标放在装备格上，手里的武器不变。点下去才换成这一格。**
>
> 0.x 不新写单元测试。1.58 的施工文档还在，这一版插在它前面。

来源：[FR-菜单-04](../../../需求文档/功能需求/菜单.md)，[FR-装备-06](../../../需求文档/功能需求/装备与道具.md)，[界面与场景交互](../../../调研文档/界面与场景交互.md)「装备界面」。光标停在候选人上只做对比，确认后才穿上。装备窗里改选之后，手上的模型换成这一把。

## 1. 为什么是这一刀

装备格在指针移入时就调用换装。人还没点，手里的武器已经换成这一格。

## 2. 做完之后

指针放在装备格上：旁边可以看这一格的名字和数字，手里的武器和模型不变。

点这一格：手里换成这一格的武器，下一次攻击用这一把。方向键轮换仍换。

## 3. 验收

`Tab` 打开分页，点 Equipment。

1. 鼠标放上这只手的第 2 格，不点：手里还是原来的武器。
2. 点这一格：手里换成这一格的武器。
