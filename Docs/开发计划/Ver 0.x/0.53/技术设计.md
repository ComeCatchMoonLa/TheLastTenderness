# 0.53 技术设计：喝完回城和余烬还能转向

> **这四件喝药时允许转向，和血瓶同一条。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 和血瓶对齐

[`FlaskItem`](../../../../Assets/Scripts/Items/Consumables/FlaskItem.cs) 播放喝药时传入 `CanRotate = true`。

[`HomewardBoneItem`](../../../../Assets/Scripts/Items/Consumables/HomewardBoneItem.cs)、[`EmberItem`](../../../../Assets/Scripts/Items/Consumables/EmberItem.cs)、[`DarkSignItem`](../../../../Assets/Scripts/Items/Consumables/DarkSignItem.cs) 播放同一段时也传入 `CanRotate = true`。卷剑碎片走回城骨这一段，不用再改。

资产上的 `isInteracting` 保持 0，和血瓶一样。

## 2. 不做

不改 `RecordedFire.Move`。不改余烬扣个数，也不拦已经点着的余烬。不新写测试。不算高风险：和已经在用的血瓶是同一个参数。
