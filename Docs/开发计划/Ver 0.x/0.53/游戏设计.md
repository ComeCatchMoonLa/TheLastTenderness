# 0.53 游戏设计：喝完回城和余烬还能转向

> **交付目标：回城骨、卷剑碎片、余烬、暗印的喝药动作播完，人还能转向。**
>
> 0.x 不新写单元测试。送回会不会被拉回原地是 0.54。余烬扣不扣个数是 0.55。

来源：[FR-周目-04](../../../需求文档/功能需求/周目与结局.md)、[FR-周目-09](../../../需求文档/功能需求/周目与结局.md)、[FR-周目-03](../../../需求文档/功能需求/周目与结局.md)、[FR-周目-01](../../../需求文档/功能需求/周目与结局.md)。血瓶喝的时候人还能转。这四件用的是同一段喝药，播完却转不了。

## 1. 为什么是这一刀

这四件播放喝药时把转向关掉，喝完没有打开。余烬不传送也会转不了，所以不依赖有没有坐下。

## 2. 做完之后

用完回城骨、卷剑碎片、余烬或暗印，喝药动作结束之后，推摇杆或移动鼠标，人能转向。

血瓶仍能在喝的时候转向。送回落在哪、个数扣不扣、已经点着的余烬放不放得出去，这一版不改。

## 3. 验收

先坐下。快捷栏分别切到这四件，各用一次。

1. 喝药动作结束后，移动时人能转向。余烬不坐下也能测这一条。
2. 血瓶喝的时候仍能转向。
