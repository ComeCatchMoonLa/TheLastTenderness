# 0.54 游戏设计：送回停在记下的火边

> **交付目标：回城骨、卷剑碎片、暗印送回之后，人停在上次坐下的那堆火旁边，不被拉回使用前的位置。**
>
> 0.x 不新写单元测试。喝完还能转向是 0.53。余烬扣不扣个数是 0.55。

来源：[FR-周目-04](../../../需求文档/功能需求/周目与结局.md)、[FR-周目-09](../../../需求文档/功能需求/周目与结局.md)、[FR-周目-03](../../../需求文档/功能需求/周目与结局.md)。人要出现在记下的火边。

## 1. 为什么是这一刀

送回把位置写在变换上。人身上的刚体下一步把人拉回使用前的地方，所以前几次像原地跳一下，偶尔才停在火边。

## 2. 做完之后

离开那堆火一段距离，用回城骨、卷剑碎片或暗印。动作结束后人在那堆火旁边，不再弹回使用前的位置。

头目血条出现时仍放不出去。灵魂、余烬、个数按原来各自的规则。转向不在这一版再改。

## 3. 验收

先坐下，再走开。

1. 用回城骨：人停在这堆火旁边，不弹回去。
2. 用卷剑碎片：同样停在火边。
3. 灵魂大于 0 时用暗印：同样停在火边。
