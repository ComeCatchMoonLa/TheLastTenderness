# 0.55 技术设计：余烬用掉一个，已经点着时放不出去

> **没点着才喝，喝成才少一个。已经点着时 `ApplyEmber` 不改上限。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 两道门

[`EmberItem.AttemptToConsumableItem`](../../../../Assets/Scripts/Items/Consumables/EmberItem.cs)：`emberLit` 已经为真时直接返回，不播放喝药。

喝成之后调用 `TrySpendConsumable`。`ApplyEmber` 返回假时不扣。

[`PlayerStatsManager.ApplyEmber`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs)：`emberLit` 已经为真时返回假，不改 `maxHP` 和 `currentHP`。没点着时仍按比例抬高，并记下点之前的上限。

## 2. 不做

不改喝药转向。不改送回落点。不新做余烬外形。不新写测试。不算高风险：已有的一次抬高测试仍只调用一次。
