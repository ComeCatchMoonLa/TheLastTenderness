# 0.55 游戏设计：余烬用掉一个，已经点着时放不出去

> **交付目标：没有余烬时用掉一个，上限变长并补到顶。已经点着时放不出去，个数不减，上限不再乘一次。**
>
> 0.x 不新写单元测试。喝完还能转向是 0.53。送回落点是 0.54。

来源：[FR-周目-01](../../../需求文档/功能需求/周目与结局.md)。第一次消耗。已经点着时不可使用，不叠上限。

## 1. 为什么是这一刀

现在用完不扣个数。已经点着再放，上限按当前这一档再乘一次。

## 2. 做完之后

没有余烬时用一个：个数少一个，上限按物品上的比例变长，当前生命补到新上限。

已经点着时再放：不播喝药，个数不变，上限不变，当前生命不因此再抬一次。

余烬外形仍不做。转向和送回落点不在这一版再改。

## 3. 验收

快捷栏切到余烬。

1. 没有余烬时用一个：个数少一个，血条变长并补满。
2. 再放一次：喝药不播，个数还是刚才那个，血条长度不变。
