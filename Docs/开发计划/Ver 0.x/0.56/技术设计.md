# 0.56 技术设计：手部吸收写入五段

> **手甲的五段抄进角色，受伤时再乘 `(1 − 手部该段)`。没戴时乘 1。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 写入和相乘

[`CharacterStatsManager`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 增加 `handArmorPDA`、`handArmorFDA`、`handArmorMDA`、`handArmorLDA`、`handArmorDDA`。

[`TakeDamage`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 在现有头、躯干、下身合成之后，该段再乘 `(1 − 对应手部吸收)`。`CombinedArmorRate` 的三个权重不改。

[`PlayerArmorManager.EquipAllArmorModels`](../../../../Assets/Scripts/Character/Player/PlayerArmorManager.cs)：`currentHandArmor` 有时，把 `physicalDA`、`fireDA`、`magicDA`、`lightningDA`、`darkDA` 写入上面五个字段。没有时写成 0。不找手部换模。

## 2. 不做

不改头、躯干、下身的 0.6、0.3、0.1。不新做手部模型。不把物理拆成打击、斩击、突刺。不新写测试。不算高风险：没戴手甲时现有三件测试的数字不变。
