# 0.56 游戏设计：手部吸收写入五段

> **交付目标：戴上手甲后，物理、火、魔、雷、暗五段都再乘过手部这一段。没戴时，头、躯干、下身的合成与现在相同。**
>
> 0.x 不新写单元测试。

来源：[FR-伤害-06](../../../需求文档/功能需求/命中判定与伤害.md)。手部五种吸收写入现有合成。物理子类各算各的见 FR-伤害-08，这一版不选。

## 1. 为什么是这一刀

头、躯干、下身穿上后，五段已经进受伤结算。手甲字段在，五种吸收没有写进去。脱掉手甲时，现有三件的权重不能被改掉。

## 2. 做完之后

没戴手甲：物理、火、魔、雷、暗与现在相同。头 0.6、躯干 0.3、下身 0.1 仍只乘一次。

戴上手甲：这一段再乘 `(1 − 手部该段吸收)`。五段各自用自己的手部吸收。脱掉后这五段手部吸收回到 0，合成回到没戴时。

不新做手部模型。不改头、躯干、下身的权重。

## 3. 验收

没戴手甲时，头吸收 0.5、其余为 0、物理伤害 100，生命从 100 降到 30。三件该段吸收都是 1 时，这一段不掉血。

戴上手甲且该段吸收是 0.5 时，上面那一击再剩一半。脱掉后回到没戴时的下降。
