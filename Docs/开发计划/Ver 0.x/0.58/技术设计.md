# 0.58 技术设计：下一周 NPC 回到原位

> **下一周把剧情 NPC 放回放置点，并把赠送进度清掉。休息不这样做。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 原位

[`StoryNpcCycle.Place`](../../../../Assets/Scripts/World/StoryNpcCycle.cs) 打开物体，放到放置点，清掉死亡并补满。

[`NewCycle.Apply`](../../../../Assets/Scripts/World/NewCycle.cs) 对 `isStoryNpc` 的人调用它。放点用 `placement`，还没记下就用 `restOrigin`。同时把 [`Talk.giftAdvanced`](../../../../Assets/Scripts/Items/Interactions/Talk.cs) 写成假。

剧情 NPC 死亡时藏起来，不删掉，这样下一周还找得到。休息仍不把他们叫回来。

## 2. 不做

不写新的 Edit Mode 用例。不改敌人难度和掉魂。不算高风险：只在下一周复位剧情 NPC。
