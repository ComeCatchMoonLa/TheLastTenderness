# 0.58 游戏设计：下一周 NPC 回到原位

> **交付目标：进入下一周后，死去的剧情 NPC 回到原位，任务进度复位。**

来源：[FR-周目-05](../../../需求文档/功能需求/周目与结局.md)。火、门、钥匙、箱子、雾门和近战的重置已经在。这一版补 NPC。

## 1. 为什么是这一刀

下一周人还在，任务重来。死掉的 NPC 不该一直缺席。

## 2. 做完之后

标成剧情的 NPC 回到放置点，活着，血满。赠送推进过的对话，进度回到还没送过。

休息不把他们叫回来。敌人更难、掉魂更多，不在这一版。

## 3. 验收

0.x 不写用例。不进场景找 NPC。看下一周把人和赠送进度复位。
