# 0.59 技术设计：没弹仍拉弓射出

> **瞄准不再看剩余。空拉在射出入口播 `Shoot Arrow`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 瞄准

[`AimAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/AimAction.cs) 去掉按剩余提前返回。双手持就进入 `aimingMode`。

## 2. 空拉

[`EmptyDraw.Clip`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/EmptyDraw.cs) 改为 `Shoot Arrow`。`Plays` 仍是剩余小于或等于 0。

[`ShootArrowAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/ShootArrowAction.cs) 在已经瞄准、并且 `Plays` 为真时，播这一段并返回。不扣弹、不生成。

[`SuccessfullyGetArrow`](../../../../Assets/Scripts/Character/CharacterAnimatorManager.cs) 在没有当前弹或剩余小于或等于 0 时仍不放弦上模型。

## 3. 不做

不改有箭才切瞄准镜头。不新写用例。已有 [`EmptyDrawTests`](../../../../Assets/Tests/EditMode/Combat/EmptyDrawTests.cs) 的片段名改成 `Shoot Arrow`。不算高风险：只把空拉从瞄准入口挪回射出。
