# 0.59 游戏设计：没弹仍拉弓射出

> **交付目标：数量为 0 时，拉弓或扣弩的射出动作做出来，场上没有新弹。瞄准不因没弹被挡在门外。**

来源：[FR-远程-03](../../../需求文档/功能需求/箭矢与弩.md)。2.121 把空拉接到了瞄准入口，播的是进瞄准的过渡 `Aiming - Start`，并且不进入 `aimingMode`。左键射出要求已经在瞄准里，所以没弹时到不了空拉。

## 1. 为什么是这一刀

拉弓射出和进入瞪准是两下。没弹时要做出来的是射出那一下，不是进瞄准的过渡。有没有箭不决定进不进瞄准。

## 2. 做完之后

双手持时按瞄准，剩余是 0 也进入 `aimingMode`。

已经在瞄准里、剩余小于或等于 0 时再射出：播 `Shoot Arrow`，不生成飞行物，不扣弹，弦上不放新箭。

剩余大于 0 仍射出。镜头在有箭时切到瞄准挂点，不在这一版。

## 3. 验收

0.x 不新写用例。已有的空拉断言改成射出片段。不进游戏拉弓。
