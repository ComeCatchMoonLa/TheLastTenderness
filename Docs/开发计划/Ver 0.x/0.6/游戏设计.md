# 0.6 游戏设计：脚本注释改成 UTF-8

> **交付目标：`Assets/Scripts` 里的中文注释用 UTF-8 保存，编辑器按 UTF-8 打开不再是乱码。不改任何语句。**

## 1. 为什么是这一刀

脚本原来是 GB2312。编辑器按 UTF-8 打开，注释就变成乱码。后面改移动和 AI 时要能读这些注释。

## 2. 怎么处理

- 字节还是 GB2312 的，转成 UTF-8。
- 注释已经被写成无效字符的，从基线提交 `6e7e791` 里把中文取回来，接到当前代码上。对不上的坏注释删掉，不另写一套说明。

不改标识符，不改逻辑，不改 `Assets/Art` 里的商店脚本。

## 3. 验收

- `Assets/Scripts` 下每个 `.cs` 都是 UTF-8，注释里不再有成片无效字符。
- 与转码前相比，去掉注释和空白后的代码一致。`InputManager` 里举盾不把冲刺写回 true 的条件还在。
