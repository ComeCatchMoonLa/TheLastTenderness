# 0.60 技术设计：豁免里状态弹不加槽

> **加槽和钉模型用同一个无敌判断。豁免里两者都不做。举盾不走这个返回。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 命中

[`AmmoDamageCollider`](../../../../Assets/Scripts/Damage/Damage%20Collider/AmmoDamageCollider.cs) 在打中角色后，只在 `isInvulnerable` 为假时调用 [`AmmoStatus.Apply`](../../../../Assets/Scripts/Items/Equipment/Weapons/Ammo/AmmoStatus.cs)，并钉模型。

基类在没有弹反、也没有举盾、并且处于豁免时已经返回，这一下不掉血。子类不再在那次返回之后加槽。

正面举盾走基类的格挡分支，不因豁免返回，所以仍加槽。

## 2. 不做

不改 2.123 的「只推进配置的那一种槽」。不新写用例。不算高风险：只把加槽挪进已有的豁免判断。
