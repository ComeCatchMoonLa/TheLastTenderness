# 0.60 游戏设计：豁免里状态弹不加槽

> **交付目标：翻滚受击豁免里吃到状态弹，生命不变，毒或出血槽也不升。正面举盾时槽仍升。**

来源：[FR-异常-06](../../../需求文档/功能需求/状态积蓄.md)。无敌期间这一下不加槽已经收尾。2.123 把加槽放在碰到角色之后、无敌判断外面，豁免里仍会涨槽。

## 1. 为什么是这一刀

豁免里这一下不掉血，也不该推进异常槽。举盾挡住是另一句，槽仍然要涨。

## 2. 做完之后

翻滚受击豁免里命中：生命不变，配置的那一槽也不变。

没有豁免时打中：槽仍按 2.123 只推进配置的那一种。正面举盾挡住时，这一槽仍升。

## 3. 验收

0.x 不新写用例。不进游戏翻滚。
