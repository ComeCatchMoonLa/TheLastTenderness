# 0.61 技术设计：光标停在另一件上能看出攻击力和吸收的高低

> **把已经算出来的差写进已有的攻击力和物理吸收两行。正数写高，负数写低，零写平。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 字

[`EquipCompare.Line`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/InventoryWindow/EquipCompare.cs) 把差写成「高」「低」或「平」，后面跟这个差。

[`ItemStatsWinManager.ShowPhysicalCompare`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/ItemStatsWinManager.cs) 先按这件自己的数字刷已有窗口，再把武器的攻击力和物理吸收、护甲的物理吸收换成这一行。

[`InventorySlotUI`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/InventoryWindow/InventorySlotUI.cs) 在第一次点、还没换上时调用它。再点同一件换上之后，这两行回到这件自己的数字。

## 2. 不做

不改 `Preview` 的差。不改确认后的吸收。不显示重量。不改翻滚。不新做文本框。不新写用例。不算高风险：只把已有的差写进已有的两行。
