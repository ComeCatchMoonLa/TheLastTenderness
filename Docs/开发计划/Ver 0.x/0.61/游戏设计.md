# 0.61 游戏设计：光标停在另一件上能看出攻击力和吸收的高低

> **交付目标：光标停在另一件武器或护甲上时，攻击力和物理吸收变高、变低能从字上看出来。确认前人和吸收不变。**

来源：[FR-菜单-04](../../../需求文档/功能需求/菜单.md)。差在 3.1 已经算出来，调用后没有写到界面上。

## 1. 为什么是这一刀

第一次点只留下攻击力和物理吸收的差，这两行仍是这件自己的数字，看不出比身上这件高还是低。

## 2. 做完之后

停在另一件上：攻击力这一行和物理吸收这一行写成差。比身上高是「高」，低是「低」，一样是「平」。

再点同一件才换上。确认前人和吸收不变。换上之后这两行回到这件自己的数字。

不显示重量。不改翻滚。

## 3. 验收

0.x 不新写用例。不进游戏点装备。确认前不换装仍是 3.1 已有的那次断言。
