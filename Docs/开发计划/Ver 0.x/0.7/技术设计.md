# 0.7 技术设计：关掉的副本移出场景

> **从场景移出物体由人在 Unity Hierarchy 里做。先备份场景文件。代码只改快捷栏空图标的报错。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 场景

只动 [`../../../../Assets/Scenes/Game.unity`](../../../../Assets/Scenes/Game.unity)。

先在 Unity 里保存当前场景。再把该文件复制为 `Assets/Scenes/Game_before_0.7.unity`。不要复制旁边的 `.meta`，让 Unity 给备份分配新的 guid。备份不进 Build Settings。

工作区里这份场景可能已经把 Player 设为激活、把 Player SP 和 Player SPP 设为关闭。本版把游戏设计第 2 节列出的关闭副本从 Hierarchy 移出，不只是保持灰色。预制体资源不删。

不改 Player 上的组件和脚本引用。不删 `Assets/Scripts`。不处理 0.10 的近战来源。

## 2. 空图标

改 [`../../../../Assets/Scripts/UI/Player UI/HUD Windows/QuickSlotsUI.cs`](../../../../Assets/Scripts/UI/Player%20UI/HUD%20Windows/QuickSlotsUI.cs)。

`UpdateCurrentWeaponIcon`、`UpdateCurrentSpellIcon`、`UpdateCurrentConsumableIcon` 里，`itemIcon == null` 时直接返回，去掉这三处 `Debug.LogError`。槽位上的 Image 引用仍为空时，原来的 `LogError` 保留，那是 UI 没接上，不是物品数据。

不改物品资产，不新建图标。

## 3. 不做

不把已经关掉的地图、故事 NPC、World 再激活。不改移动旗标。不删 General / Boss 脚本，那是 0.9。
