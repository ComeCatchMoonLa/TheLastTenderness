# 0.7 游戏设计：关掉的副本移出场景

> **交付目标：`Game` 里只留一个玩家身体，就是名为 Player 的物体。已关闭的玩家副本和已关闭的敌人副本不留在场景里。快捷栏图标为空时不再 `LogError`。**
>
> 不改 Player 身上的移动和攻击。不删脚本。雾、火、营火留在场景里。

## 1. 为什么是这一刀

层级里现在开着的内容就是 Player、三只近战和 Map 0。其余是灰色，本版不把它们再引进来。进 Play 时快捷栏还会因为 `itemIcon` 为空打出错误，Error Pause 开着就会把播放按停。

## 2. 留下和移出

> **现在激活的内容就是这 5 个：Player，Humanoid A.I - Melee (0)(1)(2)，Map 0。** 灰色物体本版不重新激活，也不再拖回场景。从场景移出时不删 Project 里的预制体。改场景前先备份 `Game.unity`。

Directional Light、EventSystem、Player Camera 留着，它们是场景底子，不计入这 5 个。

| 物体 | 本版 |
| --- | --- |
| Player | 留下，唯一的玩家身体 |
| Humanoid A.I - Melee (0)(1)(2) | 留下。收成只从一个预制体进场景是 0.10 |
| Map 0 | 留下 |
| Player SP、Player SPP、NPCs - Story、NPCs - Combat | 不在当前 Hierarchy 里就不要加回来。还在且是灰色的，从场景移出 |
| Archer、Boss (Simple A.I)、Enemy (Simple A.I )、已关闭的 Enemy (Humanoid A.I - Melee) | 同上 |
| Test Map - Locomotion、Test Map - Interacte、Test Map - Combat、World、Set Animation Event | 保持关闭，不移出，也不重新打开 |

快捷栏的武器、法术、消耗品图标可以为空。空的时候不报错，槽位保持空。本版不补图标图。

## 3. 验收

- 激活的内容是 Player、三只 Humanoid A.I - Melee、Map 0。灰色物体没有被重新打开。
- 进 Play，控制台不再出现 `weapon.itemIcon == null`、`spell.itemIcon == null`、`consumable.itemIcon == null`。
- 不把走、冲刺再测一遍。WebGL 缺 `node.exe` 仍不进本版。
