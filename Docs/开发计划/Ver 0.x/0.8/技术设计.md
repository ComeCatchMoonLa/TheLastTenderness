# 0.8 技术设计：玩家收成预制体实例

> **人在 Unity 里把场景对象存成预制体。不改脚本。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

预制体路径：`Assets/Perfabs/Player/Player.prefab`。这个目录不在 `.gitignore` 的 `1 Old` 里，预制体可以进 git。

操作：Hierarchy 选中名为 Player 的物体，拖到 `Assets/Perfabs/Player`。Unity 会生成预制体，并把场景里的物体换成它的实例。不要选 `Assets/Perfabs/1 Old/Player.prefab`。

不改 [`../../../../Assets/Scripts`](../../../../Assets/Scripts) 里的类型。不改三只近战和 Map 0。
