# 0.8 游戏设计：玩家收成预制体实例

> **交付目标：场景里名为 Player 的物体，变成 `Assets/Perfabs/Player/Player.prefab` 的实例。身上现有脚本不动。**
>
> 不用 `Assets/Perfabs/1 Old/Player.prefab`。不改移动和攻击。不删脚本。

## 1. 为什么是这一刀

0.7 已经确定激活的玩家就是这个 Player。它还是场景里单独搭的物体。收成预制体之后，以后改玩家只改这一份。

## 2. 怎么做

在 Unity 里把 Hierarchy 的 Player 拖到 `Assets/Perfabs/Player`，让场景里的 Player 变成这个新预制体的实例。

预制体资源留在 Project 里。`1 Old/Player` 不覆盖、不引用。

## 3. 验收

- Hierarchy 里的 Player 是预制体实例（名字是蓝色）。
- Inspector 上仍有原来的玩家脚本，例如 `PlayerManager`。
- 不把走和冲刺再测一遍。
