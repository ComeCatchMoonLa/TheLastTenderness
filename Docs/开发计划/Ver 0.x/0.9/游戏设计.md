# 0.9 游戏设计：战斗结算纠错

> **交付目标：破防、背刺、左手盾、按住 E、重击段号、炸弹溅射这六处按现在的规则算对。** 不把轻重击合成一个类型，不把法术改成能格挡。
>
> 对应纠错 1、2、3、5、6、9。下落、交互锁、护甲吸收、数量不在本版。

## 1. 为什么是这一刀

这六处都在当前战斗里，改的是算错的数和多出来的一次调用。职责还在原来的类型上。收成一套结算是 1.0 的事，放在数字先算对之后。

## 2. 六处各自变成什么样

| 项 | 做完之后 |
| --- | --- |
| 1 破防 | 体力扣完时进入控制器里的 `Guard_Break`，结束后能移动 |
| 2 背刺和处决 | 伤害来自攻击者的右手武器，同一次只扣一次血 |
| 3 左手盾 | 使用的手和稳定率都来自左手那面盾 |
| 5 按住 E、点按 E | 按住 E 只进入一次动作。左手没有武器时，点按 E 不空引用 |
| 6 重击段号 | 重播第一段时 `attackType` 是 `heavy_1`，播第二段才是 `heavy_2` |
| 9 炸弹 | 被炸弹直接碰到的人不再吃第二次溅射。旁边的人仍吃溅射 |

举盾本身仍然不锁移动。玩家双手攻击仍读 `oh_*` 槽。

## 3. 验收

只看这六处。不把走路和冲刺再测一遍。

- 举盾被打到破防：播的是 `Guard_Break`，结束后能走。
- 背刺或处决：血只掉一次。攻击者和受击者右手武器伤害不同时，掉血按攻击者那把。
- 只装备左手盾并按住格挡：`blockingStabilityRating` 等于这面盾的稳定率，不是右手武器的。
- 按住 E：动作只开始一次。左手武器拿掉后点按 E：Play 不因为空引用暂停。
- 重击打出第一段之后，在连击里再按一次、实际仍播第一段：`attackType` 为 `heavy_1`。
- 炸弹直接命中一个人：这个人只有直击那一次火焰伤害。站在旁边、没被弹体碰到的人仍受到溅射。
