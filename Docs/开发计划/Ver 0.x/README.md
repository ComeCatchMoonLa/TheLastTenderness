# Ver 0.x：先让 AI 能独立做完

> **这一大版本不开发玩法。** 前排只放 AI 改文件就能做完、人工只做验收的小版本。要在 Unity 里改场景、或必须先点名路径才能删磁盘的，靠后。
>
> **不在 0.x 里的**：新玩法、改名（含 `Perfabs`）、删掉场景仍在引用的 Vampire Girl 或 Polygon 整包、把三套 AI 合成一个框架、把 `CharacterManager` 的七个 Manager 重写、给历史脚本补测试、卸 Visual Scripting 等其他包。玩法在 1.x。

版本号约定见 [`../README.md`](../README.md)。0.1～0.3 已完成。0.4 由人从旧包补缺失资源，不整包导入。

## 完成定义

十条都满足才离开 0.x：

1. Git 是唯一版本控制（0.1，已完成）。
2. 工程编辑器是 Unity `6000.5.9f1`（0.2）。
3. Build Settings 只进 `Game`，文档写明当前玩家和近战敌人（0.3）。
4. 从 `TheLastTenderness0.9.1.unitypackage` 补回场景还在引用、工程里没有的资源（0.4）。不整包导入。
5. 移动旗标各只有一个写入方（0.5）。
6. 零引用的顶层导入包已移出工程（0.6）。
7. 未参与当前玩法的关闭副本不再留在 `Game` 里，激活的玩家是名为 Player 的物体（0.7）。
8. 因此不再被引用的脚本已删（0.8）。
9. 激活的玩家是仍挂现有脚本的预制体实例（0.9）。
10. 近战敌人只从 `Humanoid A.I - Melee` 进场景（0.10）。
