# 1.0 技术设计：一次命中一次结算

> **在受击者的 `CharacterCombatManager` 上加一处结算。近战、箭、背刺、处决改去调用它。`TakeDamage` 的公式不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。法术和炸弹不进格挡，按 [`../README.md`](../README.md) 里已经写明的推荐做，本版不再另选。

## 1. 现在的两条路

`DamageCollider.DealDamage`：按 `attackType` 乘当前手武器的阶段系数，点积大于 `0.3` 且正在格挡则 `AttemptBlock` 再乘格挡吸收，否则扣 `poiseBreak` 并和剩余韧性比较，然后 `TakeDamage`。箭的 `AmmoDamageCollider` 先调这个基类，所以走同一条。

`GetBackStabbed` / `GetRiposte`：用攻击者右手武器的五段乘 `criticalAttackDM`，直接 `TakeDamage`。不查格挡，不扣韧性。动画名分别是 `"Back Stabbed"` 和 `"Riposted"`。

`SpellDamageCollider`、`BombDamageCollider`、`DamagePlayer` 直接 `TakeDamage`，只传火焰段。炸弹直击和溅射的去重留在 0.9 的写法里。

## 2. 结算方法

放在 `CharacterCombatManager`，由受击者调用。调用方传入：

- 五段伤害
- 一个倍率（近战是已经选好的阶段系数，背刺和处决是 `criticalAttackDM`）
- 是否走格挡和韧性
- 韧性打击（近战用碰撞体上的 `poiseBreak`，背刺和处决传 0）
- 受击动画名
- 格挡扣体力要用的 `guardBreakModifider`（不走格挡时忽略）

方法内部先把五段乘上倍率。走格挡和韧性时，点积和 `0.3` 的判断、`AttemptBlock`、格挡吸收乘区、韧性先减再和 `poiseBreak` 比较，从 `DealDamage` 挪进来，数字不变。然后一次 `TakeDamage`。不走格挡和韧性时，直接 `TakeDamage`，动画名照传入的用。

`AttemptBlock` 仍负责扣体力和播 `Guard_Break` 或格挡受击。破防动画名保持 `Guard_Break`。

## 3. 谁改成调用它

`DealDamage` 仍负责按左右手和 `attackType` 选出阶段系数。选出之后把系数和 `poiseBreak`、`guardBreakModifider` 交给结算，自己不再写格挡乘区和韧性比较。`light_1` / `light_2` / `heavy_1` / `heavy_2` 的四个分支先留着，合成一个类型是 1.1。

`GetBackStabbed` 和 `GetRiposte` 仍检查攻击者右手武器是否存在、仍拉人。扣血改为调用结算，倍率为 `criticalAttackDM`，不走格挡和韧性。

弹反分支、血溅、方向动画的选择留在 `DamageCollider.OnTriggerEnter`。

## 4. 不做

不让法术、炸弹、`DamagePlayer` 调用这处结算。不改 `TakeDamage` 的部位权重。不改 0.9 的炸弹去重、背刺用攻击者武器、左手盾稳定率。不把 `DealDamage` 的阶段系数选择挪到 1.1 的选段类型里。不补单元测试。
