# 1.0 游戏设计：一次命中一次结算

> **交付目标：近战、箭、背刺、处决扣血前的格挡和韧性只写在一处。扣血数字与 0.9 之后相同。**
>
> 法术、炸弹、环境伤害仍直接扣血，不能被盾挡住。不改护甲的 60/30/10。不把轻重击合成一个类型。

## 1. 为什么是这一刀

0.9 已经把背刺用谁的武器、破防动画名、左手盾、炸弹打两次改对了。近战仍在 `DamageCollider.DealDamage` 里自己做阶段系数、格挡和韧性，背刺和处决在 `GetBackStabbed` / `GetRiposte` 里再直接 `TakeDamage`。再加一种命中，这两处都要抄。

## 2. 谁负责

受击者的 `CharacterCombatManager` 负责：乘上调用方给的倍率，决定这次进不进格挡和韧性，然后调用 `TakeDamage`。

`TakeDamage` 仍只做护甲吸收和扣血。选受击方向、播血、弹反仍留在伤害碰撞体。背刺和处决的拉人和播动画仍留在原来的方法里。

法术、炸弹、`DamagePlayer` 这一版不进这处结算。大纲里的推荐是它们只共享护甲和扣血。

## 3. 验收

血量和 0.9 之后一致。不把走路再测一遍。

- 普通近战命中、举盾格挡、破防、背刺或处决、箭，各打一次，掉血和受击动画与改之前相同。
- 举盾时被法术或炸弹打中，盾不减这次伤害，人和现在一样直接受伤。
- `Assets/Scripts` 里，阶段系数之后的格挡乘区和韧性比较只出现在这一处结算里。
