# 1.1 技术设计：攻击选段只有一个类型

> **新增一个不挂资产的类，专门选段。两个 Action 改成调用它。现有武器上的 Action 资产不换类型。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在的两套

`LightAttackAction.PerformAction`：体力为 0 则返回。`canDoCombo` 为真走连击，否则交互中返回，不然播第一段。然后 `PlayWeaponTrialFX`。交互中提前 `return` 时不播拖尾。

`HeavyAttackAction.PerformAction` 的体力、连击和交互判断相同，拖尾写在连击分支和第一段分支里各一次。效果与轻击相同：没播攻击就不播拖尾。

第一段都是：右手且双手用 `th*Attack1`，右手单手用 `oh*Attack1`，左手用 `oh*Attack1` 并 `mirrorAnim: true`。段号写成 `light_1` 或 `heavy_1`。

连击都是：先把 `canDoCombo` 写成 false。`lastAttack` 等于这一侧的第一段名字时播第二段并写 `*_2`，否则重播第一段并写 `*_1`。

动画字段在 `CharacterAnimatorManager`：`ohLightAttack1`、`ohLightAttack2`、`thLightAttack1`、`thLightAttack2`，重击是 `ohHeavyAttack1` 等四字段。

## 2. 选段类型

放在 `Assets/Scripts/Items/0 Item Actions/`，普通类，不是 `ScriptableObject`，没有 `CreateAssetMenu`。

一个方法接收角色、是否连击、单手第一段、单手第二段、双手第一段、双手第二段、第一段的 `AttackType`、第二段的 `AttackType`。

非连击：按上面的左右手规则播第一段，`attackType` 写第一段的枚举。双手第一段只在右手且 `isTwoHandingWeapon` 时使用。

连击：调用方已经把 `canDoCombo` 写成 false。方法里用 `lastAttack` 和当前这一侧的第一段名字比较，决定播第一段还是第二段，并写下对应的 `AttackType`。

`PlayTargetAnimation` 的参数保持 `isInteracting: true`。不在这个类里播拖尾，不查体力。

## 3. 两个 Action

删掉各自的 `Handle*Attack` 和 `Handle*AttackCombo`。`PerformAction` 收成和现在轻击一样的形状：连击或第一段二选一，成功后一次 `PlayWeaponTrialFX`。连击前写 `canDoCombo = false`。

轻击传入四个轻击动画字段和 `light_1`、`light_2`。重击传入四个重击动画字段和 `heavy_1`、`heavy_2`。

`DealDamage` 仍按 `attackType` 选阶段系数。那四个分支留到以后，本版不改 `DamageCollider`。

## 4. 不做

不加第三段。不改 `oh_*` / `th_*` 槽。不换武器资产上的 Action 引用。不改拖尾在攻击状态退出时的 `Stop`。不补单元测试。
