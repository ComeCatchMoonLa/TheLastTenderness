# 1.1 游戏设计：攻击选段只有一个类型

> **交付目标：轻击和重击播哪一段、`attackType` 写成什么，只由一个类型决定。打出来的动画与现在相同。**
>
> 不加第三段连击。不改玩家读 `oh_*`、AI 读 `th_*`。不改 1.0 的结算。

## 1. 为什么是这一刀

`LightAttackAction` 和 `HeavyAttackAction` 各写一遍「右手 / 双手 / 左手、上一击是不是第一段」。0.9 已经让重击段号跟实际动画一致，两份分支还在。再改一次连击规则要改两个类。

## 2. 谁负责

新的选段类型负责播动画、写下 `lastAttack` 和 `attackType`。

`LightAttackAction` 和 `HeavyAttackAction` 仍是武器槽上的资产。它们只保留体力检查、`canDoCombo`、交互中不能起手，以及武器拖尾。传给选段类型的是各自的第一段、第二段动画名，和 `light_1` / `light_2` 或 `heavy_1` / `heavy_2`。

左手仍播单手动画并镜像，不播双手动画。和现在一样。

## 3. 验收

轻击、重击的第一段和第二段，动画名和 `attackType` 与改之前相同。走路不重测。

- 右手单手、右手双手、左手，各打出第一段，再在连击里打出第二段。
- 连击时上一击不是第一段，仍播第一段，`attackType` 是第一段的那个值。
- 正在交互且不能连击时，不播攻击，也不播武器拖尾。
