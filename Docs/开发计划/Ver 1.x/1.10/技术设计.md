# 1.10 技术设计：镜头偏移一次缓动

> **三个模式的目标位置各有一个静态方法。`SmoothDamp` 只留在一处，仍用 `pivotOffsetVelocity` 和 `changeModeFadeTime`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SetCameraPosOffset` 按 `CurrentCameraPose` 调用三个公开方法。每个方法各写一次 `SmoothDamp`。速度和过渡时间已经共用。

瞄准目标是 `(-aimingCameraRightDist, aimingPivotHeight, 0)`。锁定是 `Vector3.up * lockedPivotHeight`。默认是 `Vector3.up * defaultPivotHeight`。

## 2. 一处缓动

在 `PlayerCameraManager` 上放三个静态方法：`AimingCameraOffsetTarget`、`LockedCameraOffsetTarget`、`DefaultCameraOffsetTarget`。参数是现在用的距离和高度，返回上面三个向量。

增加一个私有方法，只在这里调用 `SmoothDamp`，写入 `cameraPivotTransform.localPosition`。三个公开方法和 `SetCameraPosOffset` 都把目标交给它。`CameraPose` 仍是私有枚举，不改跟随、旋转和碰撞里的 `switch`。

## 3. 单元测试

Edit Mode 传入左右距离和两个高度，断言三个目标向量。不调用 `SmoothDamp`，不创建场景相机。

## 4. 不做

不改跟随、旋转、碰撞、锁定扫描。不改三个距离和高度的默认值。不把 `CameraPose` 改成公开。
