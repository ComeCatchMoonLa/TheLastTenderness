# 1.10 游戏设计：镜头偏移一次缓动

> **交付目标：瞄准、锁定、默认三种镜头偏移，共用一次缓动。三个目标位置与现在相同。**
>
> 技术设计和 TODO 进入本版再写。不改跟随、旋转、碰撞和锁定扫描。

## 1. 为什么是这一刀

`SetCameraPosOffset_AimingMode`、`SetCameraPosOffset_LockedMode`、`SetCameraPosOffset_DefaultMode` 各写一次 `SmoothDamp`。0.13 已经让三处共用 `pivotOffsetVelocity` 和 `changeModeFadeTime`。目标位置仍各写一份。

瞄准的目标是 `(-aimingCameraRightDist, aimingPivotHeight, 0)`。锁定是向上 `lockedPivotHeight`。默认是向上 `defaultPivotHeight`。

## 2. 做完之后

三个模式仍各有自己的目标位置。缓动只写一次，仍用现在那一份速度和 `changeModeFadeTime`。当前模式仍由现有的机位判断决定。

## 3. 验收

拉弓、锁定、松开之后，镜头枢轴停的高度和左右偏移与改之前相同。切换时的缓动不断、不跳。跟随和旋转不重测成另一套。

Edit Mode 单元测试传入现在的左右距离和两个高度，断言三个模式的目标位置。不调用 `SmoothDamp`，不改场景里的相机。
