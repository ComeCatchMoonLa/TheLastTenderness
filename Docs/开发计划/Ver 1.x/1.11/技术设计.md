# 1.11 技术设计：查询助手收成一处

> **装满才加倍的球形查询只留一个静态方法。三处仍传入自己的半径、层和数组。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerCameraManager`、`IdleState`、`IdleStateHumanoid` 各有一份私有 `CollectOverlaps`。都是 `OverlapSphereNonAlloc`，个数等于数组长度就加倍再查。

锁定数组从 32 起，半径 `maxLockOnDist`，层遮罩 `~0`。两处待机数组从 16 起，半径 `detectionRadius`，层 `LayerMask.player`。`AmbushState` 仍每次 `OverlapSphere`。

## 2. 一处查询

在 `Assets/Scripts/Func.cs` 增加静态类 `OverlapQuery`，公开方法 `CollectOverlaps(Vector3, float, int, ref Collider[])`。方法体与现在三份相同。

三处删掉私有方法，改为调用 `OverlapQuery.CollectOverlaps`。数组字段、初始长度、半径和层留在原调用点。不把待机状态改成依赖 `PlayerCameraManager`。

## 3. 单元测试

不写。查询命中了谁要物理场景，Edit Mode 断言不了。不为了测试把方法改成 `virtual`。半径、层、初始容量和装满才加倍靠人看。

## 4. 不做

不改伏击状态。不改锁定扇形、视线角和追击切换。不改数组的初始长度。
