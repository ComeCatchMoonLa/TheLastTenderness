# 1.12 技术设计：护甲回背包收成一处

> **交换旧甲和新甲的步骤是 `InventorySlotUI` 上的一个静态方法。三个槽位调用不合并。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`EquipArmor` 在 `noArmor` 时返回。否则按 `armor.armorType` 分三岔。每岔把资产转成 `HeadArmorItem`、`TorsoArmorItem` 或 `HipsArmorItem`，旧件非空则 `AddItem`，写入 `currentHeadArmor`、`currentTorsoArmor` 或 `currentHipsArmor`，`RemoveItem` 新件，再 `GetHeadArmorSlot`、`GetTorsoArmorSlot` 或 `GetHipArmorSlot` 的 `AddItem`。最后 `EquipAllArmorModels`。

## 2. 一次交换

增加公开静态方法 `ReplaceEquippedArmor<T>`，`T` 继承 `ArmorItem`。参数是新件、当前件的 `ref`、装备格、`PlayerInventoryManager`。

旧件非空则 `AddItem`。当前件改成新件。`RemoveItem` 新件。装备格 `AddItem` 新件。

`EquipArmor` 三岔只做类型转换并调用这个方法，槽位方法名不改。之后仍调用 `EquipAllArmorModels`。

## 3. 单元测试

Edit Mode 准备 `items` 和 `armors` 两个空列表，不跑 `Awake`。已穿一件头甲，背包里有一件新头甲。调用 `ReplaceEquippedArmor`。断言旧甲在 `armors` 里，新甲不在，装备格的 `equipment` 是新甲。躯干和下身走同一个方法，不另测。不调用 `EquipAllArmorModels`。

## 4. 不做

不改 `EquipAllArmorModels` 和 `EquipPart`。不删三个空子类。不改 `GetHipArmorSlot` 这个拼写。不改武器那一岔。
