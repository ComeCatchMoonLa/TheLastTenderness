# 1.12 游戏设计：护甲回背包收成一处

> **交付目标：头、躯干、下身穿上时，旧件回背包、新件离开背包、放进装备窗，走同一步。三个槽位名字不改。换模和五段吸收仍走 1.4。**
>
> 技术设计已写。不改武器装备。不删三个护甲子类。

## 1. 为什么是这一刀

`InventorySlotUI.EquipArmor` 对头、躯干、下身各写一遍：旧护甲非空就 `AddItem`，写上当前字段，`RemoveItem` 新护甲，再放进对应装备格。1.4 只收了换模，这三岔还在。

## 2. 做完之后

三岔仍按 `ArmorType` 分开，因为槽位方法是 `GetHeadArmorSlot`、`GetTorsoArmorSlot`、`GetHipArmorSlot`。旧件、新件和放进格子的四步只写一次。然后仍调用 `EquipAllArmorModels`。

## 3. 验收

穿上一件已有旧甲的部位：旧甲回到护甲列表，新甲离开列表，装备格里是新甲。脱掉换模后的模型和吸收与 1.4 相同，本版不重测那三条。

Edit Mode 单元测试只调用这一步交换，传入库存列表和一个带图标的装备格。不跑 `Awake`，不调用 `EquipAllArmorModels`。
