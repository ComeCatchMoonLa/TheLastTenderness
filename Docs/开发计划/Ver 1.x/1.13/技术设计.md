# 1.13 技术设计：写台词和播空动画拆开

> **`SetTalkerStatus` 只改名字和 `talkWithSB`。空动画放到单独的方法，由原来会换说话人的调用点紧接着调用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SetTalkerStatus`：这一句 `isPlayerSaid` 时，NPC 的 `talkWithSB` 为 false 并 `Play`，名字写成「你」，玩家的 `talkWithSB` 为 true。否则玩家的 `talkWithSB` 为 false 并 `Play`，名字写成 `npc.eStats.cName`，NPC 的 `talkWithSB` 为 true。

`UpdateDialogueSBS_Helper`、两段逐字协程在写字前调用它。`HandleTalkEnd` 另外对双方各 `Play` 一次。

## 2. 拆开

`SetTalkerStatus` 删掉两处 `Play`，名字和旗标保持上面的分支。

新增 `PlayTalkerEmptyPose(EnemyManager)`。同一句 `isPlayerSaid` 时只 `npc.animator.Play("NonCombat Whole Body Empty")`，否则只 `player.animator.Play` 这个名字。

在 `UpdateDialogue_Auto_SBS`、`Handle_UpdateDialogue_NonAuto_SBS` 调用 `UpdateDialogueSBS_Helper` 之前调用它。在 `UpdateDialogue_Auto_WFW` 和 `UpdateDialogue_WFW_Helper` 的 `SetTalkerStatus` 之后调用它。`AdvanceDialogue` 在手动逐句开始时同样先调用它，再进 `UpdateDialogueSBS_Helper`。

`UpdateDialogueSBS_Helper` 仍只做 `SetTalkerStatus`、写全文、`RemoveAt(0)`。`HandleTalkEnd` 不改。

## 3. 单元测试

现有 `DialogueAdvanceTests` 改为调用 `UpdateDialogueSBS_Helper`。断言全文、列表少一句、`talkerNameText` 是 NPC 名字。不给 Animator，不使用 `LogAssert`。不测自动协程和跳过。

## 4. 不做

不改 `HandleTalkEnd`。不改 `waitTime`、台词资产和输入禁用。不把方法改成 `virtual`。
