# 1.13 游戏设计：写台词和播空动画拆开

> **交付目标：换说话人时，名字和 `talkWithSB` 与 `Play("NonCombat Whole Body Empty")` 分开。台词、间隔和跳过与现在相同。**
>
> 技术设计已写。不改 `HandleTalkEnd` 里结束时的两下 `Play`。

## 1. 为什么是这一刀

`SetTalkerStatus` 同时改名字、`talkWithSB`，并对另一方 `Play`。逐句写全文也走这里，所以 Edit Mode 测一句台词会碰到没有 Controller 的 Animator。

## 2. 做完之后

写一句时仍先改名字和 `talkWithSB`，再写文本。`Play` 由推进台词的那几处另外调用，动画名仍是 `NonCombat Whole Body Empty`。玩家说时仍只播 NPC 的空动画，NPC 说时仍只播玩家的。对话结束时的两下 `Play` 留在 `HandleTalkEnd`。

## 3. 验收

四种开关各说完一段，逐字或整句、间隔、按住跳过与改之前相同。换说话人时仍能看到空动画后抽出对话动作。

Edit Mode 单元测试直接调用逐句辅助方法：NPC 说的第一句全文写上，列表少一句，说话人名字是 NPC 的名字。不调用 `Animator.Play`，不再期待 `Animator does not have an AnimatorController`。
