# 1.14 技术设计：攻击扣体力收成一处

> **消耗数字是 `CharacterAnimatorManager` 上的静态方法。`DrainStamina` 只负责选武器并在轻重击时扣。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`isUsingRightHand` 时用 `rightWeapon`，否则 `isUsingLeftHand` 时用 `leftWeapon`。`light_1`、`light_2` 扣 `baseStaminaCost * laStaminaCostM`。`heavy_1`、`heavy_2` 扣 `baseStaminaCost * haStaminaCostM`。其它 `AttackType` 不调用 `DeductStamina`。

## 2. 先选武器

增加公开静态方法 `AttackStaminaCost(WeaponItem, AttackType)`。轻击两段返回基础乘轻击系数，重击两段返回基础乘重击系数，`critical` 返回 0。`weapon` 为 null 时返回 0。

`DrainStamina` 先按右手、再按左手选出武器。没有武器就返回。攻击类型是四段轻重击之一才 `DeductStamina(AttackStaminaCost(...))`。

## 3. 单元测试

Edit Mode 创建一把 `WeaponItem`，设好基础和两个系数。断言 `light_1`、`light_2`、`heavy_1`、`heavy_2` 和 `critical`。不挂角色，不调用 `DeductStamina`。

## 4. 不做

不改武器资产上的默认系数。不改 `DeductStamina`。不把 `DrainStamina` 改成公开或 `virtual`。
