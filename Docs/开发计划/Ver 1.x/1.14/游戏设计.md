# 1.14 游戏设计：攻击扣体力收成一处

> **交付目标：轻击和重击的体力消耗先选定正在用的那把武器，再乘对应系数。左右手和轻重的结果与现在相同。**
>
> 技术设计已写。不改 `baseStaminaCost`、`laStaminaCostM`、`haStaminaCostM` 的默认值。

## 1. 为什么是这一刀

`DrainStamina` 对右手和左手各写一遍轻击、重击。公式相同：`baseStaminaCost` 乘 `laStaminaCostM` 或 `haStaminaCostM`。`critical` 不扣。

## 2. 做完之后

右手在用仍读右手武器，否则左手在用读左手武器，两手都不用则不扣。轻击两段乘轻击系数，重击两段乘重击系数。`critical` 仍不扣。

## 3. 验收

左右手的轻击、重击扣掉的体力与改之前相同。空挥或没有攻击类型时不新扣一笔。

Edit Mode 单元测试对一把武器断言四段攻击的消耗，以及 `critical` 为 0。不调用 `DrainStamina`，不创建 Animator。
