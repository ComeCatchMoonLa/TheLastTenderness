# 1.15 技术设计：灵魂数字跟 AddSouls 走

> **`AddSouls` 改完 `soulCount` 后写 HUD。击杀不再另写一次。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerStatsManager.AddSouls` 只做 `soulCount += souls`。`EnemyStatsManager.AwardSoulsOnDeath` 调用它之后再 `SetSoulCountText`。

`SoulCountUI.SetSoulCountText` 把数字写成子物体上的 `TextMeshProUGUI`。该文本引用在 `Awake` 里取。

## 2. 一处写入

`AddSouls` 改完 `soulCount` 后，若 `player.ui.hud.soulCountUI` 已接上，调用 `SetSoulCountText(soulCount)`。`AwardSoulsOnDeath` 删掉后面那次 `SetSoulCountText`。增加的数量不改。

`player` 仍由 `PlayerStatsManager.Awake` 从同一物体上的 `PlayerManager` 取得。本版不改这个查找。

## 3. 单元测试

`Assets/Tests/EditMode/AddSoulsHudTests.cs`。

在同一物体上放 `PlayerStatsManager` 和 `PlayerManager`。HUD 和 `SoulCountUI` 由测试赋给公开字段。`SoulCountUI` 的文本引用用反射写入，不依赖 `Awake`。调用 `AddSouls(5)` 后，`soulCount` 为 5，文本为 `5`。不调用 `AwardSoulsOnDeath`，不创建 Animator。

## 4. 不做

不改击杀奖励的配置。不在 `AddSouls` 里查找玩家。不改扣灵魂，本版没有扣减方法。
