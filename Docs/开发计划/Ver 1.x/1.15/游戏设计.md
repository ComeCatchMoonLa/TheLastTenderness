# 1.15 游戏设计：灵魂数字跟 AddSouls 走

> **交付目标：`AddSouls` 改灵魂数时，HUD 数字同时变成这个数。击杀后看到的数字与现在相同。**
>
> 技术设计和 TODO 进入本版前再写。

## 1. 为什么是这一刀

`AddSouls` 只加 `soulCount`。击杀在 `AwardSoulsOnDeath` 里再调用一次 `SetSoulCountText`。别的途径若只调用 `AddSouls`，数字不会变。需求 FR-界面-05 要求改灵魂的同一次结果里，HUD 等于 `soulCount`。

## 2. 做完之后

`AddSouls` 改完数字后写 HUD。击杀不再另写一次。击杀增加的数量不变。

## 3. 验收

击杀一名近战后，HUD 灵魂数字等于身上的 `soulCount`，与改之前同一次击杀的增加量相同。

Edit Mode 单元测试调用 `AddSouls` 后断言 `soulCount` 与 `SoulCountUI` 文本一致。不通过 `AwardSoulsOnDeath`，不创建 Animator。
