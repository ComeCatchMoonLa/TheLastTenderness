# 1.16 技术设计：护甲吸收权重收成一处

> **头 0.6、躯干 0.3、髋 0.1 只留在 `CharacterStatsManager` 的一处。五段伤害仍各乘一次。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`TakeDamage` 开头有局部 `Func<float, float, float, float> TotalDamageRate`。每次调用都新建这个委托。物理、火、魔、雷、暗各乘一次：

`(1 - head) * 0.6 + (1 - torso) * 0.3 + (1 - hips) * 0.1`

字段是 `headArmorPDA` 到 `hipsArmorDDA`。`PlayerArmorManager.EquipAllArmorModels` 负责写入。`PlayerStatsManager.TakeDamage` 和 `EnemyStatsManager.TakeDamage` 都先调用 `base.TakeDamage`。

## 2. 一处计算

把公式收成 `CharacterStatsManager` 上的一个私有静态方法。`TakeDamage` 里五段仍各调用它一次，不再在方法里写 `Func`。乘数仍是 0.6、0.3、0.1。

玩家和敌人的覆盖方法不改。吸收字段的名字和写入点不改。

## 3. 单元测试

`Assets/Tests/EditMode/ArmorAbsorptionWeightTests.cs`。

同一物体上放 `CharacterStatsManager` 和 `CharacterManager`。`cStats` 指回这份属性。`character` 是私有字段，用反射写入，不依赖 `Awake`。`currentHP` 先写成 100。调用 `TakeDamage(null, pd, 0, 0, 0, 0, false)`。

- 头 0.5、躯干 0、髋 0，`pd` 为 100：`currentHP` 为 30。
- 三段吸收都是 0，`pd` 为 40：`currentHP` 为 60。
- 三段吸收都是 1，`pd` 为 40：`currentHP` 仍为 100。

不调用 `EquipAllArmorModels`，不创建 Animator，不调用 `PlayRandomDamageSoundsFX`。

## 4. 不做

不改 0.6、0.3、0.1。不把五段合成再乘一次。不改护甲穿上时怎么把吸收抄进字段。不改格挡吸收。
