# 1.16 游戏设计：护甲吸收权重收成一处

> **交付目标：受伤时头 0.6、躯干 0.3、髋 0.1 只算一次。物理、火、魔、雷、暗五段仍各乘这一次的结果。扣血数字不变。**

## 1. 为什么是这一刀

`CharacterStatsManager.TakeDamage` 每次受伤都在方法里写一个局部 `Func`，五段各调用一次。权重 0.6、0.3、0.1 只出现在这个函数里。玩家和敌人的 `TakeDamage` 都调用基类，不另写一套权重。

## 2. 做完之后

三部位权重在一处算完。五段伤害仍各乘一次。`headArmorPDA` 等字段和预制体上的护甲引用不改。受伤动画和受伤音仍由现在的分支决定：`playHurtSound` 为真才播音，`damageAnimation` 不为空才播动画。

## 3. 验收

Edit Mode 单元测试直接调用 `CharacterStatsManager.TakeDamage`。`playHurtSound` 为假，`damageAnimation` 为空，不创建 Animator，不调用 `PlayRandomDamageSoundsFX`。

头吸收 0.5、躯干 0、髋 0，物理伤害 100，其余四段为 0。生命下降 70。吸收全为 0 时，生命下降等于这段伤害。吸收全为 1 时，生命不下降。
