# 1.17 技术设计：受伤音和挥刀音共用选段

> **避开上一首的选择收成 `PickClipAvoidingPrevious`。播放和音量仍留在两个播放方法里。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CharacterSoundFXManager.PlayRandomDamageSoundsFX` 在 `takingDamageSounds` 长度大于 1 时 `new List<AudioClip>`，去掉 `lastDamageSoundPlayed`，再 `Random.Range`。长度为 1 时直接播第 0 首，音量用默认值。多于一首时音量是 0.4。

`PlayRandomWeaponWhoosh` 先看 `isUsingRightHand`、`isUsingLeftHand`。两手都空则返回。否则对当前武器的 `weaponWhooshesSound` 做同样的避开上一首。音量始终用默认值。

## 2. 一处选段

在 `CharacterSoundFXManager` 上增加公开静态方法：

`PickClipAvoidingPrevious(AudioClip[] clips, AudioClip previous, int indexAmongRemaining)`

- `clips` 为空或长度为 0：返回 `null`。
- 长度为 1：返回 `clips[0]`。
- 多于一首：在不等于 `previous` 的那些里，按下标取一首。下标超出范围时夹到合法区间。若每一首都等于 `previous`，返回 `clips[0]`。

两个播放方法在长度大于 1 时，用 `Random.Range(0, 剩余首数)` 得到下标，再调用这个方法，并记下这次选中的片段。长度为 1 时仍直接播第 0 首，不改上一首记录。音量不改。

## 3. 单元测试

`Assets/Tests/EditMode/ClipSelectionTests.cs`。

不挂 `AudioSource`，不调用播放方法。

- 三首为 a、b、c，上一首是 b，下标 0 得到 a，下标 1 得到 c。
- 只有 a 一首，上一首是 a，得到 a。
- 传入空数组，得到 `null`。

## 4. 不做

不改动画事件名。不导入新音效。不改两手都空时的直接返回。不改 0.4 的受伤音量。
