# 1.17 游戏设计：受伤音和挥刀音共用选段

> **交付目标：受伤音和挥刀音避开上一首的选法只留一处。选中的片段规则不变。两手都空时挥刀音仍不播放。**

## 1. 为什么是这一刀

`PlayRandomDamageSoundsFX` 和 `PlayRandomWeaponWhoosh` 各写一遍：多于一首时跳过上一首，再随机一首。多于一首时还会新建一份列表。

## 2. 做完之后

选段走同一个方法。只有一首时仍返回这一首。多于一首时不返回上一首。播放和音量留在原来的调用点。两手都没在用时，挥刀音直接返回，不选段。

## 3. 验收

Edit Mode 单元测试只调用选段方法，不创建 `AudioSource`，不调用 `PlayOneShot`。

传入三首和上一首，再传入剩余里的下标，断言结果不是上一首。只有一首时，无论上一首是什么，都返回这一首。没有片段时返回空。
