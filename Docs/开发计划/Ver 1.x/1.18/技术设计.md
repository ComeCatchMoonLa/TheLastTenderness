# 1.18 技术设计：消耗品剩余次数可以读

> **`ConsumableRemaining` 对照 `AmmoRemaining`。只读字典，不新开扣次。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerInventoryManager.consumableLeft` 在 `Awake` 里创建。`RememberConsumable` 在字典还没有这件物品时写入 `maxItemAmount`。`TrySpendConsumable` 先记住再减一。`AmmoRemaining` 对弹药做同样的记住再返回。

## 2. 读取

在 `AmmoRemaining` 旁边增加：

`public int ConsumableRemaining(ConsumableItem item)`

`item` 为空返回 0。否则 `RememberConsumable(item)`，再返回 `consumableLeft[item]`。

不改 `TrySpendConsumable`。不改快捷栏。

## 3. 单元测试

`Assets/Tests/EditMode/ConsumableRemainingTests.cs`。

同一物体上放 `PlayerInventoryManager`。`consumableLeft` 若还没建，用反射写成空字典，不依赖 `Awake`。

- `ConsumableRemaining(null)` 为 0。
- `FlaskItem.maxItemAmount` 为 1 时，第一次读取为 1。
- `TrySpendConsumable` 成功后，再读为 0。

## 4. 不做

不改 HUD。不改炸弹次数。不把次数写回资产上的 `currentItemAmount`。
