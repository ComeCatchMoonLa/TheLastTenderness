# 1.18 游戏设计：消耗品剩余次数可以读

> **交付目标：能读到这名玩家某一件消耗品还剩几次。不增加扣次写入方，不改快捷栏文字。**

## 1. 为什么是这一刀

次数已经在 `consumableLeft` 里。弹药有 `AmmoRemaining`。消耗品只能靠 `TrySpendConsumable` 成功或失败来猜还剩几次。

## 2. 做完之后

调用方传入一件消耗品，得到剩余次数。空引用得到 0。第一次见到这件物品时，仍按它的 `maxItemAmount` 记入字典，和现在记住次数的规则相同。`TrySpendConsumable` 的扣次不改。

## 3. 验收

Edit Mode 单元测试直接读返回值，不进游戏。

空引用返回 0。一件 `maxItemAmount` 为 1 的消耗品，读到 1。再成功扣一次后，读到 0。
