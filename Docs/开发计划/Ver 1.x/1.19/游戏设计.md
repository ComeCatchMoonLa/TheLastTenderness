# 1.19 游戏设计：入伤结果留在可读字段上

> **交付目标：同一次入伤结算结束后，能读到这次有没有挡住、有没有破韧、扣到生命上的合计量。结算顺序不变。**

## 1. 为什么是这一刀

`ResolveIncomingHit` 把挡住、破韧和减伤后的五段留在局部变量里。结算结束之后，外面读不到这次的结果。

## 2. 做完之后

同一次调用结束时，三个结果留在 `CharacterCombatManager` 上。生命、体力、是否破防的先后不改。不给 `isBlocking` 增加写入方。不播放新的格挡或受击动画。

## 3. 验收

Edit Mode 调用 `ResolveIncomingHit` 后读字段，不创建 Animator。

不处理格挡和霸体时：没有挡住，没有破韧，合计量等于乘完倍率后的五段之和。处理霸体、当前韧性扣完这次仍然不大于这次的霸体伤害时：没有挡住，破韧为真，合计量仍是五段之和。
