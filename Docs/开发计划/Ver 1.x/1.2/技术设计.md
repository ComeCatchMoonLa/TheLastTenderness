# 1.2 技术设计：瞄准只有一个旗标

> **玩家侧删掉对 `isAiming` 的读取。相机三处分支改读同一个模式结果。不新建模式类。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在谁在写

`PlayerManager.aimingMode` 由 `AimAction` 写入。`PlayerCombatManager` 在按住 Q 松开时写成 false。`PlayerManager.UpdateBoolsValue` 把它推进 Animator 的 `aimingMode`。

`CharacterCombatManager.isAiming` 由 `HandleAimingState` 进入时写成 true、离开时写成 false。`HandleRollState` 和 `HandleJumpState` 进入时写成 false。

读取 `isAiming` 的玩家路径：`ShootArrowAction.PerformActionForPlayer`、`PlayerEffectsManager.Update`、`InputManager.HandleRollInput` 末尾、`PlayerManager.ResetCollider`、`HUDWindowsManager` 的准星（还要 `aimingMode`）。敌人射箭读 `eCombat.isAiming`。

相机：`FollowPlayer` 先看 `aimingMode`，再看 `lockOnFlag`。`HandleCameraRotation` 的瞄准还要 `!isInteracting`。`SetCameraPosOffset` 的锁定看 `curLockOnTarget != null`。`HandleCameraCollisions` 在瞄准时不做 `SphereCast`。

## 2. 旗标

`HandleAimingState` 对玩家不再写 `isAiming`。进入时若半径还不是 0.4，记下当前 `radius`，再写成 0.4。离开时改回记下的值。对敌人仍写 `isAiming`，供 `PerformActionForAI` 使用。

`HandleRollState`、`HandleJumpState` 对玩家改为 `aimingMode = false`，不再写 `isAiming`。敌人这两处若写到玩家字段，跳过。

`ShootArrowAction` 的玩家判断、`PlayerEffectsManager`、`InputManager` 冲刺清除、`ResetCollider`、准星，改为只读 `player.aimingMode`。`ResetCollider` 不再用 `isAiming` 挡住恢复；瞄准半径由 `HandleAimingState` 负责。

不删 `isAiming` 字段，敌人还在用。

## 3. 相机

在 `PlayerCameraManager` 里用私有枚举表示瞄准、锁定、默认。一个方法返回它：`aimingMode` 为真就是瞄准，否则 `lockOnFlag` 为真就是锁定，否则默认。

`FollowPlayer`、`HandleCameraRotation`、`SetCameraPosOffset`、`HandleCameraCollisions` 都按这个结果分支。瞄准时旋转不再额外要求 `!isInteracting`，与跟随一致。锁定偏移不再看 `curLockOnTarget != null`。

不把三个 `Handle*CameraRotation` 合成一个类。

## 4. 不做

不改锁定扫描和 `Unlock`。不改瞄准的过肩距离。不改 1.1 的选段。不补单元测试。
