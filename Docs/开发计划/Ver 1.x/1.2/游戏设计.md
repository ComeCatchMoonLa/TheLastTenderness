# 1.2 游戏设计：瞄准只有一个旗标

> **交付目标：玩家瞄准只看 `aimingMode`。相机的跟随、旋转、偏移用同一种模式结果。**
>
> 不另做相机模式类。锁定时的相机行为与现在相同。不改 1.1 的选段。

## 1. 为什么是这一刀

玩家身上有 `aimingMode`，战斗组件上又有 `isAiming`。准星要两个都为真。翻滚和跳跃只清 `isAiming`，相机仍按 `aimingMode` 走。跟随、旋转、偏移对「瞄准 / 锁定 / 默认」的判断也不一样。

## 2. 谁负责

`AimAction` 仍是唯一把 `player.aimingMode` 写成 true 的地方。没有箭、正在交互、松开格挡键时写成 false。翻滚和跳跃进入时也写成 false，代替原来清 `isAiming`。

瞄准动画进入时把胶囊半径改成 0.4，并记下进入前的半径。离开时改回记下的值。这一版不再写 `isAiming`。

相机用一个结果表示瞄准、锁定、默认。跟随、旋转、偏移、推镜都读它。瞄准优先于锁定。锁定看 `lockOnFlag`。

敌人没有 `PlayerManager.aimingMode`。敌人射箭仍读 `isAiming`，瞄准动画进入时只给敌人写这个字段。

## 3. 验收

走路不重测。

- 拉弓瞄准时，相机、角色朝向、准星一致。
- 取消瞄准或翻滚之后，胶囊半径回到瞄准前，准星关掉，相机不再停在瞄准距离。
- 锁定时相机仍贴在玩家位置、只水平看向目标。没有锁定目标时不走锁定偏移。
