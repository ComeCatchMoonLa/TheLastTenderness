# 1.20 技术设计：敌人当前状态可以读

> **`SwitchToNextState` 仍是唯一写入点。外面通过 `CurrentState` 读到它。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`currentState` 标了 `[SerializeField]`，没有公开读取。`HandleStateMachine` 在 `Tick` 返回非空时调用私有的 `SwitchToNextState`，把字段写成这个返回值。

## 2. 读取

`SwitchToNextState` 改成公开，方法体仍只赋值 `currentState`。增加 `public State CurrentState`，只返回这个字段。

`HandleStateMachine` 继续调用 `SwitchToNextState`。不改 `Tick`，不改三套具体状态。

## 3. 单元测试

`Assets/Tests/EditMode/EnemyCurrentStateTests.cs`。

测试程序集里放一个空的 `State` 子类，只用来占一个对象。`EnemyManager.SwitchToNextState` 传入它，`CurrentState` 与它是同一个引用。不调用 `Update`，不创建 Animator。

## 4. 不做

不合并 Humanoid、General、Boss。不改待机、追击、攻击怎么选下一状态。
