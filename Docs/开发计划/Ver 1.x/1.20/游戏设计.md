# 1.20 游戏设计：敌人当前状态可以读

> **交付目标：敌人换完状态后，外面能读到当前是哪一个 `State`。发现、追击、出手的切换不变。**

## 1. 为什么是这一刀

`EnemyManager` 用 `Tick` 的返回值换状态，但 `currentState` 是私有字段。外面只能在直接调用 `Tick` 时看到返回值，看不到换完之后留在身上的那一个。

## 2. 做完之后

换状态的入口仍是原来那一处。换完之后可以读到当前状态。不合并三套 AI，不改发现、追击、出手。

## 3. 验收

Edit Mode 直接调用换状态的入口，断言读到的类型与传入的下一状态是同一个对象。不进入游戏，不等一帧 `Update`。
