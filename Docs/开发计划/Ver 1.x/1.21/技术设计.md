# 1.21 技术设计：左右手段位系数收成一处

> **四档系数只在 `DamageCollider.PhaseDamageMultiplier` 里读。`DealDamage` 左右手都调用它。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DealDamage` 在 `isUsingRightHand` 和 `isUsingLeftHand` 里各写四段 `if`。两手都为假时 `multiplier` 停在 1。`critical` 走不到这四段，也停在 1。然后调用 `ResolveIncomingHit`。

## 2. 一处

`DamageCollider` 增加公开静态方法 `PhaseDamageMultiplier(bool usingRightHand, bool usingLeftHand, WeaponItem rightWeapon, WeaponItem leftWeapon, AttackType attackType)`。

两手都为假时返回 1，不读武器。否则用正在用的那只手的武器：右手优先，与现在的 `if / else if` 相同。四档按攻击类型返回对应字段。其余类型，包括 `critical`，返回 1。

`DealDamage` 把现在的两段分支换成这一次调用，后面的 `ResolveIncomingHit` 参数不改。

## 3. 单元测试

`Assets/Tests/EditMode/PhaseDamageMultiplierTests.cs`。

一件 `WeaponItem`，四档写成彼此不同的数。右手、左手分别调用，四档都等于这件武器上的字段。两手都为假时返回 1。`critical` 且右手在用时返回 1。不创建 `DamageCollider`，不创建 Animator。

## 4. 不做

不改 `criticalAttackDM`。不改武器资产上的系数。不改 `ResolveIncomingHit` 里的吸收和破韧。
