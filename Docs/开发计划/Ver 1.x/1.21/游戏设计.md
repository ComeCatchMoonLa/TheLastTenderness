# 1.21 游戏设计：左右手段位系数收成一处

> **交付目标：近战轻重击四档系数只算一次，左右手共用。打中后的伤害数字不变。**

## 1. 为什么是这一刀

`DealDamage` 在右手和左手各写一遍四档系数。同一把武器、同一段攻击，两手读到的倍率应当相同。

## 2. 做完之后

`light_1`、`light_2`、`heavy_1`、`heavy_2` 分别读 `laFirstPhaseDM`、`laSecondPhaseDM`、`haFirstPhaseDM`、`haSecondPhasDM`。两手都没在用时倍率仍是 1。`critical` 不进这四档，倍率仍是 1。结算仍进 `ResolveIncomingHit`。字段名和预制体上的系数不改。

## 3. 验收

Edit Mode：同一把武器，右手和左手的四档系数相同。两手都不用时是 1。`critical` 仍是 1。不创建碰撞体，不播挥刀动画。
