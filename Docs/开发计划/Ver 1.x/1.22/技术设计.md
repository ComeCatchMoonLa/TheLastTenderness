# 1.22 技术设计：正面点积收成一次

> **正面只在 `CharacterCombatManager.ComesFromFront` 里算。碰撞体和入伤结算都调用它。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HitComesFromFront` 用攻击者位置减去被打的人，再点被打的人的 `forward`。距离平方不大于 0.0001 时返回假。否则点积大于 0.3 为真。

`ResolveIncomingHit` 在 `isBlocking` 且攻击者不为空时写同一段。点积不大于 0.3，或距离过近，则这一下没有挡住。

## 2. 一处

`CharacterCombatManager` 增加公开静态方法 `ComesFromFront(Vector3 attackerPosition, Vector3 defenderPosition, Vector3 defenderForward)`。距离平方不大于 0.0001 时返回假。否则返回点积是否大于 0.3。

`HitComesFromFront` 改为调用它，传入碰撞体所属角色的位置、被打的人的位置和 `forward`。

`ResolveIncomingHit` 里那一段点积改为调用它。`isBlocking` 和攻击者为空时仍不调用。挡住之后的吸收、破韧、`TakeDamage` 不改。

## 3. 单元测试

`Assets/Tests/EditMode/ComesFromFrontTests.cs`。

被打的人在原点，`forward` 为 `(0, 0, 1)`。攻击者在正前方为真，在正后方为假，与被打的人重合为假。不创建 `DamageCollider`，不设置 `isBlocking`。

## 4. 不做

不改 `CriticalAttackAction` 的 ±0.8。不改举盾旗标的写入点。
