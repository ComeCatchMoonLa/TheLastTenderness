# 1.22 游戏设计：正面点积收成一次

> **交付目标：正面是否成立只留一处计算。正面挡住、侧面不挡的结果不变。**

## 1. 为什么是这一刀

`DamageCollider.HitComesFromFront` 和 `ResolveIncomingHit` 各写一次「攻击者相对被打的人，点积大于 0.3」。两处用的是同一段向量。

## 2. 做完之后

两处都调用这一处。阈值仍是 0.3。重合位置仍不是正面。背刺的 ±0.8 留在 `CriticalAttackAction`。不改 `isBlocking` 的写入点，不播格挡动画。

## 3. 验收

Edit Mode：点积大于 0.3 为正面，否则不是。重合位置不是正面。不创建碰撞体，不举盾。
