# 1.23 技术设计：举盾吸收一次拷贝

> **抄和清只在两处静态方法里写字段。左右手都调用它们。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SetBlockingAbsorptionFromBlockingWeapon` 在右手、左手各把 `physicalDA`、`fireDA`、`magicDA`、`lightningDA`、`darkDA`、`blockingStabilityRating` 抄进 `blockingPDA` 到 `blockingDDA` 和 `blockingStabilityRating`。

`ResetBlockingAbsorption` 在两手各把这六个字段写成 0。两手都为假时两个方法都不写。

## 2. 一处

`CharacterCombatManager` 增加公开静态方法 `CopyBlockingAbsorption(CharacterStatsManager stats, WeaponItem weapon)` 和 `ClearBlockingAbsorption(CharacterStatsManager stats)`。字段对应与现在相同。

`SetBlockingAbsorptionFromBlockingWeapon` 仍先看右手、再看左手，选中的那只手调用 `CopyBlockingAbsorption`。`ResetBlockingAbsorption` 同样选手当下调用 `ClearBlockingAbsorption`。不改 `isBlocking`。

## 3. 单元测试

`Assets/Tests/EditMode/BlockingAbsorptionCopyTests.cs`。

一件 `WeaponItem` 的五路吸收和稳定率写成彼此不同的数。`CopyBlockingAbsorption` 之后，角色上的六个字段与武器相同。`ClearBlockingAbsorption` 之后都是 0。不设置 `isBlocking`，不创建 Animator。

## 4. 不做

不改 `AttemptBlock` 里的精力公式。不改放下盾时谁把 `isBlocking` 写成假。
