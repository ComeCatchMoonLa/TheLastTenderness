# 1.23 游戏设计：举盾吸收一次拷贝

> **交付目标：举盾时左右手共用一次拷贝，放下时的清零也走这一处。挡住后的减伤不变。**

## 1. 为什么是这一刀

`SetBlockingAbsorptionFromBlockingWeapon` 和 `ResetBlockingAbsorption` 在右手和左手各写一遍五路吸收和稳定率。抄哪些字段已经定了。

## 2. 做完之后

举起时，正在用的那只手把武器上的五路吸收和 `blockingStabilityRating` 抄进角色。放下时这六个数写成 0。两手都没在用时仍不抄、也不清。不给 `isBlocking` 加写入方。不播举盾动画。

## 3. 验收

Edit Mode：给定一把武器，抄完后五路吸收和稳定率与武器上相同。清零后都是 0。不举盾，不改 `isBlocking`。
