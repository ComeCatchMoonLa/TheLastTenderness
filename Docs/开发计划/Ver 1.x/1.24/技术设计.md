# 1.24 技术设计：三项上限乘十收成一处

> **乘数只在 `CharacterStatsManager.LevelTimesTen`。三个写上限的方法都调用它。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Awake` 用三个方法把 `maxHP`、`maxStamina`、`maxMP` 写成对应等级乘 10，并让当前值等于上限。`MemorySlotCount` 另按门槛返回格数，不读这三处。

## 2. 一处

`CharacterStatsManager` 增加公开静态方法 `LevelTimesTen(int level)`，返回 `level * 10`。

三个方法改为把上限写成 `LevelTimesTen` 的结果。方法名和调用方不改。`MemorySlotCount` 不改。

## 3. 单元测试

`Assets/Tests/EditMode/LevelTimesTenTests.cs`。

`LevelTimesTen(10)` 为 100，`LevelTimesTen(0)` 为 0。同一物体上的 `CharacterStatsManager` 把三项等级设成 10，反射调用三个写上限的方法，三项上限都是 100；设成 0 后再调用，都是 0。不改场景和预制体。

## 4. 不做

不改记忆栏门槛。不改 HUD。不改等级字段的序列化初值。
