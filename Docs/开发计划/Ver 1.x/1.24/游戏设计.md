# 1.24 游戏设计：三项上限乘十收成一处

> **交付目标：生命、精力、专注的上限都用同一处「等级乘 10」。玩家能看见的上限不变。**

## 1. 为什么是这一刀

`SetMaxHealthFromHealthLevel`、`SetMaxStaminaFromStaminaLevel`、`SetMaxFocusPointsFromFocusLevel` 各写一遍等级乘 10。乘数已经是 10。

## 2. 做完之后

三处都调用这一处。等级 10 得到上限 100，等级 0 得到 0。不改预制体上的等级初值。不改 `MemorySlotCount`。不另定软上限曲线。

## 3. 验收

Edit Mode：等级 10 时三项上限都是 100，等级 0 时都是 0。`MemorySlotCount` 仍按原门槛返回。不写新的 HUD。
