# 1.25 游戏设计：注释改成和写入点一致

> **交付目标：这几处注释改成现在的写入点在说的事。标识符和运行结果不变。**

## 1. 为什么是这一刀

`rollFlag` 的注释写成是否在翻滚。`horizontal` 和 `vertical` 的水平、垂直写反。`Ammo` 的提示写成飞行中的弹药，赋值放的是拉弓时手上的模型。

## 2. 做完之后

`rollFlag` 写成左 Shift 按下不足 0.5 秒后松开、且有移动时的一次性标记。`horizontal` 是水平，`vertical` 是垂直。`Ammo` 的提示写成拉弓时手上的 `loadedItemModel`，不是飞出去的 `liveItemModel`。字段名不改，包括已经写进场景和预制体的名字。

## 3. 验收

对照 `InputManager.HandleRollInput`、移动输入，以及 `CharacterAnimatorManager.SucessfullyGetArrow`。没有可断言的行为，不写单元测试。
