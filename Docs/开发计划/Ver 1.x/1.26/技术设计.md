# 1.26 技术设计：敌人死亡时不再查找玩家

> **玩家引用在 `EnemyStatsManager.Awake` 里取一次。死亡回调只读这个字段。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Awake` 缓存 `WorldManager`。`HandleEnemyDeathEvent` 再 `FindAnyObjectByType<PlayerManager>`。空则打日志并返回。`lockOnFlag` 为真时 `Unlock`，然后 `AwardSoulsOnDeath`。

## 2. 缓存

增加字段，在 `Awake` 里用同一次 `FindAnyObjectByType<PlayerManager>` 赋值。`HandleEnemyDeathEvent` 改读这个字段，不再查找。后面的解锁、加魂、`Destroy` 不改。

## 3. 单元测试

`Assets/Tests/EditMode/EnemyDeathPlayerCacheTests.cs`。

一名激活的玩家，一名未激活的玩家。未激活的 `lockOnFlag` 为假。敌人的缓存字段指向未激活的那一名。调用 `HandleEnemyDeathEvent` 后，只有这名玩家的 `soulCount` 增加 `soulsAwardedDeath`。`lockOnFlag` 仍为假。不调用 `TakeDamage`，不创建 Animator。

未激活的对象不会被 `FindAnyObjectByType` 找到。魂加在这名玩家身上，说明死亡用的是缓存。

## 4. 不做

不改 `isDead` 的写入。不改灵魂数额。不改 `WorldManager` 的查找。
