# 1.26 游戏设计：敌人死亡时不再查找玩家

> **交付目标：死亡发魂和解锁沿用开局拿到的玩家引用。击杀加魂、解除锁定与现在相同。**

## 1. 为什么是这一刀

`HandleEnemyDeathEvent` 当场再 `FindAnyObjectByType` 找一次玩家。`WorldManager` 已经在 `Awake` 里留着。玩家也可以在开局留着。

## 2. 做完之后

开局缓存这名玩家。死亡发魂和解锁用这份引用。找不到时仍打日志并返回。不改 `isDead` 的写入点，不改 `soulsAwardedDeath`。不解锁定的镜头表现。

## 3. 验收

Edit Mode：场上有两名玩家，缓存指向其中未激活的那一名。死亡回调只给这名玩家加魂，数额仍是 `soulsAwardedDeath`。`lockOnFlag` 为假时仍是假。不调用 `TakeDamage`。
