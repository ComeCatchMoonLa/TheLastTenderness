# 1.27 游戏设计：待结算处决伤害不再留第二段入口

> **交付目标：无写入的二次扣血入口收掉。背刺和弹反仍只扣一次。**

## 1. 为什么是这一刀

`pendingCriticalDamage` 没有别的脚本赋值。`ApplyPendingDamage` 在它不为 0 时再 `TakeDamage` 一次。处决扣血已经在 `GetBackStabbed` 和 `GetRiposte` 里。

## 2. 做完之后

这两个成员删掉。背刺和弹反仍只走各自的 `ResolveIncomingHit`。不改背刺和弹反动画。不给处决再加一次扣血。

## 3. 验收

Edit Mode：反射断言 `ApplyPendingDamage` 和 `pendingCriticalDamage` 已经不在。不调用处决，不播动画。
