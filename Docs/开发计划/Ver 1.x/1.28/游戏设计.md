# 1.28 游戏设计：设置窗口按档位拆开

> **交付目标：画质、帧率、后处理、特效的文案和换算不再写在设置窗这一个类里。选项和套用结果不变。**

## 1. 为什么是这一刀

`SettingsWindowManager` 把四档的文案、下一档和数值写在同一个组件里。1.6–1.9 已经把套用收成一处，档位表还堆在这个类上。

## 2. 做完之后

四档的文案、相邻档、帧率数值和画质等级各自有一处。设置窗仍负责按钮和写到界面、引擎上。按钮方法名不变。不新增组件，不改预制体。垂直同步不拆。

帧率仍是 60、90、120、无限制，无限制的数值仍是 -1。画质仍从「非常低」到「最高」，等级仍是 0 到 5。后处理和特效仍是「低」和「高」，只有下一档，不新加上一档。

## 3. 验收

Edit Mode：四档的文案、相邻档和数值与上面相同。不打开设置窗，不加载预制体。
