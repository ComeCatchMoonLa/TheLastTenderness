# 1.3 技术设计：一种武器类型一段装载

> **`LoadWeaponOnSlot` 拆成左手、右手、弓在场时收背三段。`LoadWeaponModel` 先检查预制体。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在的顺序

`LoadWeaponModel` 先 `UnloadWeaponAndDestroy`，再看 `modelPrefab`。为空就返回，旧模型已经没了。

左手：写入 `currentWeapon`、装模型、装伤害体。徒手播 `Left Arm Empty`，否则播 `offHandIdleAnimation`。弓再播一次 `Left Arm Empty` 并换 `weaponController`。

右手：左手当前是弓时，这把武器记到背和右手，模型只生成在背上，右手模型销毁，播 `Right Arm Empty`。否则装到右手、装伤害体、装 IK。`isTwoHandingWeapon` 为真时把左手武器挪到背，左手改成 `unaremd` 并销毁左手模型。否则清空背槽。然后换控制器。

伤害体对徒手、三种法杖、以及左手的弓和盾，仍在 `LoadWeaponDamageCollider` 里直接返回。

## 2. 模型

`LoadWeaponModel` 改为返回 bool。`weaponItem` 或 `modelPrefab` 为空时打日志并返回 false，不销毁当前模型。成功才销毁旧模型并实例化。

`LoadWeaponOnSlot` 改为返回 bool。失败时不改该槽的 `currentWeapon`。`PlayerWeaponSlotManager` 只在返回 true 后刷新快捷栏图标。

## 3. 三段

`LoadWeaponOnSlot` 只做分发：

- 左手：`LoadLeftHandWeapon`。先装上模型。徒手只播 `Left Arm Empty`。弓先播副手待机，再播 `Left Arm Empty` 并换控制器。其余类型播副手待机。然后 `LoadWeaponDamageCollider`。
- 右手且左手是弓：`StowRightWeaponOnBack`。模型只装到背槽。成功后才写背槽和右手的 `currentWeapon`，销毁右手模型，播 `Right Arm Empty`。不换控制器。
- 其余右手：`LoadRightHandWeapon`。装到右手后装伤害体和 IK。双手标记为真时再把左手模型装到背槽，成功后才把左手改成 `unaremd` 并销毁左手模型。标记为假时清空背槽。最后换控制器。

弓、双手收纳、普通右手不再写在同一个分支的后半段。`LoadWeaponDamageCollider` 和 `LoadTwoHandIKTarget` 不改规则。

## 4. 不做

不改敌人何时写 `isTwoHandingWeapon`。不按物体名找槽。不改取箭。不补单元测试。
