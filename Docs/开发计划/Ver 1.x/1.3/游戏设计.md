# 1.3 游戏设计：一种武器类型一段装载

> **交付目标：左手、右手、弓在场时的收背，分开装。模型预制体缺失时，手上原来的武器还在。**
>
> 不改 0.10 的双手标记顺序。不合并 `oh_*` 和 `th_*`。换武器的外观与现在一致。

## 1. 为什么是这一刀

`LoadWeaponOnSlot` 把近战、弓、双手收纳和换控制器写在一个方法里。模型为空时会先拆掉上一把，再发现预制体没有。装失败不该把人缴械。

## 2. 谁负责

`WeaponHolderSlot.LoadWeaponModel` 在确认 `modelPrefab` 存在之后才销毁旧模型。

`CharacterWeaponSlotManager` 按这次要装的手，和左手是不是弓，分到三段。双手把左手收到背上，仍看 `isTwoHandingWeapon`，不看正在装的那把是不是 `melee_TH`。

玩家快捷栏只在装成功之后换图标。

## 3. 验收

换近战、弓、双手、法杖，手上的模型和控制器与改之前一致。走路不重测。

- 拔掉一把武器的 `modelPrefab` 再装：上一把模型还在，Play 不因为空碰撞体停住。快捷栏图标不换成这把缺模型的武器。
