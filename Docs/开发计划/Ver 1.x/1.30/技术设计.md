# 1.30 技术设计：瞄准旗标的清零收成一处

> **清零只在 `PlayerManager.ClearAimingMode`。跳跃、翻滚和松开瞄准调用它。`AimAction` 仍负责写成 true。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerManager.aimingMode` 是玩家瞄准的唯一旗标。`HandleJumpState` 和 `HandleRollState` 进入时写成 false。`PlayerCombatManager.Handle_Hold_Q_Input` 在 `hold_q_Input` 为 false 时也写成 false。`AimAction` 在没有箭或正在交互时另外写成 false，并在能瞄准时写成 true。

## 2. 一处清零

`PlayerManager` 增加 `ClearAimingMode`，把 `aimingMode` 写成 false。

这三处改为调用它，不再各自赋值：

- `HandleJumpState.OnStateEnter`
- `HandleRollState.OnStateEnter`
- `Handle_Hold_Q_Input` 里松开的分支

`AimAction` 的赋值不改。不改相机、移动、准星对 `aimingMode` 的读取。

## 3. 单元测试

`Assets/Tests/EditMode/AimingClearTests.cs`。

同一名玩家，`aimingMode` 先设为 true。调用跳跃进入后为 false。再设为 true，调用翻滚进入后为 false。再设为 true，松开瞄准后为 false。

不创建 Animator 控制器。不调用 `PlayTargetAnimation`。

## 4. 不做

不改 `AimAction`。不改按住瞄准是否重复进入动作。不改敌人的 `isAiming`。
