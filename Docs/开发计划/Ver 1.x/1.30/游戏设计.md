# 1.30 游戏设计：瞄准旗标的清零收成一处

> **交付目标：跳跃进入、翻滚进入、松开瞄准这三处把 `aimingMode` 清成 false，清零只写一次。拉弓和取消后的镜头仍按 1.2。**

## 1. 为什么是这一刀

1.2 已经让玩家瞄准只留 `aimingMode`。`HandleJumpState`、`HandleRollState` 和松开瞄准仍各自写成 false。三处结果相同。

## 2. 做完之后

这三处都调用同一处清零。清完之后 `aimingMode` 为 false。`AimAction` 仍是唯一把它写成 true 的地方。没有箭、正在交互时的清零留在 `AimAction`。按住期间会不会每个 `Update` 再进一次动作，不在这一版。

不改瞄准镜头，不改胶囊半径。

## 3. 验收

Edit Mode：瞄准为 true 时，跳跃进入之后为 false；再设为 true，翻滚进入之后为 false；再设为 true，松开瞄准之后为 false。不创建已初始化的 Animator 控制器。
