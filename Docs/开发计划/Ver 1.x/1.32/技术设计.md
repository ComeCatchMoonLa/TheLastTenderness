# 1.32 技术设计：特效模型字段拼写

> **只改 `PlayerEffectsManager.instantialtedFXModel` 这一个字段名，以及直接写到它的代码和 YAML 键。引用的 fileID 不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerEffectsManager` 上的公开字段是 `instantialtedFXModel`。`FlaskItem` 和 `BombItem` 在按下时写入，在 `SucessfullyUsedConsumable` 里销毁并清空。

`Assets/Perfabs/Player/Player.prefab` 有 1 处，`Assets/Scenes/Game_Before_0.7.unity` 有 3 处，都是 `instantialtedFXModel: {fileID: 0}`。

## 2. 改名

字段改成 `instantiatedFXModel`。两处物品脚本跟着改。两份 YAML 只把键名换成 `instantiatedFXModel`，`{fileID: 0}` 保持。

## 3. 单元测试

`Assets/Tests/EditMode/InstantiatedFxFieldTests.cs`。

断言新字段存在、旧字段不存在。断言上述两份文件含有 `instantiatedFXModel: {fileID: 0}`，且不再含有 `instantialtedFXModel`。不创建角色。

## 4. 不做

不改目录、类文件名、类名、动画方法名、`SucessfullyUsedConsumable`。不改这个字段上的引用值。
