# 1.35 技术设计：输入动作类名

> **改资产文件名、生成类名和 `InputManager` 上的类型。资产 `.meta` 的 guid 不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Assets/InputAcitons.inputactions` 的名字是 `InputAcitons`。guid 是 `5c2ea1392b940f04c8066d98d81b66e3`。`.meta` 里 `wrapperCodePath` 指向 `Assets/Scripts/Input/InputAcitons.cs`。

生成类是全局的 `InputAcitons`。`InputManager.inputActions` 用这个类型，并且标了 `NonSerialized`。

## 2. 改名

资产文件改成 `InputActions.inputactions`，里面的 `"name"` 改成 `InputActions`。`.meta` 跟着移动，guid 不变，`wrapperCodePath` 改成 `Assets/Scripts/Input/InputActions.cs`。

生成文件改成 `InputActions.cs`，类名和文件里的资产名跟着改。`InputManager` 的字段类型跟着改。

## 3. 单元测试

`Assets/Tests/EditMode/InputActionsRenameTests.cs`。

断言 `InputActions` 存在，`InputManager.inputActions` 的类型名是 `InputActions`。断言新资产在、旧资产不在，meta 含有原 guid，并且 `wrapperCodePath` 含有 `InputActions.cs`。断言资产和生成文件不再含有 `InputAcitons`。不创建角色。

## 4. 不做

不改目录。不改两个方法名。不改 `Interacte`。不改按键绑定。
