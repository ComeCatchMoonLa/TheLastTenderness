# 1.38 技术设计：锁定查询改成有限层

> **只改 `UpdateLockOnTargets` 里那一次 `CollectOverlaps` 的层遮罩。半径、扇形和 `Linecast` 不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerCameraManager.UpdateLockOnTargets` 在 `lockOnMode` 为真时调用 `OverlapQuery.CollectOverlaps(player.transform.position, maxLockOnDist, ~0, ref lockOnOverlapResults)`。命中后再要 `CharacterManager`，并跳过玩家自己。挡住视线的 `Linecast` 仍用 `cameraCanDetectLayers`。

`Humanoid A.I - Melee`、`Default Story NPC`，以及 `Game_Before_0.7` 里四名带 `EnemyManager` 的角色，根物体都有胶囊碰撞体，层都是 9。`Game` 场景没有把这些根物体的层改掉。

## 2. 改法

这一次的层遮罩改成 `LayerMask.npc`。注释改成只查这一层。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 里「锁定开启后每帧做一次无层遮罩的球形查询」改成这一次用 `LayerMask.npc`。每帧仍查一次，不写省下的数量。

## 3. 单元测试

`Assets/Tests/EditMode/LockOnLayerTests.cs`。

断言 `PlayerCameraManager.cs` 含有 `CollectOverlaps(player.transform.position, maxLockOnDist, LayerMask.npc`，并且不再含有 `~0`。断言 `Prefabs/Humanoid A.I - Melee.prefab` 里该根物体的 `m_Layer` 是 9。不创建角色。

## 4. 不做

不改半径、扇形角度、死亡判断、`Linecast`。不改待机和伏击的层。不改上弦的字符串比较。
