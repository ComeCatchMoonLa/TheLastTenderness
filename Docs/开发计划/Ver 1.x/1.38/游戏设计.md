# 1.38 游戏设计：锁定查询改成有限层

> **交付目标：锁定扫描只查 `npc` 层。半径仍是 `maxLockOnDist`。能锁上的人与上一版相同。**

来源：[不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1关-五小时内开.md](../../../版本候选池/不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1关-五小时内开.md)。

## 1. 为什么是这一刀

1.11 已把锁定查询收成 `OverlapQuery.CollectOverlaps`。0.29 把层遮罩留成 `~0`，对应原来不传层。仓库里带 `EnemyManager` 和胶囊碰撞体的物体都在第 9 层，也就是 `LayerMask.npc`。

## 2. 做完之后

锁定开启后，球形查询只碰到 `npc` 层。扇形、死亡判断，以及之后那条 `Linecast`，仍按现在的规则。玩家自己仍不锁。

不改上弦时对动画名的字符串比较。不改 `SucessfullyGetArrow`。

## 3. 验收

Edit Mode：调用传入的层是 `LayerMask.npc`，半径参数仍是 `maxLockOnDist`。近战预制体根上的层仍是 9。不创建角色，不真正做球形查询。
