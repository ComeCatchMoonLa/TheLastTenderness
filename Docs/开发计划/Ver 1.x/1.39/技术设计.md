# 1.39 技术设计：上弦状态不再比动画名字符串

> **只改 `PlayerEffectsManager.Update` 里那两次 `IsName`。拆模型的条件不变。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Ammo` 不为空、`aimingMode` 为假，并且 Animator 第 4 层当前状态既不是 `"Get Arrow"` 也不是 `"Aiming - Start"` 时，销毁 `Ammo` 并写成空。两次都是 `GetCurrentAnimatorStateInfo(4).IsName`。

`CharacterAnimatorManager.SucessfullyGetArrow` 仍生成箭模型并赋给 `Ammo`。

## 2. 改法

两个状态名各做一次 `Animator.StringToHash`，存成静态字段。每帧只取一次第 4 层的 `AnimatorStateInfo`，用 `shortNameHash` 和这两个哈希比较。`aimingMode` 为真时仍不拆。

`IsName` 比的是状态短名。`shortNameHash` 对的是同一个短名。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 里「拿着箭且未瞄准时……字符串比较」改成比这两个哈希。不写省下的数量。

## 3. 单元测试

`Assets/Tests/EditMode/ArrowNockStateTests.cs`。

断言 `PlayerEffectsManager.cs` 含有 `StringToHash("Get Arrow")`、`StringToHash("Aiming - Start")` 和 `shortNameHash`，并且不含 `IsName`。断言 `CharacterAnimatorManager.cs` 仍含有 `SucessfullyGetArrow`。不创建角色。

## 4. 不做

不改 `SucessfullyGetArrow` 的名字和生成箭的做法。不改动画片段。不改 `aimingMode` 的写入点。
