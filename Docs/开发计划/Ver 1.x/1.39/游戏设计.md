# 1.39 游戏设计：上弦状态不再比动画名字符串

> **交付目标：拿着箭且未瞄准时，是否还在取箭或瞄准起手，用状态哈希判断。箭模型何时留下、何时拆掉，与上一版相同。**

来源：[不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1关-五小时内开.md](../../../版本候选池/不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1关-五小时内开.md)。

## 1. 为什么是这一刀

1.38 改了锁定查询的层。上弦仍由 `SucessfullyGetArrow` 把箭模型交出去。拆模型的判断在 `PlayerEffectsManager.Update`，每帧用字符串比较 `"Get Arrow"` 和 `"Aiming - Start"`。没有一个已有布尔正好覆盖这两个状态。`aimingMode` 已经单独挡住瞄准中的拆模型。

## 2. 做完之后

瞄准中不拆。第 4 层当前状态是取箭或瞄准起手时不拆。其余时候，手里还有箭模型就拆掉并清空。射箭和扣弹与上一版相同。

不改 `SucessfullyGetArrow`。不改拉弓和射箭动画。

## 3. 验收

Edit Mode：判断使用这两个状态的 `shortNameHash`，不再调用 `IsName`。`SucessfullyGetArrow` 仍在。不创建角色，不播动画。
