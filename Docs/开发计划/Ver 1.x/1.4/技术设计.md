# 1.4 技术设计：护甲部位一份描述

> **`PlayerArmorManager` 用一个私有方法装一个部位。三个当前护甲字段保持原类型。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`EquipAllArmorModels` 对头、躯干、下身各做一遍：`UnEquipAllModels`，有当前护甲就 `EquipModelByName(transformName)` 并抄 `physicalDA` 到 `darkDA`，没有就把对应五段写成 0。躯干和下身在没有护甲时再装 `nakedTorsoModelName`、`nakedHipsModelName`。头没有赤裸名。

`InventorySlotUI.EquipArmor` 按 `ArmorType` 分成三岔，换背包物品和装备窗格子，然后调用 `EquipAllArmorModels`。

`HeadArmorItem`、`TorsoArmorItem`、`HipsArmorItem` 是空子类。`TakeDamage` 用头 0.6、躯干 0.3、下身 0.1。

## 2. 一个部位一次调用

在 `PlayerArmorManager` 增加私有方法。参数是 `ModelChanger`、`ArmorItem`、赤裸模型名，以及该部位五段吸收的 `ref`。

有护甲：按 `transformName` 装模型，五段写成护甲上的数。没有护甲：五段写成 0；赤裸名不为空才 `EquipModelByName`。调用前仍先 `UnEquipAllModels`。

`EquipAllArmorModels` 对头、躯干、下身各调用一次。头的赤裸名传空。`currentHeadArmor`、`currentTorsoArmor`、`currentHipsArmor` 的声明类型不改。

`EquipArmor` 的三岔不合并。三个空子类不删。`armor_Toros_Slot`、`GetHipArmorSlot`、`HipModelChanger` 不改名。

## 3. 单元测试

`Assets/Tests/EditMode` 里直接调用 `EquipAllArmorModels`。`ModelChanger.models` 在测试里赋好，不跑 `Awake`。断言激活的子物体和五段公开字段。不测装备窗和背包。

## 4. 不做

不加部位。不改 `TakeDamage` 的权重。不改已有护甲资产。不把 `EquipPart` 改成 `virtual`。
