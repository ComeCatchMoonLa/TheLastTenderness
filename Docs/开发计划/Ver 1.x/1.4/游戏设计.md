# 1.4 游戏设计：护甲部位一份描述

> **交付目标：头、躯干、下身用同一套步骤换模型、写五段吸收。穿上和脱下之后，模型和吸收与现在相同。**
>
> 不加第四个部位。不改 `Hip`、`Hips`、`armor_Toros_Slot` 的拼写。60/30/10 仍在 `TakeDamage`。

## 1. 为什么是这一刀

换模和写吸收在 `EquipAllArmorModels` 里写了三遍。0.11 把火、魔、雷、暗补进这三遍，结构还是三份。头没有赤裸模型，躯干和下身有。

## 2. 做完之后

一个部位的步骤只写一处：卸下该部位全部模型；有护甲就按 `transformName` 装上，并把五段吸收抄进去；没有护甲就把五段写成 0，赤裸名不为空时再装赤裸模型。头、躯干、下身各调用这一处。

背包换装、装备窗三个格子仍按头、躯干、下身分开。已有护甲资产的类型不改。

## 3. 验收

穿上、换下头、躯干、下身。模型与现在一致。赤裸时躯干和下身仍是赤裸模型，头不另装一个赤裸模型。五段吸收与 0.11 之后相同。装备窗三个格子还在。

Edit Mode 单元测试断言这一处步骤，不进 Play Mode，不依赖 Animator：

- 有护甲时，名字相符的子物体激活，其余关掉，五段吸收等于护甲上的数。
- 没有护甲时五段为 0。赤裸名不为空才激活那个模型。头不传赤裸名，子物体保持关掉。
