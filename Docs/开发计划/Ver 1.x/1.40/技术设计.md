# 1.40 技术设计：敌人根运动不在移动之外覆盖速度

> **只改 `EnemyAnimatorManager.OnAnimatorMove` 何时写水平速度。朝向条件不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

每个动画帧都把 `deltaPosition` 的垂直分量清掉，再写成刚体速度，并把阻尼写成 0。然后若 `isRotatingWithRootMotion`，用 `deltaRotation` 改朝向。

攻击、受击、死亡经 `PlayTargetAnimation(..., true)` 把 `isInteracting` 写成真。追击把 `Vertical` 写成 1，绕圈写 `Vertical` / `Horizontal`，都停在基础层状态 `Locomotion` 上。`A.I Humanoid.controller` 里这个状态就叫 `Locomotion`。

## 2. 改法

`WritesHorizontalRootVelocity(bool isInteracting, int baseLayerShortNameHash)`：交互中，或基础层短名哈希等于 `Animator.StringToHash("Locomotion")` 时返回真。

为真时仍清掉垂直分量并写水平速度，阻尼仍写成 0。为假时不写速度、不改阻尼。朝向仍只看 `isRotatingWithRootMotion`。

[`构架设计.md`](../../../代码分析/构架设计.md) 里敌人根运动那一句改成：交互中或基础层是 `Locomotion` 时写水平速度。

## 3. 单元测试

`Assets/Tests/EditMode/EnemyRootMotionTests.cs`。

断言交互中为真，`Locomotion` 哈希为真，两个都不是时为假。不创建角色。

## 4. 不做

不把导航的 `desiredVelocity` 写进刚体。不改追击、绕圈的动画参数。不改玩家的 `OnAnimatorMove`。
