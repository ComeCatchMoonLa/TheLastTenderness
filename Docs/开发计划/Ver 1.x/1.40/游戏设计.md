# 1.40 游戏设计：敌人根运动不在移动之外覆盖速度

> **交付目标：攻击、受击、死亡仍用根运动写水平速度。追击和绕圈仍由 `Locomotion` 的根运动带动。其余非交互动画不再覆盖刚体水平速度。**

## 1. 为什么是这一刀

玩家的 `OnAnimatorMove` 只在 `isInteracting` 时写速度。敌人每个动画帧都把水平根运动写进刚体。追击和绕圈的位移就来自基础层 `Locomotion` 的这段根运动，需求和调研都没有另给一个速度数。

## 2. 做完之后

`isInteracting` 为真时，水平根运动仍覆盖刚体速度，垂直分量仍丢掉。基础层当前状态是 `Locomotion` 时同样覆盖，追击和绕圈仍往前走。两种都不是时，不再写刚体速度。`isRotatingWithRootMotion` 仍决定是否用根运动改朝向。

现有 `A.I Humanoid` 的基础层只有 `Locomotion`，攻击在 Override 层。非交互时基础层仍是 `Locomotion`，水平速度仍写。追击不因此停住。

不改导航目的地，不改发现和出手。

## 3. 验收

Edit Mode：交互中要写；基础层是 `Locomotion` 时要写；其余不写。不创建敌人，不播追击。

要人看的一条：追击时人还在走，不是被钉在原地，也不是滑步。这一条不进 Test Runner。
