# 1.41 技术设计：待机、追击、转向收成一套

> **只把待机、追击、转向的 `Tick` 收进 General 的三个类。人形子类只改 `Awake` 里找哪一个周旋。攻击和周旋的类不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`IdleState` 不看 `enableAI`，也不把方向写进 `enemy.targetDir`。`IdleStateHumanoid` 看 `enableAI`，并写下 `targetDir` 和 `targetDirAngle`。

`PursueTargetState` 的转向是 `rotationSpeed * Time.deltaTime`，并且 `Awake` 找 `CombatStanceState`。`PursueTargetStateHumanoid` 的转向是 `rotationSpeed / Time.deltaTime`，`Awake` 找 `CombatStanceStateHumanoid`。进入攻击距离后都返回那份周旋。

`RotateTowardsTargetState` 与 `RotateTowardsTargetStateHumanoid` 的四个转身角度相同。人形这份多看 `enableAI`。

人形近战预制体挂的是 Humanoid 子类。`Game_Before_0.7` 里的 General 敌人挂基类。Boss 的第二阶段列表在 `BossCombatStanceState.sencondPhaseAttacks`。

## 2. 改法

`IdleState.Tick`、`PursueTargetState.Tick`、`RotateTowardsTargetState.Tick` 改成现在人形近战的那一份。追击转向保持除以 `Time.deltaTime`。

三个基类的 `Awake` 先找人形周旋，没有再找 General 周旋。追击和转向的人形子类也在自己的 `Awake` 里指向人形周旋。`IdleStateHumanoid` 不另写 `Awake`。

## 3. 单元测试

`Assets/Tests/EditMode/MeleeStateUnifyTests.cs`。

断言三个人形子类的 `Tick` 声明在对应基类上。`isPreformingAction` 为假、距离不大于 `aggroRadius` 时，人形追击返回同一物体上的 `CombatStanceStateHumanoid`。这条不要求导航网格上真有代理，`SetDestination` 可以失败。断言 `AmbushState` 存在，`BossCombatStanceState` 仍有 `sencondPhaseAttacks`，`CombatStanceStateHumanoid.Tick` 仍声明在它自己的类上。不播动画。

## 4. 不做

不合并 `AttackState` 与 `AttackStateHumanoid`。不合并两份周旋。不删 `AmbushState`。不改 Boss 的第二阶段列表。不改预制体上的脚本 guid。
