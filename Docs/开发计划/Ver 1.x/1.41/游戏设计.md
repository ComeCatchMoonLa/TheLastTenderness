## 1. 为什么是这一刀

1.40 改的是根运动何时写速度。Humanoid 与 General 的待机、追击、转向、周旋、攻击仍是两套互相 `GetComponent` 的具体类。当前 `Game` 里的近战只挂 Humanoid。

## 2. 做完之后

这五种状态各只剩一种类型。人形近战预制体改挂这一套之后，发现、追击、进入攻击距离后出手，与现在相同。`AmbushState` 不删。`BossCombatStanceState` 的第二阶段攻击列表仍由它自己读。

不删敌人模型，不新做招式。

## 3. 验收

Edit Mode：近战预制体上的追击状态能在攻击距离内切到周旋；`AmbushState` 仍在；Boss 的第二阶段列表字段仍在。不创建导航网格。

要人看的一条：进游戏后人形近战仍会发现、追、打。General 和 Boss 的脚本还在，不因为这场合并从场上消失。这一条不进 Test Runner。
