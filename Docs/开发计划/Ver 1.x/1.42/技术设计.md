# 1.42 技术设计：锁定查询从相机跟随里拆出

> **把锁定扫描和换目标从 `PlayerCameraManager` 挪到同一相机物体上的 `LockOnQuery`。跟随、旋转、撞墙不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Player Camera` 上只有 `PlayerCameraManager`。`Update` 调用 `UpdateLockOnTargets`。半径 `maxLockOnDist` 在场景里是 30，半角是 50 和 30。`FollowPlayer` 和 `HandleCameraCollisions` 不调用这次扫描。

`EnemyStatsManager` 和左右切换仍调用 `PlayerCameraManager.UpdateLockOnTargets`。`curLockOnTarget`、`lockOnFlag`、`lockOnMode` 仍由很多处读取。

## 2. 改法

新组件 `LockOnQuery` 放在 `Player Camera` 上。它拿走重叠数组、可锁定列表、两个半角、自动换目标计时，以及 `maxLockOnDist`。场景里这些数原样抄过去，再从 `PlayerCameraManager` 上删掉。

扫描和换目标的正文挪到 `LockOnQuery`。层仍是 `LayerMask.npc`，半径仍读它自己的 `maxLockOnDist`，`Linecast` 仍用相机的 `cameraCanDetectLayers`。当前目标、锁定旗标仍写在 `PlayerCameraManager` 上。

`PlayerCameraManager.UpdateLockOnTargets` 只转给 `LockOnQuery`，给原来的调用处用。`Update` 改为调用这一转接。

`LockOnLayerTests` 改读 `LockOnQuery.cs`。

## 3. 单元测试

`Assets/Tests/EditMode/LockOnSplitTests.cs`。

断言 `FollowPlayer` 和 `HandleCameraCollisions` 的正文不含 `CollectOverlaps` 和 `UpdateLockOnTargets`。断言 `LockOnQuery` 含有 `CollectOverlaps` 和 `maxLockOnDist`。断言 `Game.unity` 里 `Player Camera` 仍有半径 30。不创建场景。

## 4. 不做

不改三种机位的偏移和旋转。不改撞墙半径。不改锁定旗标的读取方。不新做锁定标记。
