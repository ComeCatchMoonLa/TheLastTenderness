# 1.42 游戏设计：锁定查询从相机跟随里拆出

> **交付目标：改锁定半径时不再改跟随和撞墙。三种机位、跟随和撞墙拉近与现在相同。**

来源：[不引入美术开-不引入过多人工关-非高风险关-质量大于2开或关-完整度约1关-五小时内开或关.md](../../../版本候选池/不引入美术开-不引入过多人工关-非高风险关-质量大于2开或关-完整度约1关-五小时内开或关.md)。

## 1. 为什么是这一刀

1.2 已让三种机位读同一瞄准条件，1.10 已把偏移缓动收成一次，1.38 已把锁定球收成 `npc` 层。`UpdateLockOnTargets` 仍写在 `PlayerCameraManager` 里，和跟随、旋转、撞墙在同一个类。

## 2. 做完之后

锁定扫描和换目标留在相机物体上的另一个组件。跟随、旋转、撞墙留在 `PlayerCameraManager`。锁定半径、扇形和 `Linecast` 的结果与 1.38 之后相同。自由镜头和瞄准镜头的跟随不变。

不新做锁定标记。

## 3. 验收

Edit Mode：`FollowPlayer` 和 `HandleCameraCollisions` 不再调用锁定扫描。锁定半径仍是 `maxLockOnDist`。不创建场景。

要人看的一条：锁定、跟随、被墙挡住时拉近，和拆开之前一致。这一条不进 Test Runner。
