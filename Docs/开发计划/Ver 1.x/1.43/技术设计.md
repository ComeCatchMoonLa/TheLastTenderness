# 1.43 技术设计：按住瞄准只进入一次动作

> **按住 Q 时，`PerformAction` 只在这一次按住的第一帧进入。松开仍清举盾和瞄准。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerCombatManager.Handle_Hold_Q_Input` 在 `hold_q_Input` 为真时每个 `Update` 都调用左手或右手的 `oh_hold_q_action.PerformAction`。松开时把 `isBlocking` 清掉，并 `ClearAimingMode`。

`BlockAction` 在已经举盾时直接返回。`AimAction` 每次都会再写 `aimingMode`。

## 2. 改法

`ShouldEnterHoldAction(bool held, ref bool alreadyEntered)`：松开时把 `alreadyEntered` 写成假并返回假。按住且已经进入过时返回假。按住且还没进入时写成真并返回真。

`Handle_Hold_Q_Input` 用它决定是否调用 `PerformAction`。返回假且当前没按住时，仍清举盾和瞄准。

## 3. 单元测试

`Assets/Tests/EditMode/HoldAimOnceTests.cs`。

断言第一次按住进入，按住的后续次不进入，松开后再按住又进入。不创建相机，不调用 `AimAction`。

## 4. 不做

不改 `AimAction` 里怎么写 `aimingMode`。不改准星。不改锁定镜头的偏移。
