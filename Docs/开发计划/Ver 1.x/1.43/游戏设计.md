# 1.43 游戏设计：按住瞄准只进入一次动作

> **交付目标：按住 Q 期间，举盾或瞄准的 `PerformAction` 只进入一次。松开仍清掉举盾和瞄准。按住时镜头停在瞄准，松开离开；已经锁定则回到锁定镜头。**

## 1. 为什么是这一刀

`Handle_Hold_Q_Input` 在按住时每个 `Update` 都调用 `oh_hold_q_action.PerformAction`。`BlockAction` 已经在举盾后直接返回。`AimAction` 每次都会再写 `aimingMode`。FR-镜头-08 的按住切镜头、松开离开已经有了。

## 2. 做完之后

同一次按住只进入一次 `PerformAction`。松开后仍把 `isBlocking` 清掉，并 `ClearAimingMode`。镜头仍是按住进入瞄准、松开离开；锁着目标时松开回到锁定镜头。

不改瞄准动画，不改准星读的旗标。

## 3. 验收

Edit Mode：按住的第一帧进入，按住的后续帧不进入，松开后下一次按住再进入。不创建相机。

要人看的一条：按住时镜头停在瞄准，松开离开；已锁定则回到锁定镜头。`AimAction` 不再每帧重进，Test Runner 看不出镜头。这一条不进 Test Runner。
