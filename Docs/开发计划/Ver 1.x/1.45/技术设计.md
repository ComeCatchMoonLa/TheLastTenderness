# 1.45 技术设计：取箭方法名

> **草稿。** 进入这一版之前对照当时的代码复核，再去掉这行。
>
> **方法名和片段上的事件名一起改。事件名没改之前不改 C#。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CharacterAnimatorManager.SucessfullyGetArrow` 用 `currentAmmo.loadedItemModel` 生成模型，赋给 `Ammo`。`EndGetArrow` 在持箭时改父物体。仓库里没有调用旧方法名的动画片段。

`ArrowNockStateTests` 断言 `CharacterAnimatorManager.cs` 仍含有 `void SucessfullyGetArrow()`，并断言拆模型用 `Get Arrow` 和 `Aiming - Start` 的 `shortNameHash`。

## 2. 改名

先改片段上的事件名，再把方法改成 `SuccessfullyGetArrow`。生成模型和改父物体的做法不动。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 和 [`接口设计.md`](../../../代码分析/接口设计.md) 里这个方法的现名跟着改。已经收尾的版本文档不改。

## 3. 单元测试

改 `Assets/Tests/EditMode/ArrowNockStateTests.cs`，不新建第二份测试。

断言 `CharacterAnimatorManager.cs` 含有 `void SuccessfullyGetArrow()`，不含 `SucessfullyGetArrow`，仍含有 `EndGetArrow`。`PlayerEffectsManager.cs` 仍含有两个 `StringToHash` 和 `shortNameHash`，不含 `IsName`。不创建角色。

## 4. 不做

不改 `EndGetArrow`。不改 `"Get Arrow"` 和 `"Aiming - Start"`。不改 `aimingMode`。不把动画片段放进仓库。不新做取箭动画。
