# 1.45 游戏设计：取箭方法名

> **交付目标：`SucessfullyGetArrow` 改成 `SuccessfullyGetArrow`。片段上的动画事件用同一个名字。取箭和上弦的结果不变。**

## 1. 为什么是这一刀

1.36 改了消耗品回调的拼写。取箭这个方法仍少一个字母。调用它的动画片段不在仓库里，只改 C# 会让片段上的事件对不上，箭模型挂不上去。

上弦是否还在取箭或瞄准起手，1.39 已经用状态哈希判断。这一版不改那两个状态名。

## 2. 做完之后

`CharacterAnimatorManager` 上的方法是 `SuccessfullyGetArrow`。生成箭模型并赋给 `Ammo` 的做法不变。`EndGetArrow` 仍把模型改挂到持箭父物体。

片段上的事件名和这个方法一起改。改 C# 之前，先由人把事件名改成 `SuccessfullyGetArrow`。

## 3. 验收

Edit Mode：新方法在，旧方法不在。`EndGetArrow` 仍在。取箭和瞄准起手仍用 `shortNameHash`。不创建角色，不播动画。

要人看的一条：拉一次弓，箭模型仍挂上。事件名不在仓库里，Test Runner 看不出漏改的片段。这一条不进 Test Runner。

漏改的片段要拉弓才看得出来。收尾前 reviewer 的结论是「通过」或「有保留通过」。
