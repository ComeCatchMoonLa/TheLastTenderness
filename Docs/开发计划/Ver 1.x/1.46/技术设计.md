# 1.46 技术设计：一次命中的五段伤害收成一组参数

> **只把 `TakeDamage` 的五段 `float` 收成 `DamageSegments`。不改护甲公式，不改 `ResolveIncomingHit` 的参数列表。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CharacterStatsManager.TakeDamage` 的参数是动画名、`pd`、`fd`、`md`、`ld`、`dd`、`playHurtSound`。每一段先乘 `CombinedArmorRate`，再相加扣 `currentHP`。`playHurtSound` 为真时播受伤音。动画名非空时 `PlayTargetAnimation`。已死亡或无敌时返回 false。

`PlayerStatsManager` 和 `EnemyStatsManager` 覆盖同一签名，成功后再写血条。敌人参数名写成全称，顺序与基类相同。

调用在 `CharacterCombatManager` 的四处、`BombDamageCollider`、`SpellDamageCollider`、`DamagePlayer`，以及 `ArmorAbsorptionWeightTests`。

## 2. 改法

新文件 `Assets/Scripts/Character/DamageSegments.cs`。

`DamageSegments` 有 `Physical`、`Fire`、`Magic`、`Lightning`、`Dark`。未写的字段是 0。

三处 `TakeDamage` 改成 `TakeDamage(string damageAnimation, DamageSegments damage, bool playHurtSound = true)`。方法里改读 `damage` 的五个字段，乘区和扣血不变。

`CharacterCombatManager` 在调用前把现有的 `pd`、`fd`、`md`、`ld`、`dd` 装进 `DamageSegments`。`ResolveIncomingHit` 的参数列表不改。

炸弹和 `DamagePlayer` 只填 `Fire`。法术碰撞体填齐五段。`ArmorAbsorptionWeightTests` 改成传入 `DamageSegments`。

## 3. 单元测试

改 `Assets/Tests/EditMode/ArmorAbsorptionWeightTests.cs`，三处调用改走 `DamageSegments`。断言的血量不变。

新增 `Assets/Tests/EditMode/DamageSegmentsTests.cs`。吸收都是 0、五段各 10、`playHurtSound` 为假、动画名为空：返回 true，`currentHP` 少 50。`isDead` 或 `isInvulnerable` 为真时返回 false，血量不变。不创建音源，不播动画。

## 4. 不做

不改 `CombinedArmorRate` 的 60/30/10。不改 `ResolveIncomingHit`、`PlayTargetAnimation`、`MeleeAttackSegment.Play` 的参数列表。不改血条怎么写。
