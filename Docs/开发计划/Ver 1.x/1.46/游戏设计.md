# 1.46 游戏设计：一次命中的五段伤害收成一组参数

> **交付目标：`TakeDamage` 的物理、火、魔、雷、暗收成一组参数。扣血和是否播受伤音与现在相同。**

## 1. 为什么是这一刀

五段伤害逐个排在 `TakeDamage` 的参数列表里。玩家和敌人各有一份同样的列表。炸弹只传火伤时也要避开其余四段。

## 2. 做完之后

调用方把五段放进同一组再交给 `TakeDamage`。动画名和是否播受伤音仍是单独的参数。护甲仍按头 60%、躯干 30%、下身 10% 乘进每一段，五段相加后扣血。

`ResolveIncomingHit` 的参数列表不动。播动画和轻重击选段不动。

## 3. 验收

Edit Mode：只传物理伤害时，半吸收的头甲、零吸收、全身吸收满的扣血与现在相同。五段各 10、吸收为 0 时扣 50。已死亡或无敌时不扣血。不播动画，不创建音源。

这一版改的是扣血入口。收尾前 reviewer 的结论是「通过」或「有保留通过」。
