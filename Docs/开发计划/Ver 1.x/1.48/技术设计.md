# 1.48 技术设计：播动画的可选开关收成一组

> **只把 `PlayTargetAnimation` 的 `canRotate`、`mirrorAnim`、`isRotatingWithRootMotion` 收成 `AnimationOptions`。`applyRootMotion` 仍等于是否交互。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayTargetAnimation(string targetAnim, bool isInteracting, bool canRotate = false, bool mirrorAnim = false, bool isRotatingWithRootMotion = false)`。缺状态时打 `"物体名: Animator 没有状态 状态名"` 并返回。有状态时：`applyRootMotion` 和 `isInteracting` 都写成是否交互，`canRotate` 写成第三个参数，`isMirrored` 写成镜像，`isRotatingWithRootMotion` 写成根运动，然后 `CrossFade` 0.2 秒。

只传两个参数的调用保持三个开关为假。多传的调用在 `BlockAction`、`CombatStanceStateHumanoid`、`CharacterWeaponSlotManager`、`FlaskItem`、`CriticalAttackAction`、`HealingSpell`、`ProjectileSpell`、`MeleeAttackSegment`。

## 2. 改法

`AnimationOptions` 放在 `CharacterAnimatorManager.cs`。字段是 `CanRotate`、`Mirror`、`RootMotion`。未写的字段是假。

签名改为 `PlayTargetAnimation(string targetAnim, bool isInteracting, AnimationOptions options = default)`。方法里改读 `options`。`applyRootMotion` 仍等于 `isInteracting`。

| 调用 | `CanRotate` | `Mirror` | `RootMotion` |
| --- | --- | --- | --- |
| 举盾开始、格挡结束、副手待机、喝药 | 真 | 假 | 假 |
| 背刺、反击 | 假 | 真 | 假 |
| 治疗、投射法术、近战选段 | 假 | 原来的镜像 | 假 |

只传动画名和是否交互的调用不改。

## 3. 单元测试

`Assets/Tests/EditMode/PlayTargetAnimationOptionsTests.cs`。

缺状态时日志含物体名和状态名，`isInteracting` 仍是假。有状态时：只传交互为真，则 `isInteracting` 和 `applyRootMotion` 为真，三个开关为假。三个开关都为真时，`canRotate`、`isMirrored`、`isRotatingWithRootMotion` 为真。不断言动画曲线。

## 4. 不做

不改 `CrossFade` 的 0.2 秒。不改 `TakeDamage` 和 `ResolveIncomingHit`。不改 `MeleeAttackSegment.Play` 的参数列表。不改动画片段。
