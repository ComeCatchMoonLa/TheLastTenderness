# 1.48 游戏设计：播动画的可选开关收成一组

> **交付目标：`PlayTargetAnimation` 的旋转、镜像、根运动三个可选开关收成一组。播出来的状态和旗标与现在相同。**

## 1. 为什么是这一刀

动画名和是否交互已经在参数前部。旋转、镜像、根运动仍是三个带默认值的可选参数，调用点很多。漏改一处，交互和根运动会静默变掉。

## 2. 做完之后

三个开关一起传入。动画名和是否交互仍单独传。`isInteracting`、`canRotate`、镜像和根运动与现在相同。

不改动画片段。不改 `TakeDamage` 和入伤结算的参数。

## 3. 验收

Edit Mode：交互、允许旋转、镜像、根运动四个旗标与改签名之前相同。缺状态时仍打出物体名和状态名。不播画面上的动画曲线。

这一版改的是播动画入口。收尾前 reviewer 的结论是「通过」或「有保留通过」。
