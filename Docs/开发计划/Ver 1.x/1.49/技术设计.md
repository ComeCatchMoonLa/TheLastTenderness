# 1.49 技术设计：轻重击选段的四段动画名收成一组

> **只把 `MeleeAttackSegment.Play` 的四段动画名收成 `MeleeAnimations`。角色、是否连击和两段 `AttackType` 仍单独传。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Play` 的参数是角色、是否连击、单手第一段、单手第二段、双手第一段、双手第二段、两段 `AttackType`。双手都空且不是连击时，只把 `attackType` 写成第一段类型并返回。否则单手用前两段名，右手双手用后两段名。左手镜像，右手双手不镜像。连击且 `lastAttack` 等于这一下的第一段名时播第二段，否则播第一段。然后 `PlayTargetAnimation`，写下 `lastAttack` 和 `attackType`。

调用在 `LightAttackAction` 和 `HeavyAttackAction`。

## 2. 改法

`MeleeAnimations` 放在 `MeleeAttackSegment.cs`。字段是 `OneHandFirst`、`OneHandSecond`、`TwoHandFirst`、`TwoHandSecond`。

`Play` 改为接收这一组和两段 `AttackType`。选出动画名、镜像和 `attackType` 的判断收成 `Select`，`Play` 调用它。双手都空的提前返回仍留在 `Play`。

轻击传入 `ohLightAttack1`、`ohLightAttack2`、`thLightAttack1`、`thLightAttack2` 和 `light_1`、`light_2`。重击换成对应的重击名和 `heavy_1`、`heavy_2`。

## 3. 单元测试

`Assets/Tests/EditMode/MeleeAttackSegmentTests.cs`。直接调用 `Select`，不创建角色。

- 右手、不连击：单手第一段，不镜像，`light_1`。
- 左手、不连击：单手第一段，镜像，`light_1`。
- 右手双手、不连击：双手第一段，不镜像，`light_1`。
- 右手、连击、`lastAttack` 等于单手第一段：单手第二段，`light_2`。
- 右手、连击、`lastAttack` 是别的名字：仍是单手第一段，`light_1`。

不调用 `PlayTargetAnimation`。

## 4. 不做

不改 `PlayTargetAnimation` 的参数。不改攻击动画名字符串。不改体力门槛。
