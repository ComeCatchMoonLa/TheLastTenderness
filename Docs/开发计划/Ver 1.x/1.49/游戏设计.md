# 1.49 游戏设计：轻重击选段的四段动画名收成一组

> **交付目标：`MeleeAttackSegment.Play` 的四段动画名收成一组。选中的动画名和 `attackType` 与现在相同。**

## 1. 为什么是这一刀

选段要同时传入角色、是否连击、四段动画名和两段 `AttackType`。四段名字占了参数列表的中段。这一下播第一段还是第二段，由这个方法决定。

## 2. 做完之后

四段动画名一起传入。角色、是否连击和两段 `AttackType` 仍单独传。选中的动画名和 `attackType` 与现在相同。

不改攻击动画。不改播动画入口的参数。

## 3. 验收

Edit Mode：连击与否对应的动画名和 `attackType` 与改签名之前相同。不创建角色去播动画。
