# 1.5 技术设计：对话收成一处推进

> **`Talk` 和 `PlayerManager` 不再各自按开关挑选对话方法。挑选留在 `TalkUI` 的一个入口里。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Talk.Interact` 在 `auto` 为真时调用 `Start_UpdateDialogue_Auto_WFW` 或 `Start_UpdateDialogue_Auto_SBS`，否则调用 `Start_UpdateDialogue_WFW_Helper` 或 `UpdateDialogueSBS_Helper`。

`PlayerManager.Update` 在 `auto` 为假时，按 `wordForWord` 调用 `Handle_UpdateDialogue_NonAuto_WFW` 或 `Handle_UpdateDialogue_NonAuto_SBS`。`skip` 为真时另调 `Handle_SkipTalk_Input`。

四条路径最后都走到 `SetTalkerStatus`、写下 `talkContent[0]`、移除这一句，结束时 `HandleTalkEnd`。

## 2. 一个入口

`TalkUI` 增加一个公开方法，读 `auto` 和 `wordForWord`，内部分到现有的自动协程、手动逐句、手动逐字。`Talk.Interact` 开始对话时只调用它。`PlayerManager.Update` 在非自动时也只调用它，不再按逐字分叉。

`Handle_SkipTalk_Input` 仍由 `skip` 单独调用。`HandleTalkEnd`、`waitTime`、`DialogueTextData` 不改。

## 3. 不做

不合并跳过和普通推进。不改台词资产。不改对话时站位和禁用输入。不补单元测试。
