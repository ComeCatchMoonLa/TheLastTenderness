# 1.5 游戏设计：对话收成一处推进

> **交付目标：自动或手动、逐句或逐字，都从同一处进入。台词、停留时间和对话结束与现在相同。**
>
> 技术设计已写。不改对话内容和跳过键。

## 1. 为什么是这一刀

开始对话时，`Talk.Interact` 按自动和逐字分成四条入口。对话进行中，`PlayerManager.Update` 再按逐字调用另外两个手动方法。同一套台词被四条路径各写一份。

## 2. 做完之后

开始对话和对话进行中的推进，都调用 `TalkUI` 上的同一处。这一处内部仍看自动和逐字：自动逐句、自动逐字、手动逐句、手动逐字的播放方式不变。按住交互仍跳过整段。对话结束时 NPC 标签、动画和界面仍按现在恢复。

## 3. 验收

四种开关各说完一段已有台词。字是逐个出现还是整句出现、要不要按键、句与句的间隔，与改之前相同。按住交互仍直接结束。不新写台词。

Edit Mode 单元测试只覆盖手动逐句：推进开始后，文本是这一句的全文，列表少这一句。自动协程、逐字打字和按住跳过要等时间和动画，靠人看。
