# 1.50 技术设计：周旋贴近距离只写一处

> **只把两处 `1.4f` 收成 `CombatStanceState.ApproachDistance`。人形的 `3f` 后退不并进 General。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CombatStanceState.WalkAroundTarget` 在 `distFromTarget > 1.4f` 时把 `verticalMovementValue` 写成 `0.5f`，否则写成 `0`。

`CombatStanceStateHumanoid.WalkAroundTarget` 在冷却中、距离小于 `3f` 时写成 `-0.5f`。冷却结束、距离大于 `1.4f` 时写成 `0.5f`，否则写成 `0`。

人形不继承 `CombatStanceState`。

## 2. 改法

`CombatStanceState` 增加 `public const float ApproachDistance = 1.4f`。两处大于 `1.4f` 的比较改成大于 `ApproachDistance`。人形的 `3f` 仍写在它自己的方法里。

## 3. 单元测试

`Assets/Tests/EditMode/ApproachDistanceTests.cs`。

断言 `ApproachDistance` 等于 `1.4f`。`CombatStanceState.cs` 和 `CombatStanceStateHumanoid.cs` 都含有 `ApproachDistance`。人形文件不含 `1.4f`，仍含 `3f`。不创建敌人。

## 4. 不做

不把人形周旋收成 `CombatStanceState` 的子类。不把 `3f` 后退写进 General。不改左右绕圈的随机。不改攻击距离。
