# 1.50 游戏设计：周旋贴近距离只写一处

> **交付目标：两套周旋靠近玩家用的 `1.4f` 只写一处。靠近和后退的结果与现在相同。**

## 1. 为什么是这一刀

人形周旋在冷却结束、距离大于 `1.4f` 时靠近。General 周旋也用 `1.4f` 靠近。这个数写了两遍。人形冷却中、距离小于 `3f` 会后退，General 没有这一段，两段流程不并。

## 2. 做完之后

靠近用的距离只留在 General 周旋上的一个常数。人形周旋读这个常数。冷却中小于 `3f` 仍后退，仍只在人形这一份。

不改移动动画。不改攻击距离。

## 3. 验收

Edit Mode：这个常数是 `1.4f`。两份 `WalkAroundTarget` 都读它，人形文件里不再出现 `1.4f`，仍有 `3f`。不创建导航网格，不播动画。

这个距离决定冷却结束后靠不靠过去。收尾前 reviewer 的结论是「通过」或「有保留通过」。
