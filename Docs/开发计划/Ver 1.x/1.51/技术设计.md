# 1.51 技术设计：下身换模类名对上 Hips

> **只把类名 `HipModelChanger` 改成 `HipsModelChanger`。`.meta` 的 guid `9df84263d0eaadb4c90ae009162a0efc` 不变，不改预制体 YAML。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HipModelChanger` 是空的 `ModelChanger` 子类。`PlayerArmorManager` 用 `GetComponentInChildren<HipModelChanger>()` 找到它，字段名是 `hipModelChanger`。`ArmorEquipTests` 用这个类型装下身。

这个 guid 挂在 `Player.prefab`、`Humanoid A.I - Melee.prefab`、`Default Story NPC.prefab` 和 `Game_Before_0.7.unity`。

## 2. 改法

文件改名为 `HipsModelChanger.cs`，类名跟着改。`.meta` 一起改名，guid 不改。

`PlayerArmorManager` 和 `ArmorEquipTests` 的类型名跟着改。字段名 `hipModelChanger` 不改。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 里这个类的现名跟着改。已经收尾的版本文档不改。

## 3. 单元测试

改 `ArmorEquipTests` 的类型参数。新增 `Assets/Tests/EditMode/HipsModelChangerRenameTests.cs`。

断言 `typeof(HipsModelChanger).Name` 是 `HipsModelChanger`，`EquipmentSlotType.armor_Hips_Slot` 的名字是 `armor_Hips_Slot`。不创建新模型。已有换模测试仍覆盖换上的模型。

## 4. 不做

不改预制体和场景 YAML。不改 `armor_Hips_Slot`。不改 `nakedHipsModelName`。不改头和躯干的换模类名。
