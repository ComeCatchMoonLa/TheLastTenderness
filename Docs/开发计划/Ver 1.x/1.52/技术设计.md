# 1.52 技术设计：专注条字段不再叫 manaBar

> **只把 `HUDWindowsManager.manaBar` 改成 `focusPointsBar`。预制体只换键名，`{fileID: 0}` 保持。不改 `currentMP` 和 `focusLevel`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HUDWindowsManager` 的公开字段是 `manaBar`，类型是 `FocusPointsBar`。`Awake` 用 `GetComponentInChildren<FocusPointsBar>()` 赋值。空引用日志是 `"manaBar == null"`。

`PlayerStatsManager` 用它写 `SetMaxMP` 和 `SetCurrentMP`。`RestRefillConsumableTests` 给它赋值。

`Assets/Prefabs/#/UI.prefab` 有一处 `manaBar: {fileID: 0}`。场景里没有这个键。

## 2. 改名

字段、赋值、日志和测试改成 `focusPointsBar`。`UI.prefab` 的键改成 `focusPointsBar`，`{fileID: 0}` 不改。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md)、[`接口设计.md`](../../../代码分析/接口设计.md)、[`可测试性.md`](../../../代码分析/可测试性.md) 里这个字段的现名跟着改。已经收尾的版本文档不改。

## 3. 单元测试

`Assets/Tests/EditMode/FocusBarFieldTests.cs`。

断言 `HUDWindowsManager` 有 `focusPointsBar`、没有 `manaBar`。断言 `UI.prefab` 含有 `focusPointsBar: {fileID: 0}`，不含 `manaBar`。不创建角色。

## 4. 不做

不改 `currentMP`、`focusLevel`、`FocusPointsBar` 的类名。不改 `SetCurrentMP`。不改贴图。
