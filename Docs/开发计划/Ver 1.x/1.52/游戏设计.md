# 1.52 游戏设计：专注条字段不再叫 manaBar

> **交付目标：HUD 上的专注条字段改成 `focusPointsBar`。蓝条数值与现在相同。**

## 1. 为什么是这一刀

条的类型是 `FocusPointsBar`，字段却叫 `manaBar`。这个字段已经写进 HUD 预制体。改名时如果引用丢了，蓝条不再更新。

## 2. 做完之后

字段名是 `focusPointsBar`。`UI.prefab` 上的引用仍是 `{fileID: 0}`。`Awake` 仍用 `GetComponentInChildren<FocusPointsBar>()` 找到这条。`currentMP` 和 `focusLevel` 不改。

不改专注条贴图。

## 3. 验收

Edit Mode：新字段在，旧字段不在。`Prefabs/#/UI.prefab` 含有 `focusPointsBar: {fileID: 0}`，不再含有 `manaBar`。不创建角色。

要人看的一条：蓝条仍跟着专注走。字段在预制体上，Test Runner 看不出运行时有没有绑上。这一条不进 Test Runner。

这一版改的是已经序列化的字段。收尾前 reviewer 的结论是「通过」或「有保留通过」。
