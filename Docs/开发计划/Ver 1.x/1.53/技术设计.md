# 1.53 技术设计：延时销毁的拼写对上 Destroyed

> **只把 `DestroyAuto.timeUntilDestoryed` 改成 `timeUntilDestroyed`。预制体只换键名，3 和 5 保持。类名和 guid 不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DestroyAuto` 的公开字段是 `timeUntilDestoryed`，默认 `1f`。`Start` 用它调用 `Destroy`。

`Assets/Prefabs/FX/BloodSplat_FX.prefab` 是 `timeUntilDestoryed: 3`。`Assets/Prefabs/FX/FX_Explosion.prefab` 是 `timeUntilDestoryed: 5`。

`DestroyAutoRenameTests` 仍断言这两个旧键。

## 2. 改名

字段和 `Destroy` 的参数改成 `timeUntilDestroyed`。两份预制体的键跟着改，数字不改。

`DestroyAutoRenameTests` 改断言新键，并断言不再含有 `timeUntilDestoryed`。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 里这个字段的现名跟着改。已经收尾的版本文档不改。

## 3. 单元测试

不新建第二份测试。`DestroyAutoRenameTests` 断言 `timeUntilDestroyed: 3` 和 `timeUntilDestroyed: 5`，以及脚本 guid 仍是 `f8ce2664a73f11840a0fe2731eec1cf5`。不创建特效。

## 4. 不做

不改类名 `DestroyAuto`。不改脚本 guid。不改默认值 `1f`。不改特效模型。
