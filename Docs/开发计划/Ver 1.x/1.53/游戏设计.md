# 1.53 游戏设计：延时销毁的拼写对上 Destroyed

> **交付目标：`timeUntilDestoryed` 改成 `timeUntilDestroyed`。等待时间仍是预制体上现在的数。**

## 1. 为什么是这一刀

字段在 `DestroyAuto` 上，拼写少了一个 e。血溅预制体是 3 秒，爆炸预制体是 5 秒。改名时如果旧值丢了，等待时间会回到默认 1 秒。

## 2. 做完之后

字段名和 Destroyed 一致。两份特效预制体仍分别是 3 和 5。类名 `DestroyAuto` 和脚本 guid 不改。

不改特效本身。

## 3. 验收

Edit Mode：新字段在，旧字段不在。两份预制体含有 `timeUntilDestroyed: 3` 和 `timeUntilDestroyed: 5`。不创建特效去播。

要人看的一条：血溅和爆炸仍按原来的秒数消失。漏改要看画面。这一条不进 Test Runner。

这一版改的是已经写进预制体的字段。收尾前 reviewer 的结论是「通过」或「有保留通过」。
