# 1.54 技术设计：设置窗的套用再拆出去

> **公开按钮方法留在 `SettingsWindowManager`。左右切换和五档套用的结果改由两个静态类型给出。不改预制体。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SelectLeftWin` 和 `SelectRightWin` 用 `switch` 决定下一扇。`VSYNC_ApplyCurrentOption` 写「启用」或「禁用」，并把 `QualitySettings.vSyncCount` 写成 1 或 0。帧率和画质套用读已有的表，再写文本和 `targetFrameRate`、`SetQualityLevel`。后处理和特效套用只写表里的文案。

`UI.prefab` 按方法名调用 `VSYNC_SwitchOption`、`SelectDisplayWin`、`SelectGameSettingsWin`、`DisplayQuality_SetNextOption`。

## 2. 改法

`SettingsSubWindowNav.Left` / `Right`：游戏向左到操控、向右到画面；画面向左到游戏、向右到声音；声音向左到画面、向右到操控；操控向左到声音、向右到游戏。

`SettingsDisplayApply`：

- 垂直同步启用返回文案「启用」和 `1`，禁用返回「禁用」和 `0`。
- 帧率返回 `FrameRateLimitTable` 的文案和数值。
- 画质返回 `DisplayQualityTable` 的文案和等级。
- 后处理、特效返回各自表的文案。

设置窗的套用方法改成调用这些结果，再写到文本和引擎。`SelectLeftWin` 和 `SelectRightWin` 改成按导航结果调用现有的四个 `Select*Win`。

## 3. 单元测试

`Assets/Tests/EditMode/SettingsApplySplitTests.cs`。

断言四个窗口的左右下一扇。断言垂直同步两档的文案和 `vSyncCount`。断言无限制帧率是 -1，非常低画质等级是 0。不创建窗口。

## 4. 不做

不改按钮方法名。不改预制体。不改四档文案表。不改对话、帧数显示和相机速度的套用。
