# 1.54 游戏设计：设置窗的套用再拆出去

> **交付目标：画面档的套用和子窗口左右切换不再写在 `SettingsWindowManager` 里。各档结果与现在相同。按钮方法名不变。**

## 1. 为什么是这一刀

1.28 已把四档文案拆出去。垂直同步的「启用」「禁用」、帧率和画质的套用，以及四个子窗口的左右切换，仍在设置窗这一个类里。按钮在 `UI.prefab` 上按方法名调用，方法不能挪走。

## 2. 做完之后

左右切换由 `SettingsSubWindowNav` 决定下一扇窗。垂直同步、帧率、画质、后处理、特效的套用结果由 `SettingsDisplayApply` 给出。设置窗仍负责按钮、写文本和写到引擎上。

垂直同步仍是启用对应 `vSyncCount` 1、禁用对应 0。帧率仍是 60、90、120、无限制（-1）。画质等级仍是 0 到 5。后处理和特效仍是低和高。不改预制体。

## 3. 验收

Edit Mode：四个子窗口向左、向右各到现在的下一扇。垂直同步、无限制帧率和「非常低」画质的套用结果与上面相同。不打开设置窗。
