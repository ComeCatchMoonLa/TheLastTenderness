# 1.55 技术设计：相机跟随和撞墙再拆出去

> **跟随落点和撞墙距离改由普通类 `CameraRigMotion` 给出。机位切换、球形检测和锁定查询留在原来的组件上。不改场景。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`FollowPlayer` 按 `CurrentCameraPose` 调用三个落点：瞄准用 `cameraTransformWhileAiming`，锁定用玩家位置，默认用 `Vector3.SmoothDamp` 和 `followFadeTime`。然后调用 `HandleCameraCollisions`。

撞墙在瞄准时直接用 `aimingCameraForwardDist`。其余先用 `defaultCameraForwardDist`，沿相机减轴心的方向做 `SphereCast`，半径 `cameraSphereRadius`，层 `LayerMask.environment`。命中则改成轴心到命中点的距离再减 `cameraCollisionOffSet`。绝对值小于 `minCollisionOffSet` 时改成这个最小值。局部位置是 `-Vector3.forward * 距离`。

## 2. 改法

`CameraRigMotion`：

- `AimPosition` 返回瞄准锚点。`LockPosition` 返回玩家位置。`DefaultPosition` 用现有的四参数 `SmoothDamp`。
- `ForwardDistance`：瞄准返回瞄准距离。否则从默认距离开始；挡住时改成命中距离减偏移；绝对值小于最小距离时改成最小距离。
- `LocalBack` 返回 `-Vector3.forward * 距离`。

三个 `SetCameraPos_*` 改成调用前三个方法。`HandleCameraCollisions` 仍自己做 `SphereCast`，再把结果交给 `ForwardDistance` 和 `LocalBack`。`FollowPlayer` 的三种机位 `switch` 保留。

[`可维护性与性能.md`](../../../代码分析/可维护性与性能.md) 里相机那句改成：跟随落点和撞墙距离在 `CameraRigMotion`，机位切换仍在 `PlayerCameraManager`。

## 3. 单元测试

`Assets/Tests/EditMode/CameraRigMotionTests.cs`。

断言瞄准和锁定落点等于传入位置。断言默认落点等于同样参数的 `SmoothDamp`。断言瞄准距离在挡住时不变。断言未挡住用默认距离，挡住用命中距离减偏移，小于最小距离时收到最小距离。断言局部位置是 `(0, 0, -距离)`。不创建场景。

## 4. 不做

不加组件。不改 `LockOnQuery`。不改旋转和轴心偏移。不改球形检测的半径、层和方向。不改场景和预制体。
