# 1.55 游戏设计：相机跟随和撞墙再拆出去

> **交付目标：跟随落点和撞墙距离不再写在 `PlayerCameraManager` 里。三种机位的结果与现在相同。不新增相机组件。**

## 1. 为什么是这一刀

1.42 已把锁定扫描和换目标拆到 `LockOnQuery`。跟随仍按瞄准、锁定、默认三种机位落点，然后做撞墙。这三步和旋转、偏移仍在同一个类里。再挂一个组件会改场景序列化。

## 2. 做完之后

跟随落点和撞墙距离由 `CameraRigMotion` 给出。相机仍按现在的三种机位决定调用哪一种，仍自己做球形检测，仍写位置。

瞄准仍落到瞄准锚点，不做撞墙，前后距离仍是瞄准距离。锁定仍落到玩家位置。默认仍用现在的 `SmoothDamp` 和 `followFadeTime`。非瞄准撞到时，距离仍是命中点到轴心再减去 `cameraCollisionOffSet`；绝对值小于 `minCollisionOffSet` 时仍收到这个最小值。相机局部位置仍是正后方乘这段距离。

锁定查询、旋转和轴心偏移不改。场景和预制体不改。

## 3. 验收

Edit Mode：瞄准和锁定的落点就是传入的位置。默认跟随与同样参数的 `SmoothDamp` 相同。瞄准距离不被阻挡改掉。未挡住时用默认距离，挡住时用命中距离减偏移；小于最小距离时收到最小距离。局部位置是 `(0, 0, -距离)`。不创建场景。

要人看的一条：跟随、三种机位和贴墙拉近仍和现在一样。这一条不进 Test Runner。

镜头在场景物体上。收尾前 reviewer 的结论是「通过」或「有保留通过」。
