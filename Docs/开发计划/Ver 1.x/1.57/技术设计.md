# 1.57 技术设计：送到记下的火只写一处

> **按名字对上位置只写在 `RecordedFire`。对上才改位置，对不上人留在原地。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HomewardBoneItem.MoveToFire` 和 `DarkSignItem.MoveToFire` 都是：找出场上的篝火，名字相同就把人的位置写成那一处。对不上就返回。

## 2. 改法

`RecordedFire.TryMatch`：在给定的名字和位置里找这个名字，找到就给出那一处位置。找不到返回 false。

`RecordedFire.Move`：收集场上篝火的名字和位置，调用 `TryMatch`。找到才改 `body.position`。

两件物品删掉自己的查找，改为调用 `RecordedFire.Move`。灵魂、骨头、余烬和残留的结算不改。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/RecordedFireTests.cs`。

同一个名字得到那一处位置，并把人挪过去。找不到时人的位置不变。不创建篝火组件。

## 4. 不做

不改回城骨和暗印何时成功。不改开战挡住。不改记下的名字怎么写入。
