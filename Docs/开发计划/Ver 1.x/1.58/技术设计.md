# 1.58 技术设计：屏幕界面不挂在角色下

> **先由人改层级，再改两处查找。不改相机。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 现在的两处查找

[`PlayerManager.Awake`](../../../../Assets/Scripts/Character/Player/PlayerManager.cs) 用 `GetComponentInChildren<PlayerUIManager>()`，所以界面必须是角色的子物体。

[`PlayerUIManager.Awake`](../../../../Assets/Scripts/UI/Player%20UI/PlayerUIManager.cs) 用 `transform.root.GetComponent<PlayerManager>()`。界面还挂在角色下时，根就是 `Player`。挪到场景根之后，根变成界面自己，这里会是空的。

## 2. 层级改完再改代码

人把 `UI` 挪到场景根并改名为 `Global UI` 之后，再改这两处：

- `PlayerManager` 上用序列化字段记下 `PlayerUIManager`，`Awake` 不再向子物体找。空着时报出物体名。
- `PlayerUIManager` 上用序列化字段记下 `PlayerManager`，`Awake` 不再读 `transform.root`。空着时报出物体名。界面内部原来用 `transform.root` 找玩家的，改从这块界面上的 `PlayerUIManager` 取。

不改 `HUDWindowsManager`、暂停、背包和弹出层里面的逻辑。不改 `PlayerCameraManager`。不改 `World Canvas`。

## 3. 不在这一版

开场把 `Player Camera` 拉到角色坐标上，另开一版。不把相机挂到 `Player` 下面。
