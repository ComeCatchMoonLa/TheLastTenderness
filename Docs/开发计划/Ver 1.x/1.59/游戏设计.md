# 1.59 游戏设计：血迹和爆炸不再用 DestroyAuto

> **交付目标：血迹大约 3 秒后消失，爆炸大约 5 秒后消失。不再挂 `DestroyAuto`。**
>
> 地上拾取、箭、炸弹、施法残留本来就不走这个组件，这一版不改它们。

来源：这两个特效根上已有粒子系统。等待秒数原来写在 `DestroyAuto` 上。

## 1. 为什么是这一刀

只有 `BloodSplat_FX` 和 `FX_Explosion` 的根物体在用 `DestroyAuto`，分别等 3 秒和 5 秒。粒子系统自己可以在停掉时销毁物体。

## 2. 做完之后

两份特效根上的粒子不再循环，发射时长仍是原来的 0.1 秒和 0.5 秒。粒子寿命收到最晚在 3 秒和 5 秒死光。Stop Action 是 Destroy，系统停掉时销毁整个物体。`DestroyAuto.cs` 和钉住它的测试不在了。

看起来仍是过几秒消失。拾取仍是 `PickUpItem` 自己藏起来，和这一版无关。

## 3. 验收

Edit Mode：两份预制体根上的时长是 3 和 5，不循环，Stop Action 是 Destroy，不再引用 `DestroyAuto`。脚本文件不在。不创建特效。

要人看的一条：血迹和爆炸仍过几秒消失。
