# 1.6 技术设计：画质档收成一处

> **六档的文案和 `SetQualityLevel` 数字只写在一处。前进和后退只改枚举，再调用套用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DisplayQuality_SetNextOption`、`DisplayQuality_SetPreviousOption`、`DisplayQuality_ApplyCurrentOption` 各有一份六档 `switch`。等级数字一致。前进把 `medium` 写成「中」，后退和套用写成「中等」。

## 2. 一处描述

在 `SettingsWindowManager` 上放三个静态方法：`DisplayQualityLabel`、`DisplayQualityLevel`、`NextDisplayQuality`、`PreviousDisplayQuality`。

等级：`veryLow` 0，`low` 1，`medium` 2，`high` 3，`veryHigh` 4，`Ultra` 5。文案用现在套用里的字，`medium` 是「中等」。`Ultra` 的下一档是 `veryLow`，`veryLow` 的上一档是 `Ultra`。

`DisplayQuality_ApplyCurrentOption` 用这两个方法写文本和 `SetQualityLevel`。前进、后退只改 `displayQuality_Options`，再调用套用。

## 3. 单元测试

Edit Mode 调用这四个静态方法。断言六档文案和等级，以及前进、后退各走一圈回到原档。不调用 `QualitySettings`。

## 4. 不做

不改垂直同步、帧率、后处理、特效质量。不改枚举名。
