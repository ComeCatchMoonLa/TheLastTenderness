# 1.7 技术设计：帧率上限收成一处

> **四档的文案和 `targetFrameRate` 数字只写在一处。前进和后退只改枚举，再调用套用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`FrameRateLimit_SetNextOption`、`FrameRateLimit_SetPreviousOption`、`FrameRateLimit_ApplyCurrentOption` 各有一份四档 `switch`。文案和数字一致：60、90、120、无限制（`-1`）。

## 2. 一处描述

在 `SettingsWindowManager` 上放四个静态方法：`FrameRateLimitLabel`、`FrameRateLimitValue`、`NextFrameRateLimit`、`PreviousFrameRateLimit`。

`max60` → 「60」和 60，`max90` → 「90」和 90，`max120` → 「120」和 120，`unlimited` → 「无限制」和 -1。`unlimited` 的下一档是 `max60`，`max60` 的上一档是 `unlimited`。

`FrameRateLimit_ApplyCurrentOption` 用这两个方法写文本和 `Application.targetFrameRate`。前进、后退只改 `frameRateLimit_Options`，再调用套用。

## 3. 单元测试

Edit Mode 调用这四个静态方法。断言四档文案和数字，以及前进、后退各走一圈回到原档。不调用 `Application.targetFrameRate`。

## 4. 不做

不改垂直同步、画质、后处理、特效质量。不改枚举名。不加第五档。
