# 1.8 技术设计：后处理文案收成一处

> **低、高的文案只写在一处。切换只改枚举，再调用套用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PostTreatmentQuality_SwitchOption` 在两档里改枚举并写文字。`PostTreatmentQuality_ApplyCurrentOption` 再按枚举写一次「低」或「高」。没有前进、后退两个按钮，只有这一次切换。套用不调用后处理 API。

## 2. 一处描述

在 `SettingsWindowManager` 上放两个静态方法：`PostTreatmentQualityLabel`、`NextPostTreatmentQuality`。

`low` 的文案是「低」，下一档是 `high`。`high` 的文案是「高」，下一档是 `low`。

`PostTreatmentQuality_ApplyCurrentOption` 用文案方法写 `postTreatmentQuality_text`。切换只改 `postTreatmentQuality_Options`，再调用套用。

## 3. 单元测试

Edit Mode 调用这两个静态方法。断言两档文案，以及切换两次回到原档。不查找后处理组件。

## 4. 不做

不改帧率、画质、垂直同步、特效质量。不改枚举名。不给后处理补引擎调用。不加第三档。
