# 1.8 游戏设计：后处理文案收成一处

> **交付目标：后处理品质的切换和套用，共用一份文案。低、高两个字与现在相同。**
>
> 技术设计已写。不改帧率、画质、垂直同步和特效质量。不把后处理接到引擎。

## 1. 为什么是这一刀

`PostTreatmentQuality_SwitchOption` 在切换时写文案，`PostTreatmentQuality_ApplyCurrentOption` 再写一遍。两处都是「低」和「高」。套用只改文字，不写后处理组件。

## 2. 做完之后

切换只改当前档，再交给套用。文案只写在套用里。低的下一档仍是高，高的下一档仍是低。点两次回到原档。

## 3. 验收

低、高各点一次，文字与改之前相同。重新打开设置，仍显示「低」或「高」。帧率、画质、垂直同步、特效质量不重测成另一套。画面上的后处理效果不因本版变亮或变暗。

Edit Mode 单元测试断言两档文案，以及切换两次回到原档。测试不查找、不开关后处理组件。
