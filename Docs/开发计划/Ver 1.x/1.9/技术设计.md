# 1.9 技术设计：特效文案收成一处

> **低、高的文案只写在一处。切换只改枚举，再调用套用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SpecialEffectQuality_SwitchOption` 在两档里改枚举并写文字。`SpecialEffectQuality_ApplyCurrentOption` 再按枚举写一次「低」或「高」。没有前进、后退两个按钮，只有这一次切换。套用不调用粒子或光照 API。

## 2. 一处描述

在 `SettingsWindowManager` 上放两个静态方法：`SpecialEffectQualityLabel`、`NextSpecialEffectQuality`。

`low` 的文案是「低」，下一档是 `high`。`high` 的文案是「高」，下一档是 `low`。

`SpecialEffectQuality_ApplyCurrentOption` 用文案方法写 `specialEffectQuality_text`。切换只改 `specialEffectQuality_Options`，再调用套用。

## 3. 单元测试

Edit Mode 调用这两个静态方法。断言两档文案，以及切换两次回到原档。不改粒子系统和光照。

## 4. 不做

不改帧率、画质、垂直同步、后处理。不改枚举名。不给特效质量补粒子或光照调用。不加第三档。
