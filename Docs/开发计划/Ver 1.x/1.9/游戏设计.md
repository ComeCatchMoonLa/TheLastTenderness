# 1.9 游戏设计：特效文案收成一处

> **交付目标：特效质量的切换和套用，共用一份文案。低、高两个字与现在相同。**
>
> 技术设计已写。不改帧率、画质、垂直同步和后处理。不把特效质量接到粒子或光照。

## 1. 为什么是这一刀

`SpecialEffectQuality_SwitchOption` 在切换时写文案，`SpecialEffectQuality_ApplyCurrentOption` 再写一遍。两处都是「低」和「高」。套用只改文字。

## 2. 做完之后

切换只改当前档，再交给套用。文案只写在套用里。低的下一档仍是高，高的下一档仍是低。点两次回到原档。

## 3. 验收

低、高各点一次，文字与改之前相同。重新打开设置，仍显示「低」或「高」。帧率、画质、垂直同步、后处理不重测成另一套。粒子和光照不因本版变密或变稀。

Edit Mode 单元测试断言两档文案，以及切换两次回到原档。测试不改粒子系统和光照。
