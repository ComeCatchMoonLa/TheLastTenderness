# Ver 1.x：重构现有战斗和物品路径

> **这一大版本只重构，不加玩法。** 11 条纠错在 [`../Ver 0.x/README.md`](../Ver%200.x/README.md) 的 0.9–0.11，不在这里重复。0.10 做完交互锁和落地，0.11 做完数量和五段吸收，所以 1.x 不再单列这两版。
>
> 不换一套战斗核心，不加事件总线或依赖注入。不删除 General / Boss 状态脚本。不改已经写进场景和预制体的拼写。
>
> 调用链在 [`../../旧代码分析/重构方案.md`](../../旧代码分析/重构方案.md)。1.0–1.3 已完成。其后的纠错是 0.12–0.15，写在 [`../Ver 0.x/README.md`](../Ver%200.x/README.md)，不继续加重构版本号。

## 版本顺序

版本号按开工顺序排。下表就是版本号，不是另一套候选编号。

| 版本 | 结束时讲清的边界 | 小时 | 边际效用 |
| --- | --- | --- | --- |
| 1.0 | 一次命中怎么变成扣血，只走一处结算。0.9 已改对的背刺、盾、破防名、炸弹去重保持 | 8 | 高 |
| 1.1 | 播哪一段攻击、`attackType` 是什么，只由一个类型决定。0.9 已改对的段号和按键保持 | 4 | 中 |
| 1.2 | 瞄准只有一个旗标。相机的旋转、跟随、偏移读同一组模式条件 | 5 | 中 |
| 1.3 | 一种武器类型一段装载。装失败时手上仍是上一把。0.10 已写好的双手顺序保持 | 7 | 中 |

这四版大约 24 小时。

1.0 已完成。法术和炸弹只共享护甲和扣血，不进格挡。文档在 [`1.0/`](1.0/)。

护甲部位一份描述还在候选里，没有版本号。0.11 已经把五段吸收写进角色。不加第四个部位时不单开，玩起来和现在一样。若以后单开，再排成当时的下一号。

## 1.0 一次命中一次结算

近战和箭走 `DealDamage`，法术和炸弹直接 `TakeDamage`。0.9 已经让背刺只用攻击者武器、破防进入 `Guard_Break`、左手盾读左手、炸弹不打两次。

施工文档：[`1.0/游戏设计.md`](1.0/游戏设计.md) / [`1.0/技术设计.md`](1.0/技术设计.md) / [`1.0/TODO.md`](1.0/TODO.md)。已完成。

这一版让近战、箭、背刺、处决调用同一处结算，扣血结果与 0.9 之后相同。`TakeDamage` 仍只做护甲和扣血。

验收：普通命中、格挡、破防、背刺、箭、炸弹的血与 0.9 之后一致。法术和炸弹仍不能被盾挡住。

## 1.1 攻击选段

施工文档：[`1.1/游戏设计.md`](1.1/游戏设计.md) / [`1.1/技术设计.md`](1.1/技术设计.md) / [`1.1/TODO.md`](1.1/TODO.md)。已完成。

`LightAttackAction` 和 `HeavyAttackAction` 各有一套选段。0.9 只改了重击段号和按键次数，两套分支还在。

这一版收成一个类型。两个 Action 只保留体力和 `canDoCombo`。玩家仍读 `oh_*`，AI 仍读 `th_*`。不加第三段。

验收：动画与 0.9 之后相同。选段和 `attackType` 只有这一处赋值。

## 1.2 瞄准和相机模式

施工文档：[`1.2/游戏设计.md`](1.2/游戏设计.md) / [`1.2/技术设计.md`](1.2/技术设计.md) / [`1.2/TODO.md`](1.2/TODO.md)。已完成。

`aimingMode` 与 `isAiming` 同时存在。相机旋转、跟随、偏移对模式的判断不一致。

这一版玩家只留 `aimingMode`。离开瞄准时胶囊半径回到进入前。三处相机逻辑读同一个模式结果。不另做模式类。敌人射箭仍读 `isAiming`。

验收：拉弓时相机、朝向、准星一致。取消瞄准后半径恢复。锁定时的相机与现在相同。

## 1.3 武器装载

施工文档：[`1.3/游戏设计.md`](1.3/游戏设计.md) / [`1.3/技术设计.md`](1.3/技术设计.md) / [`1.3/TODO.md`](1.3/TODO.md)。已完成。

`LoadWeaponOnSlot` 把弓、双手、法杖和近战写在一个方法后半段。0.10 已经把敌人的双手标记挪到装载之前。

这一版按左手、右手、弓在场时收背分成三段。实例化失败时不销毁上一把。

验收：换武器的外观与现在一致。缺模型预制体时上一把还在。

## 未排版本号：护甲部位一份描述

头、躯干、下身在装备、换模、装备窗下标里各写一份。0.11 把火、魔、雷、暗补进这三份，结构仍是三份。

若单开：用一份部位描述驱动模型和五段吸收。60/30/10 仍在 `TakeDamage`。不改 `Hip` / `Hips` / `armor_Toros_Slot` 的拼写。不加部位。换装结果与 0.11 之后相同。大约 6 小时，边际效用低。

## 先不做

| 项 | 原因 |
| --- | --- |
| 再做一遍 0.9–0.11 | 纠错已经有版本。1.x 只在其上收拢职责 |
| 合成三套 AI、删除伏击或待机 | 当前近战只挂 Humanoid。状态脚本是已做好的功能 |
| 敌人根运动改成只在交互时写速度 | 追击每个动画帧都在覆盖水平速度 |
| 合并 `oh_*` 与 `th_*` | 要改读哪一组槽，先定行为 |
| 攻击状态同一帧离开 | 会改变近战连击手感。要做再点名 |
| 重做背包、成就、设置存档、打开未激活的世界和剧情 | 不是这条路径的债 |
| 改已进预制体的拼写 | 牵场景和预制体 |
| 事件总线、对象池、按帧时间做的性能专项 | [`../../代码分析/可维护性与性能.md`](../../代码分析/可维护性与性能.md) 没有测过帧时间 |
