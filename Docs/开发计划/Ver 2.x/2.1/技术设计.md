# 2.1 技术设计：喝药成功时回蓝

> **`SucessfullyUsedConsumable` 按两个回复量分别调用 `AddHP` 和 `AddMP`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`FlaskItem.SucessfullyUsedConsumable` 调用 `AddHP(healthRecoverAmount)`，然后放治疗粒子、销毁喝药模型、装回武器。`AddHP` / `AddMP` 在当前值已经达到上限时返回 false，不把数值加过上限。

次数在 `AttemptToConsumableItem` 里的 `TrySpendConsumable` 已经扣过。

## 2. 成功回调

`healthRecoverAmount` 大于 0 时调用 `AddHP`。`focusPointsRecoverAmount` 大于 0 时调用 `AddMP`。两个都大于 0 时两次都调用。等于 0 的那一次不调用。粒子、模型和装回武器不改。

## 3. 单元测试

不写。2.x 按游戏设计手动验收。成功回调会生成粒子。

## 4. 不做

不改 `flaskType` 的分支。不新做灰瓶资产。不改 `TrySpendConsumable`。不改已满时 `AddHP` / `AddMP` 返回 false。
