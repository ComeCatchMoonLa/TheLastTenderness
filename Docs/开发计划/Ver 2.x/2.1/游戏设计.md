# 2.1 游戏设计：喝药成功时回蓝

> **交付目标：喝药动作成功后，生命回复量和专注回复量各自大于 0 时，对应的条上升，不超过上限。**
>
> 技术设计已写。不新做瓶子模型。不改次数记在哪。

## 1. 为什么是这一刀

`FlaskItem.SucessfullyUsedConsumable` 只调用 `AddHP`。`focusPointsRecoverAmount` 和 `AddMP` 已经在，成功回调不读专注回复量。需求 FR-回复-05 写明：只配生命就只回生命，只配专注就只回专注，两者都配就一起回。

## 2. 做完之后

生命回复量大于 0 时仍 `AddHP`。专注回复量大于 0 时再 `AddMP`。已满的那一条保持上限。次数仍在喝药开始时扣，本版不改。

## 3. 验收

把现有血瓶的 `focusPointsRecoverAmount` 改成大于 0 后喝成功，专注上升且不超过上限。改回 0 后喝成功，专注不变。生命回复量仍大于 0 时，生命仍上升。不写 Edit Mode 测试。
