# 2.10 技术设计：装备窗能改选这只手的每一把

> **改选走 `PlayerInventoryManager.SelectHandWeapon`。新槽加在 `EquipmentSlotType` 末尾。装备窗按数组长度画。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`weaponsInRightHandSlot` 和 `weaponsInLeftHandSlot` 的长度已经能被方向键轮换。`EquipmentWinManager.SetAllSlotIcon` 只写下标 0 和 1。`InventorySlotUI.EquipWeapon` 只处理这四格。`EquipmentSlotUI.SelectThisSlot` 只记下要往哪一格放，不改当前下标。

`EquipmentSlotType` 里右手 1、2 和左手 1、2 在护甲槽前面。这些编号已经写进预制体，不能改。

## 2. 下标 2 和 3

在枚举末尾追加 `weapon_RH_Slot_3`、`weapon_RH_Slot_4`、`weapon_LH_Slot_3`、`weapon_LH_Slot_4`。已有成员的序号不动。

`EquipmentWinManager.TryHandIndex` 把槽类型换成是否左手和下标。下标 0 到 3。不是武器槽时返回 false。

`SetAllSlotIcon` 按 `weaponSlotsUI` 里每个槽的类型去对应数组取武器。下标超出数组长度，或那一格是空的，清掉该格图标。不访问数组外面。

`PlayerInventoryManager.SelectHandWeapon(bool isLeft, int index)`：下标在数组里时，把这只手的当前下标和当前武器写成这一格，返回 true。否则返回 false，不改当前武器。

`EquipmentSlotUI.SelectThisSlot` 在记下槽类型之后，若 `TryHandIndex` 成功，调用 `SelectHandWeapon`。`pWeaponSlot` 已接上时再 `LoadWeaponOnSlot`。

`InventorySlotUI.EquipWeapon` 用 `TryHandIndex` 写入对应下标。那一格原来有武器才放回背包。写完后把当前下标设成这一格，再按现在的方式装到手上。

`Assets/Perfabs/#/UI.prefab` 的 `Weapons Slots` 用现有格子再加四格，`weaponSlotsUI` 接上。格子仍是 `EquipmentSlotUI`。不新做图标。

## 3. 单元测试

`Assets/Tests/EditMode/HandWeaponSelectTests.cs`。

左右手数组长度都是 4。选中下标 2、3 后，当前下标和当前武器是那一把。下标 4 返回 false，当前武器不变。不创建 Animator，不调用 `LoadWeaponOnSlot`。

## 4. 不做

不改方向键轮换。不改护甲槽。不增加第五把。
