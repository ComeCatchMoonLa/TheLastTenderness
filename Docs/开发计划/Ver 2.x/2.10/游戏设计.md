# 2.10 游戏设计：装备窗能改选这只手的每一把

> **交付目标：装备窗能看到并改选这一只手已经装备的每一把，包括方向键能轮到的下标 2 和 3。改选后手上是这一把。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

方向键已经按左右手数组的长度轮换。装备窗只画并改选每手下标 0 和 1。需求是 [FR-装备-06](../../../需求文档/功能需求/装备与道具.md)。

## 2. 做完之后

装备窗按这只手数组里实际有的下标显示武器。下标 2、3 在数组里时能被选中。选中后，这只手的当前下标是这一格，当前武器是这一把。从背包放进下标 2 或 3 时，也写成这一格。

数组比四短时，缺的下标不画，也不能写进去。不新做武器图标。已有槽的枚举编号不改。

## 3. 验收

Edit Mode：右手数组下标 2、3 各有一把武器。选中 2 后当前下标是 2、当前武器是那一把；选中 3 同样。左手同样。下标超出数组长度时选不中。不创建 Animator。
