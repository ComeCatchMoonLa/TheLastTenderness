# 2.100 技术设计：物理子类吸收可以不同

> **物理伤害带种类。种类填了就用该种类的部位吸收，否则用物理吸收。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 种类

[`PhysicalKind`](../../../../Assets/Scripts/Character/DamageSegments.cs)：`Standard`、`Strike`、`Slash`、`Thrust`。`DamageSegments` 增加 `Kind`，缺省是 `Standard`。

[`ArmorItem`](../../../../Assets/Scripts/Items/Equipment/Armor/ArmorItem.cs) 增加打击、斩击、突刺的吸收和「已填」。[`ArmorPhysical.Of`](../../../../Assets/Scripts/Character/ArmorPhysical.cs)：已填用该种类，否则用 `physicalDA`。没有护甲是 0。

[`PlayerArmorManager.EquipAllArmorModels`](../../../../Assets/Scripts/Character/Player/PlayerArmorManager.cs) 把头、躯干、下身、手部的三种子类吸收写入角色。没有护甲时写成 0。

[`TakeDamage`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 按 `Kind` 取这四件的该种类吸收，仍走 `CombinedArmorRate` 和手部相乘。`Standard` 仍读现在的物理吸收字段。
