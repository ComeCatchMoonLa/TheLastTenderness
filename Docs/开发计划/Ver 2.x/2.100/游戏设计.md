# 2.100 游戏设计：物理子类吸收可以不同

> **交付目标：同一套甲的打击、斩击、突刺吸收可以不同。这一下按它的物理子类，走现在的头、躯干、下身、手部合成。没填的子类仍用物理吸收。**

来源：[FR-伤害-08](../../../需求文档/功能需求/命中判定与伤害.md)。状态页的逐件乘法和固定防御、戒指不在这一版。

## 1. 为什么是这一刀

现在五段里的物理只有一个吸收。打击和斩击打在同一套甲上，掉的血一样。

## 2. 做完之后

物理伤害带上标准、打击、斩击、突刺之一。标准，或子类没填，仍用现在的物理吸收。

子类填了：头、躯干、下身仍按 0.6、0.3、0.1，手部再乘 `(1 − 手部该子类)`。

脱掉后该子类吸收是 0，回到赤裸。火、魔、雷、暗不改。

## 3. 验收

Edit Mode：头的打击吸收 0.5、斩击吸收 0，其余部位为 0。物理 100 的打击后生命从 100 到 30。同一下斩击后生命从 100 到 0。

没填斩击时，斩击与标准同一结果。

不创建护甲模型。
