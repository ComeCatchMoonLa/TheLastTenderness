# 2.101 技术设计：格挡按吸收和稳定度

> **没崩用吸收后的伤害。崩了用原来的伤害。精力仍按稳定度。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 漏过

[`SpellOnShield.Leak`](../../../../Assets/Scripts/Character/SpellOnShield.cs)：`broke` 为真时返回原来的五段。否则返回 `Absorb`。

[`ResolveIncomingHit`](../../../../Assets/Scripts/Character/CharacterCombatManager.cs)：`AttemptBlock` 之后，`currentStamina` 小于或等于 0 则 `broke` 为真，再 `Leak`。

精力仍用 `StaminaCost`。稳定度越高，`(1 − 稳定度)` 越小。

## 3. 不做

不改侧面判定。不改毒沼和异常。不算高风险：没崩时的吸收与现在相同。
