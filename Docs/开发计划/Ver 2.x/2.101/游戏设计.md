# 2.101 游戏设计：格挡按吸收和稳定度

> **交付目标：格挡没被打崩时，伤害按盾的吸收漏过。精力按稳定度扣，稳定度高扣得少。这一下把精力扣到 0 时，改按没格挡的伤害结算。**

来源：[FR-伤害-10](../../../需求文档/功能需求/命中判定与伤害.md)。毒沼、异常积蓄和举盾时精力回复变慢不在这一版。

## 1. 为什么是这一刀

吸收和稳定度已经抄到角色上，精力也按稳定度扣。精力被扣光时，这一下仍按挡住之后的伤害结算。

## 2. 做完之后

没崩：物理吸收是 1 时物理伤害变成 0。火吸收是 0 时火伤害原样漏过。稳定度 0.8 比 0.2 扣的精力少。

崩了：这一下用挡住之前的伤害。

侧面和背后仍不走格挡。

## 3. 验收

Edit Mode：伤害 40、吸收 1，没崩时是 0。火 10、吸收 0，没崩时是 10。崩了时物理仍是 40。同一击、稳定度 0.8 的精力花费小于 0.2。

不创建盾的动画。
