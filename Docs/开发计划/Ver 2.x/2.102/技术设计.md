# 2.102 技术设计：护甲提高韧性

> **护甲韧性按递减公式写成 `armorPoiseBonus`。窗口打开时并进进攻霸体。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 合成

[`ArmorPoise.Fold`](../../../../Assets/Scripts/Character/ArmorPoise.cs) 和 `FromPieces`。

[`ArmorItem`](../../../../Assets/Scripts/Items/Equipment/Armor/ArmorItem.cs) 增加 `poise`。

[`PlayerArmorManager.EquipAllArmorModels`](../../../../Assets/Scripts/Character/Player/PlayerArmorManager.cs) 把四件合成写入 `armorPoiseBonus`。没在攻击霸体窗口时，`totalPoiseDefence` 写成同一数。

[`AttackPoiseWindow.Open`](../../../../Assets/Scripts/Character/AttackPoiseWindow.cs)：进攻霸体大于 0 时，血量用 `Fold(armorPoiseBonus, bonus)`。没开过窗口时，`totalPoiseDefence` 加上多出来的那一截，不把护甲再加一遍。

## 2. 测试

[`Assets/Tests/EditMode/Combat/ArmorPoiseTests.cs`](../../../../Assets/Tests/EditMode/Combat/ArmorPoiseTests.cs)。

## 3. 不做

不写狼戒指。不改窗口外必播受击。不算高风险：护甲韧性为 0 时，现有窗口数字不变。

## 4. 验收

游戏设计第 3 节。受击动画不测。
