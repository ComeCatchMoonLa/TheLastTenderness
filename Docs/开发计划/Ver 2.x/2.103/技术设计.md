# 2.103 技术设计：突刺迎击

> **出招中的突刺才乘。倍率在武器和攻击者的戒指字段上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 乘数

[`WeaponItem`](../../../../Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs) 增加 `thrustCounterFilled`、`thrustCounter`。

[`CharacterStatsManager`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 增加 `thrustCounterRing`。小于或等于 0 当作 1。

[`ThrustCounter.Scale`](../../../../Assets/Scripts/Character/ThrustCounter.cs)：目标正在出招、种类是突刺、武器已填且倍率大于 0 时，返回武器倍率乘戒指倍率。否则返回 1。

[`ResolveIncomingHit`](../../../../Assets/Scripts/Character/CharacterCombatManager.cs) 在格挡和护甲之前，把物理伤害乘这个数。武器取攻击者的 `currentItemBeingUsed`。
