# 2.103 游戏设计：突刺迎击

> **交付目标：突刺打中正在出招的目标时，物理伤害乘武器上的迎击倍率。狮子戒指再乘自己的倍率。待机、不是突刺、没填倍率时不乘。**

来源：[FR-伤害-09](../../../需求文档/功能需求/命中判定与伤害.md)。倍率写在武器和戒指上。没戴戒指时戒指倍率是 1。

## 1. 为什么是这一刀

突刺现在和别的物理一样，不看出招。

## 2. 做完之后

目标正在出招，这一下是突刺，武器填了迎击倍率：物理伤害乘这个倍率，再乘戒指倍率。戒指没填或小于等于 0 时按 1。

待机、斩击、没填武器倍率：乘数是 1。

## 3. 验收

Edit Mode：出招、突刺、武器 1.5、戒指 1，乘数 1.5。戒指 2，乘数 3。待机、斩击、没填都是 1。

不创建戒指模型。
