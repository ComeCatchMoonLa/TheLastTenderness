# 2.104 技术设计：双手用武器格挡

> **双手握住非盾武器时，格挡键举起这把武器。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 何时用武器

[`WeaponBlock.Use`](../../../../Assets/Scripts/Character/WeaponBlock.cs)：双手握住，并且类型不是盾、空手、弓时返回真。

[`PlayerCombatManager.Handle_Hold_Q_Input`](../../../../Assets/Scripts/Character/Player/PlayerCombatManager.cs)：`Use` 为真时用右手。有 `oh_hold_q_action` 就调用它。没有时，只要没在交互、没在举盾、精力大于 0，就把 `isBlocking` 设为真，并 `SetBlockingAbsorptionFromBlockingWeapon`。

吸收和精力仍走 2.101 的漏伤和稳定度。

## 2. 测试

[`Assets/Tests/EditMode/Combat/WeaponBlockTests.cs`](../../../../Assets/Tests/EditMode/Combat/WeaponBlockTests.cs)。

## 3. 不做

不新做格挡动画。不改空手拳头。不算高风险：单手和盾的格挡入口不改。

## 4. 验收

游戏设计第 3 节。动画不测。
