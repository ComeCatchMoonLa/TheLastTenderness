# 2.104 游戏设计：双手用武器格挡

> **交付目标：双手握住一把不是盾、也不是空手的武器时，格挡键用这把武器的吸收和稳定度。单手或盾仍走原来的格挡。**

来源：[FR-攻击-09](../../../需求文档/功能需求/轻重攻击与武器技.md)。减伤和扣精力仍是格挡已经写好的那一套。空手拳头动作不在这一版。

## 1. 为什么是这一刀

双手持武器时，格挡键只在这把武器填了格挡动作时才举起来。没填动作就挡不成。

## 2. 做完之后

双手、武器不是盾也不是空手也不是弓：按下格挡，用这把武器的吸收和稳定度。没填格挡动作也举得起来。

单手、盾、弓、空手：不因此改成武器格挡。

## 3. 验收

Edit Mode：双手直剑为真。双手盾、双手空手、单手直剑为假。

不创建格挡动画。
