# 2.106 技术设计：治疗不超过上限

> **即时治疗先夹到上限，再交给 `AddHP`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 夹顶

[`SpellHeal.Apply`](../../../../Assets/Scripts/Items/Spells/SpellHeal.cs)：回复量小于或等于 0 时返回当前生命。否则不超过上限。

[`HealingSpell.SuccessfullyCastSpell`](../../../../Assets/Scripts/Items/Spells/HealingSpell.cs)：没有每秒量时，用 `Apply` 的结果减去当前生命，再 `AddHP`。持续治疗仍走 `BeginRegen`。

## 2. 测试

[`Assets/Tests/EditMode/Spells/SpellHealTests.cs`](../../../../Assets/Tests/EditMode/Spells/SpellHealTests.cs)。

## 3. 不做

不把催化器威力乘进即时治疗。不改持续治疗的每秒量。不算高风险：只夹即时治疗的结果。

## 4. 验收

游戏设计第 3 节。特效不测。
