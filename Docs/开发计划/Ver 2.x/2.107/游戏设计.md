# 2.107 游戏设计：智力或信仰不够放不出法术

> **交付目标：智力或信仰低于法术自己的要求时，不放出，专注不减。只是催化器需求不够仍不在这一版。**

来源：[FR-属性-06](../../../需求文档/功能需求/属性与升级.md)。施法入口已经挡过一次。这一版让投射和治疗在扣专注之前再挡一次。

## 1. 为什么是这一刀

要求不满足时不该放出，也不该先把专注扣掉。

## 2. 做完之后

智力要求 20、智力 19：放不出，专注不变。信仰要求 15、信仰 14：同样。

两项都达到，或要求是 0：这道门打开。蓝不够仍走原来的失败。

催化器属性不够仍放出、但威力削弱，不在这一版。
