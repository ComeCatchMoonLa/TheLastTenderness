# 2.108 技术设计：不允许附魔的武器涂不上

> **涂抹先问 `CanApply`。不行就不留下附加段，也不在这条路径里改专注。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 涂抹

[`SpellBuff.TryCoat`](../../../../Assets/Scripts/Items/Spells/SpellBuff.cs) 把武器的注入和不能附魔交给 [`WeaponBuff.TryApply`](../../../../Assets/Scripts/Items/Equipment/Weapons/WeaponBuff.cs)。返回假时附加段不在。方法不接收专注，所以不扣也不退。

允许名单仍是空注入、重、锐、精、原质、空虚。`cannotBuff` 为真时涂不上。

## 2. 测试

[`Assets/Tests/EditMode/Spells/SpellBuffTests.cs`](../../../../Assets/Tests/EditMode/Spells/SpellBuffTests.cs)。

## 3. 不做

不决定失败扣不扣蓝。不消耗道具。不改弓、盾、Boss 魂的例外名单。不算高风险：只是涂不上时不留段。

## 4. 验收

游戏设计第 3 节。进游戏涂抹不测。
