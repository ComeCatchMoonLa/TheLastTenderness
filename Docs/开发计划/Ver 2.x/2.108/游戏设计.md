# 2.108 游戏设计：不允许附魔的武器涂不上

> **交付目标：不允许附魔的武器涂不上，命中没有这段附加伤害。失败扣不扣蓝这一版不选。**

来源：[FR-注入-08](../../../需求文档/功能需求/注入与强化.md)。涂得上的名单和持续时间已经在。这一版补上涂不上时不留下这段伤害。

## 1. 为什么是这一刀

标成不能附魔，或注入不在允许名单里，再涂不该多出伤害。

## 2. 做完之后

不能附魔，或注入是火：涂不上，没有附加段。

未注入、重、锐、精、原质、空虚：涂得上，附加段在。

这条路径不改专注。失败时扣不扣蓝仍留给后面的核对，这一版不选扣，也不做退回。

## 3. 验收

Edit Mode：涂不上时附加段不在；允许的注入涂得上。不进游戏涂松脂。
