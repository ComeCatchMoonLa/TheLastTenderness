# 2.109 技术设计：武器兼作催化器

> **武器种类不是无、且和当前法术同一系，战技才放出。不合就不放出。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 判定

[`WeaponCatalyst.Decide`](../../../../Assets/Scripts/Items/Spells/WeaponCatalyst.cs) 用法术种类和 [`CatalystMatch.Allows`](../../../../Assets/Scripts/Items/Spells/CatalystMatch.cs)。种类是无，返回不是催化器。种类不是无但没有法术或学派不合，返回不放出。相符则返回放出。

## 2. 战技

[`PlayerCombatManager`](../../../../Assets/Scripts/Character/Player/PlayerCombatManager.cs) 的轻点战技，在选定武器之后：放出就走现有施法入口；不放出就停住；不是催化器才走原来的武器动作。轻击和重击不改。

## 3. 测试

[`Assets/Tests/EditMode/Spells/WeaponCatalystTests.cs`](../../../../Assets/Tests/EditMode/Spells/WeaponCatalystTests.cs)。

## 4. 不做

不乘武器法术威力。不做奇迹战技的自伤。不新做模型。不算高风险：只在种类不是无时改战技去向。

## 5. 验收

游戏设计第 3 节。进游戏按键不测。
