# 2.109 游戏设计：武器兼作催化器

> **交付目标：标成催化器的武器能放出对应系的法术。学派不合时不放出。**

来源：[FR-法术-11](../../../需求文档/功能需求/法术.md)。法杖、铃、护符、火焰与学派是否相符已经在。这一版让标了催化器种类的武器走同一条。

## 1. 为什么是这一刀

战技键要能放出当前法术里和这把武器同一系的那一记。

## 2. 做完之后

法杖配咒术、铃或护符配奇迹、火焰配火术：战技放出这一记。

种类不是无，但学派不合，或当前没有法术：不放出。

种类是无：战技仍走原来的武器动作。轻击、重击不改。

自伤换增伤，以及按武器法术威力乘算，不在这一版。

## 3. 验收

Edit Mode：上面三组真假。不创建武器模型，不进游戏按战技。
