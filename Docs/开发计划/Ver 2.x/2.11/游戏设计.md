# 2.11 游戏设计：状态页能读已有等级和灵魂

> **交付目标：分页窗里能打开状态页，读到已有的八项等级和身上的灵魂。换装不改这些数。这一页不能加点。**

来源是候选「状态页能读九项，本页不能加点」。体力和幸运没有字段，本版不补这两项，也不编幸运的效果。

## 1. 为什么是这一刀

[FR-属性-03](../../../需求文档/功能需求/属性与升级.md) 要在现有分页窗上读生命、精力、专注、力量、敏捷、智力、信仰和灵魂。`poiseLevel` 已经在 `CharacterStatsManager` 上，一并读出，文案是韧性。FR-菜单-05 里的名字、灵魂等级、负重、攻击力、吸收和下一级所需灵魂不在本版。

## 2. 做完之后

现有「技能」按钮改标成「状态」。点它打开状态页，别的子窗口关掉。页上是八行等级和一行灵魂：生命、精力、专注、韧性、力量、敏捷、智力、信仰、灵魂。数字来自 `healthLevel`、`staminaLevel`、`focusLevel`、`poiseLevel`、`strengthLevel`、`dexterityLevel`、`intelligenceLevel`、`faithLevel` 和 `soulCount`。

换上或卸下护甲、武器，这些等级和灵魂不变。这一页没有确认加点，也不改等级和灵魂。关上分页窗后战斗 HUD 仍在。

## 3. 验收

Edit Mode：给定八项等级和灵魂，读出的文本就是这九行，不含「体力」「幸运」「加点」。不创建窗口。

要人看的一条：打开分页窗，点「状态」，八项和灵魂是当前角色的数；换装后数字不变；这一页没有加点。这一条不进 Test Runner。
