# 2.110 技术设计：双手持握用提高后的力量

> **比力量需求之前，先把双手力量收成向下取整的 1.5 倍，封顶 99。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 有效力量

[`TwoHandStrength.ForNeed`](../../../../Assets/Scripts/Items/Equipment/Weapons/TwoHandStrength.cs)：不是双手时原样返回。双手时用整数 `力量 × 3 / 2`，大于 99 则 99。

[`RequirementPenalty.TryScale`](../../../../Assets/Scripts/Items/Equipment/Weapons/RequirementPenalty.cs) 增加是否双手。只有力量这一项用上面的数去比。其余四项仍用原来的等级。

## 2. 测试

[`Assets/Tests/EditMode/Weapons/TwoHandStrengthTests.cs`](../../../../Assets/Tests/EditMode/Weapons/TwoHandStrengthTests.cs)。

已有 [`RequirementPenaltyTests`](../../../../Assets/Tests/EditMode/Weapons/RequirementPenaltyTests.cs) 补上新参数，单手结果不变。

## 3. 不做

不乘力量补正。不改战技威力。不成对武器另写例外。不把这段接进挥击动画。不算高风险：只改拿来比需求的力量。
