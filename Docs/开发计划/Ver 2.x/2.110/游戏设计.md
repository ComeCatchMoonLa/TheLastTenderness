# 2.110 游戏设计：双手持握用提高后的力量

> **交付目标：双手持握时，按提高后的力量看武器的力量需求。**

来源：[FR-养成-04](../../../需求文档/功能需求/角色养成.md)。需求不足时更慢、打中更弱已经在。这一版只改拿来比力量需求的那个数。

## 1. 为什么是这一刀

单手力量不够的武器，双手按倍率之后应该够。敏捷、智力、信仰、幸运不够时，双手仍然不够。

## 2. 做完之后

有效力量 = 向下取整(力量 × 1.5)，封顶 99。66 力量双手按 99 计。

力量需求 14、力量 10：单手仍按不足结算；双手按 15，这一项不再不足。另一项仍不足时，双手仍然不足。

力量补正、战技威力、成对武器不加成，不在这一版。
