# 2.111 技术设计：灵魂等级是九项之和减 89

> **灵魂等级是九项相加再减 89。状态页打开时写出这个数。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 公式

[`SoulLevel.From`](../../../../Assets/Scripts/Character/SoulLevel.cs) 把生命、专注、耐力、体力、力量、敏捷、智力、信仰、幸运相加，再减 89。

[`CharacterStatsManager`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 补 `vitalityLevel` 和 `luckLevel`，默认 10，和另外七项的默认一样。韧性不传入。

## 2. 状态页

[`StatusWinManager`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/Status%20Window/StatusWinManager.cs) 在现有正文后加一行灵魂等级。不写「体力」「幸运」这两个字。

## 3. 测试

[`Assets/Tests/EditMode/Stats/SoulLevelTests.cs`](../../../../Assets/Tests/EditMode/Stats/SoulLevelTests.cs)。

## 4. 不做

不写重生。不写约尔的免费升级入口。不在状态页列出体力和幸运。不算高风险：只加这个和。

## 5. 验收

游戏设计第 3 节。打开窗口不测。
