# 2.111 游戏设计：灵魂等级是九项之和减 89

> **交付目标：灵魂等级等于九项之和减 89。九项全是 99 时是 802。**

来源：[FR-养成-09](../../../需求文档/功能需求/角色养成.md)。状态页已经能读八项等级和灵魂。这一版补上灵魂等级这个数。

## 1. 为什么是这一刀

灵魂等级是九项已经点过的总和，不是另外存的一个等级。

## 2. 做完之后

九项是生命、专注、耐力、体力、力量、敏捷、智力、信仰、幸运。韧性不计入。

九项都是 10 时，灵魂等级是 1。都是 99 时是 802。其中一项加一，灵魂等级加一。

状态页写出这个数。体力和幸运的名字还不写在这一页上。重生还不在。

## 3. 验收

Edit Mode：1、802，以及加一之后。不打开状态窗口。
