# 2.112 技术设计：备用武器和戒指计入负重

> **当前负重是六格武器和四枚戒指的重量和。弹药不参与。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 合计

[`Item`](../../../../Assets/Scripts/Items/Item.cs) 增加 `weight`。0 是合法重量。

[`EquipLoad.Total`](../../../../Assets/Scripts/Items/Equipment/EquipLoad.cs) 把左右手槽和戒指槽里非空的 `weight` 相加。不接收弹药。空数组按 0。

## 2. 测试

[`Assets/Tests/EditMode/Equipment/EquipLoadTests.cs`](../../../../Assets/Tests/EditMode/Equipment/EquipLoadTests.cs)。

## 3. 不做

不加护甲重量。不写负重上限。不改翻滚。不算高风险：只加这个和。

## 4. 验收

游戏设计第 3 节。翻滚不测。
