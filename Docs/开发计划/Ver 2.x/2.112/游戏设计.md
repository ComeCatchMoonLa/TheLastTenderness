# 2.112 游戏设计：备用武器和戒指计入负重

> **交付目标：备用武器和戒指计入当前负重。弹药不计入。**

来源：[FR-装备-08](../../../需求文档/功能需求/装备与道具.md)。左右手各三格和四枚戒指已经有槽。这一版让槽里的重量加进当前负重。

## 1. 为什么是这一刀

武器留在备用格，或戴上有重量的戒指，当前负重应该上去。只放进背包、或只装卸箭和螺栓，不应该变。

## 2. 做完之后

左右手六格里每一把非空武器，按它的重量计入。四枚戒指同样计入。空格是 0。

把备用格里的武器拿掉，负重下降刚才那一截。给弹药改重量，合计不变。

护甲重量、负重上限和翻滚档不在这一版。

## 3. 验收

Edit Mode：备用武器和戒指让合计上升，拿掉后回落；弹药重量变化不改合计。不进游戏看翻滚。
