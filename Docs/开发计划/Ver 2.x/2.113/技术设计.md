# 2.113 技术设计：清除暗印后窃火不再成立

> **暗印已清除时，窃火旗标不成立。终局仍用原来的三条选择。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 旗标

[`Usurpation.Holds`](../../../../Assets/Scripts/World/Usurpation.cs)：已清除则返回假，否则返回原来的窃火旗标。

[`PlayerStatsManager`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 增加 `darkSigilsCleared`，默认假。

[`EndingMarker`](../../../../Assets/Scripts/World/EndingMarker.cs) 先问 `Holds`，再交给 [`EndingChoice.Choose`](../../../../Assets/Scripts/World/EndingChoice.cs)。

## 2. 测试

[`Assets/Tests/EditMode/World/UsurpationTests.cs`](../../../../Assets/Tests/EditMode/World/UsurpationTests.cs)。

## 3. 不做

不数 8 枚。不扣清除费用。不改空虚外形。不算高风险：只在清除后拿掉窃火。

## 4. 验收

游戏设计第 3 节。终局场景不测。
