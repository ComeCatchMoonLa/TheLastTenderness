# 2.113 游戏设计：清除暗印后窃火不再成立

> **交付目标：清除暗印之后，窃火旗标不再成立。终局改走其余两条。**

来源：[FR-周目-07](../../../需求文档/功能需求/周目与结局.md)。终局一次交互只进一条已经在。这一版让清除暗印拿掉窃火。

## 1. 为什么是这一刀

暗印还在时可以是窃火。清除之后，同一次交互不该再结算成窃火。

## 2. 做完之后

窃火旗标为真、暗印未清除：仍是窃火。

暗印已清除：不再是窃火。眼和符都齐了是灭火，否则是传火。

8 枚门槛、付清灵魂和空虚外形不在这一版。

## 3. 验收

Edit Mode：清除前后的三条结算。不进终局场景。
