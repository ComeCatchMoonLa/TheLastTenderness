# 2.114 技术设计：法术行为分组

> **同层同组顶替。段数是命中次数。雾伤是最大生命乘资产上的比例。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 身体增益

[`BodyBuffs`](../../../../Assets/Scripts/Items/Spells/BodyBuffs.cs) 用层和组名。`TryPut` 在组名空着时打出资产名和 `group`，列表不变。同层同组先删掉旧的再放入。不同层保留。

[`PlayerStatsManager`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 持有这份列表。坐下休息成功时 [`CampFireInteractable`](../../../../Assets/Scripts/Items/Interactions/CampFireInteractable.cs) 把它清掉。

## 2. 段数和雾

[`SpellBehavior.Strikes`](../../../../Assets/Scripts/Items/Spells/SpellBehavior.cs) 小于 1 时按 1。[`ProjectileSpell`](../../../../Assets/Scripts/Items/Spells/ProjectileSpell.cs) 用自己的 `pelletCount` 调用它。

`TryAreaDamage` 在比例没填或小于等于 0 时打出资产名和 `areaPercent`，不扣血。填了则是最大生命乘比例。

[`Assets/Tests/EditMode/Spells/SpellBehaviorTests.cs`](../../../../Assets/Tests/EditMode/Spells/SpellBehaviorTests.cs)。

## 4. 不做

不写追踪、爆炸、连跳。不写雾的自伤。不写前摇打断时扣不扣蓝。不乘催化器法术威力。不算高风险：只加这三笔结算。
