# 2.114 游戏设计：法术行为分组

> **交付目标：身体增益按层和组顶替；多发各算一次命中；雾伤按最大生命的比例扣。**

来源：[FR-法术-09](../../../需求文档/功能需求/法术.md)。持续治疗和投射扣血已经在。这一版补行为类型上的这三笔结算。

## 1. 为什么是这一刀

同一种身体增益不该叠两份。多发不该只算一发。雾伤按最大生命走，不按固定点数。

## 2. 做完之后

身体增益分消耗品、战技、法术三层。同一层、同一个组，后放的留下，先放的消失。不同层可以同时在。组名空着就报出资产名，这一下不挂上。

坐下休息，身上的身体增益清掉。

投射或近身的段数大于 1 时，命中次数等于段数。雾的比例填了，伤害等于最大生命乘这个比例。比例没填就报出资产名，这一下不扣。

追踪、爆炸、连跳、前摇被打断扣不扣蓝，不在这一版。雾的自伤不在这一版。

## 3. 验收

Edit Mode：同层同组只留后一个，不同层都在，休息后清空；三段是三次命中；最大生命 100、比例 0.1 扣 10。不放施法动画。
