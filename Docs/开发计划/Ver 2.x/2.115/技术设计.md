# 2.115 技术设计：其余体型不进背刺

> **头目或大型不允许背刺。按下走原来的轻击。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 体型

[`BackstabBody.Allows`](../../../../Assets/Scripts/Character/BackstabBody.cs)：`isBoss` 或 `largeBody` 为真时返回假，否则返回真。

[`EnemyAISettings`](../../../../Assets/Scripts/Character/NPC/Enemy%20A.I%20Settings/EnemyAISettings.cs) 增加 `largeBody`。

[`CriticalAttackAction.Choose`](../../../../Assets/Scripts/Items/0%20Item%20Actions/CriticalAttackAction.cs) 增加是否允许背刺。不允许时，背后角度返回轻击。出手时用目标的这两项。

## 2. 测试

[`Assets/Tests/EditMode/Combat/BackstabBodyTests.cs`](../../../../Assets/Tests/EditMode/Combat/BackstabBodyTests.cs)。

## 3. 不做

不写野兽。不改弹反制裁。不改鞭。不算高风险：只在背刺前多看这两项。

## 4. 验收

游戏设计第 3 节。动画不测。
