# 2.116 技术设计：休息死亡和读档后敌人刷新

> **谁回来由 `AreaRefresh.Returns` 决定。回来就放到放置点并满血。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 谁回来

[`AreaRefresh.Returns`](../../../../Assets/Scripts/Character/NPC/AreaRefresh.cs)：剧情 NPC 和头目不回。拟态、结晶蜥蜴只有没死才回。一次性的看 `oneShotReturns`。其余回。

[`EnemyAISettings`](../../../../Assets/Scripts/Character/NPC/Enemy%20A.I%20Settings/EnemyAISettings.cs) 增加拟态、结晶蜥蜴、一次性和会不会刷新。

## 2. 何时

[`EnemyStatsManager.RestoreAfterRest`](../../../../Assets/Scripts/Character/NPC/EnemyStatsManager.cs) 先问 `Returns`，会回才用现有的放置点恢复。死亡时会回的先藏起来，不再直接删掉。

[`PlayerStatsManager`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 在生命降到 0 时对场上敌人做同一次恢复。
