# 2.116 游戏设计：休息死亡和读档后敌人刷新

> **交付目标：休息和死亡后，已写明会刷新的敌人回到放置点并满血。头目不因此回来。**

来源：[FR-敌人-06](../../../需求文档/功能需求/敌人.md)。近战死亡后休息能回来已经在。这一版按种类决定谁回来。

## 1. 为什么是这一刀

普通敌人该回来。打死的头目、拟态、结晶蜥蜴不该跟着休息复活。

## 2. 做完之后

普通敌人，不论死活，回到放置点并满血。

头目不回来。剧情 NPC 不走这条。打死的拟态不回来，没死的会回。打死的结晶蜥蜴不回来，没死的会回。一次性的只在资产写明会刷新时回来。

玩家死亡时也走这一条。休息清掉身上的异常、地上的掉落、雾门和机关，不在这一版。仓库里没有读档入口，这一版不新做存档；读档要走同一条判定。
