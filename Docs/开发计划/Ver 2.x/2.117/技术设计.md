# 2.117 技术设计：戒指加成

> **四格里按族名戴上。攻击、减伤、属性读戒指上的数。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 戴上

[`Item`](../../../../Assets/Scripts/Items/Item.cs) 增加 `ringFamily`、`attackBonus`、`absorptionBonus`、`attributeBonus`。

[`RingWear.TryPut`](../../../../Assets/Scripts/Items/Equipment/RingWear.cs) 只看前四格。族名空着时打出资产名和 `ringFamily`，不戴。同族已在则失败。没有空格则失败。

[`RingWear.TryRemove`](../../../../Assets/Scripts/Items/Equipment/RingWear.cs) 摘下这一枚。

[`PlayerInventoryManager`](../../../../Assets/Scripts/Character/Player/PlayerInventoryManager.cs) 的 `TryWearRing` / `TryRemoveRing` 调用它们。

## 2. 加成

[`RingBonus`](../../../../Assets/Scripts/Items/Equipment/RingBonus.cs) 把戴着的三项分别相加。

[`DamageCollider.DealDamage`](../../../../Assets/Scripts/Damage/Damage%20Collider/DamageCollider.cs) 给攻击者的物理伤害加上攻击加成，再减去防御者的减伤，不低于 0。

[`StatusWinManager`](../../../../Assets/Scripts/UI/Player%20UI/Tap%20Windows/Status%20Window/StatusWinManager.cs) 显示的力量加上属性加成。

## 3. 测试

[`Assets/Tests/EditMode/Equipment/RingBonusTests.cs`](../../../../Assets/Tests/EditMode/Equipment/RingBonusTests.cs)。

## 4. 不做

不写负重、翻滚、保魂、跌落、空虚外形和联机。不算高风险：只加这一类读数。

## 5. 验收

游戏设计第 3 节。模型不测。
