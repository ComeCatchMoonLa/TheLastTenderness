# 2.117 游戏设计：戒指加成

> **交付目标：戴上后攻击、减伤或属性与摘下时不同。第五枚戴不上。同名各档不能同戴。**

来源：[FR-注入-07](../../../需求文档/功能需求/注入与强化.md)。四格已经在。这一版写加成这一类。

## 1. 为什么是这一刀

戴上和摘下，攻击、减伤或属性应该不一样。第五枚没有格子。同一枚的各档不能叠戴。

## 2. 做完之后

戒指写出族名。族名空着就报出资产名，戴不上。

同一族已经戴着，再戴一档失败，原来的还在。不同族可以一起戴，最多四枚。第五枚留在外面。

攻击加成加在打出去的物理伤害上。减伤从受到的物理伤害里减去，减完不低于 0。属性加成加在状态页的力量上。摘下后这三项回到没有戒指的数。

负重、翻滚、保魂、跌落、遮住空虚和联机戒指不在这一版。

## 3. 验收

Edit Mode：戴上后三项变了，摘下后回到原值；同族第二档失败；四枚满了再戴失败。不戴模型。
