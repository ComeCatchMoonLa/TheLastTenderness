# 2.118 技术设计：戒指回复

> **回复量读戒指上的数，加进精力和一口瓶。次数不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 回复

[`Item`](../../../../Assets/Scripts/Items/Item.cs) 增加 `staminaRegenBonus`、`estusBonus`、`ashenBonus`。

[`RingRecovery`](../../../../Assets/Scripts/Items/Equipment/RingRecovery.cs) 把戴着的前四格分别相加。

[`PlayerStatsManager.RegenerateStamina`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 在这一跳的回复量上加上精力回复。

[`PlayerInventoryManager.TryGetFlaskSip`](../../../../Assets/Scripts/Character/Player/PlayerInventoryManager.cs) 在表上的一口之外加上对应瓶的加成。不改瓶的次数。

## 3. 不做

不改翻滚、负重、保魂。不重写四格规则。不算高风险：只加这一类读数。
