# 2.118 游戏设计：戒指回复

> **交付目标：戴上后精力回复或一口瓶量与摘下时不同。次数不变。**

来源：[FR-注入-07](../../../需求文档/功能需求/注入与强化.md)。四格和同族规则在 2.117。这一版写回复。

## 1. 为什么是这一刀

回复戒指该让回精力更快，或让血瓶、灰瓶一口更多。喝的次数不该跟着变。

## 2. 做完之后

精力回复加上戒指上的回复量。血瓶一口加上血瓶加成，灰瓶一口加上灰瓶加成。摘下后回到不加的数。

瓶的次数不改。第五枚和同族各档仍按 2.117。

## 3. 验收

Edit Mode：戴上后回复变多，摘下后回到原值，次数不变。不戴模型。
