# 2.12 技术设计：角度不够时只是背后一刀

> **没命中，或点积不在背刺和处决窗口里，就调用当前右手武器的轻击。窗口不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CriticalAttackAction.PerformAction` 在无敌时直接返回。射线命中后，`canBeRiposted` 且点积在 `0.8` 到 `1` 时处决，点积在 `-1` 到 `-0.8` 时背刺。其余情况这次按键结束。

轻击是 `LightAttackAction`，挂在武器的 `oh_tap_e_action` 上。精力不大于 0 时它自己返回。

## 2. 改法

`CriticalAttackAction.Choose(bool hit, float dot, bool canBeRiposted)`：

- 命中、可处决、点积在 `0.8` 到 `1`：处决。
- 命中、点积在 `-1` 到 `-0.8`：背刺。
- 其余：轻击。

处决和背刺仍走现有的 `AttempRiposte`、`AttempBackStab`。轻击调用 `cInventory.rightWeapon.oh_tap_e_action`。右手武器为空、轻击槽为空，或轻击槽就是这次动作，打出名字后返回，不调用。

无敌时仍在选择之前返回。

## 3. 单元测试

`Assets/Tests/EditMode/CriticalAttackChoiceTests.cs`。

断言背后窗口是背刺，正面可处决是处决，站偏和没有命中是轻击。不创建 Animator，不调用 `PerformAction`。

## 4. 不做

不改 `-0.8` 和 `0.8`。不改背刺伤害。不把轻击再写一份。
