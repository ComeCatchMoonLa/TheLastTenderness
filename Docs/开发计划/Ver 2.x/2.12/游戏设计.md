# 2.12 游戏设计：角度不够时只是背后一刀

> **交付目标：不在背后角度内时这一下是普通轻击，不锁背刺动画。**

来源：[FR-处决-02](../../../需求文档/功能需求/背刺与处决.md)。

## 1. 为什么是这一刀

`CriticalAttackAction` 在点积 `-1` 到 `-0.8` 时已经播背刺。角度外现在什么都不做。需求是 [FR-处决-02](../../../需求文档/功能需求/背刺与处决.md)。

## 2. 做完之后

角度外走普通轻击，不锁背刺动画。不改 `-0.8` 到 `-1` 这个窗口。不写背刺伤害倍率。

## 3. 验收

Edit Mode：角度内仍进背刺；角度外是普通轻击，不锁背刺。不创建 Animator。

要人看的一条：站偏或站远再按轻击，是普通一刀。这一条不进 Test Runner。
