# 2.120 游戏设计：戒指发现力

> **交付目标：戴上后发现力与摘下时不同。**

来源：[FR-注入-07](../../../需求文档/功能需求/注入与强化.md)。发现力底子是 100 加幸运。这一版让戒指上的固定数加进去。

## 1. 为什么是这一刀

状态页上的发现力，戴上和摘下应该不一样。

## 2. 做完之后

发现力 = 100 + 幸运 + 戴着的发现力加成。摘下后回到 100 + 幸运。

两枚戒指各自加自己写下的数。金币和特定戒指之间的乘法不在这一版。第五枚和同族各档仍按 2.117。

## 3. 验收

Edit Mode：幸运 10、加成 50 时是 160；摘下后是 110。不打开状态窗口。
