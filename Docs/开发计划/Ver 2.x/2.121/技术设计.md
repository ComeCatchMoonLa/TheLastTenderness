# 2.121 技术设计：弹药为零没有飞行物

> **剩余小于或等于 0 时只播拉弓，不进入射出。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 空拉

[`EmptyDraw.Plays`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/EmptyDraw.cs) 在剩余小于或等于 0 时为真。片段名是已有的 `Aiming - Start`。

[`ShootArrowAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/ShootArrowAction.cs) 和 [`AimAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/Bow/AimAction.cs) 在此为真时播这段并返回，不扣弹、不生成。

[`CharacterAnimatorManager.SuccessfullyGetArrow`](../../../../Assets/Scripts/Character/CharacterAnimatorManager.cs) 在没有当前弹，或剩余小于或等于 0 时不放弦上模型。

## 2. 测试

[`Assets/Tests/EditMode/Combat/EmptyDrawTests.cs`](../../../../Assets/Tests/EditMode/Combat/EmptyDrawTests.cs)。

## 3. 不做

不重写有弹才取一发。不新做举弩片段。不算高风险：只补空拉。

## 4. 验收

游戏设计第 3 节。进游戏拉弓不测。
