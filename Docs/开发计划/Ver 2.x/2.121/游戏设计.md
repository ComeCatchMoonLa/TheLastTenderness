# 2.121 游戏设计：弹药为零没有飞行物

> **交付目标：数量为 0 时仍播拉弓或举弩，不生成飞行物，不扣弹，弦上不出现新箭。**

来源：[FR-远程-03](../../../需求文档/功能需求/箭矢与弩.md)。不生成、不扣弹已经在。这一版只补空拉。

## 1. 为什么是这一刀

弹打光后再拉，人应该做出拉弓或举弩，而不是什么都不播。场上不该多出一发。

## 2. 做完之后

剩余小于或等于 0：播已有的 `Aiming - Start`，不生成飞行物，不扣弹，不往弦上放模型。弩没有单独片段，也播这一段。

剩余大于 0：仍走原来的射出。

有弹才取一发，不在这一版重写。

## 3. 验收

Edit Mode：0 是空拉，1 不是。不进游戏拉弓。
