# 2.122 游戏设计：弩和螺栓、大弓和大箭各用各的

> **交付目标：弩只吃螺栓，大弓只吃大箭。对不上时有射击动作，没有飞行物。**

来源：[FR-远程-02](../../../需求文档/功能需求/箭矢与弩.md)。弓射出箭已经在。这一版补弹种是否对得上。

## 1. 为什么是这一刀

手上是普通弓、槽里是大箭，不该飞出一发。大弓配普通箭也一样。

## 2. 做完之后

弓配箭、弩配螺栓、大弓配大箭：可以生成飞行物。

对不上：播射出动作，不生成飞行物，不扣弹。

箭槽和螺栓槽分成两格，不在这一版。不新做弩、大弓、螺栓、大箭的模型。

## 3. 验收

Edit Mode：上面几组真假。不进游戏射。
