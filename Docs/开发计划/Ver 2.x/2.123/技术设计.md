# 2.123 技术设计：状态弹推进对应的槽

> **命中时按弹上的槽调用一次。没配就不调用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 槽

[`AmmoItem`](../../../../Assets/Scripts/Items/Equipment/Weapons/Ammo/AmmoItem.cs) 增加 `statusSlot` 和 `statusGain`。

[`AmmoStatus.Apply`](../../../../Assets/Scripts/Items/Equipment/Weapons/Ammo/AmmoStatus.cs)：`None` 或积蓄小于或等于 0 时返回，槽不变。否则只调用毒、出血、冰霜、咒死里对上的那一个。

出血槽记在 [`CharacterStatsManager`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 的 `bleedMeter`。容量没填时沿用积蓄原有的报错，这一下不加。

[`AmmoDamageCollider`](../../../../Assets/Scripts/Damage/Damage%20Collider/AmmoDamageCollider.cs) 打中角色时调用 `Apply`。
