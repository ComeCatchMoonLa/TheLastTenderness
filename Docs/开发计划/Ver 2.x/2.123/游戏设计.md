# 2.123 游戏设计：状态弹推进对应的槽

> **交付目标：配了异常的弹打中后，只推进它配置的那一种槽。普通弹不推进。**

来源：[FR-远程-05](../../../需求文档/功能需求/箭矢与弩.md)。弓已经能射出。这一版补命中时的那一槽。

## 1. 为什么是这一刀

毒弹不该把出血槽一起抬上去。普通弹不该抬任何异常槽。

## 2. 做完之后

弹上写了毒、出血、冰霜或咒死，并且积蓄大于 0：打中只推进这一槽。

没写，或积蓄小于或等于 0：各槽都不变。

近战积蓄、槽往回掉、喝苔清槽，不在这一版。不新做弹的模型。

## 3. 验收

Edit Mode：毒弹只抬毒槽；出血弹只抬出血槽；普通弹都不抬。不进游戏射。
