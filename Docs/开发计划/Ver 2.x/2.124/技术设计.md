# 2.124 技术设计：立起互斥旗标后另一条关掉

> **标成会关另一条的交付成功时，立旗并关掉另一条。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 交付

[`ExclusiveFlag.Raise`](../../../../Assets/Scripts/Items/Interactions/ExclusiveFlag.cs) 把旗标写成真，另一条 `open` 写成假、`failed` 写成真。`CanTalk` 是开着且未失败。

[`Talk`](../../../../Assets/Scripts/Items/Interactions/Talk.cs) 增加 `closesOtherLine`。`Give` 成功并且这一项为真时调用 `Raise`。不成功不调用。

## 2. 测试

[`Assets/Tests/EditMode/Dialogue/ExclusiveFlagTests.cs`](../../../../Assets/Tests/EditMode/Dialogue/ExclusiveFlagTests.cs)。一次交付，不写支线。

## 3. 不做

不写休息。不写苍白舌头和具体 NPC。不改已经收尾的普通赠送。不算高风险：只加这一下立旗。

## 4. 验收

游戏设计第 3 节。进游戏找人不测。
