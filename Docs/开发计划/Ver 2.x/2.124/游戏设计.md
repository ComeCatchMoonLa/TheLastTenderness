# 2.124 游戏设计：立起互斥旗标后另一条关掉

> **交付目标：做一次会立旗的交付之后，互斥旗标立起，另一条关掉。还开着的这条仍能对话。**

来源：[FR-任务-07](../../../需求文档/功能需求/任务与NPC.md)。不写是哪一个 NPC，也不写完整支线。休息打不打开不在这一版。

## 1. 为什么是这一刀

交出去的这一下会关掉另一条。被关掉的人不再协助。交出的这一边还开着。

## 2. 做完之后

这次交付成功：旗标立起，另一条开着变成关、并标成失败。交出的这一边不因此失败。

交付不成功：旗标不立，另一条仍开着。

休息不在这一版。

## 3. 验收

Edit Mode：成功交付后另一条不能对话，这一边还能。失败的交付不立旗。不进游戏找 NPC。
