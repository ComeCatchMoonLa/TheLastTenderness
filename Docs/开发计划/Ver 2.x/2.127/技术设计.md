# 2.127 技术设计：离线时教堂枪兵由本地角色顶上

> **离线时返回传入的本地角色。不在场景里查找。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 对手

[`ChurchSpear.Opponent`](../../../../Assets/Scripts/World/ChurchSpear.cs)：离线且本地角色已填，返回它。本地没填时打出资产名和 `local`，返回空。在线返回空。

[`WorldEventManager.ChurchOpponent`](../../../../Assets/Scripts/World/WorldEventManager.cs) 把这场的名字传进去。不改开战碰撞体，不在场景里摆人。

## 2. 测试

[`Assets/Tests/EditMode/World/ChurchSpearTests.cs`](../../../../Assets/Tests/EditMode/World/ChurchSpearTests.cs)。本地角色在测试里创建。

不接在线匹配。不改生命上限和碎片。不算高风险：只决定离线时对手是谁。
