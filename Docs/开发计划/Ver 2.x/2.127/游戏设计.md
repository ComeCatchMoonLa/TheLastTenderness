# 2.127 游戏设计：离线时教堂枪兵由本地角色顶上

> **交付目标：离线时，这场的对手是传入的本地角色。不是一名不存在的远端玩家。**

来源：[FR-联机-08](../../../需求文档/功能需求/联机.md)。在线匹配不接。不在场景里摆人。

## 1. 为什么是这一刀

离线走进去，血条上的对手得是已经交给这场的本地角色。

## 2. 做完之后

离线、并且本地角色已填：对手就是这一个。

离线、本地没填：报出资产名，没有对手。

在线：这一版不返回远端玩家。

生命上限、药瓶、枪之碎片不在这一版。

## 3. 验收

Edit Mode：离线时对手是测试里建的那个本地角色。不进场景，不接匹配。
