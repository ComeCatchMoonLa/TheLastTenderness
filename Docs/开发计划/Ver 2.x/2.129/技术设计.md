# 2.129 技术设计：连续翻滚精力递增

> **幅度和停顿没填就报字段，不选数。填了才一档一档加。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 花费

[`RollChain.Cost`](../../../../Assets/Scripts/Character/Player/RollChain.cs) 看幅度、停顿、距上次成功翻滚的秒数和已经连了几次。付不起仍走现有的 `DeductStamina`：扣不成就不播。

[`PlayerLocomotionManager`](../../../../Assets/Scripts/Character/Player/PlayerLocomotionManager.cs) 只在翻滚上用它。后撤不走这条。

## 2. 测试

[`Assets/Tests/EditMode/Locomotion/RollChainTests.cs`](../../../../Assets/Tests/EditMode/Locomotion/RollChainTests.cs)。

## 3. 不做

不写死幅度和停顿秒数。不做第 23 帧才能再滚。不算高风险：只改这一次扣多少精力。

## 4. 验收

游戏设计第 3 节。连滚不测。
