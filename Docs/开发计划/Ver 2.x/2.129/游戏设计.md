# 2.129 游戏设计：连续翻滚精力递增

> **交付目标：连续翻滚每一次比上一次更费精力，停一拍之后回到基础消耗。加多少、停多久不在这一版里选。**

来源：[FR-移动-11](../../../需求文档/功能需求/玩家移动与闪避.md)。

## 1. 为什么是这一刀

不停顿地连着滚，后一次比前一次贵，贵到付不起就滚不出去。中间停够一拍，下一次又是基础消耗。

加多少、停多久，需求和调研都标了待核对。这两个数写在玩家移动上。没填就报出资产名和字段，仍只扣基础消耗，不自己选一个幅度。

第 23 帧才能再滚不在这一版。

## 2. 做完之后

字段填了：第一次扣基础；间隔没超过停顿，下一次扣基础加一档，再下一次再加一档。付不起时不播翻滚，精力不变。间隔超过停顿，下一次回到基础。

字段没填：报错，这次仍扣基础。

## 3. 验收

Edit Mode：用测试自己填的幅度和停顿，看第二次更贵、停顿后回到基础、没填时报字段。不进游戏连滚。
