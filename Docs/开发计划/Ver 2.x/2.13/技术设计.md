# 2.13 技术设计：在铁匠处确认分瓶，休息后写满

> **划分只改 `estusShare` 和 `ashShare`。休息成功才把剩余写成这两份上限。总次数不变。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`flaskTotal`、`estusShare`、`ashShare` 在 `PlayerInventoryManager`。休息调用 `RefillConsumablesToMax`，按每件消耗品自己的 `maxItemAmount` 写回，不看这两份划分。

## 2. 改法

加上 `estusLeft` 和 `ashLeft`。开局分别是 3 和 0。

`TryAllocateFlasks(int estus, int ash)`：两边都不是负数，并且相加等于 `flaskTotal` 时，只改 `estusShare` 和 `ashShare`。否则返回 false，划分和剩余都不变。

`Talk.offersFlaskSplit` 为真时，`AllocateFlasks` 把划分转给库存。不为真时返回 false。不新做人物。

`RefillConsumablesToMax` 开头把 `estusLeft`、`ashLeft` 写成当前划分。其余消耗品仍按 `maxItemAmount` 写回。

## 3. 单元测试

`Assets/Tests/EditMode/FlaskSplitTests.cs`。

总次数 4 时，划成 2 和 2 成功，剩余不变。相加不等于总次数时失败。调用写回后剩余等于划分。不创建对话窗。

## 4. 不做

不新做安德烈模型。不改交碎片和烧骨片。不在还没休息时把剩余写成满的。
