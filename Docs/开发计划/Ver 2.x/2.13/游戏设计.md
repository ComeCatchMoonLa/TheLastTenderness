# 2.13 游戏设计：在铁匠处确认分瓶，休息后写满

> **交付目标：在现有对话里改血瓶和灰瓶的分配，休息成功后两边剩余次数都是新的上限。总次数不变。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

`estusShare`、`ashShare` 和休息写回次数已经有。工程里没有安德烈。需求是 [FR-篝火-05](../../../需求文档/功能需求/篝火菜单.md)。

## 2. 做完之后

选择挂在现有 `Talk` 上，不新做人物。总次数不变，可以全给血瓶，也可以全给灰瓶。还没休息时，不把当前剩余改成新的满次数。休息成功后，两边剩余次数都是这一轮划分的上限。

## 3. 验收

Edit Mode：划分之后、休息之前，剩余次数不变；休息成功后两边都是新的上限，两边之和与划分前的总次数相同。不创建对话窗。

要人看的一条：在这名 NPC 处改分配再休息，两边都是满的。这一条不进 Test Runner。
