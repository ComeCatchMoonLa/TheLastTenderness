# 2.130 技术设计：休息清掉身上的异常

> **只把五条积蓄和三段持续时间写成 0。不改死亡，不改生命。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 清

[`AilmentRest.Clear`](../../../../Assets/Scripts/Character/AilmentRest.cs) 把毒、剧毒、出血、冰霜、咒死的积蓄，以及毒、剧毒、冰霜的剩余时间写成 0。不写 `isDead`，不写 `currentHP`。

[`CampFireInteractable`](../../../../Assets/Scripts/Items/Interactions/CampFireInteractable.cs) 在已经点燃、这次是坐下时调用它。
