# 2.130 游戏设计：休息清掉身上的异常

> **交付目标：坐下清掉毒、剧毒、出血、冰霜和咒死的积蓄，以及还在持续的毒、剧毒和冰霜。咒死已经致死的不因此站起来。**

来源：[FR-燃火-09](../../../需求文档/功能需求/燃火休息与死亡惩罚.md)。

## 1. 为什么是这一刀

坐下已经回满生命精力和专注，也已经让普通敌人回放置点。身上的毒、出血和咒死积蓄还在。

## 2. 做完之后

坐下：这五条的积蓄变成 0。毒、剧毒、冰霜还在跳的时间也变成 0。

咒死已经把人打死时，死亡和当前生命不动。清异常不把人拉起来。

门、拾取、回瓶、敌人刷新不在这一版。

## 3. 验收

Edit Mode：五条积蓄和三段持续时间清掉；容量还在；死亡仍为真，生命仍是清之前的数。不坐下，不刷新敌人。
