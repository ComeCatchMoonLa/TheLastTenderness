# 2.131 技术设计：耐久下降并按档减伤

> **七成和五成只写在 `DurabilityTier`。没填上限时系数是 1。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。
>
> 高风险：后面的伤害都乘这一档。系数写错，已有武器都会跟着错。

## 1. 档

[`DurabilityTier`](../../../../Assets/Scripts/Items/Equipment/DurabilityTier.cs) 给出系数、把伤害五段乘上、把减伤乘上、休息时修满或留在 0。挥击和挨打也从这里扣。

低于上限三成是 `current * 10 < max * 3`。到 0 含已经是负的。

[`WeaponItem`](../../../../Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs) 和 [`ArmorItem`](../../../../Assets/Scripts/Items/Equipment/Armor/ArmorItem.cs) 放上限、当前耐久，以及挥几次掉 1 点、挨打掉多少。戒指不加这些字段。

## 2. 接到伤害上

[`DamageCollider.DealDamage`](../../../../Assets/Scripts/Damage/Damage%20Collider/DamageCollider.cs) 在送出之前，按手里这把武器乘一次。法术和炸弹不走这里。

[`CharacterStatsManager.TakeDamage`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 按头、躯干、髋、手各自的系数乘减伤。系数默认 1。强韧和盾的抵挡不乘。

[`MeleeAttackSegment.Play`](../../../../Assets/Scripts/Items/0%20Item%20Actions/MeleeAttackSegment.cs) 在这一挥真的播出去时扣武器。踢不扣。

[`PlayerStatsManager.TakeDamage`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 挨打后扣身上护甲，并先按当前耐久写下四件的系数。

[`CampFireInteractable`](../../../../Assets/Scripts/Items/Interactions/CampFireInteractable.cs) 坐下时修背包和身上的武器护甲，再写下护甲系数。

## 4. 不做

不画耐久条。不改盾的抵挡和护甲强韧。不做修理粉、铁匠和月光大剑每次 4 点。不自己选 5～10 里的一个数。

游戏设计第 3 节。收尾前审查。进游戏打不测。
