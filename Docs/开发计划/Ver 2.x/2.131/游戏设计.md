# 2.131 游戏设计：耐久下降并按档减伤

> **交付目标：武器和护甲扣耐久。低于上限三成时伤害或减伤为七成，到 0 为五成。未破时休息修满，破了休息不修。**

来源：[FR-装备-12](../../../需求文档/功能需求/装备与道具.md)。

## 1. 为什么是这一刀

武器和护甲还没有耐久。后面的伤害都会乘这一档，系数只能有一处。

上限没填时不能当成已经破掉，否则现有武器都会变成五成伤害。

每挥 5～10 次掉 1 点是一段范围。护甲挨打掉多少没有写成一个数。这两个数写在武器和护甲上，没填就报字段，不扣。

## 2. 做完之后

上限填了：不低于三成时伤害和减伤不变；低于三成是七成；到 0 是五成。

上限没填：报出资产名和 `durabilityMax`，伤害和减伤仍是原来的。

挥击次数填了：够次数掉 1 点。护甲挨打掉的点数填了：挨打时扣。没填就报字段，不扣。已经是 0 不再往下扣。

大于 0 时坐下修满。已经是 0，坐下仍是 0。

盾的抵挡和护甲强韧不乘这一档。不画耐久条。

## 3. 验收

Edit Mode：三成这一档仍是原数，低于三成是 0.7，到 0 是 0.5；没填上限仍是 1。减伤按这一档乘。未破修满，破了不修。挥够次数掉 1 点，没填不扣。

不进游戏打。修理粉、铁匠、月光大剑每次 4 点不测。
