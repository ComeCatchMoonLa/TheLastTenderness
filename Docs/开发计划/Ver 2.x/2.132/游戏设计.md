# 2.132 游戏设计：掉落按配置掷骰

> **交付目标：敌人只掉自己表里的条目。必掉一定给。概率条目按发现力改掉率。没有保底。**

来源：[FR-敌人-08](../../../需求文档/功能需求/敌人.md)。实际掉率是发现力除以 100，再乘这条的基础掉率。发现力 100 是一倍，400 是四倍。

## 1. 为什么是这一刀

现在打死只给固定灵魂，不看掉落表。

过量击杀的门槛和灵魂倍数仍待核对，不在这一版。

## 2. 做完之后

必掉条目每次都进背包。概率条目用上面的掉率掷一次，各自独立，上次没出不加这次。

基础掉率没填就报出资产名和字段，这条不掉。表是空的就不掉。

发现力用已经算好的那个数。这一版不改戒指怎么叠。

## 3. 验收

Edit Mode：发现力 100 和 400 时同一条基础掉率相差四倍；必掉不看骰子；没填基础掉率不掉。不进游戏刷怪。
