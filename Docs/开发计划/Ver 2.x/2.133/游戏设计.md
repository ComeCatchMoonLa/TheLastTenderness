# 2.133 游戏设计：退回石和材料分段

> **交付目标：对上的退回石把注入退回未注入，加号留下。这一档的材料个数按资产扣。弓、弩、大弓、法器、火炬和盾不注入。**

来源：[FR-注入-09](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

注入现在换上就留着。普通、鳞片、闪耀的上限已经分开，每一档要几块材料还没按资产扣。

空虚幸运：需求写双手持最多按 +10 计，调研写左右手各一把加到最多 10、而且要空虚到 15 才有。不是同一句，不选公式。

板每周目几枚仍待核对，不写死。

## 2. 做完之后

退回石写明自己退哪一种注入。武器正是这一种时，注入清空，强化等级不动。不退宝石，不退灵魂。石头没写种类就报字段，不退。

这一档个数填了，手里够，而且没到这条路线的上限，就扣掉这么多个、等级加 1。个数没填就报字段，不升。普通上限 10，鳞片和闪耀上限 5。

弓、弩、大弓、三种法器、标成火炬的、盾，换不上注入。

## 3. 验收

Edit Mode：退回后注入空、等级还在；个数没填不升；弓和盾换不上。不进游戏找铁匠。空虚幸运不测。
