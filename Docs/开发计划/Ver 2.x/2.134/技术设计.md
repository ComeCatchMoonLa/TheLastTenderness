# 2.134 技术设计：其它消耗品

> **清哪一条、60 秒、每秒 6 或 9、+50 或 +100，都按已写的句子。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 效果

[`ConsumableEffect`](../../../../Assets/Scripts/Items/Consumables/ConsumableEffect.cs) 清出血、中毒、剧毒、冰霜和未满的咒死，并写下绿花和硬币的结束时间。

[`CharacterStatsManager`](../../../../Assets/Scripts/Character/CharacterStatsManager.cs) 留这四个数。[`PlayerStatsManager.RegenerateStamina`](../../../../Assets/Scripts/Character/Player/PlayerStatsManager.cs) 在原回复上加上绿花这一截。[`EnemyStatsManager.AwardDrops`](../../../../Assets/Scripts/Character/NPC/EnemyStatsManager.cs) 的发现力加上还没过期的硬币。

[`ListedConsumableItem`](../../../../Assets/Scripts/Items/Consumables/ListedConsumableItem.cs) 在成功帧调用效果，成功了才少一个。

## 3. 不做

不写祝福和隐秘祝福的回血量。不写打断后退不退。不做短索、引怪头骨和不死狩人护符。不算高风险：只加这些已写明的效果。
