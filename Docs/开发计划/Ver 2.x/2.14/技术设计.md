# 2.14 技术设计：附近有敌对者时坐不下去

> **半径空着就停。半径内有追击中的敌人时不休息。没有时休息与现在相同。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

已点燃的 `CampFireInteractable` 一交互就 `RestoreVitalsToMax`。敌人当前状态可以读，追击是 `PursueTargetState`。人形追击继承它。

## 2. 改法

`hostileRadius` 写在这堆火上。小于或等于 0 时打出物体名和 `hostileRadius`，然后返回，不休息。

`CampFireRest.Allow(radius, pursuingInside)`：半径不大于 0 为 false；否则没有追击中的敌人为 true。

`PursuingEnemyInside` 用 `OverlapSphere`，层是 `LayerMask.npc`，`CurrentState is PursueTargetState` 算在内。点火不受这一条影响。

## 3. 单元测试

`Assets/Tests/EditMode/CampFireRestTests.cs`。

断言半径 0 不允许，有追击不允许，半径为正且没有追击允许。不创建场景。

## 4. 不做

不写白幽灵和入侵者。不自己选一个米数。
