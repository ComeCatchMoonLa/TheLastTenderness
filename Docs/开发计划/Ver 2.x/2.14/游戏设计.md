# 2.14 游戏设计：附近有敌对者时坐不下去

> **交付目标：检测半径里有追击中的敌人时，已点燃的篝火不开始休息。对方死亡或离开后再坐下可以休息。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

`CampFireInteractable` 已经能休息。追击状态可以读。需求是 [FR-篝火-08](../../../需求文档/功能需求/篝火菜单.md)。白幽灵和入侵者不存在，不写。

## 2. 做完之后

检测半径写在这堆火的资产上。半径空着，进入休息前报出资产名和字段，然后停住，不自己选一个米数。半径内有追击中的敌人时不休息，生命和回复次数都不变。半径内没有追击中的敌人时，休息与现在相同。

## 3. 验收

Edit Mode：半径内有追击状态时休息不开始，生命和次数不变；没有追击状态时休息仍写回。不创建场景。

要人看的一条：身边有追上来的敌人时坐不下去，对方走后可以坐下。这一条不进 Test Runner。
