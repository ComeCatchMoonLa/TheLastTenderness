# 2.15 技术设计：血瓶和灰瓶不跟快捷道具挤掉

> **快捷格换成别的消耗品时，血瓶和灰瓶的剩余次数仍写在自己的一行上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

快捷栏只有 `consumableCountText`，显示当前消耗品剩余。`estusLeft` 和 `ashLeft` 已经有，切走当前消耗品时这两只瓶不再出现在这一行。

## 2. 改法

`FlaskHudCounts.Line` 返回「血瓶 n 灰瓶 m」。

`QuickSlotsUI.flaskCountText` 写这一行。`SetFlaskCounts` 在刷新当前消耗品次数时一起调用。使用键仍走当前消耗品。不另定快捷格上限。

## 3. 单元测试

`Assets/Tests/EditMode/FlaskHudCountTests.cs`。

断言这一行是给定的两只瓶剩余。不创建整页 HUD。

## 4. 不做

不改当前消耗品那一行的数字格式。不新定能排几格。
