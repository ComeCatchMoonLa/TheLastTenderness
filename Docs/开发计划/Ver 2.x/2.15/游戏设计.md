# 2.15 游戏设计：血瓶和灰瓶不跟快捷道具挤掉

> **交付目标：快捷栏切到别的消耗品时，血瓶和灰瓶的剩余次数仍单独看得见。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-菜单-07](../../../需求文档/功能需求/菜单.md)。

## 1. 为什么是这一刀

快捷栏和灰瓶回蓝已经有。现在只有一个 `currentConsumable`。需求是 [FR-菜单-07](../../../需求文档/功能需求/菜单.md)。能排多少格的上限仍待核对，这一版不另定。

## 2. 做完之后

血瓶和灰瓶的剩余次数不因为切到另一件消耗品而消失。使用键仍作用于当前快捷格。别的格子空了就跳过。不新定快捷格上限。

## 3. 验收

Edit Mode：当前消耗品不是瓶时，血瓶和灰瓶的剩余次数仍能读到。不创建窗口。

要人看的一条：快捷栏从瓶切到别的道具，两只瓶的次数还在。这一条不进 Test Runner。
