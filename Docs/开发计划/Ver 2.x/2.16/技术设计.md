# 2.16 技术设计：对话说到段尾就反复

> **说到只剩最后一句时不再删掉它。再推进仍是这一句。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`TalkUI` 每说完一句就 `RemoveAt(0)`。列表空了再交互会结束对话。

## 2. 改法

`DialogueTail.DropSpoken`：列表多于一句才删第一句。只剩一句时留下。按住跳过仍清空并结束。不换新段。

## 3. 单元测试

`Assets/Tests/EditMode/DialogueTailTests.cs`。

两句推进两次后仍剩最后一句。不创建对话窗。

## 4. 不做

不处理旗标换段。不处理说到一半离开。
