# 2.17 技术设计：把对的物品交出去会推进

> **交对了才从背包拿走，并立起这一段已经交过。交给别人或再交一次都不拿走。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`Talk` 能播对白。背包能 `RemoveItem`。没有「要的那一件」和交过旗标。

## 2. 改法

`Talk.wantedGift` 和 `giftAdvanced`。`Give` 用 `GiftExchange.CanTake`：已经交过、要的不是这一件、或不在背包，返回 false。通过后 `RemoveItem`，并把 `giftAdvanced` 写成 true。

交错就被收走不做。

## 3. 单元测试

`Assets/Tests/EditMode/GiftExchangeTests.cs`。

交错的不减背包。交对的减一件，再交失败。不创建对话窗。

## 4. 不做

不写商店加货。不处理交错就被收走。
