## 1. 为什么是这一刀

对话和背包已经有。任务旗标还没有。需求是 [FR-任务-03](../../../需求文档/功能需求/任务与NPC.md)。交错就被收走仍待核对，不做。

## 2. 做完之后

交对了，物品离开背包，这条线的下一段出现。同一件再交，包里已经没有，不再接受第二次。交给指定之外的人，对方拒绝，物品仍在背包。

## 3. 验收

Edit Mode：交对之后背包少这一件，下一段旗标立起；交给别人时背包不变。不创建对话窗。

要人看的一条：把指定物品交给对的人，再对话能看到下一段。这一条不进 Test Runner。
