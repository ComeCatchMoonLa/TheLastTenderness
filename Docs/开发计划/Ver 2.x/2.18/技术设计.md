# 2.18 技术设计：幻影墙打开后休息仍开着

> **打中或翻滚撞上才关掉碰撞和显示。打开旗标留在这面墙上，休息调用不把它写成假。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有幻影墙。`DamageCollider` 只结算角色。已点燃的篝火休息是 `RestoreVitalsToMax`，不重载场景，也不扫墙上的旗标。

## 2. 改法

新组件 `IllusionWall`，不继承 `Interactable`，所以没有打开提示。挂在带碰撞体的那一个物体上。

`opened`。`Strike` 在还没开时写成 true，并关掉同一物体上的 `Collider` 和 `Renderer`。已经开着就保持 true。`NotifyContact(false)` 是走路撞上，不调用 `Strike`。

攻击：`DamageCollider.OnTriggerEnter` 碰到带 `IllusionWall` 的碰撞体时调用 `Strike`，然后返回。角色受击仍走原来的分支。

翻滚：`OnCollisionEnter` 读到 `CharacterManager.isRolling` 时调用 `Strike`。

`AfterRest` 不改 `opened`，也不把碰撞和显示重新打开。篝火脚本不新增对这面墙的引用。不做跨场景存档，不往场景里摆墙。

## 3. 单元测试

`Assets/Tests/EditMode/IllusionWallTests.cs`。

走路撞上时旗标仍是假，碰撞还在。`Strike` 之后旗标为真，碰撞关掉。`AfterRest` 不把真写成假。不加载场景。

## 4. 不做

不铺关卡。不写跨场景存档。不处理法术的 `OnCollisionEnter`。不写只有主人打得开。
