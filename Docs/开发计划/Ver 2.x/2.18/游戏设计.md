# 2.18 游戏设计：幻影墙打开后休息仍开着

> **交付目标：没有交互提示的墙被打中或翻滚撞上后打开，同一场里休息之后仍开着。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-机关-06](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

工程里没有现成的幻影墙。休息不重载场景。需求是 [FR-机关-06](../../../需求文档/功能需求/场景机关.md)。

## 2. 做完之后

打中或翻滚撞上后关掉碰撞和显示。打开旗标留在这面墙上，同一场里休息之后仍为真。不铺关卡，不做跨场景存档。没打中之前，碰撞还在。

## 3. 验收

Edit Mode：打开之后旗标为真，休息调用不把它写成假。不创建场景。

要人看的一条：打中或撞上后面的路能过，休息后再看仍是开的。这一条不进 Test Runner。
