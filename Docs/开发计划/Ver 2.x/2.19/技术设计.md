# 2.19 技术设计：普通箱子打开后不再给第二份

> **打开一次，物品进背包。再打开不给第二份。休息调用不把已打开写成假。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`OpenChest.Interact` 播开盖，过一秒在箱子上再生成一份 `PickUpItem`。拾取才 `AddItem`。脚本随后销毁，旗标留不住。

## 2. 改法

`ChestLoot.Give(opened, item, inventory)`：已经打开、物品为空或背包为空，返回 false，不调用 `AddItem`。否则 `AddItem` 并返回 true。

`OpenChest.opened`。`itemInChest` 为空时打出物体名和 `itemInChest`，然后返回。通过后把 `opened` 写成 true，标签改成 `Untagged`，不再 `Instantiate`，也不再 `Destroy` 这个组件。获得提示仍走现有的 `SetInteractionInfo` 和 `PopUpInteractionInfoUI`。

`ChestLoot.AfterRest` 原样返回 `opened`。篝火不引用这只箱子。不做跨场景存档。

## 3. 单元测试

`Assets/Tests/EditMode/ChestLootTests.cs`。

打开一次后背包有这一件。再给失败，仍是一件。`AfterRest(true)` 仍是 true。不创建 Animator。

## 4. 不做

不写拟态。不写跨场景存档。不新做获得提示的界面。
