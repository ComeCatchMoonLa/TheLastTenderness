# 2.19 游戏设计：普通箱子打开后不再给第二份

> **交付目标：打开后物品进入背包并出现获得提示，再交互没有第二份，同一场里休息后仍是打开过的。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-机关-07](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

`OpenChest.Interact` 已经有，现在会在箱子上再生成一份拾取物。需求是 [FR-机关-07](../../../需求文档/功能需求/场景机关.md)。

## 2. 做完之后

打开后物品进入背包，并出现获得提示。再交互没有第二份。同一场里休息之后仍是打开过的。不做跨场景存档。

## 3. 验收

Edit Mode：打开一次后背包有这一件，再调用没有第二份，已打开旗标在休息调用之后仍为真。不创建 Animator。

要人看的一条：开箱能看到获得提示，再交互是空的。这一条不进 Test Runner。
