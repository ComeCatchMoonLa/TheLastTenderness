# 2.2 技术设计：背包指定当前法术和消耗品

> **`EquipThisItem` 在法术和消耗品上写入当前项并刷新快捷栏。装备分支不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`item.itemType != ItemType.equipment` 时直接返回。方向键在 `ChangeSpell` / `ChangeConsumable` 里按下标轮换，并调用 `UpdateCurrentSpellIcon` / `UpdateCurrentConsumableIcon`。

`currentSpell`、`currentSpellIdx`、`currentConsumable`、`currentComsumableIdx` 在 `CharacterInventoryManager`。列表在 `PlayerInventoryManager.spells` 和 `consumables`。

## 2. 点选

装备仍走 `EquipWeapon` / `EquipArmor`。

法术：`currentSpell` 写成这件 `SpellItem`。它在 `spells` 里时，`currentSpellIdx` 写成那个下标。然后 `UpdateCurrentSpellIcon`。

消耗品：`currentConsumable` 写成这件 `ConsumableItem`。它在 `consumables` 里时，`currentComsumableIdx` 写成那个下标。然后 `UpdateCurrentConsumableIcon`。

不在列表里时只改当前项，不改下标，也不把它加入列表。

## 3. 单元测试

不写。2.x 手动点背包验收。

## 4. 不做

不改武器和护甲的穿上。不新做背包格子。不改方向键的轮换顺序。
