# 2.2 游戏设计：背包指定当前法术和消耗品

> **交付目标：在背包里点一件法术或消耗品后，快捷栏对应格子换成这一件，之后施法或使用键用它。**
>
> 技术设计和 TODO 进入本版前再写。不新做背包窗口。

## 1. 为什么是这一刀

`InventorySlotUI.EquipThisItem` 在物品不是装备时直接返回。方向键仍能在已有列表里轮换法术和消耗品。需求 FR-装备-07 要的是点背包就能指定当前项。

## 2. 做完之后

点法术写入 `currentSpell`，快捷栏法术图标换成这一件。点消耗品写入 `currentConsumable`，快捷栏消耗品图标换成这一件。点武器或护甲仍走现在的装备。这一件已经在对应列表里时，轮换下标改到它，下一次方向键不从旧下标跳走。

## 3. 验收

背包点一件法术，快捷栏法术图标变成它，下一次施法用它。再点一件消耗品，快捷栏消耗品图标变成它，使用键用它。点武器或护甲的结果与改之前相同。不写 Edit Mode 测试。
