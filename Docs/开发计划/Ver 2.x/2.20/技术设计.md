# 2.20 技术设计：使用余烬后生命上限变长

> **提高比例写在余烬物品上。空着就停。使用后上限按这个比例变长，当前生命补到新上限。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。调研里的精确倍数仍待核对，这一版不写死。

## 1. 现在

`maxHP` 由生命等级乘 10 写一次。没有余烬物品。血条在开局抄一次上限。

## 2. 改法

`EmberItem.healthRatio`。`EmberHealth.TryRaise(maxHP, ratio)`：比例小于或等于 0 返回 false。否则新上限是 `maxHP * (1 + ratio)`。

`PlayerStatsManager.ApplyEmber`：失败时打出资产名和 `healthRatio`，不改上限。成功时把 `maxHP` 和 `currentHP` 都写成新上限。血条引用在时，同时写下上限和当前值。不新做余烬特效。

## 3. 单元测试

`Assets/Tests/EditMode/EmberHealthTests.cs`。

上限 100、比例 0.5 时，新上限和当前生命都是 150。比例 0 时上限仍是 100。不创建界面。

## 4. 不做

不写死 1.3。不处理已经处于余烬时再使用。不写死亡熄灭。不新做余烬外形。
