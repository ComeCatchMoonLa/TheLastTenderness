# 2.20 游戏设计：使用余烬后生命上限变长

> **交付目标：使用后生命上限变长，当前生命抬到新的上限。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-周目-01](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

生命上限已经有。提高比例在调研里仍待核对。需求是 [FR-周目-01](../../../需求文档/功能需求/周目与结局.md)。

## 2. 做完之后

提高比例写在余烬物品资产上。比例空着，使用前报出资产名和字段，然后停住，不写死倍数。使用后上限变长，当前生命补到新上限。只看血条，不新做余烬特效。已经处于余烬时再使用，不在这一版。

## 3. 验收

Edit Mode：资产上的比例大于 0 时，使用后上限按这个比例变长，当前生命等于新上限。比例空着时不改上限。不创建界面。

要人看的一条：使用后血条变长并补满。这一条不进 Test Runner。
