# 2.21 技术设计：学会的法术留在列表里

> **学会列表和记忆栏分成两份。没放进记忆栏时，战斗轮换读不到这一条。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`spells` 既是背包里的法术，也是 `ChangeSpell` 轮换的那一份。背包点一条会写成 `currentSpell`。

## 2. 改法

`spells` 仍是学会列表。`PlayerInventoryManager.memorized` 是记忆栏。

`Memorize`：这一条不在学会列表里，或已经在记忆栏里，不重复加入。在学会列表里则放进记忆栏。

`SpellMemory.Next` 只读记忆栏。空的返回 null，不改下标。`ChangeSpell` 用这个结果写 `currentSpell`。

背包点学会列表不再写成 `currentSpell`。放进记忆栏的菜单不在这一版，测试调用 `Memorize`。

## 3. 单元测试

`Assets/Tests/EditMode/SpellMemoryTests.cs`。

学会列表里有、记忆栏里没有时，`Next` 是 null。`Memorize` 之后 `Next` 读到这一条。不创建商店。

## 4. 不做

不做商店和王座兑换。不做记忆菜单。不改记忆栏格数。
