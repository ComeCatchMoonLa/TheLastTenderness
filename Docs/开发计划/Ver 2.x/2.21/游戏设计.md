# 2.21 游戏设计：学会的法术留在列表里

> **交付目标：学会之后法术留在列表里，未放进记忆栏时不能在战斗里轮换到这一条。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

当前法术和 `MemorySlotCount` 已经有。学会列表和记忆栏还是同一份。需求是 [FR-法术-01](../../../需求文档/功能需求/法术.md)。

## 2. 做完之后

学会列表和记忆栏分成两份。学会之后它在学会列表里。没放进记忆栏时，战斗轮换里没有它。不先做商店和王座兑换。怎么放进记忆栏的菜单不在这一版，这一版要能从测试里把一条放进或不放进记忆栏。

## 3. 验收

Edit Mode：学会列表里有、记忆栏里没有时，战斗轮换读不到这一条。放进记忆栏之后读得到。不创建商店。

要人看的一条：没放进记忆栏的法术，战斗里轮不到。这一条不进 Test Runner。
