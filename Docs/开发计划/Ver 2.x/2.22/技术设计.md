# 2.22 技术设计：暂停列里能打开背包、状态和姿态

> **暂停列有背包、状态、姿态。这一列没有加点。姿态不播放。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

暂停把 `timeScale` 写成 0。列里有设置和成就。背包和状态页已经有，不从这一列打开。

## 2. 改法

`PauseMenuEntries.Names` 是背包、状态、姿态。没有加点。

`EscWindowsManager.OpenBackpack` 调用已有的 `SelectInventoryWin`。`OpenStatus` 调用已有的 `SelectStatusWin`。`OpenStance` 不播放姿态。

暂停预制体的按钮列加上这三个按钮，点击分别调用上面三个方法。不新增结束游戏，不新增在线消息。

## 3. 单元测试

`Assets/Tests/EditMode/PauseMenuEntryTests.cs`。

三个名字都在。加点不在。不创建暂停窗。

## 4. 不做

不播放姿态。不写解锁列表。不加点。不写结束游戏和在线消息。
