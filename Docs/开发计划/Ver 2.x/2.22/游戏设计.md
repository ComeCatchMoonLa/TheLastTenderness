# 2.22 游戏设计：暂停列里能打开背包、状态和姿态

> **交付目标：暂停列能打开背包、状态和姿态三个入口。这一列不能加点。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

暂停已经把 `timeScale` 写成 0。背包和状态页已经有。需求是 [FR-菜单-01](../../../需求文档/功能需求/菜单.md)。

## 2. 做完之后

暂停列有背包、状态、姿态三个入口。背包打开现有背包。状态打开 2.11 的状态页。姿态只打开入口，解锁列表是另一条，这一版不播放姿态。这一列没有加点。结束游戏和在线消息不在这一版。

## 3. 验收

Edit Mode：三个入口在，加点入口不在。不创建暂停窗也可以只断言入口名单。

要人看的一条：打开暂停，能进背包和状态，姿态入口在，没有加点。这一条不进 Test Runner。
