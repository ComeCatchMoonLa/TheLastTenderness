# 2.23 技术设计：持续治疗按固定每秒量回血

> **每秒量写在法术上。时长空着就停。催化器威力不乘进这一段。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HealingSpell.SuccessfullyCastSpell` 用一次性 `healAmount` 调用 `AddHP`。`AddHP` 已经不超过 `maxHP`。

## 2. 改法

`healPerSecond` 和 `regenSeconds` 写在这条法术上。`healPerSecond` 大于 0 且 `regenSeconds` 小于或等于 0 时，打出资产名和 `regenSeconds`，然后返回。

`RegenHeal.Apply(current, max, perSecond, seconds)` 加上 `perSecond * seconds`，不超过 `max`。`perSecond` 或 `seconds` 不大于 0 时原样返回。

`BeginRegen` 记下每秒量和剩余时间。`TickRegen` 用经过的时间调用 `Apply`，并减少剩余时间。`Update` 调用它。`healPerSecond` 不大于 0 时仍走原来的一次性 `AddHP`。

## 3. 单元测试

`Assets/Tests/EditMode/RegenHealTests.cs`。

每秒 5、7、10 各过一秒，生命加上这些数。超过上限时停在上限。时长为 0 不加。不创建施法特效。

## 4. 不做

不乘催化器威力。不新做持续特效。不给一次性治疗改公式。
