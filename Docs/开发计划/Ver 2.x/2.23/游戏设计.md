# 2.23 游戏设计：持续治疗按固定每秒量回血

> **交付目标：补充、丰饶之光、丰饶阳光成功后按每秒 5、7、10 点加生命，不超过上限。催化器威力不改变这个每秒量。**

## 1. 为什么是这一刀

治疗施放已经有。`HealingSpell` 现在按一次性 `healAmount` 加血。需求是 [FR-法术-06](../../../需求文档/功能需求/法术.md) 里持续治疗这一截。总时长两页不一致，时长放在资产上，不选一个秒数。

## 2. 做完之后

这三条成功后按资产上的每秒量加生命，不超过当前上限。每秒量是 5、7、10。换成法术威力更高的催化器，这个每秒量不变。时长空着就停，并报出资产名和字段。一次性治疗仍走原来的 `healAmount`。

## 3. 验收

Edit Mode：每秒 5、7、10 各过一秒，生命加上这些数，不超过上限。时长为 0 时不加。不创建施法特效。

要人看的一条：放出去之后血条按这个速度往上走。这一条不进 Test Runner。
