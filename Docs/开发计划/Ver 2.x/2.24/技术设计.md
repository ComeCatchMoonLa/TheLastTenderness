# 2.24 技术设计：终局一次交互只进入一条结局

> **一次交互只返回窃火、灭火、传火中的一条。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有终局选择。身上还没有这三面旗标。

## 2. 改法

`EndingChoice.Choose(stolenFlame, eyesGiven, keeperSignUsed)`。`stolenFlame` 为真返回窃火。否则眼已交并且用过防火女的符，返回灭火。其余返回传火。只返回一个字符串。

## 3. 单元测试

`Assets/Tests/EditMode/EndingChoiceTests.cs`。

窃火优先于另外两面旗标。只有眼和符都有才是灭火。其余是传火。不创建过场。

## 4. 不做

不新做过场。不写下一周目。不把人送到终局火焰。
