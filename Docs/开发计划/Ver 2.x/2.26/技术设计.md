# 2.26 技术设计：四种催化器各放各的系

> **法杖只放魔法，圣铃和护符只放奇迹，火焰只放火焰。拿错就没有弹体或治疗。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

施法动作只比对动作上的 `SpellType` 和当前法术。武器上还没有催化器种类。

## 2. 改法

`CatalystKind` 写在武器上：法杖、圣铃、护符、火焰。`none` 表示这把不是催化器，仍走原来的学派比对。

`CatalystMatch.Allows`：法杖对魔法，圣铃和护符对奇迹，火焰对火焰。种类不是 `none` 且不配对时，不施放。

## 3. 单元测试

`Assets/Tests/EditMode/CatalystMatchTests.cs`。

四组配对为真。拿错为假，包括法杖对治疗所用的奇迹。不创建弹体。

## 4. 不做

不新做催化器模型。不改智力或信仰门禁。不改催化器战技的特殊效果。
