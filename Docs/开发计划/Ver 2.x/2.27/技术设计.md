# 2.27 技术设计：从防火女打开加点

> **花费写在资产上。够了才加一级并扣魂。不够或花费空着，两边都不变。篝火四项里没有升级。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AddSouls` 只会加魂。没有按表扣魂加级。

## 2. 改法

`LevelPurchase.TryConfirm(assetName, souls, cost, level, out newSouls, out newLevel)`。`cost` 小于或等于 0 时打出资产名和 `cost`，两边原样返回。灵魂少于花费时两边不变。够了则灵魂减去花费，等级加一。

## 3. 单元测试

`Assets/Tests/EditMode/LevelPurchaseTests.cs`。

花费为空、灵魂不够、灵魂刚好够。篝火菜单仍没有升级。不创建加点窗。

## 4. 不做

不写每一级灵魂的算式。不把升级放进篝火四项。不改属性上限公式。
