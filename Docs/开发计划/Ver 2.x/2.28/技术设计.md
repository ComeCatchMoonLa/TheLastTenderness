# 2.28 技术设计：装备槽能看到双手各三、四防具和四戒指

> **每手三格，防具四格是头、胸、手、腿，戒指四格。空格是空引用。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

每手武器数组长度是 1。防具是头、躯干、下身。没有手甲字段，没有戒指格。下身这一格当作腿。

## 2. 改法

`EquipmentLayout` 把短数组补到目标长度，已有的物品留在原下标，多出来的是空。每手 3，戒指 4。`Awake` 里补。

防具四格的名字是头、胸、手、腿。`ArmorType` 末尾加 `hands`，并加 `currentHandArmor`。已有的下身格仍是腿，不改它的字段名。

切武器时跳过空格。绕一圈仍没有可握住的武器就停在原地。

## 3. 单元测试

`Assets/Tests/EditMode/EquipmentLayoutTests.cs`。

短数组补成 3 和 4，原有物品还在，空位是空。防具名字是四项。不创建装备窗。

## 4. 不做

不新做手、腿的外形模型。戒指戴上之后的效果不在这一版。不改装备窗预制体上的格子贴图。
