# 2.28 游戏设计：装备槽能看到双手各三、四防具和四戒指

> **交付目标：装备页能看见每手三格、头胸手腿四格、戒指四格。没有的部位显示空。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-菜单-03](../../../需求文档/功能需求/菜单.md)。

## 1. 为什么是这一刀

头、躯干、下身和每手前两格已经能显示。需求是 [FR-菜单-03](../../../需求文档/功能需求/菜单.md)。手、腿的外形模型不在这一版新做。

## 2. 做完之后

装备页能看见左手三格、右手三格、头胸手腿四格、戒指四格。没有放东西的格是空的。戒指先只占格子，戴上之后的效果不在这一版。

## 3. 验收

Edit Mode：每手 3 格，防具 4 格，戒指 4 格。空引用读出来是空。不创建装备窗也可以只断言格数。

要人看的一条：打开装备页能看见这些空格。这一条不进 Test Runner。
