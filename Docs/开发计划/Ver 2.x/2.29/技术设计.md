# 2.29 技术设计：商店用灵魂买卖

> **买价和卖价写在调用方传来的数上。空着就停。不够时背包和灵魂都不变。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AddSouls` 只会加魂。没有商店这一次写入。

## 2. 改法

`ShopTrade.Buy`：价格小于或等于 0 时打出资产名和 `price`，背包和灵魂都不变。灵魂少于价格时也不变。够了则物品进背包，灵魂减去价格。

`ShopTrade.Sell`：卖价小于或等于 0 时打出资产名和 `sellPrice`。背包里有这件才拿走，灵魂加上卖价。

## 3. 单元测试

`Assets/Tests/EditMode/ShopTradeTests.cs`。

买成功、魂不够、卖成功、价格为空。不创建商店窗。

## 4. 不做

不选卖出比例。不写商人对话。不改死亡清零。
