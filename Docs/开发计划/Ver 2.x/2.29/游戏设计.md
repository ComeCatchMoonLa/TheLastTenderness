# 2.29 游戏设计：商店用灵魂买卖

> **交付目标：买得到、卖得掉，灵魂跟着变。不够时两边都不变。**

只写了游戏设计。技术设计和 TODO 进入这一版时再写。

来源：[FR-任务-02](../../../需求文档/功能需求/任务与NPC.md)。

## 1. 为什么是这一刀

对话已经能推进。`AddSouls` 已经有。需求是 [FR-任务-02](../../../需求文档/功能需求/任务与NPC.md)。卖出比例仍未入池，这一版的买价和卖价写在资产上，不选比例。

## 2. 做完之后

确认购买后物品进背包，灵魂减少买价。灵魂少于买价时，背包和灵魂都不变。卖出后物品离开背包，灵魂增加卖价。买价或卖价空着就停，并报出资产名和字段。

## 3. 验收

Edit Mode：买成功少魂进包；魂不够两边不变；卖成功出包加魂。不创建商店窗。

要人看的一条：和商人确认买卖，背包和灵魂数字一起变。这一条不进 Test Runner。
