# 2.3 技术设计：同一次挥击只结算一次

> **伤害碰撞体这一次开着的期间，每个 `CharacterManager` 只进一次结算。关掉时清空。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`OnTriggerEnter` 每次进入都认标签、队伍，然后弹反、格挡或 `DealDamage`。`EnableDamageCollider` / `DisableDamageCollider` 只改碰撞体的 `enabled`。

## 2. 这一次窗口

`DamageCollider` 上留一块 `List<CharacterManager>`。`EnableDamageCollider` 和 `DisableDamageCollider` 都清空它。

通过自身和同队判断之后，名单里已有这个人就返回。否则先记入，再走现在的弹反、格挡或受伤。两名不同的人各记一次。法术和炸弹不走这个触发器，不改。

## 3. 单元测试

不写。要物理回调。验收靠人打。

## 4. 不做

不改伤害公式。不改弹反和格挡的判定。不给法术弹和炸弹加这份名单。
