# 2.3 游戏设计：同一次挥击只结算一次

> **交付目标：同一次伤害窗口里，武器多次碰到同一名敌人，该敌人只掉一次血、只播一次受击。**
>
> 技术设计和 TODO 进入本版前再写。

## 1. 为什么是这一刀

`DamageCollider.OnTriggerEnter` 每次进入都结算。同一次挥击的碰撞体还开着时，再次碰到同一人会再扣血。需求 FR-伤害-05 要求这一窗口内每人只结算一次。

## 2. 做完之后

碰撞体这一次开着的期间，同一名敌人只结算一次。窗口关掉后再挥中，可以再结算。打中两名不同敌人时，各结算一次。

## 3. 验收

一次挥击里让武器多碰到同一人，只掉一次血。下一挥再碰到，可以再掉血。同一挥打中两个人，各掉一次。不写 Edit Mode 测试。
