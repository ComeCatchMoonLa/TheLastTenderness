# 2.30 技术设计：再注入覆盖旧的，加号留下

> **换成另一种注入后，种类是新的，强化等级不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

武器上没有注入种类，也没有强化等级。

## 2. 改法

`infusion` 和 `reinforceLevel` 写在武器上。`InfusionSwap.Replace` 只改 `infusion`。`reinforceLevel` 保持调用前的数。

## 3. 单元测试

`Assets/Tests/EditMode/InfusionSwapTests.cs`。

从甲换成乙之后读到乙，强化等级仍是换之前的数。不创建注入菜单。

## 4. 不做

不配满十五种的伤害数值。不把注入乘进这一击的结算。
