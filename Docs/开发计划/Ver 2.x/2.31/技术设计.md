# 2.31 技术设计：传送只去已经点燃的火

> **名单按点燃旗标过滤。没点燃的传不过去。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CampfireMenu` 里有传送。`CampFireInteractable.hasBeenActived` 是点燃。没有按点燃过滤的名单。

## 2. 改法

`BonfireTravel.List` 把已经点燃的名字写入调用方给的数组，返回写进的个数。没点燃的不写入。

`BonfireTravel.TryGo`：出发点没点燃、目的地没点燃、或目的地就是出发点时返回 false。另一处已点燃时返回 true。不改重生点。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/BonfireTravelTests.cs`。

两处记录里只有点燃的进名单。没点燃的选不中。另一处已点燃时可以选中。不创建篝火窗，不移动角色。

## 4. 不做

不移动角色。不改重生点。不在场景里再摆一处火。
