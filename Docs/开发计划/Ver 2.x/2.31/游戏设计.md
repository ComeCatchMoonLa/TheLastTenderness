# 2.31 游戏设计：传送只去已经点燃的火

> **交付目标：传送名单里只有已经点燃的火。没点燃的不在名单里，也选不中。**

来源：[FR-篝火-02](../../../需求文档/功能需求/篝火菜单.md)。

## 1. 为什么是这一刀

前置已解锁。坐下后的菜单是四项，其中有传送（2.25）。点燃仍是 `CampFireInteractable.hasBeenActived`。需求前置是无。[FR-篝火-02](../../../需求文档/功能需求/篝火菜单.md) 和调研「点燃、名称和传送列表」都写：没点燃的名字不在表上，也选不中。另一处已经点燃时，才能传到那一处。

落地后重生点记在出发的火还是落地的火，调研标了待核对。这一版不写。

## 2. 做完之后

名单只留下已经点燃的火。选一处没点燃的，传不过去。出发点自己没点燃，或目的地就是正坐着的这一处，也传不过去。另一处已经点燃时，可以选它。

不往场景里再摆一处火。读条和人站到火前留给人看。

## 3. 验收

Edit Mode：两处记录里只有点燃的那处进名单。没点燃的选不中。另一处已点燃时可以选中。不创建篝火窗，不移动角色。

要人看的一条：读条结束后人站在那处火前。这一条不进 Test Runner。
