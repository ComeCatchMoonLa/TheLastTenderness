# 2.32 技术设计：各处火的储物箱是同一个

> **各处火读写同一份物品列表。装备中的不放进去。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CampfireMenu` 里有储物箱。没有一份各处火共用的箱子。

## 2. 改法

`BonfireStorage.TryDeposit`：物品在背包里、且没有装备中，才从背包挪进箱子。装备中或背包里没有，两边都不动。

`BonfireStorage.TryWithdraw`：箱子里有这一件，才挪回背包。没有则两边都不动。

箱子是调用方持有的同一份列表。这一版不提供清空。灵魂数字没有参数。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/BonfireStorageTests.cs`。

存入后是同一引用。装备中的留在背包。取回后箱子里没有。不创建储物箱窗。

## 4. 不做

不写格子上限。不另列存不进去的种类。不把灵魂数字写进箱子。不接死亡流程。
