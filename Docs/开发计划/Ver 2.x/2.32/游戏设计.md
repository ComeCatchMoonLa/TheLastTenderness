# 2.32 游戏设计：各处火的储物箱是同一个

> **交付目标：在一处火放进箱子的物品，在另一处已点燃的火能取回同一件。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。坐下后的菜单是四项，其中有储物箱（2.25）。需求前置是无。[FR-篝火-03](../../../需求文档/功能需求/篝火菜单.md) 和调研「储物箱」都写：各处已点燃的火打开的是同一个箱子，死亡不清空，正在装备的要先卸下，灵魂计数不进箱子。格子上限和还有哪些种类存不进去，调研标了待核对。这一版不写。

## 2. 做完之后

从背包放进箱子后，背包里没有这一件，箱子里是同一件。另一处火取回时，进的是背包，箱子里不再有它。正在装备的放不进去。死亡之后箱子里的这一件还在。灵魂数字不写进箱子。

## 3. 验收

Edit Mode：存入后背包没有、箱子有同一引用；装备中的不动；再从同一份箱子取回。不创建储物箱窗，不调用死亡流程。

要人看的一条：两处火打开的是同一格存货。这一条不进 Test Runner。
