# 2.33 技术设计：法术记忆只在篝火改

> **没坐下时 `Memorize` 不改记忆栏。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerInventoryManager.Memorize` 不看有没有坐下。`CampfireMenu` 里有整理法术。学会列表和记忆栏已经分开（2.21）。

## 2. 改法

`Memorize(SpellItem spell, bool atBonfire)`。`atBonfire` 为 false 时返回 false，不加入记忆栏。为 true 时仍按原来的规则：不在学会列表里不加入，已经在记忆栏里不重复加入。

`SpellMemoryTests` 里原来的调用改成坐下。不另写一套记忆栏。

## 3. 单元测试

`Assets/Tests/EditMode/Spells/BonfireAttuneTests.cs`。

没坐下时记忆栏仍是空的。不创建整理法术窗。

## 4. 不做

不卡记忆栏格数。不判断同一法术占多格。不改学派门禁。
