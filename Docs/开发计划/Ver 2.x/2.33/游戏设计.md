# 2.33 游戏设计：法术记忆只在篝火改

> **交付目标：只有坐下后才能改记忆栏。没坐下时放不进去。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。学会列表已有（2.21）。坐下后的菜单是四项，其中有整理法术（2.25）。需求前置是无。[FR-法术-03](../../../需求文档/功能需求/法术.md) 和调研「记忆栏」都写：只有坐在火边能改记忆槽，战斗中只能在已记入的几条之间轮换。同一法术再选一次是否加次数，两边都标了待核对。这一版不写。栏位满了放不进去也不在这一版，格数仍看 2.6。

## 2. 做完之后

坐下时，已学会的法术可以放进记忆栏。没坐下时放不进去，记忆栏保持原样。轮换仍只读记忆栏。施放仍用现在的学派门禁。

## 3. 验收

Edit Mode：没坐下时 `Memorize` 返回 false，记忆栏不变。坐下后放得进去。不创建整理法术窗，不创建 Animator。

要人看的一条：坐下后能打开整理，站着打不开。这一条不进 Test Runner。
