# 2.34 技术设计：交书之后清单变长，人死了清单关闭

> **收这本书才把法术写进清单。人死了清单打不开。学会列表不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ShopTrade` 能买卖。没有交书加长清单，也没有按死亡关掉清单。

## 2. 改法

`SpellBookStock.TryHandIn`：`accepts` 为假，或背包里没有这本书，背包和清单都不变。为真则书离开背包，书里的法术还不在清单里的才追加。

`SpellBookStock.CanOpen`：商人还活着才返回 true。不改学会列表。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/SpellBookStockTests.cs`。

交对的书清单变长。不收的书还在背包。死后打不开，学会列表还在。不创建商店窗。

## 4. 不做

不写哪本书交给谁。不在这一版里调用 `ShopTrade`。不掉灰烬。
