# 2.34 游戏设计：交书之后清单变长，人死了清单关闭

> **交付目标：交上对应的书后出售清单变长。这名商人死了，清单不能再打开。已经学会的还在。**

来源：[FR-任务-04](../../../需求文档/功能需求/任务与NPC.md)。

## 1. 为什么是这一刀

前置已解锁。商店买卖已经能开关（2.29）。需求前置是无。[FR-任务-04](../../../需求文档/功能需求/任务与NPC.md) 和调研「教法术」都写：交上对应的书后清单变长，书消失；这个人死后，没买的不能再从他这里打开；已经学会的还在。哪本书交给谁，调研标了待核对。这一版用调用方传入的「收不收这本书」，不写死人选。

## 2. 做完之后

交上他收的书，书离开背包，出售清单多出书里的法术。不收的书留在背包，清单不变。商人还活着时清单可以打开。死后打不开。学会列表不因此变短。

## 3. 验收

Edit Mode：交对的书后清单变长、书离开背包；不收的书还在；死后打不开，学会列表还在。不创建商店窗。

要人看的一条：和这个人确认交书、死后菜单关着。这一条不进 Test Runner。
