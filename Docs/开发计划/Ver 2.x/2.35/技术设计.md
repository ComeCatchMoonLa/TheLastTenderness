# 2.35 技术设计：炭火没交之前选不到那一组

> **没交上要求的炭火时不调用替换。交上之后才换种类，强化等级仍走 2.30。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`InfusionSwap.Replace` 能换种类，强化等级不动。没有按炭火过滤的选项。

## 2. 改法

`InfusionOffer.CanSelect`：要求的炭火名字为空时返回 true。否则只在已交列表里有这个名字时返回 true。

选不中时不调用 `Replace`。选中后仍用 `Replace`，强化等级保持调用前的数。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/InfusionOfferTests.cs`。

没交时种类不变。交上后种类换成新的，强化等级还在。不创建注入菜单。

## 4. 不做

不写死十五种和炭火对照。不新做铁匠对话。
