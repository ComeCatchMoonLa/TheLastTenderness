# 2.35 游戏设计：炭火没交之前选不到那一组

> **交付目标：对应炭火还没交给铁匠时，那一组选不到。交上之后可以选。武器上已有的注入还在。**

来源：[FR-注入-02](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

前置已解锁。再注入会换成新种类，强化等级还在（2.30）。需求前置是无。[FR-注入-02](../../../需求文档/功能需求/注入与强化.md) 和调研「强化」都写：炭火没交给铁匠时那一组选不到，交上之后可以选；已经做在武器上的注入还在。十五种怎么分组，FR 写与调研待核对项一致。调研写明精、原质、火不需要炭火。这一版不写死分组，不需要炭火的那一组由调用方把要求留空。

## 2. 做完之后

要求一块炭火、而这块还没交上时，这一组选不到，武器上的注入和强化等级不动。交上之后可以选，选中后种类换成这一组，强化等级还在。不写要求的那一组，没交炭也能选。

## 3. 验收

Edit Mode：没交时选不中、种类不变。交上后可以选，种类换了，强化等级还在。不创建注入菜单。

要人看的一条：铁匠菜单里那一组出现或消失。这一条不进 Test Runner。
