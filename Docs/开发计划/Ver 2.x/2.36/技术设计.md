# 2.36 技术设计：圣女、深渊、暗月戒指增加记忆栏

> **格数是集中力门槛加上最多四格的加格。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`MemorySlotCount` 只看集中力。`EquipmentLayout.RingSlots` 是 4。戒指上没有加格。

## 2. 改法

`MemorySlotBonus.Total`：先取 `MemorySlotCount(focusLevel)`，再把传入数组的前 4 个加格相加。数组更长时，第 5 个起不读。空数组不加。

加 1 和加 2 由调用方按那枚戒指传入。这一版不新做戒指类型。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/RingMemorySlotTests.cs`。

集中力 9 时加 1、再加 1、加 2。四格为 0 时是 0。第五个数不加。不创建戒指模型。

## 4. 不做

不新做戒指模型。不改集中力门槛表。
