# 2.36 游戏设计：圣女、深渊、暗月戒指增加记忆栏

> **交付目标：戴上圣女或深渊戒指多 1 格，戴上暗月戒指多 2 格。摘下后回到只看集中力的格数。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。四格戒指已有（2.28）。集中力门槛格数已有（2.6）。需求前置是无。[FR-养成-03](../../../需求文档/功能需求/角色养成.md) 和调研「集中力」都写：圣女戒指和深渊戒指各加 1 格，暗月戒指加 2 格。

## 2. 做完之后

记忆栏格数是集中力门槛再加上四格里每枚戒指写的加格。圣女或深渊是加 1，暗月是加 2。摘下后只剩集中力那一档。第五个数不读。

## 3. 验收

Edit Mode：集中力 9 时圣女加到 1，再加深渊是 2，换成暗月是 2。四格都是 0 时回到 0。第五个数不加。不创建戒指模型。

要人看的一条：装备页上戴上和摘下之后格子数变了。这一条不进 Test Runner。
