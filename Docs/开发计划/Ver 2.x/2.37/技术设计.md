# 2.37 技术设计：武器上能读到力量和敏捷需求

> **没填的读出来是空。填了的数原样读回，包括 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`WeaponItem` 上没有力量需求，也没有敏捷需求。

## 2. 改法

力量和敏捷各有一个是否填了，以及一个数，写在 `WeaponItem` 上。

`WeaponNeed.TryStrength` 和 `TryDexterity`：没填时返回 false，不把 0 当成需求。填了则返回 true，并写出那个数。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/WeaponNeedTests.cs`。

填了 14 读回 14。没填时返回 false。填了 0 读回 0。不创建武器面板。

## 4. 不做

不改挥击速度。不改打中的伤害。不写智力、信仰、幸运。不写双手力量取整。
