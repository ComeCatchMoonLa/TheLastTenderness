# 2.37 游戏设计：武器上能读到力量和敏捷需求

> **交付目标：武器上能读到力量需求和敏捷需求。填了的是那个数。没填的是空，不是 0。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。程序前置是无，`WeaponItem` 已有。需求前置是无。[FR-属性-05](../../../需求文档/功能需求/属性与升级.md) 写武器上有力量或敏捷需求，落点是 `WeaponItem`。挥击变慢和打中更弱不在这一版。智力、信仰、幸运，以及双手力量怎么取整，本条不选。

## 2. 做完之后

填了力量需求，读回那个数。没填力量需求，读出来是空。敏捷同样。填了 0 时读回 0，和没填分开。

## 3. 验收

Edit Mode：填了 14 读回 14。没填时读不到数。填了 0 读回 0。不创建武器面板，不改挥击和伤害。

要人看的一条：武器面板上这两个点数。这一条不进 Test Runner。
