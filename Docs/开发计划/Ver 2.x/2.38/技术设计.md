# 2.38 技术设计：需求不足时更慢，打中也更弱

> **低于已填的力量或敏捷需求时，速度和伤害乘调用方传入的系数。系数空着就停。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`WeaponNeed` 能读需求。挥击和伤害还不看这两项。

## 2. 改法

`RequirementPenalty.TryScale`：没填的需求不算不足。填了且等级低于需求时，速度系数或伤害系数小于或等于 0 就打出资产名和字段，速度和伤害保持调用前的数，返回 false。两个系数都大于 0 时，速度改成速度系数，伤害改成原伤害乘伤害系数。两项都满足时速度是 1，伤害不变。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/RequirementPenaltyTests.cs`。

不足时更慢更弱。满足时回到 1 和原伤害。系数空着不变。不创建 Animator。

## 4. 不做

不写死系数。不改 Animator。不比智力、信仰、幸运。不写双手力量取整。
