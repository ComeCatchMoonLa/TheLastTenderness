# 2.39 技术设计：商人死亡留下可以交还的灰烬

> **死后灰烬进背包。交给收的人，货进他的清单。原商人的开关仍是关。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SpellBookStock.CanOpen` 在商人死亡时返回 false。没有灰烬，也没有把货并进另一份清单。

## 2. 改法

`MerchantAsh.TryDrop`：商人已死、灰烬还没在背包里，才放进背包。已经在背包里不再放。

`MerchantAsh.TryHandOver`：`accepts` 为假，或背包里没有这包灰烬，两边不动。为真则灰烬离开背包，货还不在清单里的才追加。不把原商人的 `CanOpen` 写成 true。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/MerchantAshTests.cs`。

死亡后背包有灰烬。交对后清单有货，原商人仍打不开。不创建商店窗。

## 4. 不做

不写死谁收灰烬。不在这一版里调用 `ShopTrade`。不把死亡写成活着。
