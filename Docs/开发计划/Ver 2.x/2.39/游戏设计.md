# 2.39 游戏设计：商人死亡留下可以交还的灰烬

> **交付目标：商人死亡后背包里有灰烬。交给收这包灰烬的人之后，他的清单里有这包货。原来的商人仍打不开。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。商人死亡会关掉原清单（2.34，`SpellBookStock.CanOpen`）。需求前置是无。[FR-任务-06](../../../需求文档/功能需求/任务与NPC.md) 写死亡留下灰烬，交给指定的人后可以再买。谁收这包灰烬不写死，由调用方传入收不收。

## 2. 做完之后

商人死后，灰烬进背包。再死一次不会再给一包。交给收的人，灰烬离开背包，清单里多出这包货。不收的人不动背包和清单。原来的商人清单仍然打不开。

## 3. 验收

Edit Mode：死亡后背包有灰烬。交对之后清单有这件货，原商人打不开。不创建商店窗，不创建尸体。

要人看的一条：尸体上能捡起灰烬，交给那个人之后能再买。这一条不进 Test Runner。
