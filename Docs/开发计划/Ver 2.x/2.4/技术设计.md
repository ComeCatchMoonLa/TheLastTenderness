# 2.4 技术设计：燃火休息回满

> **已点燃的燃火把三条资源写成上限并刷新 HUD，休息完成前用已有的交互锁定。箱子保持关掉。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CampFireInteractable` 在 `Interactables` 下。该父节点未激活，所以燃火进游戏看不到。同级还有 `Chest`、`Weapon Pick Up Item`、`View Info List`。

已点燃时 `Interact` 是空的。未点燃仍播放 `"Pick Up Item"` 并点着火。

## 2. 休息

`PlayerStatsManager` 增加一个方法：把 `currentHP`、`currentStamina`、`currentMP` 写成各自上限，并刷新血条、体力条、专注条。

已点燃分支调用这个方法，再 `PlayTargetAnimation("Pick Up Item", true)`。这是已经在用的动作名。全身空状态清掉 `isInteracting` 之后才能再移动和攻击。不打开篝火菜单。未点燃分支不改。

## 3. 场景

打开 `Interactables`。`Camp Fire` 保持激活。`Chest`、`Weapon Pick Up Item`、`View Info List` 设为不激活。不新摆物体。

## 4. 单元测试

不写。2.x 手动验收。

## 5. 不做

不复活敌人。不补回复次数。不打开四项菜单。不新做动画名。
