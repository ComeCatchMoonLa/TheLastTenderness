# 2.4 游戏设计：燃火休息回满

> **交付目标：只让场景里那一盏燃火进游戏。已点燃后休息，生命、精力、专注回到各自上限，完成前不能移动和攻击。**
>
> 技术设计和 TODO 进入本版前再写。不打开箱子。不打开篝火四项菜单。

## 1. 为什么是这一刀

`CampFireInteractable` 挂在未激活的 `Interactables` 下。已点燃时 `Interact` 是空的。需求 FR-燃火-02 要休息把三条资源写成上限并刷新 HUD。

## 2. 做完之后

这一盏燃火进游戏后可以交互。未点燃时仍是现在的点燃。已点燃后休息，三条回到上限。休息完成前不能移动和攻击。箱子保持关掉。

## 3. 验收

只看到这一盏燃火，看不到箱子。对已点燃的它休息，生命、精力、专注都满，休息过程中移动和攻击不发生。完成后可以离开再打。不写 Edit Mode 测试。
