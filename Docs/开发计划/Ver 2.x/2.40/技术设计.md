# 2.40 技术设计：死亡时灵魂变成零并留下残留

> **死亡时把灵魂写成 0。大于 0 才留下等量残留。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerStatsManager.TakeDamage` 在生命到 0 时调用 `Death`，`isDead` 变成真。`soulCount` 不清零。`AddSouls` 只会加，并写 HUD。

## 2. 改法

`SoulDrop.TryLeave`：数量大于 0 时返回 true，残留等于这个数。否则返回 false，残留是 0。

`PlayerStatsManager.ForfeitSouls`：按当前 `soulCount` 调用 `TryLeave`，写上有没有残留和数量，再用和 `AddSouls` 相同的 HUD 写入把 `soulCount` 写成 0。

`TakeDamage` 在调用 `Death` 之后调用 `ForfeitSouls`。

## 3. 单元测试

`Assets/Tests/EditMode/Stats/SoulDropTests.cs`。

40 留下 40 且身上为 0。0 不留下。不创建血迹，不播动画。

## 4. 不做

不生成场景里的拾取物。不把人送回火边。不捡回。
