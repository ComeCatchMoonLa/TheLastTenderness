# 2.40 游戏设计：死亡时灵魂变成零并留下残留

> **交付目标：带着灵魂死去，身上和 HUD 变成 0，留下一份等于死前数量的残留。本来是 0 则不生成。**

来源：[不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。程序前置是无。死亡已经会停操作，`AddSouls` 只会加。需求前置是无。[FR-燃火-05](../../../需求文档/功能需求/燃火休息与死亡惩罚.md) 写身上变为 0，残留等于死前灵魂，本来是 0 不生成。

这一版写在玩家死亡流程里，和 `isDead` 同一段。后面捡回和再死会读这份残留。

## 2. 做完之后

死前灵魂大于 0 时，身上变成 0，HUD 写成 0，残留数量等于死前那个数。死前是 0 时，身上仍是 0，不留下残留。

## 3. 验收

Edit Mode：40 死后身上是 0、残留是 40。0 死后没有残留。不创建血迹模型，不播死亡动画。

要人看的一条：HUD 变成 0，死亡点能看见残留。这一条不进 Test Runner。
