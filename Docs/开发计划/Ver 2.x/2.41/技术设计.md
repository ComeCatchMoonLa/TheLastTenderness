# 2.41 技术设计：捡回死亡留下的灵魂

> **捡回把残留加回身上并清掉。休息清掉死亡并把人放到火的位置。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ForfeitSouls` 会留下 `hasSoulRemnant` 和 `soulRemnant`。没有捡回。休息只 `RestoreVitalsToMax`，不改 `isDead`，不改位置。

## 2. 改法

`PlayerStatsManager.RecoverRemnant`：没有残留时返回 false。有则 `AddSouls` 那个数，再把残留清成没有。

`PlayerStatsManager.ReturnFromDeath`：`isDead` 写成 false。传入的位置不是空时，把身体放到那里。

## 3. 单元测试

`Assets/Tests/EditMode/Stats/SoulRecoverTests.cs`。

捡回 40。没有残留时不加。休息后死亡为假，位置是传入的点。不创建拾取物。

## 4. 不做

不生成地上的拾取物。不另做传送网。
