# 2.41 游戏设计：捡回死亡留下的灵魂

> **交付目标：交互残留后残留消失，身上的灵魂增加记下的数量。休息把人放回火边并清掉死亡。**

来源：[FR-燃火-06](../../../需求文档/功能需求/燃火休息与死亡惩罚.md)。

## 1. 为什么是这一刀

前置已解锁。死亡已经会留下残留（2.40）。需求前置是无。[FR-燃火-06](../../../需求文档/功能需求/燃火休息与死亡惩罚.md) 写交互后残留消失，灵魂增加记下的数量。从死亡回到可操作，这一版用休息把人放回这处火旁并清掉死亡，不另做传送。

## 2. 做完之后

有残留时捡回，残留没有了，身上加上那个数。没有残留时捡回不改灵魂。休息后 `isDead` 为假，人在传入的火的位置。

## 3. 验收

Edit Mode：残留 40 捡回后身上是 40、残留没有了。休息后死亡为假，位置是火的位置。不创建拾取物，不播捡起动画。

要人看的一条：走到残留处交互，HUD 加上那个数。这一条不进 Test Runner。
