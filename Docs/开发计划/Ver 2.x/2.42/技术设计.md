# 2.42 技术设计：没捡就再死，只留新的一笔

> **再死仍走 `ForfeitSouls`。残留只按这次的 `soulCount` 重写，不把旧的加回去。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ForfeitSouls` 用当前 `soulCount` 调用 `SoulDrop.TryLeave`，并覆盖 `soulRemnant`。没有断言再死时旧残留不被加回去。

## 2. 改法

不另写第二份留下。再死仍调用 `ForfeitSouls`。身上是 0 时 `TryLeave` 返回 false，残留被写成没有。

## 3. 单元测试

`Assets/Tests/EditMode/Stats/SoulReplaceTests.cs`。

40 还在时身上变成 10 再死，残留是 10。再变成 0 再死，没有残留。不创建拾取物。

## 4. 不做

不把旧残留加进这次的身上。不生成第二种血迹。
