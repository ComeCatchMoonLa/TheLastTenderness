# 2.42 游戏设计：没捡就再死，只留新的一笔

> **交付目标：旧残留还在时再死，旧的消失，新的只等于这次身上的灵魂。**

来源：[FR-燃火-07](../../../需求文档/功能需求/燃火休息与死亡惩罚.md)。

## 1. 为什么是这一刀

前置已解锁。已经能留下残留（2.40）并捡回（2.41）。需求前置是无。[FR-燃火-07](../../../需求文档/功能需求/燃火休息与死亡惩罚.md) 写旧残留消失，新的只等于这次身上的灵魂。

## 2. 做完之后

没捡回就再死时，残留改成这次身上的数，旧的那一笔不能再捡。这次身上是 0 时，旧残留也消失，不留下新的。

## 3. 验收

Edit Mode：先留下 40，身上再变成 10 后再死，残留是 10。这次是 0 时没有残留。不创建第二份拾取物。

要人看的一条：地上只剩新的那一笔。这一条不进 Test Runner。
