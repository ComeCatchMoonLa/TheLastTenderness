# 2.43 技术设计：休息后已死的近战回到满血

> **近战死后停用。休息再启用并写回开局位置和满血。头目仍销毁。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`EnemyStatsManager.HandleEnemyDeathEvent` 在发魂之后 `Destroy`。休息不把敌人叫回来。

## 2. 改法

`MeleeRest.Keep`：不是头目且战斗风格是近战时为真。

`Awake` 记下 `restOrigin`。近战死亡时 `hiddenForRest` 为真并停用，不 `Destroy`。`RestoreAfterRest` 启用，位置写成 `restOrigin`，生命写成上限，`isDead` 为假。

休息成功时找出包含未启用的 `EnemyStatsManager`，对 `hiddenForRest` 的调用 `RestoreAfterRest`。

## 3. 单元测试

`Assets/Tests/EditMode/Enemy/MeleeRestTests.cs`。

近战留下，头目不留。恢复后位置、满血、死亡为假。不创建整只敌人。

## 4. 不做

不恢复头目和弓手。不改发魂。
