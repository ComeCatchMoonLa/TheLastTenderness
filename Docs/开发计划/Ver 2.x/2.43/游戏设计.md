# 2.43 游戏设计：休息后已死的近战回到满血

> **交付目标：近战死掉并消失之后休息成功，它回到原位且生命为满。没休息则保持消失。头目仍销毁。**

来源：[FR-燃火-03](../../../需求文档/功能需求/燃火休息与死亡惩罚.md)。

## 1. 为什么是这一刀

前置已解锁。休息回满已经能调用。敌人死亡已经会消失。需求前置是无。[FR-燃火-03](../../../需求文档/功能需求/燃火休息与死亡惩罚.md) 写回到死亡前的位置且生命为满，没休息保持消失。

死亡现在会延时销毁。近战改成停用并记下开局位置，头目仍销毁。后面「本周目不再出现」不能把已经停用的近战当成头目一起销毁。

## 2. 做完之后

不是头目、战斗风格是近战的，死后停用，不销毁。休息后它回到记下的开局位置，生命为满，死亡为假。没休息保持停用。头目和弓手仍销毁。

## 3. 验收

Edit Mode：近战会被留下。停用后再恢复，位置是记下的点，生命是上限，死亡为假。头目不会被留下。不创建场景里的三只近战。

要人看的一条：休息后那只近战回到原位并会再打。这一条不进 Test Runner。
