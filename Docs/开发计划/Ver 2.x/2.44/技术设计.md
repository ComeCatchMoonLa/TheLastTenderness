# 2.44 技术设计：休息不取消余烬，死亡会取消

> **第一次点余烬时记下当时的上限。死亡写回这个数。休息不写。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ApplyEmber` 把 `maxHP` 按比例变长。没有余烬开关。休息和死亡都不缩回。

## 2. 改法

`emberLit` 和 `emberBaseMaxHP` 写在玩家身上。`ApplyEmber` 成功且还没点着时，先记下当前上限，再变长，并写成点着。

`ExtinguishEmber`：没点着则不动。点着则上限和当前生命写回记下的数，并关掉。死亡路径在 `ForfeitSouls` 之后调用它。休息不调用。

## 3. 单元测试

`Assets/Tests/EditMode/Stats/EmberRestTests.cs`。

变长后不熄灭仍是加长的数。熄灭后回到记下的上限。不创建特效。

## 4. 不做

不写再使用一次会不会再加一截。不新做熄灭特效。
