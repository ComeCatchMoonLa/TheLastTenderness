# 2.44 游戏设计：休息不取消余烬，死亡会取消

> **交付目标：休息后生命上限仍是余烬那一档。死亡后缩回没有余烬的一档。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。2.20 已经会把生命上限变长。需求前置是无。[FR-周目-02](../../../需求文档/功能需求/周目与结局.md) 写休息后上限仍是余烬那一档，死亡后熄灭。

## 2. 做完之后

点着余烬后，休息不把上限缩回去。死亡后上限回到点余烬之前的那一档，余烬关掉。没有余烬时死亡不改上限。

## 3. 验收

Edit Mode：上限 100、比例 0.2 后是 120。不调用熄灭时仍是 120。熄灭后是 100，余烬为假。不创建熄灭特效。

要人看的一条：坐下后血条仍是加长的那一档，死亡复活后缩回。这一条不进 Test Runner。
