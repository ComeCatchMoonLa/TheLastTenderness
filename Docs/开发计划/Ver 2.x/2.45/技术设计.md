# 2.45 技术设计：出血蓄满掉一截

> **加上的量乘（1 减抗性）。到容量就扣调用方传入的一截并清空。红苔只清空。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有出血槽。生命扣减在 `TakeDamage`。

## 2. 改法

`BleedMeter.Add`：容量小于或等于 0 时打出资产名和 `capacity`，槽不变。否则加上 `gain * (1 - 抗性)`，抗性限制在 0 到 1，结果不超过容量。

`BleedMeter.TryProc`：槽小于容量时返回 false。到了则返回 true，槽写成 0。

`BleedMeter.ApplyChunk`：从生命减去传入的一截，不低于 0。

`BleedMeter.Clear`：槽写成 0，不扣血。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/BleedMeterTests.cs`。

蓄满扣一截并清空。抗性减半涨幅。清槽不扣血。容量空着不变。不创建图标。

## 4. 不做

不写死一截占最大生命的比例。不写停手后槽往回掉。不接武器命中。
