# 2.45 游戏设计：出血蓄满掉一截

> **交付目标：槽蓄满立刻掉一截血并清空。蓄满前喝红苔则清槽，不掉那截。抗性高时同样一击涨得更少。**

来源：[FR-异常-01](../../../需求文档/功能需求/状态积蓄.md)。

## 1. 为什么是这一刀

前置已解锁。程序前置是无。需求前置是无。[FR-异常-01](../../../需求文档/功能需求/状态积蓄.md) 写蓄满掉一截并清空，蓄满前喝红苔则清槽且不掉那截。掉一截按最大生命再加多少，调研标了待核对，这一版不选，一截的数由调用方传入。

这条槽后面的毒和冰会沿用。抗性用 0 到 1：0 时这一击全加上，1 时不加。

## 2. 做完之后

槽加到容量时立刻按传入的一截扣血，槽变成 0。还没满时清槽，血不变，槽变成 0。同样的一击，抗性更高时槽涨得更少。

## 3. 验收

Edit Mode：容量 10、抗性 0、加上 10 后蓄满，扣 30，槽为 0。抗性 0.5 时加上 10 只到 5，不扣血。清槽后血不变。容量空着打出错误。不创建异常图标。

要人看的一条：槽往上走，蓄满时血条再掉一截。这一条不进 Test Runner。
