# 2.46 技术设计：普通强化停在加十，另两条停在加五

> **到顶就停。普通上限 10，鳞片和闪耀上限 5。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`WeaponItem.reinforceLevel` 能读写。没有到顶就停。

## 2. 改法

`ReinforceCap.Normal` 是 10。`ReinforceCap.Scale` 和 `ReinforceCap.Twinkling` 是 5。

`ReinforceCap.TryRaise`：当前等级已经大于或等于这条上限时返回 false，等级不变。否则加一。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/ReinforceCapTests.cs`。

普通 9 到 10，10 停。鳞片和闪耀 5 停。不创建强化菜单。

## 4. 不做

不扣矿石个数。不扣灵魂。不把鳞片的上限用到普通路线上。
