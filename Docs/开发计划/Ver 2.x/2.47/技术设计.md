# 2.47 技术设计：王座用首领魂换走一项

> **在场才换。魂离开背包，只放入选定的一件。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`GiftExchange` 能判断交的是不是要的那一件。没有首领魂换成一项。

## 2. 改法

`BossSoulTrade.TryExchange`：不在场、魂不在背包、或选定的是空，背包不变，返回 false。在场则拿走魂，只把选定的那一件放进背包。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/BossSoulTradeTests.cs`。

换走一件。不在场时不变。不创建王座窗。

## 4. 不做

不另收灵魂。不把魂捏碎换成灵魂计数。不新导模型。
