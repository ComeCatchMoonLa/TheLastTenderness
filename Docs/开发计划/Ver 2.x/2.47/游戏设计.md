# 2.47 游戏设计：王座用首领魂换走一项

> **交付目标：交出首领魂，只得到选定的那一件。不能同时得到两项。他不在场时换不了。**

来源：[FR-注入-04](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

前置已解锁。2.17 已经会把对的物品交出去。需求前置是无。[FR-注入-04](../../../需求文档/功能需求/注入与强化.md) 写交出首领魂后得到选定的一项，不能同时得到两项。是否另收一笔灵魂，调研标了待核对，这一版不另收。

## 2. 做完之后

他在场、背包里有这颗魂时，魂离开背包，只放入选定的那一件。另一件不进背包。他不在场时，背包不变。

## 3. 验收

Edit Mode：换走一件后背包里是这一件，没有魂，也没有另一件。不在场时两边不变。不创建王座窗，不新导模型。

要人看的一条：和他确认之后背包里只有选定的那一件。成品没有模型时外形是占位。这一条不进 Test Runner。
