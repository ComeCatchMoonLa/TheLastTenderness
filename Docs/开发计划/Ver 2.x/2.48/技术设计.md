# 2.48 技术设计：坐下成功记下这堆火

> **只在坐下成功时改写上次的火。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`CampFireInteractable` 在允许休息时回满。没有「上次的火」。

## 2. 改法

`LastBonfire.Remember`：坐下为真、并且火有名字时，记下这个名字。坐下为假，或名字是空，保持原来的。

`CampFireInteractable` 只在 `CampFireRest.Allow` 通过之后调用 `Remember(name, true)`。点火那一支不调用。坐不下去在允许之前返回，不调用。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/LastBonfireTests.cs`。

成功记下。不允许时不改。不调用时不改。不创建火堆。

## 4. 不做

不改传送落地记在哪一堆。不把从旁边走过写成另一次交互。
