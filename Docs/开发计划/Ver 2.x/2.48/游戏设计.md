# 2.48 游戏设计：坐下成功记下这堆火

> **交付目标：坐下成功后，这堆火是下次回去的那一处。从旁边走过不改。坐不下去时也不改。**

来源：[FR-篝火-08](../../../需求文档/功能需求/篝火菜单.md)、[FR-周目-03](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

前置已解锁。坐下成功会休息（2.4）。附近有敌对者时坐不下去（2.14）。需求前置是无。[FR-篝火-08](../../../需求文档/功能需求/篝火菜单.md) 写坐不下去不改重生点。[FR-周目-03](../../../需求文档/功能需求/周目与结局.md) 写人回到上次坐下的火。传送落地记在出发的火还是落地的火仍待核对，这一版不选。

## 2. 做完之后

坐下成功，记下的火换成这一处。坐不下去，仍是上一次记下的。从旁边走过，也不改。

## 3. 验收

Edit Mode：成功坐下后记下的名字是这一处。不允许坐下时名字不变。不调用记下时名字不变。不新做火堆。

要人看的一条：坐到另一堆火之后，回去的是这一堆。这一条不进 Test Runner。
