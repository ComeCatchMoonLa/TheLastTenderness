# 2.49 技术设计：回城骨把人送回上次的火

> **先看能不能用。能用才改位置、扣骨头、补生命蓝和药瓶，并让敌人走休息重置。灵魂和余烬不动。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`LastBonfire.recorded` 是上次坐下的火。`PlayerStatsManager` 有 `soulCount` 和 `emberLit`。休息用 `estusLeft = estusShare`、`ashLeft = ashShare`，并用 `EnemyStatsManager.RestoreAfterRest`。没有回城骨。

## 2. 改法

`HomewardBone.Allowed`：头目血条可见、骨头不大于 0、或上次的火没有名字时，为假。

`HomewardBone.TryUse`：不允许时返回 false，不改传入的状态。允许时位置名改成上次的火，骨头减一，生命和蓝写成各自上限，血瓶和灰瓶写成各自划分，`resetEnemies` 为真。不写灵魂，不写余烬。

`HomewardBoneItem`：放不出时不播使用动画。使用成功后把上述结果写回玩家，按减掉的个数扣背包里的这一件，并把人挪到名字相同的篝火。`resetEnemies` 为真时，对场上敌人调用已有的 `RestoreAfterRest`。不调用 `ReturnFromDeath`，不调用 `ExtinguishEmber`，不调用 `ForfeitSouls`。

## 3. 单元测试

`Assets/Tests/EditMode/Consumable/HomewardBoneTests.cs`。

成功时位置、骨头、生命、蓝、两瓶、灵魂、余烬和重置旗标。头目血条出现时不变。不创建骨头模型，不摆敌人。

## 4. 不做

不走死亡复苏。不补精力。不把回城骨自己的次数补回去。
