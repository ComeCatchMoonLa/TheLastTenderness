# 2.49 游戏设计：回城骨把人送回上次的火

> **交付目标：用掉一个后回到上次坐下的火。生命、蓝和药瓶次数按休息补满。灵魂不清零。余烬不熄灭。周围普通敌人按休息重置。头目血条已经出现时放不出去。**

来源：[FR-周目-04](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

前置已解锁。上次的火已有（2.48）。余烬开关已有（2.44）。需求前置是无。[FR-周目-04](../../../需求文档/功能需求/周目与结局.md) 写回到上次的火，灵魂和余烬保持原样，骨头少一个，药瓶和普通敌人按休息重置，头目血条出现时放不出去。

这一条会移动玩家，并让普通敌人走休息那次重置。高风险。

## 2. 做完之后

有上次的火、骨头至少还有一个、头目血条没出现时：人回到记下的那一处，骨头少一个，生命和蓝补到当前上限，血瓶和灰瓶次数补到这一轮划分，灵魂数字不变，余烬保持开或关。周围已死的近战按休息回来。

头目血条已经出现、没有上次的火、或骨头是 0 时：人不移动，骨头、生命、蓝、药瓶、灵魂、余烬和敌人都不改。

## 3. 验收

Edit Mode：成功时位置名是记下的火，骨头少一个，生命和蓝到上限，两瓶次数到划分，灵魂和余烬不变，并要求重置敌人。头目血条出现时这些都不改。不新做骨头模型。

要人看的一条：人站到那堆火旁边，附近已死的近战重新站起来。这一条不进 Test Runner。
