# 2.5 游戏设计：休息把回复次数写回上限

> **交付目标：已点燃的篝火休息成功后，这名玩家每种回复消耗品的剩余次数回到该物品的 `maxItemAmount`。没休息之前次数不变。**

## 1. 为什么是这一刀

生命、精力、专注已经在 `RestoreVitalsToMax` 里回到上限。次数在这名玩家的字典里，休息成功时还没有写回去。需求 FR-回复-06 和 FR-燃火-04 是同一次休息看到的同一个结果。

## 2. 做完之后

休息成功这条路径把字典里已有的每一种回复消耗品写回 `maxItemAmount`。没调用之前，扣过的次数保持原样。不复活敌人，不改篝火预制体，不生成粒子，不播新的休息动画。`TrySpendConsumable` 的扣次不改。

## 3. 验收

Edit Mode：一件消耗品的上限是 3，先扣到 1。没调用回满次数时仍是 1。调用 `RestoreVitalsToMax` 之后是 3。不创建篝火预制体，不播动画。
