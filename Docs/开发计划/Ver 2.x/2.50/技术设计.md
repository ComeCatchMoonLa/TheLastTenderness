# 2.50 技术设计：使用暗印不留下可捡血迹

> **灵魂大于 0 才送回。灵魂写成 0，不写新的残留。头目战进行时整次停住。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`LastBonfire.recorded` 是上次的火。`ForfeitSouls` 会把灵魂写成残留。`WorldEventManager.bossFightIsActive` 在开战时为真，击败后为假。回城骨自己查了一次这个字段。

## 2. 改法

`BossFightGate.Active`：含未激活物体查找 `WorldEventManager`。任一个 `bossFightIsActive` 为真则返回真。一个都找不到时打出 `WorldEventManager: bossFightIsActive 未找到` 并返回真。回城骨改成调用这一处。

`DarkSign.TryUse`：头目战进行、灵魂不大于 0、或上次的火没有名字时，返回 false，不改传入状态。否则位置名改成上次的火，灵魂写成 0。不改残留有无，不改残留数字。

`DarkSignItem`：放不出时不播使用动画。成功后把灵魂写成 0，人挪到同名篝火。不调用 `ForfeitSouls`，不扣这件物品的个数。

## 3. 单元测试

`Assets/Tests/EditMode/Consumable/DarkSignTests.cs`。

成功时位置和灵魂，原有残留还在。头目战进行时不变。不创建血迹。

## 4. 不做

不送到传火祭祀场。不熄灭余烬。不补生命。不改普通死亡留下残留。
