# 2.50 游戏设计：使用暗印不留下可捡血迹

> **交付目标：灵魂大于 0 时使用暗印，人在上次的火边，灵魂为 0，使用点没有可捡的灵魂残留。头目战进行时放不出去。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。上次的火已有（2.48）。普通死亡留下残留已有（2.40），这一版不改那条。需求前置是无。[FR-周目-03](../../../需求文档/功能需求/周目与结局.md) 写送回火边、灵魂为 0、使用点没有残留，头目血条出现时放不出去。从未坐下时送到传火祭祀场主火：仓库没有这堆火的名字，这一版不送。

## 2. 做完之后

灵魂大于 0、有上次的火、头目战没在进行：人回到记下的那一处，灵魂变成 0。已经留在别处的残留还在，使用点不新写一笔。

头目战正在进行、灵魂是 0、或没有上次的火：人不移动，灵魂和残留都不改。

## 3. 验收

Edit Mode：成功时位置名是记下的火，灵魂是 0，原有残留数字不变。头目战进行时这些都不改。不新做血迹。

要人看的一条：人站到那堆火旁边，脚下没有新的可捡灵魂。这一条不进 Test Runner。
