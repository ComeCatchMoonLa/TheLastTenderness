# 2.51 技术设计：催化器上能读到法术威力

> **填了才读得到。读到的就是填上的数，包括 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`WeaponItem.catalystKind` 能标出四种催化器。没有法术威力。

## 2. 改法

`WeaponItem` 增加 `spellPowerFilled` 和 `spellPower`。

`SpellPower.TryRead`：没填返回 false。填了返回 true，并把 `spellPower` 交给调用方。填了 0 时这个数是 0。

## 3. 单元测试

`Assets/Tests/EditMode/Spells/SpellPowerTests.cs`。

填了 12 读回 12。没填读不到。填了 0 读回 0。不创建面板，不施法。

## 4. 不做

不把威力乘进即时治疗或持续治疗。不选属性软上限。
