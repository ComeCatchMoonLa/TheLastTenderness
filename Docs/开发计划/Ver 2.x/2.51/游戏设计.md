# 2.51 游戏设计：催化器上能读到法术威力

> **交付目标：催化器上填了法术威力，读回那个数。没填的是空，不是 0。填了 0 时读回 0。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。四种催化器已有（2.26）。需求前置是无。调研写威力是催化器上的可见数字。[FR-法术-06](../../../需求文档/功能需求/法术.md) 用威力更高的催化器比较同一条即时治疗。怎么乘、属性软上限仍待核对，这一版不选。持续治疗的每秒量不读这个数（2.23）。

## 2. 做完之后

填了 12 就读回 12。没填时读不到，不会当成 0。填了 0 就读回 0。

## 3. 验收

Edit Mode：填了读回那个数，没填读不到，填了 0 读回 0。不新做面板。不把这个数乘进治疗。

要人看的一条：拿着这把催化器时能看见这个数。这一条不进 Test Runner。
