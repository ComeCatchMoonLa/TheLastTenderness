# 2.52 游戏设计：呼救被打断则同伴不来

> **交付目标：呼救做完，更远的同伴进入战斗。做完前被打出硬直，这些同伴不来。旁边同一组的敌人在发现时就转过来。**

来源：[FR-头目-02](../../../需求文档/功能需求/头目.md)。

## 1. 为什么是这一刀

前置已解锁。需求前置是无。[FR-头目-02](../../../需求文档/功能需求/头目.md) 写做完才来、做完前硬直则不来、同组在发现时就转。

这一条会给多名敌人写入目标。高风险。

## 2. 做完之后

呼救做完，不在同一组里的同伴进入战斗。做完前被打出硬直，呼救不算做完，这些同伴保持待机。同一组的人在发现的当时就转向，不必等这次呼救。没配进组、也没配进远处名单的人，发现和追击与现在相同。

## 3. 验收

Edit Mode：同组且已经发现时进入；远处只有做完才进入；做完前打断则不进入。不新做同伴模型。

要人看的一条：呼救片段做完，远处的人转过来；中途打出硬直，他们不过来。片段上要挂上开始和做完。这一条不进 Test Runner。
