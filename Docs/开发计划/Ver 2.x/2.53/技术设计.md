# 2.53 技术设计：余烬时才能召协助

> **余烬开着、并且放好了人，才把他设为可见。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerStatsManager.emberLit` 能开关。没有召唤协助。

## 2. 改法

`EmberSummon.Appears`：余烬为真并且放好了人，才返回真。

`EmberSummonSign.TrySummon`：协助引用是空时打出 `{name}: helper 未填` 并返回 false。否则按 `Appears` 把这个人设为可见或仍隐藏。

## 3. 单元测试

`Assets/Tests/EditMode/Enemy/EmberSummonTests.cs`。

余烬关着不出现。余烬开着并且放好了才出现。不创建角色，不写服务器。

## 4. 不做

不写匹配和服务器。不在没有余烬时把人留在场上。
