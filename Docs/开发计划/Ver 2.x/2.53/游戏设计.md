# 2.53 游戏设计：余烬时才能召协助

> **交付目标：没有余烬时召不来协助。有余烬时，预先放好的那个人站到场上。**

来源：[FR-联机-03](../../../需求文档/功能需求/联机.md)。

## 1. 为什么是这一刀

前置已解锁。余烬能开关（2.44）。需求前置是无。[FR-联机-03](../../../需求文档/功能需求/联机.md) 写没有余烬召不来，有余烬才召来。没有线上服务，这一版用场景里预先放好的一个人，不写匹配。

## 2. 做完之后

余烬关着时，这个人仍不在场上。余烬开着并且这里放好了人，召唤后这个人出现在原来放好的位置。没放人时召不来，并报出缺了谁。

## 3. 验收

Edit Mode：余烬关着不出现。余烬开着并且放好了人才出现。不写服务器，不新做角色。

要人看的一条：有余烬时这个人站在放好的位置。这一条不进 Test Runner。
