# 2.54 技术设计：上交到两档才领奖

> **交对才累计。到档且还没领过，才给出这一档。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`GiftExchange.CanTake` 能判断交的是不是要的那一件。没有按累计发两档奖励。

## 2. 改法

`CovenantHandIn.TryOffer`：`firstAt` 或 `secondAt` 不大于 0 时，打出 `{asset}: firstAt 未填` 或 `{asset}: secondAt 未填`，背包和累计不变，返回 false。交错或不在背包里，同样不变。

交对则从背包拿走，累计加一。累计达到第一档且还没领过，`giveFirst` 为真。达到第二档且还没领过，`giveSecond` 为真。调用方按这两个旗标各放入一次奖励。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/CovenantHandInTests.cs`。

到第一档只给第一次。到第二档再给一次。同一档再交不重复。没填和交错时不变。不创建祭坛。

## 4. 不做

不写死 10 和 30。不处理下一周目再发。不给青教单独做一条名单。
