# 2.55 技术设计：背包按页分开

> **一页只收集这一类。类由物品种类决定。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

暂停列能打开背包。物品有武器、防具、法术、消耗品。没有按页分开。

## 2. 改法

`Item.isRing`：标成戒指的进戒指页。

`BagPages.PageOf`：`WeaponItem` 是武器页，`ArmorItem` 是防具页，`SpellItem` 是法术页，`isRing` 是戒指页，其余是道具页。

`BagPages.Collect`：只把这一页的物品写进调用方给的数组，返回写了几个。

## 3. 单元测试

`Assets/Tests/EditMode/Inventory/BagPagesTests.cs`。

武器页有武器、没有道具。道具页有道具、没有武器。不打开背包窗。

## 4. 不做

不改使用键会不会把钥匙喝掉。不改页签名到调研的另一种写法。
