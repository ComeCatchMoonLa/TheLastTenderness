# 2.55 游戏设计：背包按页分开

> **交付目标：不同种类的物品出现在不同页。点开一页，不会把另一类画在同一列。**

来源：[FR-菜单-02](../../../需求文档/功能需求/菜单.md)。

## 1. 为什么是这一刀

前置已解锁。暂停列能打开背包（2.22）。需求前置是无。[FR-菜单-02](../../../需求文档/功能需求/菜单.md) 写武器、防具、戒指、道具、法术分开。页签名是否和调研逐字相同仍待核对，这一版按这五个名字，不另选用词。钥匙不喝掉不在这一版。

## 2. 做完之后

武器、盾、弓和催化器在武器页。防具在防具页。标成戒指的在戒指页。法术在法术页。其余在道具页。打开其中一页，列里只有这一类。

## 3. 验收

Edit Mode：武器页里有武器、没有道具。道具页里有道具、没有武器。不新做背包贴图。

要人看的一条：背包里翻页时，一页只有这一类。这一条不进 Test Runner。
