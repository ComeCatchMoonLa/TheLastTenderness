# 2.56 游戏设计：身上只有当前这枚印记在生效

> **交付目标：同时拥有多枚印时，只有当前戴上的那一枚在生效。包里的其余几枚不改效果。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。四格戒指已有（2.28），印记戴在这四格上。需求前置是无。[FR-联机-01](../../../需求文档/功能需求/联机.md) 写只有当前装备的那一枚在改效果。召唤标记的颜色和自动进场队列还没有，这一版只决定哪一枚算当前的。

## 2. 做完之后

四格里第一枚标成印记的是当前生效的。同一格列里后面的印记不算。只在背包里、没有戴上的印记不算。四格都没戴印记时，没有当前印记。

## 3. 验收

Edit Mode：戴上的那一枚被读到，背包里的另一枚读不到。两枚都戴上时只读到靠前的那一枚。不新做徽章。

要人看的一条：换上另一枚后，生效的变成新的这一枚。这一条不进 Test Runner。
