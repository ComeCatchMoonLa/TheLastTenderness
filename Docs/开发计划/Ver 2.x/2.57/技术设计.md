# 2.57 技术设计：无敌期间这一下不加异常槽

> **无敌为真时不调用增加。为假时仍走出血槽的 `Add`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`BleedMeter.Add` 会按抗性增加槽。没有任何命中调用它。`isInvulnerable` 为真时，近战在没格挡、没弹反的那一支里不扣血。

## 2. 改法

`StatusBuildup.Add`：无敌为真时返回原来的槽，不调用 `BleedMeter.Add`。无敌为假时把同一次的增量交给 `BleedMeter.Add`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/StatusBuildupTests.cs`。

无敌时槽不变。无敌结束后增加。不创建角色，不播翻滚。

## 4. 不做

不决定翻滚哪一帧把无敌写成真。不把武器命中接上某一种异常。
