# 2.58 技术设计：鳞片和闪耀路线不进十五种注入

> **鳞片和闪耀的注入名单写成空。普通路线原样留下。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`InfusionSwap` 能换种类。`InfusionOffer` 按炭火过滤能不能选。`ReinforceCap` 把鳞片和闪耀停在 5。武器上没有路线。

## 2. 改法

`WeaponItem.upgradePath`：`normal`、`scale`、`twinkling`。

`ScaleInfusion.List`：路线是鳞片或闪耀时返回 0，不写入名单。普通路线把交给它的名字按顺序写入，返回写了几个。不改 `reinforceLevel`。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/ScaleInfusionTests.cs`。

鳞片和闪耀的个数是 0。普通路线读到原来的名字。不创建铁匠菜单。

## 4. 不做

不写死十五种的名字。不改加五上限。不改炭火对照。
