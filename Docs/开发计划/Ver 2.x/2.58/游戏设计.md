# 2.58 游戏设计：鳞片和闪耀路线不进十五种注入

> **交付目标：走鳞片或闪耀的武器不能选那十五种注入。它们仍按自己的加五上限强化。**

来源：[FR-注入-05](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

前置已解锁。再注入、炭火过滤和加号上限已有（2.30、2.35、2.46）。需求前置是无。[FR-注入-05](../../../需求文档/功能需求/注入与强化.md) 写这两种路线的菜单里没有那十五种。十五种的名字和炭火对照仍不写死，这一版只按路线把交给它的名单清空。

## 2. 做完之后

鳞片或闪耀路线的武器，注入名单是空的。普通路线仍留下交给它的那些名字。加号上限仍是鳞片和闪耀到 5、普通到 10。

## 3. 验收

Edit Mode：鳞片和闪耀的名单个数是 0。普通路线读到交给它的名字。不创建铁匠菜单。

要人看的一条：打开这两种武器的注入，十五种都不在。这一条不进 Test Runner。
