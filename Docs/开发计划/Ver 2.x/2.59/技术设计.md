# 2.59 技术设计：协助打不中同伴，入侵打得中主人

> **协助抄主人的队伍。入侵抄另一队。同队跳过仍留在原来的命中里。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DamageCollider` 在目标 `teamID` 与自己相同时直接返回，这一下不扣血。`EmberSummonSign` 只把预先放好的人设为可见，不改队伍。没有入侵者进场。

## 2. 改法

`PhantomTeam.Team`：不是入侵时返回主人的队伍。是入侵时返回传入的另一队。

`PhantomTeam.SameTeamSkips`：两队相同返回 true。这是和现有命中同一句判断，命中代码不改。

`EmberSummonSign.TrySummon(bool, int hostTeam)`：人出现之后，若身上有 `CharacterStatsManager`，把 `teamID` 写成协助的队伍。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/PhantomTeamTests.cs`。

协助等于主人的队伍。入侵等于另一队。同队跳过，不同队不跳过。不创建角色，不改命中函数。

## 4. 不做

不改 `DamageCollider` 的同队返回。不做出侵者进场。不改紫色幻影。
