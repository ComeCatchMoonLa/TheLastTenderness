# 2.59 游戏设计：协助打不中同伴，入侵打得中主人

> **交付目标：协助打中其他协助或主人时不掉血。入侵打中主人会掉血。**

来源：[不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

前置已解锁。余烬能把预先放好的协助召到场上（2.53）。召来的是协助，不是入侵者。需求前置是无。[FR-联机-04](../../../需求文档/功能需求/联机.md) 写协助打不中同伴和主人，入侵打得中主人。

这一条用已有的 `teamID`。同队不掉血已经写在近战命中里。高风险。不改那一行怎么比较。

## 2. 做完之后

协助用主人的 `teamID`，打中主人或其他协助时，现有的同队判断让这一下不掉血。入侵用另一队的 `teamID`，打中主人时同队判断让这一下会掉血。

## 3. 验收

Edit Mode：协助的队伍等于主人。入侵的队伍等于另一队。同队不掉血，不同队会掉血。不新做角色。

要人看的一条：协助挥空主人，入侵打中主人会掉血。这一条不进 Test Runner。
