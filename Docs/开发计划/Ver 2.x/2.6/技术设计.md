# 2.6 技术设计：集中力按门槛增加记忆栏

> **格数是 `CharacterStatsManager.MemorySlotCount`，只读传入的集中力。`SetMaxFocusPointsFromFocusLevel` 仍是 `maxMP = focusLevel * 10`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。门槛与 [`角色与养成.md`](../../../调研文档/角色与养成.md) 的表一致。

## 1. 现在

`focusLevel` 在 `CharacterStatsManager`。`Awake` 用 `SetMaxFocusPointsFromFocusLevel` 把蓝上限写成等级乘 10。没有记忆栏格数。`spells` 列表长度不看集中力。

## 2. 格数

`CharacterStatsManager` 增加公开静态方法 `MemorySlotCount(int focusLevel)`。

| 集中力 | 返回 |
| --- | --- |
| 9 及以下 | 0 |
| 10～13 | 1 |
| 14～17 | 2 |
| 18～23 | 3 |
| 24～29 | 4 |
| 30～39 | 5 |
| 40～49 | 6 |
| 50～59 | 7 |
| 60～79 | 8 |
| 80～98 | 9 |
| 99 及以上 | 10 |

方法不写 `maxMP`，不读戒指，不改 `spells`。本版没有调用方去限制能记住几条法术。

## 3. 单元测试

`Assets/Tests/EditMode/MemorySlotCountTests.cs`。

对 9、10、13、14、80、98、99 调用 `MemorySlotCount`，断言 0、1、1、2、9、9、10。

同一物体上放 `CharacterStatsManager`，把 `focusLevel` 设成 14，反射调用 `SetMaxFocusPointsFromFocusLevel`，断言 `maxMP` 为 140。不创建界面，不改场景。

## 4. 不做

不画记忆栏。不在篝火整理法术。不限制 `spells` 的长度。不加栏戒指。
