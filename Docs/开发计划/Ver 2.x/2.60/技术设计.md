# 2.60 技术设计：头目使用带名字的血条

> **先算出名字和长度。算得出才打开血条，并先写上限再写当前。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ActivateBossBar` 先写当前再写上限。`SetMaxValue` 会把滑条值写成上限，开战时长度不跟当前生命走。名字空着也会打开。

## 2. 改法

`BossBar.TryShow`：名字是空，打出 `{asset}: cName 未填` 并返回 false。上限不大于 0，打出 `{asset}: maxHP 未填` 并返回 false。否则给出名字，长度是当前除以上限，限制在 0 到 1。

`ActivateBossBar`：`TryShow` 失败则不打开。成功则写名字，先写上限，再把当前写成上限乘长度，然后把血条设为可见。不打开 `World`。

## 3. 单元测试

`Assets/Tests/EditMode/World/BossBarTests.cs`。

50 / 100 读到长度 0.5 和名字。名字空着不打开。不创建贴图。

## 4. 不做

不打开 `World`。不收起死亡后的血条。不多具身体共用一条血。
