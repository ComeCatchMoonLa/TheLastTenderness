# 2.60 游戏设计：头目使用带名字的血条

> **交付目标：这场头目开战时出现带名字的长血条，长度对应当前生命。**

来源：[FR-头目-03](../../../需求文档/功能需求/头目.md)。

## 1. 为什么是这一刀

前置已解锁。`WorldUIManager.ActivateBossBar` 已存在。需求前置是无。[FR-头目-03](../../../需求文档/功能需求/头目.md) 写开战时出现带名字的长血条，长度对应当前生命。多具身体共用一条血、死亡后收起，不在这一版。

## 2. 做完之后

名字填了、生命上限大于 0 时，开战写出这个名字，长度是当前生命除以上限。名字没填或上限没填时不打开血条，并报出缺了哪个字段。

## 3. 验收

Edit Mode：名字「甲」、当前 50、上限 100 时，读到「甲」和长度 0.5。名字空着不打开。不新做血条贴图。

要人看的一条：开战时屏幕上的长条按当前生命填充，和敌人头顶的短条分开。`World` 现在是关着的，血条挂在它下面，画面上看不见。把 `Boss Health Bar` 挪到已经开着的 HUD 画布上，不要打开 `World`。这一条不进 Test Runner。
