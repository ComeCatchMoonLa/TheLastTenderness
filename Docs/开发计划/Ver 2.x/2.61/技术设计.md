# 2.61 技术设计：走进雾门后退不出来

> **开战把生命写成上限。战斗进行时不能离开。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ActivateBossFight` 打开血条和雾墙，不把生命写成上限。`BossFightGate` 在 `bossFightIsActive` 时挡住回城骨和暗印。

## 2. 改法

`FogDoor.Begin`：上限大于 0 时，把当前生命写成上限。

`FogDoor.CanLeave`：战斗进行时返回 false，否则 true。

`ActivateBossFight` 在打开血条之前调用 `Begin`。不打开 `World`。送回仍走已有的 `BossFightGate`。

## 3. 单元测试

`Assets/Tests/EditMode/World/FogDoorTests.cs`。

40 写成 100。进行中不能离开，结束后可以。不创建雾墙。

## 4. 不做

不打开 `World`。不改回城骨和暗印的挡住。不把已经打死的头目复活。
