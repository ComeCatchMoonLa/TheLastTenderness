# 2.61 游戏设计：走进雾门后退不出来

> **交付目标：交互雾门后头目以满血开始。战斗没结束时走不回去，使用送回手段仍留在场内。死亡后再进仍是满血。**

来源：[不引入美术开-不引入人工关-非高风险关-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工关-非高风险关-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。头目血条已有（2.60）。送回手段在头目战进行时已经放不出去（2.49、2.50）。需求前置是无。[FR-机关-05](../../../需求文档/功能需求/场景机关.md) 写满血开战、没结束走不回去、送回仍留在场内、死亡后再进仍是满血。

这一条会改开战时的生命。高风险。不打开 `World`。

## 2. 做完之后

开战把当前生命写成上限。战斗进行时不能离开。战斗结束后可以离开。再次开战仍写成满血。

## 3. 验收

Edit Mode：上限 100、当前 40 时，开战变成 100。战斗进行时不能离开，结束后可以。不新做雾墙。

要人看的一条：走进去之后从里面走不回去。雾墙碰撞在场景里。不要打开 `World`。这一条不进 Test Runner。
