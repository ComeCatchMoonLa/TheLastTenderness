# 2.62 技术设计：崩盾之后可以处决

> **精力打空时写成可以处决。正面贴上去仍走已有的弹反处决。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AttemptBlock` 在精力到 0 时播 `"Guard_Break"`，不把 `canBeRiposted` 写成真。`CriticalAttackAction.Choose` 只在 `canBeRiposted` 为真且正面点积够时选处决。

## 2. 改法

`GuardBreak.OpensRiposte`：精力不大于 0 时返回 true。

`AttemptBlock` 在播 `"Guard_Break"` 的同一支里，把 `canBeRiposted` 写成 `OpensRiposte` 的结果。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/GuardBreakTests.cs`。

精力 0 打开。精力大于 0 不打开。打开后正面点积够选处决。不创建角色，不播动画。

## 4. 不做

不改弹反窗口。不改背刺点积。
