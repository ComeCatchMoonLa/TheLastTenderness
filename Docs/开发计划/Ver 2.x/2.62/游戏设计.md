# 2.62 游戏设计：崩盾之后可以处决

> **交付目标：盾被打空并弯腰后，贴上去能进入和弹反相同的一次处决。**

来源：[FR-处决-04](../../../需求文档/功能需求/背刺与处决.md)。

## 1. 为什么是这一刀

前置已解锁。格挡耗尽已经会破防（0.16）。需求前置是无。[FR-处决-04](../../../需求文档/功能需求/背刺与处决.md) 写盾被打空并弯腰后贴上去进入处决。盾还举着、精力没空时，这一下仍是普通攻击。

## 2. 做完之后

精力被打到 0 并弯腰时，可以被处决。贴上去、正面点积够，进入和弹反相同的处决。精力还大于 0 时，不能因此进入处决。

## 3. 验收

Edit Mode：精力 0 时打开处决。精力大于 0 时不打开。打开之后、正面点积够，选的是处决。不新做动画。

要人看的一条：弯腰之后贴上去，双方锁进处决动作。这一条不进 Test Runner。
