# 2.63 技术设计：背后贴住进入背刺

> **还没锁、并且在背后距离内，才进入。已经锁上就不再进。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AttempBackStab` 在已经背刺时直接返回，否则写上锁定和无敌，并调用 `GetBackStabbed`。点积判断在 `Choose`。

## 2. 改法

`BackstabLock.TryEnter`：已经锁上返回 false。不在距离内，或点积不在 -1 到 -0.8，返回 false。否则把锁定写成真并返回 true。

`AttempBackStab` 先问 `TryEnter`。返回 false 则不写无敌、不调用 `GetBackStabbed`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/BackstabLockTests.cs`。

背后距离内进入一次。再按不进入。侧面不进入。不创建角色，不播动画。

## 4. 不做

不选伤害倍率。不把鞭排除在背刺外。
