# 2.63 游戏设计：背后贴住进入背刺

> **交付目标：站在人形背后的距离内按这一下，双方锁进背刺。目标生命下降一次。播完才能再动。**

来源：[不引入美术开-不引入人工关-非高风险关-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工关-非高风险关-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。`CriticalAttackAction` 已能在点积足够时调用 `GetBackStabbed`。需求前置是无。[FR-处决-01](../../../需求文档/功能需求/背刺与处决.md) 写背后距离内锁进背刺，掉一次血，播完才能再动。伤害倍率和鞭类不进背刺见调研待核对，这一版不选。

这一条会写上背刺锁定和无敌。高风险。

## 2. 做完之后

在距离内、点积在背后，并且还没锁上时，进入背刺。已经锁上时再按，不再进一次，所以不再掉第二次血。不在距离内，或点积不够背后，不锁。

## 3. 验收

Edit Mode：距离内、点积 -0.9、还没锁，进入并锁上。已经锁上时不再进入。点积 0 不进入。不新做鞭。

要人看的一条：贴在背后按下去，双方锁进 `"Back Stab"`，播完才能再动。这一条不进 Test Runner。
