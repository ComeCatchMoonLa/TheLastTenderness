# 2.64 技术设计：头目换阶段

> **按填好的生命比例换一次。只有配置了打不中，才把无敌写成真。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`UpdateBossHealthBar` 在一半血时总是调用 `ShiftToSecondPhase`。`ShiftToSecondPhase` 总是把 `isInvulnerable` 写成真，并播 `"Phase Shift"`。`hasPhaseShifted` 之后 `GetNewAttack` 改用 `sencondPhaseAttacks`。

## 2. 改法

`BossCombatStanceState.phaseThreshold`：当前生命 / 上限不高于这个数才换。小于或等于 0 表示这场不换。

`BossCombatStanceState.phaseBlocksHits`：为真时这段打不中。

`BossPhase.ShouldShift`：已经换过、上限不大于 0、或门槛不大于 0 时返回 false。否则当前 / 上限不高于门槛时返回 true。

`UpdateBossHealthBar` 用 `ShouldShift` 决定是否调用 `ShiftToSecondPhase`。`ShiftToSecondPhase` 只在 `phaseBlocksHits` 为真时把无敌写成真，不把已经为真的无敌清掉。

## 3. 单元测试

`Assets/Tests/EditMode/Enemy/BossPhaseTests.cs`。

50 / 100、门槛 0.5 要换。60 不换。换过不换。门槛 0 不换。不创建头目，不播动画。

## 4. 不做
