# 2.65 技术设计：死后撤雾并点起新火

> **头目死亡时清场。封着的新火这时才解开。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`BossHasBeenDefeated` 会关雾门和血条，没有调用方。篝火不看头目死没死。

## 2. 改法

`BossClear.Apply`：雾门写成关，头目不再留下，新火的封印写成假。

`CampFireInteractable.sealedUntilBossClear`：为真且还没点燃时，交互直接返回。

`BossHasBeenDefeated` 若指了 `rewardFire`，把 `sealedUntilBossClear` 写成假。

头目死亡、并且还没清过场时，调用 `BossHasBeenDefeated`。

## 3. 单元测试

`Assets/Tests/EditMode/World/BossClearTests.cs`。

清场后三个旗标是关、不留、可点。不创建雾墙和火堆。

## 4. 不做

不处理玩家先死、新火还不出现。不把已经销毁的头目再生成一次。
