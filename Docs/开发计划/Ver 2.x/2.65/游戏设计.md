# 2.65 游戏设计：死后撤雾并点起新火

> **交付目标：头目死亡后雾门撤掉，本周目不再出现，场地里可以点起新的篝火。**

来源：[FR-头目-06](../../../需求文档/功能需求/头目.md)。

## 1. 为什么是这一刀

前置已解锁。雾门战已经能开始，头目死亡已有。需求前置是无。[FR-头目-06](../../../需求文档/功能需求/头目.md) 写死亡后雾门撤掉，本周目不再出现，可以点起新火。人在头目还活着时死亡、新火还不在，不在这一版另做。

这一条会在头目死亡时改世界旗标。高风险。

## 2. 做完之后

头目死亡后雾门关掉，本周目头目不再留在场上，封着的新火可以点。头目还活着时，封着的新火点不着。

## 3. 验收

Edit Mode：清场后雾门为关、头目不留、新火不再封。还没清场时新火仍封着。不新做火堆。

要人看的一条：打死之后雾门没了，旁边那堆新火可以点着。把 `rewardFire` 指到那堆火，并勾上 `sealedUntilBossClear`。这一条不进 Test Runner。
