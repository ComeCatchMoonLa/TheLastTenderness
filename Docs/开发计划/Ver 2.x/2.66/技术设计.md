# 2.66 技术设计：一场头目的场地机关

> **进行中读战中开关。结束后读战后开关。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

开战和清场会改雾门和血条。没有这场自己的机关开关。

## 2. 改法

`ArenaDevice.IsOn`：战斗进行时返回战中开关。否则返回战后开关。

`WorldEventManager` 增加 `deviceOnDuringFight`、`deviceStaysAfter`、`deviceOn`。开战写成进行中的结果。清场写成结束后的结果。

## 3. 单元测试

`Assets/Tests/EditMode/World/ArenaDeviceTests.cs`。

战中开、战后关。战中关、战后开。不创建碰撞体。

## 4. 不做

不决定哪一面墙是幻影墙。不做第二场。
