# 2.66 游戏设计：一场头目的场地机关

> **交付目标：这一场配置了的机关，在战里按配置生效，战后保持写明的开关。**

来源：[不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内关.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险关-1个以上FR关-五小时内关.md)。

## 1. 为什么是这一刀

前置已解锁。头目战已经能开始（2.61）和结束（2.65）。需求前置是无。[FR-头目-07](../../../需求文档/功能需求/头目.md) 写这场配置了的机关在战里生效，战后保持写明的开关。哪一面墙是幻影墙不在这一版。第二场不在这一版。

这一条写在开战和清场上。高风险。

## 2. 做完之后

战斗进行时，机关开不开等于这场填的「战中」。战斗结束后，等于这场填的「战后」。没配战中的那场，战里是关的。

## 3. 验收

Edit Mode：战中为开、战后为关时，进行中是开，结束后是关。战中为关、战后为开时，反过来。不铺关卡。

要人看的一条：这场碰撞体在战里和战后是否还挡着。把两个开关填在这场上。这一条不进 Test Runner。
