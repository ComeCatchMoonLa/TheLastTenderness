# 2.67 技术设计：有协助时头目更厚

> **有协助且倍数填了，才把上限乘上。同一场只乘一次。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

开战会把当前生命写成上限。不看有没有协助。

## 2. 改法

`BossThickness.TryRaise`：没有协助时不改，返回 false。有协助但倍数不大于 0 时，打出 `{asset}: allyHealthMultiplier 未填`，不改，返回 false。否则上限写成原来的数乘倍数，返回 true。

`WorldEventManager` 增加 `allyJoined`、`allyHealthMultiplier`、`allyHealthApplied`。开战在写满之前，还没乘过才调用 `TryRaise`。乘上之后把 `allyHealthApplied` 写成真。

## 3. 单元测试

`Assets/Tests/EditMode/World/BossThicknessTests.cs`。

没有协助不变。倍数 1.5 变成 1.5 倍。倍数空着不改。不创建头目。

## 4. 不做

不改攻击欲望。不写死倍率。
