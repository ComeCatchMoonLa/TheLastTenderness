# 2.67 游戏设计：有协助时头目更厚

> **交付目标：协助跟着进雾门后，头目生命高于单人时的同一场。**

来源：[FR-头目-05](../../../需求文档/功能需求/头目.md)。

## 1. 为什么是这一刀

前置已解锁。已经能召到协助（2.53），雾门战能开始（2.61）。需求前置是无。[FR-头目-05](../../../需求文档/功能需求/头目.md) 写有协助时生命上限高于单人。倍率按这场配置，调研仍待核对，这一版用填上的倍数。攻击欲望不在这一版。

## 2. 做完之后

没有协助时，上限仍是原来的数。有协助、并且倍数填了时，上限变成原来的数乘这个倍数，并补到这个新上限。倍数没填时不改上限，并报出缺了字段。同一场只乘一次。

## 3. 验收

Edit Mode：没有协助时 100 仍是 100。有协助、倍数 1.5 时是 150。倍数空着不改。不新做头目外形。

要人看的一条：协助一起进去时，血条比单人那次更长。在这场勾上 `allyJoined`，并填 `allyHealthMultiplier`。这一条不进 Test Runner。
