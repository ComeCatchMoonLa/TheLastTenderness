# 2.68 技术设计：咒死蓄满则死亡

> **涨和清空沿用 `BleedMeter`。蓄满致死，离开来源才衰减，没满才能祝福。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`BleedMeter.Add` / `TryProc` / `Clear` 会涨、蓄满清空、直接清空。没有咒死死亡，也没有离开来源后的衰减。

## 2. 改法

`CurseMeter.Decay`：槽不大于 0 时保持 0，不报错。否则速度不大于 0 时打出 `{asset}: curseDecay 未填`，槽不变。否则减去速度乘时间，不低于 0。

`CurseMeter.TryKill`：调用 `BleedMeter.TryProc`。蓄满则槽写成 0 并返回 true。

`CurseMeter.TryBless`：槽已经不小于容量、且容量大于 0 时返回 false，槽不变。否则写成 `BleedMeter.Clear()`。

`CharacterStatsManager` 增加 `curseMeter`、`curseCapacity`、`curseDecay`、`curseInSource`。`Update` 里不在来源、且还活着时调用 `Decay`。`GainCurse` 用 `StatusBuildup.Add` 再 `TryKill`，杀死时把 `currentHP` 写成 0、`isDead` 写成真。`DrinkBlessing` 在未死亡时调用 `TryBless`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/CurseMeterTests.cs`。

蓄满致死并清空。离开来源按速度下降且不致死。速度空着不变。没满祝福清掉。蓄满祝福不清。不创建角色，不播死亡动作。

## 4. 不做

不接武器命中。不写死衰减速度。不播 `Death`。牺牲戒指不改这次死亡。
