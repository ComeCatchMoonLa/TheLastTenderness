# 2.69 技术设计：中毒会持续掉血，紫苔能停

> **蓄满才开始计时。紫苔把剩余时间写成 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

异常槽能涨、能蓄满清空。没有持续掉血，也没有紫苔。

## 2. 改法

`PoisonDoT.TryStart`：槽小于容量时不开始。时长不大于 0 时打出 `{asset}: poisonDuration 未填`，槽不变。否则槽写成 0，剩余时间写成时长。

`PoisonDoT.Tick`：剩余时间不大于 0 时不掉血。每秒伤害不大于 0 时打出 `{asset}: poisonDamagePerSecond 未填`，时间和生命都不变。否则按这一小段时间扣血，不低于 0，并减去用掉的时间。

`PoisonDoT.Stop`：剩余时间写成 0。

`CharacterStatsManager` 增加 `poisonMeter`、`poisonCapacity`、`poisonDuration`、`poisonDamagePerSecond`、`poisonTimeLeft`。`GainPoison` 用 `StatusBuildup.Add` 再 `TryStart`。`Update` 调用 `Tick`。`DrinkPurpleMoss` 在还剩时间时调用 `Stop`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/PoisonDoTTests.cs`。

蓄满后按秒掉血，时间走完停止。紫苔之后不再掉。时长空着不开始。不创建角色。

## 4. 不做

不接武器命中。不写死时长和每秒伤害。发作前的衰减不在这一版。剧毒和另一种药不在这一版。
