# 2.69 游戏设计：中毒会持续掉血，紫苔能停

> **交付目标：中毒槽蓄满后按填好的时长掉血，紫苔让这段停下。**

来源：[FR-异常-02](../../../需求文档/功能需求/状态积蓄.md)。

## 1. 为什么是这一刀

前置已解锁。会涨的异常槽已经有了（2.45、2.68）。需求前置是无。中毒后持续掉血，喝对应的苔停止，FR-异常-02 已写。维持多久和每秒掉多少仍待核对，写在 `poisonDuration` 和 `poisonDamagePerSecond` 上。

## 2. 做完之后

槽到容量、时长和每秒伤害都填了时，槽清空，并在这段时间里按每秒伤害掉血。时间走完自己停。紫苔把剩余时间写成 0，之后不再掉。时长或每秒伤害没填时不开始掉血。没蓄满时不掉血。

## 3. 验收

Edit Mode：容量 10、时长 2、每秒 5，蓄满后过 1 秒生命少 5，再过 1 秒再少 5 然后停。中途紫苔之后不再少。时长空着不开始。不新做瓶子。
