# 2.7 游戏设计：快捷栏能看见回复剩余次数

> **交付目标：快捷栏回复格显示这名玩家的剩余次数。喝成功减一，为 0 时显示 0，休息写回后回到上限。**

来源：[不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md](../../../版本候选池/不引入美术开-不引入人工开-非高风险开-1个以上FR关-五小时内开.md)。

## 1. 为什么是这一刀

剩余次数已经在这名玩家的字典里，休息成功会写回上限。快捷栏还只换图标，看不到次数。需求是 [FR-界面-06](../../../需求文档/功能需求/战斗HUD.md)。

## 2. 做完之后

回复格上的数字等于 `ConsumableRemaining`。喝成功一次，数字减一。次数为 0 时显示 0。`RefillConsumablesToMax` 之后回到该物品的 `maxItemAmount`。

不改 2.5 的写回。不新做数字贴图。数字用和灵魂数相同的文本，不加新字体。

## 3. 验收

Edit Mode：上限 3，扣一次后文本是 2；扣到 0 后文本是 0；调用 `RefillConsumablesToMax` 后文本是 3。不创建篝火，不创建 Animator。
