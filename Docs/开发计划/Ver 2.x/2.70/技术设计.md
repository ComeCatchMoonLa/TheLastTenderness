# 2.70 技术设计：冰霜蓄满后用火解开

> **没有这层时不改伤害和精力回复。发作中才乘。火或蓝苔把剩余时间写成 0。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`TakeDamage` 把五段加总后直接扣血。`RegenerateStamina` 按固定量回复。没有冰霜。

## 2. 改法

`Frostbite.TryProc`：没蓄满不发作。时长、一截、受伤倍数、回复倍数任一不大于 0 时，打出 `{asset}: frostDuration`、`frostChunk`、`frostDamageTaken` 或 `frostStaminaRegen` 未填，槽和生命不变。否则槽写成 0，剩余时间写成时长，生命减去这一截且不低于 0。

`Frostbite.Taken`：没发作时原样返回。发作中乘受伤倍数。

`Frostbite.Regen`：没发作时原样返回。发作中乘回复倍数。

`Frostbite.ClearedByFire`：剩余时间大于 0 且火焰伤害大于 0 时返回 true。

`Frostbite.DrinkBlueMoss`：槽或剩余时间大于 0 时都写成 0。

`Frostbite.Tick`：减去经过的时间，不低于 0。

`CharacterStatsManager` 增加 `frostMeter`、`frostCapacity`、`frostDuration`、`frostChunk`、`frostDamageTaken`、`frostStaminaRegen`、`frostTimeLeft`。`GainFrost` 调用 `TryProc`。`TakeDamage` 在扣血前调用 `Taken`，火焰伤害大于 0 时清掉剩余时间。`RegenerateStamina` 对回复量调用 `Regen`。`Update` 调用 `Tick`。`DrinkBlueMoss` 调用 `DrinkBlueMoss`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/FrostbiteTests.cs`。

蓄满扣一截。发作中伤害和回复按倍数。火解开后不再乘。没满时蓝苔清槽。时长空着不扣。不创建角色。

## 4. 不做

不接武器命中。不写死倍数和这一截。刚结算后的空档不在这一版。
