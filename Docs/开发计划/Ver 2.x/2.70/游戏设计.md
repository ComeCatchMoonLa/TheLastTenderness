# 2.70 游戏设计：冰霜蓄满后用火解开

> **交付目标：冰霜蓄满立刻掉一截，并在一段时间内受伤更高、精力回复更低；火或蓝苔提前解开。**

来源：[FR-异常-04](../../../需求文档/功能需求/状态积蓄.md)。

## 1. 为什么是这一刀

前置已解锁。异常槽已经能蓄满（2.45、2.68）。需求前置是无。蓄满掉一截，并在一段时间内降低精力回复、提高受到的伤害，火或蓝苔解开，FR-异常-04 已写。时长、这一截、受伤倍数和精力回复倍数仍待核对，写在角色上。刚结算后的空档不在这一版。

## 2. 做完之后

槽到容量，并且时长、这一截、受伤倍数、精力回复倍数都填了时，立刻扣掉这一截，槽清空，并在这段时间里受到的伤害乘上受伤倍数，精力回复乘上回复倍数。火焰伤害大于 0 时这段结束。蓝苔在没满时把槽写成 0，已经发作时把剩余时间写成 0。时间走完自己结束。任一必填没填时不发作。没蓄满时不发作。没有这层时，伤害和精力回复仍是原来的数。

## 3. 验收

Edit Mode：容量 10、时长 2、一截 30、受伤倍数 2、回复倍数 0.5。蓄满后生命少 30。这段里伤害 10 变成 20，回复 100 变成 50。火焰伤害大于 0 后倍数不再乘。蓝苔在槽为 4 时清成 0。时长空着不扣那一截。不新做冰冻特效。
