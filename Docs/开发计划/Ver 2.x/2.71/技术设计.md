# 2.71 技术设计：剧毒不能用解中毒的那一瓶

> **普通紫苔只写中毒的剩余时间。开花紫苔只写剧毒的剩余时间。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PoisonDoT` 和 `DrinkPurpleMoss` 只停中毒。没有剧毒。

## 2. 改法

`ToxicDoT.TryStart`：没蓄满不开始。时长、每秒伤害、回复倍数任一不大于 0 时，打出 `{asset}: toxicDuration`、`toxicDamagePerSecond` 或 `toxicStaminaRegen` 未填，槽不变。否则槽写成 0，剩余时间写成时长。

`ToxicDoT.Tick`：和中毒一样按剩余时间扣血。每秒伤害没填时时间和生命都不变。

`ToxicDoT.Regen`：没发作时原样返回。发作中乘回复倍数。倍数不大于 0 时打出未填，回复量不变。

`MossChoice.Apply`：`blooming` 为假时只把中毒剩余时间写成 0。为真时只把剧毒剩余时间写成 0。

`CharacterStatsManager` 增加 `toxicMeter`、`toxicCapacity`、`toxicDuration`、`toxicDamagePerSecond`、`toxicStaminaRegen`、`toxicTimeLeft`。`GainToxic`、`TickToxic`、`DrinkBloomingMoss`。`DrinkPurpleMoss` 改为走 `MossChoice`，不再直接调用 `PoisonDoT.Stop`。`RegenerateStamina` 在冰霜之后再乘剧毒回复倍数。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/ToxicDoTTests.cs`。

掉血。普通紫苔留下剧毒时间和变慢。开花紫苔停下并恢复回复，中毒时间仍在。时长空着不开始。不创建角色。

## 4. 不做

不接武器命中。不写死时长、每秒伤害和回复倍数。
