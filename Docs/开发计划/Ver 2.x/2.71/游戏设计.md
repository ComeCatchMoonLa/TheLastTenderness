# 2.71 游戏设计：剧毒不能用解中毒的那一瓶

> **交付目标：剧毒按自己的时长掉血，普通紫苔不停，开花紫苔才停。**

来源：[FR-异常-03](../../../需求文档/功能需求/状态积蓄.md)。

## 1. 为什么是这一刀

前置已解锁。中毒和紫苔已经生效（2.69）。需求前置是无。普通紫苔不停、开花紫苔才停，FR-异常-03 已写。维持多久、每秒掉多少、精力回复倍数仍待核对，写在角色上。

## 2. 做完之后

剧毒槽蓄满，并且时长、每秒伤害、精力回复倍数都填了时，槽清空，按每秒伤害掉血，精力回复乘上这个倍数。普通紫苔只停中毒，剧毒的剩余时间和变慢仍在。开花紫苔把剧毒剩余时间写成 0，精力回复回到没有剧毒时的量。中毒的剩余时间不被开花紫苔改掉。时间走完自己停。没填或没蓄满时不开始。

## 3. 验收

Edit Mode：剧毒时长 2、每秒 8，过 1 秒少 8。普通紫苔之后剧毒时间仍是 1，回复仍是一半。开花紫苔之后不再少，回复回到原量。中毒时间不被开花紫苔写成 0。时长空着不开始。不新做瓶子。
