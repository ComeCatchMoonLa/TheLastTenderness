# 2.72 技术设计：轻轻推摇杆会走

> **门槛没填时仍用跑步。填了才在门槛内改用行走速度。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HandleMove` 非冲刺时总是 `runSpeed`。冲刺是 `sprintSpeed`。

## 2. 改法

`WalkSpeed.Choose`：冲刺返回冲刺速度。`walkUntil` 不大于 0 或不小于 1 时返回跑步，不报错。输入不大于门槛时，行走速度不大于 0 或不小于跑步，打出 `{asset}: walkSpeed 未填` 并返回跑步。否则返回行走速度。输入大于门槛返回跑步。

`PlayerLocomotionManager` 增加 `walkSpeed`、`walkUntil`。`HandleMove` 用 `Choose` 取代直接取 `runSpeed`。

## 3. 单元测试

`Assets/Tests/EditMode/Locomotion/WalkSpeedTests.cs`。新目录补进 [`可测试性.md`](../../../代码分析/可测试性.md) 的分类表。

输入 0.3 是行走，输入 1 是跑步，冲刺是冲刺。门槛空着仍是跑步。不创建角色。

## 4. 不做

不新做行走动画。不写死门槛。30% 负重那一档不在这一版。
