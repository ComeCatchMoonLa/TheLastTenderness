# 2.72 游戏设计：轻轻推摇杆会走

> **交付目标：输入较小但大于零时慢于跑步，推满仍是跑步，冲刺仍更快。**

来源：[FR-移动-08](../../../需求文档/功能需求/玩家移动与闪避.md)。

## 1. 为什么是这一刀

前置已解锁。`HandleMove` 已有跑步和冲刺。需求前置是无。输入较小时慢于跑步，推满仍是跑步，FR-移动-08 已写。30% 负重以下是否再快一档不在这一版。走和跑的快慢要人看。

## 2. 做完之后

`walkUntil` 在 0 和 1 之间，并且 `walkSpeed` 大于 0、小于跑步时：输入不大于这个门槛走 `walkSpeed`，大于门槛走跑步。推满是跑步。冲刺仍是冲刺速度。门槛没填时仍是跑步，不走出一档。门槛填了但行走速度没填或不少于跑步时，仍是跑步，并报出缺了字段。

## 3. 验收

Edit Mode：门槛 0.5、行走 2、跑步 5、冲刺 7。输入 0.3 是 2，输入 1 是 5，冲刺是 7。门槛空着时输入 0.3 仍是 5。不新做行走动画。

要人看的一条：在玩家上填 `walkUntil` 和 `walkSpeed`，轻轻推、推满、按住冲刺，三档快慢能分开。这一条不进 Test Runner。
