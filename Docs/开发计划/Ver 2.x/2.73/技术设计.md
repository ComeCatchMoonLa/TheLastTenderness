# 2.73 技术设计：身上出现锁定标记

> **锁定且目标未死才显示。图没放上时不显示。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PlayerCameraManager` 有 `lockOnFlag` 和 `curLockOnTarget`。HUD 上没有锁定标记。

## 2. 改法

`LockMark.Shown`：锁定为真且目标未死时返回真。

`HUDWindowsManager` 增加 `lockMark`。`Update` 里：不该显示时关掉图。该显示但图是空的，打出 `{asset}: lockMark 未填`。否则把图挪到目标 `lockOnTransform` 的屏幕坐标。目标在相机背后时关掉。

## 3. 单元测试

`Assets/Tests/EditMode/Camera/LockMarkTests.cs`。

锁定且未死为真。未锁定或已死为假。不创建 HUD，不看画面。

## 4. 不做

不导入锁定贴图。不改锁定和解锁本身。
