# 2.73 游戏设计：身上出现锁定标记

> **交付目标：锁定成立时标记出现在目标身上，解开或目标死亡后消失。**

来源：[FR-镜头-07](../../../需求文档/功能需求/镜头与锁定.md)。

## 1. 为什么是这一刀

前置已解锁。锁定和解锁已经有了。需求前置是无。锁定成功时目标身上出现标记，死亡或解开后消失，FR-镜头-07 已写。标记跟在身上要人看。

## 2. 做完之后

锁定开着、目标还活着时，标记显示，并跟到目标的锁定点在屏幕上的位置。锁定关掉、没有目标、或目标已经死亡时，标记关掉。HUD 上没放标记图时不显示，并报出缺了字段。

## 3. 验收

Edit Mode：锁定且未死是显示。未锁定、或已死，是不显示。不导入新贴图。

要人看的一条：在 HUD 上放一张已有的 `Image`，赋给 `lockMark`。锁上时标记跟着目标，解开或目标死亡后消失。这一条不进 Test Runner。
