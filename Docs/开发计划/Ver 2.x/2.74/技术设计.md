# 2.74 技术设计：弹开之后可以处决

> **帧数没填，或已经过了窗口，弹反不成立，命中走原来的受击。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`isParrying` 为真时，命中总是把攻击者打成 `"Parried"` 并打开处决。没有帧窗口。

## 2. 改法

`ParryWindow.Open`：帧数不大于 0 时打出 `{asset}: parryWindowFrames 未填`，返回假。否则经过的帧小于帧数时返回真。

`EnableIsParrying` 记下当前 `Time.frameCount`。`DamageCollider` 在弹反分支里用经过的帧调用 `Open`。成立才弹开并 `canBeRiposted = true`。不成立则落入原来的受击。贴上去仍走 `CriticalAttackAction` 和 `GetRiposte`。

`CharacterCombatManager` 增加 `parryWindowFrames`、`parryOpenedFrame`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/ParryWindowTests.cs`。

窗口 5 时 0 和 4 为真，5 为假。帧数空着为假。不创建角色，不播动画。

## 4. 不做

不写死帧数。不改处决动画和那一次掉血的算法。
