# 2.74 游戏设计：弹开之后可以处决

> **交付目标：窗口内弹开后可以贴上去处决；窗口不对则自己被打中。**

来源：[FR-处决-03](../../../需求文档/功能需求/背刺与处决.md)。

## 1. 为什么是这一刀

前置已解锁。弹反已经会把攻击者打成 `"Parried"`，贴上去的处决和掉血已经走现成入口。需求前置是无。窗口里弹开后锁进处决，窗口不对则被打中，FR-处决-03 已写。窗口有多少帧仍待核对，写在 `parryWindowFrames` 上。锁进处决的动作要人看。

## 2. 做完之后

弹反按下后的前若干帧里被打中，对方被弹开并允许已有的处决。超过这若干帧，或帧数没填，弹反不成立，自己走原来的受击。贴上去之后仍是已有的 `"Riposte"` / `"Riposted"`，并掉一次血。

## 3. 验收

Edit Mode：窗口 5 帧时第 0 帧和第 4 帧成立，第 5 帧不成立。帧数空着不成立。不新做处决动画。

要人看的一条：在弹反者身上填 `parryWindowFrames`。窗口里弹开后贴上去，看双方锁进处决并掉一次血。窗口外自己掉血。这一条不进 Test Runner。
