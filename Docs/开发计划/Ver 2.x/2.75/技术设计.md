# 2.75 技术设计：霸体血量被打空就中断

> **窗口开着才走这条血量。没开时仍是原来的韧性比较。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`GrantWeaponAttackingPoiseBonus` 把 `offensivePoiseBonus` 加进 `totalPoiseDefence`。命中按剩余韧性决定播不播受击。没有单独的霸体血量，打不空就不会中断这段挥击。

## 2. 改法

`AttackPoise.Holds`：剩余减去这一下，不低于 0。结果大于 0 则继续，否则中断。

`CharacterStatsManager` 增加 `attackPoise`、`attackPoiseActive`。`GrantWeaponAttackingPoiseBonus` 在加成大于 0 时把 `attackPoise` 写成这份加成，并把 `attackPoiseActive` 写成真。`ResetWeaponAttackingPoiseBonus` 把窗口关掉，韧性写回护甲。

`ResolveIncomingHit` 在窗口开着时：继续则受伤动画传空，中断则传原来的受击动画并关掉窗口、韧性写回护甲。生命两种都扣。窗口没开时不读 `attackPoise`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/AttackPoiseTests.cs`。

30 减 10 还剩 20 并继续。再减 20 则中断。30 减 40 直接中断。不创建角色，不播受击。

## 4. 不做

不写死霸体血量和这一下扣多少。窗口结束后的那一击仍走原来的韧性比较。未配置进攻霸体的挥击不进这条。
