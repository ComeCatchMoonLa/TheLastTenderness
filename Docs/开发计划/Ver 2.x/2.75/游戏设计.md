# 2.75 游戏设计：霸体血量被打空就中断

> **交付目标：霸体窗口里血量没被打空时挥击继续；这一下或连续轻击把血量打空时改播受击。**

来源：[FR-硬直-04](../../../需求文档/功能需求/霸体与硬直.md)。

## 1. 为什么是这一刀

前置已解锁。`GrantWeaponAttackingPoiseBonus` 已经会在片段调用时加上进攻韧性。需求前置是无。血量被这一下打空时挥击中断，连续轻击把血量打空时同样中断，FR-硬直-04 已写。挥击中断后改播受击要人看。这一版是高风险：打空判断会被之后的命中读到。

## 2. 做完之后

窗口开着时，命中从这一段的霸体血量里扣掉这一下的 `poiseBreak`。扣完还大于 0，挥击继续，生命仍下降，不播受击。扣完不大于 0，窗口关掉，改播受击，生命仍下降。连续几下把剩余扣到 0 同样中断。窗口没开时，仍走原来的韧性比较。

## 3. 验收

Edit Mode：剩余 30、这一下 10，还剩 20 并且继续。再来 20，剩余 0 并且中断。一下 40 打在 30 上直接中断。不新做受击动画。

要人看的一条：带进攻霸体的挥击挨普通攻击时挥击继续、血下降；把霸体血量打空时挥击改播受击。这一条不进 Test Runner。
