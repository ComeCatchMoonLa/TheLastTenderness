# 2.76 技术设计：追出距离后走回起点

> **回家沿用追击已经在用的导航目标，不在 `OnAnimatorMove` 再写一套速度。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`PursueTargetState` 只要比 `aggroRadius` 远就继续追。`detectionRadius` 只用于待机发现。发现时不记下位置。

## 2. 改法

`Leash.TooFar`：察觉距离不大于 0 时返回假。否则距离大于察觉距离返回真。

`Leash.Arrived`：`returnArrive` 不大于 0 时，还没报过就打出 `{asset}: returnArrive 未填`，返回假。否则距离不大于它返回真。

`EnemyManager` 增加 `spottedFrom`、`spotRecorded`、`returningHome`、`returnArriveWarned`。`IdleState` 在第一次记下目标时写下当时的位置。

`PursueTargetState` 太远时把 `returningHome` 写成真。回家时把导航目标改成 `spottedFrom`，竖直混合写成 1。到了就清掉目标、关掉导航，回到 `IdleState`。

`EnemyAISettings` 增加 `returnArrive`。

## 3. 单元测试

`Assets/Tests/EditMode/Enemy/LeashTests.cs`。

21 对 20 要回家，19 不回家。离起点 1、门槛 2 算到了。门槛空着不算到。不创建敌人，不走导航。

## 4. 不做

不在 `OnAnimatorMove` 增加速度。不写死到点距离。活动范围补满和头目不回血不在这一版。
