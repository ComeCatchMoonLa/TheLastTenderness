# 2.76 游戏设计：追出距离后走回起点

> **交付目标：超过察觉距离后停止追击，走回发现前的位置，到了回到待机。**

来源：[FR-敌人-05](../../../需求文档/功能需求/敌人.md)。

## 1. 为什么是这一刀

前置已解锁。人形追击状态已经有了。需求前置是无。超过配置距离后停止追击，走回发现前的位置并回到待机，FR-敌人-05 已写。配置距离用已经写在设置上的 `detectionRadius`。走到多近算到了仍待核对，写在 `returnArrive`。走回起点要人看。这一版是高风险：回家和根运动写在同一条移动上。

## 2. 做完之后

追击中离目标超过 `detectionRadius` 时，不再追，走向发现前记下的位置。离这个位置不大于 `returnArrive` 时，清掉目标并回到待机。`detectionRadius` 不大于 0 时仍追。`returnArrive` 不大于 0 时不停在待机，并报出缺了字段。玩家再走进察觉范围时，待机会重新发现。

## 3. 验收

Edit Mode：距离 21、察觉 20 要回家。距离 19 不回家。离起点 1、`returnArrive` 2 算到了。`returnArrive` 空着不算到，并报错。不新建移动框架。

要人看的一条：把玩家拉出这只敌人的察觉距离，看它走回发现前的位置并停下。在 AI 设置上填 `returnArrive`。这一条不进 Test Runner。
