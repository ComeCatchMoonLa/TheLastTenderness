# 2.77 技术设计：拉出活动范围后归位并补满

> **只有普通敌人、并且活动范围填了，才回放置点并回满。头目不写这条生命。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

太远时走向发现前的位置，到了不回血。没有放置点，也没有活动范围。

## 2. 改法

`Territory.PulledOut`：是头目，或活动范围不大于 0，返回假。否则距离大于活动范围返回真。

`Territory.Refill`：把当前生命写成上限。

`Territory.Resume`：正在回家、这一下打中、接战距离大于 0、并且离目标不大于接战距离时返回真。

`EnemyAISettings` 增加 `activityRadius`。`EnemyManager` 在 `Start` 记下 `placement`。`returnToPlacement` 为真时，回家的目标改成放置点，到了把生命写成上限。`ResolveIncomingHit` 扣血之后，若 `Resume` 成立，清掉回家，不回血。

## 3. 单元测试

`Assets/Tests/EditMode/Enemy/TerritoryTests.cs`。

普通敌人超出活动范围要回。头目和活动范围空着不回。回到之后生命写成上限。接战距离内被打中转回追击，外面不转。不创建敌人。

## 4. 不做

不写死活动范围。头目不因这条归位。发现前的那次回家仍不回血。
