# 2.77 游戏设计：拉出活动范围后归位并补满

> **交付目标：普通敌人被拉出活动范围后走回放置点并回满；头目不因此回血。**

来源：[FR-头目-01](../../../需求文档/功能需求/头目.md)。

## 1. 为什么是这一刀

前置已解锁。追击已经能被距离打断（2.76）。需求前置是无。拉出活动范围后走回放置点并回满，途中再被打到且仍在接战距离就转回追击，头目不因此回血，FR-头目-01 已写。活动范围写在 `activityRadius`。走回放置点要人看。这一版是高风险：会改敌人生命的写入，并且和追出距离不是同一条回家。

## 2. 做完之后

普通敌人离目标超过 `activityRadius` 时，走向开局记下的放置点。走到之后生命写成上限，再回待机。归途中被打中，并且离目标还不大于 `aggroRadius`，转回追击，生命保持被打过的数。`activityRadius` 不大于 0 时不走这条，仍按追出距离回家、不回血。头目即使超出活动范围也不走这条，生命不因此写成上限。

## 3. 验收

Edit Mode：普通敌人距离 30、活动范围 10 要回放置点。头目同样的距离不回。活动范围空着不回。回到之后 40 写成 100。归途中、接战距离 5、人在 3 处，转回追击。人在 8 处不转回。不新做头目模型。

要人看的一条：在普通敌人的 AI 设置上填 `activityRadius`，把它拉出这个范围，看它走回放置点并且血回满。头目拉开距离时血保持当前值。这一条不进 Test Runner。
