# 2.78 技术设计：打开的门休息后仍开着

> **休息只保留已经打开的旗标，不把开着的门写成关上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有可开关的门。休息会补近战，不碰机关旗标。

## 2. 改法

`HingedDoor.FromFront`：门的前方和从门指向人的水平方向点积大于 0 才算正侧。

`HingedDoor.TryOpen`：已经打开返回假。正侧返回真。背侧返回假。

`HingedDoor.AfterRest`：原样返回打开旗标。

`HingedDoor.Swing`：打开时在关上的朝向上绕竖轴转 90 度。

`DoorInteractable` 在正侧交互成功时把 `opened` 写成真，套上转角，并关掉自身碰撞体。`CampFireInteractable` 休息时找出这些门并调用 `AfterRest`。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/HingedDoorTests.cs`。

正侧打开，背侧不开。休息保留打开和关上。打开后相对原朝向是 90 度。不放进场景。

## 4. 不做

不导入开门动画。钥匙不在这一版。
