# 2.78 游戏设计：打开的门休息后仍开着

> **交付目标：从正侧打开的门保持打开，休息后再回来仍开着。**

来源：[FR-机关-02](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

前置已解锁。需求前置是无。打开后门保持打开，休息或死亡后再回来仍开着，FR-机关-02 已写。外观用方块转 90 度，不进新的开门动画。

## 2. 做完之后

人站在门的正侧交互，门的 `opened` 写成真，方块绕竖轴转 90 度，碰撞关掉，人可以走过去。站在背侧交互，门保持关上。已经打开时再交互，仍然开着。休息调用之后，开着的仍开着，关上的仍关上。场景不重载，死亡回来时这面门也不被写成关上。

## 3. 验收

Edit Mode：正侧可以打开，背侧打不开。打开后休息仍是开的。关上的休息后仍是关的。打开后的朝向相对关上时转了 90 度。不导入开门动画。

要人看的一条：放一块方块，挂上 `DoorInteractable`，方块的正面朝外。从正面交互，看它转开；休息后再回来仍开着。背侧交互打不开。这一条不进 Test Runner。
