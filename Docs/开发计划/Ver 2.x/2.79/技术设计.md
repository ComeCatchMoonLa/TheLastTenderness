# 2.79 技术设计：有钥匙才打得开的门

> **没填钥匙的门不查背包。填了钥匙才要求背包里有这一件，并且不删掉它。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DoorInteractable` 只看正侧。不看背包。

## 2. 改法

`KeyedDoor.Allowed`：不要求钥匙时返回真。要求钥匙时，带着返回真，否则假。

`DoorInteractable` 增加 `key`。`key` 不是空才要求背包里有同一件。不允许时不改 `opened`。允许之后仍走 `HingedDoor.TryOpen`。不调用 `RemoveItem`。

## 3. 单元测试

`Assets/Tests/EditMode/Interactions/KeyedDoorTests.cs`。

没钥匙不开。有钥匙开。不要求钥匙时也能开。不创建背包，不删物品。

## 4. 不做

不删钥匙。不新做钥匙模型。
