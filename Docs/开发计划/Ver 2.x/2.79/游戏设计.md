# 2.79 游戏设计：有钥匙才打得开的门

> **交付目标：没带对应钥匙时门不动；带着就打开并保持打开。**

来源：[FR-机关-03](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

前置已解锁。门已经能从正侧打开，休息后仍开着（2.78）。需求前置是无。没有钥匙打不开，有钥匙打开并保持，FR-机关-03 已写这一眼。钥匙用完消不消失不在这一版。仍是同一块方块。

## 2. 做完之后

门填了 `key` 时，背包里没有这一件，门保持关上。背包里有这一件，从正侧打开，钥匙还在背包里。没填 `key` 的门仍按上一版打开，不要求钥匙。背侧仍然打不开。打开之后休息仍开着。

## 3. 验收

Edit Mode：要求钥匙但没带着，打不开。带着就打开，钥匙还在。不要求钥匙的门，没带着也能从正侧打开。不新做钥匙模型。

要人看的一条：钥匙用一件已有物品，门的 `key` 指到它。没把它放进背包时门不动；放进之后从正面打开。这一条不进 Test Runner。
