# 2.80 技术设计：下一周目留下人，重来世界

> **只清火、门、钥匙和头目战败。等级不进这份重来。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有下一周。头目死亡后过 `destoryWaitTime` 会 `Destroy`。门和钥匙留在当前这场。

## 2. 改法

`NewCycle.Next`：等级原样返回。火、门、战败、钥匙写成没有。

`NewCycle.StripKeys`：从列表里拿走 `isKey` 的物品，其余留下。

`Item` 增加 `isKey`。

`CampFireInteractable` 在 `nextCycleInsteadOfRest` 为真时调用 `NewCycle.Apply`，然后把这勾写成假。

`NewCycle.Apply`：用 `RemoveItem` 清背包钥匙，把门关上并转回，把火写成未点，把每场 `bossHasBeenDefeated` 写成假、战中和唤醒写成假、奖励火重新封上。还在场上的头目停掉尚未结束的隐藏，再显示出来，`isDead` 写成假，生命写成上限。不改 `allyHealthApplied`。

头目死亡不再 `Destroy`。等原来的 `destoryWaitTime` 后只隐藏，好让下一周再显示。

## 4. 不做

不写敌人更难。不生成已经删掉的身体。不改装备、法术和药瓶的写入。
