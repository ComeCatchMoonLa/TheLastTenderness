# 2.80 游戏设计：下一周目留下人，重来世界

> **交付目标：进入下一周后人留下，火、门、钥匙和头目战败按新的一周重来。**

来源：[FR-周目-05](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

前置已解锁。坐下记下的火已有（2.48）。头目战败旗标已有（2.65）。门和钥匙已有（2.78、2.79）。需求前置是无。等级、装备、法术和药瓶强化留下，火、门、钥匙和头目战败重来，FR-周目-05 已写。敌人更难的幅度不在这一版。这一版是高风险：后面的结局建在这套留下和重来上。

## 2. 做完之后

在勾了 `nextCycleInsteadOfRest` 的火上交互一次，进入下一周，这一勾用掉，之后这次交互仍是休息。进入时，等级不动。已点燃的火回到未点，打开的门关上，背包里标成钥匙的物品消失，头目战败旗标清掉。还在场景里的头目显示出来，死亡写成假，生命写成上限。已经从场景里删掉的身体不在这一版放回来。装备、已学法术和药瓶次数这一版不写，所以还在。
