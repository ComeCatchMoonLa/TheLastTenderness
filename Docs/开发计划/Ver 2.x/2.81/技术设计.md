# 2.81 技术设计：结局之后还能再进下一周

> **没记下结局时，火上的下一周勾不调用 `NewCycle.Apply`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`EndingChoice` 能选出一条，没有人调用。`nextCycleInsteadOfRest` 不看有没有结局。

## 2. 改法

`CycleGate.TryRecord`：已经有记录时返回假，记录不变。名字空时打出 `{asset}: ending 未填`，不记。否则记下并返回真。

`CycleGate.Allow`：记录不是空才返回真。

`PlayerStatsManager` 增加 `recordedEnding` 和 `RecordEnding`。`EndingMarker` 交互时用 `EndingChoice.Choose` 的结果去记。

`CampFireInteractable` 只在 `Allow` 为真时才走下一周。否则这一勾留着，继续原来的休息。

## 3. 单元测试

`Assets/Tests/EditMode/World/CycleGateTests.cs`。

第一次记下。第二次不改。空名字不记。没记下不允许，记下后允许。不创建火焰。

## 4. 不做

不改四项篝火菜单。不改三条结局的选择规则。不写敌人更难。
