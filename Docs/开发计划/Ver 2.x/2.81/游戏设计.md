# 2.81 游戏设计：结局之后还能再进下一周

> **交付目标：记下一条结局之后才能进入下一周，进入后仍按留下和重来。**

来源：[FR-周目-08](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

前置已解锁。终局三条已经能选出一条（2.24）。下一周的留下和重来已经成立（2.80）。需求前置是无。留下什么、重来什么按 FR-周目-05 那一份。敌人更难不在这一版。

## 2. 做完之后

终局交互记下一条结局。已经记下时再交互，结局不变。结局名字空着不记下。还没记下时，火上那一勾不会进入下一周，休息仍可进行。记下之后，勾上的火交互一次才进入下一周，规则仍是等级留下，火、门、钥匙和头目战败重来。

## 3. 验收

Edit Mode：第一次记下「传火」。再记「窃火」仍是「传火」。空名字不记下。没记下时不允许进入下一周。记下后允许。不新做过场。

要人看的一条：终局物体挂上 `EndingMarker`，交互一次。再到勾了 `nextCycleInsteadOfRest` 的火上交互，世界按下一周重来。这一条不进 Test Runner。
