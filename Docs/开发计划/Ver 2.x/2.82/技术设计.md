# 2.82 技术设计：智力、信仰或幸运不足时挥击也变慢

> **不足的判断多这三项。系数仍是调用方传入的，空着就停。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`RequirementPenalty.TryScale` 只比力量和敏捷。`WeaponNeed` 也只有这两项。

## 2. 改法

`WeaponItem` 增加智力、信仰、幸运的已填旗标和需求，写法与力量相同。`WeaponNeed` 增加这三项的读取。

`TryScale` 再收这三个等级。任一项已填且等级更低，就和力量、敏捷不足走同一套系数。五项都够或都没填时，速度是 1，伤害不变。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/RequirementPenaltyTests.cs` 补智力不足、智力够、三项没填。不创建 Animator。

## 4. 不做

不写死系数。不改 Animator。不写双手力量取整。
