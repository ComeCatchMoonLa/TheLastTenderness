# 2.82 游戏设计：智力、信仰或幸运不足时挥击也变慢

> **交付目标：这三项里有一项低于需求时，速度系数和力量、敏捷不足时一样变低。**

来源：[FR-注入-06](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

前置已解锁。力量或敏捷不足时更慢已经有了（2.38）。需求前置是无。五项里任一项不足，挥击和收招都变慢，FR-注入-06 已写。伤害高低仍按 FR-属性-05。系数仍由调用方传入。

## 2. 做完之后

武器上能填智力、信仰、幸运需求。这三项里有一项填了并且等级更低时，速度改成传入的速度系数，伤害改成原伤害乘传入的伤害系数。三项都没填，或填了但都够，并且力量和敏捷也够时，速度是 1，伤害不变。系数空着时不改，并报出缺了字段。

## 3. 验收

Edit Mode：智力需求 14、等级 10、系数 0.5 时速度是 0.5、伤害一半。智力等级 14 时速度是 1、伤害不变。三项都没填时速度仍是 1。不新做挥击动画。
