# 2.83 技术设计：防火女加点先预览生命、蓝、精力

> **预览用现成的等级乘十，确认仍走 `LevelPurchase.TryConfirm`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`LevelPurchase.TryConfirm` 只扣魂、加灵魂等级，不改生命、蓝、精力上限。上限是 `CharacterStatsManager.LevelTimesTen`。

## 2. 改法

`LevelPreview.Preview` 按光标所在的一项，把那一项等级加一后乘十，另外两项用现在的等级乘十。

`LevelPreview.TryRaise` 先记下这份预览，再调用 `TryConfirm`。成功后把光标那一项的等级加一，三项上限写成预览里的数。失败时等级和上限不动。

## 3. 单元测试

`Assets/Tests/EditMode/Stats/LevelPreviewTests.cs`。不创建界面。

## 4. 不做
