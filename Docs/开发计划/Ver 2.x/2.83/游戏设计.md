# 2.83 游戏设计：防火女加点先预览生命、蓝、精力

> **交付目标：确认后的生命、蓝、精力上限等于确认前的预览。**

来源：[FR-养成-05](../../../需求文档/功能需求/角色养成.md)。

## 1. 为什么是这一刀

前置已解锁。扣魂加级已经有了（2.27）。上限按等级乘十已经有了。需求前置是无。光标停在一项上时能看见这三项的预览，确认后上限按预览变。负重和每一级花多少灵魂本条不选。

## 2. 做完之后

光标停在生命、蓝或精力上时，先给出确认后的三项上限。停在哪一项，只有那一项按再高一级乘十，另外两项保持现在的上限。确认成功后，灵魂等级加一，灵魂按花费减少，三项上限等于刚才的预览。花费空着或灵魂不够时，等级、灵魂和上限都不变。

## 3. 验收

Edit Mode：生命、蓝、精力都是 10，停在生命上时预览是 110、100、100。花费 100、灵魂 100 确认后，上限仍是这组数，灵魂等级是 11。花费空着时上限仍是 100。不新做界面。不预览负重，不改花费曲线。
