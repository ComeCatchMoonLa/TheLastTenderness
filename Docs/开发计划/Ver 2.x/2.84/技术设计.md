# 2.84 技术设计：法术打在举着的盾上按吸收减伤并扣精力

> **正面举盾才走进现成的格挡结算。没举盾仍直接扣生命。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`SpellDamageCollider` 命中后直接 `TakeDamage`，不看盾。近战的正面举盾在 `CharacterCombatManager.ResolveIncomingHit` 里吸收并 `AttemptBlock`。

## 2. 改法

`SpellOnShield.UseShield` 在举盾且来自正面时为真。吸收和扣精力的数从现成格挡里抽出来，近战和法术共用。

法术命中时，先用弹体位置判断正反。为真时把这一下送进 `ResolveIncomingHit` 的格挡分支。为假时仍 `TakeDamage`。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/SpellOnShieldTests.cs`。不创建弹体，不测翻滚。

## 4. 不做

不新做弹体。不改翻滚无敌。
