# 2.84 游戏设计：法术打在举着的盾上按吸收减伤并扣精力

> **交付目标：正面举盾时，法术按盾的吸收减伤，并扣精力。**

来源：[FR-法术-05](../../../需求文档/功能需求/法术.md)。

## 1. 为什么是这一刀

前置已解锁。弹体按学派进对应伤害段已经有了（0.19）。正面举盾的吸收和扣精力已经有了。需求前置是无。砸在正面举起的盾上时按吸收结算并扣精力。翻滚穿不穿得过本条不选。

## 2. 做完之后

弹体打在正面举着的盾上时，这一下先按盾对该伤害种类的吸收变低，再扣生命，同时按已有格挡扣精力。没举盾，或举着但打在侧面和背后时，仍按原来的伤害扣生命，不扣这次格挡的精力。

## 3. 验收

Edit Mode：举盾且来自正面时走进格挡。魔法 10、该种类吸收 0.5、精力 100 时，生命少 5、精力少 10。没举盾时不走格挡。不新做弹体。不测翻滚。
