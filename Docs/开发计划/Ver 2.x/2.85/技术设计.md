# 2.85 技术设计：卷剑碎片送回并且不减少个数

> **送回仍走 `HomewardBone.TryUse`。这一版只把减掉的个数加回去，并挡住第二份。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`HomewardBone.TryUse` 送回、补药、重置，并把个数减一。拾取是 `PlayerInventoryManager.AddItem`，同一件会再进一次背包。

## 2. 改法

`CoilFragment.TryUse` 调用 `HomewardBone.TryUse`，成功后把个数写回调用前。`CoilFragment.Pickup` 在已经大于 0 时保持原数，否则是 1。

`CoilFragmentItem` 走这次使用，不调用 `TrySpendConsumable`。`AddItem` 在已经有这份碎片时直接返回。

## 3. 单元测试

`Assets/Tests/EditMode/Consumable/CoilFragmentTests.cs`。不创建模型，不测入侵。

## 4. 不做

不新做碎片模型。不改回城骨会减少个数。不判断是不是正在被入侵。
