# 2.85 游戏设计：卷剑碎片送回并且不减少个数

> **交付目标：碎片送回的结果和回城骨一样，个数不减少，再拾取仍是一份。**

来源：[FR-周目-09](../../../需求文档/功能需求/周目与结局.md)。

## 1. 为什么是这一刀

前置已解锁。回城骨送回已经有了（2.49）。需求前置是无。送回、留灵魂、留余烬、按休息补药并重置小怪、个数不减少、再拾取仍是一份。正在被入侵时放不放得出去本条不选。

## 2. 做完之后

使用后回到上次坐下的火。生命和蓝补满，血瓶和灰瓶写回上限，普通敌人按休息重置。灵魂和余烬保持使用前。背包里的个数不减少。已经有一份时再拾取，仍是那一份；没有时拾取得到一份。头目血条已经出现时放不出去，位置和个数都不变。

## 3. 验收

Edit Mode：个数 1、上次的火是甲时，用完位置是甲、个数仍是 1、灵魂和余烬不变、药瓶写回上限、要求重置。再拾取仍是 1。头目血条可见时位置和个数不变。不新做碎片模型。
