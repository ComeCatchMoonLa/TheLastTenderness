# 2.86 技术设计：白签和黄签进场时药瓶对半、生命按未余烬

> **进场只改这一次的次数和上限。回来写回进场前记下的数。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

协助召到场上不改药瓶。余烬把生命上限抬高，未余烬的数在 `emberBaseMaxHP`。血瓶和灰瓶次数在 `estusLeft`、`ashLeft`，上限在 `estusShare`、`ashShare`。

## 2. 改法

`PhantomEntry.Enter` 只接受白签和黄签。先记下当前次数和生命上限，再把次数写成上限除以 2 的整数，生命上限写成调用方传入的未余烬上限。`Return` 把记下的次数和上限写回去。

`PlayerInventoryManager.EnterPhantom` 和 `ReturnPhantom` 把这两次写进背包上的次数。红签调用 `Enter` 时次数和上限都不动。

## 3. 单元测试

`Assets/Tests/EditMode/World/PhantomEntryTests.cs`。不创建幻影模型。

## 4. 不做

红签不对半。不新做联机匹配。不把别人世界里喝空的次数存成自己的次数。
