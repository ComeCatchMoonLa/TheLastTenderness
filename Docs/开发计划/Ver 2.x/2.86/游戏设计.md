# 2.86 游戏设计：白签和黄签进场时药瓶对半、生命按未余烬

> **交付目标：白签或黄签进场时次数按上限对半，生命上限按未余烬；回来后按离开前，不把别人世界里的空瓶写成 0。**

来源：[FR-联机-06](../../../需求文档/功能需求/联机.md)。

## 1. 为什么是这一刀

前置已解锁。余烬时召协助已经有了（2.53）。余烬改生命上限已经有了（2.20）。需求前置是无。白签、黄签的血瓶和灰瓶按对半向下取整，生命上限去掉余烬那一档，回到自己的世界后不把别人世界里喝空的次数写死。红签本条不选。

## 2. 做完之后

白签或黄签进场时，先记下离开前的血瓶次数、灰瓶次数和生命上限。然后血瓶和灰瓶次数改成各自上限对半向下取整，生命上限改成未余烬的那一档。在别人世界里把次数喝到 0 之后回来，次数和上限仍是离开前记下的那些，不写成 0。红签进场不改次数，也不改上限。

## 3. 验收

Edit Mode：上限 5 和 3、当前 4 和 2、生命上限 120、未余烬 100。白签进场后次数是 2 和 1，上限是 100。喝到 0 再回来，次数是 4 和 2，上限是 120。红签进场后仍是 4、2、120。不新做幻影模型。
