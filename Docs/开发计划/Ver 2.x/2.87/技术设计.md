# 2.87 技术设计：弓的拉满和快射能分辨

> **仍是一次 `Shoot Arrow`。伤害按按住时间在两档里选，扣弹仍是原来的那一次。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`ShootArrowAction` 扣一发弹之后，伤害总是弹药上的 `physicalDamage`。瞄准没有按住时间。

## 2. 改法

弹药上增加拉满时间和拉满伤害，都带已填旗标。`PlayerManager` 在瞄准期间累计按住时间，退出瞄准时清零。

`BowShot.FullDraw` 在时间已填且按住达到门槛时为真。空着时记下错误并当快射。`BowShot.Damage` 为真时用拉满伤害，拉满伤害空着时仍用快射并记下错误。

`ShootArrowAction` 在已有的 `TrySpendAmmo` 成功之后，用这个结果写弹体伤害。动画名不变。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/BowShotTests.cs`。不创建弓，不播动画。

## 4. 不做

不新做拉弓动画。不测拉到一半取消。不改弹药为零时不发射。
