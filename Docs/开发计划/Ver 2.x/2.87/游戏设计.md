# 2.87 游戏设计：弓的拉满和快射能分辨

> **交付目标：按住够久射出的伤害和快射不同，两档都扣一发弹。**

来源：[FR-远程-01](../../../需求文档/功能需求/箭矢与弩.md)。

## 1. 为什么是这一刀

前置已解锁。`AimAction` 和 `ShootArrowAction` 已经有了。需求前置是无。拉满和快射的伤害能分辨，两档都扣一发弹。弹药为零不发射、撞上就停，脚本里已有，本条不重复。

## 2. 做完之后

瞄准后射出仍播 `Shoot Arrow`，并先扣一发弹。按住时间达到弹药上的拉满时间时，伤害用拉满伤害；没到时用原来的快射伤害。拉满时间或拉满伤害空着时不把这一发当成拉满，并报出缺了字段。两档都在扣弹之后才写伤害，所以都少一发。

## 3. 验收

Edit Mode：门槛 0.5、快射 10、拉满 25 时，按住 0.2 是 10，按住 0.5 是 25。门槛空着时按住 1 仍是 10。不新做拉弓动画。不测取消不扣弹。
