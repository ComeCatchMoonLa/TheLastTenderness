# 2.88 技术设计：踢击崩开举盾

> **踢是现有轻攻击上的一个条件。崩架仍走精力见底后的 `Guard_Break`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

轻攻击不看冲刺和朝向。举盾被打中时按伤害扣精力，见底才播 `Guard_Break`。

## 2. 改法

`ShieldKick.IsKick` 在没冲刺且向前时为真。`LightAttackAction` 按这个结果写下 `kickArmed`。

正面举盾的结算里，`kickArmed` 为真时先把精力写成 0，再走原来的 `AttemptBlock`。见底后的崩架和可处决不变。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/ShieldKickTests.cs`。不创建踢击动画。

## 4. 不做

不新做踢击动画。不测踢中超大武器的挥击。不改冲刺时的跑动攻击。
