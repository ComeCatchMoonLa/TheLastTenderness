# 2.88 游戏设计：踢击崩开举盾

> **交付目标：没在冲刺、向前的轻攻击打中举盾时，对方精力见底并进入崩架。**

来源：[FR-架势-05](../../../需求文档/功能需求/架势踢击与成对.md)。

## 1. 为什么是这一刀

前置已解锁。举盾和破防已经有了（0.16）。需求前置是无。没在冲刺时踢中举盾，对方精力被打空并进入崩架。能否踢中超大武器的挥击本条不选。

## 2. 做完之后

没在冲刺且向前按下轻攻击时，这一下记成踢。踢中正面举着的盾时，对方精力写成 0，盾放下，并播已有的 `Guard_Break`，可以处决。正在冲刺，或没有向前时，打中举盾仍按原来的格挡扣精力，不因此崩架。

## 3. 验收

Edit Mode：不冲刺且向前时记成踢。踢中举盾后精力是 0，并且可以处决。冲刺中或没有向前时不记成踢，精力 40 打中后不是 0。不新做踢击动画。
