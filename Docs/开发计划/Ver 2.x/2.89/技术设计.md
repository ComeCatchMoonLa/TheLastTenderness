# 2.89 技术设计：武器附魔会在一段时间后结束

> **附加伤害在 `DealDamage` 里加上。火用火剑上已有的 `FX_Sword_Fire`。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`DealDamage` 只交武器上的五段。注入名字在 `WeaponItem.infusion`。火剑预制体上有 `FX_Sword_Fire`。

## 2. 改法

`WeaponBuff.CanApply` 按上面的名单判断。`TryApply` 记下时长、附加伤害和这一把武器。时长空着时停住。`Tick` 把时间减到 0 后关掉。换武器或收进这一把时关掉。再涂一次覆盖旧的。

`DealDamage` 在交出去之前加上这段。角色 `Update` 里走 `Tick`，并按开或关设置名为 `FX_Sword_Fire` 的物体。装武器时找到这个物体。

## 3. 单元测试

`Assets/Tests/EditMode/Weapons/WeaponBuffTests.cs`。不新做特效。

## 4. 不做

不新做附魔特效。不改失败时扣不扣蓝。
