# 2.89 游戏设计：武器附魔会在一段时间后结束

> **交付目标：涂得上的武器在一段时间内多一段伤害，时间到、收进箱、换武器或再附魔后没有了。**

来源：[FR-法术-07](../../../需求文档/功能需求/法术.md)、[FR-注入-08](../../../需求文档/功能需求/注入与强化.md)。

## 1. 为什么是这一刀

前置已解锁。近战已经会结算五段伤害。需求前置是无。允许附魔的武器多一段会结束的伤害；涂不上的名单已经写明。失败是否仍扣蓝本条不选。

## 2. 做完之后

未注入、重、锐、精、原质、空虚可以涂上。火、深、水晶、雷、混沌、暗、祝福、单纯、毒、血涂不上。本身标成不能附魔的，未注入也涂不上。涂上之后每次挥中多出这段伤害。时间走到 0、把这一把收进箱、换成另一把，或再涂一次，这段都没有了。再涂一次只留下新的那段。看得见的一段时间用火剑上已有的 `FX_Sword_Fire`：附魔期间开着，结束后关掉。时长空着时涂不上，并报出字段。

## 3. 验收

Edit Mode：重可以涂，火不能涂，标成不能附魔的未注入也不能涂。时长 2、附加火焰 5，过 1 秒仍加上 5，再过完就没有。换成另一把或收进箱后没有。再涂成 8 之后只加 8。`FX_Sword_Fire` 在附魔期间是开的，结束后是关的。不新做特效。
