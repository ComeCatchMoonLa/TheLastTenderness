# 2.9 游戏设计：智力或信仰不够时法术放不出

> **交付目标：智力或信仰低于这条法术资产上的要求时放不出，蓝不减。两项都达到且蓝够时，按现在的学派规则放出。**

来源：[不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1开-五小时内开或关.md](../../../版本候选池/不引入美术开-不引入过多人工开-非高风险关-质量大于2关-完整度约1开-五小时内开或关.md)。

## 1. 为什么是这一刀

施法现在只核对学派和蓝够不够。需求 [FR-属性-06](../../../需求文档/功能需求/属性与升级.md) 还要智力或信仰达到这条法术自己的要求。门槛数字放在法术资产上。

## 2. 做完之后

`requiredIntelligence` 或 `requiredFaith` 大于 0，且玩家对应等级更低时，按下施法走现有耸肩。不进入施放，蓝不减。两项要求都是 0 时不看这项，已有法术仍按现在的规则放。两项都达到，蓝够，且学派对得上时，仍进入现在的施放。学派不对时仍不进入。

不新做失败动画。不改蓝不够时的耸肩。

## 3. 验收

Edit Mode：要求智力 20、信仰 0，智力 19 时放不出；智力 20 且蓝够时可以进入施放。要求信仰 15、智力 0，信仰 14 时放不出，信仰 15 且蓝够时可以进入。两项都是 0 时不因属性挡住。不创建 Animator，不扣蓝。
