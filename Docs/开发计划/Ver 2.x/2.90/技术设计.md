# 2.90 技术设计：电梯可以再拉一次

> **平台在两层之间往返。位置写在物体上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有电梯。交互入口是 `Interactable`。

## 2. 改法

`Elevator.Next` 按当前方向在下层和上层里选下一个位置，并反过来。两层相同时报错并停住。

`ElevatorPlatform` 挂在平台上，交互时调用它，写下本地坐标。场景里用一个 Unity 方块当这个平台。

## 3. 单元测试

`Assets/Tests/EditMode/World/ElevatorTests.cs`。不测休息。

## 4. 不做

不新做电梯模型或拉杆动画。不在休息时改层。
