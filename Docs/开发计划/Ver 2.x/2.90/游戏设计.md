# 2.90 游戏设计：电梯可以再拉一次

> **交付目标：拉一次平台到另一层，再拉一次回到刚才离开的方向。**

来源：[FR-机关-04](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

前置已解锁。需求前置是无。再拉一次回到刚才离开的方向。休息后停在哪一层本条不选。

## 2. 做完之后

平台旁交互一次，平台移到另一层。再交互一次，平台回到刚才离开的那一层。两层重合或另一层没填时不动，并报出字段。休息不改它停在哪。

## 3. 验收

Edit Mode：下层是 0、上层是 5 时，第一次拉到 5，第二次回到 0。两层相同时空着不动。场景里放一个 Unity 方块当平台。不新做电梯模型。不测休息后停在哪一层。
