# 2.91 技术设计：留言和别人的血渍只在在线时出现

> **一个在线布尔决定留言和血渍出不出现。灵魂残留不读这个布尔。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有留言和别人的血渍。自己的灵魂残留在死亡时留下。

## 2. 改法

`OnlineMarks.Shown` 只在在线时为真。`TryRead` 在线且正文有字时读出这句。`TryRate` 在线且还没评过时成功一次。

`OnlineMarksRoot` 按这个结果开关两个物体。场景里留言和血渍各是一个方块，挂在这个根下。灵魂残留不是这两个物体，所以不会被关掉。

## 3. 单元测试

`Assets/Tests/EditMode/World/OnlineMarksTests.cs`。不测回血和死亡动作。

## 4. 不做

不新做留言或血渍模型。不给书写者回血。不播放别人的死亡动作。
