# 2.91 游戏设计：留言和别人的血渍只在在线时出现

> **交付目标：在线才能看见并读留言、给评价、看见别人的血渍；离线这些不出现。自己的灵魂残留不受影响。**

来源：[FR-联机-07](../../../需求文档/功能需求/联机.md)。

## 1. 为什么是这一刀

前置已解锁。需求前置是无。在线才出现留言和别人的死亡标记，离线不出现，自己的灵魂残留不受影响。

## 2. 做完之后

在线时能读到留言上的字，并给一次评价。再评不改变这次评价。在线时别人的血渍出现。离线时留言和血渍都不出现。自己死亡留下的灵魂残留在离线时仍在。留言正文空着时读不到，并报出字段。

## 3. 验收

Edit Mode：在线读到「你好」，评价一次之后再评不成。离线时留言和血渍都关掉，灵魂残留仍开着。再打开在线，留言和血渍回来。场景里留言和血渍各一个 Unity 方块，不拼在一起。不测书写者回血，不测血渍播放死亡动作。
