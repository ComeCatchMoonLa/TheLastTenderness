# 2.92 技术设计：挥击中段的攻击霸体

> **窗口挂在现有攻击状态的进入和离开上。命中仍走 2.75 的结算。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`AttackPoise.Holds` 只在 `attackPoiseActive` 时扣霸体血量。`GrantWeaponAttackingPoiseBonus` 能打开窗口，攻击片段没有调用它。`HandleAttackState` 已经挂在现有轻重击上，只写下 `isAttacking`。

## 2. 改法

`AttackWindow.Open` 在进攻霸体大于 0 时打开窗口并记下这份血量。`Close` 关掉窗口，韧性回到护甲那一份。

`HandleAttackState` 进入时按当前武器调用 `Open`，离开时若窗口还开着就 `Close`。原来的两个动画事件改成调用同一处。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/AttackWindowTests.cs`。不创建 Animator。挥击续不续、硬直出不出要人看动作。

## 4. 不做

不新做攻击动画。不改霸体血量被打空就中断。
