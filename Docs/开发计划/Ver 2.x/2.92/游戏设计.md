# 2.92 游戏设计：挥击中段的攻击霸体

> **交付目标：配了进攻霸体的挥击被普通攻击打中时继续，血仍掉；这段结束后同一击打出硬直。**

来源：[FR-硬直-04](../../../需求文档/功能需求/霸体与硬直.md)。

## 1. 为什么是这一刀

前置已解锁。`GrantWeaponAttackingPoiseBonus` 已经有了，现在只在片段真的调用时生效。需求前置是无。配了进攻霸体的那一段被打中时挥击继续、血仍掉，结束后同一击打出硬直。血量被打空就中断已经有了（2.75），本条不选。

## 2. 做完之后

现有轻击、重击进入时，武器上的进攻霸体大于 0，就打开这段窗口。窗口里挨普通攻击，挥击不切受击，生命仍下降。这段结束或离开攻击状态后，窗口关掉。同一击再来，按原来的韧性打出硬直。没配进攻霸体的挥击不打开窗口。

## 3. 验收

Edit Mode：霸体 30，打 10，窗口开着时还剩 20、不打出硬直、生命少 10。窗口关掉后再打 10，打出硬直。霸体是 0 时窗口不开。不新做动画。不测霸体血量被一下打空。
