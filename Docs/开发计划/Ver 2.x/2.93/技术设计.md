# 2.93 技术设计：成对武器打出双持连段

> **成对用现有双手片段。真盾在另一只手时举不起来。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`WeaponType.melee_OH_DualWield` 没有读取方。连段按 `isTwoHandingWeapon` 选单手或双手片段。举盾不看武器类型。

## 2. 改法

`PairedWeapons.AsTwoHand` 在正在用的武器是成对时为真。`MeleeAttackSegment.Play` 用这个结果选片段。

`PairedWeapons.ShieldBlocked` 在成对和真盾同时在两只手上时为真。`BlockAction` 这时不举起。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/PairedWeaponsTests.cs`。不创建双持动画。

## 4. 不做

不新做双持动画。不把成对武器的重量算两次。
