# 2.93 游戏设计：成对武器打出双持连段

> **交付目标：标成成对的武器走双手连段，另一只手不能同时举真盾。两把普通武器不会合成。**

来源：[FR-架势-03](../../../需求文档/功能需求/架势踢击与成对.md)、[FR-架势-04](../../../需求文档/功能需求/架势踢击与成对.md)。

## 1. 为什么是这一刀

前置已解锁。单手轻击连段已经有了。架势的战技键已经改完（3.2）。需求前置是无。成对武器打出双手连段，另一只手不能同时举真盾，两把普通武器不会合成。重量是否算两次本条不选。

## 2. 做完之后

正在用的武器类型是成对时，这一下连段用现有的双手轻重击，不新做动画。两把都不是成对时，仍用单手连段。左右手里有成对、另一只是真盾时，举盾不成立。没有成对时，真盾仍能举起。

## 3. 验收

Edit Mode：成对武器选到双手第一段。普通武器在没有双手持握时仍是单手第一段。成对加真盾举不起来。两把普通武器，其中一把是真盾，仍举得起来。不新做双持动画。双持连段和各打各的要人看。
