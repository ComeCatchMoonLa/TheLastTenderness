# 2.94 技术设计：登梯、滑下和向外跳

> **三种位移都写在梯子状态上。向外跳进入已有的下落。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

没有梯子。下落看 `isInAir`。

## 2. 改法

`LadderMove.Climb` 按一次输入升降，并夹在两端之间。梯子上的 `climbSpeed` 空着时，摇杆不沿杆移动。`Slide` 在按住闪避且摇杆向下时把高度写成梯底。闪避按住读 `DodgeHeld`。`JumpOff` 在摇杆回中且按住闪避时离开梯子。在梯子上不写 `isInteracting`。

场景里放一个 Unity 方块当梯子。交互后把人标成在梯子上。向外跳时把 `isInAir` 写成真。

## 3. 单元测试

`Assets/Tests/EditMode/World/LadderMoveTests.cs`。不创建爬梯动画。

## 4. 不做

不新做爬梯动画。不改梯子上的精力回复。不做短梯踢倒。
