# 2.94 游戏设计：登梯、滑下和向外跳

> **交付目标：在梯子上能上下，按住闪避向下滑到底，摇杆回中再按闪避向梯外进入下落。**

来源：[FR-机关-01](../../../需求文档/功能需求/场景机关.md)。

## 1. 为什么是这一刀

前置已解锁。交互检测已经有了。需求前置是无。能上下，按住闪避向下滑到底，摇杆回中再按闪避向梯外下落。梯子上精力回复是快是停本条不选。短梯踢倒还不在这一版。

## 2. 做完之后

靠近梯子并交互后，人沿梯子移动。输入向上就升高，向下就降低，停在梯子两端之间。按住闪避并且摇杆向下时，人直接到梯底。摇杆回中再按闪避时，人离开梯子并进入已有的下落。不新做爬梯动画。

## 3. 验收

Edit Mode：梯子从 0 到 4，向上 1 后高度是 1，再向下 0.5 是 0.5。按住闪避且向下时高度是 0。摇杆回中按闪避时离开梯子并进入下落。没按闪避时高度不变。不创建爬梯动画。上下、滑到底和向外跳要人看。
