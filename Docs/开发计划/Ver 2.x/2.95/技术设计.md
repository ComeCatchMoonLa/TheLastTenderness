# 2.95 技术设计：下一周收回箱子、幻影墙和近战

> **`NewCycle.Apply` 再调三次已经有的收回。休息路径不改。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 收回

[`ChestLoot`](../../../../Assets/Scripts/Items/Interactions/ChestLoot.cs) 增加 `ForNewCycle`。传入是否开过，返回假。`AfterRest` 仍把开过原样返回。

[`OpenChest.CloseForNewCycle`](../../../../Assets/Scripts/Items/Interactions/OpenChest.cs) 用 `ForNewCycle` 写 `opened`，标签写成 `Interactable`。开箱状态结束时不再销毁动画机。`Awake` 记下盖子 `Lid` 的本地位置和旋转。下一周写回这两个值，并关掉动画机，避免下一帧又把盖子写成开箱结束的姿势。再开时打开动画机，从第 0 帧播 `Chest Open`。

[`IllusionWall.CloseForNewCycle`](../../../../Assets/Scripts/Items/Interactions/IllusionWall.cs) 把 `opened` 写成假，本物体上的碰撞和渲染重新打开。`AfterRest` 仍是空的。

[`NewCycle.Apply`](../../../../Assets/Scripts/World/NewCycle.cs) 在现有门、火、头目之后，找出场上的 `OpenChest`、`IllusionWall`、`EnemyStatsManager`（含未激活）。箱子和墙各调 `CloseForNewCycle`。属性调已有的 `RestoreAfterRest`。没被休息藏起来的直接返回，所以弓和还活着的近战不动。

## 2. 测试

`Assets/Tests/EditMode/Interactions/NewCyclePropTests.cs`。

休息后开过仍是真，下一周写成假。幻影墙下一周 `opened` 为假，碰撞体重新启用。不创建背包。近战放回原位仍用已有的 `MeleeRestTests`。

## 3. 不做

不刷新地上的拾取物。不关雾门。不改储物箱和背包里的非钥匙。不算高风险。

## 4. 验收
