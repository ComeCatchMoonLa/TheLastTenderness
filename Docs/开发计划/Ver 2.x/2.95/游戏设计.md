# 2.95 游戏设计：下一周收回箱子、幻影墙和近战

> **交付目标：进入下一周后，开过的箱子盖上并能再拿一次，撞开的幻影墙重新挡住，打死的近战回到原位并且满血。储物箱和背包不动。**
>
> 地上的拾取物另开一版。雾门等头目那场放进场景再做。

来源：[角色与养成](../../../调研文档/角色与养成.md)「地面上的宝箱可以再拿」，[世界与篝火](../../../调研文档/世界与篝火.md)「幻影墙、敌人按新的一周重来」。[FR-周目-05](../../../需求文档/功能需求/周目与结局.md) 没写这三样。火、门、钥匙和头目战败已经在 2.80 重来。

## 1. 为什么是这一刀

这三样物体都还在场上。箱子打开后 `opened` 保持真，休息也不盖上。幻影墙撞开后碰撞和模型关掉，休息不关回去。死掉的近战被藏起来，休息才会放回原位。进下一周时没有再调一次这些收回。

## 2. 做完之后

进下一周之后：开过的箱子 `opened` 变成假，标签回到 `Interactable`，盖子回到关上的姿势，可以再拿一次。撞开的幻影墙 `opened` 变成假，碰撞和模型重新打开。打死后藏起来的近战回到记下的原位，死亡写成假，生命写成上限。

储物箱里的东西不动。背包里不是钥匙的物品不动。钥匙仍按 2.80 拿走。地上的拾取物不刷新。雾门不关。弓和已经从场景里删掉的身体不放回来。

## 3. 验收

Edit Mode：休息后箱子仍是开的，下一周把开过写成关上。幻影墙下一周 `opened` 为假，碰撞重新打开。不创建背包，不播开箱。

在 `Game` 里进人看：开过一个箱子、撞开一面幻影墙、打死一只近战，再进下一周。箱子能再拿，墙挡住，近战站回原位并且满血。背包里的非钥匙还在。
