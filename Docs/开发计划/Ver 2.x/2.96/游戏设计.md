# 2.96 游戏设计：下一周地上的拾取还在

> **交付目标：地上捡过的东西，进入下一周后还在原来的位置，可以再捡一次。背包里已经捡到的那一份还在。**

来源：[角色与养成](../../../调研文档/角色与养成.md)「地面上的宝箱、矿石、骨片、碎片可以再拿」和「地上没捡过或将再次刷新的矿石」。箱子、幻影墙和近战已在 2.95。雾门等头目那场放进场景再做。

## 1. 为什么是这一刀

捡起时把整个物体 `Destroy` 掉。下一周没有对象可以再打开，所以不能和箱子放在同一版。

## 2. 做完之后

捡起后物体还在，只是看不见、不能再交互。进入下一周，捡过的那些回到原处，可以再捡一次，再进背包一份。没捡过的不动。

箱子、幻影墙、近战、火、门、钥匙仍按已经做的来。储物箱不动。雾门不关。

## 3. 验收

Edit Mode：捡起后物体不激活，下一周再激活，并且不再记成已捡。不创建玩家。

在 `Game` 里对人看：捡起地上一件，进下一周，它还在原地，再捡一次背包里多一份。
