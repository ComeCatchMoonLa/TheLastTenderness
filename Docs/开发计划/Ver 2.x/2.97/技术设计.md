# 2.97 技术设计：架势派生扣蓝

> **派生打出前先看蓝。够全额才扣。不够全额不打出。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 门槛

[`WeaponItem`](../../../../Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs) 增加 `lightDeriveFocusFilled`、`lightDeriveFocus`、`heavyDeriveFocusFilled`、`heavyDeriveFocus`。

[`StanceDeriveFocus.TryLaunch`](../../../../Assets/Scripts/Character/StanceDeriveFocus.cs)：全额小于或等于 0 时返回假。蓝小于全额时返回假，蓝不变。否则蓝减去全额并返回真。半价是全额除以 2 的向下取整，只用来说明中间档也落在「小于全额」里，不另写削弱。

[`StanceDeriveFocus.Commit`](../../../../Assets/Scripts/Character/StanceDeriveFocus.cs)：没在姿势里返回真，调用方照常打出。在姿势里、没有武器时返回真，不扣蓝。有武器但这一下没填或全额小于或等于 0 时，报出武器名和 `lightDeriveFocus` 或 `heavyDeriveFocus`，返回假。够全额时 `DeductMP` 并记下轻或重，姿势关掉，返回真。

[`LightAttackAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/LightAttackAction.cs) 和 [`HeavyAttackAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/HeavyAttackAction.cs) 在打出前调用 `Commit`。返回假则这一下不播。
