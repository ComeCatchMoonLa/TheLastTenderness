# 2.97 游戏设计：架势派生扣蓝

> **交付目标：姿势里打出的轻派生、重派生，蓝够这一下的全额时扣掉配置的蓝。低于半价，或落在半价与全额之间，不打出、不扣。进入姿势仍不扣蓝。**

来源：[FR-架势-01](../../../需求文档/功能需求/架势踢击与成对.md)。半价以上、全额以下的削弱程度仍待核对，这一版不选，所以这一档不打出、不扣。

## 1. 为什么是这一刀

姿势里的轻击和重击已经分成两段，蓝不变。派生要按这一下自己的蓝量，用半价门槛决定打不打出。

## 2. 做完之后

蓝大于或等于配置的全额：打出这一段，蓝减去全额。

蓝低于全额的一半（奇数向下取整），或在一半与全额之间：不打出，姿势还在，蓝不变。

没填这一下的蓝量：报出武器名和字段，不打出，姿势还在。

没有武器时仍按现在打出，不扣蓝。进入姿势不扣蓝。不新做架势姿势。

## 3. 验收

Edit Mode：全额 20、蓝 40，打出后蓝 20。全额 20、蓝 9 或 15，不打出，蓝不变。全额 17、蓝 17，打出后蓝 0。全额 17、蓝 8，不打出。没填时不打出。

不创建架势姿势。
