# 2.98 技术设计：不成对时弹反盾走弹反

> **战技键在弹反盾和右手架势之间选一只手。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 选哪只手

[`ParryShield.UseLeft`](../../../../Assets/Scripts/Character/ParryShield.cs)：没有双手握住，左手类型是盾，没标成架势，并且战技动作是 `ParryAction` 时返回真。

[`PlayerCombatManager.Handle_Tap_R_Input`](../../../../Assets/Scripts/Character/Player/PlayerCombatManager.cs)：`UseLeft` 为真时，用左手、把当前物品记成左手武器，调用左手的 `oh_tap_r_action`。否则仍用右手。

## 3. 不做

不改成对连段。不新做盾模型。不算高风险：只改战技键选哪只手。
