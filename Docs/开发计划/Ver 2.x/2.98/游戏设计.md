# 2.98 游戏设计：不成对时弹反盾走弹反

> **交付目标：左手是弹反盾、又没有双手握住右手时，战技键走左手的弹反。右手架势要双手握住才从这只手进。**

来源：[FR-架势-04](../../../需求文档/功能需求/架势踢击与成对.md)。成对连段不在这一版。

## 1. 为什么是这一刀

战技键现在只看右手。左手拿着弹反盾时，仍会进右手的架势。

## 2. 做完之后

左手是盾、没标成架势、战技动作是弹反，并且没有双手握住右手：战技键走出左手的弹反。

双手握住右手，右手标成架势：战技键进右手的架势。

左手不是这面弹反盾时，战技键仍走现在的右手。

## 3. 验收

Edit Mode：单手、左手是弹反盾时走左手。双手握住右手时不走左手。左手标成架势，或不是盾，或没有弹反动作时，不走左手。

不创建盾和武器模型。
