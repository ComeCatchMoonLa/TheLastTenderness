# 2.99 技术设计：踢击扣精力且冲刺不踢

> **踢成立时扣轻击精力。冲刺不是踢。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。没有 **[待确认]** 的接口。

## 1. 踢和花费

[`ShieldKick.Stamina`](../../../../Assets/Scripts/Character/ShieldKick.cs)：是踢时返回轻击花费，不是踢时返回 0。`IsKick` 仍是没冲刺且向前。

[`LightAttackAction`](../../../../Assets/Scripts/Items/0%20Item%20Actions/LightAttackAction.cs)：记成踢之后，按右手或左手武器的轻击花费调用 `DeductAttackStamina`。

[`CharacterAnimatorManager.DrainStamina`](../../../../Assets/Scripts/Character/CharacterAnimatorManager.cs)：已经记成踢时直接返回，避免这一下再扣一次。

## 2. 测试

[`Assets/Tests/EditMode/Combat/ShieldKickTests.cs`](../../../../Assets/Tests/EditMode/Combat/ShieldKickTests.cs)。

## 3. 不做

不新做踢和跑动攻击的动画。不改踢中举盾时对方精力见底。不算高风险：只补踢的人自己这一笔精力。

## 4. 验收

游戏设计第 3 节。动画不测。
