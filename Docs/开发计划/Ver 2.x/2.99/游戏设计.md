# 2.99 游戏设计：踢击扣精力且冲刺不踢

> **交付目标：没在冲刺、向前的轻击是踢，扣这一下轻击的精力。正在冲刺时向前轻击不是踢。**

来源：[FR-架势-05](../../../需求文档/功能需求/架势踢击与成对.md)。踢中举盾把对方精力打空已经在。踢的伤害和硬直不在这一版。

## 1. 为什么是这一刀

向前轻击已经能记成踢，冲刺时不记。踢的人自己这一下精力还没扣。

## 2. 做完之后

没冲刺且向前：记成踢，精力减去这把武器轻击的花费，最低 -60。

正在冲刺，或没有向前：不记成踢，不因此另扣这一笔。

## 3. 验收

Edit Mode：没冲刺且向前是踢，花费 12 时扣 12。冲刺且向前不是踢，这一笔是 0。没有向前也不是踢。

不创建踢的动画。
