# Ver 2.x：新增，或重启未激活的旧功能

> **这一大版本可以加玩家能看见的新行为，也可以把已经写好但未激活的旧功能重新用起来。** 不换一套战斗核心。
>
> 顺序以 [`../README.md`](../README.md) 为准。0.x 仍是纠错，1.x 仍是行为不变的收拢。

## 2.1 喝药成功时回蓝

文档：[`2.1/游戏设计.md`](2.1/游戏设计.md) / [`2.1/技术设计.md`](2.1/技术设计.md) / [`2.1/TODO.md`](2.1/TODO.md)。

生命回复量和专注回复量各自大于 0 时，喝药成功后对应的条上升。不新做瓶子。不写单元测试。大约 1–2 小时。

## 2.2 背包指定当前法术和消耗品

文档：[`2.2/游戏设计.md`](2.2/游戏设计.md) / [`2.2/技术设计.md`](2.2/技术设计.md) / [`2.2/TODO.md`](2.2/TODO.md)。

背包点法术或消耗品后，快捷栏换成这一件。点武器或护甲不改。不写单元测试。大约 2–3 小时。

## 2.3 同一次挥击只结算一次

文档：[`2.3/游戏设计.md`](2.3/游戏设计.md)。技术设计和 TODO 进入前再写。

同一次伤害窗口里，同一名敌人只结算一次。不写单元测试。大约 2–3 小时。

## 2.4 燃火休息回满

文档：[`2.4/游戏设计.md`](2.4/游戏设计.md)。技术设计和 TODO 进入前再写。

只让那一盏燃火进游戏。已点燃后休息，三条资源回满。箱子保持关掉。不写单元测试。大约 3–4 小时。
