## 2.4 燃火休息回满

文档：[`2.4/游戏设计.md`](2.4/游戏设计.md) / [`2.4/技术设计.md`](2.4/技术设计.md) / [`2.4/TODO.md`](2.4/TODO.md)。已完成。

## 2.5 休息把回复次数写回上限

文档：[`2.5/游戏设计.md`](2.5/游戏设计.md) / [`2.5/技术设计.md`](2.5/技术设计.md) / [`2.5/TODO.md`](2.5/TODO.md)。已完成。

已点燃后休息成功，这名玩家每种回复消耗品的剩余次数回到 `maxItemAmount`。没休息之前次数不变。不复活敌人，不改篝火预制体。Edit Mode 先扣次数再调用 `RestoreVitalsToMax`。大约 2 小时。

## 2.6 集中力按门槛增加记忆栏

文档：[`2.6/游戏设计.md`](2.6/游戏设计.md) / [`2.6/技术设计.md`](2.6/技术设计.md) / [`2.6/TODO.md`](2.6/TODO.md)。已完成。

记忆栏格数按 `focusLevel` 的门槛增加。9 及以下是 0，99 是 10。不改蓝上限的「等级乘 10」，不画记忆界面。Edit Mode 断言 9、10、13、14、80、98、99。大约 3 小时。
