# 3.1 技术设计：对比之后确认才换上

> **第一次点只算出攻击力和吸收的差。再点同一件才换上。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

`InventorySlotUI.EquipThisItem` 一点就把武器放进手槽并加载模型，防具立刻换上并改吸收。

## 2. 改法

`EquipCompare.Preview` 用当前和将要换上的攻击力、物理吸收算出差。不改装备，不改吸收。

`EquipCompare.Arm` 第一次对着这一件返回假，再点同一件返回真。假的时候只留下预览。真的时候才走原来的换上。

## 3. 单元测试

`Assets/Tests/EditMode/UI/EquipCompareTests.cs`。不创建 Animator。对比时人还穿着旧的，留给人看。
