# 3.1 游戏设计：对比之后确认才换上

> **交付目标：对比时只显示将要换上的数字。确认之后才真正换上，并改吸收。**

来源：[FR-菜单-04](../../../需求文档/功能需求/菜单.md)。

## 1. 为什么是这一刀

头、躯干、下身和武器现在一点就换上。需求是 [FR-菜单-04](../../../需求文档/功能需求/菜单.md)。重量和负重翻滚还没有。

## 2. 做完之后

光标停在另一件上时，用已有的攻击力和吸收数字显示将要换上的和当前的差别。确认前模型和吸收不变。确认后才换上，并改吸收。不显示重量，不改翻滚档。

## 3. 验收

Edit Mode：确认前装备和吸收不变；确认后装备换成新的，吸收是新的。不创建 Animator。

要人看的一条：对比时人还穿着旧的，确认后才换。这一条不进 Test Runner。
