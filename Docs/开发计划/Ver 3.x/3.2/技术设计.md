# 3.2 技术设计：架势的两段派生和收招

> **只有标成架势的武器改战技键。派生复用现有轻击和重击。**
>
> 需求以 [`游戏设计.md`](游戏设计.md) 为准。

## 1. 现在

战技键进 `ParryAction`，单手时播 `weapon_art`。轻击和重击各走自己的片段。没有姿势旗标。

## 2. 改法

`WeaponItem.stanceArt` 为真时，`ParryAction` 第一次按下把 `stanceHolding` 写成真，再按一次写成假。不播弹反。

姿势为真时，轻击记成轻派生，重击记成重派生，然后清掉姿势，片段仍是原来的轻击或重击。

`ResolveIncomingHit` 在这一下不在霸体窗口里时清掉姿势。窗口还挡得住时不清。

## 3. 单元测试

`Assets/Tests/EditMode/Combat/WeaponStanceTests.cs`。不创建架势动画。

## 4. 不做

不新做架势动画。不扣蓝。不改没标成架势的弹反。
