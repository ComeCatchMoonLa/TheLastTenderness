# 3.2 游戏设计：架势的两段派生和收招

> **交付目标：标成架势的武器按下后停住，再按轻击或重击走出两段，什么都不接可以收回。**

来源：[FR-架势-01](../../../需求文档/功能需求/架势踢击与成对.md)、[FR-架势-02](../../../需求文档/功能需求/架势踢击与成对.md)。

## 1. 为什么是这一刀

前置已解锁。按住或点按的武器技入口已经有了。需求前置是无。按下后停在姿势里，再按轻击或重击走出两段，不接可以收回。进入时扣不扣蓝本条不选。3.1 仍只写了游戏设计，这一版是另开的。

## 2. 做完之后

武器标成架势时，战技键不再走弹反，只记下姿势停住。姿势里按轻击，走出现有轻击；按重击，走出现有重击。再按一次战技键，姿势收回，不走出派生。没标成架势的武器仍走原来的弹反。姿势里被打中、且这一下不在霸体窗口里时，姿势断开。霸体窗口还挡得住时，姿势留着。

## 3. 验收

Edit Mode：标成架势且没在交互时能进入。姿势里轻击和重击能分开。再按战技键收回后不再是轻击或重击。没标成架势时不能靠这条进入。不在霸体窗口里被打中则姿势断开，窗口挡得住时不断。不新做架势动画。不扣蓝。两段派生和收回的动作要人看。
