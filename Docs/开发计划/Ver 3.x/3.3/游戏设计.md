# 3.3 游戏设计：实体挡住发现

> **交付目标：待机时，玩家和敌人之间有开着的非触发碰撞体，就不发现。门、墙、梯子、箱子都挡。触发器、玩家、敌人、Blocker 不挡。**

来源：[FR-敌人-01](../../../需求文档/功能需求/敌人.md)。原先中间有环境挡住就不发现，线只打 Default 和 Environment。现在改成开着的非触发碰撞体都挡。

## 1. 为什么是这一刀

关上的门在 Interactable 层，碰撞体是实心的。发现用的线不打这一层，隔着门仍会发现。墙在 Environment 或 Default 上才会挡住。

## 2. 做完之后

待机、人在扇形里时，那条线打中开着的非触发碰撞体就不发现。玩家、敌人、双方的 Blocker 不挡，空地上仍会发现。触发器不挡。

已经追上来之后，再走到门或墙后面，不因此停追。锁定镜头的线不改。门打开后碰撞体按现在的开门关掉，打开的门不再挡。

## 3. 验收

Edit Mode：遮罩含 Default、Environment、Interactable。不含玩家、敌人、Blocker。不创建角色，不打射线。

在 `Game` 里对人看：

1. 隔着关上的门，人在扇形里：不发现。
2. 门打开后：不再被这扇门挡住。
3. 中间没有实体：仍发现并追过来。
