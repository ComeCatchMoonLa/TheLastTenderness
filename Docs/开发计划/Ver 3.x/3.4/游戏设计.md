# 3.4 游戏设计：一口只回一种

> **交付目标：喝灰瓶只让专注上升，喝血瓶只让生命上升。同一口不抬两条。已满的那一条停在上限。**

来源：[FR-回复-05](../../../需求文档/功能需求/回复类消耗品.md)。原先一件瓶两种回复量都大于 0 时，一口可以两条一起抬。

## 1. 为什么是这一刀

一口该按瓶种只回一种。血瓶回生命，灰瓶回专注。物品上同时填了两种回复量，也不该两条一起抬。

## 2. 做完之后

灰瓶成功：专注加上这一口，不超过上限，生命不变。

血瓶成功：生命加上这一口，不超过上限，专注不变。

这一口的量仍读回复表，不读物品上的两种回复量。次数仍在喝下去之前扣。

## 3. 验收

Edit Mode：生命 100、上限 150、专注 40、上限 80、这一口 30。血瓶之后生命 130、专注 40。灰瓶之后生命 100、专注 70。已经到顶时那一条不变，另一条也不变。

不创建喝药模型和治疗粒子。
