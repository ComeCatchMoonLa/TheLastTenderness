# 性能

> **这条路径没有测过帧时间。** 下面只写代码每帧在做什么。没有测过的数字不写。

## 玩家

`PlayerLocomotionManager.FixedUpdate` 每次物理帧做移动、转向，并在 `HandleFall` 里向下射线检测地面。射线长度是碰撞体底部高度加上 `HeightToBeginLand`（0.8），只打环境、NPC、玩家三层。人在地上时也会打。这是固定开销，不是找到了多余循环。

`currentSpeed` 只读刚体速度的长度，不参与判定。

## 近战

Humanoid 待机的 `Tick` 用 `OverlapSphere` 按探测半径找玩家。这发生在 AI 跳动时，不是玩家的每个渲染帧。

## 查找

`FindAnyObjectByType` 用在开局（玩家找相机、相机找玩家、世界找玩家）和敌人死亡时再找一次玩家。不是每帧查找。

## 动画

`PlayTargetAnimation` 用动画名 `CrossFade`，过渡 0.2 秒。按字符串切状态本身不是每帧开销；开销在切得太勤。地面射线没打中就会切到 `Falling`，这个状态又没有出口，所以一次误判会一直停在该动画上，而不是每帧重新 CrossFade。
