# 接口

> **类型之间没有单独的接口层。** 角色之间主要靠 `CharacterManager` 上的公开字段说话。

## 旗标

移动四个字段现在各有一处写入：

| 字段 | 谁写 |
| --- | --- |
| `isRolling` | `HandleRollState` 进入和离开翻滚动画 |
| `isJumping` | `HandleJumpState` 进入和离开跳跃动画 |
| `isInAir` | `PlayerLocomotionManager.HandleFall` |
| `isSprinting` | `InputManager.HandleRollInput` |

战斗、交互、能否转向等其余旗标仍是公开字段，多处都能改。`BlockAction` 不再写 `isSprinting`。

## 播动画

`PlayTargetAnimation(动画名, 是否交互, …)` 是第二个入口。调用方传入动画名字符串。`isInteracting` 为 true 时，移动会停，直到某个动画状态把它清掉。格挡起手传的是 false，所以举盾本身不锁移动。

## 伤害

`DamageCollider` 在触发时找到对方的 `CharacterManager`，用队伍和格挡决定扣血还是弹开。投射物、炸弹有各自的碰撞体子类，入口仍是碰到人之后走属性 Manager。
