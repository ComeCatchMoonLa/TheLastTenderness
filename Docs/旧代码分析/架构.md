# 架构

> **一个角色是同一个物体上的多个 Manager，不是一套独立的战斗核心。** 玩家和近战敌人共用 `CharacterManager` 这一层。

## 角色

`CharacterManager` 在 `Awake` 里用 `GetComponent` 拿到七个 Manager：动画、战斗、特效、物品、属性、武器槽、音效。`PlayerManager`、`EnemyManager` 再各自多拿相机、输入、AI 设置这些。

近战敌人的行为是挂在同一物体上的 `State`。`State.Tick` 返回下一个状态。现在场景里的三只近战走 Humanoid 目录下的状态。General 和 Boss 是另外两套，脚本留着，当前 `Game` 基本不挂它们。

## 动画

播放走 `CharacterAnimatorManager.PlayTargetAnimation`。它按动画名 `CrossFade`，同时写下 `isInteracting`、能否转向、是否用根运动。动画进行中的开关由 Animator 上的 `StateMachineBehaviour` 改，例如翻滚、跳跃。

## 攻击和格挡

武器上配的是 `WeaponItemAction`（ScriptableObject）。`PerformAction` 收到这个角色，再去播动画、改战斗旗标。轻击、重击、格挡、弹反都是这个入口的不同资产，不是角色脚本里的分支表。

## 伤害

武器上的 `DamageCollider` 是触发器。打中别人时看队伍、是否格挡，再让对方的属性 Manager 扣血、播受击动画。
