## 后续安排

工时是粗估，不是实测，最小精度 0.5 小时：近的按 2.x 同类已收尾版本的耗时类比。M6 到 M10 不估，做到再写。

Agent 列是执行时间，不含等人，也不含拼界面和摆物体。拼界面和摆物体算人工。人工按窗口估，不只数勾选项的时间：要约窗口，勾出问题后 Agent 修复、人工再复测，一轮就是一个新窗口；人工比 Agent 慢得多，窗口之间默认隔一到数天。日历按人工列走，不按 Agent 列走。
