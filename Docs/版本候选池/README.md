# 二、后续安排

工时是粗估，不是实测，最小精度 0.5 小时：近的按 2.x 同类已收尾版本的耗时类比。M7 到 M11 不估，做到再写。接线算 Agent，拼界面和摆物体算人工。

每一档只写这一档的总工时。Agent 是接线时间，不含等人，也不含拼界面和摆物体。人工按窗口估：要约窗口，勾出问题后 Agent 修复、人工再复测，一轮就是一个新窗口。日历按人工走。
