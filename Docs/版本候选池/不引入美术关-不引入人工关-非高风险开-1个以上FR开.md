- 类型：add（2.x）
- 是否不引入美术：否，双持连段要新动画。
- 是否不引入人工：否，双持连段和各打各的要看动作。
- 是否非高风险：是，`WeaponType` 里成对枚举现在没有用法，接上之后近战选段都会读它。这是以后会读到的枚举。

- 工时：约 8 小时
- 程序前置条件：无。单手轻击连段已有。
- 需求前置条件：无。成对武器打出双手连段、另一只手不能同时举真盾，两把普通武器不会合成，FR-架势-03 与 FR-架势-04 已写。成对武器的重量是否算两次见调研待核对，本条不选。
- 做什么：一件成对武器打出双手连段，另一只手不能同时举真盾；两把普通武器不会合成这种连段。

- 推荐：简单占位。要验收的是成对才走双持、不成对各打各的，现有连段够用。
