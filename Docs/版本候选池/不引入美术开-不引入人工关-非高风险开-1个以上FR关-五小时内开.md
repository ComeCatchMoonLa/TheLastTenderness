# 不引入美术开-不引入人工关-非高风险开-1个以上FR关-五小时内开

五个开关：不引入美术 开，不引入人工 关，非高风险 开，1个以上 FR 关，五小时内 开。

本文件 4 条。索引见 [README.md](README.md)。

## 轻轻推摇杆会走

- 类型：add（2.x）
- 是否不引入美术：是，仍用现有的移动混合，不新做行走动画也可先用更慢的速度。30% 负重以下是否再快一档见未入池。
- 是否不引入人工：否，走、跑、冲刺的快慢要看出来。
- 是否非高风险：是，按输入大小选速度，Edit Mode 能断言速度。
- 1个以上 FR：否（[`玩家移动与闪避`](../需求文档/功能需求/玩家移动与闪避.md) FR-移动-08）
- 工时：约 4 小时
- 前置条件：无。`HandleMove` 已有跑步和冲刺。
- 做什么：输入较小但大于零时明显慢于跑步，推满仍是跑步，冲刺仍更快。

## 头目使用带名字的血条

- 类型：new（2.x）
- 是否不引入美术：是，`UIBossHealthBar` 已在工程里，不新做血条贴图。
- 是否不引入人工：否，血条长度是填充，单元测试不覆盖。
- 是否非高风险：是，把已有血条接到这场头目。
- 1个以上 FR：否（FR-头目-03）
- 工时：约 4 小时
- 前置条件：无。`WorldUIManager.ActivateBossBar` 已存在。
- 做什么：这场头目开战时出现带名字的长血条，长度对应当前生命。

## 崩盾之后可以处决

- 类型：add（2.x）
- 是否不引入美术：是，沿用处决动画。
- 是否不引入人工：否，贴上去进入处决要看动作。
- 是否非高风险：是，崩架之后接到已有处决。
- 1个以上 FR：否（FR-处决-04）
- 工时：约 4 小时
- 前置条件：格挡耗尽已经会破防。
- 做什么：盾被打空并弯腰后，贴上去能进入和弹反相同的一次处决。

## 身上出现锁定标记

- 类型：add（2.x）
- 是否不引入美术：是，用现有 HUD 上的 `Image`，不导入新的锁定贴图。
- 是否不引入人工：否，标记跟在身上要看画面。
- 是否非高风险：是，标记要加在 HUD 预制体上，并且读 `curLockOnTarget`。已有窗口上加一格，没有旧数据被读错或丢掉。
- 1个以上 FR：否（[`镜头与锁定`](../需求文档/功能需求/镜头与锁定.md) FR-镜头-07）
- 工时：约 4 小时
- 前置条件：无。锁定和解锁已有。
- 做什么：锁定成功时目标身上出现标记，目标死亡或解开后标记消失。
