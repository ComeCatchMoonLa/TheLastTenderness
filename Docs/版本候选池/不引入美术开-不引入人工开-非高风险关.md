- 类型：new（2.x）
- 是否不引入美术：是，界面用现有 uGUI 和已经在用的免费界面包，外形在已有分件里选，不新做蒙皮。
- 是否不引入人工：是，名字、职业和赠礼进背包能断言，外形用选中的模型编号。
- 是否非高风险：否，后面的属性和背包都建在这次交出的角色上，选错了很难拆。
- FR：[`角色养成`](../需求文档/功能需求/角色养成.md) FR-养成-01

- 做什么：创角结束后身上带着外形、名字、职业和一件葬礼赠礼。
- 已买的包或商店免费资源：玩家 `Model` 下已有分件，和护甲一样按名字开关。界面用工程里已经在用的免费 uGUI 包。没有单独的蒙皮身体。
- 能不能先简单占位：能。外形在已有分件里选一套。界面用现有 uGUI 拼。不新做蒙皮，不把多个几何体拼成一个模型。
- 推荐：简单占位。要验收的是名字、职业、赠礼，以及选中的那套分件。
