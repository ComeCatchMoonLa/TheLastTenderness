## 全都解锁

### 留言和别人的血渍只在在线时出现

- 类型：new（2.x）
- 是否不引入美术：是，地面标记用一个 Unity 自带几何体，不新做模型。
- 是否不引入人工：是，在线才出现、离线不出现，灵魂残留不受影响，能断言。
- 是否非高风险：是，一个在线布尔控制显示。
- FR：FR-联机-07
- 工时：约 6 小时
- 程序前置条件：无
- 需求前置条件：无。在线才出现留言和别人的死亡标记，离线不出现，自己的灵魂残留不受影响，FR-联机-07 已写。
- 做什么：在线时能读一条留言、给一个评价、看见一条别人的死亡标记；离线时这些不出现。自己死亡留下的灵魂残留不受这个开关影响。
- 已买的包或商店免费资源：没有地面标记。
- 能不能先简单占位：能。留言和血渍各用一个 Unity 自带几何体，不拼。
- 推荐：简单占位。要验收的是在线才出现、离线不出现。

### 武器附魔会在一段时间后结束

- 类型：add（2.x）
- 是否不引入美术：是，可见的一段时间用火剑上已有的 `FX_Sword_Fire`，不新做特效。
- 是否不引入人工：是，附加伤害在不在、时间到或换武器后清掉，能断言。
- 是否非高风险：是，这段加法进 `DealDamage`，每一击都会读。这是以后会读到的数。失败是否仍扣蓝见未入池。拒绝名单按需求：未注入、重、锐、精、原质、空虚可以涂；火、深、水晶、雷、混沌、暗、祝福、单纯、毒、血不能涂；本身标成不能附魔的，未注入也涂不上。
- FR：FR-法术-07 与 [`注入与强化`](../需求文档/功能需求/注入与强化.md) FR-注入-08。涂得上和涂不上是同一眼
- 工时：约 8 小时
- 程序前置条件：无。近战已经会结算五段伤害（1.0、1.46）。
- 需求前置条件：无。允许附魔的武器在一段时间内多一段伤害，时间到或换武器后没有了；涂不上的名单 FR-注入-08 已写。失败是否仍扣蓝见未入池，本条不选。
- 做什么：对允许附魔的武器成功之后，一段时间内每次挥中多一段对应伤害；时间到、收进箱、换武器或再附魔后这段没有了。对上面写明涂不上的武器施放，没有这段。
- 已买的包或商店免费资源：火剑上已有 `FX_Sword_Fire`。`WeaponFX` 的拖尾只在挥击时播。
- 能不能先简单占位：能。附魔期间打开 `FX_Sword_Fire`，时间到、收进箱或换武器后关掉。
- 推荐：简单占位。能看见的那一段时间用这团火，不新做特效。
