# 不引入美术开-不引入过多人工关-非高风险开-1个以上FR开-五小时内开或关

五个开关：不引入美术 开，不引入过多人工 关，非高风险 开，1个以上 FR 开，五小时内 开或关。

本文件 2 条。索引见 [README.md](README.md)。

## 状态页能读九项，本页不能加点

- 类型：add（2.x）
- 是否不引入美术：是，用文本。
- 是否不引入过多人工：否，要打开状态页读数，并确认没有加点按钮。
- 是否非高风险：是，页加在现有分页窗预制体上。没有旧数据被读错或丢掉。
- 1个以上 FR：是（FR-菜单-05 与 [`属性与升级`](../需求文档/功能需求/属性与升级.md) FR-属性-03。FR-属性-03 写了七项和灵魂，本条补到九项并明确不能在本页加点，两眼都算）
- 工时：约 4 小时
- 前置条件：生命、精力、专注、力量、敏捷、智力、信仰这些字段已在 `CharacterStatsManager` 上。体力和幸运若还没有字段，本条只先读已经存在的等级，不发明幸运的效果。
- 做什么：状态页能读到已有的等级和灵魂，穿着变化不改等级；这一页没有加点。

> **工时超过 5 小时。** 1 条。

## 需求不足时更慢，打中也更弱

- 类型：add（2.x）
- 是否不引入美术：是，不新做「变慢」的动画，用现有挥击的速度或伤害差来看。
- 是否不引入过多人工：否，要在需求不够和够的时候各打一击。
- 是否非高风险：是，力量和敏捷会进每一击的结算。这是以后会读到的数。
- 1个以上 FR：是（FR-注入-06 写挥击变慢，[`属性与升级`](../需求文档/功能需求/属性与升级.md) FR-属性-05 写伤害更低且仍能挥出。两眼都要）
- 工时：约 6 小时
- 前置条件：武器伤害和挥击已有。需求点数写在 `WeaponItem` 上。
- 做什么：力量或敏捷低于武器需求时仍能挥，但这一下比需求满足时更慢，并且打中的伤害更低。满足后再打，速度和伤害回到较高的那一档。
