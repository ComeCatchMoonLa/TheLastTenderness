# 不引入美术开-不引入过多人工开-非高风险开-质量大于2关-完整度约1关-五小时内开

六个开关：不引入美术开，不引入过多人工开，非高风险开，质量大于 2% 关，完整度约 1% 关，五小时内开。

本文件 1 条。索引见 [README.md](README.md)。

## 瞄准旗标的清零收成一处

- 类型：refactor（1.x）
- 是否不引入美术：是，不改瞄准镜头。
- 是否不引入过多人工：是，跳跃进入、翻滚进入、松开瞄准之后，`aimingMode` 都为 false。
- 是否非高风险：是，`aimingMode` 被相机、移动、冲刺和准星同时读。清零收成一处，Edit Mode 能断言这三处之后都为 false。
- 代码质量：2%（[`可维护性与性能.md`](../代码分析/可维护性与性能.md)「瞄准」：`HandleJumpState`、`HandleRollState` 和松开 Q 都会清 `aimingMode`。重复计算一组里的一处，约 2 分）
- 完整度：0（拉弓和取消后的镜头仍按已完成的 1.2）
- 工时：约 3 小时
- 前置条件：无。玩家瞄准只留 `aimingMode`（1.2）。
- 做什么：这三处清掉瞄准的结果相同，清零只写一次。按住期间会不会每个 `Update` 再进一次动作，是另一条，见 [`不引入美术开-不引入过多人工关-非高风险关-质量大于2开或关-完整度约1关-五小时内开或关.md`](不引入美术开-不引入过多人工关-非高风险关-质量大于2开或关-完整度约1关-五小时内开或关.md)「按住瞄准只进入一次动作」。
