## 顺序

不写日期。镜头、锁定、攻击、篝火、交互、终局、受击、踢、背刺、弹反、回城、余烬和暗印已测完，从测试项拿掉。还没勾的不挡下一步：轻推走路键盘测不了。见 [候选池首页](../README.md)。

M0 已完成。消耗品、法术、武器字段和 `Prefabs/Future/` 已放进这场。实施步骤不再留在这里。

下一步是 M1，不开开发计划版本。前两刀把死亡送回和残留接到场上。后面五刀结算已经在，缺的是能点到的入口。一刀做完再做下一刀。

1. 死亡送回。死亡动作结束后，人回到上次坐下记下的那堆火。清掉死亡。生命补到熄灭余烬之后的上限，精力、专注回满，两瓶按当前分配补满。已经打死的近战走现在的休息恢复。不读四项菜单，不新做界面。从没坐下过时不另送一堆默认火。全图重置和清异常不在这一刀。
2. 灵魂残留。带着灵魂死去，死亡点出现一个几何体，和钥匙同一档。走到跟前交互，几何体消失，灵魂加回那一笔，不进背包。没捡再死，旧的消失，只留这次身上的一笔。身上是 0 时不生成。不做绿色血光，代码里不做粒子。
3. 坐下弹出四项。休息照旧先结算。菜单是传送、整理法术、储物箱、离开，没有升级，没有分瓶。离开后人能走，刚补上的生命还在。
4. 传送。名单只用已经点燃的火。另一处已点燃才能过去。正坐着的这一处和没点燃的过不去。场上要有第二堆已经点燃的火，不用终局那堆。
5. 储物箱。各处火是同一份。没装备的能存能取，装备中的不行。暗印放不进。格子上限和别的种类不进这一刀。
6. 整理法术。只有坐下能改。放进空栏，同一条不能占第二格，栏满放不进。站着打不开。
7. 防火女加点。不进篝火菜单。够魂才加一级。光标停在生命、蓝或精力上时先给预览，确认后的上限等于这份预览。魂不够则不动。放一个能对话的入口，不新做模型。

后五刀要拼能点的界面，用现有的 uGUI，不新做贴图。传送和防火女另外在场上多一个物体。

瓶碎片和未死人骨片没有物品去调用。紫苔那一组没有脚本。商店、铁匠、王座、印记、分瓶这些菜单还没接上。这些都不放进这七刀。

工时是粗估，不是实测，最小精度 0.5 小时。Agent 只计接线。拼界面和摆物体算人工，走查另计。储物箱和整理法术各是两列名单，比弹出四项重。人工按窗口估，含勾出问题后的修复与复测，窗口之间隔一到数天正常。后续里程碑见 [候选池首页](../README.md)。
