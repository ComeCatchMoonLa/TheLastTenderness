## 顺序

不写日期。镜头、锁定、攻击、篝火、交互和终局已勾完，从测试项拿掉。见 [候选池首页](../README.md)。

受击两条，踢、背刺、弹反五条已测完，从测试项拿掉。还没勾的不挡下一步：轻推走路键盘测不了。

先把待搭建的测试环境里、脚本已经在、只差摆进这场的做完，再做 MVP。

1. 资产已放进这场，勾随 M0-3：回城骨、卷剑碎片、余烬、暗印，以及补充、丰饶之光、丰饶阳光。丰饶阳光的信仰要求高于这名角色，用来看耸肩。火球和治疗术的要求仍是 0。
2. 架势、成对、霸体已放进这场，勾随 M0-3。附魔、加槽、需求变慢没有调用方，不在这一步。
3. 预制体和头目已放进这场。你要做的是落点、头目走不动时的导航、两次对照和打勾。协助召唤、白签黄签、队伍、呼救、场地机关没有入口，不勾。

工时是粗估，不是实测，最小精度 0.5 小时：按条目数乘单条配置、摆放和接线的工作量估。特性版每版几分钟是代码切片速度，不能外推到摆场景；回归窗口混有摆场景、烘焙、配数和文档，也算不出干净系数。人工按窗口估，含勾出问题后的修复与复测，窗口之间隔一到数天正常。后续里程碑见 [候选池首页](../README.md)。
