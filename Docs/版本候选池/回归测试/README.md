## 顺序

不写日期。镜头、锁定、攻击、篝火、交互和终局已勾完，从测试项拿掉。轻推走路键盘测不了，先空着。

1. 背包和装备。`Esc` 点背包，或 `Tab` 再点 Inventory / Equipment。点格子。消耗品点一下就换快捷栏，法术不换。武器和护甲点一次只记住，再点同一件才换上。先点护甲格再点武器，武器还在背包里。
2. 受击、踢、背刺、弹反。背刺先去掉这只近战的 `Enable AI`。踢和弹反再勾上。弹反前把 `parryWindowFrames` 填成正数。按住 `E` 约半秒才是背刺和处决。
3. 敌人拉出约 15 米回家。现在仇恨没脱也能被引出 15 米外，这条先当缺陷，修好再勾。
4. 测试搭建里还走不到的，再开程序功能池里全都解锁的候选，再换对接池里的正式内容。
