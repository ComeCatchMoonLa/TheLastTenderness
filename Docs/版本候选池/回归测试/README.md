## 顺序

不写日期。现在这些已经够测、够修一段。镜头已勾完。战斗整段先放下。

1. 移动。走、跑、冲刺和精力，翻滚、后撤，上下坡，跳跃、下落、落地。下落会把人锁死，先修再勾完。
2. 锁定。锁上、解开、横移、换目标。
3. 交互。篝火、门、墙、电梯、梯子、箱子、拾取，以及靠近时的提示。
4. 界面。暂停、背包、状态、快捷栏。
5. 装备。换武器、换护甲、双手。
6. 战斗。攻击、格挡、受击、踢和背刺、敌人、喝药、死亡、法术、弓。
7. 终局。单独最后，会把世界重来。

这七步走完，再补测试搭建里还走不到的，然后开 [程序功能池](../程序功能池/README.md) 里全都解锁的候选，再换对接池里的正式内容。
