## 顺序

不写日期。镜头、锁定、攻击、篝火、交互和终局已勾完，从测试项拿掉。见 [候选池首页](../README.md)。

测试项里还没勾的不挡下一步：轻推走路键盘测不了；受击两条；踢、背刺、弹反五条。参数写在测试项里。

先把测试搭建「未做」里、脚本已经在、只差摆进这场的做完，再做 MVP。

1. 菜单建资产后能测：回城骨、卷剑碎片、余烬、暗印，以及补充、丰饶之光、丰饶阳光。现有法术把智力或信仰要求填得高于这名角色，才能看耸肩。
2. 现有武器上勾或填：架势、成对、附魔、进攻霸体、需求高于角色。异常槽的结算已经在，要有一把打中会加槽的攻击，并填容量、时长、每秒伤害。翻滚从第几帧开始无敌不在这一步选。
3. `Prefabs/Future/` 放进 `Game` 之后才能勾：头目血条、头目拉远、雾门、换阶段、死后清场、场地机关、协助时头目更厚、留言和血渍、协助召唤、协助和入侵的队伍、白签和黄签、呼救。

工时是粗估，不是实测，最小精度 0.5 小时：按条目数乘单条配置、摆放和接线的工作量估。特性版每版几分钟是代码切片速度，不能外推到摆场景；回归窗口混有摆场景、烘焙、配数和文档，也算不出干净系数。人工按窗口估，含勾出问题后的修复与复测，窗口之间隔一到数天正常。后续里程碑见 [候选池首页](../README.md)。

| 顺序 | Agent 工时 | 人工 |
| --- | --- | --- |
| M0-1 菜单建资产 | 约 0.5 到 1 小时 | 摆完随 M0-3 一起勾 |
| M0-2 现有武器勾字段 | 约 0.5 到 1 小时 | 同上 |
| M0-3 `Prefabs/Future/` 放进 `Game` | 约 1.5 到 3.5 小时。`World` 和 `Online Marks` 第一次进这场，十三项逐个摆入、逐项勾，估得比前两步宽 | 主验收窗口 1.5 到 2 小时逐项勾；另留 1 到 2 个补窗口，每个 1 到 1.5 小时，给修复和复测 |
| 合计 | Agent 约 2.5 到 5 小时 | |
| M1 MVP：篝火四项、防火女加点 | Agent 约 0.5 到 1 小时，只接对话和界面入口 | 1 到 1.5 小时走一遍，另留一个补窗口给修复复测 |

瓶碎片和未死人骨片没有物品去调用。紫苔那一组没有脚本。死后怎么重新能走仍在未入池。商店、铁匠、王座、印记、分瓶这些菜单还没接上。这些都不放进上面三步。
