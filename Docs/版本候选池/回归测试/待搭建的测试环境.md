## 死后走不回去

血到 0 会播死亡，画面上的灵魂数字变成 0，`isDead` 不会再清掉。开局那个 1300 是界面上的字，不是身上已经有 1300。`RecoverRemnant` 没有调用方，场上也没有残留物体。送回和残留排进 [M1](README.md) 的前两刀，做完再测，现在不勾。

| 功能 | 应看到的 | 缺什么 |
| --- | --- | --- |
| 死亡送回 | 死亡动作结束后回到上次坐下的火，人能走。生命、精力、专注回满，两瓶按当前分配补满 | M1-1。从没坐下过时不另送一堆默认火 |
| 捡回残留 | 死亡点有一个几何体。拾取后消失，灵魂加回那一笔，不进背包 | M1-2。先要人能走。不做绿色血光 |
| 没捡再死 | 地上只剩新的一笔。这次身上是 0 则不留残留 | 同上 |

## 命中不会加异常槽

出血、中毒、剧毒、冰霜、咒死的结算在代码里。没有任何命中调用加槽，填容量、时长、每秒伤害也不会在 Play 里蓄满。这一步不新接。翻滚从第几帧开始无敌不在这一步选。
