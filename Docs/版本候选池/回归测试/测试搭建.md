### 要填上的数

玩家预制体：

| 字段 | 回归用的值 | 否则 |
| --- | --- | --- |
| `walkSpeed`，`walkUntil`，`runSpeed`，`sprintSpeed` | 2，0.4，5，7 | `walkSpeed` 不大于 0 或不小于 `runSpeed` 时，轻推仍是跑步，或进游戏报未填 |
| `parryWindowFrames` | 一个正数 | 现在是 0，弹反会报未填，分不出窗口内和窗口外。正式帧数没定，这个正数只给这场 |

近战用 `Humanoid A.I Settings - Melee`：`activityRadius` 15，`returnArrive` 1，`detectionRadius` 30，`aggroRadius` 5。视野大约左右各 62 度，中间有墙则不发现。察觉距离大于活动半径，所以拉出 15 米就是满血回家，走不到「只回到发现前的位置、不满血」。`returnArrive` 没填时，它走回发现前的位置不会停下。

`Camp Fire` 的 `hostileRadius` 是 8。小于等于 0 时坐下会报未填。

`Arrow`：`physicalDamage` 50 是快射。`fullDrawTime` 填正数，`fullDrawDamage` 填成大于 50，两档的「已填」勾上。空着时拉满仍打出 50，看不出两档。

### 背包

`Player` 预制体的 `items` 里有 `Key`。场景把它盖成了三件护甲：`Chr_HelmetAttachment_07`、`Chr_Torso_Female_14`、`Chr_Hips_Female_21`。

回归场的 `items` 要同时有：

- `Key`。没有它，门的「拿掉钥匙打不开」勾不了。
- 上面三件里吸收不同的至少两件。一样的话，确认换装看不出吸收变了。

回城骨、卷剑碎片、余烬、暗印已放进这名玩家的消耗品。瓶碎片和未死人骨片没有物品去调用加次数和升档。死亡后的掉魂和捡魂在未做里：画面数字会死成 0，地上没有东西可捡，人也不会自己站起来。

### 消耗品

血瓶是 `Estus Flask`，项名称「血瓶」，类型 `estus`。灰瓶是 `Ash Flask`，项名称「灰瓶」，类型 `ashen`。两件都用 `Drink`。火炸弹用 `Throw_Consumable`。

这名玩家接上 `Flask Recovery Table`。`flaskTotal` 4，`estusShare` 和 `estusLeft` 都是 3，`ashShare` 和 `ashLeft` 都是 1，`boneTier` 是 0。没接上表时喝成功报 `PlayerInventoryManager.recoveryTable 未填`，这一口不加生命也不加蓝。

`boneTier` 为 0 时，血瓶一口加生命 250，灰瓶一口加蓝 80。改成 1 时是 335 和 95，改成 10 时是 600 和 200。先把生命打到不满、蓝用掉一截再喝，上限不够时会加到顶，看不出整段。物品上的 `healthRecoverAmount`、`focusPointsRecoverAmount` 不决定这一口。喝药扣的是快捷栏当前件的 `Current Item Amount`，不扣画面上「血瓶」「灰瓶」那一行。那一行在休息时写回各自的 Share。

回城骨、卷剑碎片、余烬、暗印已在消耗品里，使用动作都是 `Drink`。回城骨、余烬、暗印个数 3，卷剑碎片个数 1。余烬的 `healthRatio` 是 0.3，空着报未填并停住。暗印没有更枯外形，用了也看不出变枯。

瓶碎片、未死人骨片、紫苔和祝福、分瓶仍在未做。前两样没有物品调用 `AddFlaskShard` 和 `AddBoneShard`。苔药没有脚本。分瓶没有对话。

### 死后走不回去

血到 0 会播死亡，画面上的灵魂数字变成 0，`isDead` 不会再清掉。开局那个 1300 是界面上的字，不是身上已经有 1300。`RecoverRemnant` 没有调用方，场上也没有残留物体。死后回火的规则已定：死亡播完后自动回到上次坐下的篝火旁恢复可操作，见 [FR-燃火-08](../../需求文档/功能需求/燃火休息与死亡惩罚.md)；当前仓库没有回火流程，这一条排期前，掉魂、捡魂和再死一次都不测。

| 功能 | 应看到的 | 缺什么 |
| --- | --- | --- |
| 捡回残留 | 走到死亡点拾取，残留消失，灵魂加回那一笔 | 场上的残留，以及人重新能走。等 FR-燃火-08 排期 |
| 没捡再死 | 地上只剩新的一笔。这次身上是 0 则不留残留 | 同上。现在第二次死不了，因为第一次已经不能操作 |

### 命中不会加异常槽

出血、中毒、剧毒、冰霜、咒死的结算在代码里。没有任何命中调用加槽，填容量、时长、每秒伤害也不会在 Play 里蓄满。这一步不新接。翻滚从第几帧开始无敌不在这一步选。
