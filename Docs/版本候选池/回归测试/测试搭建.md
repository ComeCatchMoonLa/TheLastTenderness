# 测试搭建

> **已做的用来勾 [测试项.md](测试项.md)。未做的代码已经有，Play 里还走不到。** 这是 Play 回归场，不是正式关卡，也不是正式数值。

打开 `Assets/Scenes/Game.unity`，点 Play。终局那一组会重来世界，放在最后勾。

`Floor`、`Wall1` 到 `Wall4` 只垫脚和挡路。`Pick Up Item` 是地上的 `Key`，不是武器。`Fire`、`Directional Light`、`EventSystem` 留着。主相机下的 `Sphere` 不参与相机碰撞，不要删。

### 要填上的数

玩家预制体：

| 字段 | 回归用的值 | 否则 |
| --- | --- | --- |
| `walkSpeed`，`walkUntil`，`runSpeed`，`sprintSpeed` | 2，0.4，5，7 | `walkSpeed` 不大于 0 或不小于 `runSpeed` 时，轻推仍是跑步，或进游戏报未填 |
| `parryWindowFrames` | 一个正数 | 现在是 0，弹反会报未填，分不出窗口内和窗口外。正式帧数没定，这个正数只给这场 |

近战用 `Humanoid A.I Settings - Melee`：`activityRadius` 15，`returnArrive` 1，`detectionRadius` 30，`aggroRadius` 5。视野大约左右各 62 度，中间有墙则不发现。察觉距离大于活动半径，所以拉出 15 米就是满血回家，走不到「只回到发现前的位置、不满血」。`returnArrive` 没填时，它走回发现前的位置不会停下。

`Camp Fire` 的 `hostileRadius` 是 8。小于等于 0 时坐下会报未填。

`Arrow`：`physicalDamage` 50 是快射。`fullDrawTime` 填正数，`fullDrawDamage` 填成大于 50，两档的「已填」勾上。空着时拉满仍打出 50，看不出两档。

### 背包

`Player` 预制体的 `items` 里有 `Key`。场景把它盖成了三件护甲：`Chr_HelmetAttachment_07`、`Chr_Torso_Female_14`、`Chr_Hips_Female_21`。

回归场的 `items` 要同时有：

- `Key`。没有它，门的「拿掉钥匙打不开」勾不了。
- 上面三件里吸收不同的至少两件。一样的话，确认换装看不出吸收变了。

回城骨、卷剑碎片、余烬、暗印没有物品资产，不要为了回归临时造一个假物品。它们在未做里。死亡后的灵魂残留也在未做里：数字记下了，场上没有东西可捡，人也不会自己站起来。

### 死后走不回去

血到 0 会播死亡，灵魂数字变成 0，`isDead` 不会再清掉。`RecoverRemnant` 没有调用方，场上也没有残留物体。

| 功能 | 应看到的 | 缺什么 |
| --- | --- | --- |
| 捡回残留 | 走到死亡点拾取，残留消失，灵魂加回那一笔 | 场上的残留，以及把人放开或放回火边 |
| 没捡再死 | 地上只剩新的一笔。这次灵魂是 0 则旧的也没有 | 同上。现在第二次死不了，因为第一次已经不能操作 |

### 命中不会加异常槽

出血、中毒、剧毒、冰霜、咒死的结算在代码里。没有任何武器或法术在打中时去加这些槽，Play 里蓄不满。

准备会加对应槽的攻击，并填上容量、时长、每秒伤害。时长或容量空着时不应开始发作。无敌为真时这一下不加槽，无敌结束后的下一击才加。翻滚从第几帧开始无敌还没定，不要为了这一条先选一个帧数。
