# 测试环境

> **`Game` 里已经摆上的。** 用来勾 [测试项.md](测试项.md)。代码有了、Play 里还走不到的在 [待搭建的测试环境.md](待搭建的测试环境.md)。这是 Play 回归场，不是正式关卡，也不是正式数值。

打开 `Assets/Scenes/Game.unity`，点 Play。终局那一组会重来世界，放在最后勾。

## 场景摆放

物体站在哪、彼此离多远。槽位里放了哪一件、字段填了多少，见下面两节。

| 用来测 | 物体 | 怎么摆 |
| --- | --- | --- |
| 走、跑、冲、锁定 | `Player`、场景根上的 `Global UI`、`Player Camera`、两只近战 | 两只都在能锁上的距离里，左右分开站 |
| 盾、踢、背刺、弹反、处决 | 同一只 `Humanoid A.I - Melee`，会举盾 | 身前和背后都有空地 |
| 拉远回家 | 这只近战的放置点 | 能走出 15 米以上。不满血回家这场走不到 |
| 坐下和敌对 | `Camp Fire` | 能把近战拉进火周围，也能拉开后再坐下 |
| 门 | `Door` | 正面和背面都走得到 |
| 幻影墙 | `LlusionWall` | 能翻滚撞上。走路撞上应不开 |
| 电梯 | `Elevator` | 两个落点都站得住人，高度分开。两层叠在一起时平台不会动 |
| 梯子 | `Ladder` | 有高度。滑得到底。离开时下面能下落 |
| 箱子 | `Chest` | 走得到 |
| 死亡 | 一块能把自己打死的空地 | M1-1、M1-2 做完之前没有可拾取的残留，见 [待搭建的测试环境](待搭建的测试环境.md) |
| 头目 | `World`，以及放大的那只头目 | `End Camp Fire` 开局封着，和用来休息的 `Camp Fire` 不是同一堆 |
| 终局 | `Ending`，以及勾了下一周的 `End Camp Fire` | 和用来休息的 `Camp Fire` 不是同一堆 |

`Floor`、`Wall1` 到 `Wall4` 只垫脚和挡路。`Pick Up Item` 是地上的 `Key`，不是武器。`Fire`、`Directional Light`、`EventSystem` 留着。主相机下的 `Sphere` 不参与相机碰撞，不要删。

## 接上的引用

谁指着谁、哪一格放了哪一件。个数和半径在下一节。

| 接在 | 指向 |
| --- | --- |
| `Global UI` 的 `player` | 这场的 `Player` |
| `Door` 的钥匙 | `Key` |
| `Chest` 里面 | 一件已有物品 |
| 玩家 `items` | `Key`，以及 `Chr_HelmetAttachment_07`、`Chr_Torso_Female_14`、`Chr_Hips_Female_21` 里吸收不同的至少两件。预制体上原来只有 `Key`，场景把它盖成了这三件护甲。没有 `Key`，门的「拿掉钥匙打不开」勾不了。两件吸收一样时，确认换装看不出变化 |
| 玩家消耗品 | `Estus Flask`、`Ash Flask`、`Fire Bomb`、回城骨、卷剑碎片、余烬、暗印。瓶碎片、未死人骨片、紫苔和祝福、分瓶仍在 [待搭建的测试环境](待搭建的测试环境.md) |
| 玩家 `Flask Recovery Table` | 这场用的回复表。没接上时喝成功报 `PlayerInventoryManager.recoveryTable 未填`，这一口不加生命也不加蓝 |
| 右手 | 第 3 格双手斧，第 4 格 `Stance Sword`，第 5 格成对剑。弓的对照要另留一把普通单手 |
| 左手 | 弓、盾，再加一把不是弓的单手。没有这把，左手轻击那一条不勾。火焰催化器给火球。护符或圣铃用来放 `Heal Player`，也用来对火球看拿错不施放 |
| 弹药槽 | `Arrow` |
| 记忆列表 | 火球、治疗术、补充、丰饶之光、丰饶阳光。直接填在这名玩家身上。只有一份时上方向键不换 |
| `Stance Sword` | `stanceArt` 已勾。`Oh_tap_r_action` 是 `Parry Action`。单手剑按 `Y` 握不上。没有姿势 |
| 血瓶、灰瓶、火炸弹 | 项名称「血瓶」「灰瓶」。类型 `estus`、`ashen`。两瓶用 `Drink`，火炸弹用 `Throw_Consumable` |
| 回城骨、卷剑碎片、余烬、暗印 | 使用动作都是 `Drink`。暗印没有更枯外形，用了也看不出变枯 |

死亡后的掉魂和捡魂还没接上，见 [待搭建的测试环境](待搭建的测试环境.md)。画面数字会死成 0，地上没有东西可捡，人也不会自己站起来。

## 这场填的数

正式数值不在这里。这些数只让这场能分出结果。

| 填在 | 回归用的值 | 否则 |
| --- | --- | --- |
| 玩家 `walkSpeed`，`walkUntil`，`runSpeed`，`sprintSpeed` | 2，0.4，5，7 | `walkSpeed` 不大于 0 或不小于 `runSpeed` 时，轻推仍是跑步，或进游戏报未填 |
| 玩家 `parryWindowFrames` | 一个正数 | 是 0 时弹反报未填，分不出窗口内和窗口外。正式帧数没定 |
| 近战 `Humanoid A.I Settings - Melee` | `activityRadius` 15，`returnArrive` 1，`detectionRadius` 30，`aggroRadius` 5 | `returnArrive` 没填时，它走回发现前的位置不会停下 |
| `Camp Fire` 的 `hostileRadius` | 8 | 小于等于 0 时坐下报未填 |
| `Arrow` | `physicalDamage` 50。`fullDrawTime` 为正数，`fullDrawDamage` 大于 50，两档的「已填」勾上 | 空着时拉满仍打出 50，看不出两档 |
| 回复表 | `flaskTotal` 4，`estusShare` 和 `estusLeft` 都是 3，`ashShare` 和 `ashLeft` 都是 1，`boneTier` 0 | 喝药扣的是快捷栏当前件的 `Current Item Amount`，不扣画面上「血瓶」「灰瓶」那一行。那一行在休息时写回各自的 Share |
| `boneTier` 0 时每一口 | 血瓶加生命 250，灰瓶加蓝 80。1 档是 335 和 95，10 档是 600 和 200 | 先把生命打到不满、蓝用掉一截再喝。上限不够时会加到顶，看不出整段。物品上的 `healthRecoverAmount`、`focusPointsRecoverAmount` 不决定这一口 |
| 回城骨、余烬、暗印，卷剑碎片 | 个数 3，卷剑碎片个数 1 | |
| 余烬 `healthRatio` | 0.3 | 空着报未填并停住 |
| 双手斧，霜剑 | 进攻霸体 75，霜剑是 1 | 霜剑仍是普通单手 |
| 头目 | 名字「头目」。`phaseThreshold` 0.5。`allyJoined` 勾上，倍数 1.5 | |
| 补充、丰饶之光、丰饶阳光 | 每次 10 秒。丰饶阳光信仰要求 11 | 火球和治疗术的要求是 0，才能用来打盾。预热特效播完留在场上，不挡 |
| 开局画面上的灵魂数字 | 1300 | 这是界面上的字。地上没有可捡的残留 |

近战视野大约左右各 62 度，中间有墙则不发现。察觉距离大于活动半径，所以拉出 15 米就是满血回家，走不到「只回到发现前的位置、不满血」。
