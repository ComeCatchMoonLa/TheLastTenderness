# 测试项

> **在 `Game` 里按下面打勾。** 测过的把 `[ ]` 改成 `[x]`。搭建见 [测试搭建.md](测试搭建.md)。走不到的在那一份的未做里，不在这里勾。

终局会重来世界，放在最后。界面只看打开、关闭和显示。装备只看穿上、换下和因此改变的战斗。

## 移动

- [ ] 轻轻推摇杆：人走路，明显慢于跑步。
- [ ] 摇杆推满：人跑步。轻推不得变成跑步。
- [ ] 按住冲刺：比跑步更快。松手回到跑步或走路。
- [ ] 举盾或瞄准时按住冲刺：不进入冲刺。
- [ ] 冲刺会扣精力。降到冲刺所需的最低值后停住，不会扣成负数。
- [ ] 按住冲刺时精力不往回长。松开、不再做动作，过一会儿才开始回复，并且不超过上限。
- [ ] 摇杆有输入时短按闪避：向该方向翻滚，并扣精力。精力付不清则不翻。
- [ ] 摇杆回中时短按闪避：后撤，并扣精力。精力付不清则不后撤。
- [ ] 下坡比平地快，人贴着坡走。上坡也贴着坡，不悬空。
- [ ] 移动中按跳跃：向移动方向起跳，并扣精力。站着不动不跳。瞄准时不跳。
- [ ] 人还在下落时按走路，不立刻进入地面移动。落地之后才能再走。从矮坎下来不播落地，从更高的地方下来才播。
- [ ] 点火、开箱、拾取或休息的动作没播完：走路和攻击不开始。动作结束才能再做。

## 镜头

- [ ] 转鼠标或右摇杆：镜头绕着人转，抬头低头不会翻过去。
- [ ] 人移动时镜头跟着。松手后还会滑一小段再停，不是瞬间粘住，也不是滑到一半停死。
- [ ] 人贴着墙：镜头拉近，不穿进墙里。离开墙后回到原来的距离。
- [ ] 瞄准时人仍有碰撞半径，不会缩成能穿墙的一条线。瞄准时画面用瞄准机位。松开后回到原来的机位。

## 锁定

- [ ] 锁定活着的近战：标记出现在它的锁点上，并跟着锁点移动。镜头看着这一只。
- [ ] 解开锁定，或把目标打死：标记关掉。解开后可以再自己转镜头。这场要能看见标记。
- [ ] 锁定后不冲刺：推左右是横移，人继续面向目标。推前后也面向目标。
- [ ] 锁定时翻滚：身体朝翻滚的方向，不是一直对着目标。
- [ ] 自动换目标关掉，两只都在范围内：左右切换时标记换到另一只。只有一只时仍是这一只。
- [ ] 自动换目标开着：左右键不手动换目标。
- [ ] 左手是弓时按锁定：不进入锁定。弓收起来之后仍能锁。

## 攻击

- [ ] 右手轻击、重击都能打出。打中会掉血。连段窗口里再按，轻击和重击都能接上第二段。
- [ ] 左手槽里有一把不是盾、也不是弓的武器时，左手轻击打出的是这一把，不是右手那一刀。左手是盾时，按住是举盾。
- [ ] 挥击时武器拖尾出现。这一下结束，拖尾关掉。
- [ ] 精力还剩一点、不够支付这一下轻击或重击：动作仍打出，精力条见底。精力已经是 0 时这一下不开始。画面上看不出负到多少。
- [ ] 同一次伤害窗口里，同一个敌人只掉一次血。窗口还开着时再碰到他，可以再掉一次。窗口关掉后再挥中，又可以掉。一挥同时打中两个人，各掉一次。
- [ ] 左右手都空着挥一下：不播挥刀音。手上有武器时仍播。

## 格挡

- [ ] 正面举盾挡住：按盾减伤，并按这面盾的稳定度扣精力。
- [ ] 从侧面来的一下：角度内挡住，角度外打在身上。
- [ ] 这一下格挡的精力付不清：破防，不是只减伤。
- [ ] 格挡命中时不播肉体受伤的声音。没挡住时仍播。

## 受击

- [ ] 从左侧打来并破韧：身体向左受击。从右侧打来并破韧：身体向右受击。
- [ ] 这一下的硬直结束后再被打：重新播受击，不是卡在上一次硬直里。画面上看不出韧性数字。

## 踢、背刺、弹反

- [ ] 没在冲刺，并且向前的轻攻击打中举盾：对方精力见底，进入崩架。冲刺中，或这一下没有向前，仍按原来的格挡扣精力，不崩架。
- [ ] 崩架弯腰后贴上去：双方进入处决，打出一次伤害。对方精力还在时，这一下仍是普通攻击。
- [ ] 贴在它正背后按轻击：进入背刺，不是普通一刀。已经进入背刺之后，这一下不再掉第二次血。
- [ ] 没贴正，或距离不够：走现有轻击，不是什么都不做。
- [ ] 弹反按下后的前若干帧里打中：弹开，再贴上去能处决。帧数过了再打中：打在自己身上，不能处决。`parryWindowFrames` 是 0 时不要勾，先按搭建把帧数填成正数。

## 敌人

这只近战的活动半径是 15，察觉距离是 30，所以拉出 15 米时还在察觉距离里，走的是满血回家。不满血、只走回发现前位置，要察觉距离小于活动半径，这场对不上，不勾。

- [ ] 人出现在它面朝的扇形里，中间没有墙，并且在察觉距离内：它追过来并出招。打中玩家时玩家掉血。走到它背后，或中间隔着墙：它不因此追来。
- [ ] 打中它：头上出现血条，当前血比上限短。过一会儿血条关掉。把它打死：血条去掉，它不再出招，玩家的灵魂数字增加。休息前它不会自己站起来。
- [ ] 把它拉出大约 15 米：它走回放置点，生命回到上限。归途中离它大约 5 米以内打中它，它转回追击，不满血回家。离得更远打中，它继续回家。

## 篝火

- [ ] 火还没点：交互是点火。点着之后提示变成休息，火的粒子开着。
- [ ] 近战正在追，并且人在火周围 8 米内：坐不下去，生命不回满。
- [ ] 拉开之后坐下：自己的生命、蓝、精力回到上限。这一下才把这堆火记成下次回去的火。走过或坐不下去，都不改上次的火。
- [ ] 坐下前先把近战打死：坐下后这只近战回到开局位置并且满血，不是消失。
- [ ] 坐下再起来：人可以再走路。

## 喝药

- [ ] 喝血瓶成功：生命上升。喝带蓝的瓶子成功：蓝也上升。回复量是 0 的那一条不涨。
- [ ] 连续按喝药：喝下去的是按下那一下时选中的瓶子，不是中途换成的另一瓶。
- [ ] 连续按火炸弹：炸出去的是按下那一下时选中的那一件。

## 机关

- [ ] 这扇门还关着时，从背侧交互：打不开。
- [ ] 背包里没有 `Key`，从正面交互：门不动。
- [ ] `Key` 放回背包，从正面打开：门转开约 90 度，人走得过去。钥匙仍在背包里。
- [ ] 休息后再回来：这扇门仍开着。
- [ ] 没填钥匙的门仍从正侧打开。这场只有一扇填了钥匙的门时，这一条不勾。
- [ ] 翻滚撞上幻影墙：碰撞和模型关掉。走路撞上不开。休息后再看，墙仍是开的。
- [ ] 对电梯交互一次：平台到另一处。再交互一次：回到刚才离开的方向。休息不把它拉回出发层。
- [ ] 靠近梯子交互：能上下。
- [ ] 在梯子上按住闪避且摇杆向下：人滑到梯底。
- [ ] 摇杆回中再按闪避：人离开梯子并进入下落。
- [ ] 开一次箱子：物品进背包。再交互没有第二份。休息后再看，仍是打开过的。
- [ ] 交互地上的武器拾取：武器进背包。

## 死亡

死前先确认灵魂数字大于 0。捡回残留在测试搭建的未做里，不要在这里找地上的血迹。

- [ ] 血到 0：播死亡，灵魂数字变成 0，人不能再走、不能再攻击。镜头不再跟着转。
- [ ] 死前灵魂就是 0：灵魂数字仍是 0。

## 界面

- [ ] 靠近门、火、箱子或可拾取物：出现该物体自己的提示。走开后提示关掉。
- [ ] 受伤时血条下降。挥击或冲刺时精力条下降，松开并过一会儿才回，不超过上限。放法术时蓝条下降。灵魂数字和身上的灵魂一致。
- [ ] 不在暂停时按分页切换：背包、装备、状态轮换。暂停列里能打开背包、状态、姿态，没有加点。再按暂停打开暂停。返回或再按暂停关掉，人又能走。
- [ ] 暂停打开时人不再走。关掉之后恢复。
- [ ] 暂停里改自动或跳过：关掉再打开，仍是改过的值。
- [ ] 状态页能读八项等级和灵魂。这一页不能加点。
- [ ] 背包按种类分页。点开一页只有这一类，不会和别的种类混在同一列。
- [ ] 在背包里点一件法术或消耗品：快捷栏当前项换成它。点武器或护甲，不改快捷栏当前消耗品。
- [ ] 下方向键换成下一件消耗品。快捷栏当前项跟着变，使用的是这一件。
- [ ] 记忆里有两份法术时，上方向键换成下一份，快捷栏法术图标跟着变。只有一份时不换。
- [ ] 快捷栏回复格能看见剩余次数。喝成功一次，数字减一。减到 0 仍显示 0。坐下之后回到该瓶的上限。
- [ ] 切到火炸弹这类别的消耗品：血瓶和灰瓶的次数仍单独看得见。使用键作用于当前这一件，不误喝瓶子。
- [ ] 快捷栏里一件没有图标的武器、法术或消耗品：这一格清掉上一张图并停用。有图标的仍换成新图。
- [ ] 开箱或拾取成功：出现获得提示。

## 装备

- [ ] 装备页每只手三格、防具四格、戒指四格。空位是空的。已经穿着的那件还在。
- [ ] 装备窗能改选这只手的第 2、第 3 把。选中后当前武器是这一把。方向键轮换不改这次选中的下标。
- [ ] 左手不是弓时，右方向键换成右手下一把，手上的模型跟着换。左手是弓时，右方向键不换右手武器。
- [ ] 左方向键换成左手下一把。手上的模型跟着换。
- [ ] 按双手：左手是弓，或右手是双手武器时，持握切换，再按一次回来。右手是普通单手剑且左手不是弓时，按双手不切换。
- [ ] 护甲槽上点一件武器：武器仍在背包里，不因为点错槽就丢了。
- [ ] 第一次点另一件：人还穿着旧的，给出攻击力和吸收的差，不显示重量，翻滚不变。
- [ ] 再点同一件：才换上，吸收变成新的。点到第三件时仍只预览，不换上。
- [ ] 换上另一件之后再打开状态页：等级和灵魂仍是换装前的数。
- [ ] 从带拖尾的武器换成另一类型：左手上一次的拖尾关掉。

## 法术

这场要已经按搭建装备火球、火焰催化器、护符和 `Heal Player`。智力或信仰不够因而耸肩的情况在测试搭建的未做里，不在这里。

- [ ] 生命不满时用护符放 `Heal Player`：生命加 50，不超过上限。已经满了不再往上加。
- [ ] 蓝不够时放治疗：这一下停住，不把蓝扣进一个成功的治疗。
- [ ] 换成护符或圣铃再放这发火球：不施放。换回火焰催化器仍放得出。
- [ ] 弹体打在近战正面举着的盾上：按盾的吸收减伤，并扣它的精力。
- [ ] 它没举盾，或这一下不是正面：按原来的伤害扣生命，不走盾的吸收。

## 弓

`Arrow` 的拉满时间和拉满伤害已经按搭建填好，并且拉满伤害大于 50。

- [ ] 按住达到拉满时间再射：伤害高于快射。
- [ ] 没到拉满时间就松手：伤害是快射那一档 50。
- [ ] 两档都先扣一发弹。

## 终局

- [ ] 在结局标记上交互一次：记下这一处已经标好的那一条结局。再交互一次，不改成另一条，也不会同时记下两条。玩家不在这里面三选一。
- [ ] 还没记下结局时，到勾了下一周的那堆火上交互：不进下一周。这堆火仍可以当普通休息用。
- [ ] 已经记下结局之后，再到这堆火上交互一次：进入下一周。等级还在。火要重新点，打开过的门关上，`Key` 不在背包。这一勾用掉，再交互不再进一周。
