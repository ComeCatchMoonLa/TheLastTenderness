# 测试项

> **在 `Game` 里按下面打勾。** 测过的把 `[ ]` 改成 `[x]`。搭建见 [测试搭建.md](测试搭建.md)。走不到的在那一份的未做里，不在这里勾。

终局会重来世界，放在最后。界面只看打开、关闭和显示。装备只看穿上、换下和因此改变的战斗。

## 移动

- [ ] 轻轻推摇杆：人走路，明显慢于跑步。(键盘暂时无法测试轻推)

## 受击

先让它打你，不要追着它跑。挨到的那一下之前，用鼠标把自己转到侧面：面朝它的左前方挨一次，再面朝它的右前方挨一次。看的是身体倒向哪一侧，不是韧性数字。

- [ ] 从左侧打来并破韧：身体向左倒。从右侧打来并破韧：身体向右倒。
- [ ] 这一下倒完、人能再动之后，再挨一下：又倒一次，不是卡在上一次的姿势里。

## 踢、背刺、弹反

背刺先把敌人停住。选中 `Humanoid A.I - Melee`，去掉 `Enable AI`。它不再转向、不再追。测完踢和弹反之前再勾上，那两下要它自己举盾、自己出招。

点一下 `E` 是轻击。按住 `E` 约半秒（或按住鼠标左键）才是背刺和处决。`Z` 是左手弹反。按住 `Q` 是举盾。

- [ ] 勾上 `Enable AI`。等它举起盾。不按 `Shift`，按住 `W` 再点 `E`：它精力见底并弯腰。按住 `Shift` 再打，或站着不往前打：它只按格挡扣精力，不弯腰。
- [ ] 它弯腰时贴到身前，按住 `E`：双方进入处决，打出一次伤害。它还没弯腰时按住 `E`：这一下仍是普通攻击。
- [ ] `Enable AI` 关掉。走到它正背后，按住 `E`：进入背刺，不是普通一刀。背刺动作播的时候不再掉第二次血。
- [ ] 站在它身侧或离远一点，按住 `E`：是普通轻击，人不会吸到它背后。
- [ ] `Enable AI` 勾上。`parryWindowFrames` 填一个正数，否则不要勾。按 `Z` 之后马上挨它的攻击：它被弹开，贴上去按住 `E` 能处决。等一下再挨打：打在自己身上，不能处决。

## 敌人

这只近战的活动半径是 15，察觉距离是 30，所以拉出 15 米时还在察觉距离里，走的是满血回家。不满血、只走回发现前位置，要察觉距离小于活动半径，这场对不上，不勾。

- [ ] 把它拉出大约 15 米：它走回放置点，生命回到上限。归途中离它大约 5 米以内打中它，它转回追击，不满血回家。离得更远打中，它继续回家。
    BUG: 仇恨未拉脱时可以引出15米外。

## 背包和状态

打开方式：`Esc` 打开暂停，点背包。或 `Tab` 打开分页，点 Inventory，标题变粗的是当前页。点的是格子，不是格子上的字。

- [ ] 点一件消耗品：快捷栏当前消耗品图标换成它。点一件法术：快捷栏法术图标不变。点武器或护甲：快捷栏当前消耗品不变。

## 武器

先 `Tab` 打开分页，点 Equipment。

- [ ] 数格子：每只手三格，防具四格，戒指四格。没有图标的是空的。身上穿着的那件，图标还在对应的格上。
- [ ] 点这只手的第 2 格：手里换成这一格的武器。再点第 3 格：手里换成第 3 格的。关掉分页，按右方向键（左手是左方向键）换成下一把。再打开 Equipment：刚才点的那一格还是选中的，不跟着方向键跳到另一格。
- [ ] 先点一格护甲（头、身或髋）。再点背包里的一件武器。武器还在背包里，手里的武器不变。

## 护甲

武器和护甲都是：点一次只记住，再点同一件才换上。点到另一件，又变成只记住。差值没有画在界面上，看人身上的模型和吸收还是不是旧的。

- [ ] 点一件没穿着的护甲：人还穿着旧的，吸收还是旧的，翻滚不变。
- [ ] 再点同一件：才换上，吸收变成新的。接着点第三件：人仍穿着刚才换上的那件，不换成第三件。
- [ ] 换上之后点 Status：等级和灵魂还是换装前的数。
