## 受击

这只近战勾上 `Enable AI`。共用的 `Humanoid A.I Settings - Melee` 里，去掉 `allowAIToPerformBlock`、`allowAIToPerformDodge`、`allowAIToPerformParry`、`allowAIToPerformCombos`。只把概率改成 0 仍会抽到一次。`aggroRadius` 保持 5，`detectionRadius` 20，`activityRadius` 30。站进 5 米，它冷却好了就出刀，不举盾、不翻滚、不弹反、不连击，近处也不会回家。

挨到的那一下之前，用鼠标把自己转到侧面：面朝它的左前方挨一次，再面朝它的右前方挨一次。看的是身体倒向哪一侧，不是韧性数字。

- [ ] 从左侧打来并破韧：身体向左倒。从右侧打来并破韧：身体向右倒。
- [ ] 这一下倒完、人能再动之后，再挨一下：又倒一次，不是卡在上一次的姿势里。

## 踢、背刺、弹反

点一下 `E` 是轻击。按住 `E` 约半秒（或按住鼠标左键）才是背刺和处决。`Z` 是左手弹反。按住 `Q` 是举盾。概率仍在 `Humanoid A.I Settings - Melee`。你出手时它才掷格挡、闪避、弹反。

- [ ] 勾上 `Enable AI`，勾上 `allowAIToPerformBlock`，`blockLikelyHood` 填 100。去掉闪避和弹反那两个允许。先打它一下，等盾举起。不按 `Shift`，按住 `W` 再点 `E`：它精力见底并弯腰。按住 `Shift` 再打，或站着不往前打：它只按格挡扣精力，不弯腰。
- [ ] 它弯腰时贴到身前，按住 `E`：双方进入处决，打出一次伤害。它还没弯腰时按住 `E`：这一下仍是普通攻击。
- [ ] 选中这只近战，去掉 `Enable AI`。它不再转向、不再追。走到它正背后，按住 `E`：进入背刺，不是普通一刀。背刺动作播的时候不再掉第二次血。
- [ ] 还是关掉 `Enable AI`。站在它身侧或离远一点，按住 `E`：是普通轻击，人不会吸到它背后。
- [ ] 勾上 `Enable AI`。去掉格挡、闪避、弹反三个允许，让它出刀。玩家的 `parryWindowFrames` 填一个正数，否则不要勾。按 `Z` 之后马上挨它的攻击：它被弹开，贴上去按住 `E` 能处决。等一下再挨打：打在自己身上，不能处决。

## 回城

先坐下，快捷栏切到这一件再用。

- [ ] 坐下后用掉回城骨，回到那堆火，个数少一个，灵魂和余烬不变。
- [ ] 卷剑碎片同样送回，个数不减少。
- [ ] 头目血条已经出现时，用回城骨或卷剑碎片，人留在场内。

## 余烬与暗印

快捷栏切到这一件再用。更枯外形还没有，这里不看变枯。

- [ ] 用余烬后上限按 0.3 变长并补到顶。
- [ ] 灵魂大于 0 时用暗印送回，灵魂变成 0。

## 持续治疗

左手换成护符，上方向键换到这一份再放。这三份每次持续 10 秒，只给这场。

- [ ] 补充、丰饶之光按每秒 5 和 7 加生命，且不超过上限。
- [ ] 丰饶阳光放不出，并耸肩。

## 架势

右手切到第 4 格架势剑。霜剑留着对照。

- [ ] 切到架势剑，战技键先停住，轻击和重击走出两段，再按一次收回。霜剑的战技键仍弹反。

## 成对

右手切到第 5 格成对剑。霜剑和左手盾留着对照。

- [ ] 成对剑的连段走双手片段。另一只手是真盾时举不起来。霜剑仍单手，真盾仍能举起。

## 挥击霸体

右手第 3 格是双手斧，进攻霸体 75。霜剑是 1。

- [ ] 切到双手斧，挥击窗口里挨普通攻击继续且生命仍掉。窗口里这一点被打空，或离开窗口后再挨，改播受击。

## 头目

层级里叫 `Boss`，血条名字是「头目」。原来的近战留着对照。走进雾门开战。`End Camp Fire` 开局封着。换阶段若报缺特效，先记下，不挡这条。

- [ ] 开战出现带名字的长血条。血量是当前生命除以上限。
- [ ] 把头目拉出活动范围，它不因此回满。原来的近战拉出活动范围会回满。
- [ ] 战斗进行时走不回雾门外面。头目死后雾门关掉，再走进去不会重新开战，`End Camp Fire` 可以点。
- [ ] 头目生命降到一半后播换阶段。连段仍是原来的。
- [ ] 这场血条上限是单人的 1.5 倍。去掉 `allyJoined` 再开，上限缩回。
