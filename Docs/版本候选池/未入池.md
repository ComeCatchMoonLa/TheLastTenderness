# 未入池

下面这些看起来像可选版本，但不进 [README.md](README.md) 里按六个开关分开的那些文件。

原因是行为没定：需求和调研对不上、标了待核对或待补、两份文档互相打架，或这一字段在两边都没有。这里不写质量、完整度和工时，也不替它们选公式。

脚本里已经做到、因此根本不是候选的，列在文末，方便核对完整度分母。那些不是「没定」，只是不再排期。

## 翻滚、后撤、跳跃在精力介于零和花费之间

- 名称：精力大于 0 但不够支付翻滚、后撤或跳跃时，动作出不出、精力降到多少
- 缺哪条证据：[`精力.md`](../需求文档/功能需求/精力.md) FR-精力-06 和 [`玩家移动与闪避.md`](../需求文档/功能需求/玩家移动与闪避.md) FR-移动-06 写仍播放，精力降到 0 以下，最低 -60。[`移动与镜头.md`](../调研文档/移动与镜头.md)「精力不够时」写同一条。同一篇「四向翻滚」仍写往往会做出来并把精力打到空，并写是否对所有档位成立，待核对。轻击和重击已经按前一条入池，这里只剩这三下
- 对应文档路径：`Docs/需求文档/功能需求/精力.md`；`Docs/需求文档/功能需求/玩家移动与闪避.md`；`Docs/调研文档/移动与镜头.md`
