# 池-其余

这些条目不进前面四份。四条的定义与 [`池-不用人看-非高风险-过线.md`](池-不用人看-非高风险-过线.md) 开头相同。A 是不引入美术，B 是不引入过多人工，C 是非高风险，D 是质量大于 2% 或完整度达到约 1%。过线的完整度按一条玩家会走到的编号记 1%。行为没定的在 [`未入池.md`](未入池.md)，不在这里再选公式。

前面四份：

| 文件 | 为什么在那里 |
| --- | --- |
| [不用人看、非高风险、过线](池-不用人看-非高风险-过线.md) | Edit Mode 能断言，不是高风险，质量大于 2% 或完整度约 1% |
| [不用人看、非高风险、不过线](池-不用人看-非高风险-不过线.md) | Edit Mode 能断言，不是高风险，质量和完整度都不过线 |
| [不用人看、高风险、不过线](池-不用人看-高风险-不过线.md) | Edit Mode 能断言，但是高风险，质量和完整度都不过线 |
| [要人看、高风险、不过线](池-要人看-高风险-不过线.md) | 要进游戏看，而且高风险，质量和完整度都不过线 |

按进不了这四份的原因分成三份，一共 108 条。

| 文件 | 条数 | 为什么在这里 |
| --- | --- | --- |
| [引进美术](池-其余-引进美术.md) | 14 | 要新动画或新模型 |
| [要人看并且高风险、同时质量或完整度过线](池-其余-要人看.md) | 82 | 要进游戏看，也属于高风险，质量或完整度过线 |
| [不用人看但高风险并且过线](池-其余-不用人看.md) | 12 | Edit Mode 能断言，但是高风险，并且质量或完整度过线 |

走、翻滚、头目、异常、篝火、装备这些玩家会走到的条目大多在第二份，因为它们要进游戏看，也属于高风险，完整度记了约 1%。第二份再按六条规则拆开，一份不超过 30 条，见 [`池-其余-要人看.md`](池-其余-要人看.md)。

要人看画面但并不高风险的，也归本索引下的池-其余；现在没有这种条目。

质量算法与 [`池-不用人看-非高风险-过线.md`](池-不用人看-非高风险-过线.md) 末尾相同。玩法候选对不上那八组缺口时，代码质量写 0。完整度分母约 129 条还没在当前路径上做到的可观察编号，一条记 1%，同一眼只记一次。写到 2% 的是同一候选里两眼都能单独看出来。工时超过大约一天的，条目里写了还要再切，但仍留在对应的那一份里。
