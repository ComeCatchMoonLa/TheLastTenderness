## 全都解锁

### 耐久下降并按档减伤

- 类型：add（2.x）
- 是否不引入美术：是，不新做耐久条贴图。战斗画面上不常驻耐久条。
- 是否不引入人工：是，掉到三成和掉到 0 后的伤害系数能断言。
- 是否非高风险：否，后面的伤害都乘这一档。系数写错后，已平衡的武器都会跟着错，不能只改一处调用。
- FR：[`装备与道具`](../../需求文档/功能需求/装备与道具.md) FR-装备-12
- 工时：Agent 4h+人工 0h
- 程序前置条件：无。
- 需求前置条件：无。低于三成约七成、到 0 约五成，未破休息修满、破了休息不修，FR-装备-12 已写。
- 做什么：武器和护甲扣耐久。低于上限三成时伤害或减伤为七成，到 0 为五成。未破时休息修满，破了休息不修。

### 创角外形

- 类型：new（2.x）
- 是否不引入美术：是，外形在已有分件里选，不新做蒙皮。
- 是否不引入人工：是，选中的模型编号能断言。
- 是否非高风险：否，后面的外观都建在这次交出的分件上，选错了很难拆。
- FR：[`角色养成`](../../需求文档/功能需求/角色养成.md) FR-养成-01
- 工时：Agent 2h+人工 4h
- 程序前置条件：无。
- 需求前置条件：无。创角结束后身上是选定的外形，FR-养成-01 已写。
- 做什么：结束后身上是选定的那一套已有分件。
- 已买的包或商店免费资源：玩家 `Model` 下已有分件，和护甲一样按名字开关。没有单独的蒙皮身体。
- 能不能先简单占位：能。外形在已有分件里选一套。不新做蒙皮。
- 推荐：简单占位。要验收的是选中的那套分件。
