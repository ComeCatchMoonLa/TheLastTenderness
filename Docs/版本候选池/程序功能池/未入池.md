# 未入池

下面这些看起来像可选版本，但不进 [README.md](README.md) 里按三个开关分开的那些文件。

原因是行为没定：需求和调研对不上、标了待核对或待补、两份文档互相打架，或这一字段在两边都没有。这里不写工时，也不替它们选公式。

每条在「名称」前用「类型」标信息状态。调研正文里的 **待核对** 就是信息待验证，不在这里再抄一遍。下面只收会挡住排期的条目。

| 类型 | 什么时候标 |
| --- | --- |
| 信息待补充 | 这个可观察结果还没有写成可以照着做的句子，也没有一条待核对的数字 |
| 信息待统一 | 两处都写成了确定结果，两句不一样。一处已写死、另一处仍把相反结果留在待核对里，也标这一类 |
| 信息待验证 | 只标了待核对，或只留下约数、未核的名单，没有第二句相反的确定结果 |

脚本里已经做到、因此根本不是候选的，列在文末，方便核对哪些编号已经做到。那些不是「没定」，只是不再排期。
