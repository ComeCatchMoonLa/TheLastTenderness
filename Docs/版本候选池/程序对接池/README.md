# 程序对接池

> **这里是程序以外的活。** 只有代码时，游戏玩不起来。Play 回归在 [回归测试](../回归测试/README.md)，不是这里。

对照 [`程序工作流解耦指导`](../../程序工作流解耦指导/README.md)。结算和新动词留在代码里。

[需求.md](需求.md) 是 M6 的交接：策划打原作，写成同一句，写回需求和调研。要敲定的条目在 [待核对总表](../../调研文档/待核对总表.md) 里「挡住当前或近期排期」的那一列，不在需求.md 里再抄一份。写回之后的实现留在 [未入池](../程序功能池/未入池.md)，由程序排。策划和程序都做完，这条才离开 M6。

数值到文案这八个文件交在资产、场景和界面上。M8 等的是这八类。

| 文件 | 内容 |
| --- | --- |
| [需求.md](需求.md) | 策划先写回，程序再实现。条目见待核对总表里挡住排期的那一列 |
| [数值.md](数值.md) | 游戏要能玩，策划要交的数、引用、曲线和表 |
| [关卡.md](关卡.md) | 游戏要能玩，关卡要交的点位和顺序 |
| [界面.md](界面.md) | 控件树、样式、字体、图标 |
| [模型.md](模型.md) | 角色、武器、机关、场景的模型和材质 |
| [特效与灯光.md](特效与灯光.md) | 粒子、武器光、灯和后处理 |
| [动画.md](动画.md) | 片段、状态机、动画事件时间点 |
| [声音.md](声音.md) | 要挂上的声音片段 |
| [文案.md](文案.md) | 台词、物品名、界面句子 |

公式还没定的不在这里填，见 [未入池.md](../程序功能池/未入池.md)。需求.md 不另列条目，写回后的实现也在未入池。
