# 关卡

> **游戏要能玩，点位和顺序交在场景里。** [测试搭建.md](../回归测试/测试搭建.md) 那条短路只给回归走。正式区域另摆。不给某一段路新写结算。

已经能摆的动词：坐下休息、开门、幻影墙、电梯、梯子、开箱、拾取、结局标记、下一周的火、近战发现和回家。死亡残留还不能摆，见 [未入池](../程序功能池/未入池.md)「死后怎么重新能走」。

## 一条能玩的路径

| 要有的 | 交什么 |
| --- | --- |
| 出生和篝火 | 人从哪出现，哪一堆火是上次坐下的火 |
| 门和钥匙 | 钥匙放在哪一段，门挡住哪一段。背面走得到的门要标出来 |
| 幻影墙、梯子、电梯 | 撞墙的翻滚路线、梯子的层、电梯两个落点 |
| 箱子 | 哪一只只给一次，给哪一件已有物品 |
| 敌人 | 每只的放置点、活动范围、这场允许多远的追击 |
| 结局 | 结局标记，以及勾了下一周的那堆火。这堆火和普通休息火分开 |

顺序由这些点串起来。开门、爬梯、坐下本身不再改。

## 预制体在，可玩场景里没有

放进会加载的场景才算交了。只留在预制体里，Play 走不到。

| 预制体 | 要摆的 |
| --- | --- |
| `Prefabs/Future/World` | 雾门、Boss 血条、开战区域 |
| `Prefabs/Future/Online Marks` | 留言和血渍的点 |
| `Default Story NPC` | 剧情 NPC 的站位 |

## 摆了也还不能玩

这些没有从场景进得去的入口。先摆 NPC 或招牌不会变成能玩。

- 防火女加点。对话没有调用加点。
- 分瓶、交物品、商人、交书、铁匠、王座换魂、交灰烬。
- 协助召唤。
- 留言和血渍的显示开关。点可以先摆，在线时出不出现还没有调用入口。
