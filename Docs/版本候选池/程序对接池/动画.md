# 动画

> **片段、状态机和事件时间点交在动画资产上。** 代码只设已经有的参数。位移由代码驱动，正式片段不要再用根运动推位置。

控制器是 `Humanoid.controller`。攻击判定的时间点加在剪辑的动画事件上，事件名用现有名单。

## 已经在控制器里、要换成正式片段的

走、跑、冲、跳、翻滚、后撤、下落、落地、轻击、重击、受击、格挡、`Guard_Break`、背刺、处决、死亡、拉弓 `Aiming`、`Shoot Arrow`、施法、治疗、开箱、`Talk_01`、`Talk_02`。

落地和对地的时间窗、攻击霸体窗口，加在新片段上，不改结算。
