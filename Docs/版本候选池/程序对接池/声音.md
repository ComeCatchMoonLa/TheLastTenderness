# 声音

> **片段、音量和音高交在挂好的声音槽上。** 同一种时机里换片段不改结算。新的时机才要新的代码事件。

| 时机 | 现在的槽 | 要交的 |
| --- | --- | --- |
| 武器挥击 | 武器上的 `weaponWhooshesSound` | 每把武器的挥击。可以多条，播放时避开刚播过的一条 |
| 受击 | 角色上的 `takingDamageSounds` | 受击 |
| 篝火休息 | 篝火上的 `campFireActivationSFX` | 正式篝火声。换片段时换这处引用 |
| 脚步、格挡、弹反、踢击、开门、开箱、界面点击 | 没有单独的槽，或还是测试片段 | 有对应时机后再挂。没有片段就不要用一条无声把流程当成已经有声音 |
| 区域音乐 | `World` 预制体上的 `World BGM` | 正式区域的音乐。这场还没放进可玩场景 |

盾被打破、坠落落地这类还没有单独声音时机的，先不要做一批无人播放的片段。要新时机时再登记。
