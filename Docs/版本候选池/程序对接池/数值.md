# 数值

> **游戏要能玩，这些数、引用和表必须交在资产上。** 回归场用的数在 [测试搭建.md](../回归测试/测试搭建.md)，那一份不是这张表。没定的公式不要填假数。

## 角色

| 要交的 | 交在哪 | 现在 |
| --- | --- | --- |
| 走、跑、冲的速度，以及走路摇杆门槛 | 玩家预制体 | 只有测试场的 2、5、7 和门槛 0.4 |
| 冲刺的精力消耗和最低精力 | 同一处 | 有测试值 |
| 血、蓝、精力的上限和回复 | 角色数据 | 够测试场打一场 |
| 瓶的回复量和各档次数 | `Flask Recovery Table`、`Estus Flask` | 有表，不是正式曲线 |
| 弹反能接上的帧数 | 角色上的 `parryWindowFrames` | 现在是 0，进游戏报未填。正式帧数没定，测试场可以先填正数 |

负重会不会改变走路速度，还没定，不要在这里加一档速度。

## 武器和弹药

每把要玩的武器交：伤害、耐力消耗、硬直、用哪套已有攻击动作。弓的弹药另交快射伤害、拉满伤害、拉满要按住多久。

`Arrow` 现在只有快射伤害 50。拉满时间和拉满伤害是空的。弩、大弓、螺栓、大箭还没有各自的武器数据和弹药数据。

## 防具

每一件交各属性吸收。玩家要能看出换装前后吸收不同，至少两件吸收不一样。

四件怎么合成成状态页上的总吸收，还没定。不要在某一件上写一个「总吸收」冒充合成结果。

## 消耗品和钥匙

| 物品 | 现在 |
| --- | --- |
| `Key` | 有资产。门引用这一件 |
| 瓶、火炸弹 | 有资产 |
| 回城骨 | 没有物品资产。代码有，包里放不进去 |
| 卷剑碎片 | 没有物品资产。拾取不增量、使用不减量的规则在代码里 |
| 余烬 | 没有物品资产。生命上限变长的规则在代码里 |
| 暗印 | 没有物品资产。没有枯萎外形时，这一件即使用了也看不出变枯 |

## 敌人

每一只会进关卡的敌人交：用哪份角色数据、哪套行为、发现距离、活动半径、回家距离、会不会举盾。近战测试用的是 `Humanoid A.I Settings - Melee`（发现 30、仇恨 5、活动 15、回家 1）。弓手、Boss、简单 AI 各有一份设置，还没有正式遭遇在用。

## 机关

篝火交敌对半径，现在测试用 8。梯子交爬升速度。电梯交两处位置和移动时间。这些数跟着正式路的长度改，不继续沿用测试场为了走得完而设的值。

## 还不能填

| 缺的 | 原因 |
| --- | --- |
| 升级花费随等级怎么涨 | 曲线没定 |
| 坠落扣多少血 | 公式没定 |
| 双手攻击力怎么取整 | 取整没定 |
| 掉落表、商店价 | 没有正式表。不要填一行假数据 |
| 戒指改负重、治疗、翻滚、施法、处决 | 这些结算还没接到戒指上。表填了也不会变 |

戒指数值、商店和掉落要等对应结算进了代码，再按这张表交。
