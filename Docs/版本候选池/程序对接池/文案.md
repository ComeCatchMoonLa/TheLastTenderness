# 文案

> **玩家能看见的句子交在文案资产上。** 代码按已经有的条目取句子。新的一种副作用才加命令，不在句子里写结算。

## 台词

| 现在 | 要交的 |
| --- | --- |
| `Talk TextData Test 1`、`Talk TextData Test 2` | 正式台词和选项。测试句可以留在回归场 |
| 说话人名字 | 正式名字。空着的必填台词，进入那段对白前停住 |

可选闲聊可以没有，没有就不播。

## 物品和提示

| 现在 | 要交的 |
| --- | --- |
| 物品上的 `itemName`，例如箭是「箭」 | 正式物品名和说明 |
| 箱子交互提示「打开」 | 正式交互句 |
| `PlayerDeath 0`、`PlayerDeath 1` | 正式死亡提示 |
| 界面上的英文标签（状态、吸收、设置） | 正式界面句子 |

句子按条目取。不要在代码里把「获得」和数量拼成一句。本地化只换这一条的译文，不改分支。

## 还没有句子的

防火女、商人、铁匠、王座、交书、交灰烬没有正式台词。这些入口也还没接到对话上，见 [关卡.md](关卡.md)。句子可以先写，没有入口时玩家看不到。
