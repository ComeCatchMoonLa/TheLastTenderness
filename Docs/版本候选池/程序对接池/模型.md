# 模型

> **角色、武器、机关和场景的网格、贴图、材质交在资产上。** 一个占位是一个几何体，不把多个几何体拼成模型。换网格不改结算。

玩法要读的外观（受击闪白、溶解）放在材质已有的属性名上。新模型按所在目录的导入设置进来，不逐个改缩放和压缩。

## 角色

| 现在 | 要交的 |
| --- | --- |
| 玩家 `Model` 下已有分件，按名字开关 | 正式身体。创角和改造各选一套已有分件，或换成正式外形 |
| 近战、弓手是人形占位或胶囊 | 对应敌人模型 |
| 野兽用胶囊体 | 野兽模型 |
| 离线枪兵用胶囊体 | 枪兵模型 |
| 拟态是箱子加一只近战 | 拟态模型 |
| 没有更枯的一套外形 | 带着暗印变空虚要等这套。换装不能代替 |

## 武器和物品

| 现在 | 要交的 |
| --- | --- |
| 一批免费剑、弓、箭、盾、火把式武器网格 | 正式武器。颜色不同的剑不是不同武器的终稿 |
| 钥匙没有自己的模型 | 钥匙模型。开门仍认 `Key` 这件物品 |
| 弩、大弓、螺栓、大箭各还是几何体或没有 | 对应模型和弹药 |
| 状态弹是球体 | 正式弹 |
| 回城骨、卷剑碎片、余烬、暗印没有物品外形 | 有物品资产之后再挂模型。资产本身见 [数值.md](数值.md) |

## 机关和场景

| 现在 | 要交的 |
| --- | --- |
| 门是立方体 | 门的模型和材质 |
| 电梯是一块平台 | 电梯模型 |
| 梯子、箱子、篝火是测试用的网格 | 正式梯子、箱子、篝火 |
| 幻影墙是一块墙 | 正式墙。撞开后隐藏的仍是这块的碰撞和模型 |
| 留言和血渍各一个几何体 | 地面上的留言和血渍 |
| `Floor`、`Wall1` 到 `Wall4` | 正式地形。这些方块只属于回归场 |
