# 特效与灯光

> **粒子、武器光、灯和后处理交在资产和场景里。** 代码只在已有时机打开、关掉，或写入已经约定的强度、颜色、位置。

## 特效

| 现在 | 要交的 |
| --- | --- |
| 附魔共用火剑上的 `FX_Sword_Fire` | 每种附魔自己的武器光。结束时间仍由代码关 |
| `FX_Sword_Trails` | 正式挥击拖尾 |
| `BloodSplat_FX` | 正式命中 |
| `Fireball_Projectile`、`Fireball_Impact`、`Fireball_Warm_Up`、`FX_Explosion` | 正式火球和爆炸 |
| 篝火、休息若仍是测试粒子 | 正式粒子 |
| 自己的灵魂残留没有物体 | 死亡点上一团带绿色的血光。等 [未入池](../程序功能池/未入池.md)「死后怎么重新能走」定了再交。在线留言旁的血渍是另一件，见 [模型.md](模型.md) |

没有对应特效时，这一下就不显示。不要在玩法代码里搭一套粒子代替。

## 灯光和后处理

`Game` 里现在有一盏 `Directional Light`，只够看清回归场的方块。正式区域的灯、体积和后处理放在该场景里。代码不写灯的位置和颜色。
