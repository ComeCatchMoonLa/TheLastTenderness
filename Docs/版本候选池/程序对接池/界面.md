# 界面

> **控件树、位置、样式、字体和图标交在界面预制体上。** 代码按已经接好的引用读写。同一块继续用 uGUI，不在代码里再搭一层。

主界面是 `Assets/Prefabs/UI/Global UI/Global UI.prefab`，放在场景根上。

## 已经在用、还是测试样式的

档：M9。

| 窗口 | 要换成 |
| --- | --- |
| `HUD Windows` | 正式的血、蓝、精力条和数字 |
| `LockMark` | 正式锁定图。现在是一块文字 |
| `Inventory Window`、`Equipment Window`、`Item Stats Window` | 正式背包和装备比较 |
| `Status Window`、`Player Stats Window` | 正式状态页 |
| `Esc Window` | 正式暂停。里面要能进背包、状态、姿态，不加点入口留在代码里 |
| `Talk Window` | 正式对话，含说话人名字和正文 |
| `Interact Window` | 正式交互提示 |
| `View Info Window` | 正式获得和死亡提示 |
| `Display Window` | 正式弹出信息 |

设置、按键、音量、统计、成就这些窗口已经在同一棵树上（`Settings Window`、`Control Window`、`Sound Window`、`Game Settings Window`、`Statistical Window`、`Achievement Window`）。要玩到它们，就换成正式布局；不玩到的可以先留着，不要为了统一再抄一套。

字体换成正式字体。缺字体时停住，不退回另一套把字显示出来。档：M9。

## 场景里的界面

头顶短血条挂在角色身上，跟着人走。样式换成正式的是 M9。`World Canvas` 的绘制模式是屏幕空间，只是还挂在 `World` 上，不是场景里的牌子。头目长条并进 `Global UI` 之前，它留在这棵上；并进去排在 M5，样式是 M9。
