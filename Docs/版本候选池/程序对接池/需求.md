# 需求

> **M7 先敲定，再实现。策划和程序都要参加。** 策划打原作，把挡住排期的待实机写成同一句，写回需求和调研。写回之后，程序按那一句实现。写回之前没有版本，程序不开工。

要敲定的就是 [待核对总表](../../调研文档/待核对总表.md) 里「挡住当前或近期排期」的那一列。程序侧对不上的证据、写回哪一份文档，在 [未入池](../程序功能池/未入池.md)。写回之后，实现从那里再排进版本。

这一列不在这里再抄一份。总表里不挡近期排期的、资产位、联机和长线，留在总表自己的分类里。同名戒指各档不能同戴，调研和 FR-注入-07 已经是同一句。双手槽位、攻击离帧、`guardBreakM`、成就解锁、画质和镜头速度，到对应版本再拍板，见未入池「实现选择」。
