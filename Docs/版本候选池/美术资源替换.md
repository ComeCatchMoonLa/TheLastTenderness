# 美术资源替换

> **占位先能玩。** 换资源时只换这一张表里的外观，不改结算。候选池里的开关不因为换了外观再改回去。

## 已经写进开发计划

| 版本 | 现在用的 | 以后换成 |
| --- | --- | --- |
| 2.78 打开的门休息后仍开着 | 一个立方体绕竖轴转 90 度 | 门的模型和开门动画 |
| 2.79 有钥匙才打得开的门 | 同一块方块。钥匙用一件已有物品，不新做钥匙模型 | 钥匙模型。门的外观跟 2.78 |

## 一个几何体

不把多个几何体拼成一个模型。

| 版本 | 现在用的 | 以后换成 |
| --- | --- | --- |
| 留言和别人的血渍只在在线时出现 | 留言和血渍各一个 Unity 自带几何体 | 地面上的留言和血渍 |
| 野兽不进入背刺动画 | 一只胶囊体，标成野兽 | 野兽模型 |
| 状态弹推进对应的槽 | 一个球体当弹 | 元素弹模型 |
| 弩和螺栓、大弓和大箭各用各的 | 弩、大弓、螺栓、大箭各一个几何体 | 对应的武器和弹药模型 |
| 离线时教堂枪兵由本地角色顶上 | 一个胶囊体当这场的本地对手 | 枪兵模型 |
| 电梯可以再拉一次 | 一个几何体当平台，脚本移到另一层再移回来 | 电梯模型和拉杆动画 |

## 现成动作，不新做动画

| 版本 | 现在用的 | 以后换成 |
| --- | --- | --- |
| 弓的拉满和快射能分辨 | 现有 `Shoot Arrow`。两档只差伤害 | 拉满和快射两段动画 |
| 踢击崩开举盾 | 一段现有攻击打中举盾，接到已有的 `Guard_Break` | 踢击动画 |
| 架势的两段派生和收招 | 姿势先停住。两段派生用现有轻击和重击 | 架势、轻派生、重派生 |
| 成对武器打出双持连段 | 现有单手连段。只有标成成对才走 | 双持连段 |
| 只列出已经解锁的姿态 | 点一条播已有的 `Talk_01` | 各条姿态动画 |
| 挥击中段的攻击霸体 | 现有攻击片段上加已有的霸体事件 | 不必换。窗口仍加在正式攻击片段上 |
| 拟态打开会咬，打中会站起来 | 现成开箱，加上一只现有近战 | 拟态模型和啃咬动画 |
| 登梯、滑下和向外跳 | 沿梯子上、更快地下、再向外侧进入已有下落 | 爬、滑、向外跳的动画 |

## 已有的角色和特效

| 版本 | 现在用的 | 以后换成 |
| --- | --- | --- |
| 创角交出外形和赠礼 | 玩家 `Model` 下已有分件，按名字开关。界面用现有 uGUI 和已经在用的免费界面包 | 正式的创角身体和创角界面 |
| 改造只改外形 | 在创角那套之外再换一套已有分件 | 正式的改造外形 |
| 武器附魔会在一段时间后结束 | 火剑上的 `FX_Sword_Fire`。附魔期间开着，时间到或换武器关掉 | 各附魔自己的武器光 |

## 先不换

带着暗印死亡会加深空虚没有占位。`Model` 下的分件是换装，不是更枯的一套。有了枯萎外形再做这一条。
