# 试玩流程

> **在 `Game` 里走一条短路，把已经收尾、而且 Play 里真会被调用的功能串起来。** 不新写代码，不开创角。摆完是场景和资产改动，不是一版。

构建里只有 `Assets/Scenes/Game.unity`。现在开着的是 `Test Map - Interacte`。不要打开 `World`。雾门、开战和头目血条都在那棵下面，打开它会把没准备好的一场头目一起放出来。

## 先填这些数

空着或是 0 时，对应功能会报错并停住，或者根本不发生。

| 填在哪 | 字段 | 填什么 |
| --- | --- | --- |
| `Assets/Data/A.I/AI Settings/Humanoid A.I Settings - Melee.asset` | `returnArrive` | 大于 0，例如 `1`。近战预制体用的就是这份设置 |
| 同一份 | `activityRadius` | 大于 0 且小于已有的 `detectionRadius`（现在是 30），例如 `15` |
| 玩家上的 `PlayerLocomotionManager` | `walkSpeed` | 小于 `runSpeed`。`runSpeed` 现在是 5，走路可填 `2` |
| 同一处 | `walkUntil` | 大于 0 且小于 1，例如 `0.4`。摇杆幅度不超过它就走路 |
| 近战的 `CharacterCombatManager` | `parryWindowFrames` | 大于 0 的整数，例如 `8`。具体多少帧仍在未入池，这里只为了窗口不是空的 |
| HUD 上 | `lockMark` | 放一张已有的 `Image`，赋给 `HUDWindowsManager.lockMark`。不新做贴图 |

现有那堆 `Camp Fire` 的 `hostileRadius` 已经是 8，`hasBeenActived` 已勾上。敌人要放在这 8 米外面，否则追过来时坐不下去。

这堆火的 `nextCycleInsteadOfRest` 现在是勾着的。先取消，把它当作日常休息的火。另复制一堆放到远处，只在复制体上勾 `nextCycleInsteadOfRest`，专用来进下一周。

## 再摆这些

都放在 `Test Map - Interacte` 下面。能交互的物体：层与现有 `Door` 相同，标签 `Interactable`。

从 `Assets/Prefabs/Humanoid A.I - Melee.prefab` 拖一只到休息火 8 米外。这只身上已经有 `Talk`，靠近会提示「对话」，播的是两段测试台词，没有加点。

| 物体 | 怎么做 |
| --- | --- |
| 钥匙 | 复制一个拾取物，`PickUpItem.item` 指到 `Assets/Data/Items/Key.asset`。现有 `Door` 的 `key` 已经指着这一件 |
| 第二堆火 | 复制 `Camp Fire`，取消日常火上的下一周勾，只给这一堆勾上 |
| 幻影墙 | 一个立方体，碰撞体不要勾触发器，挂 `IllusionWall` |
| 电梯 | 一个立方体，挂 `ElevatorPlatform`。`home` 和 `away` 填两个不同的本地坐标 |
| 梯子 | 一个带碰撞的物体，挂 `LadderInteractable`。勾上 `bottomFilled`、`topFilled`、`climbSpeedFilled`，例如底 `0`、顶 `4`、速度 `2` |
| 已有的箱子、门、结局标记 | 不用新做。`Weapon Pick Up Item` 若是关着的，确认 `item` 有引用后再打开 |

## 走进去的顺序

1. 轻轻推摇杆是走路，推满是跑，按住冲刺更快。锁定近战，标记跟着它。
2. 轻击、重击、举盾。近战会举盾时，用踢把它打进崩架，再贴上去处决。背后贴住按轻击是背刺。
3. 弹反窗口里弹开再处决。窗口外自己掉血。
4. 把近战拉出大约 15 米，它走回起点并补满。只拉出察觉距离、还没出 15 米时，它走回发现前的位置。
5. 在 8 米内追着时，休息火坐不下去。拉开之后坐下：自己回满，这只近战回到满血。
6. 从门的正面交互。背包里没有 `Key` 时打不开，捡起后再从正面打开。休息后再回来仍开着。背侧打不开。
7. 翻滚撞上幻影墙，墙消失，休息后再看仍是开的。
8. 拉一次电梯到另一处，再拉一次回来。
9. 靠近梯子交互。向上爬、按住闪避且摇杆向下滑到底、摇杆回中再按闪避向梯外落下。
10. 开一次箱子，再交互是空的。
11. 把自己打死。魂变成 0，死亡点有残留。捡起来魂加回去。没捡再死一次，地上只剩新的一笔。
12. 打开装备，光标停在另一件上时人还穿着旧的，确认后才换。暂停里能进背包、状态、姿态，没有加点。
13. 最后才碰终局。在 `EndingMarker` 上交互一次，再到勾了下一周的那堆火上交互。火要重新点，门关上，钥匙不在背包。

背包里如果已经有回城骨、卷剑碎片、余烬或弓，顺手用一次：回城骨少一个并回到上次坐下的火，卷剑碎片个数不变，余烬把血条拉长，弓按住久一点伤害更高。没有这些物品就跳过，不要为了它们新做菜单。
