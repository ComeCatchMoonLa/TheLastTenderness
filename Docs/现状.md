## 代码

[`../Assets/Scripts/`](../Assets/Scripts/) 约 142 个脚本，按文件夹分工：

| 文件夹 | 做什么 |
| --- | --- |
| `Character/Player` | 玩家移动、战斗、背包、输入 |
| `Character/NPC` | 敌人属性、战斗，以及 General / Humanoid / Boss 状态机 |
| `Items` | 物品、装备、消耗品、法术、攻击动作 |
| `Damage` | 伤害碰撞体 |
| `Animator` | Animator 状态回调（攻击、翻滚、跳跃等） |
| `UI` | 玩家 HUD、背包、装备、设置、对话 |
| `World` | 场景事件碰撞体 |
| `Camera` | 玩家相机 |
| `Sounds` | 声音播放 |
| `SomeData` | 设置、对话等少量数据脚本 |

配置资产在 [`../Assets/Data/`](../Assets/Data/)（物品、AI、文本）。状态机在 [`../Assets/Art/Animations/Animator Controllers & Masks/`](../Assets/Art/Animations/Animator%20Controllers%20%26%20Masks/)。项目自己搭的预制体在 [`../Assets/Perfabs/`](../Assets/Perfabs/)（物品、特效、敌人、地图）。`Perfabs/0 Resource` 和 `Perfabs/1 Old` 不进 git。
