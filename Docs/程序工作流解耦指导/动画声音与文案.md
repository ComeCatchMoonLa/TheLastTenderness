# 动画声音与文案

> 片段上的时间点、用哪条声音、台词怎么分支，放在动画、音频和文案能改的资产上。程序留下参数、事件名和闭合命令。

换脚步声、改一句台词、把攻击判定往前挪两帧，不应改结算代码。

## 对方改什么

- 动画：Animator Controller 里的状态、混合和过渡；剪辑上的动画事件时间点。Unity 手册把 Animator Controller 定义成片段和过渡组成的状态机资产。
- 声音：在哪个事件里用哪条片段、音量、音高随机、混音和闪避。玩法只在约定的时机发出事件 id。
- 文案：台词、选项、本地化字符串，以及在闭合命令名单里的舞台指令（给物品、设旗标、播一个已登记的声音事件）。

位移由动画根运动驱动，还是由代码驱动，合同里选定一种。不要根运动和代码各推一半位置。

## 程序留下的合同

### 动画

- 代码设置的是参数名（速度、攻击、受击），以及查询「现在是否在某个状态或某个时间窗」。状态机怎么连，在 Controller 上。
- 动画事件的合同是一份固定函数名。时间点在剪辑上。Unity 手册：事件调用同名函数，并可带 Float、Int、String 或对象引用。函数名不在剪辑上自由发明；剪辑上的名字必须落在这份名单里，否则进入使用该剪辑的玩法前拒绝，并报出剪辑名和事件名。
- 名单里的函数做结算或发出已登记的声音、特效事件。函数内部不写死「这一下用哪条片段」。

### 声音

- 玩法发出事件 id。选片段、音量、随机、总线和闪避在音频资产或中间件里。
- 新的一种时机（例如「盾被打破」）才登记新的事件 id。同一种时机里换片段、改音量，不改代码。
- 没有音频程序员时，也可以用引擎里的音频事件资产加同一条规则：代码只持有 id，不持有 `AudioClip`。

Audiokinetic 记录里，Blue Fang 的程序在音效提出新需求时，先让对方用 Wwise 里已有的手段试，再决定要不要写新代码。Inventorix 的记录写的是：混音和过渡在 Soundcaster 里试，不用为了一点音量让程序改硬编码再编译。Whisper of the House 的做法更窄：命名里带上集成所需的信息，少量事件覆盖大部分播放，音频线不改引擎里的玩法文件。这些是具体项目的做法，合同只取同一条边界：玩法不拥有片段和混音。不要求因此接入某一种中间件。

### 文案

Jon Manning 关于 Yarn Spinner 的记录把边界写清楚了：给作者的语言只回答「现在显示哪一句、哪条命令、哪个选项」。不加引号的文本就是一句台词，这样作者写的是剧本，不是第二门编程语言。台词和控制流分开之后，本地化只换字符串。占位句可以先写上，以后再换成终稿。

合同：

- 玩家能看见的句子放在字符串表，或放在这种受约束的文本里。代码按 id 取句子。
- 命令是一份闭合名单。文案只能调用已经登记的命令。新的一种副作用才加命令。
- 本地化换的是该 id 的译文。控制流、命令和分支条件不放进译文里改。
- 必填台词为空：进入该段对白前报出资产名和 id，然后停住。可选的闲聊可以没有，没有就表示不播。

```csharp
// 句子被代码拼出来，译文对不齐
label.text = "获得 " + itemName + " x" + count;

// 句子在表里，代码只填已约定的空位
label.text = table.Format("loot.gained", itemName, count);
```

## 空位

剪辑、音频片段、译文可以后到。程序先登记参数名、事件 id 和命令。

必填的控制器、必填的事件、必填的台词 id 空着时，进入该玩法前停住，并报出资产名和字段或 id。不要用一段无声、一句硬编码的占位英文或一个默认剪辑把流程跑完，还让校验当它已经完成。

## 做与不做

| 做 | 不做 |
| --- | --- |
| 状态和过渡放在 Animator Controller | 在代码里按时间硬切每一段剪辑 |
| 事件函数名用固定名单，时间点在剪辑上 | 在剪辑上随便写函数名；在代码里写「第 0.3 秒出伤」 |
| 玩法发出声音事件 id | 在玩法里 `Play` 指定片段，并写死音量和音高 |
| 台词按 id 取，命令来自闭合名单 | 把台词写死在代码里；用拼接造句子 |
| 译文只替换字符串 | 让译者改分支或改命令才能完成一种语言 |

## 何时仍要改代码

- 新的动画参数、新的时间窗查询、新的事件函数。加进名单，不在某一个剪辑上临时调用私有方法。
- 新的声音时机。先登记事件 id；片段之后再补，空着就按必填停住。
- 新的命令。例如对白第一次需要「打开一扇门」，先把命令做成可复用动词，再让文案调用。不要为这一句对白写一段只被它使用的代码。

根运动和代码驱动二选一要改，也是代码合同的改动，因为两处一起推位置会让手感无法只在剪辑上调。
