# 调研：《黑暗之魂 3》本体与两部 DLC

> **调研对象是《黑暗之魂 3》本体与两部 DLC 的可感知玩法系统。** 交付是玩家能操作、能看到结果的系统规则。本仓库脚本对照放在阅读顺序的最后。

玩法代码仍按角色上的多个 Manager、动画状态行为、物品动作资产来组织，实现走 `MonoBehaviour`、Animator 的 `StateMachineBehaviour`、`ScriptableObject`。打开工程用的编辑器以开发计划为准，是 Unity `6000.5.9f1`。
