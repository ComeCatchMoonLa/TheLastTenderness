# 世界与篝火

> **这篇写《黑暗之魂 3》本体，加上《艾雷德尔的灰烬》和《环印城》里，篝火、死亡、余烬和周目怎样改世界。** 关卡路线和剧情对白不写。数值停在分档和有无，对不上的标 **待核对**。

绿条称为精力，和 [`移动与镜头.md`](移动与镜头.md) 同一套叫法。蓝条是施法和战技用的专注。血瓶回生命，灰瓶回蓝。喝药的动作见 [`魔法与道具.md`](魔法与道具.md)。加点能加出什么见 [`角色与养成.md`](角色与养成.md)。人怎么被送进别人的世界见 [`角色交互与联机.md`](角色交互与联机.md)。

祭祀场是防火女和铁匠安德烈所在的主城。两部资料片的篝火、雾门、死亡和余烬走同一套规则，差别写在各自小节里。

## 篝火记住的是你坐下的那一次

> **重生点是上一次在篝火坐下的位置。从旁边走过、只站着看菜单素材，都不会改这条记录。**

游戏经常自动存档。中途退出再进来，人留在退出时的位置，不会被拉回篝火。死亡、暗印、回城骨、卷剑碎片才会把人送回「上次坐下」的那一堆火。

坐下成功的瞬间，这堆火写成重生点，并立刻做完休息结算。菜单里再选离开，只是站起来，结算不退回。

附近有还在敌对的人时，交互走不进坐下。人保持站立，回血、补药、重置、改重生点都不发生。白幽灵或入侵者还在这个世界里时，主人也坐不下去，要先让客人离开。客人不能坐主人的火来改自己世界的重生点。

## 点燃、名称和传送列表

> **传送列表只出现已经点燃的篝火。没点燃的名字不在表上，也选不中。**

未点燃的火第一次交互：火点着，角色随即坐下，休息结算照常发生，这处加入传送列表。以后再交互就是直接坐下。

每处火有自己的名字，挂在所属区域的名字下面。列表是文字，按区域分组，再列出该区域里点着的火。本体和两部资料片一旦有火点着，就各自成组出现在同一张表里。本文不抄这张表，也不写每处火在地图的哪一截。

主城、关卡中途、头目战后新长出来的火，点着之后都按同一份名单规则收入。有一处和主城结构相似的暗处场景，里面的火是另一处传送点，点燃状态和主城那堆火分开记。

至少要有可以互选的已点燃火，传送才有目的地。出发点自己也必须是已点燃、并且你正坐在上面。

拔出卷剑会单独熄灭祭祀场主篝火，见下一节。

## 篝火菜单与火边的人

> **坐下之后的菜单是传送、整理法术、储物箱、离开。升级在防火女的对话里，分瓶在铁匠安德烈那里，两人都在祭祀场火边。**

人一旦坐下，休息已经结算。菜单是结算之后才看的选项。

| 要做的事 | 入口 | 结果 |
| --- | --- | --- |
| 休息 | 在火前交互并坐下 | 生命回到当前上限，精力、蓝回满，血瓶和灰瓶补到当前分配的次数；普通敌人重置；重生点改成这堆火 |
| 整理法术 | 篝火菜单 | 记忆槽换成这次要带上场的法术 |
| 传送 | 篝火菜单 | 去另一处已点燃的火 |
| 储物箱 | 篝火菜单 | 存取物品。任意一堆火打开的是同一个箱子 |
| 离开 | 篝火菜单 | 站起来。坐下时已经做完的结算留着 |
| 升级 | 防火女的对话 | 花身上的灵魂升一级。她站在祭祀场主篝火旁边 |
| 分配血瓶和灰瓶 | 铁匠安德烈的对话 | 总次数不变，红与蓝重新切分。他在祭祀场 |
| 瓶碎片 | 交给祭祀场的铁匠安德烈 | 血瓶加灰瓶的总次数加一，最多十五口 |
| 未死人骨片 | 只有祭祀场主篝火，且身上带着骨片 | 烧掉后每一口的回复量提高一档，血瓶和灰瓶一起涨，最多十档。数字是固定值，见角色篇 |

祭祀场主篝火在打完结局、并且当时没有立刻进入下一周目时，还会多出「进入下一周目」。见「周目切换」。

### 休息结算的细则

坐下补的生命，以当前上限为准。余烬形态还在的话，上限是点过余烬的那一档，生命补到这一档的顶。余烬形态不在，就补到平常上限。坐下不会把余烬点燃，也不会把已经点着的余烬弄灭。

精力、蓝补满。血瓶和灰瓶的剩余次数补到这次分配的上限，次数为零也会被补回去。背包里别的一次性消耗品不补。

毒、猛毒、出血和冻伤的持续状态与累积，在坐下时清掉。诅咒的累积层数会不会一起清，**待核对**。

记忆里的法术本身不丢。蓝补满之后，这些法术又能按蓝的消耗再放。法术没有「休息前只能放三次、休息刷新次数」这种另计的次数。

身上的灵魂计数留在自己这里，不因休息减少。

敌人：普通敌人回到初始位置，生命回满，仇恨清掉，全图都这样，不只是这堆火旁边那一间。已经战败的头目不再出现，头目房保持打开后的状态。拟态怪打死之后不再出现。结晶蜥蜴打死之后本周目不再出现；它逃走、人没打死时，下一次能不能在原处再撞见，**待核对**。入侵型的 NPC 被击退后，本周目不再走进来。还有一部分单独放着的强敌打死也不刷新。完整的「谁不刷新」名单不当作地图来抄，边界 **待核对**。

还活着的头目：如果人在战斗中途跑回去坐下，或传送离开，这场战斗中的伤害作废，下次再进雾门，头目仍是满生命。

世界这边保持不动的：

- 已经打开的门、拉开的杠杆、放下的桥、踢下来的梯子、打穿的幻影墙、打坏的掩体
- 已经接通的短路
- 地上拾取过的道具，包括钥匙、武器、素材、要交给 NPC 的物件
- 已经打开并拿空的箱子
- NPC 谈过的进度、店货解锁
- 余烬形态的开或关（休息不改这一项）

敌人爆在地上、还没拾取的掉落，会跟着这只敌人被重置一起清掉。场景里原本就摆着的发光道具，没捡就一直在，捡过才从世界上消失。未拾取掉落是否在任何情况下都被休息清掉，**待核对**。

### 传送

只能从正坐着的火，传到另一处已经点燃的火。目的地包括主城、其他区域和两部资料片里点着的火。未点燃的火不在列表里。

坐下时的休息在读条之前已经发生，所以出发前敌人已经重置、药已经补满。落地之后，重生点记在出发前那堆火上，还是改记成落地的这堆火，**待核对**。死亡时回到哪一堆，能把这两记区分开。

### 整理法术

只有坐在火边能改记忆槽。记忆槽数量随集中力这项属性增加，有上限，门槛见 [`角色与养成.md`](角色与养成.md)。已获得的法术从列表放进空槽。一条法术占一个槽。有没有占两槽的例外，**待核对**。

属性不够的法术能否仍放进槽、上场时只是放不出来，**待核对**。战斗中途不能打开这份整理。

### 储物箱

任意已点燃篝火的菜单进的是同一个箱子。死亡不会清空。下一周目箱子里的装备和消耗品跟着角色走。钥匙放进箱子能不能躲过周目清除，**待核对**。

正在装备的东西要先卸下再存。暗印放不进箱子。还有哪些种类存不进去，**待核对**。格子数量很大。精确上限 **待核对**。灵魂计数不放进箱子，灵魂留在 HUD 那个数字上。

### 离开

离开使角色从坐下站起，可以走路。刚才那次休息的回血、补药、重置和重生点都还在。

### 升级从防火女进入

加点是防火女对话里的一项。她在祭祀场主篝火旁边，所以人经常在这堆火边上升级：先可以坐下休息，再转去和她说话。野外篝火那张菜单里没有加点。从别的火传送回祭祀场，再找她，进的是同一页加点。

这一页花的是身上的灵魂计数。确认一次，等级加一，花费随当前等级变高。灵魂够就可以连着加。具体成长见 [`角色与养成.md`](角色与养成.md)。

另有有限次的免费加点，每次在角色上留下一枚暗蚀刻印，并提高空洞。刻印数量是后面「窃火」旗标的条件。防火女可以再花一笔灵魂把刻印治愈掉，治愈之后窃火这条旗标不再成立。免费次数的上限和仪式还会再添几枚刻印，见「结局旗标」。地点和步骤不写。

重分配属性是另一个人的界面，次数按周目计算，见 [`角色交互与联机.md`](角色交互与联机.md)。篝火和防火女的加点页只能往上加。

### 血瓶次数和每一口的量

初始带着血瓶，三口。灰瓶要在祭祀场拿到瓶子本身，总次数变成四，其中一口在灰瓶上。瓶碎片交给祭祀场的铁匠安德烈，总次数加一，血加灰的上限到十五口。超过上限之后再交碎片，没有进一步的效果。分瓶也在安德烈，不在篝火菜单。

分配只是把现有总次数在血瓶和灰瓶之间搬。可以全部划给血瓶，也可以全部划给灰瓶。休息、死亡复活、被送回篝火时，补满的是这一轮分配，不会把曾经划走的次数悄悄改回。

未死人骨片只能在祭祀场主篝火烧掉。每烧一片，血瓶每一口回的生命和灰瓶每一口回的蓝一起提高一档，最多十档。回复是固定值，不按上限的百分比。表在 [`角色与养成.md`](角色与养成.md)。两部资料片不再把这套上限另做一版。

两次篝火之间，药也会少量回来：击倒敌人有机会补回一口或两口，瓶子越空、敌人越强，越容易看到。击倒入侵者会补回若干口，经常血瓶和灰瓶一起补，到不了坐下那种整组补满。概率和每次补几口，**待核对**。

武器、盾和护甲有耐久。战斗画面上没有一条常驻耐久条。还没破时，坐下休息会修满。掉到 0 之后休息修不好，铁匠安德烈菜单里的修理就是修这个。低于三成时攻击或减伤变成七成，到 0 时变成一半。

### 祭祀场主篝火和卷剑

这堆火要插着卷剑才维持点燃。剑拔出来握在手里，主篝火熄灭，传送列表里暂时没有它。剑再插回去，火重新点着，名字回到列表。其他已经点燃的火不靠这把剑，仍能休息和互相传送。剑卖掉、丢掉或不在背包里时，主火还能不能点，**待核对**。

## 死亡、血迹和复活

> **生命到 0 就死亡。身上的灵魂计数留在死亡处的血迹里，人在上一次坐下的篝火复活。再死一次，旧血迹连同里面的灵魂一起消失。**

死亡时操作停住，画面给出死亡提示。计数归零。若死前处于余烬形态，余烬熄灭。复活后的生命上限是没点余烬的那一档，并补到这一档的顶。精力、蓝回满。

血瓶和灰瓶补到当前分配的满次数，和坐下休息补药是同一条规则。死亡复活并不整段等于休息，差别在下表。

| | 坐下休息 | 死亡后复活 |
| --- | --- | --- |
| 生命 | 补到当前上限。余烬还在就补到余烬那一档 | 余烬熄灭，补到平常上限 |
| 精力、蓝 | 补满 | 补满 |
| 血瓶、灰瓶 | 补到当前分配 | 同样补到当前分配 |
| 灵魂计数 | 留在身上 | 掉在死亡点，计数清零 |
| 余烬 | 维持坐下前的开或关 | 熄灭 |
| 普通敌人 | 重置 | 重置 |
| 还活着的头目 | 若离开了战斗，下次仍是满生命 | 头目房里死掉，头目重置为满生命，雾门还在 |
| 重生点 | 改成刚坐下的这堆火 | 回到上次坐下的那堆火，不因为死亡改写 |
| 暗蚀刻印与空洞 | 休息不加深空洞 | 身上还有暗蚀刻印时，空洞加深 |
| 背包里的道具 | 留着 | 留着。没使用的灵魂道具、钥匙、素材不掉在地上 |

背包里的「灵魂道具」和 HUD 上的灵魂计数是两笔账。死亡只处理计数。道具没被使用，就还在包里，捡回来或以后再用都会把数字加进计数。

自己的血迹是死亡点上一团带绿色的血光，要走到跟前按拾取才拿回那一笔灵魂。拿到后计数加回。地上同时只留最近的一摊自己的灵魂血迹。还没去捡就再死一次：旧的那摊消失，里面的灵魂永久失去；新血迹只装着这一次死亡时身上的计数（中间没捞到、也没再赚到的话，就是空的或只有这一段新赚的）。

血迹落在死亡位置。坠亡或掉出可行走地面时，它可能停在捡不到的地方。会不会被挪到最近的地面，**待核对**。

有的戒指让死亡不交出灵魂，人身上的计数还在，也就没有可捡的灵魂血迹。还有的让已经落在地上的旧血迹多留一次机会。诅咒直接致死时，这些戒指是否仍生效，**待核对**。各枚戒指的差别不在这篇展开。

退出到标题再读档，人停在退出的位置。这次读档会不会把药补满、会不会重置敌人，**待核对**。它不等于在篝火坐下。

## 余烬

> **余烬是单独点上的形态。点燃后生命上限提高、条变长，并且这具身体可以被入侵、可以召唤帮手。坐下休息不自动点燃。死亡会熄灭。**

使用余烬道具：若当前不是余烬形态，进入余烬形态，生命上限提高一截并补到新上限。常见说法是大约提高到平常的一点三倍，精确比例 **待核对**。已经是余烬形态时再使用，上限不再加一截，生命仍补到余烬那一档的顶。魔法与道具仍把「只浪费还是拉回上限」留在待核对，见 [未入池](../版本候选池/程序功能池/未入池.md)「余烬已经点着时再使用」（信息待统一）。

余烬形态下能看见并使用协助召唤符号，也能被入侵。未点余烬时，协助符号不作为可召唤目标出现。入侵与匹配的条件见 [`角色交互与联机.md`](角色交互与联机.md)。

会点燃余烬的情况：

- 使用余烬道具
- 头目立下。战败结算时恢复余烬形态，并把生命补到余烬上限
- 作为被召唤的帮手，帮主人打完该区域头目并回到自己的世界。奖励细则见联机篇

不会点燃余烬的情况：

- 在篝火坐下
- 使用回城骨或卷剑碎片回到火边
- 使用暗印。暗印把人送回火边，余烬仍保持使用前的开或关

死亡一定会熄灭。复活后要再点道具、再打赢头目，或靠联机的那次返回，才会再进入余烬形态。

## 暗印、回城骨、卷剑碎片

> **三样都把人送回上次坐下的篝火。暗印无限次，并丢掉身上的灵魂计数，地上不留可以捡回的那一摊。回城骨和卷剑碎片留下灵魂，也留下余烬。**

开局道具里就有暗印，不能卖掉，不能放进储物箱。还没有任何一次坐下时，暗印改送到祭祀场主篝火。

| | 暗印 | 回城骨 | 卷剑碎片 |
| --- | --- | --- | --- |
| 次数 | 无限 | 消耗品，用一个少一个 | 无限。拾取一次后进后续周目仍留着，不叠第二份 |
| 去向 | 可选上次坐下的火或祭祀场主火；从未坐下则只去祭祀场主火 | 与暗印的去向相同 | 与回城骨相同 |
| 灵魂计数 | 全部失去，不生成可拾取的自己的血迹 | 保留 | 保留 |
| 余烬 | 保留 | 保留 | 保留 |
| 药与敌人 | 送回并重载。药按休息规则补满，普通敌人重置 | 同左 | 同左 |

使用时有一段驻足动作，这段里挨打会打断。头目战已经开始、雾门已经把人关在房里时，三样都放不出去。正在被入侵、或自己是别人世界里的客人时，哪些被禁、客人是否改用另一件离场道具，**待核对**。客人离场的道具见 [`角色交互与联机.md`](角色交互与联机.md)。

有一条祷告也是回到上次坐下的火，花蓝，灵魂和余烬都留着。施法条件见 [`魔法与道具.md`](魔法与道具.md)。

## 雾门、头目房和战后的火

> **雾门把人放进头目房，并把退路关上。头目战败后雾门散去。房内或紧挨出口通常能再点一堆火，点着才进入传送列表。**

雾门是堵在入口上的雾。交互后走过去。进去之后，这道雾从里面出不来，回城类道具也放不了。头目以满生命开始。中途死亡：人回到上次坐下的火，雾门还在，头目下次仍是满生命。中途离开再回来，同样是满生命。

多段头目在房内换阶段、换名字、换血条时，雾门保持关上，要整场结束才打开。阶段表现见 [`敌人与头目.md`](敌人与头目.md)。

战败后雾门撤掉，本周目不再出现。场地里常在这时多出一处尚未点燃的火，规则和路上的未点燃火一样：点了才能传送过去。也有头目不把新火安在房里，下一处火仍要自己去点。哪一位安在房里、哪一位安在门外，本文不列。

余烬形态下，帮手可以跟进雾门。入侵者是在穿门时被送走，还是能留在房里，**待核对**。帮手若没在时限内跟进会被送回，时限 **待核对**。

《艾雷德尔的灰烬》和《环印城》的头目雾门同一套。环印城里有一场头目，对手可以是另一名玩家，没有玩家时由本地角色顶上。雾门、血条和战后的火仍按头目房处理。人怎样被选进这场，见 [`角色交互与联机.md`](角色交互与联机.md)。

## 幻影墙、可破坏环境和箱子

> **幻影墙要打中或翻滚撞上才会开，开了本周目保持。箱子打开后空着。拟态在被当成箱子打开时会咬人，先打中则会站起来当敌人。**

### 幻影墙

墙看起来和旁边的墙一样，没有单独的「打开」提示。用攻击打中，或用翻滚撞上去，墙打开，后面的路或道具露出来。打开后的缺口在本周目保持，休息和死亡都不把它封上。

只有这个世界的主人能把它打开。召唤来的人打在同一面墙上，墙不会为客人裂开。两部资料片里的幻影墙同一规则。具体哪面墙是空的，不在这篇当路线写。

### 可破坏的东西

木箱、木桶、薄木板打坏就留着缺口，休息不复原。有的墙要很重的一下，或某只大型敌人的冲撞，才会永久打开，这是一次性的世界变化。打坏之后露出的道具按普通拾取处理，捡过就从世界上消失。

### 箱子和拟态

普通箱子：提示为打开，播一段开盖，拿走里面的东西，盖子保持开着，再交互没有第二次收获。

拟态外表接近普通箱子，链条的摆法和普通箱子不同。朝向口诀很容易记反，这篇不写口诀。

- 按打开：它进入啃咬，伤害很高，人被扣在动作里。咬完若还活着，它已经是可锁定的敌人。
- 先用攻击打中：它直接站起来进入战斗，啃咬那一下不先结算。头上是普通敌人的短血条。
- 猎人符丢在它身上：它瘫下一段时间，这段里的打开变成安全拾取，东西进包，不必打死它。
- 打死之后本周目不再出现，掉落按击杀结算。休息不把它变回箱子。

地上的箱子、道具和幻影墙属于这个世界的主人。客人打得了主人世界里的拟态，拿不走主人地上的装备。客人能否用猎人符让主人的拟态瘫下，**待核对**。

开盖被打中会不会把动作打断，见 [`界面与场景交互.md`](界面与场景交互.md)。

## 周目切换

> **等级、属性和身上的装备留下。火、门、敌人和钥匙按新的一周重来。人可以在结局之后先留在本周目，之后再从祭祀场主篝火进入下一周。**

终局结算的字幕走完，游戏询问要不要立刻进入下一周目。拒绝的话，人回到祭祀场，本周目还能继续逛，包括还没去的资料片。终局那一次交互已经消耗，本周目不能换另一条结局。之后在祭祀场主篝火选择进入下一周目，效果和当时立刻进入相同。

留下的：

- 等级和属性
- 武器、防具、戒指、已学会的法术、非钥匙的消耗品，以及它们的强化
- 血瓶和灰瓶的瓶子、总次数、分配、骨片强化等级
- 盟约职位和已经换到的盟约奖励
- 姿态
- 身上的灵魂计数，以及储物箱里的非钥匙物品
- 空洞的程度
- 卷剑碎片

清掉并在世界上重来的：

- 已经点燃的篝火。要重新点，传送列表跟着变空再一条条加回来
- 打开过的门、短路、幻影墙、踢下的梯子、破坏的掩体
- 头目战败。雾门回来，头目以满生命再战
- 普通敌人、拟态、结晶蜥蜴、入侵型 NPC
- 场景里的拾取物
- 钥匙。门重新锁上。钥匙类物品从背包拿掉
- 暗蚀刻印这份道具，以及会解锁某类商店货的灰、书卷一类钥匙物。有记载把个别骨头类道具算作例外，是否真的留下，**待核对**
- NPC 的任务进度。死过的人回到最初位置
- 结局改过的天色一类世界表现

空洞程度留下，刻印道具按钥匙物清掉。没有刻印之后，留下的空洞还改不改属性或外观，**待核对**。

每一周目敌人更难打，击杀掉的灵魂更多。部分戒指在更后的周目以更高一档出现在拾取点，已经拿过的低档仍在背包里。本文不写哪一枚换到哪一周、放在哪。难度加到某一周之后主要只剩数值，不再换新的戒指档。封顶是第几周，**待核对**。

## 结局只作为世界旗标

> **传火、灭火、窃火在终局那一次交互里互斥。旗标在交互之前就写在角色和世界上，提示文字可以和真正的结算不一致。**

终局区域本身要先满足一组旗标：若干指定头目已死，对应遗灰已经放到祭祀场的位置上。缺一则祭祀场主篝火不会多出前往终局的传送。是哪些头目、遗灰放在哪，不在这篇写。资料片头目不计入这组旗标，也不单独改变下面三条结局。

```text
终局交互
  窃火旗标已满           --> 结算为窃火
  否则，使用防火女的符
       （须已把眼交给她） --> 结算为灭火
         灭火进行中的短窗口里攻击她 --> 改由玩家接过火
  其余情况               --> 结算为传火
字幕之后
  立刻下一周目           --> 按「周目切换」重置世界，角色保留
  留下                   --> 回祭祀场，终局交互已消耗
```

### 传火

没有灭火所需的道具旗标，或者有符但没去用，并且窃火旗标未满：在终局火焰上交互，结算为传火。

### 灭火

先把一件「眼」交给防火女，旗标打开。终局火焰旁边才会出现她的召唤符。使用这张符，结算为灭火。眼从哪拿到，不写。

灭火的场面开始后有一小段可以攻击防火女。攻击成功则改成由玩家接过火。这条没有单独的结局成就，界面结果更接近传火那一侧。攻击窗口的长度 **待核对**。

### 窃火

旗标要靠暗蚀刻印叠到门槛，并完成会再加入刻印的那次仪式，且在终局之前没有让防火女治愈这些刻印。常见说法是门槛为八枚。精确数量 **待核对**。

旗标已满时，终局火焰上的提示文字仍可能写成传火。真正走进去的结算是窃火。提示字符串不等于旗标。

窃火旗标和灭火旗标同时成立时，同一次交互进哪一条，**待核对**。

## 两部资料片

《艾雷德尔的灰烬》和《环印城》进入之后，各自的篝火使用点燃、坐下、传送、死亡回到上次坐下的火这一套。点着的火出现在传送列表的独立分组。死亡、血迹、余烬、暗印、雾门、幻影墙、箱子和拟态不另写规则。

进资料片的那个物体，用的是场景交互，进门之后仍要自己点燃那里的第一堆火，才能从主城表里往返。物体在哪、怎么走到，不写。

环印城那场可由玩家顶上的头目，见「雾门」一节。匹配不在这篇。

- 坐下是否清掉诅咒的累积层数
- 结晶蜥蜴逃走后，再次出现要休息、传送还是重新进入区域
- 不刷新强敌的完整范围。已写明的是头目、打死的拟态、打死的结晶蜥蜴、被击退的入侵型 NPC
- 退出再读档会不会补药、会不会重置敌人
- 坠亡或掉出场景时，灵魂血迹停在死亡坐标，还是被挪到地面
- 保魂戒指在诅咒致死时是否仍生效
- 敌人未拾取的掉落，是否每次休息都清掉
- 传送落地后，重生点记在出发的火，还是落地的火
- 属性不够的法术能否放进记忆槽；有没有一条法术占两槽
- 储物箱的格子上限；暗印之外还有哪些放不进去；钥匙放进箱子能否躲过周目清除

- 穿雾门时入侵者是否被送走；帮手没跟上的时限
- 余烬提高生命上限的精确比例
- 猎人符能否由客人对主人世界的拟态使用
- 周目清除的例外道具是否存在；空洞程度在刻印道具被删后还改什么
- 周目难度在第几周封顶
- 窃火刻印的精确门槛
- 窃火与灭火旗标同时在场时，终局交互进哪条
- 灭火途中攻击防火女的窗口长度
