# 待核对总表

2026-10-08 对九篇调研正文里全部 **待核对** 做一次总盘点。目的不是把每一项都查到，而是先回答「这条对本项目需不需要核实」，再决定要不要查。

各篇正文仍保留行内 **待核对** 字样；本表是这些标记的总处置。行内标记与本表冲突时，以本表为准。

## 处置分四类

- **已核实**：外网文字资料足以定论，结论已写回正文。已核实项不在本表登记——结论以九篇正文为准，核实过程与来源见 git 历史。
- **资产位**：这不是一条系统常数，而是每件武器、每个敌人、每条法术、每个关卡自己的数值或名单。项目规则是数值、曲线、引用放在资产上（见 `.cursor/rules/authoring-boundary.md`），调研不替资产选值。这类标记保留「逐件不同」的描述即可，不需要外网核实，排期时由资产填。
- **待实机**：外网没有可靠文字、或文字互相冲突，只能在游戏内测一遍。其中挡住排期、需求和调研又必须一致的，进 [`../版本候选池/程序功能池/未入池.md`](../版本候选池/程序功能池/未入池.md)；不挡当前排期的留在正文行内。
- **联机/长线**：只在联机系统或周目循环批次才用得到，单机 MVP 不挡事，放到对应批次开始前再核。

## 一、判为「资产位」、不再作为系统待核对的项

## 二、判为「待实机」的项（外网无定论，按游戏内测）

挡住当前或近期排期的，已进 [`未入池.md`](../版本候选池/程序功能池/未入池.md)：

1. 精力为正但不足时，翻滚/后撤/跳跃是否一律打出、精力最低是否 −60、是否对轻中重所有档位成立（另含战技在精力不足而蓝够时放不放）。
2. 蓝够精力不够时法术放不放、失败起手扣不扣精力。
3. 施法前摇被打断（含护符霸体被打碎）时蓝扣不扣。
4. 武器不允许附魔时这一拍扣不扣蓝（松脂失败不消耗已核，法术附魔失败的蓝去向待测）。
5. 同一法术能否在记忆菜单重复记忆（NGA 相关截图属法环板块，不能作证）。
6. 瓶碎片交给安德烈后新一口是否立即进当前剩余；分瓶未休息时剩余是否重算。
7. 休息或重载后电梯停在离开层还是默认层（敌人篇「回初始位置」与界面篇「离开层」两处未合）。
8. 非致死掉落六项合成的具体公式、致死高度对应米数、落地攻击打中敌人时自己扣不扣掉落伤害。

不挡近期排期、留在正文行内即可的实机项：沉重翻滚 12 帧的 30fps 起帧逐帧直测（现按推算 2～13，四档翻滚候选按推算值排，见 FR-负重-05）、涂擦动作开始后被打断束缎退不退回、坐下是否清咒死层、结晶蜥蜴逃走后再现条件、退出读档是否补药/重置敌人、坠亡血迹是否挪到地面、保魂戒对咒死是否生效、未拾取掉落是否每次休息清空、传送落地后重生点记哪堆火、卷剑不在背包时主火能否点、雾门内入侵者与客人时限、推门/开箱被打断时世界状态怎么算、客人能否使用主人世界的若干交互、喝药能否翻滚取消与满血连喝、短索能否移动投掷、禁药时长、花朵时长、红眼宝珠与干燥手指是否每次消耗、别人世界喝掉的瓶数是否带回、装备中的物品能否直接卖、地上物品联机能否捡、毒抗是否减持续伤害。
