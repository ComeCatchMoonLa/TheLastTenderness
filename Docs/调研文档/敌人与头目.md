# 敌人与头目

> **普通敌人、精英、迷你头目和头目共用一套战斗语言：发现、追击、选招、霸体、硬直、死亡、掉落。** 差别写在每类实体配了哪些动作、血条怎么显示、死亡后会不会再出现。本体和两部 DLC（《艾雷德尔的灰烬》、《环印城》）都沿用这套语言。

本文按系统记玩家能看出来的结果。招式名字、站点顺序和剧情因果不展开。玩家自己的翻滚、弹反窗口和受击规则见 [`战斗系统.md`](战斗系统.md)。幻影、种子和盟约见 [`角色交互与联机.md`](角色交互与联机.md)。休息、余烬和周目循环见 [`世界与篝火.md`](世界与篝火.md)。

界面上能对上的资源沿用同一套称呼：生命、精力、蓝。敌人离开出生位置再被拉回来，记作**归位**。

## 放置上的四类

| 类别 | 玩家能看出来的差别 | 休息之后 |
| --- | --- | --- |
| 普通敌人 | 头顶短血条，走发现和归位 | 满血回到放置点 |
| 精英 | 仍是短血条，动作更重、血更厚；红眼是同一类的加强放置 | 与普通敌人相同 |
| 迷你头目与唯一敌人 | 有的有名字，多数没有雾门 | 一部分保持死亡，一部分照常刷新 |
| 头目 | 雾门、屏幕下方独立血条、名字 | 保持死亡 |

红眼只加强这一只的生命和攻击欲望，不改变它的刷新类别。

## 待机与巡逻

> **没发现玩家之前，敌人停在放置时的姿势里。** 这个姿势就是它的待机。

常见姿势：

- 站桩，朝一个固定方向。
- 沿一段路线来回走。走到端点会停一下再折返。
- 跪、坐、趴在地上装睡或装死。玩家靠近、出声或打中它，它才起身。
- 接在场景物件上，例如从墙里、天花板或尸体堆里伸出来。触发前没有可锁定的身体。

巡逻只覆盖它自己的那一段路。玩家站在路边、且还没进视野和听觉时，它会走完路线，不会提前改道过来。

同一片区域里可以同时有站桩和巡逻。组队时，往往一个人看见人，旁边还在走路的会一起停下来转向。这是发现时的同组连锁。专门的呼救动作在后面单独记。

## 发现

> **发现靠两件事：看不看得到，听不听得见。** 任何一件成立，敌人从待机进入战斗，转向玩家并开始接近或准备攻击。

视野是身前的一块扇形，有距离上限。背对玩家、中间有墙或厚掩体时，扇形被挡住，光站在旁边不会因为「人在附近」就发现。贴到很近时，不少敌人不再看朝向，身边这一圈直接进入战斗。扇形角度和距离按敌人配置，猎犬一类听觉更远。精确米数待核对。

听觉单独生效。这些动作会出声：

- 奔跑和冲刺，比走路响。
- 翻滚、攻击、举盾受击时的脚步和武器声。
- 施法、投掷、射击。
- 从高处落地。

走路可以穿过较远的听觉范围。降低脚步声的装备、降低身形显眼程度的法术，会把对应的那一项发现距离缩短。具体条目和数值在 [`魔法与道具.md`](魔法与道具.md)，这里只记它们改的是发现距离，不改已经进入战斗之后的追击。

敌人没有单独的警戒条。玩家用来判断的现象是：它喊一声、拔武器、或从巡逻收成朝向玩家的战斗姿态。

已经在战斗中的敌人会把发现传给附近同组的同伴，同伴从待机直接进入战斗。传的范围通常限于这一组的放置，不会把整张地图叫醒。专门的呼救动作把这个范围再拉开，见下文。

## 追击

发现之后敌人沿可行走的路径接近玩家。路径绕开墙和多数障碍。它会走进自己能走的门和坡，也会在追击中掉下没有栏杆的边缘。掉下去摔死，结算和普通死亡一样。

追击速度分档：有的一直走，有的发现后改跑，有的离得远时冲刺、贴到攻击距离就改成横着走。人形更常在中距离围着玩家绕，给自己的攻击或举盾留位置。野兽多半直线贴上来。

垂直方向不保证聪明。目标在高台上时，没配跳跃接近的敌人会挤在台子下面；配了攀爬、飞扑或远程的会换对应动作。飞行单位不沿地面路径走，见体型一节。

多名玩家在场时（主人、协助幻影，以及种子生效后的入侵者），敌人会换目标。没有一条给玩家看的仇恨数值。离它近、并且刚打中它的人，更容易被追。换目标发生在它这段动作做完之后，进行中的挥击仍朝原方向。

## 攻击选择

> **每只敌人只从自己配好的动作里挑。** 距离、玩家正在做什么、它自己的动作间隔，决定下一下是哪一招。

| 局面 | 配了相应动作时的常见选择 |
| --- | --- |
| 贴着身体 | 短连段、举盾、侧步或翻滚、抓取 |
| 一步之外 | 突进、冲刺砍、盾击 |
| 明显够不着 | 边靠近边进入下一段，或改远程和施法 |
| 玩家在喝药、使用道具或读施法条 | 用更快的突进打断 |
| 玩家绕到背后 | 急转身、翻滚离开，或用背上没有破绽的招 |
| 自己的连段第一下打中 | 把连段的后续接完 |
| 刚被弹开或架势崩掉 | 进入可处决，这段不能自己取消 |

动作和动作之间有间隔。间隔里它可能横移、举盾或发呆。间隔结束才再选下一次攻击。同组的几个敌人可以一起上手，游戏不强制他们轮流。动作慢的大型单位挥击长、站位挤，看起来像在让位置。游戏允许他们同时攻击。

一部分人形会在玩家的攻击落到身上的短窗口里弹反。弹反成功，玩家进入可处决。踢击、抓取、鞭式抽打，以及许多双手超大武器的挥击，不进弹反窗口。哪些招能弹，按那一招的配置。

攻击可以带追踪：挥出之前身体会朝玩家当前的位置转一小段。转向有上限，从侧面绕出去仍然躲得开。

## 远程

远程是攻击选择里的一档，单独配弓、弩、投掷或喷吐的敌人才会用。

它们尽量停在一个喜欢的距离：太近就后退再射，太远就一边补进一边射。只配了弓、没有近战武器的，被贴住后仍会试图拉开，不会临时换成剑。弓和投掷都能被盾挡住，也吃闪避的无敌段。射击有可见的拉弓或甩手，打空后有拉第二次的间隔。

有的人形背上同时有近战武器和弩。离得远时切手弩，贴上来再切回剑。切换本身有一段收武器的动作。

远程敌人按配置一直射，箭不会打空。会耗尽的是玩家自己的箭。

## 施法

施法同样是配进去的动作：魔法、奇迹、火焰，以及给自己或同伴加上的短时强化。读条用可见的姿势和聚气表示。读条被打出硬直，这下法术不生效。蓝在起手就扣还是读完才扣，待核对。蓝不够时，这下要么放不出来，要么它改选不耗蓝的动作。

常见用途：

- 远处直接造成伤害的投射物或落点。
- 战斗开始时给自己上伤害或防御强化。
- 自己或同伴生命变低时读治疗。治疗被打断则这次不加血。
- 异常类的喷吐和聚集，例如中毒、出血、冰冻。

头目和施法型精英用的是同一套「读条可被打断」，只是它们的读条往往带霸体，普通攻击打不停。带霸体的读条仍会掉血。

## 呼救同伴

> **呼救是一次专门动作：叫声或举杖，做完才把更远的同伴从待机拉进战斗。** 旁边本来就挨着、属于同一组的敌人，在发现的瞬间就会一起转过来，不必等这次叫声。

呼救的有效圈比普通的同组连锁大。有的呼救还会给圈里的同伴一个短时间的伤害强化。动作本身很长，途中被打出硬直，叫醒和强化都不生效。

没配呼救的敌人只会用普通连锁。头目战里「召唤小兵」是场地脚本，在头目一节里写，不走这次叫声。

## 活动范围与归位

> **每只普通敌人有一块围绕放置点的活动范围。玩家把它拉出这块范围，它放弃当前目标，沿路径走回放置点。**

归位中的表现：

1. 它停止追击，转身往回走。
2. 归途中若再被打中，并且玩家仍在能重新接战的距离内，它会回到追击，生命保持被打过的数值。
3. 一直走到放置点并完成脱战，这次追击里掉的生命补满，姿态回到待机。
4. 归途中玩家跑出加载、或者直接休息、死亡、回家、读档，按刷新处理：它已经在放置点满血等着。

雾门、一部分关着的大门和头目场地的边界会截断追击。敌人不跟着穿过已经关上的雾门。头目在自己的场地里不因距离归位。雾门关上之后，回城骨放不出去。死亡或退出读档会结束这场战斗，头目回到满血。

少数敌人的活动范围被故意拉得很长，会追过好几个房间，直到一扇它们不穿的门。这仍是活动范围，只是这块范围大。

## 脱战回血

脱战回血发生在归位完成的那一下，生命一次补满。战斗进行中没有缓慢回复。

战斗进行中，普通敌人没有站桩回血。玩家看到的回血来自三种别处的规则：

- 它或同伴读了治疗法术。
- 归位完成，生命回到满值。这次追击里打掉的血全部作废。
- 玩家休息、死亡回篝火、使用回城骨、传送或退出重进，整片区域的可刷新敌人直接以满血出现在放置点。

头目没有脱战回血。场地内拉开距离，血量保持在当前值。阶段转换把血条换成下一截的配置，此前打掉的血留在上一截里。

## 被打断

> **打在身上的一下会不会让敌人播受击，看这一下的冲击有没有压过它当时的韧性。** 生命无论打断与否都会扣。

玩家能分开的反应：

| 反应 | 看到的结果 |
| --- | --- |
| 短硬直 | 当前挥击取消，播一小段受击，马上能再动 |
| 大硬直 | 身体明显失去平衡。一部分人形在这段里可以被处决 |
| 击飞或打倒 | 离地或趴下，起身前有一段时间只能吃打 |
| 无受击 | 动作继续。这一下的冲击没过韧性，或者正处在霸体段落 |

韧性是一条不画在界面上的计量。连续打中会把它打空，停手片刻它会涨回来。打空的那一下播大硬直。轻武器要多打几下才掏空厚皮的敌人，重武器往往一两下就够。门槛的具体数字待核对。

抓取、背刺、处决一旦双方锁进同一段动画，被抓的一方不能用普通受击把这段动画取消。

## 霸体

霸体是一段「打中了仍不播受击」的时间。血照扣，韧性仍可能在暗中减少。霸体段落结束，或者韧性先被打空，后续的命中再按上一节处理。

常见挂在这些地方：

- 中大型武器挥到中段的时候。
- 一部分武器战技和战吼的整段。
- 头目的许多连段。有的头目整场都几乎不播普通受击，只在韧性被打空或脚本规定的破绽里才露出大硬直。
- 转阶段、抢人、从高处落下的脚本动作。这些段落常常连韧性打断也一起关掉，见头目一节。

霸体不挡住背刺和处决的锁定动画。攻击已经进了这两段，霸体会被这段动画换掉。

玩家自己的霸体和无敌帧见 [`战斗系统.md`](战斗系统.md)。敌人这边的结论相同：无敌是这下没打到身体；霸体是打到了但不中断。

## 死亡

生命到 0，敌人播死亡，不能再被锁定，不能再选招。死亡当时把灵魂加到玩家的计数上，再在尸体旁掷掉落。

尸体停在原地，直到下一次区域刷新。刷新后尸体消失，可刷新的敌人回到放置点。有的死亡会再爆一次范围伤害，或从尸体里伸出另一段身体接着打。那段新身体是另一次生命，死透才算这次放置被清空。

这些情况没有可搜的尸体：

- 入侵幻影和敌对 NPC 幻影，死亡后直接散掉。
- 头目召唤出来、配置为消散的小兵。
- 被场地规则收走的单位，例如绑在操纵者身上的飞行体，操纵者死亡时一起消失。

头目死亡的动画更长。动画结束，雾门打开，场地按「头目已死」记下，再刷新也不会把这个头目放回来。

## 体型与行为差异

> **体型决定它能不能被背刺、能不能被弹反、倒地之后有没有处决，以及追击走不走地面。** 具体技能仍看这只敌人的配置。

### 人形

身高接近玩家、用手持武器的敌人走人形规则。

- 可以举盾。盾有稳定度，承受冲击时耗精力，精力不够会崩开，崩开后有一段可处决。
- 战斗中会翻滚或侧步，翻滚带一段攻击穿身的窗口，窗口长短按那一招。
- 背后有破绽时可以被背刺。破绽多在攻击后摇和受击里，霸体挥击途中通常背刺不进去。
- 弹反成功，或盾被踢崩，进入处决。
- 会绕到玩家背后，用它们自己的背刺。
- 有的会在战斗中切武器、切到远程、喝药或施法。喝药和切武器的细则，敌对 NPC 更完整，见下一节。普通人形士兵多数只有一块固定装备。

### 野兽

狼、狗、鼠、虫、蛆这一类贴近地面、用扑咬和冲刺。

- 听觉距离往往更远，具体半径待核对。追击少绕圈，多半直线扑。
- 体型对不上背刺和弹反，倒地也没有处决提示。
- 很容易被打出短硬直或整段击飞。
- 常成组同时扑上来。
- 异常（出血、中毒）出现得勤。某一只免不免疫，仍按它的抗性配置。

大型猛兽（巨蟹、巨狼）介于野兽和大型之间：不能背刺，韧性很高，有的在韧性打空后会露出一次大硬直，那次硬直是否带处决，按这只的配置，待核对完整名单。

### 大型

巨人、重甲骑士、恶魔、以及明显高过玩家一截的单位。

- 挥击的霸体段落长，小武器连打只能慢慢掏韧性。
- 攻击范围宽，经常带抓取或把人打飞的一段。
- 一般不能背刺，也不能按人形的窗口弹反。
- 韧性打空时，一部分会跪下或露出一段很长的破绽，这时可以处决；另一部分只有大硬直，起身后继续打。
- 转身慢。贴在身侧比远处正面更不容易吃到下一击的起手。
- 有的会因场景旗标改阵营。旗标改完，休息也不会把它按普通敌人重新标回敌对。

### 飞行

飞行单位不沿地面巡逻。

- 短距离扑击、跳起再落地的，按节奏离开地面，落地后仍可以被锁定和打硬直。乌鸦骑士一类属于这种。
- 一直停在空中的，锁定点在高处，地面武器经常够不着，它用投射、俯冲或吐息攻击。
- 环印城的天使一类把空中的身体绑在地面上的操纵者身上。空中身体负责攻击，真正打死它要打死操纵者。操纵者死亡，空中的身体一起消失。
- 停在固定位置用吐息封路的大型飞龙，不按「追出活动范围再归位」处理。它死不死由这块场地的规则决定，有的场地用落点攻击一次结算。

### 隐身与埋伏

这里的「看不见」分三种，三种都先于普通视野。

| 方式 | 触发前 | 触发后 |
| --- | --- | --- |
| 装死、石化、嵌在墙里或尸堆里 | 没有战斗姿态，有的连锁定点都没有 | 靠近、出声或受击，身体出现并进入追击 |
| 藏在物件外形里 | 看起来像场景的一部分 | 受击或玩家贴到跟前，恢复成本体再攻击 |
| 淡入的召唤物 | 由另一个单位唤出来，出现过程中就已经能造成伤害 | 召唤者死亡，或这只自己的生命到 0 |

埋伏用的是距离和声响触发，不只看扇形视野。所以会在玩家还没锁定到它的时候先打中。

玩家用的隐身和消声，缩短的是上一节那种视野和听觉，不会让已经埋伏触发的单位退回隐藏。敌人里谁会主动把自己收成物件，按单只配置，完整名单待核对。

### 拟态

> **拟态宝箱在被识破前占用宝箱的位置和交互。** 它按唯一敌人放置，击杀后本周目保持消失。

静止时它保持箱子的外形。打开，或对它造成伤害，它展开身体并进入战斗。展开过程中减伤更高。展开后的动作以踢、扫和抓取为主，抓取会把玩家咬进一段锁动画并结算一次大伤害。韧性很高，不按人形弹反。

两条专门交互：

- **不死狩人护符**：掷在静止或已展开的拟态上，它进入一段时间的无力，这段里可以像普通宝箱一样取出里面的东西。效果结束，它回到静止的箱子姿态，并带一段苏醒动作。护符对普通敌人和头目不产生睡眠。对人形入侵者，这件道具还有一段禁止喝药的效果，时长待核对。
- **魅惑**：火焰法术，能把它暂时变成同伴。详情在诱导一节。即便处于魅惑中，对静止箱子执行「打开」仍会触发它的攻击。

箱子链的朝向是外观上的辨别方法：真箱子和拟态的链子方向相反。这是模型事实，不另开一条战斗规则。

拟态被打死之后本周目不再出现。它身上的物品如果在刷新前没取走，是否还留在地上，待核对。

## 敌对 NPC 与入侵者

> **敌对 NPC 和玩家入侵者使用角色的那套资源：生命、精力、蓝、负重、药瓶和记忆的法术。** 他们的血条多数是锁定点上的短条。被做成头目的那几场才使用屏幕下方的长条，例如环印城的教堂枪兵战。

能看到的行为：

- **喝药**：拿出药瓶读一段喝药动作，回复生命或蓝。次数有限。喝的途中被打出硬直，这口药浪费。敌对 NPC 的次数是单独配的；玩家入侵者带到别人世界里时，血瓶和蓝瓶都按自己的次数对半、向下取整。
- **翻滚**：耗精力，带一段闪避窗口。负重档次改变翻滚距离，规则与玩家相同。精力见底就翻不完整，或翻完站在原地喘气。
- **切武器**：左右手和多把武器之间切换，切换有收刀动作。切到盾才能举盾，切到催化剂才能施法，切到弓才能瞄准射击。
- **施法**：耗蓝。蓝不够则这下失败。读条规则与施法型敌人相同，并且他们有更多人形才有的取消和翻滚取消。
- **弹反、背刺、处决**：人形体型，玩家能对他们做，他们也能对玩家做。

敌对 NPC 的等级、装备和药瓶次数是作者配好的，看起来像一名玩家，数值不一定等于你当前的角色。玩家入侵者带去的是他自己的建造，再吃幻影规则里的生命和药瓶削减，见 [`角色交互与联机.md`](角色交互与联机.md)。

他们的阵营由旗标决定：剧情把他们标成敌对，或玩家先打了他们。旗标没立起来时，他们站在对话位置上，不走视野发现。立起来之后按这一节战斗，并且会追出普通士兵那种短活动范围，有的会追过整段关卡。

死亡之后身体消散。脚本安排的入侵者和多数有名字的敌对 NPC，本周目只死一次。掉落可能是一段灵魂、一件装备或盟约道具。任务旗标同时被标成死亡，见交互篇。

## 篝火重置与区域清空

> **会刷新的是普通敌人和精英。头目保持死亡。迷你头目和唯一敌人看这只有没有被标成一次性。**

这些操作都会让可刷新敌人满血回到放置点，尸体消失，药瓶和生命、精力、蓝按休息规则补满：

- 在篝火坐下。
- 从篝火传走，或使用回城骨一类回到上次休息的篝火。
- 死亡后在篝火醒来。
- 退出游戏再读档。

坐下的那一下就已经刷新，不必再在菜单里点某一项。

不会被这些操作叫回来的：

- 已经打死的头目。雾门保持打开，场地里的头目血条不再出现。
- 已经打死的拟态。
- 已经打死的结晶蜥蜴。蜥蜴若是自己逃走钻进地里、人还没死，下一次刷新会再出现，直到被打死。
- 已经打死的脚本入侵者和多数有名字的敌对 NPC。
- 作者标成一次性的精英或迷你头目。没有雾门、血很厚的单位里，两种都有：有的休息就回来，有的死了就空着。没有一条「血比普通怪厚就永不刷新」的总开关。名单待核对。

刚把一片区域里的活敌都打死、人还没休息时：地上有尸体和没收的光点，没有人再发现你。这是暂时清空。下一次刷新，可刷新的那些满血站回去，尸体和没捡的光点清掉。黑暗之魂 3 没有「同一只普通敌人杀死足够多次就永远消失」的计数。

永久留在世界上的是另一批状态：打开过的捷径、打烂后不再复原的门、已死的头目、已死的一次性敌人，以及由旗标换掉的一组放置。旗标换掉的意思是：某个头目死亡或某件物品交付之后，这段路刷新出来的是另一批敌人，旧的那批不再使用。这按世界状态保存。归位只把被拉走的那一只送回原处。

电梯、一部分机关和可破坏的路障会在刷新时回到初始位置。已经拉下的捷径杠杆保持打开。界面与场景交互写电梯停在离开时的那一层，重载后回不回默认层仍待核对，见 [未入池](../版本候选池/程序功能池/未入池.md)「休息或重载后电梯停在哪一层」（信息待统一）。

## 头目

> **头目是一场被雾门圈起来的战斗：独立血条、可以分阶段、可以往场地里加人或加机关。** 打死之后周目内不再出现。

### 雾门

雾门是场地的门。主人穿过雾门，头目血条出现，战斗开始。已经在场的协助幻影可以跟着进去。雾门外面的召唤标记进不去。入侵者会被这场进门送走，算入侵失败。

战斗中再从正面走回雾门，出不去。回城骨、卷剑碎片和暗印在血条已经出现后放不出去，和 [`世界与篝火.md`](世界与篝火.md) 的离开道具一致。死亡或退出读档会结束这场：头目回到满血，跟着进来的幻影被送回。

主人死亡，雾门里的战斗结束。再挑战时头目是满血，阶段从头开始。

### 独立血条

血条在屏幕下方，带名字，和锁定点上的短条分开。锁定头目时短条可能同时存在，真正代表这场战斗进度的是下方这条。

几种排法：

- 一只头目一条血。
- 阶段切换后换成下一条血，上一条清空或直接隐藏。
- 多具身体共用一条血。打倒外围的个体，扣的是这条总血，或只是在掏真正承载血条的那一具。两种在不同场次里都出现。
- 后加入的同伴有自己的短条或自己的长条，和主血条同时存在。

### 阶段切换

阶段是同一场战斗里换一套动作、换场地或加人。触发用下面这些条件里的一种或几种，按这场头目的配置：

- 生命降到某个比例。
- 战斗经过的时间。
- 头目走到场地里的某个位置。
- 若干个可破坏的位点被打掉。
- 场上的小兵被清掉，或反过来，小兵被召唤出来。

纯计时、不看血量的场次相对少。每场用哪一种待核对，不在这里逐场列表。

切换时常见的表现：动作套换掉、音乐换掉、场地附加火焰或新的行走面、血条换成下一截。切换用的那段动作见下一小节。

### 第二个实体

第二个实体在阈值到达时被放进场地，或从一开始就在，但会在中途改变行为。

- 它可以有自己的锁定点和自己的血，也可以给总血条打工。
- 它死了，留下的那只可能换一套更密的攻击选择。
- 它可能被反复召唤。杀掉当前这一只只清掉这一只，脚本到点会再放。
- 《艾雷德尔的灰烬》里存在「血量到了之后加入第二名大型战斗者」的场次。环印城的教堂枪兵则是把另一名玩家或一名 NPC 当作这个实体拉进来。会话规则见 [`角色交互与联机.md`](角色交互与联机.md)。

### 无敌与转阶段动作

转阶段、进场、抢投和一部分传送，带一段不接受伤害的时间。这段里武器打在身上没有伤害数字，血条不动，也不会累积用于击昏的韧性。

默认按「这段不掉血」处理。有的场次在动画的头几帧或尾巴上仍能打进去，那是这只头目的单独配置。名单待核对。

场地把人吸住、双方锁进一段动画时，这段同样不按普通受击取消。抓取命中后的伤害是这段脚本自己结算的。

### 场地机关

机关和头目的攻击一起构成这场战斗，不依赖它的右手武器。

| 机关 | 玩家看到的结果 |
| --- | --- |
| 掉台、崩塌的地板 | 行走面变小，掉出去直接死亡。少数场次里头目自己掉出去也会结算 |
| 火焰、毒、暗和诅咒雾 | 站在区域里持续扣生命或涨异常槽。举盾挡不住脚下的区域 |
| 可破坏位点 | 血条几乎不掉，直到这几个位点被打掉。伤害要打在位点上 |
| 召唤小兵 | 小兵用自己的短血条，会刷新。头目死时小兵按配置停止或一起消失 |
| 绑在另一具身体上的威胁 | 打死操纵者，空中的或远端的攻击体一起消失 |
| 特定攻击才造成有效伤害 | 普通攻击刮不掉血，或只刮掉极少。换上这场战斗提供的手段之后，伤害才按正常方式进血条 |

这些都是这一场的配置。没有「所有头目都会掉台」的总开关。

### 战败、魂魄与篝火

头目死亡的当次结算：

- 一大笔直接进入计数的灵魂。
- 一件头目灵魂道具。道具可以当成普通灵魂使用，也可以交给变位的 NPC，换成武器或法术。变位在 [`角色交互与联机.md`](角色交互与联机.md)。
- 有的场次再固定加上一件法术、灰烬、装备或篝火。
- 新周目里，部分头目会多掉一枚同名戒指的强化版本。

雾门打开。许多场次会在场地里或门口点起一处新篝火，作为之后的休息点。没配新篝火的，仍然把道路或电梯解锁。人若死在头目身上，回到进门之前那处已点燃的篝火。新篝火要等这场胜利之后才出现。

头目灵魂和那笔直接灵魂只在这只头目死亡时给一次。周目内打第二次不会发生，因为头目不复活。

### 召唤 NPC 幻影

雾门外侧的地面上会出现带名字的召唤标记，名字是这名 NPC。主人在余烬状态下可以召他们进来，占一个协助名额。他们使用敌对 NPC 那套资源：会喝药、会翻滚、会施法，血比玩家建造薄或厚都是预先配的。

他们计入「场上有多少协助幻影」，因此会计入头目生命的提高。他们死亡则本场离开，不能在雾门里再召一次。这场头目死亡，或主人死亡，他们一起结算离开。

NPC 标记不需要另一名玩家在线。哪些头目门口有谁，由任务旗标决定：旗标没到，标记不出现；这名 NPC 已死或已敌对，标记消失。

### 幻影人数与头目生命

> **跟着进入雾门的协助幻影越多，头目的最大生命越高。** NPC 幻影和玩家幻影都算。

公开且稳定的部分：

- 人数在进门时算进这场战斗。血条按提高后的上限显示。
- 加成按头目分别配置。没有一条全游戏共用的固定比例。
- 普通敌人在有协助幻影的区域里也会变厚，幅度通常比头目小。
- 一部分头目同时提高减伤，所以同样的攻击扣下去的血更少。攻击欲望会不会因为人数变高而改表，待核对。

公开测试对不上、因此不写死的部分：

- 每个具体头目的倍率。
- 入侵者算不算进这个人数。协助幻影算，这是稳定的；红灵一类敌对幻影通常进不了雾门。
- 有人在战斗中途用黑水晶离开或死亡之后，已经提高的上限会不会降回来。
- 三人协助时，不同头目的生命大约落在两倍多到三倍半之间。这个区间来自玩家测试，界面上不显示倍率。

教堂枪兵是例外：充当头目的那名玩家，生命上限不加，加的是减伤、精力和蓝这一类。见交互篇。

## 误伤、诱导与异常

### 误伤

普通敌人的武器挥击穿过同伴，不扣同伴的生命。玩家看到两只怪的武器交在一起，两边都不播受击。

这些情况会伤到旁边的敌人：

- 地上的火焰、毒沼、岩浆、坠落。谁踩进去谁掉血，不管阵营。
- 一部分爆炸和吐息。挥击不误伤，范围爆炸可能伤到站在圈里的同伴。哪些爆炸算，待核对。
- 被魅惑之后。被魅惑的个体把原来的同伴当成目标，伤害按真实战斗结算。
- 主人使用了巨人种子之后，区域内的敌人会把入侵者当成目标。同伴之间的挥击仍然穿过。规则见 [`角色交互与联机.md`](角色交互与联机.md)。

### 诱导

诱导是让敌人自己走到某个点，或暂时换阵营。

- **引诱颅骨**：扔在地上，许多普通敌人和拟态会走过去查看。查看时有一段不攻击的窗口。头目和一部分特殊敌人无视它。走路的目标若在悬崖外，它们会顺着路径掉下去，掉死按普通死亡结算。
- **魅惑**：远程火焰，命中后这只敌人暂时成为施法者一方。它攻击其他敌人，也能攻击入侵者，不会被主人锁定。持续约半分钟。进行中的挥击仍可能刮到施法者。对玩家和玩家幻影无效。能被魅惑的多为配置允许的人形和部分大型人型；头目、多数野兽和不少特殊人形无效。完整名单和可否刷新持续时间，待核对。
- **拉开归位**：把敌人引出活动范围，它自己走回放置点并回满血。用的是归位规则。

### 睡眠

没有一条通用的睡眠槽。流血、中毒、冰冻那类异常条里不包含睡眠。

让目标停下来的专用手段是上一节的拟态护符：只对拟态宝箱生效，生效期间可以拾取，结束后它回到箱子待机。普通敌人和头目不被这件道具催眠。

### 冰冻与其他异常

异常是一条攒满才爆发的槽。敌人和玩家都能当目标。免疫的单位槽不涨，或涨了也不爆发。抗性决定涨得快慢，界面不列出数字。

| 异常 | 攒满时 |
| --- | --- |
| 冰冻 | 立刻掉一块生命，并进入一段恢复变慢、减伤变差的状态。状态结束前再用火属性打中，冰冻状态会提前结束。火是否一击就清掉，待核对细项 |
| 出血 | 立刻掉一块生命，槽清空，可以再次攒 |
| 中毒 | 之后一段时间内持续掉血 |
| 猛毒 | 持续掉血更猛，或叠加额外惩罚。和中毒的界面表现接近 |
| 诅咒 | 槽满时玩家直接死亡 |

冰冻、出血打在敌人身上同样生效，只要这只不是免疫。爆发瞬间的硬直很短，多数敌人不会因为槽满就进入可处决。

### 击倒与处决

> **倒地本身不打开处决。** 处决要另有一段「可致命一击」的状态。

能进入这段状态的途径：

- 弹反成功。
- 对举盾的人形把稳定度打崩，常见做法是踢击。
- 一部分敌人的韧性被打空，播一段下跪或摇晃，这段被标成可处决。

人形武器使用者通常三条都能碰上。野兽、飞行单位、拟态，倒地后只能用普通攻击补刀，没有处决的锁定动画。大型单位里，只有配置了「破韧后下跪」的那些才会给处决，其余只是大硬直。

头目里，只有被配成可以弹反或可以破韧处决的才打开这段状态。其他头目即使倒在地上，也仍是普通受击或阶段动画，贴上去轻攻击不会锁进处决。

从高处砸下去的下落攻击是单独的一段伤害，不占用处决状态，也不要求对方正在倒地。

已经被处决动画锁住的敌人，这段里不再吃普通连段；伤害在动画里结算一次。

## 掉落

> **灵魂是确定的。物品分「这只必掉」和「按发现力掷一次」。** 概率项没有越打越容易出的保底计数。

### 灵魂

敌人死亡的瞬间，基础灵魂加进玩家的计数，屏幕上有数字。最后一击是谁，不改这笔钱归主人所有；在场的协助幻影另外拿到削减后的一份，比例待核对。

头目在基础灵魂之外再给一件头目灵魂道具。道具进背包，不自动换成计数里的灵魂。使用它才变成灵魂；拿去变位则消耗这件道具，换成装备或法术。

### 道具、装备与材料

死亡时在尸体旁边出现光点的，是物品掉落。拾取后进背包。光点里的内容按这只敌人的条目来：

- 消耗品和钥匙类道具。
- 它所用的武器、防具或戒指，概率通常低于材料。
- 强化和注入用的材料：各种泰坦鳞片、结晶鳞、宝石。条目里没有的材料，发现力再高也不会变出来。

每次死亡独立掷一次。上一只没出，不会给下一只累计幸运。

### 保底从哪里来

保底来自放置：这件东西在周目内只安排一次。概率项每次独立重掷，失败次数不累计。

| 来源 | 周目内的次数 |
| --- | --- |
| 头目灵魂、头目附带的固定物品 | 一次 |
| 地上的尸体、不会刷新的箱子 | 搜空一次 |
| 拟态、已击杀的结晶蜥蜴、其他一次性敌人身上的固定掉落 | 一次 |
| 普通敌人条目里写明必掉的东西 | 每次刷新后的死亡都掉 |
| 普通敌人的概率条目 | 每次死亡重新掷，可能永远不掉 |

发现力改的是概率条目掷中的机会。界面上有道具发现力。幸运提高它。短时间的锈币、一部分戒指、武器和头冠在穿上或使用期间提高它。有的头冠在提高发现力和灵魂获取的同时持续扣生命。这些装备的百分比和叠乘方式待核对，这里只记方向：它们改发现力或改灵魂乘数，不改掉落条目本身。

一次性敌人若已死、光点还没捡，就休息或读档，光点多半一起消失，而且这只敌人不再刷新。这组合会把这份掉落弄没。是不是每一类一次性敌人都这样，待核对。

### 过量击杀的灵魂加成

单次攻击造成的伤害明显高于目标满血时，这次击杀掉进计数的灵魂会高于这只敌人的基线。玩家无法在界面上看到「过量」两个字，只能看到数字变大。

这条加成叠在「提高灵魂获取」的装备乘数上。头目、跌落致死、以及靠中毒等异常把血磨完的击杀，不吃这条加成。

精确要超过满血的多少、灵魂多出的比例是多少、背刺和处决算不算「一次攻击」，公开测试并不完全一致，待核对。武器和刷取地点不在这里列。

## 两部 DLC 里的用法

行为类型没有新的总类，增加的是配置。

《艾雷德尔的灰烬》：

- 重甲的密林骑士走大型人形：霸体长、可破韧。
- 鸦人能短距离离地，落地后仍按地面单位被打硬直。
- 持火把的跟随者会治疗或强化附近同伴，走施法和呼救。
- 有名字的敌对 NPC 会喝药和翻滚，死亡后不再刷新。
- 有一场头目在生命阈值后加入第二个大型实体，过渡动作不接受伤害。

《环印城》：

- 天使是绑在地面操纵者上的飞行攻击体。
- 审判者召唤会淡入的小兵，小兵死亡可以被再召。
- 环印骑士是高韧性人形，使用武器战技。
- 教堂枪兵把玩家或 NPC 放进头目位置。生命不加、减伤随主人一侧的人数提高，详见交互篇。
- 若干头目用生命阈值更换动作套，并带一段拒绝伤害的过渡。

两部 DLC 的普通敌人都按本文的刷新规则走：休息回来，头目和一次性单位不回来。

## 待核对

- 各类敌人的视野角度、听觉半径、近身无视朝向的距离。
- 归位完成前的那一段，伤害是否照常进入，还是有短暂锁血。
- 韧性打空的数值门槛。
- 施法被打断时蓝的扣除时机。
- 呼救的半径，以及哪些叫声附带强化。
- 会把自己收成场景物件的敌人名单。
- 拟态护符禁止人形喝药的时长；拟态光点在休息后是否残留。
- 大型单位里哪些破韧之后可以处决。
- 无雾门的厚血精英里，哪些休息会刷新。
- 哪些过渡动画的头尾仍能造成伤害。
- 每个头目在不同幻影人数下的生命和减伤倍率；战斗中途少人之后倍率会不会降。
- 协助幻影击杀敌人时，主人与幻影各自拿到的灵魂比例。
- 哪些爆炸会误伤同伴。
- 魅惑的完整目标名单和持续时间能否刷新。
- 火属性解除冰冻需要的命中次数。
- 过量击杀的伤害门槛、灵魂比例，以及背刺是否计入。
- 发现力和灵魂装备的叠乘百分比。
- 一次性掉落在未拾取时，是否每次刷新都消失。
