# 本仓库对照

本篇只对照当前仓库里已有的脚本入口。调研覆盖哪些系统写在 [`范围.md`](范围.md)，目录在 [`README.md`](README.md)。

> **能跑的是移动、锁定、精力、轻重点攻击、近战命中、举盾、喝药回血、人形近战五状态、三条 HUD。** 负重、翻滚无敌、属性加成、武器技扣蓝、药瓶持续回复、篝火休息、死亡血迹都还对不上黑魂 3 的可验收结果。类名来自写文档时读过的 `Assets/Scripts/`。

当前 `Game` 场景根上激活的是 [`../../Assets/Perfabs/Player/Player.prefab`](../../Assets/Perfabs/Player/Player.prefab)。三只人形近战在未激活的 `Test Map - Combat` 下。篝火、雾墙、Boss、箱子挂在未激活父节点下，脚本留在工程里，运行进不去。细节见 [`../代码分析/构架设计.md`](../代码分析/构架设计.md)。

「未找到」表示按类名、字段名在 `Assets/Scripts/` 里没有对应类型。已有类但当前场景没用到，写在缺口里单独说明。

## 总表

| 系统 | 黑魂 3 行为要点 | 本仓库已有入口 | 缺口 |
| --- | --- | --- | --- |
| 玩家操控 | 走跑冲刺、有方向翻滚、无方向后撤、跳跃、下落落地；攻击占身体，举盾不锁移动 | `PlayerLocomotionManager`、`InputManager`、`HandleRollState`、`HandleJumpState` | 翻滚距离不随负重变化。`"Land"` 只在刚落地的那一步播放，`Falling` 没有带回 Empty 的出口 |
| 镜头与锁定 | 绕背、锁定、切换、失去目标解开、瞄准镜头 | `PlayerCameraManager` | 旋转、跟随、偏移三处对「瞄准 / 锁定」的判断不一致。`ChangeLockOnTargetMode.minHP` 没有分支 |
| 精力 | 精力付冲刺翻滚攻击和举盾；蓝付法术和武器技；见底有可见失败；停下后恢复 | `CharacterStatsManager`、`PlayerStatsManager`、`DrainStamina` | 武器技不扣蓝。`FlaskType.ashen` 和 `focusPointsRecoverAmount` 不参与结算 |
| 攻击与武器技 | 轻击连段、重击、武器技、举盾、弹反、背刺处决、双手另一套动作 | `WeaponItem` 的 `oh_*` / `th_*`、`LightAttackAction`、`HeavyAttackAction`、`BlockAction`、`ParryAction`、`CriticalAttackAction` | 双手轻击重击已按 `isTwoHandingWeapon` 换 `thLightAttack*` / `thHeavyAttack*`，玩家输入仍调用 `oh_*`。武器技 `ParryAction` 双手分支为空且不扣蓝 |
| 命中与伤害 | 窗口内结算一次；五段伤害；护甲与正面举盾分两层减伤；破韧才硬直 | `DamageCollider`、`TakeDamage` | 近战同一窗口可再次进入再结算。火 / 魔 / 雷 / 暗吸收穿戴不写入。法术和炸弹不走格挡与韧性 |
| 霸体 / 超级霸体 | 攻击中段普通命中不打断；更重的段落连重击也不打断；血仍扣 | `GrantWeaponAttackingPoiseBonus`、`totalPoiseDefence`、`poiseBreak` | 未找到超级霸体旗标。`poiseLevel` 无结算读取。`armorPoiseBonus` 穿戴不写 |
| 无敌帧 | 翻滚和后撤的一段窗口内伤害穿过身体 | `isInvulnerable`、`EnableIsVulnerable` | `HandleRollState` 只写 `isRolling`。翻滚无敌依赖片段是否调用 `EnableIsVulnerable`，状态本身不打开 |
| 负重 | 装备重量百分比分成轻翻、中翻、重翻、超重不能翻 | 未找到 | `Item`、`EquipmentItem`、`ArmorItem`、`WeaponItem` 都没有重量字段 |
| 属性 | 升级改变上限，力量敏捷智力信仰加入伤害和需求 | `healthLevel` 等八个等级字段 | 只有生命、精力、蓝按等级乘 10。力量、敏捷、智力、信仰、`poiseLevel` 不参与伤害。未找到升级入口 |
| 装备与道具 | 左右手多槽、头身手腿、戒指、快捷栏，换装立刻改动作 | `CharacterInventoryManager`、`PlayerArmorManager`、`QuickSlotsUI` | 防具只有 `head` / `torso` / `hips`。未找到戒指。装备窗只画每手前两格 |
| 回复类治疗 | 喝药锁移动并持续回血或回蓝；治疗法术扣蓝；休息补满次数 | `FlaskItem`、`HealingSpell` | 血瓶结算是一次 `AddHP`。次数写在资产上。已点燃篝火的休息分支是空的 |
| 敌人 AI 状态 | 待机、发现、追击、周旋、攻击、会放弃追击；Boss 转阶段 | `IdleStateHumanoid` 等五状态、`BossCombatStanceState` | 追击不回到待机。General / Boss 不在当前 `Game` 的近战上。`BossHasBeenDefeated` 无调用方 |
| 死亡与燃火循环 | 死亡留血迹，再死丢掉；休息设重生点并重置小怪 | `Death`、`AddSouls`、`CampFireInteractable` | 未点燃时可以点燃。休息回满、药瓶次数、血迹、灵魂归零、重生点都没有入口。玩家死亡后停在当场 |
| 战斗 HUD | 三条条、灵魂、药瓶次数、锁定标记、敌人血条、Boss 血条 | `HealthBar`、`StaminaBar`、`FocusPointsBar`、`SoulCountUI`、`UIEnemyHealthBar`、`UIBossHealthBar` | 灵魂只在敌人死亡时改字。灰瓶次数没有单独的条。锁定标记未在 HUD 脚本里找到 |

行为原文在 [`README.md`](README.md) 索引的九篇里；[`黑魂3系统行为.md`](黑魂3系统行为.md) 只作跳转。下面按系统写清入口路径，避免总表把缺陷说短。

## 玩家操控

入口：

- `Assets/Scripts/Character/Player/PlayerLocomotionManager.cs`：`HandleMove`、`HandleRotate`、`HandleFall`、`HandleJump`、`HandleRoll`、`HandleBackStep`。
- `Assets/Scripts/Character/Player/InputManager.cs`：冲刺和 `rollFlag` 只在 `HandleRollInput` 写。精力不大于 `sprintNeedMinStamina` 时清掉冲刺。
- `Assets/Scripts/Animator/HandleState/Humanoid/HandleRollState.cs`、`HandleJumpState.cs`：写入 `isRolling`、`isJumping`。

`isInteracting` 为真时 `HandleMove` 停写速度。`BlockAction` 播放举盾时这个参数是 false，举盾本身不锁移动。锁定且非冲刺时 `HandleRotate` 朝锁定目标转。

缺口：全脚本没有按负重改翻滚距离或速度的字段。`HandleFall` 用 `wasInAir` 包住，`"Land"` 只在刚落地的那一步播放。`Falling` 没有带回 Empty 的出口。负重四档仍没有字段。

## 镜头与锁定

入口：`Assets/Scripts/Camera/PlayerCameraManager.cs`。`lockOnFlag` 表示已经锁上目标。`UpdateLockOnTargets` 做半径重叠和 `Linecast`。目标死亡时 `EnemyStatsManager.HandleEnemyDeathEvent` 调用 `Unlock`。瞄准读 `PlayerManager.aimingMode`，动画侧另有 `HandleAimingState` 写的 `isAiming`。

缺口：跟随、旋转、偏移对瞄准和锁定的条件不相同，同一时刻镜头和角色朝向可能各看各的。`ChangeLockOnTargetMode` 里的 `minHP` 没有分支。弓瞄准能进 `AimAction`，但要求 `isTwoHandingWeapon` 且有箭。

## 精力

入口：

- `CharacterStatsManager`：`currentHP` / `currentStamina` / `currentMP`，上限由 `healthLevel`、`staminaLevel`、`focusLevel` 各乘 10。`RegenerateStamina` 在停下消耗超过 1 秒后恢复，举盾用更小的 `staminaRegenerationAmountWhilstBlocking`。
- 冲刺、翻滚、后撤、跳跃的扣除在 `PlayerLocomotionManager`。翻滚、后撤、跳跃在 `DeductStamina` 返回 false 时不播放。攻击扣除在动画事件 `DrainStamina`（`CharacterAnimatorManager`）。
- 举盾承击在 `CharacterCombatManager.AttemptBlock`：精力扣光播放破防。
- 法术扣蓝在 `SpellItem.focusPointCost`，`ProjectileSpell` 看 `DeductMP` 的结果。

缺口：`ParryAction` 不读 `currentMP`。轻击和重击只在 `currentStamina` 小于等于 0 时拒绝；大于 0 但低于本次消耗时动画照播，`DrainStamina` 里的 `DeductStamina` 不够就不扣。血瓶字段 `focusPointsRecoverAmount` 在 `SucessfullyUsedConsumable` 里没有使用，实际只 `AddHP`。`FlaskType` 有 `estus` 和 `ashen`，使用逻辑不分支。

## 攻击与武器技

入口：`PlayerCombatManager.HandleCombatInput` 按按住 E、按住 Q、点按 E、点按 R、点按 Q、点按 Z 的顺序，调用武器上的 `WeaponItemAction.PerformAction`。轻击重击是 `LightAttackAction`、`HeavyAttackAction`，连段看 `canDoCombo`；`isTwoHandingWeapon` 时这两处改播 `thLightAttack*`、`thHeavyAttack*`。举盾是 `BlockAction`。点按类武器技脚本是 `ParryAction`，播 `CharacterAnimatorManager.weapon_art`（默认字符串 `"Parry"`）。处决和背刺是 `CriticalAttackAction`，`GetBackStabbed` / `GetRiposte` 用攻击者的 `rightWeapon`。`pendingCriticalDamage` 没有写入方，`ApplyPendingDamage` 读到 0 就返回。弓是 `AimAction`、`ShootArrowAction`。

双手轻击、重击和武器技分开看。前者已有动画分支。后者是下面的缺口。

缺口：

- 玩家输入仍调用 `oh_*`。`th_tap_*` 只在 `ItemBasedAttackAction`（人形 AI）里调用。
- `ParryAction` 在 `isTwoHandingWeapon` 时分支是空的，单手也不读 `currentMP`。
- 未找到独立的战技资源类型（每把武器一套蓝耗、一段霸体、一段无敌）。战技目前是动画名字符串。
- 冲刺攻击、跳跃攻击：未找到单独的 Action 类。

## 命中与伤害

入口：

- 近战和箭：`DamageCollider.OnTriggerEnter` → `DealDamage`。五种数在这里乘武器阶段系数，正面格挡再乘吸收，并用 `poiseBreak` 与 `totalPoiseDefence` 决定受击动画名是否为空。左手举盾时 `SetBlockingAbsorptionFromBlockingWeapon` 读左手武器的吸收和 `blockingStabilityRating`。
- 护甲合成在 `CharacterStatsManager.TakeDamage`：头 60%、躯干 30%、下身 10%。
- 法术 `SpellDamageCollider`、炸弹 `BombDamageCollider` 走碰撞，只传火焰段，不进 `DealDamage`。
- 环境 `DamagePlayer` 只打玩家。

缺口：近战没有「这一刀已经打过此人」的标记。`EquipAllArmorModels` 只写物理吸收，另外四段在结算里保持 0。炸弹直击后再溅射，同一人可以结算两次。

## 霸体 / 超级霸体

入口：`CharacterAnimatorManager.GrantWeaponAttackingPoiseBonus` 把 `WeaponItem.offensivePoiseBonus` 加进 `totalPoiseDefence`，`ResetWeaponAttackingPoiseBonus` 写回 `armorPoiseBonus`。这两个方法供动画片段按名字调用。`DamageCollider` 在 `totalPoiseDefence` 减掉 `poiseBreak` 之后仍大于 `poiseBreak` 时不播受击，血已经在 `TakeDamage` 里扣。`poiseResetTimer` 到点后把韧性设回 `armorPoiseBonus`。

缺口：未找到名为超级霸体的字段或状态。`poiseLevel` 只声明，结算不读。`PlayerArmorManager` 穿戴时不写 `armorPoiseBonus`。法术和炸弹不读韧性，打中它们时这段加防不会保住动作。Boss 转阶段写的是 `isInvulnerable`，这一段是打不中；霸体是打中之后仍扣血、动作不中断。

## 无敌帧

入口：`CharacterStatsManager.isInvulnerable`。`TakeDamage` 在该旗标为真时直接返回。动画事件方法 `EnableIsVulnerable` / `DisableIsVulnerable` 在 `CharacterAnimatorManager`。`HandleEmptyState` 进入时把它写成 false。`CriticalAttackAction` 会把执行者写成无敌。`EnemyStatsManager.ShiftToSecondPhase` 在转阶段时写成 true。

旗标为真时不受伤，和翻滚自己打开一段窗口，是两件事。前者这条入口已经有。

缺口：`HandleRollState`、`HandleJumpState` 不写 `isInvulnerable`。后撤步也没有自己的状态行为去开无敌。翻滚期间能否穿过伤害，取决于 `"Rolling"` 片段有没有打 `EnableIsVulnerable` 事件；本调研没有把控制器里每段翻滚逐帧打开核对。代码上没有「翻滚第几帧到第几帧无敌」的数据，只有一个全局布尔。

## 负重

未找到装备重量、最大负重、负重百分比、轻翻 / 中翻 / 重翻 / 超重这些类型或字段。`Item`、`EquipmentItem`、`ArmorItem`、`WeaponItem`、`AmmoItem` 的字段里没有重量。`PlayerLocomotionManager` 的翻滚只扣 `rollCost` 并播放 `"Rolling"`。

这一条要从字段开始加，现有翻滚入口是 `HandleRoll` 加 `HandleRollState`，加的时候仍走这两处，不另建一套移动组件。

## 属性

入口：`CharacterStatsManager` 上的 `healthLevel`、`staminaLevel`、`focusLevel`、`poiseLevel`、`strengthLevel`、`dexterityLevel`、`intelligenceLevel`、`faithLevel`。前三个在 `Awake` 里乘 10 写成上限。

缺口：力量、敏捷、智力、信仰不出现在 `DealDamage` 或 `TakeDamage`。未找到升级菜单、灵魂消耗、武器需求、加分字母。`soulCount` 只由 `PlayerStatsManager.AddSouls` 增加，敌人死亡时 `AwardSoulsOnDeath` 调用它。没有把灵魂扣掉的升级函数。

黑魂 3 状态页里的集中力槽位数量、体力与负重的挂钩、幸运，对应字段未找到。

## 装备与道具

入口：

- 武器装载：`CharacterInventoryManager`、`WeaponHolderSlot`、`CharacterWeaponSlotManager`。
- 防具：`InventorySlotUI.EquipArmor`、`PlayerArmorManager.EquipAllArmorModels`，部位枚举 `ArmorType` 为 `head`、`torso`、`hips`。
- 快捷栏：`QuickSlotsUI`，消耗品走 X 键和 `ConsumableItem.AttemptToConsumableItem`。
- 双手：`CharacterManager.isTwoHandingWeapon`。

缺口：未找到手部、腿部以外的第四防具部位，未找到戒指类型。装备窗只显示左右手槽的前两格，每手 4 把里后两把靠方向键换。背包格子和总表 `items` 的引用在玩家预制体上对不齐，法术格点进去直接返回。数量 `currentItemAmount`、箭的 `cnt` 写在 `ScriptableObject` 上。

## 回复类治疗

入口：

- `FlaskItem.AttemptToConsumableItem` 在播喝药前减少 `currentItemAmount`，`SucessfullyUsedConsumable` 里 `AddHP(healthRecoverAmount)`，然后 `LoadWeaponsOnBothHands`。
- `HealingSpell` 在释放时 `AddHP`，并调用 `DeductMP`，不看扣蓝是否成功。
- `CampFireInteractable`：未点燃时播 `"Pick Up Item"`、弹出 `CampFireLitPopUpUI`、打开火焰。`hasBeenActived` 为真时的方法体是空的。

点燃是未点燃时的这条交互。休息回满、灰瓶结算、死亡血迹是另外的缺口。

缺口：回血发生在动画事件的一次调用，生命直接跳到加上的数值，没有喝的过程中持续上涨。灰瓶回蓝未接到 `Add` 专注点。休息不补满生命、蓝和药瓶次数，也不重生敌人。药瓶次数和玩家是否在场无关，改的是那一份资产。

`HealingSpell` 现有资产走奇迹动画 `"Spell_Heal_Start"`。学派门禁在 `MiracleSpellAction` 等三个类，它们只核对 `SpellType`。

## 敌人 AI 状态

当前 `Game` 的近战挂 `Assets/Scripts/Character/NPC/State/Humanoid A.I/`：

| 状态类 | 玩家能看到的 |
| --- | --- |
| `IdleStateHumanoid` | 范围内、视野角内、`Linecast` 没挡住时把玩家写成 `currentTarget`，切到追击 |
| `PursueTargetStateHumanoid` | 朝目标移动；距离不大于 `aggroRadius` 时切周旋 |
| `RotateTowardsTargetStateHumanoid` | 转向，并可能按距离切回追击或周旋 |
| `CombatStanceStateHumanoid` | 选攻击，也掷举盾、闪避、弹反；目标 `canBeRiposted` 时走处决方向 |
| `AttackStateHumanoid` | 打出后同一 `Tick` 回到转向 |

`EnemyManager.Update` 调用 `currentState.Tick`。距离和夹角在 `UpdateAICombatInfo`。

缺口：`PursueTargetStateHumanoid` 在距离大于 `aggroRadius` 时继续追，没有切回 `IdleStateHumanoid`，也没有把 `currentTarget` 清掉。未找到「追丢后放弃」的状态。

平行的一套在 `General A.I/`（多一个 `AmbushState`），Boss 选招在 `Boss A.I/BossCombatStanceState`。当前 `Game` 的三只近战没有挂这两套。半血转阶段在 `EnemyStatsManager.UpdateBossHealthBar`，依赖 Boss 血条和 `BossCombatStanceState`。`WorldEventManager.BossHasBeenDefeated` 没有调用方，雾墙不会因为敌人 `Death` 打开。这些物体的父节点在 `Game` 里未激活。

## 死亡与燃火循环

入口：

- 玩家：`PlayerStatsManager.TakeDamage` 在 `currentHP <= 0` 时调用 `Death`，播放 `"Death"` 并 `isDead = true`。`InputManager`、`PlayerLocomotionManager`、`PlayerCombatManager` 看见死亡就返回。
- 敌人：`EnemyStatsManager.Death` 解锁定、`AddSouls`、延时 `Destroy`。
- 篝火：上一节的 `CampFireInteractable`。未点燃时会点燃。已点燃后的休息回满、药瓶次数、死亡血迹不跟点燃写在同一条。

缺口：未找到血迹物体、死亡时把 `soulCount` 归零、记录重生点、把玩家移回篝火、把已死小怪重新生成。玩家死后停在死亡动画，`PlayerUIManager.Update` 先返回，已经打开的暂停菜单无法按返回关掉。

## 战斗 HUD

入口都在 `Assets/Scripts/UI/`：

| 玩家看到的 | 类 |
| --- | --- |
| 生命、精力、蓝 | `HealthBar`、`StaminaBar`、`FocusPointsBar`，由 `PlayerStatsManager` 在数值变化时写 `Slider` |
| 灵魂数字 | `SoulCountUI`，敌人 `AwardSoulsOnDeath` 里 `SetSoulCountText` |
| 快捷道具图标 | `QuickSlotsUI` |
| 交互提示 | `InteractUI` |
| 小怪血条 | 敌人子物体上的 `UIEnemyHealthBar`，受伤后显示约 2 秒 |
| Boss 血条 | `UIBossHealthBar`，`WorldUIManager.ActivateBossBar` 打开 |

`HUDWindowsManager` 持有这些引用。条本身没有每帧去读属性。

缺口：`AddSouls` 只改数字，HUD 要等 `SetSoulCountText` 才变字；玩家死亡没有把它写成 0。未找到灰瓶剩余次数的独立显示。锁定标记未在 `HUD Windows` 下找到对应类，锁定状态只在 `PlayerCameraManager.lockOnFlag`。Boss 条要 `World` 物体激活且开战碰撞体被走到才会出现，当前 `Game` 这条路是关掉的。

## 写需求时先碰到的缺口

按「没有这块入口」和「有入口但对不上可验收结果」分成两组，方便以后拆版本。调研不排进开发计划。

还没有类型可挂的：

1. 负重四档翻滚。
2. 属性加入伤害、装备需求、升级扣魂。
3. 死亡血迹、灵魂掉落与捡回、重生点。
4. 篝火休息：补满、回药、重置普通敌人。
5. 追丢目标后回到待机。

已有入口、验收仍对不上黑魂 3 的：

1. 翻滚无敌只是动画事件布尔，`HandleRollState` 不负责窗口。
2. 霸体只加 `offensivePoiseBonus`，超级霸体未找到，护甲韧性不穿进结算。
3. 武器技是 `ParryAction` 的一个动画名，不扣蓝，双手为空。
4. 药瓶一次 `AddHP`，灰瓶字段空着，次数在资产上。
5. 五段伤害里只有物理吸收会随穿甲变化；近战同一刀可以打中两次。
