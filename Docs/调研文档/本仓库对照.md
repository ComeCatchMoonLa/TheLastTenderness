# 本仓库对照

本篇只对照当前仓库里已有的脚本入口。调研覆盖哪些系统写在 [`范围.md`](范围.md)，目录在 [`README.md`](README.md)。

缺口见 [`../代码分析/正确性.md`](../代码分析/正确性.md)。调用过程见 [`../代码分析/接口设计.md`](../代码分析/接口设计.md)。场景里哪些物体开着见 [`../代码分析/构架设计.md`](../代码分析/构架设计.md)。

「未找到」表示按类名、字段名在 `Assets/Scripts/` 里没有对应类型。

## 总表

| 系统 | 黑魂 3 行为要点 | 本仓库已有入口 |
| --- | --- | --- |
| 玩家操控 | 走跑冲刺、有方向翻滚、无方向后撤、跳跃、下落落地；攻击占身体，举盾不锁移动 | `PlayerLocomotionManager`、`InputManager`、`HandleRollState`、`HandleJumpState` |
| 镜头与锁定 | 绕背、锁定、切换、失去目标解开、瞄准镜头 | `PlayerCameraManager` |
| 精力 | 精力付冲刺翻滚攻击和举盾；蓝付法术和武器技；见底有可见失败；停下后恢复 | `CharacterStatsManager`、`PlayerStatsManager`、`DrainStamina` |
| 攻击与武器技 | 轻击连段、重击、武器技、举盾、弹反、背刺处决、双手另一套动作 | `WeaponItem` 的 `oh_*` / `th_*`、`LightAttackAction`、`HeavyAttackAction`、`BlockAction`、`ParryAction`、`CriticalAttackAction` |
| 命中与伤害 | 窗口内结算一次；五段伤害；护甲与正面举盾分两层减伤；破韧才硬直 | `DamageCollider`、`TakeDamage` |
| 霸体 | 攻击窗口里霸体血量没被打空时挥击继续、血仍扣；单次重击或连续轻击把血量打空则挥击中断 | `GrantWeaponAttackingPoiseBonus`、`totalPoiseDefence`、`poiseBreak` |
| 无敌帧 | 翻滚和后撤的一段窗口内伤害穿过身体 | `isInvulnerable`、`EnableIsVulnerable` |
| 负重 | 装备重量百分比分成轻翻、中翻、重翻、超重不能翻 | 未找到 |
| 属性 | 升级改变上限，力量敏捷智力信仰加入伤害和需求 | `healthLevel` 等八个等级字段 |
| 装备与道具 | 左右手多槽、头身手腿、戒指、快捷栏，换装立刻改动作 | `CharacterInventoryManager`、`PlayerArmorManager`、`QuickSlotsUI` |
| 回复类治疗 | 喝药锁移动并持续回血或回蓝；治疗法术扣蓝；休息补满次数 | `FlaskItem`、`HealingSpell` |
| 敌人 AI 状态 | 待机、发现、追击、周旋、攻击、会放弃追击；Boss 转阶段 | `IdleStateHumanoid` 等五状态、`BossCombatStanceState` |
| 死亡与燃火循环 | 死亡留血迹，再死丢掉；休息设重生点并重置小怪 | `Death`、`AddSouls`、`CampFireInteractable` |
| 战斗 HUD | 三条条、灵魂、药瓶次数、锁定标记、敌人血条、Boss 血条 | `HealthBar`、`StaminaBar`、`FocusPointsBar`、`SoulCountUI`、`UIEnemyHealthBar`、`UIBossHealthBar` |

行为原文在 [`README.md`](README.md) 索引的九篇里。
