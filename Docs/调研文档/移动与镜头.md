# 移动与镜头

> **这篇写《黑暗之魂 3》本体，加上《艾雷德尔的灰烬》和《环印城》里，玩家怎么移动、怎么掉下去、镜头跟着谁。** 数值停在分档。帧数、秒数、米数对不上的地方标 **待核对**，不当成已经量过。

相关养成和装备见 [`角色与养成.md`](角色与养成.md)、[`装备与建造.md`](装备与建造.md)。挥击、格挡和命中见 [`战斗系统.md`](战斗系统.md)。

绿条是精力。下面精力指这一条。蓝条是施法和战技用的专注，细则放在战斗篇。

## 走、跑与冲刺

> **摇杆推多深决定走还是跑；按住闪避键才进入冲刺，冲刺一直扣精力。**

未锁定时，移动方向跟着镜头的水平朝向。锁定后，方向改成相对当前目标的前、后、左、右，角色面向目标。

| 输入 | 玩家看到的 |
| --- | --- |
| 轻轻推摇杆 | 慢走，不扣精力 |
| 推满 | 跑步，不持续扣精力 |
| 推满并按住闪避 | 冲刺，比跑步更快，按住期间持续扣精力 |
| 负重超过 100% | 只剩更慢的走，跑步和冲刺都起不来 |

冲刺中精力见底，冲刺停住，人回到跑步或慢走，要等精力回上一截才能再冲。起步至少要有一点精力；具体最低值 **待核对**。未超重时，跑步和冲刺的快慢不随负重分档再变一档。30% 以下走路是否比中量稍快，**待核对**。

攻击、翻滚、喝药、背刺、处决进行时，摇杆不改当前这一下的位移。死亡后移动停住。

## 四向翻滚与后撤

> **点一下闪避：有方向就是翻滚，没有方向就是后撤。** 未锁定时翻滚朝摇杆相对镜头的方向，可以是斜向，落点跟着这一下的方向。锁定后收成面对目标的前、后、左、右四向，见下一节。

翻滚扣一截精力。动作中段有一段身体碰不到伤害的窗口，末尾的起身又能挨打。窗口长度随负重当位变，见「负重当位」。窗口里刀、箭、法术打上去都不结算。窗口外同一下会扣血，并可能打出受击。

后撤是向后退一小步，位移比翻滚短，同样扣精力。它也有一段短于翻滚的无敌，精确帧数 **待核对**。后撤接轻攻击会变成后撤攻击，接招规则在 [`战斗系统.md`](战斗系统.md)。

翻滚和后撤的前中段不能再接一次翻滚或地面攻击。收招允许之后才能再滚、再砍。连续翻滚的精力花费会一次比一次高，中间停一停再滚会回到基础花费。每次加多少、间隔多久算「连续」，**待核对**。

精力正好是 0 时，翻滚和后撤都起不来。精力还剩一点但不够完整花费时，这一下往往会做出来并把精力打到空，随后有一段更长的空档才开始回复。这一点是否对所有武器和所有档位成立，**待核对**。

## 锁定时的闪避

> **锁定之后，闪避键加方向是朝目标坐标系的前后左右翻滚，角色继续面向目标。**

| 摇杆 | 结果 |
| --- | --- |
| 前 | 朝目标翻进去 |
| 后 | 背离目标翻出 |
| 左 / 右 | 横向翻，身体保持朝向目标 |
| 不推摇杆 | 后撤，退的是背离目标的那一侧 |

左右翻是绕着目标挪位，方便贴着它绕到侧面。四向翻滚和未锁定的斜向翻滚用的是同一套负重档，无敌窗口跟着档走，不因为锁定另开一档。

锁定中仍然可以边走边绕。走路时角色面向目标，横移是侧身步，后退是面对目标往后退。

## 跳跃、落地与落地攻击

> **跳跃从冲刺里起跳。从够高的地方落下时按下攻击，变成落地攻击。**

默认操作是冲刺中按下移动摇杆起跳。按键设置里可以改成冲刺中再按闪避。起跳扣一截精力。腾空期间不能按地面规则再翻滚。短跳落地是很短的落地，马上能走、能滚。

跳跃攻击是另一下：没有在冲刺中点摇杆的前提下，向前并按重攻击，人会跃起劈下去。冲刺中按重攻击，不少武器也会直接做这一下跳跃攻击。哪些武器另有独立的冲刺重击，**待核对**。这一下的伤害和霸体在 [`战斗系统.md`](战斗系统.md)。

从更高处落下：

- 短落差：普通落地，不扣生命。
- 更高：落地动作更重，硬直更长，并按高度扣生命。扣的是生命上限的一截，所以生命上限变高不会让致死高度跟着变高。
- 再高：直接死亡。见「掉落伤害」。

下落过程中按攻击，会做落地攻击（下落攻击）。高度不够时，玩家看到的仍是普通跳跃攻击。高度够时，武器朝下落点戳下去。打中脚下的人造成很重的一击；对方正倒在地上时，这一下可以接成处决。落在敌人身上时自己还扣不扣掉落伤害，**待核对**。

## 负重当位

> **状态页用当前装备重量除以最大负重，得到百分比。翻滚按这个百分比分四档。** 最大负重随提高负重的属性和部分戒指变。换装后下一滚立刻用新档。

算进重量的是身上穿着的防具、左右手的武器和盾、戒指。双手持握不会把重量除掉一半。

| 负重 | 翻滚和后撤 | 无敌窗口 | 精力 |
| --- | --- | --- | --- |
| 约 30% 及以下 | 滚得最远。整段翻滚用的时间和中量档差不多，所以地面上滑得更快 | 和中量档同一截。常见说法是这段比沉重档多出一帧，具体帧数 **待核对** | 回复按常速 |
| 约 30% 到 70% | 距离中等 | 同上，具体帧数 **待核对** | 回复按常速 |
| 约 70% 到不满 100% | 沉重翻滚，距离短，动作更慢。后撤也变慢变短 | 比上面两档略短。常见说法是少一帧，具体帧数 **待核对** | 回复大约慢两成，精确比例 **待核对** |
| 达到或超过 100% | 翻滚和后撤都起不来 | 没有闪避窗口 | 只能慢走；跑步、冲刺、跳跃一并失去。回复是否再慢一截，**待核对** |

每一档「翻滚这一下扣多少精力」是否不同，公开说法不一致，**待核对**。能看出来的消耗差别，是沉重档回复更慢，以及连续翻滚越滚越贵。

30% 和 70% 的边界有四舍五入：界面上正好停在整数时，实际档位可能差一点点。验收时用稍低于和稍高于这两个数各滚一次，看距离和沉重动作。

## 精力

> **停手一小段之后精力自己往上长。举盾期间长得明显更慢。绿花是临时加快回复，不提高上限。**

哪些动作扣精力：

| 动作 | 怎么扣 |
| --- | --- |
| 冲刺 | 按住期间持续扣 |
| 翻滚、后撤、跳跃 | 起手扣一截 |
| 轻攻击、重攻击、跑动攻击、翻滚攻击、后撤攻击、跳跃攻击、落地攻击、踢击 | 每一段出手扣一次 |
| 武器战技、施法 | 成功放出时扣精力，同时另扣蓝，见 [`战斗系统.md`](战斗系统.md) |
| 举盾挡下一击 | 按这一下的力气和盾的稳定度扣 |
| 爬梯子时挨打 | 按一下扣精力；见「梯子」 |

攻击的精力在挥出时扣，连段每一段各扣一次。同一段里连按不会把这一段再扣第二次。

精力不够时：

- 精力为 0：攻击、翻滚、后撤、跳跃、冲刺都不开始。
- 精力大于 0 但少于这一下的标价：很多近战仍会挥出，并把精力打到空，然后有更长的空窗才回复。是否每种动作都允许「剩一点就做」，**待核对**。
- 蓝不够时的施法失败是另一件事：人会做失败起手，扣一点精力，蓝不进负数，法术不出去。战技在后来的调整里，蓝见底仍能做出来但明显变弱；法术没有这条例外。调整编号 **待核对**。
- 举着盾时精力被打到 0：这一下破防，人进入可被处决的崩架，伤害按没挡住结算。

回复：

- 任何扣精力的动作结束后，先等一小段，条才开始上涨。砍完的空档比松开冲刺更久。具体秒数 **待核对**。
- 举着盾（或双手武器做成的格挡）时，回复大幅变慢。盾放下后才回到正常。
- 负重进入沉重档后，基础回复变慢，和举盾叠在一起更慢。
- 冰霜打满后的减益、剧毒，也会拖慢回复。见 [`战斗系统.md`](战斗系统.md)。
- 绿花是消耗品，吃下去一段时间加快回复。带苞的绿花是更强的一瓶。持续时间 **待核对**。
- 草纹盾之类的装备、绿花戒指，是穿上就在的被动，和绿花叠在一起。草纹盾在左手、人改成双手持右手武器、盾背在背上时，回复加成仍在。换成另一把左手武器就没了。
- 荣耀大盾一类的盾会明显压低回复，即使人不在挥刀。
- 温和祷告是战技回蓝，不走精力这条。
- 绿花和身体增益占同一个身体增益位：再吃另一种身体增益会把绿花顶掉。戒指和盾的被动不被它顶掉。

精力上限由耐力养成决定，见 [`角色与养成.md`](角色与养成.md)。上限变了，同一套动作的扣法不变，只是更能连着做。

## 梯子

> **靠近梯子按互动爬上去。往下按住闪避是滑下；停在梯上再按闪避是向梯外跳开。挨打扣精力，精力空了再挨一下会摔下去。**

上和下：摇杆朝梯的上下。爬的时候移动速度固定，不消耗精力来维持攀爬。爬的过程中精力回复变慢还是完全停住，**待核对**。

滑下：在梯子上按住闪避，同时摇杆向下，人贴着梯子快速下滑，到底才松开。只按闪避、摇杆回中，是中途跳下：人朝梯子外侧跃出，然后进入下落。滑到一半改成跳下，做法是松开方向再按一次闪避。

梯子上可以攻击：轻攻击朝上戳，重攻击朝下打。这两个用在和别人抢同一架梯子。打中对方会削对方精力；对方精力见底后再挨一下，就会脱离梯子往下掉。自己被打也是这套。单次很重的一击能否在精力没空时直接打下梯子，**待核对**。摔下去之后按高度结算掉落伤害，够高就是死。

《艾雷德尔的灰烬》和《环印城》里的梯子遵守同一套攀、滑、跳、受击，没有另开操作。

## 掉落伤害

> **短落差不扣血。中等高度按生命上限的比例扣血，所以堆生命不会提高「还能活」的高度。超过致死高度直接死，银猫戒指和静步也救不了。** 具体米数 **待核对**。公开讨论里有人把致死高度说成大约二十米，和「按属性、负重、是否余烬计算能活的高度」的说法并存，这里不采单方数字。

能感知到的分档：

| 高度 | 结果 |
| --- | --- |
| 低 | 落地无伤害 |
| 中 | 扣生命，落地硬直变长。扣血是上限的一截，余烬把上限撑大时，同一高度扣的数字也变大 |
| 致死 | 直接死亡，和当前生命剩多少无关 |

同一处岩架会不会扣血，还受敏捷、体力、当前装备重量影响。公式 **待核对**。

银猫戒指和法术静步去掉的是「本来不会致死」的那部分掉落伤害。致死高度本身不抬高。两部 DLC 的深谷也适用：看得到底不等于落下去还能活。

棱石可以事先扔下去听声音。发出惨叫表示这一落会致死。棱石按的是余烬后满生命的标准，未余烬或残血时，棱石不叫也可能被掉落伤害打死，这一点 **待核对**。

另有一类空坑是在落地之前就把人判死，人还在空中就死了。罪业城等深井、两部 DLC 的断崖里都有。这和「落地再算伤害」是两条规则。落地攻击打中脚下的敌人时，自己掉落伤害如何结算，**待核对**。

## 镜头

> **平时是绕着角色转的自由镜头。锁定把镜头交给一个目标。旅程中没有可以打开的大地图。**

### 自由镜头

右摇杆让镜头绕角色转。俯仰有上下限，转不到脚底。镜头撞上墙、柱和坡时会被推进来，避免穿进几何体。走路和跑步不会自动把镜头转到背后，方向一直由右摇杆决定。

### 锁定

按锁定，在面前一段距离、视线没被挡死的敌人里选一个。镜头转到能同时看着角色和目标的角度，角色战斗朝向跟着目标，移动改成相对目标的前后左右。

已锁定时，右摇杆左右切到下一个合格目标。再按一次锁定，主动解开。

锁定会丢失的情况：

- 目标死亡。
- 目标走出锁定距离。
- 中间被墙或地形挡住，持续到锁定维持不住。短时间擦到柱子不一定立刻掉，掉之前镜头会先被拉得很近。

解开之后回到自由环绕，停留在解开时的朝向附近。

大体型敌人有时锁点偏在身体某一处，或者根本锁不上。哪些怪属于这一类，**待核对**。

遮挡拉近不限于锁定：自由镜头贴墙同样会推进来。锁定时更明显，因为镜头要同时框住人和目标，中间一堵墙就会把镜头挤到角色肩上。

### 弓的瞪准和自由瞪准

弓、弩、大弓的瞪准是另一种镜头：双手持弓后按左手轻攻击进入，准星出现，人转向准星方向，移动变成慢走。射完或松开后，回到原来的自由环绕或锁定。部分大弓可以在瞪准里再放大视野，上下方向键是常见操作，是否每张弓都有，**待核对**。

锁定不代替准星。锁着目标直接射，箭常常朝身体中线飞，高低差会丢。要打高处或落点很远的目标，用瞪准里的准星。

自由瞪准指两件事：

- 弓已经进入准星，右摇杆（或鼠标）把落点从锁定目标上挪开。
- 望远镜：举起望远镜自由张望，施法会朝当前视线飞出去。这是法术的自由瞪准，和锁定点自动朝目标的施法分开。

弩可以不进入这套长拉弓，在左右手直接射击，详见 [`战斗系统.md`](战斗系统.md)。

### 没有大地图

旅途中打不开大地图，界面上也没有小地图。已经点燃的篝火在传送列表里按区域排成名字。认路靠场景、篝火名字和地上留言。两部 DLC 的区域同样如此。

## 姿态

> **姿态是角色演出用的一套动作，从姿态菜单里选。做的时候可以被打中打断。有一部分要做任务、捡物品或联机道具才出现在菜单里。**

开局菜单里只有一部分。新的姿态学到之后进入完整列表，也可以挂到快捷里。选中后角色做出对应动作，这段时间移动输入会把它打断，翻滚也会打断。

施放过程中没有无敌。挨打会取消姿态并进入受击，伤害照常结算。姿态是否额外提高受到的伤害，**待核对**。

和战斗相关的用法只有几条能看见结果：

- 在指定地点做出指定姿态，会触发场景。死后的龙之路是在消耗王庭往后的尸体上拿到姿态，到古龙山顶那块位置做出来，才会被送去古龙顶。没学会这个姿态，那个位置没有反应。
- 暗月忠诚一类姿态要在指定雕像前做出来，才能加入对应盟约。
- 看守墓场、暗月一类盟约的等级奖励里带姿态道具，交还誓约物品之后菜单里才有。
- 有的姿态在任务角色的过程中直接交给玩家，有的是地图上的尸体。具体哪一个从哪条任务来，名片级别的名单 **待核对**，避免把奖励和尸体搞混。

《艾雷德尔的灰烬》和《环印城》是否各新增了独立姿态，公开名单不齐，**待核对**。两部 DLC 里已经会的姿态用法不变：做的时候能被打断，任务和场景仍然认菜单里的名字。

火防女看到部分姿态会有反应，这是演出，不改变移动和镜头规则。
