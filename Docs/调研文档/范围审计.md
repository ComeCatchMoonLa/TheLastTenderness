# 调研范围审计（2026-10-08）

> 本文件不是又一篇系统调研，而是对九篇调研做一次「调研自己的范围」审计：覆盖面够不够、组织合不合适、哪些内容写错或写浅、哪些待核对项对本项目根本不必核。结论用来指导补缺、纠错和取舍。旧九篇保留，补缺写进 [`调研补遗.md`](调研补遗.md)；本文件只给判断和依据。

审计方法：①列出九篇全部章节，和《黑暗之魂 3》本体+两 DLC 的可操作系统全集逐项对照；②读每个疑似写浅的章节，回外网核事实；③对每条待核对项问「这个数字/名单影响不影响本项目排期，应该放资产还是放代码」。

## 一、覆盖结论：系统广度基本够，但有三类问题

九篇的章节结构已经覆盖 DS3 绝大部分可操作系统：移动、精力、四档翻滚、锁定、近战、战技、架势、成对、格挡、弹反、处决、霸体、异常、弓弩、三系法术、催化器、消耗品、药瓶、装备、注入、强化、护甲、戒指、弹药、属性、升级、重生、空虚、篝火、死亡、余烬、暗印、周目、三结局、门/梯/电梯/雾门/箱子/幻影墙、敌人 AI 全套、头目阶段、拟态、掉落、NPC、商店、任务、赦罪、九盟约、联机全套、留言血渍、姿态、HUD、菜单。

问题不是漏了整套系统（上一轮怀疑漏了耐久/掉落/迎击/诱导/NPC 召唤符——复查后这些章节**都存在**），而是下面三类：

### 问题 1：个别章节写得浅或写错（要纠错/补深）

| 章节 | 问题 | 事实依据 |
| --- | --- | --- |
| 装备篇「耐久度」 | 写法接近 DS1/2，漏了 DS3 的关键节奏：**武器每挥 5～10 次才掉 1 点**（不是每次挥都掉），**护甲只在挨打时掉**；月光大剑蓄力重击每次掉 4 点是特例 | wikidot Game Mechanics - Durability；From 官方手册也只写「坐火完全恢复耐久」 |
| 掉落「道具概率」 | 只写「按发现力掷一次」，没写清公式与无保底。公式是 **掉率 =（发现力/100）× 条目基础掉率**，发现力 100 时等于基础值、400 时 4 倍；每次击杀独立掷，失败不累计 | wikidot Item Discovery：Chance = (Discovery/100) × DropChance |
| 侍女涨价 | 已核 1.2→5 六档、卖出价不受影响，九篇里只在魔法篇买卖提了一句，角色交互篇商店没写 | wikidot General：prices increase for each death without absolution up to six times, no effect on sell price |
| 过量击杀 | 章节存在但具体倍数、适用边界标了待核对；外网结论不稳定（社区普遍引用约 +20%，Boss/坠落/异常磨死不吃，背刺处决是否算有分歧），维持待实机 | 与未入池一致 |

### 问题 2：调研有写、但需求文档没有承接（这是更要紧的缺口，不在本文件解决）

这些在九篇里是完整章节，但功能需求里没有对应 FR：耐久与修理（脚本无字段）、敌人掉落掷骰与发现力公式（脚本无）、过量击杀、突刺迎击与狮子戒、魅惑/引诱颅骨等诱导、头目门口离线可召的 NPC 召唤符、侍女涨价。**它们是玩家可观察的系统规则、不属于非目标里的「数值大全」，需求侧应当补 FR 或显式声明延后。** 这一条记给需求阶段处理，不在调研补遗里展开。

### 问题 3：待核对项混了三种东西，需要分开

九篇行内 **待核对** 约 330 处，混着：

1. **资产位数值/名单**（占多数）——逐把武器的精力、逐条法术秒数、逐只敌人视野、逐场头目倍率。项目规则明确「数值、曲线、引用放资产，动词放代码」，这类不该花外网核，[`待核对总表.md`](待核对总表.md) 已归为资产位。
2. **要实机的系统判定**（约 10 条）——精力 -60 跨档、打断扣蓝、瓶碎片当前剩余、电梯停层、落地自伤等，外网无定论，只能进游戏测，已进未入池。
3. **少数可由权威文字定论、但还没查的**——本轮补遗只处理这一类（见下）。

## 二、组织方式评估：不需要推翻重写

上一版授权「若组织很差可新建文件重写」。审计后的判断：**九篇的组织是合适的，不重写。**

- 九篇按「养成 / 建造 / 移动 / 战斗 / 法术道具 / 世界 / 场景界面 / 敌人 / 联机」切分，和游戏主循环、和需求目录、和代码 Manager 分层都对得上；读者能预测内容在第几篇。
- 每篇用「可观察结果 + 行内待核对 + 文末待核对清单」的写法，和仓库 `.cursor/rules` 的文档规范一致。
- 真正的毛病是个别章节浅、以及缺一份跨篇的系统补遗，不是结构错。推翻重写会丢掉这种可预测性，收益为负。
- 因此采用「保留九篇 + 新增 [`调研补遗.md`](调研补遗.md) 补深纠错」的方式；补遗只放**纠正旧句或旧文没写准**的内容，并在对应旧章节加一行指向补遗，避免两处各说各话。

## 三、本轮补遗要处理的清单

1. 耐久度：补「武器 5～10 挥掉 1、护甲仅挨打掉、特例月光大剑」，并明确坐火恢复、破了找安德烈/修理粉修未破/修理法术的边界。
2. 掉落概率：写明 Chance=(发现力/100)×基础掉率、独立重掷无保底；发现力加成来源已在角色篇，补遗只补公式。
3. 侍女涨价：在角色交互篇商店补「每死一次未赦罪涨价一档、最多六档、卖出价不变」。
4. 待验证项再过滤：把可由权威文字定论的从「待核对」里提出来核掉；确认剩余项按资产位/待实机分流。

不处理：过量击杀倍数、敌人逐只数值、联机逐场倍率（无定论或资产位）。
