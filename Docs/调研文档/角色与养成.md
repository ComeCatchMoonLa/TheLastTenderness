# 角色与养成

> **本体和两部资料片共用同一套角色规则。** 创角只决定起点；九项属性在防火女处逐点购买；灵魂等级一直往上加。装备槽、注入、强化和戒指的做法见 [装备与建造.md](装备与建造.md)。

本文写玩家在创角界面、状态页、篝火和战斗里能对上的规则。两部资料片是《艾雷德尔的灰烬》和《环印城》（界面译名以游戏内为准）。不写单件装备图鉴，不写剧情对白。帧数、成长曲线和费用公式拿不准就标「待核对」。

## 名词

| 本文用词 | 玩家看到的东西 |
| --- | --- |
| 生命 | 红色血条 |
| 精力 | 绿色条。冲刺、翻滚、跳跃、攻击、举盾承击都花它 |
| 蓝条 | 蓝色条。法术和武器战技花它 |
| 生命力 | 把生命上限抬高的属性 |
| 集中力 | 把蓝条上限抬高，并增加法术栏位的属性 |
| 耐力 | 把精力上限抬高的属性 |
| 体力 | 把负重上限抬高的属性 |
| 灵魂 | 持有的数字。升级、购物、强化都花它 |
| 灵魂等级 | 九项属性已经点过的总等级 |
| 空虚 | 暗印带来的虚化程度。影响外形，也影响空虚注入 |
| 余烬 | 一种临时强化状态。生命上限上浮，并打开联机 |

界面上的绿条在有的翻译里叫体力。本文把绿条叫做精力，把提高负重上限的属性叫做体力，避免和另外几作的叫法混在一起。

## 创角

> **创角交出四样东西：外形、名字、起始职业、一件葬礼赠礼。** 职业带出的是开局属性、装备和道具。之后九项都可以继续点。

### 外观

创角先选性别，再改身体和脸。能调的大致包括：

- 体型：身量、肩宽、肌肉这类整体比例。
- 脸：预设脸往上再调五官的形状和位置，以及瞳孔、肤色、皱纹、妆面、伤痕一类表层。
- 毛发：发型、发色、眉毛；男性还有胡须。

性别会改变默认体型和护甲在身上的轮廓。同一职业、同一套属性下，男女的生命、精力和面板伤害按同一套属性算。外形可以在后文罗莎莉亚处再改。创角编辑器的具体滑条数量待核对。

### 姓名

名字在创角时输入，长度有上限，部分符号会被拒绝。精确字数和禁用字符待核对。

罗莎莉亚的改造服务打开的是外形编辑。名字和起始职业不能在那里改。性别、脸和体型可以改。起始职业一旦定下，就会一直当作属性下限的来源，跨周目也带着走。

一个存档槽一个角色。槽的数量待核对。

### 起始职业

职业决定三件事：

1. 九项属性的初始整数，以及由此得出的起始灵魂等级。
2. 开局穿戴和放在包里的武器、护甲、法术、道具。
3. 重生时每项属性不能再往下压的下限。这个下限等于该职业的初始值。

加点本身没有职业锁。骑士可以一直点智力，魔法师可以一直点力量。软上限看的是属性点到了多少，不看职业名字。

十个职业的手感分工如下。起始灵魂等级和九项整数以创角界面为准；下表的等级是常见记忆，**整列待核对**。赤贫九项拉平、灵魂等级为 1，可以当作验算等级公式的锚点（见后文「灵魂等级」）。

| 职业 | 常见起始等级（待核对） | 开局偏向 | 开局装备的类型 |
| --- | --- | --- | --- |
| 骑士 | 9 | 生命、耐力、体力比较齐，力量和敏捷够用一把直剑 | 直剑、盾、一套中等偏重的甲 |
| 佣兵 | 8 | 敏捷更高 | 成对弯刀、较轻的甲 |
| 战士 | 7 | 力量更高 | 斧、盾、中甲 |
| 传令 | 9 | 信仰略高，带治疗祷告 | 矛、盾、护符或圣铃、一段治疗 |
| 盗贼 | 5 | 幸运更高 | 匕首、弓、轻甲 |
| 暗杀者 | 10 | 敏捷和智力都有一点 | 刺剑、法杖、一段魔法 |
| 魔法师 | 6 | 智力、集中力高，生命偏低 | 法杖、魔法、很轻的衣 |
| 火术师 | 8 | 智力和信仰同时有起步 | 火焰器具、火球、短柄近战武器 |
| 圣职者 | 7 | 信仰高 | 锤、奇迹器具、治疗祷告 |
| 赤贫 | 1 | 九项放在同一低点 | 木棒一类的钝器，护甲几乎没有 |

职业译名以创角界面为准。开局法术的正式名字、盾和甲的具体款式，属于开局包裹，不在这里列成图鉴。赤贫的剑和盾都要从后面再找。

职业附带的法术只要已经出现在法术列表里，就占用记忆规则，和后来买到的法术一样：要有空栏，要满足施放属性，在篝火处记忆。

### 葬礼赠礼

葬礼赠礼是开局多拿的一件道具，不改九项属性，不改灵魂等级。常见方向包括：一枚加生命上限的戒指、立刻回复的祝福、一颗火属性注入宝石、投掷用的火焰瓶、提高发现力的硬币、一根能变形的树枝。完整名单和官方译名**待核对**。也可以选择什么都不拿。

赠礼只在创角时领一次。丢掉或用掉之后，没有「再领一次葬礼」的菜单。

### 职业下限以后一直有效

防火女加点只能把某一项往上加，不能在那里把点数减掉。要把已经点上的属性搬去另一项，要去罗莎莉亚重生。重生可以降点，降到该职业的初始值为止。

因此两个灵魂等级相同的角色，如果出身职业不同，能分配的点数形状不一样：初始偏高的那一项，有一部分点数是「降不下去」的。赤贫九项起点相同，能调整的空间最大。

## 九项属性

> **生命上限看生命力，蓝条上限和法术栏位看集中力，精力上限看耐力，负重上限看体力。** 力量、敏捷、智力、信仰、幸运决定能不能正常挥武器、法术加成有多高，以及异常和发现力。

每升 1 级灵魂等级，只加 1 点到九项中的一项。状态页会预览这一下加完之后，生命、蓝、精力、负重和各类防御大概变成多少。

属性对伤害的影响，在武器和法术器具上用字母表示，从高到低大致是 S、A、B、C、D、E，没有加成时是一条横杠。字母会随强化等级和注入改变。字母到实际倍率的公式**待核对**。

### 生命力

生命力提高生命上限。点得越靠后，每一级多出来的生命越少。玩家经常讨论的变缓位置在二十多级、四十级、五十级附近，精确拐点和每一级的生命数**待核对**。

生命上限还会被这些东西再改掉，它们和生命力叠在同一个红条上：

- 余烬状态按一定比例抬高上限。精确比例**待核对**。
- 加生命的戒指、有的头甲特效。
- 祝福注入的武器在握着时缓慢回复当前生命。生命上限仍只看生命力、余烬和加生命的戒指。

红条归零即死亡。死亡规则里和灵魂有关的部分见后文。

### 集中力

集中力做两件事。

第一，提高蓝条上限。蓝条付给法术和武器战技。前期每一级增加得多，后面变少。精确曲线**待核对**。

第二，增加能同时记忆的法术栏位数。栏位按门槛跳跃，中间那些等级只加蓝、不加栏。圣女戒指和深渊戒指各再加 1 格，暗月戒指再加 2 格。（Fandom、Wikidot）

| 集中力 | 栏位数 |
| --- | --- |
| 9 及以下 | 0 |
| 10～13 | 1 |
| 14～17 | 2 |
| 18～23 | 3 |
| 24～29 | 4 |
| 30～39 | 5 |
| 40～49 | 6 |
| 50～59 | 7 |
| 60～79 | 8 |
| 80～98 | 9 |
| 99 | 10 |

有的法术占两格或更多。栏位够不够，按占用的格子总数算，占两格的法术要留出两格。

记忆在篝火做：从已获得的法术里往栏位里放。没放进栏位的法术不会出现在战斗切换里。

蓝不够时，法术是失败起手，蓝不会被扣成负数。武器战技不是失败起手：蓝见底仍能做出来，特殊效果变弱或没有，这一下花的精力更多。失败的法术那一下是否完全不扣蓝，**待核对**。

### 耐力

耐力提高精力上限。精力付给：

- 按住冲刺时持续扣除。
- 翻滚、后撤步、跳跃，各扣一次。
- 每一段轻击、重击、踢。
- 举盾吃下攻击时，按这一击的力度和盾的稳定度再扣。

精力在停止消耗一小段时间之后自动回复。举盾期间回复变慢。回复速度还能被戒指、盾的特效、绿花类消耗品改掉。

耐力对精力的增长在中后期明显变缓。常见说法是大约四十级以后几乎不再增加，精确拐点**待核对**。

负重上限不看耐力。负重看体力。

### 体力

体力提高能穿戴的最大重量。当前装备重量除以这个上限，得到负重百分比，再分成四档翻滚。四档对距离、精力和无敌时间的影响写在 [装备与建造.md](装备与建造.md)。

负重上限 = 40 + 体力：体力从 1 到 99 每一级固定多 1 点负重，不设软上限（体力 10 时 50、40 时 80、99 时 139）。加负重上限的戒指在这个值上另加，同一套装备的百分比随之下降，翻滚档位跟着变。

跌落伤害的决定因素见 [移动与镜头.md](移动与镜头.md)「掉落伤害」（高低差、生命上限、装备总重、负重上限、体力、技量六项）；直接减免靠技量，法术静步和银猫戒指只免非致死段。

### 力量

力量做三件事：

1. 满足武器和盾上写的力量需求。
2. 按武器面板的力量字母，提高物理伤害。重注入会把这个字母抬高。
3. 双手握住同一把武器时，参与需求和伤害计算的力量按 1.5 倍计，小数一律向下取整，结果不超过属性上限 99。因此有的武器单手性格不够、双手握就挥顺了；需求和伤害共用同一个 1.5 倍。细节见装备篇。

单手时，力量对伤害的增长在大约四十级和六十级附近变缓。双手因为有 1.5 倍且封顶 99，六十六级力量双手时恰好按 99 计，顶满力量加成。

力量不够时的可见惩罚（动作变糟、伤害大幅下降）见装备篇，智力、信仰、敏捷不够也走同一类惩罚。双手只能补力量，补不上敏捷和信仰。

### 敏捷

敏捷满足武器的敏捷需求，并按敏捷字母提高伤害。锐注入把这个字母抬高。刺剑、弯刀、刀、弓这一类往往更吃敏捷。

敏捷另外缩短法术的施放时间，快到某个点为止。常见说法是敏捷算到五十就不再加快吟唱。贤者戒指一类会提供「虚拟敏捷」，只拿来算施法速度，不拿来算武器需求，也不拿来算武器伤害。虚拟敏捷的数值和五十这个上限**待核对**。

部分施法器具只要握在另一只手，就能加快施法，不必真用它把法术放出去。这是器具特性，精确加快多少**待核对**。

### 智力

智力满足魔法、部分火焰术、部分暗渊法术和部分武器的需求。法杖面板上的「法术加成」主要随智力上升，魔法弹和魔法附魔都读这个数。

水晶注入把武器的伤害改成带魔法，并让智力字母变高。单纯注入也吃智力，同时让握着的武器缓慢回复蓝。

智力和信仰一起决定火术器具的法术加成，也决定混沌、暗这两类注入，以及一部分同时看两项属性的器具。常见配装会把两项都点到四十附近或六十附近再感觉变缓，精确拐点**待核对**。

### 信仰

信仰满足奇迹、部分火焰术、部分暗渊法术和部分武器的需求。圣铃和护符的法术加成主要随信仰上升。

雷注入把武器带上雷电并吃信仰。祝福注入让武器吃信仰，握着时缓慢回复生命，并对部分会再站起来的骸骨类有额外压制。压制的精确对象和倍率**待核对**。

护符常见的战技是让吟唱过程更难被打断。圣铃常见的战技是花一次蓝，然后缓慢回血，不是回蓝。器具差异见装备篇。

### 幸运

幸运提高三样玩家能在状态页或掉落里感觉到的东西：

1. 发现力。状态页有一个发现力数字，捡东西的稀有程度读它。发现力 = 100 + 幸运，戒指、头冠、金币等再各自加固定数：贪婪金蛇戒指 +50/+75/+100/+115、结晶老者刺剑每把 +50、贪欲者烙印 +100、生锈硬币 +50、生锈金币 +100（硬币持续 60 秒）；金蛇戒指与贪欲者烙印叠放时二者之间按乘法叠。
2. 出血和毒的积蓄，对那些面板上幸运字母高的武器更明显。血注入、毒注入、空虚注入都和这条有关。
3. 空虚状态下，空虚注入的武器会再提供额外幸运。规则见后文「空虚化」。

异常积蓄随幸运的变缓点常见说法在四十附近，精确拐点**待核对**。

### 属性带来的固定防御

状态页上，八种伤害各自有一个固定防御数字，另有一个吸收百分比。固定防御会随灵魂等级缓缓上升，九项各自贡献多少**待核对**。护甲主要把吸收百分比拉高，也会再加一点固定防御。

这两步在战斗里怎样扣血，见后文「伤害类型」。

### 属性与四条异常抗性

状态页另外有四条抗性：出血、毒、冰霜、咒死。抗性越高，别人往你身上堆这些条就越慢。护甲会加一大截，属性加点会加底子。能打满的状态是五条：出血、中毒、剧毒、冰霜、咒死。剧毒和中毒共用毒这一条抗性，解药不同，见后文「五种异常」。

哪一项属性主要加哪一条抗性，公开讨论里常见的对应还不稳定，**下表待核对**：

| 抗性 | 常被归到的属性（待核对） |
| --- | --- |
| 出血 | 耐力、幸运 |
| 毒 | 体力 |
| 冰霜 | 生命力 |
| 咒死 | 多项都有一点，主项未定 |

幸运同时让你自己更容易把别人打出出血。点幸运会把「造成出血」和「抵抗出血」一起往上抬，净结果看武器和对手。

### 玩家能感觉到的变缓

同一套字母下，属性从很低点上来，伤害涨得快；过了中段，再点一级，面板涨得少。这就是软上限。它是成长曲线的形状，菜单里没有单独的「软上限」一栏。

| 属性 | 玩家用来判断「再点也瘦了」的常见位置 | 精确拐点 |
| --- | --- | --- |
| 生命力 | 二十多、四十、五十附近，生命增量明显变小 | 待核对 |
| 集中力 | 蓝量逐渐变瘦；栏位只在门槛上跳 | 待核对 |
| 耐力 | 大约四十级后精力几乎停涨 | 待核对 |
| 体力 | 负重每级固定 +1，到 99 都不变瘦 | 已核对：40 + 体力，无软上限 |
| 力量 | 单手约四十和六十；双手六十六顶满 99 | 双手 1.5 倍向下取整已核对；单手拐点待核对 |
| 敏捷 | 武器伤害的变缓点，外加施法速度的封顶 | 待核对 |
| 智力、信仰 | 法术加成约在四十和六十附近变瘦；火术看两项之和 | 待核对 |
| 幸运 | 发现力和异常约在四十附近变瘦 | 待核对 |

超过这些位置仍然可以点，仍然会计入灵魂等级，只是单项收益变小。等级本身还会抬高固定防御。

## 灵魂与等级

> **灵魂是持有的一串数字。灵魂等级是已经购买过的属性点总和。** 等级越高，下一级越贵。加点只在防火女那里做。

### 灵魂从哪来，死亡时掉什么

敌人、首领和可消耗的灵魂道具提供灵魂。道具要在物品栏里使用，数字才会进入「持有灵魂」。没使用的灵魂道具、没兑换的首领魂魄，待在背包里。

死亡时发生的是：

- 当前持有的灵魂数字留在死亡地点，角色在上次休息的篝火复活。
- 走回去接触那一摊，数字回到身上。
- 在拿回来之前再次死亡，上一摊消失。
- 在篝火休息、传送，不会把那一摊清掉。
- 已经花掉的灵魂不退。背包里的灵魂道具和首领魂魄不掉在地上。

有的戒指在死亡时保住这笔灵魂，戒指自己碎掉，之后要再获得一枚。这属于装备篇里的戒指类型。

### 灵魂等级

灵魂等级 = 九项属性之和 − 89。赤贫九项都是 10、和为 90，等级为 1，可以验算这个常数；9×99 = 891，减 89 得最高等级 802。

出身职业不同，创角当下的灵魂等级就不同，因为初始属性之和不同。之后每在防火女处确认一次加点，等级加 1。

约尔提供的免费升级同样加灵魂等级和一项属性，并且种下暗印。那是等级，只是不收灵魂。见「空虚化」。

### 升级消耗随等级上升

下一级的灵魂价格只看当前灵魂等级，不看你点的是力量还是信仰。升到 L 级的费用（L≥12）= 0.02L³ + 3.06L² + 105.6L − 895，小数截尾；L=2～11 是固定数列 673/689/706/723/740/757/775/793/811/829（L=12 公式给出 847，与数列后的表接上）。早期很便宜，后期一级的价格会高到需要专门去打灵魂（如 40 级 9505、80 级 37377）。

状态页在确认前就会把价格和加点后的生命、蓝、精力、负重显示出来。魂不够时无法确认。

重生不改变灵魂等级，所以重生也不会把「下一级有多贵」调低。免费升级把等级抬高之后，下一注正常升级会按新等级计价。

### 防火女处加点

传火祭祀场的防火女负责购买等级。流程是：

1. 和她交谈，选择升级。
2. 选一项属性，看预览。
3. 付出这一级的灵魂，确认。
4. 灵魂等级加 1，该项加 1，立刻反映在生命、蓝、精力、负重和武器面板上。

她不在场时，这处升级不可用。是否另有替代的加点处，**待核对**。篝火本身不能购买等级。

把特定的灵魂交给她之后，她的菜单里会多出一项：清除暗印和空虚。费用等于从当前灵魂等级起连续升级 N 次的魂量之和，N 是身上的暗印枚数（最多 8 枚，见「空虚化」），即按上文升级费用曲线把接下来 N 级的价格相加。这是系统服务，后续结局不在本文展开。药瓶次数和回复不经过她。

## 重生与改造外观

> **罗莎莉亚用苍白舌头做两件服务：把现有属性点重分配，以及重做外形。** 重生次数有限。灵魂等级保持不变。

### 重生

重生的规则：

- 每次消耗一枚苍白舌头。
- 灵魂等级不动。你只能把已经拥有的点数挪到别的属性上。
- 任何一项都不能低于出身职业的初始值。
- 每个周目重生和改造一共五次。进入下一周目后次数恢复。
- 预览之后才确认。确认前退出，舌头不扣，次数不减。

重生不移除暗印，不改变空虚程度，不退回已经强化的武器，不遗忘已经学会的法术。

把舌头交给她升盟约位阶，是另一条菜单。拿去重生的那枚舌头是否同时计入盟约，**待核对**。

### 改造外观

同一地点可以用舌头重做外形：性别、体型、脸、肤色、发型。不能改名字，也不能改出身职业。是否每一条创角滑条都在，**待核对**。

改造同样消耗舌头，和重生共用每个周目那五次。

改造不改变九项属性，也不改变职业下限。

## 空虚化

> **暗印留在灵魂上。每死一次，空虚程度按印的数量增加。空虚改外形，并让空虚注入的武器额外提供幸运。**

### 暗印怎样种下

有一条不收灵魂的升级，约尔可以做五次。每次灵魂等级加 1，玩家在升级界面自选一项属性加上，同时得到一枚暗印。第一次在空虚 0 就能做。之后要空虚升到 2、6、12、15，才会再出现下一次。做满五次后这条服务结束，身上有 5 枚印。终局窃火还要在亚诺尔隆德与安里举行婚礼，仪式后再得到安里身上的 3 枚暗印，身上合计 8 枚，才进入窃火结局的旗标。（Fandom、Wikidot）

暗印是角色身上的计数，会显示在状态相关的界面里。它随着角色进入下一周目，除非被防火女的付费服务拿掉。

### 死亡如何增加空虚

身上有暗印时，每次死亡增加的空虚等于当时的暗印枚数，所以两次免费升级之间要先死，把空虚堆到下一档。（Fandom、Wikidot）空虚有上限，常见上限是 99，**待核对**。

没有暗印时，死亡不会往上加空虚。已经堆高的空虚，在印被移除时一并清掉。

### 外形

空虚低的时候，皮肤发灰、面容干瘪一点点。空虚升高后，脸变成明显的虚化亡者，身体也更枯。头盔可以挡住一部分，脸仍会露在对谈和部分头盔外面。

这层外形和创角脸叠在一起，认得出是同一个人。它不改属性面板上的九项原始点数。额外幸运是武器提供的，见下一节。

### 和空虚注入、幸运的关系

空虚注入的武器仍然是物理伤害，面板上出现幸运字母。空虚达到 15（即已经空虚化）时，**当前握在手上的**这类武器按强化等级直接附加幸运：+0 加 2，+1～+4 加 3，+5～+9 加 4，+10 加 5。左右手各握一把就叠加到最多 +10；幸运本身已到 99 时不再增加。备用槽里的不算。

额外幸运直接写进状态页的幸运数字，并进发现力、出血和毒的结算。收起武器或把空虚清零，这截加成消失。

未注入、重、锐等其他注入不会因为你空虚就多给幸运。血注入本身吃幸运，但它不提供「因空虚而额外增加的幸运」，除非武器同时走空虚这条注入。一把武器只有一种注入。

有的戒指只遮住虚化外形，暗印、空虚数值和幸运加成都还在。那是外形开关，放在装备篇的戒指里。

### 解除空虚的途径

按系统效果分，三条路不一样：

| 途径 | 空虚程度 | 暗印 | 虚化外形 | 之后死亡 |
| --- | --- | --- | --- | --- |
| 使用净化石 | 回到 0 | 还在 | 恢复 | 再次按印的数量增加空虚 |
| 石像上的付费解除 | 回到 0 | 还在 | 恢复 | 同上 |
| 防火女清除暗印 | 回到没有印的状态 | 全部移除 | 恢复 | 不再因为死亡增加空虚 |

净化石是消耗品，用掉一枚即生效。石像那一项解除空虚，另收灵魂。同一座石像还提供「赦免」：清除你对非敌对角色造成的敌对标记，费用是灵魂等级 ×1000。

防火女的清除要先把一枚特定灵魂交给她，菜单里才会出现。费用等于当前等级起连续 N 次升级（N=暗印枚数，最多 8）的魂量之和，算法见上文「防火女处加点」。付完之后免费升级种下的印没了，虚化加成也没了。这条路线的剧情分支本文不写。

只遮外形的戒指不在这张表里。它不治疗。

## 法术记忆

> **法术先学会，再在篝火放进栏位，战斗中才能切换着放。** 栏位数量看集中力。威力看器具面板上的法术加成。

三个学派：

| 学派 | 主要属性 | 器具 |
| --- | --- | --- |
| 魔法 | 智力 | 法杖 |
| 奇迹 | 信仰 | 圣铃或护符 |
| 火焰术 | 智力和信仰一起 | 火焰器具 |

暗渊是伤害类型，也是一批法术的倾向，不是第四个学派。它占用的栏位和所属学派的器具一致：暗渊魔法用法杖，暗渊奇迹用圣铃或护符。暗渊火焰用火焰器具。

获得法术的途径包括：商人购买、法术书交给商人后解锁新货、首领魂魄在王座兑换、盟约位阶奖励。书和灵魂只决定「学会没有」。学会之后留在列表里，跨周目还在。周目是否收回法术书本身，见「新游戏周目」，标了待核对。

施放条件：

- 要装备对应器具。
- 要已记忆，并且战斗中选中这一条。
- 要付得起蓝。
- 属性没达到法术或器具需求时，仍然可能放得出来，但威力会差一截。惩罚幅度**待核对**。

同一时间记忆的总格数不能超过集中力给出的格子。篝火休息时可以重配，不必再付灵魂。

法术加成这个数字涨上来之后，抛射法术、武器附魔法术、治疗法术的效果一起变强。治疗具体回多少还看法术本身。附魔只能加在允许附魔的武器上，规则在装备篇。

## 药瓶

> **红瓶回生命，蓝瓶回蓝。瓶碎片增加两者一共能喝的次数，未死人骨片加强两者每一口的回复。** 次数在铁匠安德烈处分配。

角色有两只瓶：

- 红瓶：喝下去之后在一段时间内回复生命。被打会打断后续回复。
- 蓝瓶：回复蓝，同样是喝下去的一次配额。

成长分两根线：

1. 瓶碎片交给传火祭祀场的铁匠安德烈，提高红瓶和蓝瓶共享的总次数。开局只有血瓶，三口。在祭祀场拿到灰瓶后，总次数变成四，其中一口在灰瓶上。之后每交一片加一口，加到十五口为止。再交没有效果。世界上各捡一次，商店不能无限购买。

## 余烬

> **余烬是一层临时的生命上限，死了就掉。** 它同时是能否召唤、能否被入侵的开关。

使用余烬物品，或在没有余烬时击败首领，会进入余烬状态：

- 生命上限提高 30%，血条上多出一截。
- 当前生命立刻补到新的上限；击败还会发放余烬的首领时同样补满。
- 可以召唤协助，也可以被入侵。联机细则不在本文展开，这里只记下它挂在余烬状态上。

死亡清除余烬，生命上限回到生命力和戒指给出的数值。在篝火休息不清除余烬。已经处于余烬时余烬物品根本不能使用：不会再消耗一个，也不回血、不叠上限，头目已死再杀一头也不叠。余烬把生命上限提高 30%，使用当下把生命抬到新上限。

两部资料片不改变余烬的算法。资料片首领同样可以在你没有余烬时，用击败来重新点亮它。

## 伤害类型

> **一次攻击先按伤害类型拆开。每一类先过固定防御，再过吸收百分比，然后加总扣生命。** 异常是另外四条蓄积槽，蓄满才发作。

### 八种要分别减的伤害

物理分成四种子类，元素和暗渊各算一类。状态页和护甲、盾的说明都按这个列：

| 类型 | 玩家怎样区分 |
| --- | --- |
| 普通物理 | 没有特别标成打击、斩击、突刺的物理 |
| 打击 | 锤、部分斧和棍，砸在盔甲上往往更痛 |
| 斩击 | 弯刀、多数横斩 |
| 突刺 | 矛、刺剑、不少直剑的重击 |
| 魔法 | 法术和水晶注入的那一段 |
| 火焰 | 火术、火注入、混沌注入的那一段 |
| 雷电 | 雷注入和雷属性奇迹的那一段 |
| 暗渊 | 深、暗注入和暗渊法术的那一段 |

同一把武器的轻击和重击可以是不同的物理子类。例如轻击斩、重击刺。盾和甲对这四种子类的吸收可以不一样，所以同一套甲，被锤打和被刀砍，减掉的比例不同。

注入和附魔经常让一次命中同时带物理和一种元素。两种都要走完整的两步，再相加。

### 吸收和固定减伤是两步

对未举盾的命中，每一种伤害单独计算：

1. **固定防御。** 用攻击这一类的攻击力，对上防守方这一类的固定防御。攻击力比防御高很多时，这一步削掉的比例较小。攻击力接近或低于防御时，削掉的比例变大。所以很小的一下，或者被拆成两段的伤害，会在这一步损失更多。
2. **吸收。** 把上一步剩下的伤害，乘上「1 减去该类吸收」。吸收是百分比，来自四件护甲、有的戒指，以及举盾时盾自己的吸收。

各类型算完之后加总，成为这一下扣掉的生命。

固定防御曲线的分段系数**待核对**。四件护甲（和戒指等来源）的吸收在状态页按逐件乘法合成总百分比：总吸收 = 100×(1−(1−a1/100)(1−a2/100)…)，标准、打击、斩击、突刺四类各自独立，见 [`装备与建造.md`](装备与建造.md)「护甲」。玩家验收时以状态页上的总吸收为准。

举盾再插进额外的一层，只对来自正面的攻击：

- 盾上该类吸收决定还能漏进多少血。物理吸收很高的盾，物理几乎不漏血，但精力照扣。
- 扣多少精力，看这一击的冲击和盾的稳定度。稳定度越高，同样一击扣的精力越少。
- 精力不够付这一下，举盾崩开，人进入可被处决的破防，伤害按没挡住来结算。破防瞬间漏进的那一截，护甲吸收是否仍然生效，**待核对**。
- 从背后或侧面打来的攻击，不吃盾的这层吸收。

弹反成功则这一下不按普通命中扣血，对方被弹开并在短时间里可以被处决。弹反和举盾是两种结果。

环境伤害（毒沼、岩浆、跌落、诅咒喷吐里属于直接扣血的部分）不走武器的弹反。跌落是否完全不吃护甲吸收，**待核对**。

### 分裂伤害为什么往往更瘦

一次 400 的纯物理，固定防御只吃一次。一次 200 物理加 200 火焰，固定防御吃两次，每次都按「攻击不那么高」的那一档去削。所以面板上两行数字加起来差不多时，打在有防御的人身上，往往是纯物理留下更多血损。

吸收仍然各算各的。对方火焰吸收很低时，分裂里的火焰段会讨回一部分便宜。选择注入，就是在「多一种伤害类型」和「每一种都被固定防御削一次」之间做取舍。

### 五种异常

异常不占用上面八类的吸收。它们各自有一条蓄积槽。状态页上的抗性是四条：剧毒和中毒共用毒抗。抗性降低每一击推进的速度。槽会在停止挨打之后慢慢退，退的速度**待核对**。

| 异常 | 蓄满之后 | 怎样结束 |
| --- | --- | --- |
| 出血 | 按目标生命上限的一个比例，再加一段固定值，立刻扣血。比例和固定值**待核对**。然后槽清空，需要重新积 | 槽没满时喝红苔清掉积蓄。蓄满后那一截血已经掉了。身上的蛆用火或火把清 |
| 中毒 | 在一段时间里持续扣生命。每跳伤害和总时长**待核对** | 等结束，或使用紫苔。开花紫苔也能清 |
| 剧毒 | 持续扣血更重，并拖慢精力回复 | 开花紫苔。普通紫苔清不了剧毒 |
| 冰霜 | 立刻扣一截血，并在一段时间里让吸收变差、精力回复变慢。数值和时长**待核对** | 蓝苔清积蓄，也能解已经发作的冰冻。受到火焰伤害可以提前解除已经发作的这层状态 |
| 咒死 | 蓄满则当场死亡 | 未满时离开来源，槽慢慢消退。祝福能在灌满前清掉这条槽。蓄满没有「先死再喝药救回」的治疗 |

出血武器、血注入、涂出血的消耗品，都是在堆同一条槽。毒和冰霜同理。咒死主要来自少数敌人的攻击，玩家武器几乎不把咒死当作输出手段；若有例外，**待核对**。

冰霜被火焰提前解除，指的是已经发作的那层减益。火焰伤害能否把尚未蓄满的冰霜槽也清零，**待核对**。

## 命中加成

> **普通命中按攻击力走两步减伤。另外几类命中用武器上的突刺计点做额外倍率：背后的背刺，以及弹反或打崩盾之后的处决。**

### 突刺计点

武器面板上有一个暴击或突刺计点。匕首、刺剑通常高，大锤、特大剑通常低，默认值常见是 100。计点影响背刺和处决的伤害，不影响普通轻击那一下的倍率。计点怎样乘进最终伤害，公式**待核对**。

物理子类里的「突刺」是伤害类型，和这个计点同名不同事。矛的普通轻击是突刺类型，走吸收，不自动变成处决。

### 背后

从目标背后贴住并使用轻击，可以进入背刺：双方锁进一段动画，结算一次，伤害使用当前武器的攻击力，并吃突刺计点。

能进这套动画的，主要是有近战挥击的武器。鞭、弓、弩、法杖做不出背刺动画。盾击和踢按普通命中结算。距离或角度差一点点，这一下就会落成普通轻击。精确的角度和距离**待核对**。

背刺发生时，对方的举盾和普通霸体都不拿来减这次伤害。无敌帧仍然优先：身体没被这下判定碰上，动画就不会开始。

### 弹反或破防之后的处决

两种打开方式：

1. **弹反。** 用带弹反战技的盾、匕首或拳头，在对方攻击碰上的短窗口里成功弹开。对方眩晕一小段。这时在身前轻击，进入处决动画。
2. **破防。** 把对方举盾的精力打空，或者用踢、战技、重击把盾打崩。崩开之后同样可以在身前轻击进入处决。

处决同样吃当前武器的突刺计点和攻击力，锁动画，结算一次。计点和背刺是否共用完全相同的公式，**待核对**。

鞭没有处决动画。空手和部分拳套有，伤害按它们自己的攻击力和突刺计点算。

从高处落到目标身上的下落攻击有额外伤害。它是否读取突刺计点，**待核对**。

### 突刺迎击

还有一种不进动画的加成：使用突刺类型的攻击，打在对方正在出招的身体上，伤害提高。矛、刺剑、带突刺重击的直剑最常用到。提高的基础幅度**待核对**。专门的戒指会再放大这一段，见下一节。

迎击单独结算：对方不锁进动画，只是这一下更疼。它仍然走八类伤害的两步减伤。

### 用来举例的戒指

只举类型，不列戒指图鉴。

| 类型 | 玩家能感觉到的变化 | 例子 |
| --- | --- | --- |
| 放大处决和背刺 | 同样的背刺或处决，扣血明显变多 | 大黄蜂戒指 |
| 放大突刺迎击 | 突刺攻击打在对方出招中时更疼；普通砍中、背刺动画不靠这枚 | 狮子戒指一类 |

大黄蜂戒指对背刺和处决的倍率**待核对**。它对普通轻击没有那一档加成。它是否也放大下落攻击，**待核对**。

这些戒指占装备篇里的戒指槽。四枚槽的规则不在这里重复。

## 盟约位阶

> **盟约是角色身上的一条平行等级。** 上交该盟约的信物升阶，升满后继续上交不再升。换盟约会把当前生效的盟约换掉，已经升过的阶保留。

每个盟约有自己的信物和阶数。有排名的盟约按累计上交分两档：10 和 30。第二档是累计交满 30，不是在 10 之外再交 30。青教没有这两档。升满后继续上交不再升。换盟约会把当前生效的盟约换掉，已经升过的阶保留。《环印城》有教堂枪兵这一条盟约，上交仍是这两档。

升阶的结果通常是：领到该盟约的一枚戒指、一个法术或一件武器，各领一次。这些报酬进入背包之后，规则就和普通装备、法术一样，不要求你一直停在该盟约里才能使用。个别报酬是否必须在盟约中才发动，**待核对**。

盟约同时改联机时的召唤阵营和入侵规则。那一部分只在这里记一句：位阶和「现在加入的是哪一个盟约」是两个状态，战利品和自动召唤读的是后者，已经领过的奖励不收回。

资料片没有把九项属性改成另一套，也没有新的第十项属性。资料片盟约若存在，仍走「交信物、升阶、领一次报酬」。是否真有资料片独占盟约，**待核对**；没有的话，资料片只是增加了可上交的战场和报酬物品。

## 新游戏周目

> **进入下一周目后，敌人的生命和伤害上升，角色等级和已经拥有的装备留下。** 世界进度收回。键类道具里哪些被收回，有的能确定，有的待核对。

通关结局之后，玩家自己选择何时开始下一旅程。选择之前可以继续留在当前周目，把没打完的区域和两部资料片打完。开始的菜单位置在传火祭祀场的篝火，精确选项文字**待核对**。

### 敌人

每一周敌人的生命和造成的伤害都提高，掉落的灵魂也提高。提升大约到很后面的一周停滞，常见说法是加到第七次新周目为止。精确倍率，以及停在旅程几，**待核对**。

敌人的吸收、异常抗性是否一起提高，**待核对**。两部资料片里的敌人跟随当前旅程，算法相同。

部分拾取物会变成更强一档的戒指（同名戒指的加一级、加二级）。再往后，《环印城》里还能在首周就拿到加三级的版本。加三级是否只存在于资料片、基础周目的加一级加二级从第几周开始替换，**待核对**。规则上能确定的是：捡到的是「这一周该出现的那一档」，已经握在手里的低档戒指不会被自动升级。

### 角色保留什么

下面这些跟着人走，不随世界重置：

- 外形、名字、性别、出身职业及其属性下限。
- 灵魂等级和九项当前值。
- 持有灵魂、背包里的灵魂道具、还没兑换的首领魂魄。
- 武器、护甲、戒指、弹药、消耗品，以及它们的强化等级和注入。
- 已经学会并留在列表里的法术，已经升过的盟约位阶。
- 药瓶的总次数和骨片强化等级，以及你上次分配的红蓝比例。
- 余烬是否还亮着：若是在余烬状态进入新周目，是否保持，**待核对**。按角色状态一般会保持，死亡才会灭。
- 暗印和空虚程度。
- 已获得的手势。

### 世界重置什么

下面这些按新的一周重新来：

- 敌人、首领重新出现，捷径关上，要再开。
- 篝火要重新休息才会回到传送列表。传火祭祀场是例外，人从这里出发。这个传送列表是否真的全清，**待核对**，按一次新的旅程来写。
- 地面上的宝箱、矿石、骨片、碎片可以再拿。已经买进等级的药瓶强化不因此倒退。
- 商人、任务角色回到他们在这一周的起始位置。周目不沿用上一周的对话进度。
- 敌对标记是否保留，**待核对**。赦免和虚化是角色状态，倾向保留到你主动去清。

### 键物和重要道具

键物指开门、解锁铁匠安德烈工艺、解锁商人货单、推进角色服务的那些不可当作普通消耗品堆叠的道具。

| 项目 | 周目规则 |
| --- | --- |
| 已经强化好的武器和护甲 | 保留，等级不掉 |
| 包里还没花掉的矿石和宝石 | 保留 |
| 地上没捡过或将再次刷新的矿石 | 新周目重新出现。板类每周目仍然很少，枚数**待核对** |
| 药瓶碎片、骨片已转化为等级的部分 | 保留等级；地上的实物刷新 |
| 已学会的法术 | 保留 |
| 用来解锁商品的法术书、炭火 | 是否从背包收回、铁匠安德烈菜单是否因此收起注入类别，**待核对** |
| 各种钥匙 | 收回，门重新锁上。个别钥匙是否例外，**待核对** |
| 交给防火女的那枚灵魂（开启清除暗印的服务） | 服务是否在新周目还留在菜单里，**待核对** |
| 首领魂魄 | 背包里没用掉的保留；上一周已经兑换或消耗的不会自动补回。新的一周再击败首领，会再得到一次 |
| 王座兑换资格 | 人还在王座上就能继续兑。世界重置不会把已经兑到手里的武器收回 |
| 资料片入口 | 上一周已经去过，新周目是否还要重新满足进入条件，**待核对** |
| 盟约位阶 | 保留 |
| 罗莎莉亚的剩余重生次数 | 按「新周目恢复满次数」理解，精确**待核对** |
| 暗印免费升级是否还能再做一轮 | **待核对**。暗印本身如果还在，不会因为新周目自动消失 |

炭火和注入的关系是：炭火解锁的是铁匠安德烈菜单里的类别。就算新周目把炭火收回，已经做在武器上的注入也不会褪掉。没解锁时，只是不能把下一把武器改成那一类。这一段里「会不会收回」仍待核对，武器上的注入会留下这一点可以确定。

## 待核对清单

创角与等级：

- 外观滑条的具体项数；姓名长度和非法字符。
- 十个职业的起始灵魂等级和九项初始整数。赤贫九项拉平且等级为 1，用作锚点。
- 葬礼赠礼的完整名单和译名；存档槽数量。

属性与资源：

- 生命力每一级的生命。（余烬把生命上限提高 30% 已核对。）
- 集中力的蓝量曲线。
- 耐力对精力在大约四十级后是否停涨。
- 八种固定防御里，九项各自的权重。
- 出血、毒、冰霜、咒死分别主要随哪项属性上升。
- 力量、敏捷、智力、信仰、幸运的单手伤害拐点；敏捷加快施法的封顶点；贤者戒指的虚拟敏捷。（双手 1.5 倍向下取整、66 力量顶满 99 已核对。）
- 法术在属性不足时的威力惩罚。

空虚、重生、服务：

- 重生用的舌头是否计入盟约位阶。
- 空虚上限是否为 99。
- 石像解除空虚（解咒）的费用公式。（空虚武器按强化等级附加幸运、备用槽不计、状态页幸运数字直接变高，已核对；赦免 = 等级×1000、清除暗印 = 接下来 N 级费用之和，已核对。）
- 防火女不在时有没有第二处加点。

伤害与命中：

- 固定防御曲线的分段系数。（护甲吸收逐件乘成总百分比的公式已核对，见装备篇。）
- 破防那一下漏血时，护甲吸收是否仍生效；跌落是否吃吸收。
- 出血的生命比例和固定值；毒的时长和每跳；冰霜发作后的伤害、吸收下降、精力回复下降和时长；火焰能否清掉未满的冰霜槽；咒死槽的消退速度。
- 突刺计点进入背刺和处决的公式；二者是否同一条公式；大黄蜂戒指的倍率；下落攻击是否吃计点和大黄蜂；狮子戒的迎击倍率。
- 背刺所需的精确角度和距离。

药瓶与周目：

- 哪些敌人会回一口药。
- 敌人血量和伤害在每一周的倍率，以及停在第几周；吸收和异常抗性是否跟着涨。
- 戒指加一级、加二级从第几周替换；加三级是否只在《环印城》。
- 新周目是否保持余烬；篝火传送列表是否全清；敌对标记是否保留。
- 炭火、法术书、钥匙哪些被收回；清除暗印的菜单是否还在；资料片入口要不要重新触发；暗印免费升级能否再做一轮。瓶碎片和未死人骨片不能在商店无限购买。
- 个别盟约报酬是否必须停留在该盟约才生效。
