# 需求文档

> **本文档是《黑暗之魂 3》本体与《艾雷德尔的灰烬》《环印城》的代码相关功能的复刻目标。** 成功时，玩家能亲手走通这些系统里可观察的行为。排期仍以 [`../开发计划/README.md`](../开发计划/README.md) 为准。本次只落需求，不改计划，不另起版本号，不开工。

## 阅读顺序

1. 先读调研。目录在 [`../调研文档/README.md`](../调研文档/README.md)。正文按 [`范围.md`](../调研文档/范围.md) 索引的九篇来：角色与养成、装备与建造、移动与镜头、战斗系统、魔法与道具、世界与篝火、界面与场景交互、敌人与头目、角色交互与联机。数值、门槛和次数拿不准时，需求写「与调研中待核对项一致」。
2. 再读本目录。旧编号是先前窄切片，保留原文。新编号补完整游戏里那一批还没写入的系统。每条标题下标 **当前已有** 或 **待补**。收尾版本把这一条的可观察结果做完的，标 **当前已有**。只做了一截的仍标 **待补**，落点写明哪一截已经在。
3. [`../代码分析/入口对照.md`](../代码分析/入口对照.md) 回答仓库里有没有入口。条目标记以本目录各条标题下的状态为准。对照里的缺口不拿来把已经收尾的条改回待补，也不拿来删掉完整游戏里的系统。
4. [项目目标](项目目标.md)、[非目标](非目标.md)、[验收方式](验收方式.md)。

## 调研已写、需求待承接的系统（2026-10-08 范围审计）

调研文档里已有完整规则、不属于非目标，但功能需求还没有对应 FR、`Assets/Scripts/` 也未实现。补 FR 或显式声明延后前，先在此登记，避免遗漏：

- 装备**耐久与修理**（消耗节奏、30%/0 两档、坐火/铁匠/修理粉/修理法术四条恢复途径；调研见《装备与建造》「耐久度」）
- 敌人**掉落掷骰与发现力公式**（实际掉率 = 发现力/100 × 基础掉率、独立重掷无保底）与**过量击杀**额外灵魂（倍数待实机）（调研见《敌人与头目》「掉落」）
- **突刺迎击**（突刺打中出招中的敌人加伤、狮子戒指）与**魅惑/引诱颅骨等诱导**（调研见《战斗系统》《魔法与道具》）
- 头目门口离线可召的 **NPC 召唤符**（调研见《角色交互与联机》）
- 侍女被杀复活后**涨价六档**、赦罪回降、卖出价不变（调研见《角色交互与联机》「商店」，可并入 FR-任务-02）

这些都是玩家可观察的系统规则，不是单件资产数值。需求是否纳入范围由后续排期决定，不在此处替它选实现。

## 用语

需求与调研对齐时用这些名字：防火女；传火祭祀场；资料片《艾雷德尔的灰烬》《环印城》；催化器是法杖、圣铃、护符、火焰。分瓶在铁匠安德烈。瓶碎片交给铁匠安德烈，总次数加一，血瓶加灰瓶最多十五口。未死人骨片在传火祭祀场主篝火烧掉，每一口的回复升一档，最多加十档。九项属性是生命力、集中力、耐力、体力、力量、敏捷、智力、信仰、幸运。精力上限看耐力，负重上限看体力，蓝条和法术栏看集中力，生命上限看生命力。法术是魔法、奇迹、火焰三系，暗是伤害种类。
