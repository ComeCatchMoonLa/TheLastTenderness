# 任务与 NPC

> **对话说到段尾就反复。商店用灵魂买卖。把对的物品交出去会推进。交书之后清单变长，人死了清单关闭。商人死亡留下可以交还的灰烬。** 待补的是攻击后敌对、赦罪恢复对话，以及互斥任务休息后仍关着。剧情台词和每条支线经过哪张地图不写。

## 已有入口

对话说到段尾就反复（2.16）。商店用灵魂买卖（2.29）。赠送对的物品会消耗并推进（2.17）。交书之后清单变长，人死了清单关闭（2.34）。商人死亡留下灰烬（2.39）。

攻击后敌对、赦罪、互斥旗标休息后仍关：当前仓库未找到对应类型。

## 需求

### FR-任务-01 对话说到段尾就反复

**当前已有**

对一名 NPC 交互，每次往下一句。这一段最后一句开始反复之后，再对话仍是这一句。休息、进入新区域、击倒对应头目或交出物品，使这一名 NPC 的旗标推进后，下一次对话从新的一段开始，再说到新的反复句。句子说完之前离开，下次从这段还没说完的进度接上，或按该 NPC 的配置重头说。教学姿态随这名 NPC 的教学对话进入姿态列表（姿态也能配进留言，见 [FR-联机-07](联机.md)、[FR-菜单-06](菜单.md)）。NPC 因进度换到新站位后，旧位置的交互消失，对话、商店等服务在新位置继续；只打死头目、没离开这片区域再回来时，人可能还停在旧位置，重载后才到位。

验收：连按对话直到一句开始反复。推进一次旗标（休息、进区域、交物品或击倒对应头目，按这个人的配置）后再对话，出现新的一段。


### FR-任务-02 商店用灵魂买卖

**当前已有**

打开商店，用灵魂买一件，一次确认可以买多件。确认后该物进入背包，灵魂减少标出的价格。把一件允许出售的装备卖出，它离开背包，灵魂增加，增加量少于买它的价格；每件的卖出价是固定魂量，不随买入价或侍女涨价变动。关键道具、已装备在身上的物品、标出不可交易的物品没有出售项。把一包灰烬交给祭祀场的侍女后，她的清单多出这包里的货。商人还活着时，同一批货在商人自己的菜单里。

（待补）侍女被玩家杀死、复活后：买入价按 1.2、1.5、2、3、4、5 倍逐次上涨，每赦罪一次回降一档；卖出价不受影响。

验收：用灵魂买一件，包里多出它，灵魂减少。卖出一件允许卖的装备，灵魂增加且少于买价。把灰烬交给侍女，她的清单多出那一批。


### FR-任务-03 赠送对的物品会消耗并推进

**当前已有**

把指定物品赠送给对应的人。物品从背包消失，随后对话多出新的一句，或商店、法术清单多出一项。把同一件再赠一次时，包里已经没有它，菜单不再接受第二次。交给指定之外的人时，对方拒绝，物品仍在背包。若某件交错即被收走，与调研中待核对项一致。

验收：把指定物品交给对的人。物品消失，对话或商店多一项。交给别人时对方拒绝，物品还在包里。


### FR-任务-04 交书后清单变长，人死后清单关闭

**当前已有**

把卷轴、圣书或火焰书交给对应这一系的人。书从背包消失，他的商店多出书里的那一批法术，没交书时清单里没有这批；用灵魂可以买下并学会。属性低于法术要求时仍可以买下、进持有列表，但不能装备使用。交错给不对应的人会被拒收，物品留在背包。这个人死亡之后，没买的那些不能再从他这里打开。已经学会的法术仍在持有列表里。

验收：把书交给这一系的人。书消失，商店多出法术。这个人死后，没买的不能再从他这里打开。已经学会的还在列表里。


### FR-任务-05 攻击后敌对，赦罪恢复活人的对话

**待补**

对非敌对的 NPC 造成伤害。服务菜单消失，此人转入追击或攻击，休息后仍然敌对。不是一击就敌对：伤害超过阈值、或累计打出 3 次伤害才转入敌对；踢击和无伤害的弹开类奇迹不计入，被敌人攻击波及的伤害计入；敌对前读档计数清零。在赦罪处支付灵魂等级 ×1000 后，这名还活着的人恢复对话；《环印城》的解咒之碑提供第二处同样的赦罪（兼售付费解除空虚，见 [FR-养成-10](角色养成.md)）。已经打死的人付完灵魂也不会回到原处。赦罪只取消敌对：任务失败旗标、已交物品、已经关掉的互斥线都不因赦罪退回或重开。

验收：攻击非敌对的人。菜单消失，此人转入攻击，休息后仍敌对。付灵魂赦罪后，这名还活着的人恢复对话。已经打死的人不会回来。


### FR-任务-06 商人死亡留下灰烬

**当前已有**

把一名商人打死。本周目原处不再对话，尸体或掉落处可以拾取灰烬。把灰烬交给侍女后，清单按 FR-任务-02 并入。休息不会把这名商人叫回来。非商人的一般 NPC 被打死后同样在本周目不刷新：由旗标控制铺在头目门口的具名召唤符消失（见 [FR-联机-03](联机.md)），其专有装备在尸体或掉落处可以拾取一次。NPC 也可能因任务旗标或距离关系，从可对话直接转为敌对生物。

验收：打死商人。原处不再对话，可以捡到灰烬。休息后他不回到原处。


### FR-任务-07 互斥旗标关掉另一条协助

**待补**

做出会立起互斥旗标的交付（例如把苍白舌头交给会关掉另一条协助线的那次）。之后，被关掉的那条线上的人不再提供协助或对话停在失败。在篝火休息不会把这条线重新打开。还开着的线上的人仍能对话。

旗标不只对话与交付两种：区域到达、物品在背包、休息或重载次数、手势、NPC 所在位置都可以立旗标。错误进度的交付会直接立起互斥旗标、把另一条线标成失败。终局交互时，只在未失败旗标所允许的选项中收束结局。

验收：做一次会关掉另一条线的交付。被关掉的人不再提供协助。休息后这条线仍是关掉的。还开着的人仍能对话。
