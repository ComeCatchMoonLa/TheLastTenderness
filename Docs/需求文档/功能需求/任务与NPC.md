# 任务与 NPC

> **任务是一组立起之后大多不能倒退的旗标。** 本篇写对话、商店、赠送、敌对和旗标结果。剧情台词和每条支线经过哪张地图不写。本篇默认待补。

## 已有入口

场景里有可开关的对话和商店窗口，对照未把它们接到黑魂 3 的旗标。敌对、灰烬移交、赦罪、任务旗标：当前仓库未找到对应类型。

## 需求

### FR-任务-01 对话说到段尾就反复

**待补**

对一名 NPC 交互，每次往下一句。这一段最后一句开始反复之后，再对话仍是这一句。休息、进入新区域、击倒对应头目或交出物品，使这一名 NPC 的旗标推进后，下一次对话从新的一段开始，再说到新的反复句。句子说完之前离开，下次从这段还没说完的进度接上，或按该 NPC 的配置重头说。

### FR-任务-02 商店用灵魂买卖

**待补**

打开商店，用灵魂买一件。确认后该物进入背包，灵魂减少标出的价格。把一件允许出售的装备卖出，它离开背包，灵魂增加，增加量少于买它的价格。把一包灰烬交给祭祀场的侍女后，她的清单多出这包里的货。商人还活着时，同一批货在商人自己的菜单里。

### FR-任务-03 赠送对的物品会消耗并推进

**待补**

把指定物品赠送给对应的人。物品从背包消失，随后对话多出新的一句，或商店、法术清单多出一项。把同一件再赠一次时，包里已经没有它，菜单不再接受第二次。交给指定之外的人时，对方拒绝，物品仍在背包。若某件交错即被收走，与调研中待核对项一致。

### FR-任务-04 交书后清单变长，人死后清单关闭

**待补**

把一条法术书或卷轴交给这一系的人。书从背包消失，他的商店多出书里的法术，用灵魂可以买下并学会。这个人死亡之后，没买的那些不能再从他这里打开。已经学会的法术仍在持有列表里。

### FR-任务-05 攻击后敌对，赦罪恢复活人的对话

**待补**

对非敌对的 NPC 造成攻击。服务菜单消失，此人转入追击或攻击，休息后仍然敌对。在赦罪处支付灵魂后，这名还活着的人恢复对话。已经打死的人付完灵魂也不会回到原处。费用随灵魂等级变化，与调研中待核对项一致。

### FR-任务-06 商人死亡留下灰烬

**待补**

把一名商人打死。本周目原处不再对话，尸体或掉落处可以拾取灰烬。把灰烬交给侍女后，清单按 FR-任务-02 并入。休息不会把这名商人叫回来。

### FR-任务-07 互斥旗标关掉另一条协助

**待补**

做出会立起互斥旗标的交付（例如把苍白舌头交给会关掉另一条协助线的那次）。之后，被关掉的那条线上的人不再提供协助或对话停在失败。在篝火休息不会把这条线重新打开。还开着的线上的人仍能对话。
