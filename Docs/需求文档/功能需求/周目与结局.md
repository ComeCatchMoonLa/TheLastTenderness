# 周目与结局

> **使用余烬后生命上限变长，休息不取消，死亡会取消。暗印把人送回上次的火并且不留可捡血迹。回城骨送回时灵魂和余烬还在。卷剑碎片同样送回，个数不减少。终局一次交互只进入一条结局。** 待补的是下一周留下人、重来世界，清除暗印之后窃火不再成立，以及结局之后再进下一周。死亡时把灵魂留在地上再捡回，仍是 [FR-燃火-05](燃火休息与死亡惩罚.md) 至 [FR-燃火-07](燃火休息与死亡惩罚.md)。

## 已有入口

玩家死亡播放 `"Death"` 并 `isDead = true`，人停在当场。死亡时灵魂变成零并留下残留，见 [FR-燃火-05](燃火休息与死亡惩罚.md)。

余烬改生命上限（2.20、2.44）。坐下记下这堆火（2.48）。回城骨送回（2.49）。卷剑碎片送回且个数不减（2.85）。暗印不留可捡血迹（2.50）。终局一次交互只进一条（2.24）。空虚、下一周目、清除暗印之后的窃火：当前仓库未找到对应类型。

## 需求

### FR-周目-01 使用余烬后生命上限变长

**待补**

使用余烬物品。生命上限变高，条变长，当前生命补到这个新上限，角色身上能看出余烬形态。已经处于这形态时再使用一次，上限不再加一截，生命仍补到这一档的顶。提高的比例与调研中待核对项一致。魔法与道具仍把再使用写成待核对，见 [未入池](../../版本候选池/程序功能池/未入池.md)「余烬已经点着时再使用」（信息待统一）。

落点：使用后上限按资产上的比例变长，当前生命补到新上限（2.20）。只看血条，不做出余烬外形。已经点着时再使用不在 2.20。

### FR-周目-02 休息不改余烬，死亡会熄灭

**当前已有**

余烬还在时坐下休息。休息结束，上限仍是余烬那一档，生命补到这一档的顶。把角色打死并复活。余烬熄灭，上限回到没有余烬时的一档，生命补到这一档的顶。没有余烬时坐下，休息不会把余烬点着。

落点：休息不取消余烬，死亡会取消（2.44）。

### FR-周目-03 使用暗印丢掉灵魂并且不留可捡血迹

**当前已有**

身上灵魂大于 0 时使用把人送回篝火的暗印。人出现在上次坐下的篝火，灵魂计数为 0，死亡点没有可拾取的自己的灵魂血迹。从未坐下过时，人出现在传火祭祀场主篝火。头目血条已经出现时，这件物品放不出去，人仍留在场内。

落点：坐下成功记下这堆火（2.48）。使用暗印不留下可捡血迹（2.50）。

### FR-周目-04 回城骨把人送回，灵魂和余烬还在

**当前已有**

使用回城骨。人出现在上次坐下的篝火，灵魂计数与使用前相同，余烬保持使用前的开或关，这枚骨头从背包减少一个。普通敌人和药瓶次数按休息补满。头目血条已经出现时，这枚骨头放不出去。

落点：回城骨把人送回上次的火，灵魂和余烬还在（2.49）。

### FR-周目-05 下一周目留下角色，重来世界

**待补**

在传火祭祀场主篝火选择进入下一周目。九项点数、武器和护甲的强化与注入、已学会的法术、血瓶和灰瓶的总次数与骨片档位、盟约已经领过的奖励，都还在。已经点燃的篝火要重新点，打开过的门重新关上，钥匙从背包消失，已打败的头目再次以满生命出现。敌人更难、掉魂更多的幅度与调研中待核对项一致。

落点：火要重新点，门关上，钥匙从背包消失，还在场上的头目满血（2.80）。开过的箱子盖上可再拿，撞开的幻影墙重新挡住，藏起来的近战回原位并且满血（2.95）。地上捡过的东西回到原处（2.96）。雾门还不在。

### FR-周目-06 终局一次交互只进入一条结局

**当前已有**

在终局火焰上交互一次。窃火旗标已经满足时，结算为窃火。旗标未满足、并且已经把眼交给防火女、又使用了她的符时，结算为灭火。其余情况结算为传火。同一次交互只出现这三条中的一条字幕或旗标结果。缺了通往终局的条件时，主篝火上没有前往终局的传送。

落点：一次交互只进入传火、灭火或窃火中的一条（2.24）。

### FR-周目-07 清除暗印之后窃火不再成立

**待补**

在窃火所需的暗印还在时，让防火女清除暗印并付清灵魂。再走到终局火焰上交互，结算不再是窃火，按 FR-周目-06 的其余两条走。暗印枚数门槛与调研中待核对项一致。

### FR-周目-08 结局之后可以留下再进下一周

**待补**

终局字幕结束后选择留下。人回到传火祭祀场，本周目还能行走，终局那一次交互不能再换另一条结局。之后在主篝火选择进入下一周目，保留和重置与 FR-周目-05 相同。

### FR-周目-09 卷剑碎片送回并且不减少个数

**当前已有**

使用卷剑碎片。人出现在上次坐下的篝火，灵魂计数与使用前相同，余烬保持使用前的开或关，背包里的个数不减少。再拾取一次，背包里仍是一份。普通敌人和药瓶次数按休息补满。头目血条已经出现时放不出去。

落点：使用后回到上次的火，个数不减少，再拾取仍是一份（2.85）。头目血条出现时放不出去。回城骨仍会减少个数（2.49）。
