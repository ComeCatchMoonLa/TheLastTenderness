# 命中判定与伤害

> **近战打中会扣生命，无敌标志为真时不扣，正面格挡会减伤并耗精力，精力耗尽时播放破防。同一次挥击对同一人只结算一次。** 待补的是五种护甲吸收都参与穿着后的承伤，以及物理子类的吸收可以不同。翻滚动作自己打开受击豁免窗口见 [FR-移动-07](玩家移动与闪避.md)，那一条待补。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 五段伤害、护甲减免、无敌与死亡返回 | `CharacterStatsManager.TakeDamage` | `Assets/Scripts/Character/CharacterStatsManager.cs` |
| 近战触发、格挡、韧性 | `DamageCollider` | `Assets/Scripts/Damage/Damage Collider/DamageCollider.cs` |
| 武器五段攻击力 | `WeaponItem` | `Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs` |
| 护甲五段吸收 | `ArmorItem` | `Assets/Scripts/Items/Equipment/Armor/ArmorItem.cs` |
| 玩家受伤后刷新血条 | `PlayerStatsManager.TakeDamage` | `Assets/Scripts/Character/Player/PlayerStatsManager.cs` |

五段是物理、火、魔、雷、暗。穿戴护甲时，现有逻辑只把物理吸收写入头、躯干、下身。火、魔、雷、暗的吸收字段出现在属性面板，结算读得到字段，穿戴路径不写它们。

同一次挥击用 `DamageCollider.hitThisWindow` 记下已经打过的角色。窗口关掉后这份记录清掉。

## 需求

### FR-伤害-01 命中扣生命

**当前已有**

伤害体打开期间碰到另一名有 `CharacterManager`、且未死亡、未无敌、队伍编号不同的角色。对方生命下降。生命条或敌人头上的血条在同一次受伤后变短。生命降到 0 时进入死亡，见 [燃火休息与死亡惩罚](燃火休息与死亡惩罚.md) 与 [敌人](敌人.md)。

### FR-伤害-02 同队不互相伤害

**当前已有**

伤害体的 `teamID` 与目标角色的 `teamID` 相同。碰上之后双方生命都不变。

### FR-伤害-03 无敌不受伤

**当前已有**

目标 `isInvulnerable` 为真时被打到。生命不变，不播放受击动作。标志恢复为假后再被打到，生命下降。

本条看的是这个标志。翻滚、后撤是否在动作里打开它，见 [FR-移动-07](玩家移动与闪避.md)。

### FR-伤害-04 格挡减伤

**当前已有**

角色正面举盾时被打到。本次生命下降少于未格挡时的同类攻击，精力下降。精力仍大于 0 时，举盾保持。

### FR-伤害-05 一次挥击结算一次

**当前已有**

同一次挥击的伤害窗口内，武器多次碰到同一名敌人，该敌人只掉一次血、只播一次受击。窗口关闭后再挥中，可以再结算。打中两名不同敌人时，各结算一次。

落点：`DamageCollider.hitThisWindow`（2.3）。

### FR-伤害-06 穿着护甲后五种伤害都减

**待补**

角色穿上在火、魔、雷、暗上写了吸收的护甲后，受到对应那种伤害时，生命下降少于赤裸时的同一击。脱掉后回到赤裸时的下降量。物理吸收保持穿上就生效。

落点：`CharacterStatsManager.TakeDamage` 已经按部位读取五种吸收。穿戴入口在 `InventorySlotUI` 与护甲装备逻辑，当前只写物理吸收。

### FR-伤害-07 格挡耗尽可见破防

**当前已有**

举盾被打，精力被这一次格挡扣到耗尽。角色放下盾，播放 `Guard_Break`，这段时间不能移动和攻击。硬直结束后可以再举盾。

入口：`CharacterCombatManager.AttemptBlock` 在 `currentStamina` 小于等于 0 时清格挡，并 `PlayTargetAnimation("Guard_Break", true)`。控制器里的状态名是 `Guard_Break`。

### FR-伤害-08 物理子类的吸收可以不同

**待补**

穿上同一套护甲，先吃一记打击，再吃一记斩击或突刺。两次生命下降能分辨出差别。脱掉这套后再各吃一次，差别回到赤裸时的下降。状态页上标准、打击、斩击、突刺四类（以及魔法、火、雷、暗）各自独立合成：总吸收% = 100×(1−(1−a1/100)(1−a2/100)(1−a3/100)(1−a4/100)…)，四件装备与戒指等来源逐件相乘；固定防御先算，吸收百分比后算。

### FR-伤害-09 突刺迎击

**待补**

用突刺类攻击打中一名正处在出招动作中的敌人。这一击的伤害高于同样条件下打中待机敌人的同一下（反击加成）。狮子戒指把这一档加成放大。敌人用突刺打中出招中的玩家时同样结算。具体倍率写在武器与戒指资产上（与调研中待核对项一致）。

落点：当前仓库未找到对应类型。

### FR-伤害-10 格挡按吸收与稳定度两层结算

**待补**

- 物理吸收 100% 的盾在正面挡住物理攻击时，这一下生命不下降；元素吸收不满时，对应火、魔、雷、暗伤害从盾漏过，生命仍下降。
- 每次成功格挡都扣精力，扣多少看这一击的力度与盾的稳定度；用武器当盾时稳定度通常差。举盾时精力回复变慢，见 [FR-精力-04](精力.md)。
- 精力被格挡扣到 0：盾放下、播崩架（FR-伤害-07），这一下改按未格挡结算，可以马上接崩架处决（[FR-处决-04](背刺与处决.md)）。
- 格挡只在正面、且在盾覆盖角度内成立；背后和侧面的打击不走盾。格挡不挡坠落伤害与毒沼一类环境持续伤害。举盾成功挡住攻击时，武器或攻击附带的异常积蓄仍常常加到举盾者身上（见 [状态积蓄](状态积蓄.md)）。

落点：`AttemptBlock` 现状只做扣精力与破防，分层结算待补。

### FR-伤害-11 环境伤害与弹刀

**待补**

近战打在硬度足够的表面（墙、部分头目的躯体或护甲）时弹刀：这一击不结算伤害，挥击被弹回并有一小段硬直。毒沼、岩浆、坠落、机关与部分爆炸等环境伤害不走举盾减伤、也不能被弹反，直接按对应伤害段结算（坠落见 [FR-移动-09](玩家移动与闪避.md)）。

落点：当前仓库有 `DamagePlayer` 一类环境触发器，弹刀类型未找到。
