# 回复类消耗品

> **血瓶在动画成功后会回血，次数为零时会耸肩，喝的过程中不能再扣一次。次数记在这名玩家身上。专注回复在成功后生效。燃火休息后把次数补满。**

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 使用键 | `PlayerInventoryManager.HandleUseConsumableInput` | `Assets/Scripts/Character/Player/PlayerInventoryManager.cs` |
| 血瓶 | `FlaskItem` | `Assets/Scripts/Items/Consumables/FlaskItem.cs` |
| 消耗品基类 | `ConsumableItem` | `Assets/Scripts/Items/Consumables/ConsumableItem.cs` |
| 喝药状态 | `HandleUseComsumableState` | `Assets/Scripts/Animator/HandleState/Humanoid/HandleUseComsumableState.cs` |

`FlaskItem` 上有 `healthRecoverAmount` 与 `focusPointsRecoverAmount`。成功回调按大于 0 的那一项调用 `AddHP` 或 `AddMP`。`flaskType` 区分血瓶和灰瓶。

剩余次数在这名玩家身上，不写在瓶资产的剩余次数上。回血要等动画事件 `SuccessfullyCastConsumable`。

## 需求

### FR-回复-01 喝血瓶回血

**当前已有**

生命未满、血瓶次数大于 0 时按下使用键。角色播放喝药动作。动作上的成功事件触发后，生命上升，不超过上限。手上的武器在喝完后回到喝之前的装备。

生命已满时使用，生命保持上限。

### FR-回复-02 次数为零不能喝

**当前已有**

次数为 0 时按下使用键。角色播放 `Shrug`，生命不变。

### FR-回复-03 喝的过程中不连扣

**当前已有**

喝药动作尚未结束、`isUsingConsumable` 仍为真时再次按下使用键。次数不再减少，也不会叠第二段喝药。

### FR-回复-04 次数属于这名玩家

**当前已有**

喝掉一次后，只有这名玩家的剩余次数减一。重新进入游戏，或另一处读取同一瓶资产时，剩余次数仍是该玩家自己剩下的次数，不会因为资产被上次喝过而变成 0。在 HUD 上能看到剩余次数，见 [FR-界面-06](战斗HUD.md)。

落点：次数在 `PlayerInventoryManager` 上按血瓶和灰瓶分开记（0.34）。快捷栏这一件的开局剩余是 `currentItemAmount`，超过 `maxItemAmount` 时按上限，不写回资产（0.42）。喝药仍走 `FlaskItem.AttemptToConsumableItem`。

### FR-回复-05 灰瓶回专注，一口只回一种

**待补**

血瓶与灰瓶是两瓶，按 [FR-篝火-05](篝火菜单.md) 分配总次数；一口只喝当前这一瓶，只回复这一瓶对应的那一种资源：喝灰瓶，动作成功结束后专注上升，不超过上限；喝血瓶，只增加生命。不存在一口同时抬生命和专注的瓶。次数按 FR-回复-04 减少。

落点：`FlaskItem.SuccessfullyUsedConsumable` 在对应回复量大于 0 时调用 `AddHP` 或 `AddMP`（2.1）。现状允许一件瓶同时配两种回复量并一口双回，与目标不符，待按瓶种（`flaskType`）二选一结算。已满的那一条保持上限。

### FR-回复-06 休息后次数回到上限

**当前已有**

把次数用到少于上限之后，在燃火处休息成功。该玩家的回复次数回到配置的上限，下一次喝药可以回血。未休息前次数保持用剩的数量。

休息行为见 [FR-燃火-02](燃火休息与死亡惩罚.md)。落点：休息把玩家身上的回复次数写回上限（2.5）。分瓶之后写满的是这一轮划分，见 [FR-篝火-05](篝火菜单.md)。

### FR-回复-07 喝药分段回复，打断与连喝

**待补**

一瓶的回复在喝药动作里分段涨满，不是一次跳满。动作被打断时，已经涨上的部分保留，还没涨的不补。0 次时使用播耸肩（FR-回复-02）。按住使用键可以连喝，每一口各扣一次次数；满血时是否继续扣次数、喝药能不能用翻滚取消，与调研中待核对项一致。

落点：现状成功事件一次结算，分段回复与连喝待补。

### FR-回复-08 其他消耗品通则

**待补**

- 消耗品用一次少一个，离手即扣，成功帧之后产生效果；动作开始后被打断时物品退不退回，与调研中待核对项一致（松脂与束缎见 [FR-注入-08](注入与强化.md)）。
- 解除异常：红苔、紫苔、开花紫苔、蓝苔分级解除出血、中毒、剧毒、冰霜，没有对应异常时使用也消耗；祝福一类在咒死槽未满时清槽。
- 一次性回复：祝福、隐秘祝福立即回一截生命；绿花类一段时间加快精力回复；硬币、虫丹等一段时间提高发现力。
- 投掷类（短索、引怪头骨、不死狩人护符）的规则见 [FR-法术-10](法术.md)。

落点：当前仓库未找到成套类型。
