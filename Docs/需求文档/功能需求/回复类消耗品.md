# 回复类消耗品

> **血瓶在动画成功后会回血，次数为零时会耸肩，喝的过程中不能再扣一次。** 待补的是次数记在这名玩家身上、专注回复真正生效，以及燃火休息后把次数补满。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 使用键 | `PlayerInventoryManager.HandleUseConsumableInput` | `Assets/Scripts/Character/Player/PlayerInventoryManager.cs` |
| 血瓶 | `FlaskItem` | `Assets/Scripts/Items/Consumables/FlaskItem.cs` |
| 消耗品基类 | `ConsumableItem` | `Assets/Scripts/Items/Consumables/ConsumableItem.cs` |
| 喝药状态 | `HandleUseComsumableState` | `Assets/Scripts/Animator/HandleState/Humanoid/HandleUseComsumableState.cs` |

`FlaskItem` 上有 `healthRecoverAmount` 与 `focusPointsRecoverAmount`。成功回调 `SuccessfullyUsedConsumable` 只调用 `AddHP`。`flaskType` 有字段，使用逻辑不读它。

次数在 `AttemptToConsumableItem` 里就从这份 `ScriptableObject` 的 `currentItemAmount` 减 1。回血要等动画事件 `SuccessfullyCastConsumable`。

## 需求

### FR-回复-01 喝血瓶回血

**当前已有**

生命未满、血瓶次数大于 0 时按下使用键。角色播放喝药动作。动作上的成功事件触发后，生命上升，不超过上限。手上的武器在喝完后回到喝之前的装备。

生命已满时使用，生命保持上限。

### FR-回复-02 次数为零不能喝

**当前已有**

次数为 0 时按下使用键。角色播放 `Shrug`，生命不变。

### FR-回复-03 喝的过程中不连扣

**当前已有**

喝药动作尚未结束、`isUsingConsumable` 仍为真时再次按下使用键。次数不再减少，也不会叠第二段喝药。

### FR-回复-04 次数属于这名玩家

**待补**

喝掉一次后，只有这名玩家的剩余次数减一。重新进入游戏，或另一处读取同一瓶资产时，剩余次数仍是该玩家自己剩下的次数，不会因为资产被上次喝过而变成 0。在 HUD 上能看到剩余次数，见 [FR-界面-06](战斗HUD.md)。

落点：次数从 `FlaskItem` 这份资产上的 `currentItemAmount` 挪到 `PlayerInventoryManager` 或 `PlayerStatsManager` 的运行时数据。喝药仍走 `FlaskItem.AttemptToConsumableItem`。

### FR-回复-05 专注回复生效

**待补**

使用一件配置了 `focusPointsRecoverAmount` 且类型为回复专注的血瓶，动作成功结束后，专注上升，不超过上限。只配置了生命回复量的血瓶，仍只增加生命。两者都配置时，成功后生命和专注一起上升。次数按 FR-回复-04 减少。

落点：`FlaskItem.SuccessfullyUsedConsumable` 现有 `AddHP`。`AddMP` 已在 `PlayerStatsManager`。

### FR-回复-06 休息后次数回到上限

**待补**

把次数用到少于上限之后，在燃火处休息成功。该玩家的回复次数回到配置的上限，下一次喝药可以回血。未休息前次数保持用剩的数量。

休息行为见 [FR-燃火-02](燃火休息与死亡惩罚.md)。落点：休息逻辑写回玩家身上的次数，类型仍是 `FlaskItem` 与 `CampFireInteractable`。
