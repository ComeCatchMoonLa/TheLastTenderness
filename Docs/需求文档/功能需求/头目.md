# 头目

> **呼救被打断则同伴不来。头目使用带名字的血条，能换阶段。有协助时更厚。死后撤雾并点起新火。一场头目的场地机关按这场配置生效。** 待补的是敌对的人会喝药和翻滚。拉出活动范围后归位并补满已有，见 FR-头目-01。当前场景三只近战的发现、追击、受击和死亡仍是 [FR-敌人-01](敌人.md) 至 [FR-敌人-05](敌人.md)。招式不按每只头目列出。

## 已有入口

人形五状态在 `Humanoid A.I/`。普通敌人离放置点超过活动范围会走回放置点（0.50）。Boss 选招在 `BossCombatStanceState`。阶段看 `phaseThreshold`，血条刷新在 `EnemyStatsManager.UpdateBossHealthBar`，长血条是 `UIBossHealthBar`。头目血条和阶段不在当前 `Game` 的三只近战上。`EnemyStatsManager` 在头目死亡时调用 `WorldEventManager.BossHasBeenDefeated`。

呼救被打断则同伴不来（2.52）。带名字的血条（2.60）。换阶段（2.64）。有协助时更厚（2.67）。死后撤雾并点起新火（2.65）。场地机关按这场配置（2.66）。

敌对的人会喝药和翻滚：还没有。拉出活动范围后归位并补满（2.77，活动范围改成离放置点 0.50）。

## 需求

### FR-头目-01 拉出活动范围后归位并补满

**当前已有**

一只会巡逻或装睡的普通敌人，在被发现前不追玩家。把它拉出这只敌人的活动范围。它停止追击，走回放置点，走到之后生命回到满值，姿态回到待机。归途中再打中它，并且人还在能接战的距离内，它转回追击，生命保持被打过的数值。头目在自己的场地里拉开距离时，生命保持当前值，不因距离归位。

落点：离放置点超过活动范围走回放置点，走到之后生命写成上限（2.77 量的是离玩家，0.50 改成离放置点）。归途中仍在接战距离被打中则转回追击，不满血。头目不因此归位。

### FR-头目-02 呼救被打断则同伴不来

**当前已有**

让一只配了呼救的敌人做出呼救动作。动作做完，更远处、不在同一组即时连锁里的同伴进入战斗。在动作做完之前把它打出硬直，这些更远的同伴保持待机。呼救还可以给被叫醒来的同伴附一段短时的伤害强化。旁边本来就在同一组里的敌人，在发现的当时就会一起转过来，不必等这次呼救。

### FR-头目-03 头目使用带名字的血条

**当前已有**

进入雾门后，屏幕上出现带名字的头目血条，和敌人头顶的短条分开。打中头目时这条下降。多具身体共用一条血时，打配置里承担这条血的身体，血条下降。头目死亡后，这条血条收起。

### FR-头目-04 阶段切换换动作或血条

**当前已有**

把一场配置了阶段的头目打到它的切换条件（生命比例、场地位置、可破坏位点或时间，按这场的配置）。它换一套动作，或血条换成下一截、旧血条作废。切换动作播着的时候，打在身上血条不动、不积蓄韧性。头目的进场动画、部分抢投和传送动作同样无敌；哪些动作的头尾帧可以打伤，逐场配置。纯计时还是看血，与这一场的配置以及调研中待核对项一致。

### FR-头目-05 协助跟进雾门后头目更厚

**当前已有**

独自进入雾门，记下头目生命上限。另一次让一名协助幻影一起进入。头目生命上限高于独自进入，血条按提高后的上限显示；倍率按进门时场上的人数当场结算，中途人数变化是否回落与调研中待核对项一致。协助区域里的普通敌人也会变厚，幅度通常小于头目。教堂枪兵按生命上限不加、其余资源随人数上升的特例走，见 [FR-联机-08](联机.md)。具体倍率按这场配置，与调研中待核对项一致。

### FR-头目-06 死后雾门撤掉，可以点起新火

**当前已有**

把这场头目打到死亡。它的死亡动画播完之后雾门才消失，本周目再来到入口，雾门不再挡住，头目不在场地里。场地或紧挨出口处若配置了新篝火，它以未点燃的样子出现，点着之后进入传送列表。人在头目还活着时死亡，回到进门之前那处已点燃的火，头目以满生命重来、场内幻影被送回，新火还不在。头目死亡给一笔大灵魂，并掉落可在王座兑换的头目灵魂道具（兑换见 [FR-注入-04](注入与强化.md)）。

### FR-头目-07 场地机关按这场配置生效

**当前已有**

在一场带场地机关的头目战里，能看见该场配置的那一种结果：掉出去死亡、站在区域里持续掉血或涨异常槽、只有用特定方式或特定攻击打才造成有效伤害、只有打掉位点血条才明显下降、阈值一到第二名大型战斗者加入（杀死后头目变招，可反复召唤）、召唤出的小兵用短血条，或打死操纵者后远端的攻击体消失。举盾挡不住脚下的区域伤害。没配该机关的另一场头目，不出现这一种结果。

### FR-头目-08 敌对的人会喝药和翻滚

**待补**

把一名原来可以对话的人打成敌对，或走进一名已敌对的配置角色。对方会喝药、翻滚、切换武器或施法，生命因此变化；它的药瓶次数有限，喝药动作被打断时这一口浪费。把它打死之后，本周目原处不再有对话，休息也不会把它叫回来站着说话。下一周目是否重新放置，见 [FR-周目-05](周目与结局.md)。
