# 属性与升级

> **生命、精力、专注的上限已经跟着三项等级走，击杀近战敌人会增加灵魂并刷新数字。** 待补的是角色属性界面、花灵魂升级、武器需求不足时伤害变低，以及智力和信仰挡学校的法术。九项属性、防火女入口、重生和空虚见 [角色养成](角色养成.md)。本篇编号原文不动。

## 已有入口

| 内容 | 类型 | 路径 |

已有等级字段：`healthLevel`、`staminaLevel`、`focusLevel`、`poiseLevel`、`strengthLevel`、`dexterityLevel`、`intelligenceLevel`、`faithLevel`。上限换算留在 `SetMaxHealthFromHealthLevel` 等三个方法里，本需求不写死乘数。

`ItemStatsWinManager` 展示的是当前看着的那件装备，没有角色等级和持有灵魂。升级界面、花灵魂加级：当前仓库未找到对应类型。武器需求等级：当前仓库未找到对应类型。

## 需求

### FR-属性-01 三项上限跟着等级

**当前已有**

提高 `healthLevel`、`staminaLevel` 或 `focusLevel` 后重新进入游戏，或在现有逻辑重新计算上限之后，对应的最大生命、最大精力、最大专注升高，条的满格一起变长。降低等级则满格变短。当前生命、精力、专注不超过新的上限。

### FR-属性-02 击杀获得灵魂

**当前已有**

打死当前场景里的一名近战敌人。玩家 `soulCount` 增加该敌人 `soulsAwardedDeath` 配置的数量，HUD 上的灵魂数字变成增加后的值。

`AddSouls` 本身只改数字。击杀这条会同时写 `SoulCountUI`。其他途径增减灵魂的显示见 [FR-界面-05](战斗HUD.md)。

### FR-属性-03 能读到角色属性

**待补**

打开角色属性界面。玩家能看到生命、精力、专注、力量、敏捷、智力、信仰的当前等级，以及身上的灵魂数。穿着的变化不改这些等级数字。关上界面后战斗 HUD 仍在。

落点：现有面板窗口（`TapWindowsManager`）增加一页，读取 `PlayerStatsManager`。不另做界面框架。

### FR-属性-04 花灵魂升级

**待补**

在已点燃的燃火处打开升级（燃火菜单见 [燃火休息与死亡惩罚](燃火休息与死亡惩罚.md)）。灵魂足够时提高上述某一项等级，灵魂数字减少，该项等级加一。生命、精力或专注升级后，对应上限立刻按 FR-属性-01 变长。灵魂不足时选择升级，等级和灵魂都不变。

当前仓库未找到对应类型。落点：`PlayerStatsManager` 上增减 `soulCount` 与现有等级字段，并由燃火交互打开这个界面。

### FR-属性-05 武器需求不足时更弱

**待补**

装备一把写了力量或敏捷需求的武器。需求不满足时，用它打中同一名敌人，伤害低于需求满足时的同一段轻击。需求满足后再打，伤害回到较高的那一档。角色仍能挥出动作。

当前仓库未找到武器需求字段。落点：字段加在 `WeaponItem` 上，比较 `strengthLevel` / `dexterityLevel`，结算仍走 `DamageCollider`。

### FR-属性-06 智力与信仰限制法术

**待补**

当前法术的学派与智力或信仰的要求不符，或低于该法术要求的等级时，按下施法。角色不放出弹体、也不治疗，专注不减少。要求满足且专注足够时，施法动作出现，成功后产生该法术已有的效果（现有投射物或治疗）。

已有门禁是 `SorcerySpellAction`、`PyromancySpellAction`、`MiracleSpellAction`，它们核对 `currentSpell.spellType` 和专注是否够。效果在 `SpellItem`。智力和信仰不参与这次核对。
