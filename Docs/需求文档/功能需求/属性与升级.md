# 属性与升级

> **生命、精力、专注的上限已经跟着三项等级走，击杀近战敌人会增加灵魂并刷新数字。状态页能读已有等级和灵魂。防火女处花灵魂加点。武器需求不足时打中更弱。法术自身需求不够时放不出；只是催化器需求不够时仍能放，但按削弱后的法术威力结算。** 九项里的体力和幸运、重生和空虚见 [角色养成](角色养成.md)。本篇编号原文不动。

## 已有入口

| 内容 | 类型 | 路径 |
| --- | --- | --- |
| 等级与三项上限 | `CharacterStatsManager` | `Assets/Scripts/Character/CharacterStatsManager.cs` |
| 灵魂数量 | `PlayerStatsManager.soulCount`、`AddSouls` | `Assets/Scripts/Character/Player/PlayerStatsManager.cs` |
| 击杀后加灵魂并写 HUD | `EnemyStatsManager.AwardSoulsOnDeath` | `Assets/Scripts/Character/NPC/EnemyStatsManager.cs` |

已有等级字段：`healthLevel`、`staminaLevel`、`focusLevel`、`poiseLevel`、`strengthLevel`、`dexterityLevel`、`intelligenceLevel`、`faithLevel`。上限换算留在 `SetMaxHealthFromHealthLevel` 等三个方法里，本需求不写死乘数。

`ItemStatsWinManager` 展示的是当前看着的那件装备。角色等级和灵魂在状态页。花灵魂加级在 `LevelPurchase`。武器需求在 `WeaponItem` 上。

## 需求

### FR-属性-01 三项上限跟着等级

**当前已有**

提高 `healthLevel`、`staminaLevel` 或 `focusLevel` 后重新进入游戏，或在现有逻辑重新计算上限之后，对应的最大生命、最大精力、最大专注升高，条的满格一起变长。降低等级则满格变短。当前生命、精力、专注不超过新的上限。

验收：改高一项生命、精力或专注等级并让上限重算。对应的满格变长。改低则满格变短。


### FR-属性-02 击杀获得灵魂

**当前已有**

打死当前场景里的一名近战敌人。玩家 `soulCount` 增加该敌人 `soulsAwardedDeath` 配置的数量，HUD 上的灵魂数字变成增加后的值。

`AddSouls` 本身只改数字。击杀这条会同时写 `SoulCountUI`。其他途径增减灵魂的显示见 [FR-界面-05](战斗HUD.md)。

验收：击杀一只近战。灵魂数字增加。


### FR-属性-03 能读到角色属性

**当前已有**

打开角色属性界面。玩家能看到生命、精力、专注、力量、敏捷、智力、信仰的当前等级，以及身上的灵魂数。穿着的变化不改这些等级数字。关上界面后战斗 HUD 仍在。

验收：打开角色属性。能看见各项等级和当前灵魂。换装后等级数字不变。

落点：分页窗里的状态页读 `healthLevel`、`staminaLevel`、`focusLevel`、`strengthLevel`、`dexterityLevel`、`intelligenceLevel`、`faithLevel` 和 `soulCount`（2.11）。`poiseLevel` 一并读出，文案是韧性。体力和幸运不在这一页。这一页不能加点。

### FR-属性-04 花灵魂升级

**当前已有**

与防火女对话打开升级（篝火菜单里没有升级项）。灵魂足够时提高上述某一项等级，灵魂数字减少，该项等级加一。生命、精力或专注升级后，对应上限立刻按 FR-属性-01 变长。灵魂不足时选择升级，等级和灵魂都不变。

验收：与防火女对话花灵魂升一级。灵魂减少，等级加一。升生命、精力或专注时满格立刻变长。灵魂不够时等级和灵魂都不变。篝火菜单里没有升级入口。

落点：扣魂和加级在 `LevelPurchase.TryConfirm`（2.27）。入口是防火女的对话，不是燃火菜单，见 [FR-养成-05](角色养成.md)。花费没填或灵魂不够时，等级和灵魂都不变。

### FR-属性-05 武器需求不足时更弱

**当前已有**

装备一把写了力量或敏捷需求的武器。需求不满足时，用它打中同一名敌人，伤害低于需求满足时的同一段轻击。需求满足后再打，伤害回到较高的那一档。角色仍能挥出动作。

验收：属性不够武器需求时打一击，记下掉血。满足需求后再打同一段。第二次掉血更多。两次都能挥出去。

落点：需求写在 `WeaponItem` 上，能读到力量和敏捷（2.37）。不足时更慢，打中也更弱（2.38）。挥击变慢的比较见 [FR-注入-06](注入与强化.md)。

### FR-属性-06 智力与信仰限制法术

**待补**

两种情形分开看：

- **法术自身**的学派、智力或信仰要求不满足（含低于该法术要求的等级）时，按下施法。角色不放出弹体、也不治疗，专注不减少。
- **只是催化器**的属性要求不满足时，法术仍施放，成功后产生该法术已有的效果（现有投射物或治疗），但按催化器削弱后的法术威力结算；与法术威力无关的效果不受影响。催化器自己的战技在需求不满足时不能使用。削弱比例写在催化器资产上。

要求满足且专注足够时，施法动作出现，成功后产生该法术已有的效果。

验收：智力或信仰低于法术自身要求时施法，没有弹体或治疗、专注不减；只是催化器需求不够时，法术仍放出但结果弱于满足时，催化器战技不能用。

落点：`SorcerySpellAction`、`PyromancySpellAction`、`MiracleSpellAction` 核对学派、专注，以及智力或信仰（2.9），现状是不满足即不放；催化器需求不满足仍放行并按削弱威力结算这一分支还没接。蓝不够时的耸肩不改。拿错催化器见 [FR-法术-02](法术.md)。

### FR-属性-07 等级带来固定防御与异常抗性底子

**待补**

提高九项等级时，角色对八类伤害的固定防御、以及出血/毒/冰霜/咒死四条异常抗性的底子随等级缓慢上升（剧毒共用毒抗）；护甲在底子之上再加吸收与异常抗性，合成规则见 [FR-伤害-08](命中判定与伤害.md) 与 [FR-异常-01](状态积蓄.md) 起。具体分段系数写在属性曲线上，需求不写死。幸运另外影响出血与毒的积蓄量，规则见 [FR-异常-01](状态积蓄.md)。

验收：升级前后对比状态页，固定防御与四条异常抗性底子随等级上升。

落点：当前仓库未找到对应类型。
