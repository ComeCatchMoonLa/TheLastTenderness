# 敌人

> **当前场景里的三只近战会发现玩家、追击、攻击，并在死亡时给灵魂、解除锁定。休息后已死的近战回到满血。** 待补的是玩家走远后放弃追击并回到原地。归位回血、头目阶段和战后篝火见 [头目](头目.md)。本篇编号原文不动，验收仍用这三只近战。

当前 `Game` 里激活的敌人是人形近战，状态在 `Assets/Scripts/Character/NPC/State/Humanoid A.I/`。`General A.I/` 与 Boss 状态不在这三只身上，本系统的验收用这三只。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 每帧驱动状态 | `EnemyManager` | `Assets/Scripts/Character/NPC/EnemyManager.cs` |
| 发现 | `IdleStateHumanoid` | `Assets/Scripts/Character/NPC/State/Humanoid A.I/IdleStateHumanoid.cs` |
| 追击 | `PursueTargetStateHumanoid` | `Assets/Scripts/Character/NPC/State/Humanoid A.I/PursueTargetStateHumanoid.cs` |
| 交战姿态 | `CombatStanceStateHumanoid` | `Assets/Scripts/Character/NPC/State/Humanoid A.I/CombatStanceStateHumanoid.cs` |
| 攻击 | `AttackStateHumanoid` | `Assets/Scripts/Character/NPC/State/Humanoid A.I/AttackStateHumanoid.cs` |
| 死亡与灵魂 | `EnemyStatsManager` | `Assets/Scripts/Character/NPC/EnemyStatsManager.cs` |

待机时在视野和射线都够到玩家的情况下，把玩家写成 `currentTarget` 并切到追击。攻击打出的同一次 `Tick` 会离开攻击状态。受击是否播动画，规则与玩家相同，见 [霸体与硬直](霸体与硬直.md)。

追击脚本里没有「走远就回家」的距离。当前仓库未找到勒回点类型。

## 需求

### FR-敌人-01 发现玩家

**当前已有**

玩家从敌人正面走进它的发现范围，中间没有环境挡住。敌人转向玩家并开始追。玩家待在它背后、或中间有环境挡住时，它保持待机。

落点：正面扇形里，开着的非触发碰撞体挡住就不发现（3.3）。玩家、敌人、Blocker 和触发器不挡。背后仍不发现。

`enableAI` 为假的敌人保持待机。当前场景里三只近战的 AI 是开的。

### FR-敌人-02 追击并进入攻击距离

**当前已有**

敌人发现玩家后，向玩家移动。距离近到它的攻击距离内时，它停下追击并出手，玩家生命可以因此下降。玩家在中距离拉开但尚未脱离整张地图时，它继续跟着走。

落点：发现后用导航的 `desiredVelocity` 走过去，近到攻击距离仍出手（0.48）。中距离拉开仍跟着走。

### FR-敌人-03 受击与打空

**当前已有**

玩家一击打断它的韧性时，它播放受击并暂停追击或攻击，生命下降。韧性还够时，它继续当前动作，生命仍然下降。攻击挥空、没有打到玩家时，玩家生命不变，它回到交战或追击，而不是停在攻击动作里。

交战姿态中，它有时会举盾、闪避或做弹反动作。这是现有掷选，不是每次必现。

### FR-敌人-04 死亡

**当前已有**

近战敌人生命降到 0。它播放死亡动作，不再追击和攻击，玩家灵魂增加（[FR-属性-02](属性与升级.md)）。玩家当时锁着它时，锁定按 [FR-镜头-06](镜头与锁定.md) 解除或改锁。一段时间后这只敌人从场景里消失。

### FR-敌人-05 走远后放弃

**待补**

敌人正在追击时，玩家拉开到超过它的配置距离。它停止追击，走回发现玩家之前的位置，并回到待机。玩家再次进入发现范围时，它重新开始 FR-敌人-01。

落点：`PursueTargetStateHumanoid.Tick` 与 `IdleStateHumanoid`。回家的位置用这只敌人开始追击前的坐标，不新建 AI 框架。人沿导航走回去（0.48）。
