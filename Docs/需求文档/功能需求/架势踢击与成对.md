# 架势、踢击与成对武器

> **架势要按两次，成对武器的左手键打出双持连段，踢击用来崩盾。** 本篇默认待补。站立轻击、重击、武器技和举盾仍是 [FR-攻击-01](轻重攻击与武器技.md) 至 [FR-攻击-07](轻重攻击与武器技.md)。

## 已有入口

武器技入口是 `ParryAction`，播放动画名，双手分支为空，不读蓝。`WeaponItem` 上有单手和双手的轻重攻击组。

架势标成后战技键停住，轻击和重击分成两段，再按一次收回（3.2）。成对连段还不在。没冲刺且向前的轻攻击打中举盾时精力见底并崩架（2.88）。

## 需求

### FR-架势-01 架势再接轻击或重击

**待补**

装备战技为架势的武器，蓝足够时按战技键。角色进入一个可维持的姿势。姿势里按轻攻击，走出一击；重新进入后按重攻击，走出与刚才能分辨的另一击。两击打中时目标掉血。进入姿势就扣蓝，还是派生时才扣蓝，与调研中待核对项一致。

落点：标成架势时战技键停住，轻击记成一段、重击记成另一段（3.2）。没标成架势仍弹反。可见的架势姿势还不在。扣蓝还不在。

### FR-架势-02 姿势可以不接招就收回

**待补**

进入架势后不按轻攻击和重攻击。角色从姿势回到可移动，场上没有这次派生的伤害。被打中且这一下不在霸体窗口里时，姿势断开。

落点：再按一次战技键收回，不走出派生（3.2）。霸体窗口挡得住时姿势留着，血量被打空或窗口没开则断开。格挡成功，以及背刺、处决，还不因此断开。

### FR-架势-03 成对武器打出双持连段

**待补**

按游戏要求把一件成对武器握成双持，按这套握法的连段键。一次连段里能打中目标不止一下，精力下降。这期间再按举盾，盾不举在正面。战技键仍放出这件武器自己的战技，蓝下降。

落点：正在用的武器是成对时，连段选现有双手片段（2.93）。另一只手是真盾时举不起来。重量是否算两次还不在。

### FR-架势-04 两把不成对的武器不合成连段

**待补**

左右手各装备一把彼此不成对的武器。按左手攻击，只有左手那一把打出单下，不出现成对连段。战技键在单手时走出当前生效那一侧的战技；左手是弹反盾时，战技键走出弹反，右手武器的架势要双手握住右手武器才进得去。

落点：两把都不是成对时仍走单手片段（2.93）。没有成对时真盾仍能举起。

### FR-架势-05 踢击崩开举盾

**待补**

没有在冲刺时，向前并按轻攻击。角色做出踢击，精力下降。踢中正在举盾、精力偏低的目标时，对方精力被大量扣掉；扣到见底时盾放下并弯腰。正在冲刺时，向前加轻攻击走出跑动攻击，不走出这次踢击。

落点：没冲刺且向前的轻攻击打中正面举盾时，精力写成 0 并进入可处决（2.88）。踢击自己的精力消耗、冲刺时的跑动攻击还不在。
