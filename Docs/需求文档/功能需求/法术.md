# 法术

> **法术先学会，再在篝火放进记忆栏，手里的催化器还得对上这一系。蓝不够时失败起手。持续治疗按固定每秒量回血。正面举盾时弹体按吸收减伤并扣精力。允许附魔的武器在一段时间内多一段伤害。** 待补的是四种催化器的战技、翻滚穿过弹体、即时治疗按法术威力变多。法术自身需求不够时放不出；只是催化器需求不够时仍放得出、按削弱后的法术威力结算，见 [FR-属性-06](属性与升级.md)。窄切片原文不动。

## 已有入口

`SpellItem`、`HealingSpell`、`ProjectileSpell` 在 `Assets/Scripts/Items/Spells/`。出手动作有 `SorcerySpellAction`、`MiracleSpellAction`、`PyromancySpellAction`。记忆栏格数见 [FR-养成-03](角色养成.md)。催化器上的法术威力能读到，还不乘进治疗。四种催化器的战技差异：当前仓库未找到对应类型。

催化器只用这四个名字：法杖、圣铃、护符、火焰。

## 需求

### FR-法术-01 学会的法术留在列表里

**当前已有**

用灵魂向对应系的人买下一条法术，或捡起一条，或在王座用首领魂换成一条。它出现在持有列表里。休息、死亡、传送之后它仍在。还没放进记忆栏时，战斗中的法术轮换里没有它。

验收：买下、捡到或用首领魂换到一条法术。它在持有列表里。不放进记忆栏时，战斗轮换里没有它。

落点：学会之后留在列表里，休息、死亡、传送之后仍在（2.21）。当前法术不在记忆栏时不进入战斗轮换，快捷栏清掉图标（0.40）。

### FR-法术-02 催化器对上系才放得出来

**当前已有**

记忆一条魔法，手上握法杖，施法后出现弹体、斩击、护盾或该条的辅助效果，蓝下降。换成圣铃或护符再放同一条，没有这些效果。记忆一条奇迹，圣铃和护符都能放出；握火焰催化器时放不出。记忆一条火焰法术，只有火焰催化器放得出来。暗伤害的法术仍用它所属那一系的催化器。

验收：用法杖放魔法，有弹体或该条的效果，蓝下降。换成圣铃放同一条，没有效果。奇迹用圣铃或护符放得出，用火焰催化器放不出。火焰法术只用火焰催化器放得出。

落点：法杖放魔法，圣铃和护符放奇迹，火焰放火焰。拿错时没有弹体或治疗（2.26）。智力或信仰不够时仍放不出。

### FR-法术-03 记忆只在篝火改

**当前已有**

坐下后打开整理法术，把已学会的法术放进空栏。离开后战斗轮换里出现这一条，HUD 上能看见当前图标。栏位被占满时，再放一条放不进去。集中力跨过 [FR-养成-03](角色养成.md) 的门槛后多出的格子可以再放。战斗中打开不了这页，只能在已记入的几条之间轮换。

验收：坐下后把法术放进空栏。战斗里能轮到它。栏满时再放不进去。战斗中打不开整理页。

落点：记忆只在篝火改（2.33）。栏位格数见 [FR-养成-03](角色养成.md)。

### FR-法术-04 四种催化器的战技各走各的

**待补**

在蓝足够时按战技键：法杖让下一发魔法打出的伤害高于没开这次战技时；圣铃花一次蓝，之后大约一分钟生命持续上升，收起圣铃或改成双手握住另一侧武器时这段结束，挨打不打断；护符让下一次奇迹在挨普通命中时读条继续，生命仍下降；火焰催化器放出一次近身的火，命中的目标掉血。蓝不够时，上述特殊效果都不出现，蓝不进负数。

验收：蓝够时分别按四种催化器的战技。法杖让下一发更疼，圣铃花一次蓝后持续回血，收起圣铃这段就停，挨打不停。护符让下一次奇迹挨普通打时读条继续，火焰打出近身火。蓝不够时这些效果都没有，蓝不为负。

落点：这四种战技还不在。拿错催化器放不出见 [FR-法术-02](法术.md)。

### FR-法术-05 投射命中扣对应种类的生命

**待补**

对一条投射法术施法。弹体飞出并打中敌人时，该敌人生命下降，伤害种类按这条法术（魔法、火焰、雷电或暗）。砸在正面举起的盾上时，按盾对该种类的吸收结算，精力下降。翻滚无敌期间穿过时，生命不变。

验收：投射打中敌人掉血。打在举着的盾上按吸收结算。翻滚穿过时不掉血。

落点：弹体按学派进对应伤害段（0.19）。正面举盾按吸收减伤并扣精力（2.84）。没举盾或不是正面时仍扣生命。翻滚是否打开无敌见 [FR-移动-07](玩家移动与闪避.md)。

### FR-法术-06 治疗回到生命且不超过上限

**待补**

生命未满时用圣铃或护符放出即时治疗。成功后生命上升，不超过当前上限，蓝下降。即时治疗的回复量 = 催化器法术威力 × 该奇迹系数：微快恢复（Heal Aid）1.5、恢复（Heal）3.0、中恢复（Med Heal）4.1、大恢复（Great Heal）5.5、阳光疗愈（Soothing Sunlight）7.0、放出恢复（Projected Heal）1.7。换成法术威力更高的同系催化器，同一条即时治疗回得更多，仍然不超过上限。除阳光疗愈与放出恢复外，对队友只回一半（阳光疗愈队友 ×4.5、放出恢复队友 ×2.3）。持续回血的补充、丰饶之光、丰饶阳光按固定每秒量加生命，分别是每秒 5、7、10 点（温暖每秒 35 点）；换成法术威力更高的催化器，这个每秒量不变。总时长这里不写死。（Fandom、Wikidot）

验收：生命未满时放治疗。生命上升且不超过上限。换威力更高的同系催化器，回得更多，仍不超过上限。

落点：这三条按资产上的每秒量加生命，不超过上限，威力不改变这个量（2.23）。催化器上的法术威力能读到，还不乘进即时治疗（2.51）。一次性治疗仍走 `healAmount`。

### FR-法术-07 武器附魔加一段会结束的伤害

**当前已有**

对允许附魔的武器施放武器附魔。接下来的命中多出这段伤害。时间结束、换到另一把、或再涂上别的附魔后，这段消失。对 [FR-注入-08](注入与强化.md) 里涂不上的武器施放时，没有这段新伤害，法术不留下效果。

验收：对允许附魔的武器施放附魔，随后命中多一段伤害。换武器或时间结束后这段没了。对涂不上的注入武器施放，没有这段。

落点：涂得上的武器在时长内每次挥中多这段伤害，时间到、换武器、收进箱或再附魔后没有（2.89）。看得见的一段时间用 `FX_Sword_Fire`。

### FR-法术-08 蓝不够时失败起手

**当前已有**

把蓝降到低于当前法术的消耗再施法。角色有一段短动作，没有弹体、治疗或增益，蓝停在大于等于 0 的原处。记忆栏为空时再按施法，同样没有这些效果。蓝和精力都够、催化器也对时，效果出现。失败短动作播 `Shrug` 是项目沿用道具 0 次的表现，调研只写失败起手，不规定动作。

验收：蓝低于消耗时施法。有短动作，没有弹体或治疗，蓝不为负。记忆栏为空时同样没有效果。

落点：蓝不够时施法门禁播 `Shrug`，治疗在扣蓝失败时停住，蓝不进负数（0.31）。记忆栏里没有当前法术时也播 `Shrug`，不放效果，不扣蓝（0.40）。

### FR-法术-09 法术的行为类型与身体增益分组

**待补**

- 投射类：一条法术可以一次放出多发弹体、各算各的命中；有的落地后爆炸，有的带追踪转向。
- 近身类：多段斩击，可以附带异常积蓄。
- 范围类：在目标之间连跳；雾状法术在场内按最大生命的百分比持续扣血（是否有自伤与调研中待核对项一致）。
- 自身增益类：战吼、坚韧、铁身躯、隐身等在角色身上维持一段时间。身体增益分消耗品、战技、法术三层：同一层的增益互相顶替（同组名单写在法术资产上），不同层可以共存；持续回血类增益互相顶替；坐下休息清掉身体增益。攻击法术、武器附魔与即时治疗的效果随催化器法术威力变化，见 FR-法术-06。
- 任何法术在出手前摇被打断时，这一下不结算；护符霸体吟唱被打碎时蓝扣不扣，与调研中待核对项一致（见 [未入池](../../版本候选池/程序功能池/未入池.md)）。

验收：放一条多发弹体、一条雾状法术和一个自身增益。多发各算命中；雾内目标按最大生命百分比掉血；同层增益再放一个顶替前一个，坐火后增益清掉。

落点：当前仓库未找到对应类型。

### FR-法术-10 辅助法术、诱导与特殊投掷

**待补**

- 辅助法术：隐身（降低被发现距离）、静步（压低坠落伤害，仍不免固定致死高度）、沉默（封住场内施法）、安抚（让敌人不再主动发现）、修理（恢复当前装备着且未破的武器护甲耐久，见 [FR-装备-12](装备与道具.md)）。
- 诱导：引诱颅骨一类投掷物在落地处查看一段时间、把敌人引过去，头目无视，也能把敌人引到坠边摔下去；魅惑让一名人形敌人暂时改打同伴，持续约半分钟，名单与时长写在资产上，目标被拉得过远时仍按归位处理（见 [FR-敌人-05](敌人.md)）。
- 不死狩人护符：投中拟态（宝箱怪）使其瘫软，可以安全开箱取物；投中入侵者时一段时间禁止喝药。
- 其他投掷：短索一类用来拉远距离或引单个敌人。

验收：丢出引诱颅骨，一群普通敌人被引离而头目不跟；不死狩人护符投中未醒拟态后能安全开箱，投中入侵者期间其喝药不回复。

落点：当前仓库未找到对应类型。

### FR-法术-11 武器兼作催化器

**待补**

第二类催化器是武器（刺剑、镐、烛台、弯刀、恶魔爪痕等）：轻击、重击仍是这把武器的砍杀并扣精力，战技键改为施放当前记忆的法术、扣蓝，威力按武器面板上的法术威力；有一件奇迹武器战技先扣自己一截生命、再提高随后奇迹的威力（自伤换增伤）。学派与武器不合时，战技空挥、不放出法术。

验收：用一件兼作催化器的武器以战技放出当前记忆法术，蓝下降；学派不合时空挥。

落点：当前仓库未找到对应类型。
