# 法术

> **法术先学会，再在篝火放进记忆栏，手里的催化器还得对上这一系。** 本篇默认待补。学派门禁的现有动作类只核对法术类型和蓝，智力与信仰的完整规则以本篇为准。窄切片 [FR-属性-06](属性与升级.md) 原文不动。

## 已有入口

`SpellItem`、`HealingSpell`、`ProjectileSpell` 在 `Assets/Scripts/Items/Spells/`。出手动作有 `SorcerySpellAction`、`MiracleSpellAction`、`PyromancySpellAction`。记忆栏格数、法术威力数字、四种催化器的战技差异：当前仓库未找到对应类型。

催化器只用这四个名字：法杖、圣铃、护符、火焰。

## 需求

### FR-法术-01 学会的法术留在列表里

**待补**

用灵魂向对应系的人买下一条法术，或捡起一条，或在王座用首领魂换成一条。它出现在持有列表里。休息、死亡、传送之后它仍在。还没放进记忆栏时，战斗中的法术轮换里没有它。

### FR-法术-02 催化器对上系才放得出来

**待补**

记忆一条魔法，手上握法杖，施法后出现弹体、斩击、护盾或该条的辅助效果，蓝下降。换成圣铃或护符再放同一条，没有这些效果。记忆一条奇迹，圣铃和护符都能放出；握火焰催化器时放不出。记忆一条火焰法术，只有火焰催化器放得出来。暗伤害的法术仍用它所属那一系的催化器。

### FR-法术-03 记忆只在篝火改

**待补**

坐下后打开整理法术，把已学会的法术放进空栏。离开后战斗轮换里出现这一条，HUD 上能看见当前图标。栏位被占满时，再放一条放不进去。集中力跨过 [FR-养成-03](角色养成.md) 的门槛后多出的格子可以再放。战斗中打开不了这页，只能在已记入的几条之间轮换。

### FR-法术-04 四种催化器的战技各走各的

**待补**

在蓝足够时按战技键：法杖让下一发魔法打出的伤害高于没开这次战技时；圣铃使生命在一段时间内持续上升，直到这段结束或被打停；护符让下一次奇迹在挨普通命中时读条继续，生命仍下降；火焰催化器放出一次近身的火，命中的目标掉血。蓝不够时，这些效果都不出现。

### FR-法术-05 投射命中扣对应种类的生命

**待补**

对一条投射法术施法。弹体飞出并打中敌人时，该敌人生命下降，伤害种类按这条法术（魔法、火焰、雷电或暗）。砸在正面举起的盾上时，按盾对该种类的吸收结算，精力下降。翻滚无敌期间穿过时，生命不变。

### FR-法术-06 治疗回到生命且不超过上限

**待补**

生命未满时用圣铃或护符放出治疗。成功后生命上升，不超过当前上限，蓝下降。换成法术威力更高的同系催化器，同一条治疗回得更多，仍然不超过上限。

### FR-法术-07 武器附魔加一段会结束的伤害

**待补**

对允许附魔的武器施放武器附魔。接下来的命中多出这段伤害。时间结束、换到另一把、或再涂上别的附魔后，这段消失。对 [FR-注入-08](注入与强化.md) 里涂不上的武器施放时，没有这段新伤害，法术不留下效果。

### FR-法术-08 蓝不够时失败起手

**待补**

把蓝降到低于当前法术的消耗再施法。角色有一段短动作，没有弹体、治疗或增益，蓝停在大于等于 0 的原处。记忆栏为空时再按施法，同样没有这些效果。蓝和精力都够、催化器也对时，效果出现。
