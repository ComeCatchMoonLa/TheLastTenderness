# 注入与强化

> **再注入覆盖旧的，加号留下。炭火没交之前选不到那一组。普通强化停在加十，鳞片和闪耀停在加五，并且不进十五种注入。王座用首领魂换走一项。五项需求里任一项不足时挥击更慢、打中更弱。未注入、重、锐、精、原质、空虚涂得上附魔，火、深、水晶、雷、混沌、暗、祝福、单纯、毒、血涂不上。** 待补的是四枚戒指戴上就能看见变化，以及附魔的积蓄。手上换模型、三部位穿戴仍是 [FR-装备-01](装备与道具.md) 至 [FR-装备-07](装备与道具.md)。需求不足时伤害变低的比较仍是 [FR-属性-05](属性与升级.md)。

## 已有入口

武器数据在 `WeaponItem`。穿戴在 `CharacterInventoryManager` 与 `WeaponHolderSlot`。护甲只有头、躯干、下身。面板文字在 `ItemStatsWinManager`。

十五种注入、炭火分组、强化加号上限、王座兑换已经有。戒指槽有四格，戴上之后的各类效果还没有。附魔涂得上的名单和会结束的附加伤害在 2.89。积蓄还不在。

## 需求

### FR-注入-01 再注入覆盖旧的，加号留下

**当前已有**

把一把已经强化过的武器做成十五种注入中的一种。面板变成该注入的伤害种类和属性字母。再做成另一种，旧种类消失，新种类出现，强化加号仍是刚才那个数字。宝石按次消耗，旧宝石不回到背包。十五种的名字和字母以铁匠菜单为准，分组与调研中待核对项一致。

验收：把已强化的武器注入一种，再改成另一种。面板换成新的伤害种类，加号还在，旧宝石不回到包里。

落点：再注入覆盖旧种类，加号留下（2.30）。

### FR-注入-02 炭火交给安德烈后才出现那一组

**当前已有**

炭火还在背包时，铁匠安德烈的注入菜单里没有这一组。把炭火交给他之后，这一组可以选，包里的对应宝石能用在合格武器上。已经做在武器上的注入，在炭火交出去之前就保持在面板上。

验收：炭火还在包里时，安德烈的菜单没有这一组。交出去之后，这一组可以选。

落点：炭火没交之前选不到那一组（2.35）。

### FR-注入-03 普通武器停在加十，另两条材料停在加五

**当前已有**

用普通矿石给一把可注入的武器强化。加号升到加十后，菜单不再给出下一级。用鳞片强化的武器升到加五后停住，闪耀矿石的武器同样停在加五。两种材料不能互相替代。每一级的材料个数和灵魂价格与调研中待核对项一致。

验收：普通武器加到加十后没有下一级。鳞片武器和闪耀矿石武器加到加五后没有下一级。

落点：普通强化停在加十，鳞片和闪耀停在加五（2.46）。

### FR-注入-04 王座用首领魂换走一项

**当前已有**

把一枚首领魂交给王座上的人，在武器、法术或该魂列出的其他项里选一项。确认后魂从背包消失，选中的那一项进入背包或学会列表。直接把这枚魂当作灵魂道具用掉时，计数增加，王座上不再能用同一枚去换。他不在场时，这次兑换打不开。

验收：在王座选一项换掉首领魂。魂消失，选中的进入背包或学会列表。把魂直接用成灵魂后，王座不能再用这枚去换。

落点：确认后魂消失，选中的那一项拿走（2.47）。

### FR-注入-05 鳞片和闪耀路线不进十五种注入

**当前已有**

对一把用鳞片或闪耀矿石强化的武器打开注入。菜单里没有十五种注入。普通矿石的武器在炭火已解锁时，能看到属于它的那些注入。

验收：对鳞片或闪耀路线的武器打开注入。十五种都不在菜单里。

落点：鳞片和闪耀路线不进十五种注入（2.58）。

### FR-注入-06 需求不足时挥击变慢

**当前已有**

装备一把写了需求的武器，让力量、敏捷、智力、信仰、幸运里至少一项低于面板。挥击和收招慢于该武器需求全部满足时的同一段。五项里任一项不足，都出现这种变慢。伤害高低的比较仍按 [FR-属性-05](属性与升级.md)。

验收：让五项需求里任一项不足，挥同一段。动作慢于全部满足时。伤害高低另看 FR-属性-05。

落点：五项里任一项低于需求时，速度和伤害按同一套系数变低（2.38、2.82）。没填的需求不参与比较。

### FR-注入-07 四枚戒指，类型戴上就能看见

**待补**

戒指槽有四格。第五枚戴不上。按类型各戴一枚并观察：

| 类型 | 操作后能看见的 |
| --- | --- |
| 加成或负重 | 状态页上的上限或负重百分比变化 |
| 回复 | 精力回升变快，或血瓶、灰瓶一口回复变多，次数不变 |
| 翻滚 | 同一负重档下，翻滚的无敌或外形与摘下时不同（卡尔萨斯血环把无敌窗从第 2～14 帧延到第 2～18 帧） |
| 施法或处决 | 同一条法术或同一次背刺，结果与摘下时不同 |
| 保魂或保血迹 | 死亡时灵魂不交出、死亡点没有自己的血迹；或让已经落在地上的旧血迹在再死后多留一次（咒死致死时是否生效与调研中待核对项一致） |
| 跌落 | 同一高度坠落扣血变少；不能越过固定致死高度 |
| 发现力 | 状态页上的发现力数字上升 |
| 加法术栏位 | 在集中力给出的记忆格之外多记忆一格 |
| 联机 | 隐身接近、改变敌人仇恨、改变阵营颜色等 |
| 遮住空虚 | 外形恢复，暗印仍在，再次死亡空虚仍会上升 |

同名的不同档位戒指不能同戴（如一枚戒指与它的 +1、+2 档不能同时戴，各档随周目出现）；异名戒指可以同戴。逐枚效果与互相覆盖名单写在戒指资产上。

验收：戴满四枚。第五枚戴不上。按类型各看一次状态页、回复、翻滚、施法或处决、或空虚外形。遮外形的那枚戴上后暗印还在。


### FR-注入-08 只有允许附魔的武器涂得上

**待补**

对未注入、重、锐、精、原质或空虚的武器使用松脂或法术附魔。接下来的命中多出该附魔的伤害或积蓄，持续时间结束后这段消失。对火、深、水晶、雷、混沌、暗、祝福、单纯、毒、血这些注入再涂，没有这段新伤害。本身标成不能附魔的武器，未注入也涂不上。弓、弩、大弓一律不能附魔；盾只能被魔力武器、强魔力武器附魔；Boss 魂武器默认不能涂，例外六件（安里直剑、狂王钉锤、暗影剑、龙牙、烟之特大剑、太阳直剑），普通武器里屠夫刀、信徒火炬、侍女短剑、学者烛台、火炬不能涂。涂在不允许的武器上不生效也不消耗道具。同一把武器同时只保留一段武器附魔：再涂一段盖掉先涂；附有附魔的武器切到备用格或收起时，这段效果消失。松脂、短效松脂、元素涂剂（红涂剂等）与法术附魔同走这一条；涂抹动作开始后被打断、涂剂退不退回，与调研中待核对项一致。

验收：给未注入、重、锐、精、原质或空虚的武器涂附魔，命中多出一段，时间结束后没有。给火、深、水晶、雷、混沌、暗、祝福、单纯、毒或血注入再涂，没有这段。同一件再涂一段盖掉先涂；切到备用格后效果消失。

落点：这张名单决定涂不涂得上，涂上的伤害会结束（2.89）。盖写、切武器消失与涂剂分类还不在。积蓄还不在。

### FR-注入-09 退回石、材料分段、不可注入类别与空虚幸运

**待补**

- 用该注入对应的专用退回石，可以把武器从这一种注入退回未注入：不退宝石和灵魂，强化加号保留。
- 普通武器的强化矿石按强化段分四档，最高一档是板（圆盘），板每种每周目获得枚数有限；鳞片路线与闪耀路线各自分段，逐档材料个数写在资产上。
- 弓、弩、大弓、法器、火炬和盾不进十五种注入（其中哪些连附魔也不能涂，见 FR-注入-08）。
- 空虚（亡者）注入的武器按强化等级给**当前手**附加幸运：+0 起附加 2 点，逐档升到 +10 时 5 点；双手持时最多按 +10 计，99 封顶；武器收起或卸下即失效，放在备用格不生效；其他注入不给附加幸运。

验收：用退回石把注入武器退回未注入，加号保留、宝石不退；弓、弩、法器、火炬、盾不在十五注入里；空虚武器在当前手按强化等级加幸运，收起或放进备用格后失效。

落点：当前仓库未找到对应类型。
