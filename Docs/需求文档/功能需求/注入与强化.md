# 注入与强化

> **武器同时只有一种注入，强化加号和注入各自保留。** 本篇默认待补。手上换模型、三部位穿戴仍是 [FR-装备-01](装备与道具.md) 至 [FR-装备-07](装备与道具.md)。需求不足时伤害变低的比较仍是 [FR-属性-05](属性与升级.md)。

## 已有入口

武器数据在 `WeaponItem`。穿戴在 `CharacterInventoryManager` 与 `WeaponHolderSlot`。护甲只有头、躯干、下身。面板文字在 `ItemStatsWinManager`。

十五种注入、炭火、强化加号、王座兑换、戒指、附魔能否涂上：当前仓库未找到对应类型。

## 需求

### FR-注入-01 再注入覆盖旧的，加号留下

**待补**

把一把已经强化过的武器做成十五种注入中的一种。面板变成该注入的伤害种类和属性字母。再做成另一种，旧种类消失，新种类出现，强化加号仍是刚才那个数字。宝石按次消耗，旧宝石不回到背包。十五种的名字和字母以铁匠菜单为准，分组与调研中待核对项一致。

### FR-注入-02 炭火交给安德烈后才出现那一组

**待补**

炭火还在背包时，铁匠安德烈的注入菜单里没有这一组。把炭火交给他之后，这一组可以选，包里的对应宝石能用在合格武器上。已经做在武器上的注入，在炭火交出去之前就保持在面板上。

### FR-注入-03 普通武器停在加十，另两条材料停在加五

**待补**

用普通矿石给一把可注入的武器强化。加号升到加十后，菜单不再给出下一级。用鳞片强化的武器升到加五后停住，闪耀矿石的武器同样停在加五。两种材料不能互相替代。每一级的材料个数和灵魂价格与调研中待核对项一致。

### FR-注入-04 王座用首领魂换走一项

**待补**

把一枚首领魂交给王座上的人，在武器、法术或该魂列出的其他项里选一项。确认后魂从背包消失，选中的那一项进入背包或学会列表。直接把这枚魂当作灵魂道具用掉时，计数增加，王座上不再能用同一枚去换。他不在场时，这次兑换打不开。

### FR-注入-05 鳞片和闪耀路线不进十五种注入

**待补**

对一把用鳞片或闪耀矿石强化的武器打开注入。菜单里没有十五种注入。普通矿石的武器在炭火已解锁时，能看到属于它的那些注入。

### FR-注入-06 需求不足时挥击变慢

**待补**

装备一把写了需求的武器，让力量、敏捷、智力、信仰、幸运里至少一项低于面板。挥击和收招慢于该武器需求全部满足时的同一段。五项里任一项不足，都出现这种变慢。伤害高低的比较仍按 [FR-属性-05](属性与升级.md)。

### FR-注入-07 四枚戒指，类型戴上就能看见

**待补**

戒指槽有四格。第五枚戴不上。按类型各戴一枚并观察：

| 类型 | 操作后能看见的 |
| --- | --- |
| 加成或负重 | 状态页上的上限或负重百分比变化 |
| 回复 | 精力回升变快，或血瓶、灰瓶一口回复变多，次数不变 |
| 翻滚 | 同一负重档下，翻滚的无敌或外形与摘下时不同 |
| 施法或处决 | 同一条法术或同一次背刺，结果与摘下时不同 |
| 遮住空虚 | 外形恢复，暗印仍在，再次死亡空虚仍会上升 |

同名各档能否叠戴，与调研中待核对项一致。

### FR-注入-08 只有允许附魔的武器涂得上

**待补**

对未注入、重、锐、精、原质或空虚的武器使用松脂或法术附魔。接下来的命中多出该附魔的伤害或积蓄，持续时间结束后这段消失。对火、深、水晶、雷、混沌、暗、祝福、单纯、毒、血这些注入再涂，没有这段新伤害。本身标成不能附魔的武器，未注入也涂不上。
