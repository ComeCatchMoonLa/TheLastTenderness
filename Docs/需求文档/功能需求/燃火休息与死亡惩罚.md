# 燃火休息与死亡惩罚

> **玩家死亡后会停在死亡动作里，不能再移动和攻击。未点燃的燃火在脚本里可以点着。** 休息回满、复活敌人、补药、死亡掉灵魂再捡回，标为待补。死亡灵魂标记：当前仓库未找到对应类型。篝火菜单四项、分瓶和烧碎片见 [篝火菜单](篝火菜单.md)。本篇编号原文不动。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 点燃与休息入口 | `CampFireInteractable` | `Assets/Scripts/Items/Interactions/CampFireInteractable.cs` |
| 点燃提示 | `CampFireLitPopUpUI` | `Assets/Scripts/UI/Player UI/Pop Up Windows/CampFireLitPopUpUI.cs` |
| 玩家死亡 | `PlayerStatsManager.TakeDamage` 调用 `CharacterStatsManager.Death` | `Assets/Scripts/Character/Player/PlayerStatsManager.cs` |
| 交互检测 | `PlayerManager.CheckForInteractableObject` | `Assets/Scripts/Character/Player/PlayerManager.cs` |

`hasBeenActived` 为假时，交互播放 `"Pick Up Item"`，弹出「篝火燃起」，打开火焰，提示改为「休息」。`hasBeenActived` 为真时，交互方法是空的。

当前 `Game` 里燃火挂在未激活父节点下，进游戏看不到。验收本系统时，只激活场景里已有的那一个 `CampFireInteractable`，不新摆关卡。

## 需求

### FR-燃火-01 点燃

**当前已有**

将已有燃火物体激活后，对尚未点燃的它交互。角色播放拾取动作，屏幕出现燃起提示，火焰可见，再次靠近时提示是「休息」。

已点燃后的回满、补药、复活敌人和死亡血迹是 [FR-燃火-02](燃火休息与死亡惩罚.md) 起的待补。灰瓶回蓝见 [FR-回复-05](回复类消耗品.md)。

### FR-燃火-02 休息恢复自身

**待补**

对已点燃的燃火交互并确认休息。角色生命、精力和专注回到各自上限。休息完成前不能移动和攻击。完成后可以离开并再次战斗。

落点：`CampFireInteractable.Interact` 已点燃的分支，调用 `PlayerStatsManager` 上已有的回满手段（把当前值写成上限并刷新三条 HUD）。

### FR-燃火-03 休息恢复敌人

**待补**

先满足 [FR-敌人-04](敌人.md)，近战敌人死亡并消失。再在这处燃火休息成功。该敌人回到死亡前的位置，生命为满，会再次发现并攻击玩家。未休息时它保持消失。

落点：休息时使用这只敌人原有的预制或场景实例状态。`EnemyStatsManager.Death` 现有逻辑会延时 `Destroy`。恢复方式由当时的技术设计二选一：死亡时先停用并记下位置，或按原预制在原位再生成。本需求只验收玩家看到的结果。

### FR-燃火-04 休息补满回复次数

**待补**

回复次数未满时休息成功。次数回到上限，见 [FR-回复-06](回复类消耗品.md)。

### FR-燃火-05 死亡留下灵魂

**待补**

玩家持有灵魂时被敌人打死。角色播放死亡并停止操作（FR-燃火-08）。身上的灵魂数变为 0，HUD 数字变为 0。死亡位置出现可交互的灵魂残留，数量等于死亡前持有的灵魂。

当前仓库未找到对应类型。落点：在 `PlayerStatsManager` 死亡流程里记下数量，并生成一个现有 `Interactable`（可与 `PickUpItem` 同类）放在死亡点。

身上本来就是 0 时死亡，不生成残留。

### FR-燃火-06 捡回灵魂

**待补**

玩家再次可操作后走到 FR-燃火-05 的残留处并交互。残留消失，身上的灵魂增加残留记下的数量，HUD 数字同步增加。

怎么从死亡回到可操作：在燃火休息的完成流程里把玩家放回该燃火旁并清掉死亡状态。本条验收从这个状态接着走。

### FR-燃火-07 未捡回时再次死亡

**待补**

残留还在、身上又获得了新的灵魂时再次死亡。旧残留消失，新残留只等于这次死亡时身上的灵魂。旧的那一笔不能再捡回。

### FR-燃火-08 死亡后不能操作

**当前已有**

玩家生命降到 0。角色播放死亡动作，`isDead` 为真。移动、翻滚、攻击和喝药都不再出现。敌人可以仍留在场上。
