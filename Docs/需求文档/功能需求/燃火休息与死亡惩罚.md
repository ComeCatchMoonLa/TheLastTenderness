# 燃火休息与死亡惩罚

> **玩家死亡后会停在死亡动作里，不能再移动和攻击。未点燃的燃火可以点着。休息回满自身、让已死的近战回到满血、把回复次数写回上限。死亡时灵魂变成零并留下残留，捡回后加回身上；没捡就再死，只留新的一笔。** 篝火菜单四项、分瓶和烧碎片见 [篝火菜单](篝火菜单.md)。本篇编号原文不动。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 点燃与休息入口 | `CampFireInteractable` | `Assets/Scripts/Items/Interactions/CampFireInteractable.cs` |
| 点燃提示 | `CampFireLitPopUpUI` | `Assets/Scripts/UI/Player UI/Pop Up Windows/CampFireLitPopUpUI.cs` |
| 玩家死亡 | `PlayerStatsManager.TakeDamage` 调用 `CharacterStatsManager.Death` | `Assets/Scripts/Character/Player/PlayerStatsManager.cs` |
| 交互检测 | `PlayerManager.CheckForInteractableObject` | `Assets/Scripts/Character/Player/PlayerManager.cs` |

`hasBeenActived` 为假时，交互播放 `"Pick Up Item"`，弹出「篝火燃起」，打开火焰，提示改为「休息」。已点燃后再交互，附近没有敌对者时可以坐下，生命、精力和专注回到上限，回复次数写回上限。死亡把 `soulCount` 写成 0，并在死亡点留下可捡的残留。

当前 `Game` 里燃火挂在未激活父节点下，进游戏看不到。验收本系统时，只激活场景里已有的那一个 `CampFireInteractable`，不新摆关卡。

## 需求

### FR-燃火-01 点燃

**当前已有**

将已有燃火物体激活后，对尚未点燃的它交互。角色播放拾取动作，屏幕出现燃起提示，火焰可见；同一次交互随即自动坐下，按 [FR-燃火-02](燃火休息与死亡惩罚.md) 起完成整段休息结算（回满、补瓶、敌人重置、这堆火写成重生点），篝火菜单出现。不需要再交互第二次，也没有「只点火、不坐下」的分支。

落点：播放拾取，火焰可见，点燃后直接进入坐下休息，提示改成「休息」。燃起提示先激活物体再淡入淡出（0.47）。

已点燃后的回满、补药、复活敌人和死亡血迹见 [FR-燃火-02](燃火休息与死亡惩罚.md) 起。灰瓶回蓝见 [FR-回复-05](回复类消耗品.md)。附近有敌对者时坐不下去，见 [FR-篝火-08](篝火菜单.md)。

### FR-燃火-02 休息恢复自身

**当前已有**

对已点燃的燃火交互并确认休息。角色生命、精力和专注回到各自上限。休息完成前不能移动和攻击。完成后可以离开并再次战斗。

落点：`CampFireInteractable` 已点燃的分支把当前生命、精力、专注写成上限并刷新 HUD（2.4）。

### FR-燃火-03 休息恢复敌人

**当前已有**

先满足 [FR-敌人-04](敌人.md)，近战敌人死亡并消失。再在这处燃火休息成功。该敌人回到死亡前的位置，生命为满，会再次发现并攻击玩家。未休息时它保持消失。

落点：休息后已死的近战回到满血（2.43）。头目是否同样回来不在本条，见 [头目](头目.md)。

### FR-燃火-04 休息补满回复次数

**当前已有**

回复次数未满时休息成功。次数回到上限，见 [FR-回复-06](回复类消耗品.md)。

### FR-燃火-05 死亡留下灵魂

**当前已有**

玩家持有灵魂时被敌人打死。角色播放死亡并停止操作（FR-燃火-08）。身上的灵魂数变为 0，HUD 数字变为 0。死亡位置出现可交互的灵魂残留，数量等于死亡前持有的灵魂。

有的戒指让死亡不交出灵魂：戴上后死亡，身上计数保留，死亡点没有可捡血迹；另有戒指让已经落在地上的旧血迹在再死后多留一次机会。咒死直接致死时这些戒指是否生效，与调研中待核对项一致。身上本来就是 0 时死亡是否生成残留，待实机（见 [未入池](../../版本候选池/程序功能池/未入池.md)），本条现状按不生成残留验收。

落点：`PlayerStatsManager` 死亡时把 `soulCount` 写成 0，并在死亡点留下残留（2.40）。使用暗印不留这份可捡血迹，见 [FR-周目-03](周目与结局.md)。

### FR-燃火-06 捡回灵魂

**当前已有**

玩家再次可操作后走到 FR-燃火-05 的残留处并交互。残留消失，身上的灵魂增加残留记下的数量，HUD 数字同步增加。

怎么从死亡回到可操作：在燃火休息的完成流程里把玩家放回该燃火旁并清掉死亡状态。本条验收从这个状态接着走。落点：捡回走 2.41。

### FR-燃火-07 未捡回时再次死亡

**当前已有**

残留还在、身上又获得了新的灵魂时再次死亡。旧残留消失，新残留只等于这次死亡时身上的灵魂。旧的那一笔不能再捡回。

落点：再死只留新的一笔（2.42）。

### FR-燃火-08 死亡后不能操作

**当前已有**

玩家生命降到 0。角色播放死亡动作，`isDead` 为真。移动、翻滚、攻击和喝药都不再出现。敌人可以仍留在场上。随后人自动回到上一次坐下的篝火旁（不是停在死亡动作里等操作），死亡状态清掉，在火边恢复可操作；复活时精力与专注回满，血瓶与灰瓶按当前分配补满（[FR-篝火-05](篝火菜单.md)），普通敌人按 FR-燃火-09 重置；身上其余数字按死亡结算（魂为 0、余烬熄灭），见 [FR-燃火-05](燃火休息与死亡惩罚.md)。背包里的灵魂道具与 HUD 上的计数是两笔账：死亡只把计数归零，没用过的魂道具不掉、仍在背包。落点：当前人停在死亡动作里、场上没有可捡残留也没有回到火边的流程，需要在死亡播完后把玩家放回上一次休息的燃火并清除 `isDead`。

### FR-燃火-09 休息还清异常、重置敌人并保持世界状态

**待补**

一次坐下的休息结算，除了 FR-燃火-02、FR-燃火-04，还包括：

- 身上的毒、剧毒、出血与冰霜的持续效果和积蓄清掉；咒死层清不清与调研中待核对项一致。
- 普通敌人（含精英）全图回到放置点、生命补满、仇恨清空；已经打死的头目、拟态、结晶蜥蜴、被击退的入侵 NPC 不回来；活着的头目在休息或传送后脱战，下次再打是满生命。
- 门、杠杆、放下的桥、踢下的梯子、打开的幻影墙与打坏的掩体、已经接通的短路、地上拾取过的道具（含钥匙与要交给 NPC 的物件）、已经拿空的箱子、NPC 谈过的进度与店货解锁，休息后保持，不回滚。
- 身上灵魂计数休息不减少。击倒普通敌人有概率回 1～2 口瓶，击倒入侵者回若干口；具体概率与几口写在敌人资产上。

落点：现状 FR-燃火-03 只把本处已死近战写回满血，全图重置、清异常与世界状态保持未找到类型。
