# 状态积蓄

> **出血、中毒、剧毒、冰霜、咒死各有一条槽。槽蓄满才结算。无敌期间这一下不加槽。** 护甲让普通伤害变少仍是 [FR-伤害-06](命中判定与伤害.md)。

## 已有入口

`StatusBuildup`、`BleedMeter`、`Frostbite`、`CurseMeter` 在 `Assets/Scripts/Character/`。出血蓄满掉一截（2.45）。中毒持续掉血，紫苔能停（2.69）。剧毒不能用解中毒的那一瓶（2.71）。冰霜蓄满后用火解开（2.70）。咒死蓄满则死亡（2.68）。无敌期间这一下不加槽（2.57）。翻滚自己打开无敌见 [FR-移动-07](玩家移动与闪避.md)。

比例、时长和消退速度与调研中待核对项一致。

## 需求

### FR-异常-01 出血蓄满立刻掉一截血

**当前已有**

用带出血的攻击连续打中同一目标，槽看得见往上走。蓄满时目标立刻再掉一截生命，槽清空。之后可以重新积。停手不打，槽在蓄满之前往回掉。蓄满之前喝红苔，槽被清掉，这一下不掉那截血。

### FR-异常-02 中毒持续掉血，紫苔能解除

**当前已有**

把中毒槽蓄满。目标在一段时间内生命继续下降，这段结束前使用紫苔，下降停止。不用药则一段时间后自己停。

### FR-异常-03 剧毒和中毒用不同的药解除

**当前已有**

把剧毒槽蓄满。目标持续掉血，并且精力回复慢于中毒之前。使用普通紫苔，剧毒的持续掉血仍在。使用开花紫苔，持续掉血停止，精力回复恢复。

### FR-异常-04 冰霜蓄满后火能提前解开

**当前已有**

把冰霜槽蓄满。目标立刻掉一截生命，并且接下来吸收变差或精力回复变慢。对这个目标造成火焰伤害后，这层变慢或变脆消失。喝蓝苔也能解开。不造成火焰伤害、也不喝蓝苔时，这段自己结束。槽还没满时，蓝苔能把积蓄清掉。

### FR-异常-05 咒死蓄满则死亡

**当前已有**

把咒死槽蓄满。目标进入死亡，不能再操作或再选招。槽还没满时离开来源，槽往回掉，目标保持存活。没满时使用祝福，槽被清掉。

### FR-异常-06 无敌期间这一下不加槽

**当前已有**

在翻滚的受击豁免里吃到本来会推进出血或毒的一击。生命不变，对应的槽也不上升。豁免结束后再吃同样一击，槽上升。
