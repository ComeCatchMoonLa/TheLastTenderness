# 状态积蓄

> **出血、中毒、剧毒、冰霜、咒死各有一条槽。槽蓄满才结算，停手之后往回掉。** 本篇默认待补。护甲让普通伤害变少仍是 [FR-伤害-06](命中判定与伤害.md)。

## 已有入口

`DamageCollider` 结算五段直接伤害，不推进异常槽。紫苔、红苔一类解除道具：当前仓库未找到对应类型。

比例、时长和消退速度与调研中待核对项一致。

## 需求

### FR-异常-01 出血蓄满立刻掉一截血

**待补**

用带出血的攻击连续打中同一目标，槽看得见往上走。蓄满时目标立刻再掉一截生命，槽清空。之后可以重新积。停手不打，槽在蓄满之前往回掉。

### FR-异常-02 中毒持续掉血，紫苔能解除

**待补**

把中毒槽蓄满。目标在一段时间内生命继续下降，这段结束前使用紫苔，下降停止。不用药则一段时间后自己停。

### FR-异常-03 剧毒和中毒用不同的药解除

**待补**

把剧毒槽蓄满。目标持续掉血，并且精力回复慢于中毒之前。使用普通紫苔，剧毒的持续掉血仍在。使用开花紫苔，持续掉血停止，精力回复恢复。

### FR-异常-04 冰霜蓄满后火能提前解开

**待补**

把冰霜槽蓄满。目标立刻掉一截生命，并且接下来吸收变差或精力回复变慢。对这个目标造成火焰伤害后，这层变慢或变脆消失。不造成火焰伤害时，这段自己结束。

### FR-异常-05 咒死蓄满则死亡

**待补**

把咒死槽蓄满。目标进入死亡，不能再操作或再选招。槽还没满时离开来源，槽往回掉，目标保持存活。

### FR-异常-06 无敌期间这一下不加槽

**待补**

在翻滚的受击豁免里吃到本来会推进出血或毒的一击。生命不变，对应的槽也不上升。豁免结束后再吃同样一击，槽上升。
