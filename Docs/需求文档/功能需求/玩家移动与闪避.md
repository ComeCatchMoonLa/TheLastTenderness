# 玩家移动与闪避

> **跑动、冲刺、翻滚、后撤和跳跃已经能在当前玩家上操作。轻推与推满分成两种移速。** 落差够时会切入落地，落地后能走。待补的是翻滚途中的一段受击豁免，以及精力大于 0 但付不清时的闪避和跳跃。无敌标志为真时不受伤见 [FR-伤害-03](命中判定与伤害.md)，那一条当前已有。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 移动、冲刺扣精力、翻滚、后撤、跳跃、下落 | `PlayerLocomotionManager` | `Assets/Scripts/Character/Player/PlayerLocomotionManager.cs` |
| 移动量、冲刺、翻滚与后撤的输入 | `InputManager` | `Assets/Scripts/Character/Player/InputManager.cs` |
| 翻滚状态旗标 | `HandleRollState` | `Assets/Scripts/Animator/HandleState/Humanoid/HandleRollState.cs` |
| 播动作并锁普通移动 | `CharacterAnimatorManager.PlayTargetAnimation` | `Assets/Scripts/Character/CharacterAnimatorManager.cs` |

交互动画期间 `HandleMove` 不再改速度。精力不够支付时，`DeductStamina` 不扣，对应动作不播放。

## 需求

### FR-移动-01 地面移动

**当前已有**

角色未处于交互动画、也没有待处理的翻滚输入时，按住移动。角色沿镜头水平方向在地面移动，精力条不因此下降。

验收：按住移动。角色沿镜头方向在地面移动，精力不因此下降。


### FR-移动-02 冲刺

**当前已有**

角色有移动量、未瞄准、未格挡，按住闪避键。精力高于冲刺门槛时，角色以快于 FR-移动-01 的速度移动，精力持续下降。精力落到门槛及以下时，冲刺停止，速度回到地面移动。

门槛和每帧消耗在 `PlayerLocomotionManager` 上配置，需求不写死数字。「未瞄准、未格挡」与 FR-移动-05 的瞄准中不能跳同属操作层输入互斥，调研未写，是项目细化。

验收：有方向时按住闪避键。速度快于跑步，精力下降；精力降过门槛后速度回到跑步。


### FR-移动-03 翻滚

**当前已有**

短按闪避键，且松手时移动量大于 0，精力足以支付翻滚。角色转向当时的移动方向，播放 `Rolling`。翻滚期间普通移动不再改速度；动作结束后可以再次移动。

验收：有方向时短按闪避。角色朝输入方向播放翻滚，翻滚时推移动摇不改速度，结束后可以再跑。


### FR-移动-04 后撤步

**当前已有**

短按闪避键，且松手时移动量为 0，精力足以支付后撤。角色播放 `Backstep`，期间不能用普通移动改速度。

验收：站定后短按闪避。角色播放后撤步。


### FR-移动-05 冲刺中起跳、下落与落地

**待补**

角色处于冲刺中（FR-移动-02）、未瞄准、未处于交互动画，精力足以支付跳跃时按下跳跃键。角色朝冲刺方向离开地面。只是行走或跑步、没有进入冲刺时，按跳跃键不起跳（官方操作表：跳跃是冲刺中按键；按键设置可改成闪避键承担，但仍要在冲刺中）。离地后播放 `Falling`。落差达到当前配置时播放 `Land`。

瞄准中按跳跃，角色不起跳（操作层输入互斥，调研未写，是项目细化）。

验收：冲刺中按跳跃。角色朝冲刺方向离地并播放下落，落差够时切入落地；只是跑步不冲刺时按跳跃，不起跳。瞄准中按跳跃，角色不起跳。落地后能走。点 Play 后、运行中点层级面板之后，角色仍站在地上，不悬空、不陷进地里停在下落。

落点：`HandleFall` 只在刚从空中落到地上的那一步切一次，落差够播 `Land`，不够播 `NonCombat Whole Body Empty`（0.10）。判地的三层是 `PlayerLocomotionManager` 里的常量；玩家自己的 `Character Collider Blocker` 是运动学刚体，不和身体胶囊体相撞。点 Play 后、运行中点层级面板之后人仍站在地上（0.38）。现状起跳只校验移动量，冲刺前提还没接。

### FR-移动-06 精力大于 0 就能闪避和跳跃

**待补**

精力大于 0 但低于翻滚、后撤或跳跃的配置消耗时做对应操作。角色仍播放 `Rolling`、`Backstep` 或 `Jump`，精力降到 0 以下，最低 -60。精力小于等于 0 时不播放这些动作。负重达到或超过上限时翻滚和后撤另算，见 [FR-负重-05](负重与翻滚.md)。

验收：把精力耗到不够支付，再试翻滚、后撤、跳跃。动作不出现，精力不变。

落点：当前 `DeductStamina` 付不清就失败，动作不播放，精力不变。

### FR-移动-07 翻滚中的受击豁免

**待补**

翻滚动作进行中的一段时间内，敌人攻击打在角色上，生命不下降，受击动画不播放。这段时间结束后，再被打到会掉血。帧数按 30 帧计：以扣精力的动作开始帧为第 1 帧，轻档、中档的无敌从第 2 帧起、到第 14 帧止，共 13 帧，第 1 帧可挨打；沉重档共 12 帧，按帧测总帧数推算为第 2～13 帧，逐帧直测待核对。后撤步全程可以受伤，没有无敌窗口，躲攻击靠位移。

验收：翻滚途中被近战打中。生命不降。翻滚结束后再被打中，生命下降。

落点：`CharacterAnimatorManager` 已有 `EnableIsVulnerable` / `DisableIsVulnerable`，会改 `CharacterStatsManager.isInvulnerable`。脚本不保证翻滚片段一定调用它们。`HandleRollState` 只写 `isRolling`。标志为真时的不受伤见 [FR-伤害-03](命中判定与伤害.md)。

### FR-移动-08 行走与跑步

**当前已有**

移动输入较小但大于零时，角色以明显慢于跑步的速度行走。输入推满时速度回到 FR-移动-01 的跑步。冲刺仍快于跑步。

验收：轻推摇杆与推满各走一段。轻推更慢，推满回到跑步，按住闪避仍更快。

落点：`PlayerLocomotionManager` 上的 `walkUntil` 与 `walkSpeed`（2.72）。门槛或行走速度没填成慢于跑步时，仍走跑步。负重 70.0% 以下走路、跑步、冲刺速度不随档位变化：30% 以下不比中量更快，轻档只有翻滚距离更远（翻滚攻击取消早 2 帧）；高于 70% 才整体变慢。

### FR-移动-09 掉落伤害分三档

**待补**

从可行走地面落下。落差小：落地只播 `Land`，不扣血。中等落差：按当前生命上限扣一截血，落地硬直比无伤落地更长。落差超过固定的致死高度：不经落地动作直接死亡，这个高度是固定值、不随属性变化；掉进空坑时，在落地之前即按死亡结算。扣多少由六项合成：高低差、生命上限、装备总重、负重上限、体力、技量；技量在 8～20 之间减伤最明显。银猫戒指与静步法术压低扣血，但越过固定致死高度仍死；惜别之泪能接住非致死的那一摔。六项合成的具体公式与致死高度对应的米数，与调研中待核对项一致（待实机）。

验收：从小落差、中落差、超过致死高度各落下一次。无伤、扣血且硬直更长、直接死亡三档能分辨；银猫/静步压低扣血但越过致死高度仍死。

落点：`HandleFall` 现状只切落地动画，未找到掉落伤害类型。

### FR-移动-10 跳跃攻击与下落攻击

**待补**

- 冲刺中前推并按下重击，角色出跳跃攻击（哪些武器在冲刺重击中改为跳跃攻击，逐件写在资产上）。
- 空中按下重击出下落攻击：高度足够时是下戳重击，打中敌人按重击结算并把人压倒地，倒地的敌人可以走近接处决（见 [FR-处决-06](背刺与处决.md)）；高度不够时按普通跳跃攻击结算。
- 下落攻击打中脚下敌人时，自己这一下是否仍扣掉落伤害，与调研中待核对项一致（待实机）。

验收：冲刺中重击出跳跃攻击；空中重击出下落攻击，打倒地敌人后能接处决。

落点：当前仓库未找到对应类型。

### FR-移动-11 连续翻滚精力递增

**待补**

不停顿地连续翻滚：每一次翻滚的精力消耗比上一次高，直到付不起；中间停顿一拍后，下一次翻滚回到基础消耗。递增幅度与停顿秒数与调研中待核对项一致。翻滚要等上一段收招之后才能接下一次（第 23 帧可再滚）。

验收：不停顿连续翻滚，每一次精力消耗高于上一次；停顿后回基础。

落点：当前仓库未找到对应类型。
