# 箭矢与弩

> **弓吃箭，弩吃螺栓，大弓吃大箭。对不上的弹射不出去。** 本篇默认待补。双手持弓时的瞄准镜头仍是 [FR-镜头-08](镜头与锁定.md)。

## 已有入口

`AimAction`、`ShootArrowAction` 与 `AmmoItem` 在物品动作和弹药脚本里。弓要双手持握且身上有箭才能进瞄准。拉满和快射按按住时间分两档伤害（2.87）。

`ShootArrowAction` 在 `TrySpendAmmo` 失败时不生成飞行物，也不播 `Shoot Arrow`。三种弹药互不相通、近距离拍击：当前仓库未找到对应类型。

## 需求

### FR-远程-01 弓拉满和快射能分辨

**待补**

双手持弓，装备箭。轻攻击射出一发，箭的数量少一，打中敌人时生命下降。重攻击拉得更久再松手，打中时的冲击或伤害与快射能分辨。拉到一半取消、箭没有飞出时，数量不减少。数量是否在取消时保持，与调研中待核对项一致；飞出的那一发一定少一枚。

落点：按住达到弹药上的拉满时间时用拉满伤害，没到时用快射，两档都先扣一发（2.87）。开局剩余是弹药上的 `Cnt`，超过 `Max Cnt` 时按上限，每射一发少一（0.41）。拉到一半取消还不在。

### FR-远程-02 弩和螺栓、大弓和大箭各用各的

**待补**

装备弩和螺栓，射击后螺栓少一，打中掉血。给弩装备普通箭时，射击没有飞行物。双手持大弓并装备大箭，能射出大箭。给大弓装备普通箭时，拉弓动作不生成飞行物。

### FR-远程-03 弹药为零时没有飞行物

**待补**

把当前这一种弹打到 0，再拉弓或扣弩。角色可以做出拉弓或举弩的动作，场上没有新的箭或螺栓。换上数量大于 0 的同一种弹之后，再射，飞行物出现并且数量少一。

落点：开局剩余是 `Cnt`，减到 0 后再射不生成飞行物（0.41）。数量为 0 时是否仍播拉弓动作，还没按本条分开。

### FR-远程-04 飞行物撞上就停

**待补**

箭或螺栓飞出后打在墙上，它停在撞击处，墙后的敌人生命不变。打在敌人身上时该敌人生命下降。正面举盾挡住时，按盾的吸收结算。

### FR-远程-05 状态弹推进对应的槽

**待补**

用毒箭或带出血的箭打中同一目标，对应的积蓄槽上升，规则见 [状态积蓄](状态积蓄.md)。换回普通箭打同一目标，不推进那条异常槽。
