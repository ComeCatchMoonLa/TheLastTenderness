# 精力

> **精力会随冲刺、翻滚、跳跃和攻击下降，停手后回到上限，并为零时轻击和重击出不了手。** 翻滚、后撤、跳跃在精力不够支付时已经不出手，见 [FR-移动-06](玩家移动与闪避.md)。待补的是轻击、重击和武器技：精力大于 0 但低于本次消耗时仍会出招。

代码字段是 `currentStamina` / `maxStamina`。界面条是 `StaminaBar`。全文称精力。完整游戏里把精力上限抬高的属性叫耐力，见 [FR-养成-02](角色养成.md)。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 上限、回复、扣减 | `CharacterStatsManager` | `Assets/Scripts/Character/CharacterStatsManager.cs` |
| 玩家条刷新、冲刺与交互时暂停回复 | `PlayerStatsManager` | `Assets/Scripts/Character/Player/PlayerStatsManager.cs` |
| 攻击扣精力 | `CharacterAnimatorManager.DrainStamina` | `Assets/Scripts/Character/CharacterAnimatorManager.cs` |
| 武器上的攻击消耗 | `WeaponItem.baseStaminaCost` 及轻重系数 | `Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs` |

上限由 `staminaLevel` 换算。换算数字留在 `CharacterStatsManager`，本需求不写死。

## 需求

### FR-精力-01 精力条与数值一致

**当前已有**

进入游戏时精力条是满的。之后每次冲刺、翻滚、后撤、跳跃、攻击或回复，条的长度和 `currentStamina` 一起变，不超过上限。

### FR-精力-02 动作消耗精力

**当前已有**

成功的冲刺、翻滚、后撤、跳跃会按 `PlayerLocomotionManager` 上的配置降低精力。轻击和重击在攻击动画事件 `DrainStamina` 触发时，按当前武器的基础消耗和轻重系数降低精力。

### FR-精力-03 停手后回复

**当前已有**

冲刺或交互动画过程中，精力不回升。两者都结束后，经过一段停顿，精力持续上升，直到上限后停止。

停顿时长和每秒回复量在 `CharacterStatsManager` 上配置。

### FR-精力-04 格挡时回复更慢

**当前已有**

角色举着盾、并未冲刺、也不在交互动画中时，精力回升速度慢于 FR-精力-03 的非格挡回复。放下盾之后，回复速度回到非格挡。

### FR-精力-05 精力为零不能出招

**当前已有**

精力为 0 时点轻击或重击。角色不播放攻击动作。把精力回复到大于 0 后再点，攻击动作出现。

### FR-精力-06 不够支付就不开始

**待补**

精力大于 0，但低于这一次轻击、重击或武器技的配置消耗时，角色不进入该动作，精力保持原值。消耗足够时，动作开始，精力下降。

翻滚、后撤、跳跃在精力低于配置消耗时已经不出手，精力不变，见 [FR-移动-06](玩家移动与闪避.md)。

落点：出招前已有 `DeductStamina` 与 `LightAttackAction` / `HeavyAttackAction` 的判断。当前轻击和重击只在精力小于等于 0 时拒绝；介于 0 和本次消耗之间时仍会播放攻击，事件里的 `DeductStamina` 在不够时不扣。`ParryAction` 不读精力也不读蓝。
