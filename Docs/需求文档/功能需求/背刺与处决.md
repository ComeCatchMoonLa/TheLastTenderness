# 背刺与处决

> **背刺和弹反之后的处决把双方锁进一段动画，结算一次。** 本篇默认待补。普通命中、格挡和破防硬直仍是 [FR-伤害-04](命中判定与伤害.md)、[FR-伤害-07](命中判定与伤害.md)。

## 已有入口

`CriticalAttackAction` 能播背刺和弹反后的动画，伤害读攻击者的 `rightWeapon`。`pendingCriticalDamage` 没有写入方，读到 0 就返回。`ParryAction` 负责弹反动作，不读蓝。

锁动画的一次结算、角度不够时退回普通攻击、野兽不进入背刺：当前仓库未找到对应类型。

## 需求

### FR-处决-01 背后贴住进入背刺

**待补**

站在人形目标背后的距离内按轻攻击。双方锁进背刺动画，目标生命下降一次，动画播完才能再动。鞭类武器在同样位置按轻攻击，打出的是普通一击，不锁这段动画。伤害倍率与调研中待核对项一致。

### FR-处决-02 角度不够时只是背后一刀

**待补**

站在目标背后偏开，或距离不够，再按轻攻击。打出普通攻击，目标不锁进背刺动画。血可以下降，规则与普通命中相同。

### FR-处决-03 弹反对上之后可以处决

**待补**

用战技是弹反的盾或武器，在对方攻击落到身上的短窗口里按下。对方攻击被弹开并弯腰。趁这段贴上去按轻攻击，双方锁进处决动画，目标生命下降一次。窗口对不上时，自己被打中，生命下降，对方不弯腰。帧数与调研中待核对项一致。

### FR-处决-04 盾被打空之后可以处决

**待补**

用踢击、盾击或把对方格挡精力打到 0，使对方弯腰。贴上去按轻攻击，进入与 [FR-处决-03](背刺与处决.md) 同类的处决动画。对方还举着盾、精力没被打空时，同样的轻攻击只是普通一击。

### FR-处决-05 野兽不进入背刺动画

**待补**

对野兽体型贴到背后按轻攻击。打出普通攻击，双方不锁进背刺。对人形在同样条件下操作，按 FR-处决-01 进入背刺。
