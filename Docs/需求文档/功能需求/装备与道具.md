# 装备与道具

> **拾取、换到手上、穿三部位护甲、轮换武器、双手切换、装备窗改选这一只手的每一把，以及从背包把法术或消耗品设成当前快捷项，已经能在玩家身上看见。** 待补的是备用武器和戒指计入负重、弹药不计入。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 背包列表 | `PlayerInventoryManager` | `Assets/Scripts/Character/Player/PlayerInventoryManager.cs` |
| 装上武器模型与伤害体 | `CharacterWeaponSlotManager`、`WeaponHolderSlot` | `Assets/Scripts/Character/CharacterWeaponSlotManager.cs`、`Assets/Scripts/Items/Equipment/Weapons/WeaponHolderSlot.cs` |
| 护甲换模 | `ModelChanger` | `Assets/Scripts/Items/Equipment/Armor/ModelChanger/ModelChanger.cs` |
| 背包格子上的穿戴 | `InventorySlotUI` | `Assets/Scripts/UI/Player UI/Tap Windows/InventoryWindow/InventorySlotUI.cs` |
| 拾取 | `PickUpItem` | `Assets/Scripts/Items/Interactions/PickUpItem.cs` |

物品基类是 `Item`（`Assets/Scripts/Items/Item.cs`）。护甲按 `armorType` 写入头、躯干、下身。装备窗能改选这一只手已经装备的每一把。背包里点法术或消耗品会改成当前快捷项。

## 需求

### FR-装备-01 拾取进背包

**当前已有**

走近带 `PickUpItem` 的物体并交互。该物品进入玩家背包，世界上的这件拾取物按它现有逻辑消失或不可再交互。打开背包能看到刚捡到的那一件。

### FR-装备-02 武器装备到手上

**当前已有**

在背包里把一把近战武器装备到右手或左手。对应手出现该武器模型，随后用这只手攻击时，命中使用这把武器的伤害。卸下或换成另一把后，手上的模型换成新的那一把。

### FR-装备-03 穿戴三部位护甲

**当前已有**

把头部、躯干、下身护甲各装备一次。角色对应部位的模型按 `ModelChanger` 换成该护甲的外形。再装备同一部位的另一件，旧的回到背包，外形换成新的一件。

物理吸收是否写入，见 [FR-伤害-06](命中判定与伤害.md)。

### FR-装备-04 轮换已装备的武器

**当前已有**

同一只手装备了不止一把武器时，按该手的轮换输入。手上的模型换成列表中的下一把，下一次攻击使用新的这一把。

### FR-装备-05 双手持握

**当前已有**

握持键可以把右手或左手里任意一把武器改成双手握持：点按切右手武器，长按切左手武器；成对武器切成成对持握。角色双手持握后左手槽让出，攻击动作符合 [FR-攻击-04](轻重攻击与武器技.md)。再切换一次，回到双手之前的左右手装备。双手有效力量按 floor(力量×1.5)、封顶 99，见 [FR-养成-04](角色养成.md)。

### FR-装备-06 装备窗覆盖该手全部武器

**当前已有**

打开装备窗，能看到并切换这一只手已经装备的每一把武器，包括方向键能轮换出来的后面几把。在窗口里改选之后，手上的模型与下一次攻击使用新选中的那一把。

落点：`EquipmentSlotUI` 与 `PlayerInventoryManager` 的左右手列表（2.10）。换上空手后下一击用拳头模型上的伤害体（0.51）。指针移入不改选，点这一格才换上，点了仍停在装备页（0.52）。

### FR-装备-07 从背包指定当前法术和消耗品

**当前已有**

在背包里选定一件法术。快捷栏上的法术图标变成这一件，之后施法使用它。再选定一件消耗品，快捷栏消耗品图标变成这一件，之后使用键消耗它并产生它的效果。

落点：`PlayerInventoryManager` 的 `currentSpell` 与 `currentConsumable`（2.2）。

### FR-装备-08 备用武器和戒指计入负重，弹药不计入

**待补**

同一套已经穿上的护甲不变，把一把重武器放进这只手没拿在身上的备用槽。当前负重上升。把它卸回背包、不放进左右手的槽之后，负重回落。戴上或摘下一枚有重量的戒指，负重数字跟着增减。装备或卸下箭、螺栓，负重数字不因此增减：弹药重量为 0，装备着和背包里的都不计入负重。手、腿外形和四枚戒指槽见 [FR-菜单-03](菜单.md)。负重上限 = 40 + 体力，见 [FR-负重-01](负重与翻滚.md)。

### FR-装备-09 护甲四部位，可混穿

**待补**

护甲分头、躯干（胸）、手（护手）、腿四件，可以来自不同套装混穿；卸下或留空的部位不提供吸收、异常抗性、霸体与重量。状态页和装备纸娃娃上四件分别显示。

落点：现状护甲按 `armorType` 只有头、躯干、下身三件（FR-装备-03）；护手第四部位与四件混穿待接，手、腿外形见 [FR-菜单-03](菜单.md)。

### FR-装备-10 切换有收刀动作，成对武器不并用盾

**待补**

- 切换或轮换武器时，角色先播收刀/拔刀动作，动作完成后新武器才在手上；动作中挨打可以打断切换，打断后人仍拿旧武器。
- 成对武器是一件物品、成对持握时占一种握法：成对持握期间不能再用盾；重量按一件计，不按两件。
- 使用消耗品（喝药等）或战斗中改选快捷物品时，双手中的武器收起，动作结束后恢复。

落点：当前仓库未找到对应类型。

### FR-装备-11 武器类别的可观察分界

**待补**

逐件武器的节奏与数值写在资产上，类别分界固定：

- 盾用于举盾格挡与稳定度结算（[FR-伤害-10](命中判定与伤害.md)），部分盾的战技是弹反或盾击；火炬提供照明，不能弹反。
- 空手槽用拳头：轻击、重击各有动作，伤害低。
- 弓与大弓必须双手持握进入瞄准；弩可单手持、另一手拿盾；法杖、圣铃、护符、火焰是施法器具，轻击施法、重击是近身敲击（见 [FR-法术-02](法术.md)、[FR-远程-06](箭矢与弩.md)）。
- 短刃、重剑、斧锤、长柄、拳爪鞭等类别的挥击节奏、能否弹反、霸体窗口长短按类别资产区分，不另立系统。

落点：当前仓库未找到成套类型。

### FR-装备-12 耐久消耗与修理

**待补**

武器、盾和护甲有耐久，戒指没有；战斗画面上没有常驻耐久条。

- 消耗节奏：武器每挥 5～10 次掉 1 点（月光大剑蓄力重击每次掉 4 点是特例），护甲只在挨打时掉。
- 两档惩罚：耐久低于上限 30% 时，武器伤害与护甲减伤为七成；掉到 0 时为五成；盾牌抵挡力和护甲强韧度不受这两档影响。
- 四条恢复途径：还没破（大于 0）时坐下休息修满；已经破了休息修不好，找铁匠安德烈花灵魂修；修理粉和修理法术只修当前装备着且未破的武器护甲（修理粉一次恢复 150 点），对已破损的无效。

落点：当前仓库未找到对应类型。
