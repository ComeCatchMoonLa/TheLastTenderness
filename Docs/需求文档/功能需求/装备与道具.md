# 装备与道具

> **拾取、换到手上、穿三部位护甲、轮换武器、双手切换、装备窗改选这一只手的每一把，以及从背包把法术或消耗品设成当前快捷项，已经能在玩家身上看见。** 待补的是备用武器和戒指计入负重、弹药不计入。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 背包列表 | `PlayerInventoryManager` | `Assets/Scripts/Character/Player/PlayerInventoryManager.cs` |
| 装上武器模型与伤害体 | `CharacterWeaponSlotManager`、`WeaponHolderSlot` | `Assets/Scripts/Character/CharacterWeaponSlotManager.cs`、`Assets/Scripts/Items/Equipment/Weapons/WeaponHolderSlot.cs` |
| 护甲换模 | `ModelChanger` | `Assets/Scripts/Items/Equipment/Armor/ModelChanger/ModelChanger.cs` |
| 背包格子上的穿戴 | `InventorySlotUI` | `Assets/Scripts/UI/Player UI/Tap Windows/InventoryWindow/InventorySlotUI.cs` |
| 拾取 | `PickUpItem` | `Assets/Scripts/Items/Interactions/PickUpItem.cs` |

物品基类是 `Item`（`Assets/Scripts/Items/Item.cs`）。护甲按 `armorType` 写入头、躯干、下身。装备窗能改选这一只手已经装备的每一把。背包里点法术或消耗品会改成当前快捷项。

## 需求

### FR-装备-01 拾取进背包

**当前已有**

走近带 `PickUpItem` 的物体并交互。该物品进入玩家背包，世界上的这件拾取物按它现有逻辑消失或不可再交互。打开背包能看到刚捡到的那一件。

### FR-装备-02 武器装备到手上

**当前已有**

在背包里把一把近战武器装备到右手或左手。对应手出现该武器模型，随后用这只手攻击时，命中使用这把武器的伤害。卸下或换成另一把后，手上的模型换成新的那一把。

### FR-装备-03 穿戴三部位护甲

**当前已有**

把头部、躯干、下身护甲各装备一次。角色对应部位的模型按 `ModelChanger` 换成该护甲的外形。再装备同一部位的另一件，旧的回到背包，外形换成新的一件。

物理吸收是否写入，见 [FR-伤害-06](命中判定与伤害.md)。

### FR-装备-04 轮换已装备的武器

**当前已有**

同一只手装备了不止一把武器时，按该手的轮换输入。手上的模型换成列表中的下一把，下一次攻击使用新的这一把。

### FR-装备-05 双手持握

**当前已有**

对当前右手近战武器做双手切换。角色改为双手持握，左手槽让出，攻击动作符合 [FR-攻击-04](轻重攻击与武器技.md)。再切换一次，回到双手之前的左右手装备。调研写选中的左右手武器都可以改双手；正确性把本条转述成只限双手武器或弓。见 [未入池](../../版本候选池/程序功能池/未入池.md)「哪些武器能切成双手」（信息待统一）。

### FR-装备-06 装备窗覆盖该手全部武器

**当前已有**

打开装备窗，能看到并切换这一只手已经装备的每一把武器，包括方向键能轮换出来的后面几把。在窗口里改选之后，手上的模型与下一次攻击使用新选中的那一把。

落点：`EquipmentSlotUI` 与 `PlayerInventoryManager` 的左右手列表（2.10）。

### FR-装备-07 从背包指定当前法术和消耗品

**当前已有**

在背包里选定一件法术。快捷栏上的法术图标变成这一件，之后施法使用它。再选定一件消耗品，快捷栏消耗品图标变成这一件，之后使用键消耗它并产生它的效果。

落点：`PlayerInventoryManager` 的 `currentSpell` 与 `currentConsumable`（2.2）。

### FR-装备-08 备用武器和戒指计入负重，弹药不计入

**待补**

同一套已经穿上的护甲不变，把一把重武器放进这只手没拿在身上的备用槽。当前负重上升。把它卸回背包、不放进左右手的槽之后，负重回落。戴上或摘下一枚有重量的戒指，负重数字跟着增减。装备或卸下箭、螺栓，负重数字不因此增减。手、腿外形和四枚戒指槽见 [FR-菜单-03](菜单.md)。调研「弹药」仍写弹药叠有重量、算进负重，见 [未入池](../../版本候选池/程序功能池/未入池.md)「换装后能读到负重」（信息待统一）。
