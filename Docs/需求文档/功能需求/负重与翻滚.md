# 负重与翻滚

> **当前翻滚只有一种动作，和身上的装备无关。** 重量、负重上限和轻、中、重三档翻滚都还没有类型。完整游戏的四档分界在 FR-负重-02、03、05，落在现有移动与属性上。

## 已有入口

翻滚播放 `Rolling`，进入 `HandleRollState` 时把 `isRolling` 写成 true。速度和精力消耗在 `PlayerLocomotionManager`，与装备列表无关。

| 会参与以后负重的现有类型 | 路径 |
| --- | --- |
| 翻滚 | `Assets/Scripts/Character/Player/PlayerLocomotionManager.cs` |
| 右手、左手武器 | `WeaponItem`，`Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs` |
| 头、躯干、下身护甲 | `ArmorItem`，`Assets/Scripts/Items/Equipment/Armor/ArmorItem.cs` |
| 等级字段 | `CharacterStatsManager`（生命、精力、专注、韧性、力量、敏捷、智力、信仰） |

武器和护甲上的重量、角色当前负重、负重上限、轻中重档位：当前仓库未找到对应类型。角色等级里没有单独的负重属性字段。

## 需求

### FR-负重-01 能看见当前负重

**待补**

角色换上或卸下武器、护甲后，界面上能看到当前负重和负重上限，数字随这身装备变化。赤裸且使用当前空手时，当前负重低于穿上一套护甲之后。负重上限 = 40 + 体力（体力 1 到 99 每点固定 +1，无软上限），加负重上限的戒指在这个值上另加；箭和螺栓重量为 0，装备多少都不改变当前负重。

落点：重量写在现有 `WeaponItem` / `ArmorItem` 上，合计放在 `PlayerStatsManager` 或 `PlayerInventoryManager`，给 HUD 或属性窗读取。

### FR-负重-02 三档翻滚能分辨

**待补**

负重相对上限处于轻、中、重三档时，各做一次有方向的翻滚。轻档比中档滚得更远，时长相同。重档更近，动作更慢。同一档内连续两次翻滚，观感一致。四档的分界和刚好卡在 30%、70%、100% 上的归属见 FR-负重-05。

落点：`PlayerLocomotionManager.HandleRoll` 与 `HandleRollState`。按档位选择已有翻滚动作或根运动，不新建移动框架。

### FR-负重-03 超重不能翻滚

**待补**

当前负重达到或超过上限时短按闪避并带方向。角色不播放翻滚，以慢于 [FR-移动-01](玩家移动与闪避.md) 跑步的速度移动，也不能后撤、冲刺和跳跃。负重回到低于上限后，再次短按可以翻滚。刚好等于上限时也不能翻。

### FR-负重-04 提高负重属性后档位变轻

**待补**

同一套装备下，提高与负重上限相关的那项属性，直到上限上升使比例跨过一档。再翻滚时，观感从原来的较重档变为较轻档。属性尚未增加时，翻滚保持原档。

属性从哪里加，见 [FR-属性-04](属性与升级.md)。当前仓库未找到这项属性的字段，补在 `CharacterStatsManager` 的现有等级字段旁。负重上限对应的那一项属性，完整游戏里叫体力，见 [FR-养成-02](角色养成.md)。

### FR-负重-05 四档分界能分辨

**待补**

把负重比例放在低于 30%、刚好 30%、刚好 70%、高于 70% 且低于 100%、刚好 100%，各翻滚一次。低于 30% 滚得最远。30% 和 70%（含这两点）距离中等，动作时长与低于 30% 的那一档相同，无敌都是 13 帧。高于 70% 且低于 100% 距离更短、动作更慢，无敌 12 帧，精力回复大约慢两成。各档翻滚扣的精力是同一截，不随档位变。达到或超过 100% 时不播放翻滚、后撤、跑步、冲刺和跳跃。帧数按 30 帧计：以扣精力的动作开始帧为第 1 帧，轻档、中档无敌是第 2～14 帧（第 1 帧可挨打）；沉重档 12 帧按帧测总帧数推算为第 2～13 帧（逐帧直测待核对）。后撤没有无敌窗口，全程可以受伤。70.0% 以下走路、跑步、冲刺速度不随档位变化，30% 以下不比中量更快。
