# 轻/重攻击与武器技

> **点按可以打出轻击、重击和一段连击，双手持握会换双手攻击动作，按住可以举盾。** 待补的是双手也能打出武器技，并且武器技和攻击一样要先付得起精力或专注。

## 已有入口

调度在 `PlayerCombatManager`（`Assets/Scripts/Character/Player/PlayerCombatManager.cs`）。一次输入只调用右手或左手武器上的一个 `WeaponItemAction.PerformAction`。槽位定义在 `WeaponItem`：单手 `oh_*`、双手 `th_*`，点按或按住，键位 E / Q / R / Z。

| 动作 | 类型 | 路径 |
| --- | --- | --- |
| 轻击与连击 | `LightAttackAction` | `Assets/Scripts/Items/0 Item Actions/LightAttackAction.cs` |
| 重击与连击 | `HeavyAttackAction` | `Assets/Scripts/Items/0 Item Actions/HeavyAttackAction.cs` |
| 格挡 | `BlockAction` | `Assets/Scripts/Items/0 Item Actions/BlockAction.cs` |
| 单手武器技动画 | `ParryAction` | `Assets/Scripts/Items/0 Item Actions/ParryAction.cs` |
| 动作基类 | `WeaponItemAction` | `Assets/Scripts/Items/0 Item Actions/WeaponItemAction.cs` |

双手轻击和重击在 `LightAttackAction`、`HeavyAttackAction` 里按 `isTwoHandingWeapon` 改播 `thLightAttack*`、`thHeavyAttack*`，见 FR-攻击-04。武器技是另一条：当前仓库没有单独命名为武器技的类型。单手 `ParryAction` 播放动画字段 `weapon_art`，不读蓝。双手分支是空的，见 FR-攻击-06。玩家调度仍调用 `oh_*` 槽；`th_*` 槽由人形敌人的 `ItemBasedAttackAction` 使用。

验收时用当前武器资产上已经填好的槽。点按 E 走 `oh_tap_e_action`（左手是弓时走左手），按住 E 走 `oh_hold_e_action`，按住 Q 走格挡相关槽。具体键以 `PlayerCombatManager.HandleCombatInput` 的调用为准。

## 需求

### FR-攻击-01 轻击

**当前已有**

精力大于 0、角色不在交互动画中时，点按轻击槽。角色播放当前持握方式下的第一段轻击，身体转向由锁定或移动决定。精力为 0 时见 [FR-精力-05](精力.md)。

### FR-攻击-02 轻击连段

**当前已有**

第一段轻击播到连击窗口（动画事件 `EnableCombo` 把 `canDoCombo` 写成 true）时再次点按轻击。角色接下一段轻击，并避免重复播放第一段。窗口结束后再点，从第一段重新开始。

### FR-攻击-03 重击

**当前已有**

精力大于 0、不在交互动画中时，点按重击槽。角色播放第一段重击。连击窗口内再次点按重击槽，角色接下一段重击。

### FR-攻击-04 双手攻击

**当前已有**

角色切换为双手持握当前武器后点轻击或重击。播放的动作换成双手字段（`thLightAttack1` 等），并和单手攻击能看出差别。切回单手后，再攻击回到单手动作。

双手切换的输入在 `PlayerInventoryManager.HandleTwoHandInput`。武器技槽见 [FR-攻击-06](轻重攻击与武器技.md)。

### FR-攻击-05 举盾与放下

**当前已有**

当前武器的格挡槽有 `BlockAction` 时按住格挡键。角色进入举盾，仍可以移动。松开后举盾结束。举盾期间精力回复见 [FR-精力-04](精力.md)。

### FR-攻击-06 武器技

**待补**

单手和双手持握下，点按该武器的武器技槽。角色播放这把武器自己的武器技动作。精力大于 0 就出手，可以降到 0 以下，与 [FR-精力-06](精力.md) 同一规则。蓝低于这一下的专注消耗时，动作仍然播放，特殊效果变弱或没有，这一下花费的精力更高，蓝不进负数。蓝够时按配置扣蓝，特殊效果完整出现。武器技进行中，普通移动不改速度。法术蓝不够是失败起手，见 [FR-法术-08](法术.md)。验收写精力或专注不够时动作不出现，两句还没合成，见 [未入池](../../版本候选池/程序功能池/未入池.md)「武器技精力不够时放不放」（信息待统一）。

双手轻击和重击见 [FR-攻击-04](轻重攻击与武器技.md)，那一条当前已有。

落点：沿用 `WeaponItem` 上已有槽和 `WeaponItemAction`。`ParryAction` 只覆盖单手播放 `weapon_art`，不检查消耗；双手分支为空。玩家现有输入继续调用 `oh_*` 槽。

### FR-攻击-07 挥击窗口

**当前已有**

轻击或重击动作上的 `OpenDamageCollider` 被调用时，当前手的伤害体开始生效，打到别人会受伤。`CloseDamageCollider` 之后，武器再碰上别人，这一次不再扣血。

动画事件在 `CharacterAnimatorManager`。片段没有挂这两个事件时，这一次挥击打不中人。
