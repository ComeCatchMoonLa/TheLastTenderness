# 镜头与锁定

> **自由跟随、遮挡拉近、锁定、左右换目标、丢失目标后解除，以及目标身上的锁定标记，当前相机和 HUD 已经做到。**

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 跟随、旋转、遮挡、锁定 | `PlayerCameraManager` | `Assets/Scripts/Camera/PlayerCameraManager.cs` |
| 锁定键与左右切换键 | `InputManager` | `Assets/Scripts/Character/Player/InputManager.cs` |
| 锁定时转向目标 | `PlayerLocomotionManager.HandleRotate` | `Assets/Scripts/Character/Player/PlayerLocomotionManager.cs` |
| 弓瞄准 | `AimAction` | `Assets/Scripts/Items/0 Item Actions/Bow/AimAction.cs` |
| 是否自动换目标 | `GameSettingsData.autoChangeLockOnTarget` | `Assets/Scripts/SomeData/GameSettingsData.cs` |

锁定标记在 `HUDWindowsManager.lockMark`。`CharacterManager.lockOnTransform` 是角色身上的锚点。图没填时不显示。

## 需求

### FR-镜头-01 自由镜头

**当前已有**

未锁定、未瞄准时移动视角。镜头绕角色转动，俯仰停在配置的上下限内，角色位置被镜头平滑跟随。

### FR-镜头-02 镜头与墙

**当前已有**

未瞄准时，镜头与角色之间有环境遮挡。镜头沿视线拉近，仍能看见角色，并在遮挡消失后回到原来的距离。

### FR-镜头-03 锁定与解除

**当前已有**

左手武器不是弓时，按一次锁定键。范围内有未死亡、视线未被环境挡住的其他角色时，进入锁定。再按一次，锁定结束，镜头回到自由跟随。

范围内没有合格目标时，按锁定键后镜头仍是自由跟随。

### FR-镜头-04 锁定朝向

**当前已有**

锁定一名近战敌人后，镜头水平朝向该目标。角色未冲刺、未翻滚时，身体转向该目标。冲刺或翻滚期间，身体朝向移动方向。调研写锁定翻滚时角色继续面向目标，两句还没合成，见 [未入池](../../版本候选池/程序功能池/未入池.md)「锁定时翻滚身体朝哪」（信息待统一）。

### FR-镜头-05 左右切换目标

**当前已有**

设置里关闭自动换目标，且锁定成立、左右各有另一名可锁定敌人时，按左切换键改锁左边那名，按右切换键改锁右边那名。镜头随之转向新目标。

### FR-镜头-06 目标丢失

**当前已有**

关闭自动换目标时，锁定的敌人跑出最大锁定距离，或与玩家之间被环境挡住。附近还有另一名合格敌人时，锁定改到距离更近的那名。没有合格敌人时，锁定解除。

锁定目标死亡时，`EnemyStatsManager.HandleEnemyDeathEvent` 会先解除再重新查找。

### FR-镜头-07 锁定标记

**当前已有**

锁定成立时，玩家能在目标身上或屏幕上看到标记，并随目标移动。解除锁定、目标死亡或 FR-镜头-06 找不到下一名目标时，标记消失。

落点：`LockMark.Shown` 与 `HUDWindowsManager.lockMark`（2.73）。锁定且目标未死才显示。图是空的时不显示，并报出字段。目标在相机背后时关掉。

### FR-镜头-08 弓的瞄准镜头

**当前已有**

双手持弓且有箭时按住瞄准，镜头切到角色的瞄准挂点，角色水平朝向跟着视角转。松开后回到锁定或自由镜头。左手是弓时，锁定键不进入 FR-镜头-03。
