# 霸体与硬直

> **韧性不够时受击会播动画并停步，韧性还够时只掉血。挥击窗口里的霸体血量被打空时改播受击。** 待补的是穿上护甲后更不容易被打出受击。

全文把「受击停步」称为硬直，把「挥击途中普通受击打不断这一击」称为霸体。代码里对应字段是 `totalPoiseDefence`、`poiseBreak`、`offensivePoiseBonus`、`armorPoiseBonus`、`attackPoise`。

## 已有入口

| 行为 | 类型 | 路径 |
| --- | --- | --- |
| 受击时扣韧性并决定是否播受击动画 | `DamageCollider.DealDamage` | `Assets/Scripts/Damage/Damage Collider/DamageCollider.cs` |
| 韧性回落计时 | `CharacterStatsManager.HandlePoiseResetTimer` | `Assets/Scripts/Character/CharacterStatsManager.cs` |
| 攻击时加减进攻韧性 | `GrantWeaponAttackingPoiseBonus`、`ResetWeaponAttackingPoiseBonus` | `Assets/Scripts/Character/CharacterAnimatorManager.cs` |
| 武器的破韧与进攻韧性 | `WeaponItem` | `Assets/Scripts/Items/Equipment/Weapons/WeaponItem.cs` |

`poiseLevel` 有字段，结算不读它。`armorPoiseBonus` 不由穿戴写入。进攻韧性在动画事件被调用且加成大于 0 时打开霸体窗口。

受击动画通过 `PlayTargetAnimation` 把 `isInteracting` 写成 true，期间 `HandleMove` 不改速度。

## 需求

### FR-硬直-01 破韧后硬直

**当前已有**

角色或近战敌人被击中，当前韧性不足以维持这一击（结算后的 `totalPoiseDefence` 不再大于本次 `poiseBreak`）。目标生命下降，并播放受击动作。受击动作期间不能用移动输入改速度。动作结束后可以再移动。

### FR-硬直-02 未破韧只掉血

**当前已有**

同一目标在韧性仍然高于本次 `poiseBreak` 时被击中。生命下降，保持当前动作，不播放受击动画。攻击中的那一下可以继续。这是当前脚本的结算。完整游戏里，护甲韧性只在带霸体的攻击窗口和中量、沉重翻滚里参与比较，见 FR-硬直-05。

### FR-硬直-03 韧性恢复

**当前已有**

连续受击后停止再受击。经过 `totalPoiseResetTime` 配置的时间，韧性回到当前 `armorPoiseBonus`。在此之后，原先能打出硬直的一击若不再超过恢复后的韧性，结果符合 FR-硬直-02。

### FR-硬直-04 攻击霸体

**当前已有**

武器配置了进攻霸体时，挥击进行到该段，被一次原本会打出硬直的普通攻击打中。霸体血量还没被打空时，挥击继续播完，不切到受击动画；生命仍下降。同一窗口里挨到重击，同样扣霸体血量。血量被这一下打空时，挥击中断，改播受击。连续轻击把血量打空时同样中断。（Fandom、Wikidot）挥击结束后，同样的一击再打来，按 FR-硬直-01 进入硬直。

未配置进攻霸体的挥击，途中被打中则进入硬直，这一击中断。

落点：窗口开着时从这份血量扣 `poiseBreak`，扣完大于 0 则继续，否则播受击（2.75）。现有攻击状态进入时，进攻霸体大于 0 就打开窗口，离开时只关掉自己这次的窗口（2.92）。连击切到下一段不会把刚打开的窗口关掉。

### FR-硬直-05 护甲提高韧性

**待补**

穿上写了韧性的护甲，站着或做没有霸体窗口的挥击时被打中，仍然播放受击动画。换成带霸体窗口的挥击再被同一击打中，窗口内挥击可以继续，生命仍下降。脱掉该护甲后，同一击在同一个窗口里改为打出受击动画。窗口外，甲再重也播受击。状态页总韧性按递减公式合成：新韧性 = 当前韧性 + 这件韧性 − 当前韧性×这件韧性/100，四件护甲与狼戒指等额外韧性逐件并入。

落点：护甲字段与 `armorPoiseBonus`。穿戴入口当前不把护甲韧性写入角色。`poiseLevel` 若参与上限，和护甲加成一起在角色属性上能看出来。

### FR-硬直-06 受击分四级，倒地与起身

**待补**

受击按这一击的等级播四种结果：轻硬直、重硬直、击飞、击倒（连盾带人拍倒属于击倒）。连续轻击不能把轻硬直无限续成控制。倒在地上的目标：崩架与部分被拍地的可以走近接处决（[FR-处决-04](背刺与处决.md)、[FR-处决-06](背刺与处决.md)）；普通击飞倒地不给处决，哪些倒地能处决按敌人配置。起身自动站起、也可以手动翻起，起身末尾可以挨打；起身过程有一段无敌，帧数与调研中待核对项一致。

落点：当前只有一档受击动画，击飞、击倒与起身无敌未找到类型。
