## 二、冲突与查证结论

### 已定论并写回的冲突

**冲突 1：属性不足时法术能不能放（调研《角色与养成》「施放条件」 ↔ FR-属性-06）。**

- 调研原句：「属性没达到法术或器具需求时，仍然可能放得出来，但威力会差一截。」
- FR-属性-06 原句：要求不符「角色不放出弹体、也不治疗，专注不减少」。
- 查证：两种情形要分开。①**法术自身**需求不达标：放不出（3DM 法术使用方法「满足条件才能使用指定的魔法」；法语奖杯攻略把「法术要求的智/信高于自身」列为施放失败条件之一）。②**催化器**需求不达标：法术仍放得出，催化器法术威力修正约按 60% 结算，与法术威力无关的效果按 100%（惜别之泪一类生效但无特效），催化器自己的战技不能用（NGA《拿副手的妖术枝条需要升级吗？》实测帖；bilibili 零悠悠《关于黑暗之魂三的装备版面惩罚机制》；kamikouryaku《恵みの祈り》「能力不足では発動しない」）。
- 处置：调研句子改分两款；FR-属性-06 改写为「法术需求不达标放不出、蓝不扣；催化器需求不达标仍施放、按削弱的法术威力结算、催化器战技不能用」。削弱幅度是资产位，不写死。

**冲突 2：错误弹种能不能装进弹药格（调研《装备与建造》「三种不相通」 ↔ FR-远程-02）。**

- 调研原句：「选错类型的弹不会出现在这把武器的弹药格里」「弓不能装大箭，大弓不能装普通箭」。
- FR-远程-02 原句：「给弩装备普通箭时，射击没有飞行物……给大弓装备普通箭时，拉弓动作不生成飞行物」。
- 查证：装备菜单里箭槽与螺栓槽是**分开的两类槽**，箭不能放进螺栓槽（菜单层就选不进）；但**箭与大箭同属箭槽、不区分，弓与大箭可以混装**，装备页连「弓＋大箭」的攻击力都会照常显示（kamikouryaku《弓》：「矢と大矢が区別されないので弓＋大矢の攻撃力も表示される」；wikidot Dragonslayer Greatarrow：「Can only be used with greatbows」指发射而非装备）。槽内弹种与武器不对应时，射击不生成飞行物。
- 处置：调研「弹药」一节改为「箭与螺栓分槽、菜单层互不能装；箭与大箭同槽可混装，不对应时射不出」；FR-远程-02 措辞改为「槽中弹种与武器不对应时，射击不生成飞行物」，可观察结果不变。

**冲突 3：跳跃是否必须在冲刺中起跳（调研《移动与镜头》「跳跃、落地与落地攻击」 ↔ FR-移动-05）。**

- 调研原句：「跳跃从冲刺里起跳。」FR-移动-05 原句只要求「有移动量」。
- 查证：官方 WEB 手册操作表「ジャンプ（ダッシュ中にボタン）」；官方入门指南「Jump (left stick button while dashing)」；多家攻略一致「you need to be sprinting before jumping」。
- 处置：FR-移动-05 条件加上「冲刺中」。现有实现若放宽，作为实现偏差记在落点，不改目标。

**冲突 4：一口药能不能同时回血又回蓝（调研《魔法与道具》「紫瓶·喝药」 ↔ FR-回复-05）。**

- 调研原句：「一口只回复分配给这一瓶的那一种。」FR-回复-05 原句：「两者都配置时，成功后生命和专注一起上升。」
- 查证：血瓶与灰瓶是两瓶、铁匠分配总次数，一口只喝其中一瓶（官方入门指南「set how many flask uses are for health, and how many for FP」；RPGamer 等多家评测一致）。
- 处置：FR-回复-05 改为灰瓶一口只回专注、血瓶一口只回生命；「两者都配置」一句删除。FR-回复-04 落点里「按血瓶和灰瓶分开记」与原作一致，保留。

**冲突 5：圣铃战技的持续回血会不会被挨打打断（调研《魔法与道具》催化器表 ↔ FR-法术-04）。**

- 调研原句：「圣铃：战技扣蓝，角色身上持续回血，直到时间结束或再次被打断。」FR-法术-04 原句：「收起圣铃或改成双手握住另一侧武器时这段结束，挨打不打断。」
- 查证：恵みの祈り发动后约 60 秒、每拍缓慢回血；**必须保持单手或双手拿着圣铃**，收起或改双手持另一侧武器效果消失；挨打不结束（kamikouryaku《恵みの祈り》：「聖鈴を常に片手あるいは両手持ちしていなければ効果が消失する。反対側の武器の両手持ちも禁止」）。
- 处置：FR-法术-04 正确，不改；调研「直到时间结束或再次被打断」改为「直到约 60 秒时间结束，或收起圣铃、改双手持另一侧武器；挨打不打断」。

**冲突 8：暗印/回城骨/卷剑碎片的目的地是固定还是可选（调研《世界与篝火》对比表 ↔ FR-周目-03/04/09）。**

- 调研原句：三件道具去向均为「可选上次坐下的火或祭祀场主火；从未坐下则只去祭祀场主火」。FR 三条均写死「出现在上次坐下的篝火」。
- 查证：wikidot Homeward Bone 与 Tools：「return to the last bonfire rested at, **or** to the Firelink Shrine Bonfire」，道具说明同文，使用时玩家选去向。
- 处置：FR-周目-03/04/09 各加「使用时在『上次坐下的火』与『传火祭祀场主火』之间选择；从未坐下时只有主火可选」。

**冲突 10：敌人脱战归位点（调研《敌人与头目》「活动范围与归位」 ↔ FR-敌人-05）。**

- 调研原句：放弃目标后「沿路径走回放置点」「一直走到放置点并完成脱战」。FR-敌人-05 原句写「走回发现玩家之前的位置」，落点用「开始追击前的坐标」。
- 查证：敌人刷新与归位以原始放置点为准（GameGuides「reset to its original location」；同需求集 FR-头目-01 已写「走回放置点」，口径本来就该统一）。巡逻者巡逻途中被发现时，追击前坐标不等于放置点。
- 处置：FR-敌人-05 目标改为放置点；现有脚本按追击前坐标回家是实现偏差，落点保留，由代码分析《正确性》跟踪。

### 不判冲突、但更正标记的两条

- **FR-注入-07 同名戒指各档叠戴。** 调研 2026-10-08 已核实「同名各档不可同戴、异名可叠」，FR 仍写「与调研中待核对项一致」。改为确定句。
- **FR-联机-08 教堂枪兵生命上限。** 调研确定「随主人一侧人数上升的是蓝、精力、韧性、减伤和异常抗性，生命上限不加」，FR 写成「与待核对项一致」。生命上限改为确定句；各档减伤与枪饰数仍是资产位/长线待核对。

### 查不到文字定论、转待实机的两条（两边都不改，登记 [`../版本候选池/程序功能池/未入池.md`](../版本候选池/程序功能池/未入池.md)）

- **冲突 7：身上 0 魂死亡是否生成血迹。** 调研推断「新血迹可以是空的」，FR-燃火-05 写「不生成残留」。官方手册与各家维基只写「持有灵魂全掉、形成血痕」，没有 0 魂边界的文字证据，需实机录一遍。
- **冲突 9：敌人尸体是定时消失还是留到区域刷新。** 调研写「尸体停在原地直到下一次区域刷新」，FR-敌人-04（当前已有）写「一段时间后从场景里消失」。官方手册支持「休息后敌人复活（一部除外）」，但没有尸体存留时长的直接证据；暂时清空机制与调研说法自洽，仍以实机为准。实机结论出来前，FR-敌人-04 现状句不动。

### 上报但不构成冲突的一条

- **火焰催化器战技（调研《魔法与道具》催化器表 ↔ FR-法术-04）。** 调研写「本体火焰的战技本身很弱……资料片有的火焰催化器战技是一次贴身喷射」，FR 写「火焰催化器放出一次近身的火，命中掉血」。查证本体咒术之火战技就是「発火（Combustion）」——「手元に強い炎を発生させる」，正是近身火焰伤害（wikidot Pyromancy Flame）；资料片送灵火另算（战技回血、施放带残火）。两边不矛盾：FR 写的是発火的可观察结果，调研「很弱」是强度评价。两边都不改，仅记录。
