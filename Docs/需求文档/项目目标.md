# 项目目标

> **玩家能走通《黑暗之魂 3》本体与两部资料片里、由代码驱动的那些系统，并且每一步都能亲手操作、看见结果。** 成功标准是下面这些行为成立。画质对齐、关卡美术和剧情文本不进入完成定义。

复刻范围是完整游戏的代码相关功能：创角与九项属性、装备注入与强化、移动与镜头、近战与远程、法术、篝火与周目、菜单与场景机关、敌人与头目、NPC 任务与联机痕迹。资料片《艾雷德尔的灰烬》《环印城》走同一套九项属性。多出来的是能观察到的条目，例如教堂枪兵那场头目。

实现放在本仓库已有的 Unity 工程上，类型保持 `MonoBehaviour`、Animator 的 `StateMachineBehaviour`、`ScriptableObject`。排期见 [README](README.md) 与 [`../开发计划/README.md`](../开发计划/README.md)。本目标不另写版本号。

## 成功时玩家能做什么

1. 创角后带出外形、名字、职业和一件葬礼赠礼。九项属性在状态页上能读到。生命上限随生命力变，蓝条和法术栏随集中力变，精力上限随耐力变，负重上限随体力变。
2. 在防火女处花灵魂加点，预览先出现，确认后等级和资源立刻变。在罗莎莉亚处用苍白舌头重生或改造：重生后灵魂等级不变，单项不低于职业起点；改造后外形变、九项不变。带着暗印死亡时空虚加深，清除暗印后死亡不再加深空虚。
3. 走、跑、冲刺、翻滚、后撤、跳跃仍按已有移动编号能看见。负重按四档拉开翻滚。锁定、切换目标和弓的瞄准镜头仍按已有镜头编号能看见。
4. 轻击、重击、武器技、举盾仍按已有攻击和伤害编号能看见。在此之上：架势能接出两段不同派生，成对武器走出双持连段，踢击能崩开举盾，背后能背刺，弹反或崩架后能处决，箭和弩打得出飞行物并消耗对应弹药。
5. 法术先学会，再在篝火放进记忆栏。法杖、圣铃、护符、火焰各自放出对应系的法术；拿错催化器时没有弹体或治疗。蓝不够时失败起手，蓝不进负数。
6. 十五种注入能改写武器面板。炭火没交给铁匠安德烈时，对应组选不到。普通强化停在加十，鳞片和闪耀矿石停在加五。王座用首领魂换走一件成品。戒指最多四枚，戴上后该类型的上限、回复、翻滚、施法或处决能看出变化。需求不足时挥击变慢。
7. 野外篝火坐下后的菜单是传送、整理法术、储物箱、离开。升级在防火女。分瓶和瓶碎片都在铁匠安德烈，总次数最多十五口。未死人骨片在传火祭祀场主篝火烧掉，回复最多加十档。使用余烬后生命上限变长，死亡后缩回。使用暗印回到上次坐下的火，灵魂清零，地上没有可捡的灵魂血迹。自己死亡留下的可捡灵魂仍按已有燃火编号。
8. 进入下一周目后，等级、装备、已学法术和药瓶强化留下；已点燃的火、打开的门、钥匙和头目战败按新的一周重来。终局一次交互按旗标进入传火、灭火或窃火中的一条。
9. 梯子、门、电梯、雾门、幻影墙、箱子和拟态各自有可重复的操作结果。打开过的门和打穿的幻影墙在休息后仍开着。
10. 暂停菜单能打开背包分页、装备、状态、姿态。状态页能读九项和负重，加点不在这一页。没有可点的世界地图。
11. 普通敌人除了已有的发现和追击，还能在被拉出活动范围后归位回血，呼救被打断时同伴不来。头目有带名字的血条和阶段；战后雾门撤掉，本周目不再出现，并可以在场地里点起新篝火。
12. NPC 能逐句对话、用灵魂买卖、收下赠送的物品。攻击后该人敌对，赦罪后仍活着的人恢复对话。任务旗标立起后，休息不会把已经失败的那条线重新打开。
13. 九个盟约里，身上生效的是当前装备的那一枚印记。余烬状态下能召协助，入侵者能打中主人，协助幻影之间打不掉血。在线时能读留言、给好评、看别人的死亡血渍；离线时这些别人留下的痕迹不出现。

具体系数留在武器、护甲和角色检视器里，并与调研中待核对项一致。玩家要能分辨「扣了、回了、挡住了、档位变了、旗标换成了下一段」。
