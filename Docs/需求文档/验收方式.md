# 验收方式

> **每条 FR 自带一行 `验收：`，写在该条规则与落点之间。** 按这行手动操作，看角色和界面结果；通过标准是该条的可观察结果出现。能在 Edit Mode 里断言的，以对应版本技术设计里的测试为准。一条失败只记这一条。

## 看的场景

- 已有编号在 Build Settings 里的 `Game` 里看。当前激活内容是玩家、三只近战和 Map 0。
- 燃火条目先只激活场景里已有的 `CampFireInteractable` 再看。
- 新编号在能摆出该条角色和交互物的场景里看。雾墙、头目阶段和未激活物体上的脚本，按 FR-机关、FR-头目验收；旧的 FR-敌人仍用当前场景里的三只近战。
- 数值用检视器里的配置，并与调研中待核对项一致；步骤不要求特定点数。

## 怎么看

- 待补条目在实现那一条之后，用同一行 `验收：` 再看；当前已有条目现在就能看。
- `验收：` 是祈使操作（做什么、看什么），不是规则的第二份描述；规则以该条 FR 正文为准。两者若不一致，改的是验收行。
