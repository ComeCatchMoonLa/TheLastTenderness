# 验收方式

> **按编号手动操作，看角色和界面结果。** 能在 Edit Mode 里断言的，以该版技术设计里的测试为准。这里的步骤是给人看的。通过标准是对应编号里的可观察结果出现。一条失败只记这一条。

已有编号在 `Game` 里看。新编号在能摆出该条角色和交互物的场景里看。数值用检视器里的配置，并与调研中待核对项一致。步骤不要求特定点数。

待补条目在实现那一条之后用同一步骤再看。当前已有条目现在就可以看。
