# 任务与 NPC 的验收

对应 [任务与 NPC](../功能需求/任务与NPC.md)。不按剧情台词验收。

1. **FR-任务-01**：连按对话直到一句开始反复。推进一次旗标（休息、进区域、交物品或击倒对应头目，按这个人的配置）后再对话，出现新的一段。
2. **FR-任务-02**：用灵魂买一件，包里多出它，灵魂减少。卖出一件允许卖的装备，灵魂增加且少于买价。把灰烬交给侍女，她的清单多出那一批。
3. **FR-任务-03**：把指定物品交给对的人。物品消失，对话或商店多一项。交给别人时对方拒绝，物品还在包里。
4. **FR-任务-04**：把书交给这一系的人。书消失，商店多出法术。这个人死后，没买的不能再从他这里打开。已经学会的还在列表里。
5. **FR-任务-05**：攻击非敌对的人。菜单消失，此人转入攻击，休息后仍敌对。付灵魂赦罪后，这名还活着的人恢复对话。已经打死的人不会回来。
6. **FR-任务-06**：打死商人。原处不再对话，可以捡到灰烬。休息后他不回到原处。
7. **FR-任务-07**：做一次会关掉另一条线的交付。被关掉的人不再提供协助。休息后这条线仍是关掉的。还开着的人仍能对话。
