# 周目与结局的验收

对应 [周目与结局](../功能需求/周目与结局.md)。地上可捡的灵魂残留另看 FR-燃火-05。

1. **FR-周目-01**：使用余烬。生命上限变长并补到顶。再使用一次，上限不再变长，生命仍补到这一档的顶。
2. **FR-周目-02**：余烬还在时坐下。上限仍是余烬那一档。被打死复活后，上限缩回没有余烬的一档。没有余烬时休息，不会点着余烬。
3. **FR-周目-03**：灵魂大于 0 时使用送回篝火的暗印。人在上次的火边，灵魂为 0，死亡点没有可拾取的灵魂血迹。头目血条出现时使用，人留在场内。
4. **FR-周目-04**：使用回城骨。人回到上次的火，灵魂数字不变，余烬保持原样，骨头少一个。头目血条出现时使用，人留在场内。
5. **FR-周目-05**：从主篝火进入下一周目。等级、装备加号、已学法术和药瓶档位还在。已点燃的火要重新点，打开的门关上，钥匙不在包里，打过的头目再次满生命出现。
6. **FR-周目-06**：在终局火焰交互一次。暗印门槛已满时结算为窃火。未满、已交眼并使用防火女的符时结算为灭火。其余结算为传火。条件不够时，主篝火没有前往终局的传送。
7. **FR-周目-07**：先让防火女清除暗印，再做终局交互。结算不再是窃火。
8. **FR-周目-08**：结局后选择留下。人在传火祭祀场，不能再换另一条结局。之后再选进入下一周目，保留和重置与 FR-周目-05 相同。
9. **FR-周目-09**：使用卷剑碎片。人回到上次的火，灵魂数字不变，余烬保持原样，个数不减少。再拾取一次仍是一份。头目血条出现时使用，人留在场内。
