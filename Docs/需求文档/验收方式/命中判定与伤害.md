# 命中判定与伤害的验收

对应 [命中判定与伤害](../功能需求/命中判定与伤害.md)。

1. **FR-伤害-01**：对近战敌人打出一次命中。它的血变少。把玩家打到 0 时玩家死亡，见燃火条目。
2. **FR-伤害-02**：用同队的伤害体打自己人。生命不变。
3. **FR-伤害-03**：在无敌标志为真时挨打，生命不变。标志结束后挨打，生命下降。
4. **FR-伤害-04**：正面举盾吃下一击，再在同一状态下不举盾吃同一类攻击。举盾时掉血更少，并且精力下降。
5. **FR-伤害-05**：让武器在一次挥击里多次碰到同一敌人。只掉一次血。下一挥再碰到，可以再掉。
6. **FR-伤害-06**：赤裸吃一次火、魔、雷或暗伤害，记下掉血。穿上对应吸收的护甲再吃同样一击，掉血更少。脱掉后回到赤裸的掉血。
7. **FR-伤害-07**：举盾吃到精力被扣光的一击。盾放下，能看见破防硬直，期间不能移动和攻击。结束后可以再举盾。
8. **FR-伤害-08**：穿上同一套甲，各吃一记打击和一记斩击或突刺。两次掉血能分辨。脱掉后再各吃一次，回到赤裸时的差别。
9. **FR-伤害-09**：在敌人出招动作中用突刺打中，伤害高于它待机时的同一下；戴上狮子戒指后这一档加成更大。
10. **FR-伤害-10**：百物防盾正面挡住物理攻击不掉血；元素吸收不满时对应元素漏血；格挡扣光精力后崩架、这一下按未格挡掉血；举盾仍中毒沼持续伤害，异常仍积蓄。
11. **FR-伤害-11**：近战打在硬表面弹刀，不结算伤害；环境持续伤害无视举盾。
