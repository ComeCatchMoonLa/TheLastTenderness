# 回复类消耗品的验收

对应 [回复类消耗品](../功能需求/回复类消耗品.md)。

1. **FR-回复-01**：生命未满时喝血瓶。动作成功后生命上升且不超过上限，武器回到手上。
2. **FR-回复-02**：次数为 0 时再按使用。角色耸肩，生命不变。
3. **FR-回复-03**：喝药动画没播完时连按。次数只减一次。
4. **FR-回复-04**：喝一次后看这名玩家的剩余次数。重新进入游戏，次数仍是剩下的那些，同一瓶资产不被喝成 0。
5. **FR-回复-05**：喝灰瓶只回专注，喝血瓶只回生命；不存在一口同时抬两条的瓶。
6. **FR-回复-06**：次数未满时在燃火休息。次数回到上限。
7. **FR-回复-07**：喝药动作被打断时，已涨的部分保留；按住连喝，每口各减一次次数。
8. **FR-回复-08**：红/紫/蓝苔分别解对应异常，无异常时使用也消耗；短索与引怪头骨投掷后产生各自效果。
