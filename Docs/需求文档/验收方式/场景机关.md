# 场景机关的验收

对应 [场景机关](../功能需求/场景机关.md)。头目死后雾门撤掉另看 FR-头目-06。

1. **FR-机关-01**：在梯子端点交互后上下爬。按住闪避并向下则滑到底。摇杆回中只按闪避则向梯外跳开。没踢倒的短梯，下端没有登梯。
2. **FR-机关-02**：打开一扇门并走过去。休息后再回来，门仍开着。
3. **FR-机关-03**：没有钥匙时锁着的门打不开。钥匙在包里时打开，休息后仍开。
4. **FR-机关-04**：拉一次电梯，平台到另一层。再拉一次，平台回到另一方向。
5. **FR-机关-05**：走进雾门。战斗未结束时走不回去。使用暗印，人留在场内。死亡复活后再进，头目仍是满生命。
6. **FR-机关-06**：对没有打开提示的墙攻击或翻滚撞上。后面的路出现。休息后再来，缺口还在。
7. **FR-机关-07**：打开箱子，物品进包。再交互没有第二份。休息后盖子仍开着。
8. **FR-机关-08**：对拟态打开，被咬并掉血，它变成可锁定的敌人。对另一只先攻击，它站起来，不先咬那一口。投中不死狩人护符后它瘫软，可安全开箱。打死后再回来，原处不再是未开的箱子。
9. **FR-机关-09**：双开门动作长于单开门；非电梯拉杆分永久与可扳回两种；远距杠杆放下的桥不再升起；打坏的掩体碎后保持。梯上轻攻上戳、重攻下打，空精再挨打摔落。
