# 头目的验收

对应 [头目](../功能需求/头目.md)。当前场景三只近战另看 FR-敌人。不按每只头目记招。

1. **FR-头目-01**：没被发现时，巡逻或装睡的敌人不追。把它拉出活动范围，它走回原位并补满生命。归途中再打中，它转回追击，血保持被打过的值。头目在场地里拉开距离，血保持当前值。
2. **FR-头目-02**：让呼救做完，更远的同伴进入战斗。另一次在做完前打断，这些同伴保持待机。
3. **FR-头目-03**：进入雾门后出现带名字的头目血条。打中时下降。头目死亡后血条收起。
4. **FR-头目-04**：打到这场配置的切换条件。动作套或血条更换。切换动作期间血条不动。
5. **FR-头目-05**：独自进雾门记下上限。另一次带一名协助者进入。头目上限高于独自进入。
6. **FR-头目-06**：头目死亡后雾门消失，本周目再来头目不在。配置了新火的场次，点着后出现在传送列表。头目还活着时人死去，新火还不在。
7. **FR-头目-07**：在带场地机关的一场里，看到掉台致死、站在区域里掉血、打位点才掉血、小兵短血条、或打死操纵者后远端攻击消失之中这场配了的那一种。另一场没配时不出现。
8. **FR-头目-08**：把可对话的人打成敌对。对方喝药或翻滚，生命因此变化。打死之后休息，原处不再有对话。
