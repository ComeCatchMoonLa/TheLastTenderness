# 属性与升级的验收

对应 [属性与升级](../功能需求/属性与升级.md)。

1. **FR-属性-01**：改高一项生命、精力或专注等级并让上限重算。对应的满格变长。改低则满格变短。
2. **FR-属性-02**：击杀一只近战。灵魂数字增加。
3. **FR-属性-03**：打开角色属性。能看见各项等级和当前灵魂。换装后等级数字不变。
4. **FR-属性-04**：与防火女对话花灵魂升一级。灵魂减少，等级加一。升生命、精力或专注时满格立刻变长。灵魂不够时等级和灵魂都不变。篝火菜单里没有升级入口。
5. **FR-属性-05**：属性不够武器需求时打一击，记下掉血。满足需求后再打同一段。第二次掉血更多。两次都能挥出去。
6. **FR-属性-06**：智力或信仰低于法术自身要求时施法，没有弹体或治疗、专注不减；只是催化器需求不够时，法术仍放出但结果弱于满足时，催化器战技不能用。
7. **FR-属性-07**：升级前后对比状态页，固定防御与四条异常抗性底子随等级上升。
