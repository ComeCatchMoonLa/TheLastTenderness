# 战斗HUD的验收

对应 [战斗HUD](../功能需求/战斗HUD.md)。锁定标记用镜头条目的 FR-镜头-07。

1. **FR-界面-01**：战斗时三条条都看得见。受伤、喝血、冲刺、回精力时，对应的条跟着变。
2. **FR-界面-02**：轮换武器、切换法术或消耗品。对应快捷栏图标换成新的。
3. **FR-界面-03**：打中近战。头上出血条。停手后隐藏，再打又出现（隐藏延迟按配置）。
4. **FR-界面-04**：走进可交互物再走开。提示出现，离开后消失。
5. **FR-界面-05**：击杀、升级扣灵魂、死亡清零、捡回残留各做一次。每一次 HUD 数字都等于身上的灵魂。
6. **FR-界面-06**：看快捷栏上的回复次数。喝一次减一，到 0 再喝会耸肩，休息后回到上限。
7. **FR-界面-07**：挂异常时看 HUD 图标与积蓄槽；低血时画面边缘发红；无操作后界面自动隐藏、操作唤回；入侵与获得道具各出对应横幅。
