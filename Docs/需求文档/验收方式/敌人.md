# 敌人的验收

对应 [敌人](../功能需求/敌人.md)。

1. **FR-敌人-01**：从正面走进近战的发现范围。它转向并追来。从背后走或隔着墙，它不动。
2. **FR-敌人-02**：让它追到身边。它出手，玩家可以掉血。拉开一段但仍在地图内，它继续跟。
3. **FR-敌人-03**：一击打掉它的韧性，它停下来播受击。韧性够时它继续动并掉血。它挥空时玩家不掉血。
4. **FR-敌人-04**：把它打到 0。它播死亡，不再攻击，玩家灵魂增加。锁着它时锁定结束或改锁别人。尸体何时清掉按 FR-敌人-04 的待实机口径验收。
5. **FR-敌人-05**：追击中跑出它的放弃距离。它沿路径走回放置点、到点补满并待机；巡逻者也回放置点。再走进发现范围，它重新追。
6. **FR-敌人-06**：休息、传送、死亡复活、读档各做一次，普通敌人都回放置点满血；打死的拟态与结晶蜥蜴不回，钻地逃走的蜥蜴再现。
7. **FR-敌人-07**：分别引野兽、大型敌人和一个埋伏点：野兽不吃背刺，大型敌人破韧下跪前不能处决，埋伏敌人在触发前锁不到。
8. **FR-敌人-08**：同一敌人在发现力 100 与 400 下各刷若干次，掉率约为四倍差距；过量一击杀死时灵魂高于基线，头目与坠亡不吃。
