# 既有切片的验收

> **在 `Game` 场景里按编号手动操作。** 对应的需求在 [`../功能需求/`](../功能需求/)。燃火条目先只激活已有的 `CampFireInteractable`。

## 移动与闪避

对应 [玩家移动与闪避](../功能需求/玩家移动与闪避.md)。

1. **FR-移动-01**：按住移动。角色沿镜头方向在地面移动，精力不因此下降。
2. **FR-移动-02**：有方向时按住闪避键。速度快于跑步，精力下降；精力降过门槛后速度回到跑步。
3. **FR-移动-03**：有方向时短按闪避。角色朝输入方向播放翻滚，翻滚时推移动摇不改速度，结束后可以再跑。
4. **FR-移动-04**：站定后短按闪避。角色播放后撤步。
5. **FR-移动-05**：有方向时按跳跃。角色离地并播放下落，落差够时切入落地。瞄准中按跳跃，角色不起跳。落差条件一直成立时会反复切入落地，下落停在该状态，稳定走回地面跟开发计划 0.10。
6. **FR-移动-06**：把精力耗到不够支付，再试翻滚、后撤、跳跃。动作不出现，精力不变。
7. **FR-移动-07**：翻滚途中被近战打中。生命不降。翻滚结束后再被打中，生命下降。
8. **FR-移动-08**：轻推摇杆与推满各走一段。轻推更慢，推满回到跑步，按住闪避仍更快。

## 镜头与锁定

对应 [镜头与锁定](../功能需求/镜头与锁定.md)。

1. **FR-镜头-01**：未锁定时转动视角。镜头绕角色转，俯仰到头后停住。
2. **FR-镜头-02**：把镜头转到墙后。镜头拉近，仍能看见角色；离开墙后距离恢复。
3. **FR-镜头-03**：面对近战敌人按锁定键，再按一次。第一次锁上，第二次回到自由镜头。对着空处按，镜头保持自由。
4. **FR-镜头-04**：锁上敌人后站立。镜头和角色都朝向它。冲刺或翻滚时身体朝移动方向。
5. **FR-镜头-05**：关闭自动换目标，锁中间的敌人，左右各有一只时按左右切换。镜头改看另一只。
6. **FR-镜头-06**：关闭自动换目标后，把目标拽出锁定距离或用墙挡住。有别的敌人时改锁更近的一只；没有时锁定结束。
7. **FR-镜头-07**：锁上时能看见标记，跟着目标。解锁或目标死亡后标记消失。
8. **FR-镜头-08**：双手持弓并有箭时按住瞄准。镜头切到瞄准位置，角色跟着水平转向。松开后离开瞄准。

## 精力

对应 [精力](../功能需求/精力.md)。

1. **FR-精力-01**：开局精力条是满的。做一次翻滚，条变短，数值不超过上限。
2. **FR-精力-02**：分别做冲刺、翻滚、后撤、跳跃、轻击、重击。每一次成功后精力都比动作前少。
3. **FR-精力-03**：冲刺或攻击刚结束时精力不立刻涨。停下片刻后涨回满格并停住。
4. **FR-精力-04**：举盾站立，观察回升。慢于放下盾之后的回升。
5. **FR-精力-05**：精力打到 0 时点轻击和重击。没有攻击动作。回过 0 之后再点，攻击出现。
6. **FR-精力-06**：留下一点点精力，使它大于 0 但小于这一次轻击、重击或武器技的消耗，再操作。动作仍然开始，精力降到 0 以下。精力小于等于 0 时不开始。翻滚、后撤、跳跃见 FR-移动-06。

## 攻击

对应 [轻重攻击与武器技](../功能需求/轻重攻击与武器技.md)。

1. **FR-攻击-01**：精力充足时点轻击槽。角色打出第一段轻击。
2. **FR-攻击-02**：第一段尚在连击窗口时再点轻击。接下一段。窗口过后再点，回到第一段。
3. **FR-攻击-03**：点重击槽，并在连击窗口内再点。先出第一段重击，再接下一段。
4. **FR-攻击-04**：切到双手后再轻击，然后切回单手轻击。两段动作能看出差别。
5. **FR-攻击-05**：按住格挡键再松开。按住时举盾并能移动，松开后盾放下。
6. **FR-攻击-06**：单手、双手各点一次武器技槽。都播放这把武器的武器技。把精力或专注耗到不够再点，动作不出现。（信息待统一，见 [未入池](../../版本候选池/程序功能池/未入池.md)「武器技精力不够时放不放」。功能需求写精力大于 0 就出手，蓝不够仍播放。）
7. **FR-攻击-07**：挥击中段打到敌人会掉血。收招之后用武器贴着敌人，这一下不再掉血。

## 伤害

对应 [命中判定与伤害](../功能需求/命中判定与伤害.md)。

1. **FR-伤害-01**：对近战敌人打出一次命中。它的血变少。把玩家打到 0 时玩家死亡，见燃火条目。
2. **FR-伤害-02**：用同队的伤害体打自己人。生命不变。
3. **FR-伤害-03**：在无敌标志为真时挨打，生命不变。标志结束后挨打，生命下降。
4. **FR-伤害-04**：正面举盾吃下一击，再在同一状态下不举盾吃同一类攻击。举盾时掉血更少，并且精力下降。
5. **FR-伤害-05**：让武器在一次挥击里多次碰到同一敌人。只掉一次血。下一挥再碰到，可以再掉。
6. **FR-伤害-06**：赤裸吃一次火、魔、雷或暗伤害，记下掉血。穿上对应吸收的护甲再吃同样一击，掉血更少。脱掉后回到赤裸的掉血。
7. **FR-伤害-07**：举盾吃到精力被扣光的一击。盾放下，能看见破防硬直，期间不能移动和攻击。结束后可以再举盾。
8. **FR-伤害-08**：穿上同一套甲，各吃一记打击和一记斩击或突刺。两次掉血能分辨。脱掉后再各吃一次，回到赤裸时的差别。

## 霸体与硬直

对应 [霸体与硬直](../功能需求/霸体与硬直.md)。

1. **FR-硬直-01**：用一击打掉敌人韧性。它播受击并停步，血下降。受击结束后它能再动。
2. **FR-硬直-02**：在韧性还够时再打一击。它掉血，攻击或追击不被切成受击。
3. **FR-硬直-03**：连续打到快破韧后停手，等到韧性恢复时间过去。原来能打出硬直的力度若已不够，敌人只掉血。
4. **FR-硬直-04**：用带进攻霸体的挥击时挨一记普通攻击。挥击播完，血下降。挥完再挨同样一击，进入硬直。用不带霸体的挥击挨打，挥击被打断。
5. **FR-硬直-05**：穿上有韧性加成的护甲前后，用同一击打玩家。穿上后不播受击，脱掉后播受击，两次都掉血。

## 负重与翻滚

对应 [负重与翻滚](../功能需求/负重与翻滚.md)。

1. **FR-负重-01**：赤裸看负重，再穿上一套护甲。当前负重变高，上限仍显示。
2. **FR-负重-02**：把负重调到轻、中、重三档，各翻滚一次。三档的距离或时长能分辨，同一档连续两次一致。
3. **FR-负重-03**：负重超过上限时带方向短按闪避。不翻滚，移动慢于跑步。降回上限内后再按，可以翻滚。
4. **FR-负重-04**：装备不变，只提高负重属性直到档位变轻。翻滚观感轻于升级前。
5. **FR-负重-05**：把比例放在大约三成以下、七成以下、十成以下各翻一次，再放到达到或超过十成。前三档能分辨，最后一档不翻滚。卡线和无敌长短按调研里的待核对项看。

## 属性与升级

对应 [属性与升级](../功能需求/属性与升级.md)。

1. **FR-属性-01**：改高一项生命、精力或专注等级并让上限重算。对应的满格变长。改低则满格变短。
2. **FR-属性-02**：击杀一只近战。灵魂数字增加。
3. **FR-属性-03**：打开角色属性。能看见各项等级和当前灵魂。换装后等级数字不变。
4. **FR-属性-04**：在燃火处花灵魂升一级。灵魂减少，等级加一。升生命、精力或专注时满格立刻变长。灵魂不够时等级和灵魂都不变。完整游戏的入口另看 FR-养成-05。
5. **FR-属性-05**：属性不够武器需求时打一击，记下掉血。满足需求后再打同一段。第二次掉血更多。两次都能挥出去。
6. **FR-属性-06**：智力或信仰不够时施法。没有弹体或治疗，专注不减。条件够且专注够时，施法产生效果。

## 装备与道具

对应 [装备与道具](../功能需求/装备与道具.md)。

1. **FR-装备-01**：对拾取物交互。背包里出现该物品，地上的物体消失。
2. **FR-装备-02**：把近战武器装备到一只手。手上出现模型，用这只手打中会掉血。换成另一把，模型跟着换。
3. **FR-装备-03**：头、躯干、下身各穿一件。外形变成对应护甲。同一部位再穿一件，外形换成新的，旧的回到背包。
4. **FR-装备-04**：一只手有多把武器时按轮换。模型和下一击换成下一把。
5. **FR-装备-05**：做一次双手切换再切回来。双手时攻击符合攻击文档的双手动作，切回后左右手装备恢复。
6. **FR-装备-06**：打开装备窗，选中方向键能轮换到的靠后武器。手上的模型改成它。
7. **FR-装备-07**：在背包点一件法术和一件消耗品。快捷栏图标改成这两件，随后施法和使用键作用于它们。
8. **FR-装备-08**：护甲不变，把重武器放进备用槽。负重上升。卸回背包后负重回落。戴上戒指，负重不因戒指增减。

## 回复类消耗品

对应 [回复类消耗品](../功能需求/回复类消耗品.md)。

1. **FR-回复-01**：生命未满时喝血瓶。动作成功后生命上升且不超过上限，武器回到手上。
2. **FR-回复-02**：次数为 0 时再按使用。角色耸肩，生命不变。
3. **FR-回复-03**：喝药动画没播完时连按。次数只减一次。
4. **FR-回复-04**：喝一次后看这名玩家的剩余次数。重新进入游戏，次数仍是剩下的那些，同一瓶资产不被喝成 0。
5. **FR-回复-05**：喝配置了专注回复的瓶子。专注上升。只配了生命的瓶子只加生命。
6. **FR-回复-06**：次数未满时在燃火休息。次数回到上限。

## 敌人

对应 [敌人](../功能需求/敌人.md)。

1. **FR-敌人-01**：从正面走进近战的发现范围。它转向并追来。从背后走或隔着墙，它不动。
2. **FR-敌人-02**：让它追到身边。它出手，玩家可以掉血。拉开一段但仍在地图内，它继续跟。
3. **FR-敌人-03**：一击打掉它的韧性，它停下来播受击。韧性够时它继续动并掉血。它挥空时玩家不掉血。
4. **FR-敌人-04**：把它打到 0。它播死亡，不再攻击，玩家灵魂增加。锁着它时锁定结束或改锁别人。稍后它消失。
5. **FR-敌人-05**：追击中跑出它的放弃距离。它回到原位并待机。再走进发现范围，它重新追。

## 燃火与死亡

对应 [燃火休息与死亡惩罚](../功能需求/燃火休息与死亡惩罚.md)。先激活场景里已有的燃火物体。

1. **FR-燃火-01**：对未点燃的燃火交互。出现燃起提示和火焰，提示变为「休息」。
2. **FR-燃火-02**：先把生命、精力、专注打掉一些，再对已点燃的燃火休息。三项回到满格，完成后可以走动。
3. **FR-燃火-03**：打死一只近战并等它消失，再休息。它回到原位，满血，会再发现玩家。
4. **FR-燃火-04**：药瓶次数未满时休息。次数回到上限。
5. **FR-燃火-05**：带着灵魂被打死。不能再操作，灵魂数字为 0，死亡处出现可交互的残留。
6. **FR-燃火-06**：休息后走到残留处交互。残留消失，灵魂数字加上那一笔。
7. **FR-燃火-07**：残留还在时再获得灵魂并再次死亡。旧残留没了，新残留只等于这次身上的灵魂。
8. **FR-燃火-08**：玩家血到 0。死亡动作出现，再按移动、攻击、喝药都没有新动作。

## 战斗 HUD

对应 [战斗 HUD](../功能需求/战斗HUD.md)。锁定标记用镜头条目的 FR-镜头-07。

1. **FR-界面-01**：战斗时三条条都看得见。受伤、喝血、冲刺、回精力时，对应的条跟着变。
2. **FR-界面-02**：轮换武器、切换法术或消耗品。对应快捷栏图标换成新的。
3. **FR-界面-03**：打中近战。头上出血条。停手约两秒后隐藏，再打又出现。
4. **FR-界面-04**：走进可交互物再走开。提示出现，离开后消失。
5. **FR-界面-05**：击杀、升级扣灵魂、死亡清零、捡回残留各做一次。每一次 HUD 数字都等于身上的灵魂。
6. **FR-界面-06**：看快捷栏上的回复次数。喝一次减一，到 0 再喝会耸肩，休息后回到上限。
