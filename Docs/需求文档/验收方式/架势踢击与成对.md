# 架势、踢击与成对武器的验收

对应 [架势踢击与成对](../功能需求/架势踢击与成对.md)。

1. **FR-架势-01**：战技键进入架势。姿势里按轻攻击和按重攻击，打出能分辨的两击，打中掉血。
2. **FR-架势-02**：进入架势后不接轻击和重击。角色回到可移动，没有派生伤害。被打中时姿势断开。
3. **FR-架势-03**：成对武器打出连段，一次里能打中不止一下，精力下降。这段里举不起正面的盾。战技键仍放出战技，蓝下降。
4. **FR-架势-04**：左右手各拿一把不成对的武器。左手攻击只打单下。左手是弹反盾时，战技键是弹反。
5. **FR-架势-05**：不冲刺时向前加轻攻击，踢出一脚。踢中举盾且精力偏低的目标，对方精力大减，见底时弯腰。冲刺中向前加轻攻击，走出跑动攻击。
