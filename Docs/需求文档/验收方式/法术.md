# 法术的验收

对应 [法术](../功能需求/法术.md)。

1. **FR-法术-01**：买下、捡到或用首领魂换到一条法术。它在持有列表里。不放进记忆栏时，战斗轮换里没有它。
2. **FR-法术-02**：用法杖放魔法，有弹体或该条的效果，蓝下降。换成圣铃放同一条，没有效果。奇迹用圣铃或护符放得出，用火焰催化器放不出。火焰法术只用火焰催化器放得出。
3. **FR-法术-03**：坐下后把法术放进空栏。战斗里能轮到它。栏满时再放不进去。战斗中打不开整理页。
4. **FR-法术-04**：蓝够时分别按四种催化器的战技。法杖让下一发更疼，圣铃持续回血，护符让下一次奇迹挨普通打时读条继续，火焰打出近身火。蓝不够时这些效果都没有。
5. **FR-法术-05**：投射打中敌人掉血。打在举着的盾上按吸收结算。翻滚穿过时不掉血。
6. **FR-法术-06**：生命未满时放治疗。生命上升且不超过上限。换威力更高的同系催化器，回得更多，仍不超过上限。
7. **FR-法术-07**：对允许附魔的武器施放附魔，随后命中多一段伤害。换武器或时间结束后这段没了。对涂不上的注入武器施放，没有这段。
8. **FR-法术-08**：蓝低于消耗时施法。有短动作，没有弹体或治疗，蓝不为负。记忆栏为空时同样没有效果。
