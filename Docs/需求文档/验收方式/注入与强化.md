# 注入与强化的验收

对应 [注入与强化](../功能需求/注入与强化.md)。

1. **FR-注入-01**：把已强化的武器注入一种，再改成另一种。面板换成新的伤害种类，加号还在，旧宝石不回到包里。
2. **FR-注入-02**：炭火还在包里时，安德烈的菜单没有这一组。交出去之后，这一组可以选。
3. **FR-注入-03**：普通武器加到加十后没有下一级。鳞片武器和闪耀矿石武器加到加五后没有下一级。
4. **FR-注入-04**：在王座选一项换掉首领魂。魂消失，选中的进入背包或学会列表。把魂直接用成灵魂后，王座不能再用这枚去换。
5. **FR-注入-05**：对鳞片或闪耀路线的武器打开注入。十五种都不在菜单里。
6. **FR-注入-06**：让五项需求里任一项不足，挥同一段。动作慢于全部满足时。伤害高低另看 FR-属性-05。
7. **FR-注入-07**：戴满四枚。第五枚戴不上。按类型各看一次状态页、回复、翻滚、施法或处决、或空虚外形。遮外形的那枚戴上后暗印还在。
8. **FR-注入-08**：给未注入、原质或空虚的武器涂附魔，命中多出一段，时间结束后没有。给重或元素注入再涂，没有这段。
