# 燃火休息与死亡惩罚的验收

对应 [燃火休息与死亡惩罚](../功能需求/燃火休息与死亡惩罚.md)。先激活场景里已有的 `CampFireInteractable`。

1. **FR-燃火-01**：对未点燃的燃火交互。出现燃起提示和火焰，提示变为「休息」。
2. **FR-燃火-02**：先把生命、精力、专注打掉一些，再对已点燃的燃火休息。三项回到满格，完成后可以走动。
3. **FR-燃火-03**：打死一只近战并等它消失，再休息。它回到原位，满血，会再发现玩家。
4. **FR-燃火-04**：药瓶次数未满时休息。次数回到上限。
5. **FR-燃火-05**：带着灵魂被打死。不能再操作，灵魂数字为 0，死亡处出现可交互的残留。
6. **FR-燃火-06**：休息后走到残留处交互。残留消失，灵魂数字加上那一笔。
7. **FR-燃火-07**：残留还在时再获得灵魂并再次死亡。旧残留没了，新残留只等于这次身上的灵魂。
8. **FR-燃火-08**：玩家血到 0。死亡动作出现，再按移动、攻击、喝药都没有新动作。复活后精力专注回满、两瓶按分配补满、普通敌人重置。
9. **FR-燃火-09**：带毒/出血状态坐下，状态清掉；开门、拾取、NPC 进度在休息后保持；普通敌人全图回放置点，头目不回；击倒敌人后有机率回瓶。
