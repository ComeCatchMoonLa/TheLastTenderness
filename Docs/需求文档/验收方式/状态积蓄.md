# 状态积蓄的验收

对应 [状态积蓄](../功能需求/状态积蓄.md)。比例和时长按调研里的待核对项。

1. **FR-异常-01**：连续打出血直到槽满。目标立刻再掉一截血，槽清空。蓄满前停手，槽往回掉。
2. **FR-异常-02**：蓄满中毒。目标持续掉血。用紫苔后停止。
3. **FR-异常-03**：蓄满剧毒。持续掉血，精力回复变慢。普通紫苔不去掉它。开花紫苔使掉血停止。
4. **FR-异常-04**：蓄满冰霜。立刻掉血，随后吸收变差或精力回复变慢。吃到火焰伤害后这层消失。
5. **FR-异常-05**：蓄满咒死。目标死亡。槽没满时离开来源，槽回落，目标还活着。
6. **FR-异常-06**：在翻滚受击豁免里吃到会积蓄的一击。生命不变，槽也不升。豁免结束后再吃，槽上升。
