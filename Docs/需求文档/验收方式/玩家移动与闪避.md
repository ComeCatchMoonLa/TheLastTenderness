# 玩家移动与闪避的验收

对应 [玩家移动与闪避](../功能需求/玩家移动与闪避.md)。

1. **FR-移动-01**：按住移动。角色沿镜头方向在地面移动，精力不因此下降。
2. **FR-移动-02**：有方向时按住闪避键。速度快于跑步，精力下降；精力降过门槛后速度回到跑步。
3. **FR-移动-03**：有方向时短按闪避。角色朝输入方向播放翻滚，翻滚时推移动摇不改速度，结束后可以再跑。
4. **FR-移动-04**：站定后短按闪避。角色播放后撤步。
5. **FR-移动-05**：冲刺中按跳跃。角色朝冲刺方向离地并播放下落，落差够时切入落地；只是跑步不冲刺时按跳跃，不起跳。瞄准中按跳跃，角色不起跳。落地后能走。点 Play 后、运行中点层级面板之后，角色仍站在地上，不悬空、不陷进地里停在下落。
6. **FR-移动-06**：把精力耗到不够支付，再试翻滚、后撤、跳跃。动作不出现，精力不变。
7. **FR-移动-07**：翻滚途中被近战打中。生命不降。翻滚结束后再被打中，生命下降。
8. **FR-移动-08**：轻推摇杆与推满各走一段。轻推更慢，推满回到跑步，按住闪避仍更快。
9. **FR-移动-09**：从小落差、中落差、超过致死高度各落下一次。无伤、扣血且硬直更长、直接死亡三档能分辨；银猫/静步压低扣血但越过致死高度仍死。
10. **FR-移动-10**：冲刺中重击出跳跃攻击；空中重击出下落攻击，打倒地敌人后能接处决。
11. **FR-移动-11**：不停顿连续翻滚，每一次精力消耗高于上一次；停顿后回基础。
