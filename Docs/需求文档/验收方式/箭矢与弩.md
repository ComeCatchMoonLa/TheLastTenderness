# 箭矢与弩的验收

对应 [箭矢与弩](../功能需求/箭矢与弩.md)。瞄准镜头另看 FR-镜头-08。

1. **FR-远程-01**：双手持弓，快射一发，箭少一，打中掉血。重攻击拉得更久，打中时的冲击或伤害与快射能分辨。箭没飞出就取消时，数量不减少。
2. **FR-远程-02**：弩加螺栓能射中并少一枚螺栓。给弩装普通箭，没有飞行物。大弓加大箭能射出。大弓装普通箭，没有飞行物。
3. **FR-远程-03**：当前弹打到 0 再拉弓或扣弩。没有新的飞行物。补上数量大于 0 的同种弹后再射，飞行物出现并且少一枚。
4. **FR-远程-04**：箭打在墙上停下，墙后的敌人不掉血。打在身上掉血。举盾挡住时按盾的吸收结算。
5. **FR-远程-05**：用毒箭或出血箭打中，对应槽上升。换普通箭打同一目标，那条槽不因此上升。
