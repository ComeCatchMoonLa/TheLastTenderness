# 篝火菜单的验收

对应 [篝火菜单](../功能需求/篝火菜单.md)。休息回满和死亡留魂另看既有切片里的 FR-燃火。

1. **FR-篝火-01**：对已点燃的篝火坐下。菜单里是传送、整理法术、储物箱、离开。没有升级和分瓶。离开后角色站起，刚才补上的生命还在。
2. **FR-篝火-02**：在列表里选另一处已点燃的火。读条后站在那处火前。没点燃的名字不在表上。
3. **FR-篝火-03**：在一处火把未装备的道具放进箱子。到另一处火打开，还能取回。死亡后再看，仍在箱里。
4. **FR-篝火-04**：坐下后进入整理法术，改一格。站起来后战斗轮换与这格一致。不坐下时打不开这页。
5. **FR-篝火-05**：在安德烈处把次数全划给血瓶，再划一部分给灰瓶。总次数不变。休息后补满的是这一轮划分。
6. **FR-篝火-06**：在传火祭祀场把一枚瓶碎片交给铁匠安德烈。血瓶加灰瓶的总次数加一。达到十五口后再交，总次数不变。
7. **FR-篝火-07**：在同一处烧掉一枚未死人骨片。两只瓶每一口的回复提高，次数不增加。
8. **FR-篝火-08**：身边还有敌对目标时对篝火交互。角色站着，生命和次数不按休息补满。目标清空后再交互，可以坐下。
