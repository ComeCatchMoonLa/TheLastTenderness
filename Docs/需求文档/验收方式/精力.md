# 精力的验收

对应 [精力](../功能需求/精力.md)。

1. **FR-精力-01**：开局精力条是满的。做一次翻滚，条变短，数值不超过上限。
2. **FR-精力-02**：分别做冲刺、翻滚、后撤、跳跃、轻击、重击。每一次成功后精力都比动作前少。
3. **FR-精力-03**：冲刺或攻击刚结束时精力不立刻涨。停下片刻后涨回满格并停住。
4. **FR-精力-04**：举盾站立，观察回升。慢于放下盾之后的回升。
5. **FR-精力-05**：精力打到 0 时点轻击和重击。没有攻击动作。回过 0 之后再点，攻击出现。
6. **FR-精力-06**：留下一点点精力，使它大于 0 但小于这一次轻击、重击或武器技的消耗，再操作。动作仍然开始，精力降到 0 以下。精力小于等于 0 时不开始。翻滚、后撤、跳跃见 FR-移动-06。
