# 联机的验收

对应 [联机](../功能需求/联机.md)。自己的灵魂血迹另看 FR-燃火-05。等级区间和上交数量按调研里的待核对项。

1. **FR-联机-01**：装备一枚盟约印记，标记颜色或队列按它变化。换成另一枚，旧队列不再拉走这名角色。
2. **FR-联机-02**：把上交物交到第一档，得到一件奖励。交到第二档，再得到一次。同一周目同一档再交，不重复拿到已经领过的那一件。
3. **FR-联机-03**：余烬状态下对白色协助符召唤，人进来并出现头像。去掉余烬后再对符交互，召不进来。区域头目死后，协助符召不进来。
4. **FR-联机-04**：协助者打主人，主人不掉血。入侵者打主人，主人掉血。紫色幻影打主人，主人掉血。
5. **FR-联机-05**：入侵者打死主人后被送回，并得到该盟约的上交物。另一次让主人走进雾门，入侵者离开且没有这份上交物。
6. **FR-联机-06**：被白符或黄符召进去的人，能喝的次数是自己上限对半向下取整，生命上限是未余烬的那一档。回到自己的世界后，次数和上限按离开前自己的瓶子和余烬，不把别人世界里的空瓶永久写成 0。
7. **FR-联机-07**：在线时读一条留言并评好。作者若在线，生命少量上升。交互别人的暗红血渍，播放死亡动作，自己的灵魂数不变。离线后再看，这些留言和暗红血渍不出现。
8. **FR-联机-08**：离线走进教堂枪兵的雾门。头目血条出现，对手是本地角色。在线匹配到穿印记的人时，血条上是那名玩家。
9. **FR-联机-09**：入侵者站在普通敌人前，敌人追主人。主人使用巨人种子后，敌人可以改去打入侵者。
10. **FR-联机-10**：戴青教被入侵时系统呼叫蓝色守卫；青色守护者或暗月被自动拉进被入侵世界；法隆、奥尔德里奇在对应区域被系统自动入侵、头目死后停止；干燥手指改变在场人数槽位。另验头目门口的具名 NPC 召唤符：余烬时可见、召入占协助名额（FR-联机-03）。
