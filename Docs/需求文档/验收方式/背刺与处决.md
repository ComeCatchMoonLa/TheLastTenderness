# 背刺与处决的验收

对应 [背刺与处决](../功能需求/背刺与处决.md)。

1. **FR-处决-01**：站在人形背后贴住按轻攻击。双方锁进动画，目标掉一次血。鞭在同样位置打出的是普通一击，不锁动画。
2. **FR-处决-02**：站偏或站远再按轻攻击。普通攻击命中，不锁背刺动画。
3. **FR-处决-03**：在攻击落到身上的短窗口按弹反。对方弯腰。贴上去轻攻击，锁进处决，掉一次血。窗口对不上时自己掉血，对方不弯腰。
4. **FR-处决-04**：把对方盾的精力打空或踢到弯腰，再贴身轻攻击。进入处决。盾还举着、精力没空时，这一下是普通攻击。
5. **FR-处决-05**：对野兽贴背轻攻击。普通一击，不锁背刺。对人形在同样条件下进入 FR-处决-01。
