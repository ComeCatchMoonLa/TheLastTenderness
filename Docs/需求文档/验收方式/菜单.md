# 菜单的验收

对应 [菜单](../功能需求/菜单.md)。战斗三条条另看 FR-界面。

1. **FR-菜单-01**：打开暂停。能进背包、状态、姿态。列里没有升级。结束游戏再进来，人停在退出时的位置。
2. **FR-菜单-02**：背包里翻到武器、防具、戒指、道具、法术各看一页。把一件道具放进快捷格，战斗里能用它。钥匙按使用键喝不掉。
3. **FR-菜单-03**：装备界面能看见右手三槽、左手三槽、头身手脚、四个戒指槽。装备第三把武器后，轮换能拿到它。穿上手和腿，对应外形更换。
4. **FR-菜单-04**：光标停在另一件上，变高和变低的数字能区分。确认前模型不变。确认后模型更换，负重跨档时下一次翻滚按新档。
5. **FR-菜单-05**：打开状态，读到九项、负重、吸收和下一级所需灵魂。这一页不能确认加点。
6. **FR-菜单-06**：选一个已解锁姿态。角色做出动作，播完可以再走。新得到的姿态出现在列表里。
7. **FR-菜单-07**：快捷格从血瓶切到别的道具。血瓶和灰瓶的次数仍单独显示。
8. **FR-菜单-08**：暂停和背包里没有可点房间的地图。换区域靠篝火列表里的名字。
