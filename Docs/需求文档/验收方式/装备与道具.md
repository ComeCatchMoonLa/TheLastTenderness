# 装备与道具的验收

对应 [装备与道具](../功能需求/装备与道具.md)。

1. **FR-装备-01**：对拾取物交互。背包里出现该物品，地上的物体消失。
2. **FR-装备-02**：把近战武器装备到一只手。手上出现模型，用这只手打中会掉血。换成另一把，模型跟着换。
3. **FR-装备-03**：头、躯干、下身各穿一件。外形变成对应护甲。同一部位再穿一件，外形换成新的，旧的回到背包。
4. **FR-装备-04**：一只手有多把武器时按轮换。模型和下一击换成下一把。
5. **FR-装备-05**：做一次双手切换再切回来。双手时攻击符合攻击文档的双手动作，切回后左右手装备恢复。
6. **FR-装备-06**：打开装备窗，选中方向键能轮换到的靠后武器。手上的模型改成它。
7. **FR-装备-07**：在背包点一件法术和一件消耗品。快捷栏图标改成这两件，随后施法和使用键作用于它们。
8. **FR-装备-08**：护甲不变，把重武器放进备用槽。负重上升。卸回背包后负重回落。戴上一枚有重量的戒指，负重增加；装卸箭或螺栓，负重不变。
9. **FR-装备-09**：四件护甲（头、躯干、护手、腿）分属不同套装穿上。四个部位外形各自更换，卸下的部位不再贡献。
10. **FR-装备-10**：切换武器期间有收刀动作，挨打打断后仍拿旧武器；成对武器成对持握时不能用盾；喝药时武器收起。
11. **FR-装备-11**：盾走格挡、火炬照明、空手出拳头、弓弩法器各有握法，类别差异能分辨。
12. **FR-装备-12**：武器耐久打到三成以下伤害约七成、到 0 约五成；未破时坐火修满，破了坐火不修，修理粉只修未破装备。
