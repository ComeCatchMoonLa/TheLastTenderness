# 角色养成的验收

对应 [角色养成](../功能需求/角色养成.md)。

1. **FR-养成-01**：完成一次创角，选外形、名字、职业和一件赠礼（或明确不拿）。进游戏后外形与选择一致，赠礼在包里，开局装备对得上该职业。
2. **FR-养成-02**：打开状态页，读到九项。只加生命力，生命上限变长；只加耐力，精力上限变长；只加体力，负重上限变长。
3. **FR-养成-03**：把集中力停在门槛下，记住法术栏格数。跨过下一档后再看，格子变多。门槛按调研里的待核对项。
4. **FR-养成-04**：拿一把单手力量不够、双手够的武器。单手挥得慢，双手握之后同一段恢复正常。另一项属性仍不够时，双手仍然慢。
5. **FR-养成-05**：和防火女对话，打开升级，看预览和花费。灵魂够时确认，等级加一。灵魂不够时等级不变。篝火菜单里没有升级。
6. **FR-养成-06**：在罗莎莉亚处把点数挪到另一项并确认。灵魂等级不变，被减的项不低于职业起点。确认前退出，舌头还在。本周目和改造合起来用满五次后再确认，点数不再变。进入下一周目后又能做。
7. **FR-养成-07**：做一次改造并确认。外形变了，九项点数不变。
8. **FR-养成-08**：做一次免费升级，得到暗印。死亡后外形更枯。用净化石后外形恢复，再死一次又变枯。防火女清除暗印后再死，空虚不再上升。
