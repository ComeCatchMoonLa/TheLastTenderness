# 负重与翻滚的验收

对应 [负重与翻滚](../功能需求/负重与翻滚.md)。

1. **FR-负重-01**：赤裸看负重，再穿上一套护甲。当前负重变高，上限仍显示。
2. **FR-负重-02**：把负重调到轻、中、重三档，各翻滚一次。三档的距离或时长能分辨，同一档连续两次一致。
3. **FR-负重-03**：负重超过上限时带方向短按闪避。不翻滚，移动慢于跑步。降回上限内后再按，可以翻滚。
4. **FR-负重-04**：装备不变，只提高负重属性直到档位变轻。翻滚观感轻于升级前。
5. **FR-负重-05**：把比例放在大约三成以下、七成以下、十成以下各翻一次，再放到达到或超过十成。前三档能分辨，最后一档不翻滚。卡线和无敌长短按调研里的待核对项看。
