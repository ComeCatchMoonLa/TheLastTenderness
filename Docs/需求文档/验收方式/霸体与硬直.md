# 霸体与硬直的验收

对应 [霸体与硬直](../功能需求/霸体与硬直.md)。

1. **FR-硬直-01**：用一击打掉敌人韧性。它播受击并停步，血下降。受击结束后它能再动。
2. **FR-硬直-02**：在韧性还够时再打一击。它掉血，攻击或追击不被切成受击。
3. **FR-硬直-03**：连续打到快破韧后停手，等到韧性恢复时间过去。原来能打出硬直的力度若已不够，敌人只掉血。
4. **FR-硬直-04**：用带进攻霸体的挥击时挨一记普通攻击。挥击播完，血下降。挥完再挨同样一击，进入硬直。用不带霸体的挥击挨打，挥击被打断。
5. **FR-硬直-05**：穿上有韧性加成的护甲前后，用同一击打玩家。穿上后不播受击，脱掉后播受击，两次都掉血。
6. **FR-硬直-06**：用不同等级的攻击打出轻硬直、重硬直、击飞、击倒四档；崩架倒地能接处决，普通击飞倒地不能。
