# TheLastTenderness

玩家能走通《黑暗之魂 3》本体与两部资料片里、由代码驱动的那些系统，并且每一步都能亲手操作、看见结果。

**运行。** Unity **6000.5.9f1**。打开 `Assets/Scenes/Game.unity`，点 Play。

**边界。** 验收的是能操作、能看见的行为。画质、关卡怎么铺、剧情文本不在完成定义里。

**进度。** 做到哪一版看 [`Docs/开发计划/README.md`](Docs/开发计划/README.md)。做完的记在 [`Docs/更新日志/更新日志.md`](Docs/更新日志/更新日志.md)。文档入口在 [`Docs/README.md`](Docs/README.md)，资源在哪在 [`Assets/README.md`](Assets/README.md)。
